# 【万能文章型二一】注文・味の好み・アレルギー指定のパターン構文（Tolong jangan pakai / Kurangi / Alergi terhadap）

インドネシアの食堂（ワルン）やカフェ、レストランで、自分の好みや健康状態に合わせて味付けをカスタマイズするためのパターン構文です。

インドネシア料理はデフォルトで「激辛（pedas）」「甘い（manis）」「化学調味料（MSG/micin）」がたっぷり入っていることが一般的です。胃腸を守り、アレルギー事故を防ぎ、美味しく食事を楽しむためには、**「〜を入れないで」「〜を控えめに」「別添えにして」「アレルギーがあります」**の4大パターン構文を注文時に堂々と伝えられるようにしておくことが不可欠です。

本記事では、食事の味付けカスタマイズ・アレルギー指定の4大パターン構文を演習します。

---

## パターン1：【完全排除】〜を絶対に入れないでください（Tolong jangan pakai + 食材 / 調味料）

苦手な食材、宗教的・アレルギー的にNGな調味料を完全に抜きにして注文する型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Tolong jangan pakai + [食材 / 調味料] + ya. / Tanpa + [食材 / 調味料], ya.
> ```
> `Tanpa gula`（無糖）、`Tanpa cabe`（唐辛子抜き）など、「Tanpa + 名詞」の短縮形も店員に100%通じます。

### 🔄 差し替え用パーツ一覧

| 場面 | [食材 / 調味料] | 日本語 | 意味 |
| :--- | :--- | :--- | :--- |
| **辛さ** | `cabe / sambal sama sekali` | 唐辛子／サンバル全く無し | 辛味をゼロにする |
| **糖分** | `gula / sirup manis` | 砂糖／甘いシロップ | 完全に無糖のお茶・コーヒー |
| **調味料** | `micin / MSG / vetsin` | 化学調味料（味の素） | 味の素抜きで自然な味付け |
| **香草** | `daun ketumbar / seledri` | パクチー／セロリの葉 | 香草系の薬味抜き |
| **氷** | `es batu` | 氷 | 常温・氷なしの飲み物 |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Mas, nasi gorengnya <strong>tolong jangan pakai cabe sama sekali</strong> ya, tidak pedas.</div>
<div class="id-translation">店員さん、ナシゴレンは唐辛子を一切入れないでくださいね。辛くしないで。【注文】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mbak, pesan es teh manis satu, tapi <strong>tanpa gula sama sekali (es teh tawar)</strong> ya.</div>
<div class="id-translation">すみません、冷たいお茶を1つ、でも砂糖は完全に入れない（無糖アイスティー）でお願いします。【カフェ】</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong <strong>jangan pakai micin</strong> ya di kuah baksonya.</div>
<div class="id-translation">バッソ（肉団子）のスープに化学調味料（MSG）を入れないでくださいね。【食堂】</div>
</div>

## パターン2：【分量調整】〜を控えめに／少なめにしてください（Kurangi + 調味料 / Sedikit saja）

完全に抜くのではなく、「少しだけなら大丈夫」「控えめにしたい」という大人の味覚調整型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Tolong kurangi + [調味料], sedikit saja ya.
> ```
> 「Less sugar」「Less spicy」をインドネシア語で的確に伝える型です。

### 🔄 差し替え用パーツ一覧

| 場面 | [調味料] | 表現 | 意味 |
| :--- | :--- | :--- | :--- |
| **甘さ** | `gulanya (less sugar)` | `sedikit saja ya` | 砂糖控えめでほんの少しだけ |
| **辛さ** | `pedasnya (sedang)` | `cabainya satu biji saja` | 唐辛子は1本だけに抑える |
| **油分** | `minyaknya` | `jangan terlalu berminyak` | 油っこくなりすぎないようにする |
| **塩分** | `garamnya` | `jangan terlalu asin` | しょっぱくなりすぎないようにする |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Kopi susunya tolong <strong>kurangi gulanya ya</strong>, manisnya sedikit saja.</div>
<div class="id-translation">カフェラテ（コーヒースス）の砂糖を少なめにしてください。甘さは控えめで。【カフェ】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mas, tolong <strong>pedasnya sedang saja</strong>, jangan terlalu banyak cabe ya.</div>
<div class="id-translation">お兄さん、辛さは中くらいにしてね、唐辛子を入れすぎないで。【屋台】</div>
</div>

## パターン3：【別添えの指定】〜を別の小皿に分けてください（Minta dipisah）

サンバルやソースを最初から料理に混ぜられると激辛になって食べられないため、「別添え」を頼む安全策の型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Tolong [調味料 / ソース] dipisah ya. / Minta [調味料] di mangkuk kecil.
> ```
> `dipisah`（分けられる＝受動態）は、旅行者や駐在員が最も重宝する魔法のキーワードです。

### 🔄 差し替え用パーツ一覧

| 場面 | [調味料 / ソース] | 意味 |
| :--- | :--- | :--- |
| **サンバル** | `sambalnya tolong dipisah` | サンバル（辛味ペースト）を別添えにする |
| **スープ** | `kuahnya tolong dipisah dari mie` | スープを麺と別々の器にする |
| **タレ** | `bumbu kacangnya dipisah` | ピーナッツソースを別添えにする（ガドガド等） |
| **氷** | `es batunya tolong dipisah di gelas lain` | 氷を別のグラスに分けてもらう |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Mas, untuk ayam bakarnya, <strong>sambalnya tolong dipisah di piring kecil</strong> ya.</div>
<div class="id-translation">店員さん、アヤム・バカール（焼き鳥）のサンバルは小皿に分けて別添えにしてくださいね。【レストラン】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mie ayam ini <strong>kuahnya tolong dipisah</strong> ya, jangan langsung disiram.</div>
<div class="id-translation">このチキンヌードルはスープを別添えにしてください。直接かけないでね。【食堂】</div>
</div>

## パターン4：【アレルギー申告】私は〜のアレルギーがあります（Saya alergi terhadap...）

健康や命に関わるアレルギー情報を正確かつ毅然と伝える型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Maaf, saya alergi terhadap + [アレルゲン食材]. Apakah makanan ini mengandung [食材]?
> ```
> `alergi` はオランダ語起源の国際共通語です。

### 🔄 差し替え用パーツ一覧

| 場面 | [アレルゲン食材] | 意味 |
| :--- | :--- | :--- |
| **甲殻類** | `udang dan kepiting (seafood)` | エビとカニ（甲殻類） |
| **ナッツ類** | `kacang tanah / kacang-kacangan` | ピーナッツ／ナッツ類 |
| **卵** | `telur ayam` | 鶏卵 |
| **乳製品** | `susu sapi / produk olahan susu` | 牛乳／乳製品 |
| **小麦** | `tepung terigu (gluten)` | 小麦粉（グルテン） |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Maaf Mas, <strong>saya alergi terhadap udang</strong>. Apakah nasi goreng ini ada udangnya?</div>
<div class="id-translation">すみません、私はエビアレルギーがあります。このナシゴレンにはエビが入っていますか？【アレルギー確認】</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya <strong>alergi parah terhadap kacang tanah</strong>, tolong jangan sampai tercampur ya.</div>
<div class="id-translation">私はピーナッツに対する重度のアレルギーがありますので、絶対に混入しないようお願いします。【安全確保】</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

型の空欄を埋めて、料理注文やアレルギー指定の文を完成させてみましょう。

<details class="id-quiz">
<summary>練習1：【別添え】「サンバルは別皿に分けていただけますか？」（型：Sambalnya tolong dipisah...）</summary>
<strong>正解: Sambalnya tolong dipisah di piring kecil ya.</strong><br>
解説: 
- <code>dipisah</code> は「別添えにする・分ける」。辛さ事故を防ぐ最重要フレーズです。
</details>

<details class="id-quiz">
<summary>練習2：【砂糖抜き】「無糖のアイスティーを1つお願いします。」（型：Pesan es teh tawar / tanpa gula...）</summary>
<strong>正解: Tolong pesan es teh tawar satu (es teh tanpa gula) ya.</strong><br>
解説: 
- 単に「Es teh manis」と頼むと激甘になります。砂糖抜きは <code>Es teh tawar</code> または <code>tanpa gula</code> です。
</details>

<details class="id-quiz">
<summary>練習3：【アレルギー】「私はエビのアレルギーがあります。」（型：Saya alergi terhadap...）</summary>
<strong>正解: Saya alergi terhadap udang.</strong><br>
解説: 
- <code>alergi terhadap [アレルゲン]</code> の指定構文です。
</details>
