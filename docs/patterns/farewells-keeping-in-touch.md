# 別れの挨拶・連絡維持のパターン構文（Sampai ketemu lagi / Kabari ya / Hubungi saya lewat WhatsApp）

日常の別れ際や、帰任・帰国・送別会、または出張先での別れの場面で、温かい別れの言葉を述べ、今後も連絡を取り合い続けるための構文パターンです。

再会を約束し、良好な関係を保つための必須表現を整理します。

---

## 1. 最重要パターン型一覧

| パターン構文 | 意味 | ニュアンス・使用場面 |
| :--- | :--- | :--- |
| **Sampai jumpa / Sampai ketemu lagi!** | またお会いしましょう！またね！ | 日常および公式な別れの定番 |
| **Kabari saya kalau [Kondisi] ya!** | [条件]の時は知らせてね！連絡ちょうだいね！ | 友人・同僚への連絡リクエスト |
| **Jangan sungkan untuk menghubungi saya lewat WhatsApp** | どうぞ遠慮なくWhatsAppでご連絡ください | ビジネス・親しい関係での連絡維持 |
| **Hati-hati di jalan dan selamat sampai tujuan!** | 道中気をつけて、無事に目的地に着きますように！ | 見送る際のお決まりの祈り |

---

## 2. 実践例文カード

<div class="id-example">
<div class="id-sentence">Terima kasih atas pertemuan hari ini. Sampai ketemu lagi di rapat minggu depan ya!</div>
<div class="id-translation">本日のミーティングありがとうございました。来週の会議でまたお会いしましょう！</div>
<div class="id-explanation">sampai ketemu lagi（また会う時まで、またね）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Kalau kamu ada waktu senggang di Jakarta, kabari aku ya, nanti kita nongkrong bareng lagi!</div>
<div class="id-translation">もしジャカルタで暇な時間（空き時間）ができたら、連絡してね。また一緒にダベろう！</div>
<div class="id-explanation">waktu senggang（空き時間、余暇） / kabari（知らせる、一報を入れる）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Selamat jalan, semoga penerbangan Anda menyenangkan dan selamat sampai kembali di Tokyo. Tetap jaga komunikasi ya!</div>
<div class="id-translation">道中ご無事で。快適なフライトで無事に東京へお戻りになれますように。これからも連絡を取り合い続けましょうね！</div>
<div class="id-explanation">selamat jalan（去る人への「さようなら」） / tetap jaga komunikasi（連絡を保ち続ける）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 相手に「何かあったら連絡ちょうだいね、知らせてね」と頼む際の定番動詞は？</summary>
<strong>正解: Kabari ya!</strong><br>
解説: kabar（知らせ・ニュース）に接尾辞 -i がつき、「私に一報を知らせて」の意味になります。
</details>

<details class="id-quiz">
<summary>Q2. 旅行や帰国でその場を去っていく人に対して「道中ご無事で、いってらっしゃい」と見送る挨拶は？</summary>
<strong>正解: Selamat jalan!</strong><br>
解説: 出発する人には「Selamat jalan（良い旅路を）」、その場に残る人には「Selamat tinggal（良い滞在を）」と言います。
</details>
