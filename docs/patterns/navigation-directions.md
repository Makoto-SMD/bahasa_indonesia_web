# 【万能文章型二四】移動・道順・目的地指示のパターン構文（Lewat jalan mana / Berapa lama / Antar ke / Turun di）

タクシー、配車アプリ（Grab/Gojek）、運転手付きレンタカー、あるいは街中で道を尋ねたり目的地を指示するためのパターン構文です。

インドネシアの大都市（特にジャカルタやスラバヤ、バリ島）では、時間帯による大渋滞や一方通行（Satu arah）、奇数偶数ナンバー規制（Ganjil-Genap）が日常茶飯事です。運転手に任せきりにせず、「どの道を通る？」「高速を使って」「〜の前で降ろして」とクリアに指示を出すことで、時間を大幅に節約できます。

本記事では、移動・道順・降車指示の4大パターン構文を演習します。

---

## パターン1：【目的地・送迎の指示】〜まで送ってください（Tolong antar ke + 目的地）

タクシーに乗った瞬間、または配車アプリのメッセージで目的地を伝える基本の型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Pak, tolong antar saya ke + [目的地] + ya.
> ```
> `antar` は「送る・送り届ける」という動詞です。

### 🔄 差し替え用パーツ一覧

| 場面 | [目的地] | 意味 |
| :--- | :--- | :--- |
| **空港** | `Bandara Soekarno-Hatta Terminal 3` | スカルノ・ハッタ空港第3ターミナル |
| **ホテル** | `Hotel Indonesia Kempinski di Bundaran HI` | ブンダランHIのホテル・インドネシア |
| **駅** | `Stasiun Gambir / Stasiun Halim Whoosh` | ガンビル駅／ハリム高速鉄道駅 |
| **モール** | `lobby utara Mall Grand Indonesia` | グランド・インドネシアの北側ロビー |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Pak, <strong>tolong antar saya ke Bandara Soekarno-Hatta Terminal 3 Internasional</strong> ya.</div>
<div class="id-translation">運転手さん、スカルノ・ハッタ空港第3ターミナル（国際線）まで送ってくださいね。【空港移動】</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong <strong>antar ke alamat kantor ini sesuai dengan titik peta di aplikasi</strong> ya.</div>
<div class="id-translation">アプリのマップのピンの位置に従って、このオフィスの住所まで送ってください。【配車アプリ】</div>
</div>

## パターン2：【ルート・経路の指定】〜経由で行ってください（Lewat + 道路 / Jalan tol）

渋滞を避けるため、高速道路や特定の通りを指定する型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Pak, tolong lewat + [道路 / 高速道路] + saja ya biar cepat.
> ```
> `lewat jalan tol`（高速道路経由）は、有料でも早く着きたい時の最重要フレーズです。高速代（e-toll）は乗客負担となります。

### 🔄 差し替え用パーツ一覧

| 場面 | [道路 / ルート] | 理由 | 意味 |
| :--- | :--- | :--- | :--- |
| **高速道路** | `jalan tol dalam kota` | `biar tidak macet` | 渋滞しないよう都市高速経由で |
| **大通り** | `Jalan Sudirman` | `karena jalannya lebar` | 道が広いスディルマン通り経由で |
| **抜け道** | `jalan tikus / jalan pintas` | `kalau bapak tahu` | もし運転手さんがご存知なら裏道・抜け道で |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Pak, <strong>tolong lewat jalan tol saja ya</strong> biar tidak telat sampai bandara. Biar saya yang bayar tolnya.</div>
<div class="id-translation">運転手さん、空港に遅刻しないよう高速道路を通ってくださいね。高速代は私が払います。【高速指定】</div>
</div>

<div class="id-example">
<div class="id-sentence">Biasanya kalau jam segini, <strong>lebih cepat lewat jalan mana ya Pak</strong>?</div>
<div class="id-translation">普段この時間帯だと、どの道を通ったほうが早いですかね、運転手さん？【道順相談】</div>
</div>

## パターン3：【所要時間の確認】ここから〜までどれくらいかかりますか？（Berapa lama sampai...?）

スケジュールを立てるため、所要時間を尋ねる型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Dari sini sampai ke + [目的地], kira-kira butuh waktu berapa lama?
> ```
> `Kira-kira`（およそ・約）を挟むことで、渋滞の読めないインドネシアでも現実的な目安を教えてもらえます。

### 🔄 差し替え用パーツ一覧

| 場面 | [目的地] | 意味 |
| :--- | :--- | :--- |
| **駅** | `stasiun kereta cepat Whoosh di Halim` | ハリムの高速鉄道Whoosh駅 |
| **観光** | `kawasan wisata Tanah Lot` | タナロット観光エリア |
| **ホテル** | `hotel tempat kita menginap` | 私たちが宿泊しているホテル |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Pak, <strong>kira-kira berapa lama sampai ke stasiun kalau macet begini</strong>?</div>
<div class="id-translation">運転手さん、このように渋滞していると駅までおよそどれくらい時間がかかりますか？【所要時間確認】</div>
</div>

<div class="id-example">
<div class="id-sentence">Dari bandara ke pusat kota Jakarta <strong>biasanya butuh waktu sekitar 45 menit sampai 1 jam</strong>.</div>
<div class="id-translation">空港からジャカルタ中心街までは通常約45分から1時間ほどかかります。【案内】</div>
</div>

## パターン4：【ピンポイントの降車指示】〜の前で降ろしてください（Tolong turunkan saya di...）

目的地に着いたとき、安全かつ正確に車を停めてもらう型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Pak, tolong turun di + [目印 / 場所] + depan ya. / Stop di sini saja.
> ```
> 口頭では `Saya turun di depan lobi ya`（ロビーの前で降ります）と自らを主語にするか、単に `Stop di sini, Pak`（ここで止めてください）と言えば十分です。

### 🔄 差し替え用パーツ一覧

| 場面 | [目印 / 場所] | 意味 |
| :--- | :--- | :--- |
| **ロビー** | `depan lobi utama apartemen` | アパートのメインロビー前 |
| **コンビニ** | `depan Indomaret / Alfamart itu` | あのインドマレット／アルファマートの前 |
| **門・ゲート** | `sebelah pos satpam pintu gerbang` | 正門の警備員室の横 |
| **信号手前** | `sebelum lampu merah di kiri jalan` | 信号手前の道路の左側 |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Pak, <strong>tolong turunkan saya di depan lobi hotel</strong> yang ada satpamnya ya.</div>
<div class="id-translation">運転手さん、警備員がいるホテルのロビー前で降ろしてくださいね。【降車】</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Stop di kiri jalan sini saja Pak</strong>, pas di samping minimarket. Terima kasih!</div>
<div class="id-translation">こちらの道路の左側で停めてください、ちょうどコンビニの横です。ありがとうございました！【停車】</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

型の空欄を埋めて、移動や道案内の文を完成させてみましょう。

<details class="id-quiz">
<summary>練習1：【目的地指示】「空港まで送ってください。」（型：Pak, tolong antar saya ke...）</summary>
<strong>正解: Pak, tolong antar saya ke bandara ya.</strong><br>
解説: 
- <code>antar saya ke [目的地]</code> はタクシーでの最重要定型句です。
</details>

<details class="id-quiz">
<summary>練習2：【高速指定】「高速道路を通ってください。」（型：Tolong lewat jalan tol...）</summary>
<strong>正解: Tolong lewat jalan tol saja ya Pak biar cepat.</strong><br>
解説: 
- <code>lewat jalan tol</code> は「高速道路経由で」。
</details>

<details class="id-quiz">
<summary>練習3：【降車】「ロビーの前で降ります。」（型：Saya turun di depan lobi ya.）</summary>
<strong>正解: Pak, saya turun di depan lobi ya. / Stop di depan lobi ya.</strong><br>
解説: 
- <code>turun di [場所]</code> は「〜で降りる」。
</details>
