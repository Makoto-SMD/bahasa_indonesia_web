# 【万能文章型①】依頼・許可・希望のパターン構文（Tolong / Boleh / Mau / Minta）

外国語を話す際、すべての文をゼロから組み立てようとすると頭が追いつかなくなります。

最も効率的で実践的な方法は、**「決まった万能の型（スロット付きテンプレート）」を1つ覚え、その中の穴埋めパーツ（単語）を状況に応じて差し替えること**です。

本記事では、日常会話・旅行・職場のあらゆる場面で最も使う**「依頼（〜して）」「許可（〜していい？）」「希望（〜したい・〜が欲しい）」「要求（〜をください）」**の4大パターンを、穴あきテンプレートと具体的な代入例文のセットで徹底解説します。

---

## パターン1：【依頼】〜してください

相手に何かをお願い・指示する際の最も基本的かつ丁寧な型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Tolong + [動詞] + [目的語 / 場所] + (ya).
> ```
> 末尾に「ya」を添えると、命令感が消えて柔らかく親しみやすい依頼になります。

### 🔄 差し替え用パーツ一覧（シチュエーション別）

| シチュエーション | [動詞] | [目的語 / 場所] | 意味 |
| :--- | :--- | :--- | :--- |
| **オフィス** | `kirim`（送る） | `laporan ini lewat email` | このレポートをメールで |
| **タクシー・車** | `belok`（曲がる） | `ke kiri di lampu merah depan` | 前の信号で左へ |
| **カフェ・店** | `buatkan`（作る） | `kopi dingin tanpa gula` | 無糖のアイスコーヒーを |
| **日常・部屋** | `matikan`（消す） | `lampu dan AC di kamar` | 部屋の電気とエアコンを |
| **トラブル** | `tunggu`（待つ） | `sebentar di sini` | ここで少しの間 |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Tolong <strong>kirim</strong> <strong>laporan ini lewat email</strong> ya.</div>
<div class="id-translation">このレポートをメールで送信してくださいね。【オフィス】</div>
</div>

<div class="id-example">
<div class="id-sentence">Pak, tolong <strong>belok</strong> <strong>ke kiri di lampu merah depan</strong> ya.</div>
<div class="id-translation">運転手さん、前の赤信号のところで左に曲がってくださいね。【タクシー】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mas, tolong <strong>buatkan</strong> <strong>kopi dingin tanpa gula</strong> ya.</div>
<div class="id-translation">すみません、無糖のアイスコーヒーを作っていただけますか？【カフェ】</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong <strong>matikan</strong> <strong>lampu dan AC di kamar</strong> sebelum keluar.</div>
<div class="id-translation">外出する前に部屋の電気とエアコンを消してください。【部屋】</div>
</div>

## パターン2：【許可】〜してもよろしいですか？

自分が何か行動を起こす前に、相手の許可や了承を得る万能の型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Boleh saya + [動詞] + [目的語 / 対象]?
> ```
> 非常に丁寧で腰の低い表現で、旅行先でもビジネスでも相手に好印象を与えます。

### 🔄 差し替え用パーツ一覧

| シチュエーション | [動詞] | [目的語 / 対象] | 意味 |
| :--- | :--- | :--- | :--- |
| **観光・外出** | `ambil`（撮る） | `foto di sini` | ここで写真を |
| **オフィス・会議** | `lihat`（見る） | `dokumen ini sebentar` | この書類を少し |
| **店舗・カフェ** | `duduk`（座る） | `di kursi sebelah ini` | この隣の席に |
| **日常・持ち物** | `pinjam`（借りる） | `pulpen untuk tanda tangan` | サイン用のボールペンを |
| **支払い** | `bayar`（払う） | `pakai kartu kredit / QRIS` | クレジットカード／QRISで |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Permisi, boleh saya <strong>ambil</strong> <strong>foto di sini</strong>?</div>
<div class="id-translation">すみません、ここで写真を撮ってもよろしいですか？【観光】</div>
</div>

<div class="id-example">
<div class="id-sentence">Pak, boleh saya <strong>lihat</strong> <strong>dokumen ini sebentar</strong>?</div>
<div class="id-translation">（お相手の名前）様、この書類を少し拝見してもよろしいでしょうか？【ビジネス】</div>
</div>

<div class="id-example">
<div class="id-sentence">Permisi, apakah boleh saya <strong>duduk</strong> <strong>di kursi sebelah ini</strong>?</div>
<div class="id-translation">恐れ入ります、この隣の席に座ってもよろしいですか？【カフェ・電車】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mbak, boleh saya <strong>bayar</strong> <strong>pakai QRIS</strong>?</div>
<div class="id-translation">店員さん、QRISで支払ってもいいですか？【レジ】</div>
</div>

## パターン3：【希望】〜したい／〜なものが欲しい

自分の欲求・要望を店員や同僚にクリアに伝える型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Saya mau + [動詞 / 名詞] + (yang [形容詞]).
> ```
> 「yang + 形容詞」を後ろにつけることで、「〜なやつ（サイズ・味・色・価格）」をピンポイントで指定できます。

### 🔄 差し替え用パーツ一覧

| シチュエーション | [動詞/名詞] | yang [形容詞] | 意味 |
| :--- | :--- | :--- | :--- |
| **レストラン** | `makanan`（食べ物） | `tidak pedas sama sekali` | 全く辛くないもの |
| **買い物** | `kaos ini`（このTシャツ） | `ukurannya lebih besar (L)` | よりサイズが大きいもの（L） |
| **ホテル** | `kamar`（部屋） | `pemandangannya menghadap laut` | 眺望が海に面しているもの |
| **外出・移動** | `pergi`（行く） | `ke pusat perbelanjaan terdekat` | 最寄りのショッピングセンターへ |
| **仕事** | `bicara`（話す） | `tentang proyek minggu depan` | 来週のプロジェクトについて |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Saya mau <strong>makanan</strong> <strong>yang tidak pedas sama sekali</strong> ya, Mas.</div>
<div class="id-translation">全く辛くない料理が欲しいです（辛くないものをお願いします）。【レストラン】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mbak, saya mau <strong>kaos ini</strong> tapi <strong>yang ukurannya lebih besar</strong>, ada tidak?</div>
<div class="id-translation">すみません、このTシャツでもっとサイズが大きいものはありますか？【ショッピング】</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya mau <strong>kamar</strong> <strong>yang bebas asap rokok (non-smoking)</strong>.</div>
<div class="id-translation">禁煙（タバコの煙のない）の部屋を希望します。【ホテル】</div>
</div>

## パターン4：【要求】〜をください（Minta）

物をもらったり、追加サービスを求めたりする際の直接的で通じやすい型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> (Permisi,) boleh minta + [名詞 / サービス]?
> ```
> 頭に「Permisi（すみません）」、末尾に「ya」を添えると親しみやすくなります。

### 🔄 差し替え用パーツ一覧

| シチュエーション | [名詞 / サービス] | 意味 |
| :--- | :--- | :--- |
| **レストラン** | `garpu dan sendok tambahan` | 追加のスプーンとフォーク |
| **飲食店・レジ** | `struk / kuitansi pembayarannya` | 支払いレシート・領収書 |
| **ホテル** | `handuk bersih dua lembar` | 清潔なタオル2枚 |
| **街中・移動** | `bantuan untuk angkat koper` | スーツケースを持ち上げる手助け |
| **オフィス** | `kontak WhatsApp Pak Budi` | ブディさんのWhatsApp連絡先 |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Permisi Mas, boleh minta <strong>garpu dan sendok tambahan</strong> ya?</div>
<div class="id-translation">すみません店員さん、追加のスプーンとフォークをいただけますか？【レストラン】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mbak, boleh minta <strong>struk pembayarannya</strong>?</div>
<div class="id-translation">レシートをいただけますか？【レジ】</div>
</div>

<div class="id-example">
<div class="id-sentence">Halo resepsionis, boleh minta <strong>handuk bersih dua lembar</strong> ke kamar 302?</div>
<div class="id-translation">フロントですか？ 302号室に清潔なタオルを2枚いただけますでしょうか？【ホテル】</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

型の空欄を埋めて、指定された日本語に対応する文を完成させてみましょう。

<details class="id-quiz">
<summary>練習1：【オフィス】「このファイルを今すぐ確認してください。」（型：Tolong + 動詞 + 目的語）</summary>
<strong>正解: Tolong periksa file ini sekarang ya.</strong><br>
解説: 
- 型: <code>Tolong [動詞] [目的語] ya.</code>
- 代入パーツ: <code>periksa</code>（確認する・検査する） + <code>file ini sekarang</code>（このファイルを今すぐ）
</details>

<details class="id-quiz">
<summary>練習2：【日常】「あなたのWi-Fiパスワードを聞いてもいいですか？」（型：Boleh saya + 動詞 + 目的語）</summary>
<strong>正解: Boleh saya tahu kata sandi (password) Wi-Fi Anda? / Boleh saya minta password Wi-Fi-nya?</strong><br>
解説: 
- 型: <code>Boleh saya [tahu / minta] [kata sandi Wi-Fi]?</code>
- 許可を求めつつ情報をもらう定番の型です。
</details>

<details class="id-quiz">
<summary>練習3：【カフェ】「甘くない温かいお茶が欲しいです。」（型：Saya mau + 名詞 + yang + 形容詞）</summary>
<strong>正解: Saya mau teh hangat yang tidak manis.</strong><br>
解説: 
- 型: <code>Saya mau [名詞] yang [形容詞].</code>
- 代入パーツ: <code>teh hangat</code>（温かいお茶） + <code>yang tidak manis</code>（甘くないやつ）
</details>
