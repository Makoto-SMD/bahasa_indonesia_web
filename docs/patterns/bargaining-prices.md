# 【万能文章型二二】値段交渉・割引要求・条件確認のパターン構文（Bisa kurang tidak / Kalau ambil banyak / Ada diskon）

伝統市場（パサール）、お土産屋、露店（カキリマ）、個人商店で、お互いが笑顔で納得のいく価格交渉（Bargaining / Tawar-menawar）を行うためのパターン構文です。

インドネシアでの値段交渉は、単に相手を値切って負かすことではなく、**「笑顔のコミュニケーションと親しみ（Ramah tamah）」を通じた人間関係の構築ゲーム**です。強引に迫るのではなく、「安くしてもらえませんか？」「まとめ買いしたら安くなる？」「予算がこれくらいなんだけど」とユーモアを交えて交渉する型を身につけましょう。

本記事では、値段交渉・割引要求・条件確認の4大パターン構文を演習します。

---

## パターン1：【ストレートな割引交渉】少し安くしてもらえますか？（Bisa kurang tidak?）

最も直接的で、あらゆる市場で誰でも通じる王道の値引き交渉型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Pak / Bu, harganya bisa kurang sedikit tidak?
> ```
> 笑顔で「Boleh kurang ya?」「Kurang dikit dong, Mas!」と語尾を柔らかく言うと店主の態度が一気に和らぎます。

### 🔄 差し替え用パーツ一覧

| 場面 | 言い回し | 意味 |
| :--- | :--- | :--- |
| **丁寧** | `Apakah harganya masih bisa kurang sedikit, Bu?` | 奥さん、お値段もう少し勉強していただけますか？ |
| **親しみ** | `Bisa kurang dong Pak, langganan nih!` | 安くしてよご主人、お得意さんなんだから！ |
| **希望額提示** | `Kalau [金額] boleh tidak, Mas?` | もし〜ルピアならいかがですか？ |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Bu, baju batik ini bagus, tapi <strong>harganya bisa kurang sedikit tidak</strong>?</div>
<div class="id-translation">お母さん、このバティック服素敵だけど、お値段少し安くしてもらえませんか？【市場】</div>
</div>

<div class="id-example">
<div class="id-sentence">Kemahalan Mas! <strong>Kurang dikit dong</strong>, jadi 50 ribu ya?</div>
<div class="id-translation">高すぎるよお兄さん！ちょっとまけてよ、5万ルピアにして？【交渉】</div>
</div>

<div class="id-example">
<div class="id-sentence">Harga pasnya berapa Pak? <strong>Bisa kasih diskon tidak</strong>?</div>
<div class="id-translation">最終の底値はいくらですかご主人？割引してもらえますか？【土産物店】</div>
</div>

---

## パターン2：【まとめ買い条件】たくさん買ったら安くなりますか？（Kalau ambil banyak...）

店主にとって魅力的な「まとめ買い（Grosir / Beli banyak）」を交渉材料にする賢い型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Kalau saya ambil + [数量], dapat harga berapa per biji / buah?
> ```
> 「3つ買うから」「1ダース買うから」という提案は、店主も割引に応じやすくなります。

### 🔄 差し替え用パーツ一覧

| 場面 | [数量] | 意味 |
| :--- | :--- | :--- |
| **個数** | `tiga potong sekaligus` | 一度に3着 |
| **箱・セット** | `lima kotak untuk oleh-oleh` | お土産用に5箱 |
| **まとめ** | `banyak untuk teman kantor` | オフィスの同僚用にたくさん |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Kalau saya <strong>ambil tiga potong baju batik ini</strong>, dapat harga berapa Bu?</div>
<div class="id-translation">もしこのバティック服を3着まとめて買ったら、いくらにしてもらえますか？【まとめ買い】</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya mau beli 5 kotak kopi Luwak untuk oleh-oleh, <strong>bisa dapat harga grosir</strong>?</div>
<div class="id-translation">お土産にルワックコーヒーを5箱買いたいのですが、卸値（まとめ買い価格）にしてもらえますか？【お土産】</div>
</div>

---

## パターン3：【予算の限界提示】予算がこれくらいしかなくて…（Anggaran saya cuma...）

「本当は買いたいけれど、お小遣いが足りない」というポーズを取り、相手の譲歩を引き出す型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Uang / Anggaran saya cuma ada + [金額]. Kalau boleh, saya ambil sekarang.
> ```
> 「もしOKなら今すぐ買います」という即決の約束を添えるのがコツです。

### 🔄 差し替え用パーツ一覧

| 場面 | [金額] | 意味 |
| :--- | :--- | :--- |
| **工芸品** | `100 ribu rupiah` | 10万ルピア |
| **お土産** | `200 ribu untuk dua barang ini` | この2つの商品で20万ルピア |
| **果物** | `50 ribu per kilo` | 1キロあたり5万ルピア |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Duh, uang tunai saya <strong>cuma ada 150 ribu rupiah</strong> nih. Boleh tidak Pak?</div>
<div class="id-translation">うーん、私の手持ちの現金が15万ルピアしかなくて。これじゃダメですかご主人？【交渉】</div>
</div>

<div class="id-example">
<div class="id-sentence">Kalau <strong>boleh 100 ribu, saya langsung ambil sekarang</strong> juga deh.</div>
<div class="id-translation">もし10万ルピアで良いなら、今すぐ買っていきますよ。【即決アピール】</div>
</div>

---

## パターン4：【交渉不成立の撤退】ちょっと考えます（Pikir-pikir dulu ya）

価格が折り合わなかったり、相手の反応を試すために一旦その場を立ち去るフリをする型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Terima kasih ya, saya mau pikir-pikir / lihat-lihat toko lain dulu.
> ```
> インドネシアの市場では、立ち去ろうと背中を向けた瞬間に「Ya sudah, boleh deh!（よし、わかった、その値段でいいよ！）」と引き止められることが日常茶飯事です。

### 🔄 差し替え用パーツ一覧

| 場面 | 表現 | 意味 |
| :--- | :--- | :--- |
| **検討** | `Saya mau pikir-pikir dulu ya, terima kasih.` | 一度よく考えてみますね、ありがとうございます。 |
| **他店比較** | `Saya mau keliling lihat toko sebelah dulu ya.` | 隣のお店を一回り見てからまた来ますね。 |
| **保留** | `Nanti kalau cocok saya balik lagi ke sini.` | 後で納得したらまたここに戻ってきますね。 |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Harganya masih agak mahal ya. <strong>Saya pikir-pikir dulu deh, makasih ya Mas</strong>.</div>
<div class="id-translation">値段がまだちょっと高いですね。一度考えます、お兄さんありがとう。【一旦離脱】</div>
</div>

<div class="id-example">
<div class="id-sentence">Nanti kalau toko lain tidak ada yang lebih murah, <strong>saya pasti kembali ke toko Ibu lagi</strong>.</div>
<div class="id-translation">他の店にもっと安いのがなければ、必ずまたお母さんのお店に戻ってきますね。【愛嬌ある挨拶】</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

型の空欄を埋めて、値段交渉の文を完成させてみましょう。

<details class="id-quiz">
<summary>練習1：【値引き】「少し安くしてもらえませんか？」（型：Harganya bisa kurang...）</summary>
<strong>正解: Harganya bisa kurang sedikit tidak, Pak? / Boleh kurang ya?</strong><br>
解説: 
- <code>Bisa kurang tidak?</code> は市場での最重要フレーズです。
</details>

<details class="id-quiz">
<summary>練習2：【まとめ買い】「3つ買ったら、いくらになりますか？」（型：Kalau saya ambil tiga, dapat harga berapa?）</summary>
<strong>正解: Kalau saya ambil tiga, dapat harga berapa?</strong><br>
解説: 
- <code>ambil</code>（取る＝買う）を使ってまとめ買いのディスカウントを打診します。
</details>

<details class="id-quiz">
<summary>練習3：【保留】「一度考えてみますね、ありがとう。」（型：Saya mau pikir-pikir dulu...）</summary>
<strong>正解: Terima kasih, saya mau pikir-pikir dulu ya.</strong><br>
解説: 
- <code>pikir-pikir dulu</code> は「少し考える」。無理な押し売りに応じず礼儀正しく立ち去る型です。
</details>
