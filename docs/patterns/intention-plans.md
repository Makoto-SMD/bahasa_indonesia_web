# 【万能文章型⑩】決意・予定・意図のパターン構文（Berencana untuk / Berniat / Baru akan / Mau coba）

未来の予定や自分の目標、今まさにやろうとしている行動を周囲に共有するパターン構文です。

単に `akan`（〜するだろう）や `mau`（〜したい）を繰り返すだけでなく、**「計画している」「意図がある」「今まさに〜するところだ」「試しに〜してみる」**といったニュアンスを自在に使い分けることで、自分の意志をより明確に伝えられるようになります。

本記事では、意図・計画・試みを表現する4大パターンを演習します。

---

## パターン1：【計画・予定】〜する計画／予定です（Berencana untuk + 動詞）

将来のスケジュールや具体的なアクションプランを公式・半公式に伝える型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Saya / Kami berencana untuk + [動詞句] + (pada / tahun depan / bulan depan).
> ```
> `rencana`（計画）の派生語 `berencana`（計画を持つ）を使ったスマートな表現です。

### 🔄 差し替え用パーツ一覧

| 場面 | [動詞句] | 時期 | 意味 |
| :--- | :--- | :--- | :--- |
| **キャリア** | `belajar bahasa Indonesia sampai tingkat mahir` | `tahun ini` | 今年中に上級レベルまで学ぶ |
| **旅行** | `liburan ke Raja Ampat bersama keluarga` | `bulan depan` | 来月家族とラジャ・アンパットへ旅行する |
| **事業** | `membuka kantor cabang baru di Surabaya` | `tahun depan` | 来年スラバヤに新支社を開設する |
| **生活** | `pindah apartemen yang lebih dekat stasiun` | `akhir tahun ini` | 今年の暮れにより駅に近いアパートへ引っ越す |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Saya <strong>berencana untuk mengambil ujian UKBI</strong> pada akhir tahun ini.</div>
<div class="id-translation">私は今年末にUKBI（インドネシア語検定）を受験する予定です。【学習目標】</div>
</div>

<div class="id-example">
<div class="id-sentence">Perusahaan kami berencana untuk <strong>meluncurkan produk baru</strong> bulan depan.</div>
<div class="id-translation">弊社は来月、新製品を発売する計画を立てております。【ビジネス】</div>
</div>

<div class="id-example">
<div class="id-sentence">Kami berencana untuk <strong>mengunjungi Candi Borobudur</strong> waktu libur Lebaran.</div>
<div class="id-translation">私たちはレバラン休みにボロブドゥール寺院を訪れる計画をしています。【旅行】</div>
</div>

## パターン2：【意志・意図】〜するつもりです／〜する気はありません（Berniat untuk / Tidak berniat）

心の中で固めた個人的な意図や決意を表明する型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Saya berniat untuk + [動詞句]. / Saya tidak berniat untuk + [動詞句].
> ```
> `niat` は「意図・意志・志」を表すアラビア語起源の重みのある単語です。

### 🔄 差し替え用パーツ一覧

| 場面 | 肯定/否定 | [動詞句] | 意味 |
| :--- | :--- | :--- | :--- |
| **配慮** | `tidak berniat` | `menyinggung perasaan siapa pun` | 誰の感情も害するつもりはない |
| **決意** | `berniat` | `melanjutkan studi S2 di Jakarta` | ジャカルタで大学院修士課程に進学する気だ |
| **仕事** | `tidak berniat` | `menunda pekerjaan penting ini` | この重要業務を先送りする気はない |
| **生活** | `berniat` | `mulai hidup lebih sehat dan rajin olahraga` | より健康的な生活を始め運動に励む決意だ |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Maaf, saya <strong>sama sekali tidak berniat</strong> untuk menyinggung perasaan Anda.</div>
<div class="id-translation">申し訳ありません、あなたの感情を害する意図は全くありませんでした。【釈明】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mulai bulan ini saya <strong>berniat untuk menabung</strong> lebih banyak uang.</div>
<div class="id-translation">今月からもっと多くのお金を貯金する決意をしています。【生活目標】</div>
</div>

## パターン3：【直前のタイミング】今まさに〜するところです（Baru mau / Baru akan）

アクションを起こそうとしたまさにその瞬間のタイミングを伝える型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Saya baru mau + [動詞句] + (ketika / pas [別の出来事]).
> ```
> 「ちょうど〜しようとしていたところなんだ！」と相手の連絡と行動が重なったときなどに最適です。

### 🔄 差し替え用パーツ一覧

| 場面 | [動詞句] | タイミング | 意味 |
| :--- | :--- | :--- | :--- |
| **連絡** | `hubungi kamu lewat telepon` | `pas kamu kirim pesan` | ちょうど君からメッセージが来たとき |
| **外出** | `keluar dari kantor` | `eh tiba-tiba hujan deras` | え、突然の豪雨 |
| **食事** | `makan siang di kantin` | `pas dipanggil bos` | ちょうど上司に呼ばれたとき |
| **作業** | `kirim file laporan ini` | `sekarang juga` | 今まさにこの瞬間に |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Eh, saya <strong>baru mau telepon kamu</strong> lho! Pas banget.</div>
<div class="id-translation">えっ、私もちょうど君に電話しようとしていたところだったんだよ！タイミングぴったり。【電話】</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya <strong>baru mau makan siang</strong>, kamu mau ikut tidak?</div>
<div class="id-translation">今ちょうどお昼を食べに行くところなんだけど、一緒に行く？【同僚への誘い】</div>
</div>

## パターン4：【試しのアクション】試しに〜してみます（Mau coba + 動詞）

いきなり本気でやるのではなく、「お試しでやってみる」「味見してみる」という気軽な挑戦を伝える型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Saya mau coba + [動詞 / 名詞] + (dulu).
> ```
> 末尾に `dulu`（まずは・とりあえず）を添えると、「まずは試しに一回やってみる」という完璧なニュアンスになります。

### 🔄 差し替え用パーツ一覧

| 場面 | [動詞 / 名詞] | 意味 |
| :--- | :--- | :--- |
| **料理** | `makanan tradisional ini dulu` | まずはこの伝統料理を味見してみる |
| **アプリ** | `aplikasi pembayaran baru ini` | この新しい決済アプリを試してみる |
| **提案** | `cara kerja yang baru disarankan` | 新しく提案されたやり方を試してみる |
| **買い物** | `pakai baju batik ukuran L ini dulu` | まずはこのLサイズのバティック服を試着してみる |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Kelihatannya enak, saya <strong>mau coba makan sambal ini dulu</strong> ya.</div>
<div class="id-translation">美味しそうですね、まずはこのサンバルを試しに食べてみますね。【食事】</div>
</div>

<div class="id-example">
<div class="id-sentence">Mbak, boleh saya <strong>coba pakai sepatu ini</strong> dulu?</div>
<div class="id-translation">店員さん、この靴を試しに履いてみてもいいですか？【試着】</div>
</div>

<div class="id-example">
<div class="id-sentence">Kita bisa <strong>coba metode ini dulu selama satu minggu</strong> untuk lihat hasilnya.</div>
<div class="id-translation">結果を見るために、まずはこの方法を1週間試してみましょう。【業務改善】</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

型の空欄を埋めて、予定や意図の文を完成させてみましょう。

<details class="id-quiz">
<summary>練習1：【予定】「来月、バリ島へ旅行に行く計画をしています。」（型：Saya berencana untuk...）</summary>
<strong>正解: Saya berencana untuk liburan ke Bali bulan depan.</strong><br>
解説: 
- <code>berencana untuk</code>（〜する計画である）+ <code>liburan ke Bali bulan depan</code>（来月バリ島で休暇を過ごす）。
</details>

<details class="id-quiz">
<summary>練習2：【タイミング】「今まさにオフィスを出ようとしていたところです。」（型：Saya baru mau...）</summary>
<strong>正解: Saya baru mau keluar dari kantor sekarang.</strong><br>
解説: 
- <code>baru mau</code> は「今まさに〜しようとしている直前」。アクションの目前を表します。
</details>

<details class="id-quiz">
<summary>練習3：【試み】「まずはこの料理を少し試食してみてもいいですか？」（型：Boleh saya coba...）</summary>
<strong>正解: Boleh saya coba cicipi makanan ini dulu?</strong><br>
解説: 
- <code>coba cicipi</code> は「味見してみる」。末尾に <code>dulu</code> を添えて謙虚に試食を依頼します。
</details>
