# 【万能文章型②】場所・存在・移動・交通のパターン構文（Ada / Di mana / Naik / Antar）

見知らぬ土地での移動、道案内、ホテルの設備確認、タクシーでの目的地指定などは、旅行や出張で最も緊張するシチュエーションです。

しかし、**「存在（あるか・ないか）」「位置（どこか）」「移動（何に乗って行くか）」「経由指示（どこを通るか）」**という4つのコア構文の型を身につけてしまえば、あとは目的地や乗り物の名詞を差し替えるだけで、どんな場所へも自在に移動し、必要な施設を見つけられるようになります。

本記事では、場所・存在・交通の万能テンプレートと、状況別の差し替え用単語セット、代入例文を徹底解説します。

---

## パターン1：【存在・有無】〜に〜はありますか？

ある場所に特定の設備・サービス・在庫があるかを確認する最重要の型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Apakah ada + [名詞 / サービス] + di + [場所]?
> ```
> 日常会話では文頭の「Apakah」を省略して `Ada + [名詞] + di + [場所]?` と語尾を上げて言うだけで通じます。

### 🔄 差し替え用パーツ一覧（シチュエーション別）

| シチュエーション | [名詞 / サービス] | [場所] | 意味 |
| :--- | :--- | :--- | :--- |
| **カフェ・飲食店** | `stopkontak (colokan)`（コンセント） | `dekat meja ini` | この席の近く |
| **ホテル** | `kolam renang dan pusat kebugaran` | `lantai paling atas` | 最上階 |
| **店舗・薬局** | `obat pereda sakit kepala` | `toko ini` | この店 |
| **モール・公共施設**| `ruang menyusui / nursery` | `gedung ini` | この建物の中 |
| **街中・移動** | `stasiun MRT / halte busway` | `sekitar sini` | この周辺・近所 |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Permisi, apakah ada <strong>stopkontak</strong> di <strong>dekat meja ini</strong>?</div>
<div class="id-translation">すみません、この席の近くにコンセントはありますか？【カフェ・充電】</div>
<div class="id-explanation">stopkontak / colokan（コンセント電源プラグ）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Apakah ada <strong>obat flu dan batuk</strong> di <strong>minimarket ini</strong>?</div>
<div class="id-translation">このミニマートに風邪薬と咳止めはありますか？【店舗】</div>
</div>

<div class="id-example">
<div class="id-sentence">Apakah ada <strong>stasiun MRT terdekat</strong> di <strong>sekitar sini</strong>?</div>
<div class="id-translation">この周辺に最寄りのMRT駅はありますか？【街中】</div>
<div class="id-explanation">sekitar sini（この周辺・このあたり）。</div>
</div>

## パターン2：【位置の質問】〜はどこにありますか？

トイレ、エレベーター、ATM、特定の売り場などの位置を尋ねる型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> [名詞 / 施設] + ada di mana ya?
> (または)
> Di mana + [名詞 / 施設]?
> ```
> 尋ねる名詞を先に言って「ada di mana ya?（どこにありますか？）」と続ける方が、相手に聞きたい対象が真っ先に伝わりやすくおすすめです。

### 🔄 差し替え用パーツ一覧

| 施設・名詞 | 日本語 | 例文の完成形 |
| :--- | :--- | :--- |
| **toilet / kamar kecil** | トイレ、お手洗い | `Toilet ada di mana ya?` |
| **lift / eskalator** | エレベーター／エスカレーター | `Lift menuju lantai 5 ada di mana ya?` |
| **mesin ATM BCA** | BCA銀行のATM機 | `Mesin ATM terdekat ada di mana ya?` |
| **tempat penitipan barang** | コインロッカー、手荷物預かり所 | `Tempat penitipan barang ada di mana?` |
| **pintu darurat** | 非常口、緊急脱出扉 | `Pintu darurat ada di sebelah mana?` |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Permisi Mas, <strong>toilet pria</strong> ada di mana ya?</div>
<div class="id-translation">すみません店員さん、男性用トイレはどこにありますか？【モール】</div>
</div>

<div class="id-example">
<div class="id-sentence">Maaf Pak, <strong>mesin ATM untuk tarik tunai</strong> ada di sebelah mana ya?</div>
<div class="id-translation">恐れ入ります、現金引き出し用のATM機はどちら側にありますか？【駅・空港】</div>
<div class="id-explanation">tarik tunai（現金引き出し） / di sebelah mana（どの側・どの方向）。</div>
</div>

## パターン3：【移動手段】〜へ〜に乗って行きたい

目的地と利用したい交通機関（電車、バス、配車アプリ、タクシー）を伝える型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Saya mau pergi ke + [目的地] + naik + [交通手段].
> ```
> 「naik + 乗り物」で「〜に乗って・〜を利用して」を表します。

### 🔄 差し替え用パーツ一覧

| [目的地] | [交通手段] | 日本語の意味 |
| :--- | :--- | :--- |
| `Bandara Soekarno-Hatta` | `Kereta Bandara (Railink)` | スカルノハッタ空港へ空港鉄道で |
| `Stasiun Bandung` | `Kereta cepat Whoosh` | バンドン駅へ高速鉄道ウーシュで |
| `Monas (Monumen Nasional)` | `TransJakarta (Busway)` | モナス（独立記念塔）へトランスジャカルタで |
| `Mall Grand Indonesia` | `MRT` | グランドインドネシアへMRTで |
| `kantor cabang di Cikarang` | `mobil jemputan / travel` | チカランの支社へ送迎車で |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Saya mau pergi ke <strong>Bandara Soekarno-Hatta</strong> naik <strong>Kereta Bandara</strong> supaya bebas macet.</div>
<div class="id-translation">渋滞を避けるため、スカルノハッタ空港へ空港鉄道に乗って行きたいです。【空港移動】</div>
<div class="id-explanation">bebas macet（渋滞知らず・渋滞がない）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Hari Sabtu ini kami mau pergi ke <strong>Bandung</strong> naik <strong>Whoosh</strong> dari Stasiun Halim.</div>
<div class="id-translation">今週の土曜日、私たちはハリム駅からウーシュに乗ってバンドンへ行く予定です。【旅行】</div>
</div>

## パターン4：【ルート・経由指示】〜経由で〜まで連れて行ってください

タクシー（Bluebird）や配車アプリ（Grab/Gojek）のドライバーに、希望のルートや立ち寄り先を指定する型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Tolong antar saya ke + [目的地] + lewat + [経由地 / ルート] ya.
> ```
> 高速道路（Jalan Tol）を使いたいときや、特定の道路を通ってほしいときに絶大な威力を発揮します。

### 🔄 差し替え用パーツ一覧

| [目的地] | [経由地 / ルート] | 意図・理由 |
| :--- | :--- | :--- |
| `Hotel Mulia Senayan` | `jalan tol dalam kota` | 都心高速道路を通って早く着きたい |
| `Bandara Halim` | `jalan arteri non-tol` | 高速料金を節約したい／下道で行く |
| `kantor pusat` | `stasiun untuk jemput teman` | 友人を拾うために駅を経由する |
| `apartemen saya` | `minimarket sebentar` | 買い物に少し立ち寄る |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Pak, tolong antar saya ke <strong>Hotel Mulia</strong> lewat <strong>jalan tol</strong> ya, biayanya saya yang tanggung.</div>
<div class="id-translation">運転手さん、高速道路経由でホテル・ムリアまで連れて行ってください。高速代は私が負担します。【タクシー】</div>
<div class="id-explanation">biayanya saya yang tanggung（費用は私が負担します・持ちます）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong antar saya ke <strong>rumah sakit</strong> lewat <strong>jalan pintas</strong> yang paling cepat ya, Pak. Sedang darurat.</div>
<div class="id-translation">緊急ですので、一番早い近道を通って病院まで送ってください。【緊急移動】</div>
<div class="id-explanation">jalan pintas（近道・抜け道） / sedang darurat（緊急事態です）。</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

<details class="id-quiz">
<summary>練習1：【存在確認】「このホテルに無料のWi-Fiはありますか？」（型：Apakah ada + 名詞 + di + 場所?）</summary>
<strong>正解: Apakah ada Wi-Fi gratis di hotel ini? / Ada Wi-Fi gratis di hotel ini?</strong><br>
解説: 
- 型: <code>Apakah ada [Wi-Fi gratis] di [hotel ini]?</code>
- Wi-Fiや駐車場、朝食の有無をフロントで尋ねる鉄板フレーズです。
</details>

<details class="id-quiz">
<summary>練習2：【位置の質問】「一番近い薬局はどこにありますか？」（型：[施設] + ada di mana ya?）</summary>
<strong>正解: Apotek terdekat ada di mana ya?</strong><br>
解説: 
- 型: <code>[Apotek terdekat] ada di mana ya?</code>
- <code>apotek</code>（薬局） + <code>terdekat</code>（最寄りの）をスロットに差し込みます。
</details>

<details class="id-quiz">
<summary>練習3：【経由指定】「銀行に少し立ち寄ってから、オフィスまで送ってください。」（型：Tolong antar saya ke + 目的地 + lewat + 経由地）</summary>
<strong>正解: Tolong antar saya ke kantor lewat bank sebentar ya. / Tolong antar saya ke kantor, mampir ke bank dulu ya.</strong><br>
解説: 
- 目的地（kantor）と立ち寄り経由地（bank）を組み合わせた日常配車フレーズです。
</details>
