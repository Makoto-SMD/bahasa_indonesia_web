# 確信度・可能性のグラデーション表現構文（Sangat mungkin / Hampir pasti / Kemungkinan kecil）

未来の予測や不確実な状況について、「ほぼ確実」「大いにあり得る」「五分五分」「可能性は低い」といった確信度（Derajat Kepastian）のグラデーションを正確に表現するための構文パターンです。

リスク管理や予測の議論に欠かせないボキャブラリーを整理します。

---

## 1. 確信度の度合い別表現マップ

| 確信度レベル | インドネシア語表現 | 日本語のニュアンス | 確率のイメージ |
| :--- | :--- | :--- | :--- |
| **100%（確実）** | **Pasti / Sudah dapat dipastikan** | 間違いなく、確実に | 100% |
| **80〜90%（ほぼ確実）** | **Hampir pasti / Sangat besar kemungkinannya** | ほぼ確実、可能性が極めて高い | 80〜90% |
| **60〜70%（高い可能性）** | **Sangat mungkin / Kemungkinan besar** | 大いにあり得る、十中八九 | 60〜70% |
| **50%（中立・五分五分）** | **Bisa jadi / Mungkin saja / Ada kemungkinan** | かもしれない、あり得る | 50% |
| **20〜30%（低い可能性）** | **Kecil kemungkinannya / Kurang memungkinkan** | 可能性は低い、難しそうだ | 20〜30% |
| **0%（不可能）** | **Mustahil / Sangat tidak mungkin** | あり得ない、不可能だ | 0% |

## 2. 実践例文カード

<div class="id-example">
<div class="id-sentence">Melihat tren pertumbuhan saat ini, hampir pasti target penjualan tahunan kita akan tercapai sebelum bulan Desember.</div>
<div class="id-translation">現在の成長トレンドを見る限り、年間の売上目標が12月前に達成されることはほぼ確実（hampir pasti）です。</div>
<div class="id-explanation">hampir pasti（ほぼ確実） / tercapai（達成される）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Ada kemungkinan besar bahwa bank sentral akan menaikkan suku bunga acuan pada kuartal mendatang demi menekan inflasi.</div>
<div class="id-translation">インフレを抑制するため、中央銀行が来四半期に政策金利を引き上げる可能性は極めて高い（ada kemungkinan besar）です。</div>
<div class="id-explanation">suku bunga acuan（政策金利・基準金利） / menekan inflasi（インフレを抑え込む）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Kecil kemungkinannya proyek konstruksi ini bisa selesai tepat waktu mengingat kendala cuaca buruk yang terus berlanjut.</div>
<div class="id-translation">悪天候が続いている現状を考慮すると、この建設プロジェクトが期限通りに完了する可能性は極めて低い（kecil kemungkinannya）です。</div>
<div class="id-explanation">kecil kemungkinannya（可能性は低い） / mengingat（〜を考慮すると）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「十中八九、可能性が極めて高い」を表す名詞句構文は？</summary>
<strong>正解: Kemungkinan besar...（または Sangat besar kemungkinannya）</strong><br>
解説: kemungkinan（可能性）＋ besar（大きい）で高い確信度を示します。
</details>

<details class="id-quiz">
<summary>Q2. 「絶対にあり得ない、不可能である」を意味する強い否定語は？</summary>
<strong>正解: Mustahil（または Tidak mungkin sama sekali）</strong><br>
解説: mustahil はアラビア語起源の単語で、論理的・物理的に不可能であることを表します。
</details>
