# 原因・因果関係を深掘りするパターン構文（Faktor utamanya adalah / Menyebabkan timbulnya / Disebabkan oleh）

単純な接続詞「karena（なぜなら）」を超えて、ビジネスの要因分析、学術レポート、ニュース解説で論理的な因果関係を精緻に説明するための構文パターンです。

中上級の読解や論理的プレゼンテーションに必須の表現を整理します。

---

## 1. 最重要パターン型一覧

| パターン構文 | 意味 | ニュアンス・使用場面 |
| :--- | :--- | :--- |
| **Faktor utama di balik masalah ini adalah [Faktor]** | この問題の背後にある主たる要因は[要因]です | 要因分析の定型構文 |
| **[Hal A] menyebabkan timbulnya [Hal B]** | [A]が[B]の発生を引き起こす | 明確な能動的因果関係の提示 |
| **[Hal A] disebabkan oleh [Hal B]** | [A]は[B]に起因する／によって引き起こされる | 受動的な因果関係の明示 |
| **Dampak langsung dari fenomena ini adalah...** | この現象から直接もたらされる影響は... | 結果・インパクトの深掘り |

---

## 2. 実践例文カード

<div class="id-example">
<div class="id-sentence">Faktor utama di balik penurunan penjualan kuartal ini adalah melonjaknya biaya logistik dan inflasi global.</div>
<div class="id-translation">今四半期の売上低下の主たる要因は、物流コストの高騰と世界的なインフレです。</div>
<div class="id-explanation">faktor utama（主要因） / melonjaknya（急騰すること） / penurunan penjualan（売上減少）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Curah hujan yang ekstrem selama tiga hari berturut-turut menyebabkan timbulnya bencana banjir bandang di kawasan permukiman.</div>
<div class="id-translation">3日間連続した極端な降雨量が、住宅街における鉄砲水災害の発生を引き起こしました。</div>
<div class="id-explanation">berturut-turut（連続して） / menyebabkan timbulnya（〜の発生を引き起こす）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Kemacetan parah di pusat kota sebagian besar disebabkan oleh peningkatan pesat kepemilikan kendaraan pribadi.</div>
<div class="id-translation">都心部の深刻な交通渋滞の大部分は、自家用車保有の急速な増加に起因しています。</div>
<div class="id-explanation">sebagian besar disebabkan oleh（大部分は〜に起因する） / peningkatan pesat（急増）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「〜の発生を引き起こす、〜の原因となる」を表す他動詞構文は？</summary>
<strong>正解: menyebabkan timbulnya...（または mengakibatkan）</strong><br>
解説: menyebabkan（〜を引き起こす）＋ timbul（生じる・湧き出る）の名詞化で、事態の発生をもたらすことを表します。
</details>

<details class="id-quiz">
<summary>Q2. 「直接的な影響・結果」を意味する名詞句は？</summary>
<strong>正解: dampak langsung</strong><br>
解説: dampak（影響・インパクト）＋ langsung（直接の）で客観的な帰結を指します。
</details>
