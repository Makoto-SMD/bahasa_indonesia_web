# 【万能文章型四三】誘い・約束・同行依頼のパターン構文（Mau ikut makan / Kapan-kapan kita ngopi yuk / Ada acara tidak）

友人や同僚を食事やお茶（Nongkrong）、休日のイベントに誘う、あるいは誰かの集まりに「一緒に行ってもいい？」と同行をお願いするためのパターン構文です。

インドネシアでは「Nongkrong（カフェや屋台でダベる・おしゃべりする）」文化が生活の中心にあります。堅苦しい招待状ではなく、「お昼ご飯食べに行かない？（Mau ikut makan siang?）」「今度いつかお茶しようよ！（Kapan-kapan kita ngopi yuk!）」「土曜日は何か予定ある？」と軽やかに誘い合える構文をマスターすれば、現地の友達作りは百発百中です。

本記事では、誘い・約束・同行の4大パターン構文を演習します。

---

## パターン1：【その場の気軽な誘い】〜に行かない？／一緒にどう？（Mau ikut... yuk?）

ランチや休憩、帰宅時にその場でサッと声をかける型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Mau ikut [アクティビティ] bareng kita tidak? / [アクティビティ] yuk!
> ```
> 文末の `yuk`（〜しようぜ・行こうよ）は、親しみやすさ満点の魔法の誘い言葉です。

### 🔄 差し替え用パーツ一覧

| 場面 | [アクティビティ] | 意味 |
| :--- | :--- | :--- |
| **ランチ** | `makan siang di warung Padang depan kantor` | オフィス前のパダン料理屋で昼食 |
| **お茶** | `ngopi santai di kafe bawah lantai 1` | 1階のカフェで気楽にコーヒー |
| **帰宅** | `pulang bareng naik MRT` | MRTで一緒に帰る |
| **買い物** | `beli cemilan ke minimarket sebentar` | コンビニにお菓子を買いに行く |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Teman-teman, <strong>kami mau makan siang di warung bakso sebelah, mau ikut tidak</strong>?</div>
<div class="id-translation">みんな、隣のバッソ屋にお昼食べに行くんだけど、一緒に行かない？【同僚への声かけ】</div>
</div>

<div class="id-example">
<div class="id-sentence">Sudah jam 5 sore nih, <strong>istirahat ngopi sebentar yuk</strong>!</div>
<div class="id-translation">もう夕方5時だよ、ちょっとコーヒー飲んで一息つこうよ！【気軽な誘い】</div>
</div>

## パターン2：【将来の約束・社交辞令の誘い】今度いつか〜しようよ！（Kapan-kapan kita... yuk）

特定の日時を決めずに、「今度ぜひ行こうね！」と関係性を温める型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Kapan-kapan kita + [アクティビティ] + bareng-bareng ya / yuk!
> ```
> `Kapan-kapan`（そのうち・いつか）は別れ際やLINE交換時の必須フレーズです。

### 🔄 差し替え用パーツ一覧

| 場面 | [アクティビティ] | 意味 |
| :--- | :--- | :--- |
| **カフェ** | `nongkrong sambil ngopi santai` | コーヒー飲みながらゆっくりダベる |
| **食事** | `makan malam dan cobain sate kambing enak` | 美味しいヤギのサテを食べに行く |
| **旅行** | `jalan-jalan liburan ke Bogor atau Bandung` | ボゴールやバンドンへ小旅行する |
| **スポーツ** | `main bulutangkis bareng waktu akhir pekan` | 週末に一緒にバドミントンをする |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Asyik banget ngobrol sama kamu! <strong>Kapan-kapan kita nongkrong ngopi bareng lagi yuk</strong>.</div>
<div class="id-translation">君とのおしゃべり、すごく楽しかったよ！今度いつかまた一緒にお茶してダベろうね。【親睦】</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kapan-kapan mampir ke rumah saya ya</strong>, nanti saya masakkan kuliner khas Jepang.</div>
<div class="id-translation">今度いつか私の家に遊びに来てね、日本の名物料理を振る舞うから。【自宅招待】</div>
</div>

## パターン3：【予定の事前確認】〜は何か予定ある？（Ada acara tidak?）

相手に予定があるかどうかを確かめてから、本題の誘いを切り出す気遣い型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Hari [曜日] nanti kamu ada acara tidak? Kalau senggang, mau tidak kita [アクティビティ]?
> ```
> `acara` は「予定・イベント」、`senggang` / `luang` は「手が空いている・暇である」です。

### 🔄 差し替え用パーツ一覧

| 場面 | [曜日・日時] | [アクティビティ] | 意味 |
| :--- | :--- | :--- | :--- |
| **週末** | `hari Sabtu malam minggu besok` | `nonton konser musik di Senayan` | スナヤンで音楽コンサートを見る |
| **今夜** | `nanti malam setelah jam kerja` | `makan malam di restoran Jepang` | 和食レストランでディナー |
| **休日** | `hari Minggu pagi` | `joging sehat bareng di CFD Sudirman` | スディルマンのCFDで健康ジョギング |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Budi, <strong>hari Sabtu besok kamu ada acara tidak</strong>? Kalau tidak ada, temani saya cari baju batik yuk.</div>
<div class="id-translation">ブディ、今度の土曜日は何か予定ある？もし空いてたら、バティック服を探すのに付き合ってくれない？【お出かけ】</div>
</div>

<div class="id-example">
<div class="id-sentence">Malam ini kamu ada rencana apa? <strong>Kalau senggang, makan malam bareng yuk</strong>.</div>
<div class="id-translation">今夜は何の予定？もし空いてるなら、一緒に夕飯食べようよ。【食事】</div>
</div>

## パターン4：【同行のお願い】私も一緒に行っていい？（Boleh saya ikut?）

相手の楽しそうな計画を聞いて、「私も仲間に入れて！」と同行を頼む型です。

> [!TIP]
> ### 📐 基本の型（スロット・テンプレート）
> ```text
> Wah kedengarannya seru! Apakah boleh saya ikut bergabung?
> ```
> インドネシア人は誰かが加わることを大歓迎（Boleh banget!）してくれます。遠慮は無用です。

### 🔄 差し替え用パーツ一覧

| 場面 | 表現 | 意味 |
| :--- | :--- | :--- |
| **気軽** | `Boleh ikut tidak? Mau ikutan dong!` | 一緒に行っていい？仲間に入れてよ！ |
| **丁寧** | `Apakah tidak merepotkan kalau saya ikut bergabung?` | 私がご一緒してもご迷惑になりませんか？ |
| **車・同乗** | `Boleh saya numpang mobil sampai stasiun terdekat?` | 最寄駅まで車に乗せて（同乗させて）もらえますか？ |

### 💡 代入した完成例文

<div class="id-example">
<div class="id-sentence">Kalian mau pergi ke pasar malam ya? <strong>Boleh saya ikut bergabung tidak</strong>? Penasaran pengen lihat!</div>
<div class="id-translation">みんな夜市（パサール・マラム）に行くの？私も一緒に行っていい？興味があって見てみたいんだ！【同行希望】</div>
</div>

<div class="id-example">
<div class="id-sentence">Wah, seru banget rencananya! <strong>Kalau tidak keberatan, ajak saya juga ya</strong>.</div>
<div class="id-translation">わあ、すごく楽しそうな計画！差し支えなければ、私にもぜひ声をかけて（誘って）ね。【参加希望】</div>
</div>

## 5. 穴埋めパターンドリル（Latihan Mandiri）

型の空欄を埋めて、誘いや約束の文を完成させてみましょう。

<details class="id-quiz">
<summary>練習1：【気軽な誘い】「昼ご飯一緒に食べに行かない？」（型：Mau ikut makan siang bareng...）</summary>
<strong>正解: Mau ikut makan siang bareng kami tidak? / Makan siang yuk!</strong><br>
解説: 
- <code>Mau ikut [動詞] bareng?</code> は「一緒に〜しない？」の定番です。
</details>

<details class="id-quiz">
<summary>練習2：【いつか約束】「今度いつか一緒にお茶しようよ！」（型：Kapan-kapan kita ngopi bareng...）</summary>
<strong>正解: Kapan-kapan kita ngopi bareng yuk!</strong><br>
解説: 
- <code>Kapan-kapan kita [動詞] yuk</code> は「今度いつか〜しよう！」。
</details>

<details class="id-quiz">
<summary>練習3：【予定確認】「今度の土曜日、何か予定ある？」（型：Hari Sabtu besok kamu ada acara tidak?）</summary>
<strong>正解: Hari Sabtu besok kamu ada acara tidak?</strong><br>
解説: 
- <code>ada acara tidak</code> は「予定はある？」。
</details>
