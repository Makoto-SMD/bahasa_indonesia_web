# G05：南スマトラ州（Sumatera Selatan）— 海上帝国の栄光シュリーヴィジャヤ・ムシ川・エムペエムペの都パレンバン

スマトラ島南東部に広がる **南スマトラ州（Provinsi Sumatera Selatan）**。その州都 **パレンバン（Palembang）** は、西暦683年の碑文記録が残るインドネシア最古の都市であり、かつて東南アジアの海上交易と仏教教学の中心として君臨した **シュリーヴィジャヤ王国（Kerajaan Sriwijaya）** の王都でした。

街の中央を滔々と流れる大河 **ムシ川（Sungai Musi）**、朱色の巨大橋 **アンペラ橋（Jembatan Ampera）**、そして魚のすり身と黒い黒酢タレが絶品の国民的料理 **エムペエムペ（Pempek）**。南スマトラの栄光ある歴史と豊かな生活文化を学びましょう。

## 1. 千年の海上交易帝国：シュリーヴィジャヤの遺産

7世紀から13世紀にかけて栄えた **Kerajaan Sriwijaya** は、マラッカ海峡とスンダ海峡を完全掌握し、中国の唐王朝やインドのチョーラ朝と交易・外交を結びました。唐の僧侶 **義浄（Yijing）** は、インドのナーランダー大学へ赴く前にパレンバンに長期滞在し、千人以上の仏僧が仏典を研究している様子を記録に残しています。

この国際交易の歴史は、パレンバンの文化にマレー、中国、アラブ、ジャワの要素が美しく融合する土壌を育みました。

## 2. ムシ川の象徴アンペラ橋と国民食エムペエムペ

パレンバン市民のアイデンティティは、ムシ川と食にあります。
- **Jembatan Ampera**: 1965年に完成した全長1,177メートルの大橋。スカルノ初代大統領の提唱で、日本の戦争賠償資金と技術援助によって建設されました（かつては船の通過時に中央桁が跳ね上がる可動橋でした）。
- **Pempek Palembang**: イカン・テンギリ（サワラ）などの新鮮な白身魚のすり身にサゴ椰子粉を練り込んで揚げた練り物料理。椰子砂糖（Gula Batok）、ニンニク、唐辛子、酢で作られた黒い濃厚な特製タレ 「**チュコ（Cuko）**」 を器に注いで飲みながら食べるのが本場流です。

- **Bagi warga Palembang, makan pempek belum lengkap rasanya jika tidak menghirup kuah cuko yang pedas dan manis.**<br>
  （パレンバン市民にとって、辛く甘酸っぱいチュコだれをすすらなければ、エムペエムペを食べた心地がしない。）
- **Berbagai varian pempek seperti kapal selam yang berisi telur utuh dan pempek lenjer sangat disukai masyarakat.**<br>
  （丸ごとの卵が入った「カパル・スラム（潜水艦）」や棒状の「レンジール」など、多彩な種類のエムペエムペが人々に愛されている。）

## 3. 南スマトラ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Sriwijaya** | シュリーヴィジャヤ | サンスクリット語で「輝かしい勝利」を意味する大海上帝国 |
| **Jembatan Ampera** | アンペラ橋 | 「Amanat Penderitaan Rakyat（人民の苦難の信託）」の略称から名付けられた赤い橋 |
| **Pempek Kapal Selam** | 潜水艦エムペエムペ | 中にアヒルの生卵を丸ごと包み込んで揚げた、最も人気のある大型エムペエムペ |
| **Kuah Cuko** | チュコだれ | パレンバン産黒ヤシ砂糖、酢、ニンニク、青唐辛子を煮詰めた秘伝の黒酢タレ |
| **Pindang Patin** | ピンダン・パティン | パティン魚をレモングラス、パイナップル、唐辛子と煮込んだ甘酸っぱく辛い絶品スープ |

## まとめと旅のヒント

1. **お土産の定番**: パレンバン空港では、真空パックされたエムペエムペセットが観光客の一番人気のお土産です。
2. **ムシ川クルーズ**: 夕暮れ時に水上バスや小舟に乗ると、ライトアップされたアンペラ橋と川辺のクト・ブサック要塞がロマンチックに輝きます。
3. **金糸の美術品**: ソンケット織物は、熟練の職人が数ヶ月かけて手織りする最高峰の工芸品で、国家行事や結婚式の正装として珍重されます。
