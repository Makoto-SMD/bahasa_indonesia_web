# G23：北スラウェシ州（Sulut）— 微笑みの港都マナド・ブナケンの蒼海・ミナハサの戦士

スラウェシ島の北東の角、フィリピンや太平洋に向かって腕を伸ばすように位置する **北スラウェシ州（Provinsi Sulawesi Utara / Sulut）**。

州都 **マナド（Manado）** は、キリスト教教会が立ち並び、オランダ植民地時代には「東インドの小さなオランダ」とも呼ばれた異国情緒あふれる港湾都市です。垂直に落ち込むドロップオフが息を呑む世界屈指のダイビングの聖地 **ブナケン国立公園（Taman Nasional Bunaken）**、戦士の誇りを伝える **ミナハサ民族（Suku Minahasa）** の古代巨石墓、そしてカツオの燻製や激辛唐辛子料理 **リカリカ（Rica-rica）**。開放的で陽気な北スラウェシの魅力を探訪しましょう。

## 1. 海中パラダイス：ブナケン海洋公園の絶壁

マナド沖合に浮かぶ **Taman Nasional Bunaken** は、世界中のスキューバダイバーの憧れの地です。
- **Dinding Karang Vertikal（垂直のドロップオフ）**: 島の周囲を取り囲むサンゴ礁は、水深数メートルの棚から一気に数百メートルへと切り立つ垂直の海底絶壁（ウォール）を形成しています。
- **Keanekaragaman Hayati Laut**: 世界の全海洋生物種の約7割、サンゴ種の約9割が確認されていると言われる驚異の生物多様性を誇り、悠然と泳ぐウミガメ（Penyu Sisik）、ナポレオンフィッシュ、群れをなすバラクーダに出会えます。

## 2. ミナハサの戦士魂と情熱の美食文化

マナドの内陸部に広がる高冷地 **ミナハサ（Minahasa）** は、豊かな火山灰土壌と独自の歴史を持ちます。
- **Waruga（古代の巨石墓）**: サワンガン（Sawangan）村などに残るミナハサ古代の石棺。遺体を母胎の胎児と同じ姿勢（座った状態）で石棺に納め、三角屋根の重い石蓋を被せる独特の埋葬文化です。
- **Tari Kabasaran（カバサラン戦士の舞）**: 真っ赤な衣装をまとい、鳥の羽の兜、鋭い刀（Santi）と盾を持ったミナハサ戦士たちの勇壮な舞踊。目をカッと見開き、大地を踏み鳴らす迫力で悪気を払います。
- **Kuliner Manado（情熱の激辛と健康粥）**:
  - **Tinutuan（マナド粥）**: カボチャ、キャッサバ、トウモロコシ、空心菜などの緑黄色野菜をトロトロに煮込んだ朝食用の極上健康粥。
  - **Ayam Rica-rica**: 大量の赤唐辛子、レモングラス、生姜、ライムで炒め煮にした、火を噴くような辛さと爽やかさが共存する名物料理。
  - **Cakalang Fufu**: 新鮮なカツオを背開きにし、竹の枠に固定して炭火の煙で赤褐色に燻製した保存食。

## 3. 北スラウェシ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |

## まとめと旅のヒント

1. **トモホンの花祭り**: 高原都市トモホン（Tomohon）では毎年8月に国際フラワーフェスティバル（TIFF）が開催され、満開の花で飾られたパレードカーが街を彩ります。
2. **色の変わる湖リノウ**: トモホン近郊のリノウ湖（Danau Linow）は、高濃度の硫黄成分のため光の加減で緑、青、琥珀色へと神秘的に色が変化します。
3. **カツオの燻製（Cakalang Fufu）**: マナドの空港やスーパーで真空パックされたチャカラン・フフは、ほぐして唐辛子と炒めると絶品のご飯のおかずになります。
