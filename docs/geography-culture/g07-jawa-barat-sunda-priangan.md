# G07：西ジャワ州（Jawa Barat）— 神々の住まうプリアンガン・スンダ文化・竹の音色アンクルン

ジャワ島西部に広がる **西ジャワ州（Provinsi Jawa Barat）** は、ジャワ人に次ぐインドネシア第2の人口（約4,000万人以上）を誇る **スンダ民族（Suku Sunda）** の故郷です。

緑豊かな茶畑が連なる肥沃な高原地帯は古くから **「パラヒャンガン（Parahyangan＝神々の住まう地 / プリアンガン）」** と呼ばれ、州都 **バンドン（Bandung）** はかつてオランダ人に「ジャワのパリ（Paris van Java）」と謳われました。竹の揺すり楽器 **アンクルン（Angklung）** の清らかな音色、優美なスンダ語、生野菜をふんだんに味わうヘルシーな食文化を体験しましょう。

## 1. 自然の恵みと高原都市バンドン（Paris van Java）

バンドンは周囲を山々に囲まれた高原盆地にあり、1年中爽やかな気候に恵まれています。
- **Gedung Sate（サテビル）**: 屋根の先端にサテ（串焼き）のような飾りを持つ美しいアール・デコ調建築で、西ジャワ州庁舎として有名です。
- **アジア・アフリカ会議（Konferensi Asia-Afrika 1955）**: ネルー、周恩来、ナセルら第三世界の指導者が集結し、「平和十原則（Dasasila Bandung）」を採択した歴史の舞台（Gedung Merdeka）でもあります。
- **Tangkuban Parahu & Kawah Putih**: ひっくり返った舟のような形の伝説の活火山や、幻想的なエメラルドグリーンの酸性火口湖が広がります。

## 2. スンダの美学：竹の共鳴アンクルンと野菜の食文化

スンダ人は穏やかで人懐こく、礼儀正しい（someah hade ka sembuh）人柄で知られます。
- **Angklung**: ユネスコ無形文化遺産。長さの異なる竹筒を枠に吊り下げ、手で左右に揺すって音を鳴らす楽器です。合奏体験で有名な「サウン・アンクルン・ウジョ（Saung Angklung Udjo）」では、数百人の観客が一人ひとつの音を担当し、心一つに美しい名曲を奏でます。
- **Lalapan & Sambal Terasi**: スンダ料理の真骨頂は、キュウリ、キャベツ、スリク（バジルに似た香草）などの新鮮な生野菜（Lalap）を手でちぎり、エビ味噌サンバルにディップして食べるヘルシーなスタイルです。

## 3. 西ジャワ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Parahyangan** | パラヒャンガン | 「神々の座所」を意味する西ジャワ山岳高原地帯の美称（ジャカルタとバンドンを結ぶ特急列車名でもある） |
| **Angklung** | アンクルン | 竹製の伝統打楽器。ドレミ音階（ダ・ディ・ドゥ・ダ・ディ）を揺らして合奏する |
| **Gedung Sate** | サテビル | バンドンの象徴。塔の頭頂部がサテ串の形をしていることから名付けられた |
| **Wayang Golek** | ワヤン・ゴレック | スンダ伝統の立体的な木彫り操り人形劇（人形遣いはダラン Dalang） |
| **Batagor** | バタゴール | 「Bakso Tahu Goreng」の略。魚のすり身を詰めた豆腐やワンタンの揚げ物にピーナッツソースをかけた人気軽食 |

## まとめと旅のヒント

1. **高速鉄道Whoosh**: 2023年に開業した東南アジア初の高速鉄道「Whoosh」により、ジャカルタ（ハリム駅）からバンドン（テガルルール駅）までわずか30〜45分で快適にアクセスできます。
2. **親称の使い分け**: スンダ文化圏では、男性への親愛の呼びかけとして「Akang（兄さん）」、女性へは「Teteh（姉さん）」が心地よく使われます。
3. **カフェ巡り**: バンドン北部（ダゴ・レンバン）には山々の大パノラマを望む洗練されたオープンカフェが無数にあり、週末の癒やしスポットとなっています。
