# G01：アチェ州（Aceh）— メッカのベランダ・シャリーア法・珈琲と津波復興の歴史

スマトラ島の北西端、インドネシア最西端に位置する **アチェ特別州（Provinsi Aceh）**。古くからインド洋交易の要衝として栄え、東南アジアで最も早くイスラム教を受け入れたことから 「**メッカのベランダ（Serambi Mekkah）**」 と称されます。

独自の自治権（シャリーア法 / Hukum Syariah）を持つ唯一の州であり、世界的に名高いガヨ・アラビカ珈琲の産地、そして2004年スマトラ島沖地震津波（Tsunami Aceh）からの不屈の復興を遂げた地でもあります。アチェの豊かな文化と歴史を学びましょう。

## 1. 歴史とアイデンティティ：「メッカのベランダ」

アチェ王国（Kesultanan Aceh）は16〜17世紀のイスカンダル・ムダ王（Sultan Iskandar Muda）の時代に黄金期を迎え、ポルトガルやオランダの植民地支配に対しても頑強に抵抗し続けました。

巡礼船がメッカへ旅立つ前の最後の寄港地であったことから「Serambi Mekkah」の愛称で呼ばれ、現在でも住民の日常生活や法制度においてイスラムの価値観が深く根付いています。

  （バイトゥラフマン・グランドモスクはバンダ・アチェ中心部に雄大にそびえ立ち、人々の不屈の信仰の象徴となっている。）

  （2004年の猛烈な大津波に襲われたにもかかわらず、この歴史的モスクは大きな損傷を受けることなく頑丈に立ち続けた。）

## 2. 自然と特産品：世界最高峰のガヨコーヒーと最北端サバン島

アチェ中央部の高原地帯（Dataran Tinggi Gayo）で栽培される **Kopi Arabika Gayo** は、有機栽培によるフルーティな酸味と芳醇なアロマで世界中のコーヒー愛好家を魅了しています。

また、北端に浮かぶウェイ島（Pulau Weh）のサバン（Sabang）には 「**インドネシア最西端ゼロキロ地点記念碑（Monumen Titik Nol Kilometer Indonesia）**」 があり、国歌『Dari Sabang sampai Merauke』の歌い出しとして国民に親しまれています。

- **Pulau Weh di Sabang menawarkan pemandangan bawah laut yang spektakuler bagi para penyelam internasional.**<br>
  （サバンに位置するウェイ島は、世界各国のダイバーたちに息を呑むような素晴らしい海中景観を提供している。）
- **Setiap wisatawan yang mencapai Tugu Nol Kilometer berhak mendapatkan sertifikat resmi sebagai bukti kunjungan.**<br>
  （ゼロキロ地点記念碑に到達した旅行者は皆、訪問の証として公式証明書を受け取る権利がある。）

## 3. アチェを語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Serambi Mekkah** | メッカのベランダ | アチェの歴史的・宗教的な尊称 |
| **Tari Saman** | サマン舞踊 | ユネスコ無形文化遺産。息の合った高速の手拍子と上半身の動きが特徴 |
| **Mie Aceh** | ミー・アチェ | カレー風味の濃厚なスパイススープまたは炒め麺（具はマトンやカニ、エビ） |
| **Ayam Tangkap** | アヤム・タンカップ | カレーリーフ（daun temurui）や青唐辛子を香ばしく素揚げした鶏肉料理 |
| **Museum Tsunami** | 津波博物館 | リドワン・カミル氏設計。震災の記憶を後世に継承する祈りの建築 |

## まとめと旅のヒント

1. **歴史と誇り**: 独立不羈の精神と敬虔な信仰が息づく地。服装や礼儀作法（イスラムの戒律尊重）に配慮して旅することが推奨されます。
2. **カフェ文化**: バンダ・アチェの街角には無数のカフェ（warung kopi）があり、ネルドリップ式で高く注がれる名物「Sanger」を片手に人々が夜遅くまで語り合います。
3. **記憶の継承**: 津波博物館や座礁した発電船（PLTD Apung）など、災害の教訓を伝えるモニュメントが街中に点在しています。
