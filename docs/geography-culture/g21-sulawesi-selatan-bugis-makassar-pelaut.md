# G21：南スラウェシ州（Sulsel）— 誇り高き海洋民族ブギス＆マカッサル・帆船ピニシ・東の雄鶏

スラウェシ島の南西半島部に位置し、東部インドネシア最大の経済・交通ハブである **南スラウェシ州（Provinsi Sulawesi Selatan / Sulsel）**。

その中心都市 **マカッサル（Makassar / 旧名ウジュン・パンダン）** は古くから国際貿易港として繁栄し、勇敢な海洋民族 **ブギス族（Suku Bugis）** と **マカッサル族（Suku Makassar）** を育んできました。釘を一切使わずに建造され世界を航海した伝統木造帆船 **ピニシ（Perahu Pinisi）**、オランダ東インド会社（VOC）を震撼させた「東の雄鶏」**ハサヌディン王（Sultan Hasanuddin）**、そして牛骨とスパイスが濃厚なスープ **チョト・マカッサル（Coto Makassar）**。誇り高き海の民の歴史と文化を学びましょう。

## 1. 大洋を駆けた海の覇者：ピニシ帆船とブギスの誇り

ブギス・マカッサルの人々は、羅針盤や設計図を持たず、風と星座の運行を読む直感だけでオーストラリア大陸北岸（マカッサン・コンタクト）からアフリカ・マダガスカル島まで交易航海を繰り広げた伝説の船乗り（Pelaut Tangguh）です。
- **Perahu Pinisi（ピニシ帆船）**: ブルクンバ県タナ・ベル（Tana Beru）の砂浜で、棟梁（Ponglima）の指揮のもと、熟練の職人たちが鉄木（Kayu Besi）を用いて釘を1本も使わず木組みだけで造り上げる二本マストの巨大木造スクーナー船。2017年にユネスコ世界無形文化遺産に登録されました。
- **Siri' na Pacce（誇りと共感の倫理）**: ブギス・マカッサル社会の最高道徳規範。「Siri'（自尊心・尊厳・恥を知る心）」と「Pacce（他者の苦しみへの深い共感・同胞愛）」を持ち、不当な侮辱には命を賭して立ち向かい、困窮する仲間には身銭を切って助け合う不屈の精神です。

## 2. ロッテルダム要塞と美食の街マカッサル

マカッサルは、歴史のドラマとグルメの街として名高い都市です。
- **Benteng Rotterdam（ロッテルダム要塞）**: 16世紀のゴワ王国（Kerajaan Gowa）が築いたウジュン・パンダン要塞を、1667年にオランダのスペールマン提督が占領・改築した巨大な城塞。東部インドネシアの植民地支配の拠点となり、ジャワ戦争の英雄ディポロゴロ王子が終生幽閉された場所でもあります。
- **Pantai Losari**: 市民が夕暮れ時に集まる名所。水平線に沈む黄金の夕陽を眺めながら、木槌で平たく叩いたバナナを炭火で焼き、椰子砂糖蜜をかけた **ピサン・エペ（Pisang Epe）** を頬張るのがマカッサル流の黄昏です。
- **Coto Makassar & Konro**: 牛の肉や内臓を数十種のスパイスとピーナッツ粉で煮込んだコク深い濃厚スープ **チョト・マカッサル**。ヤシの葉で包んだクトゥパット（Ketupat）を浸して食べる至福の味です。

## 3. 南スラウェシ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Perahu Pinisi** | ピニシ帆船 | ユネスコ無形文化遺産。ブルクンバ県で手造りされる二本マストの伝統的木造大型帆船 |
| **Sultan Hasanuddin** | ハサヌディン王 | ゴワ王国第16代スルタン。オランダ軍と激しく戦った国家英雄「東の雄鶏」 |
| **Coto Makassar** | チョト・マカッサル | 牛肉、胃袋やレバーなどのモツを、ピーナッツとスパイスの濃厚白濁スープで煮込んだ郷土料理 |
| **Sop Konro / Konro Bakar** | コンロ | 巨大な牛の骨付きバックリブをスパイシーなスープで煮込んだもの（炭火焼きはKonro Bakar） |
| **Rammang-Rammang** | ラマンラマン | マロス県にある世界第3位の規模を誇る雄大なタワーカルスト（石灰岩カルスト地形）湿地帯 |

## まとめと旅のヒント

1. **東部インドネシアの玄関口**: スルタン・ハサヌディン国際空港（UPG）は、マルク諸島やパプアへ向かう乗り継ぎの大ハブ空港です。
2. **カルストの秘境ラマンラマン**: マロス（Maros）のラマンラマンへ小舟で川を遡ると、映画『アバター』のような石灰岩の巨岩タワーと古代壁画洞窟が迎えてくれます。
3. **甘い誘惑ピサン・エペ**: ロサリ海岸の屋台で食べる「Pisang Epe Keju Cokelat（焼きバナナのチーズチョコがけ）」は、夜景鑑賞の最高のお供です。
