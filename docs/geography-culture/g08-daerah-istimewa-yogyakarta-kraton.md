# G08：ジョグジャカルタ特別州（DIY）— 古都クラトンの魂・バティックの美・学術と芸術の聖地

ジャワ島中南部に位置し、「Jogja（ジョグジャ）」の愛称で世界中の旅人や学生に愛される **ジョグジャカルタ特別州（Daerah Istimewa Yogyakarta / DIY）**。

独立戦争期には一時的にインドネシア共和国の首都となり、共和制国家の中にありながらスルタン（イスラム君主）が世襲で知事を務める唯一の特別州です。生きたジャワ文化の心臓部 **クラトン王宮（Kraton）**、壮麗な **プランバナン寺院群（Candi Prambanan）**、ろうけつ染め **バティック（Batik）**、学生街の活気あふれる屋台文化を探訪しましょう。

## 1. 生きたジャワ王宮：クラトンと哲学軸線（Sumbu Filosofi）

1755年、マタラム王国の分割によって誕生した **クラトン（Kraton Ngayogyakarta Hadiningrat）**。
2023年には、北の聖峰 **メラピ火山（Gunung Merapi）** から、白塔（Tugu）、マリオボロ通り、王宮、そして南の **インド洋（Laut Selatan）** を一直線に結ぶ **「ジョグジャカルタ哲学軸線（Sumbu Filosofi）」** がユネスコ世界文化遺産に登録されました。

これは、人間の誕生から成長、霊的成熟、そして創造主への回帰を象徴する壮大な都市計画です。

## 2. 芸術・遺跡・学生の街：プランバナンからアンクリガンまで

ジョグジャカルタの魅力は、壮大な歴史遺産と親しみやすい日常文化の融合にあります。
- **Candi Prambanan**: 9世紀に建立されたインドネシア最大のヒンドゥー教寺院遺跡（シヴァ神殿の高さは47m）。夜間にはライトアップされた寺院を背景に、野外劇場で壮麗な「ラーマーヤナ舞踊劇（Sendratari Ramayana）」が上演されます。
- **Kota Pendidikan（学術都市）**: 名門ガジャ・マダ大学（UGM）をはじめ多数の高等教育機関が集まり、全国から数十万人の学生が暮らす知性あふれる街です。
- **Gudeg & Angkringan**: 若いジャックフルーツを椰子砂糖とココナッツミルクでじっくり甘辛く煮込んだ伝統料理 **グドゥグ（Gudeg）**。夜になると歩道にゴザを敷いた屋台 **アンクリガン（Angkringan）** が現れ、真っ赤に焼けた木炭をグラスに放り込む名物 **コピ・ジョス（Kopi Jos）** を囲んで人々が語らいます。

## 3. ジョグジャカルタを語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Kraton** | クラトン | ジャワの伝統王宮。ガムラン演奏や宮廷舞踊が日々練習・奉納されている |
| **Abdi Dalem** | アブディ・ダレム | 王宮に身を捧げる宮廷侍従。無給に近い名誉職として仕える |
| **Gudeg** | グドゥグ | ジャックフルーツ、ゆで卵、鶏肉、牛皮の辛味煮（Krecek）を添えた伝統料理 |
| **Kopi Jos** | コピ・ジョス | 淹れたてのホットコーヒーに真っ赤に熱した木炭（arang）を直接投入する名物コーヒー |
| **Bakpia Pathok** | バッピア・パトゥック | 緑豆餡（Kacang Hijau）やチーズ、チョコレートをパイ生地で包んだ代表的銘菓 |

## まとめと旅のヒント

1. **バティックの選び方**: 「Batik Tulis（手描き）」は職人が数週間かけて蝋（malam）で線を描いた最高級品。「Batik Cap（銅板スタンプ）」や「Batik Print（プリント）」と区別して鑑賞しましょう。
2. **銀細工の古都コタゲデ**: 南東部のコタゲデ（Kotagede）地区には初代マタラム王国の古跡と銀細工工房（kerajinan perak）が集まっています。
3. **言葉と礼儀**: ジャワ文化の精髄である丁寧語（Krama）と柔らかな物腰が大切にされ、穏やかな心（tepa selira）で接すると地元の人々との距離がぐっと縮まります。
