# G16：南カリマンタン州（Kalsel）— 千の川の街バンジャルマシン・伝統水上マーケット・宝石の都マルタプラ

カリマンタン島南東部に位置する **南カリマンタン州（Provinsi Kalimantan Selatan / Kalsel）** は、バリト川やマルタプラ川など無数の河川が縦横に張り巡らされ、古くから 「**千の川の街（Kota Seribu Sungai）**」 と称される水の都です。

朝靄の川面に色鮮やかな果物を積んだ小舟が集う伝統の **水上マーケット（Pasar Terapung）**、天然ダイヤモンドの採掘と研磨で世界に知られる宝石の街 **マルタプラ（Martapura）**、商才に長け敬虔な信仰心を持つ **バンジャル民族（Suku Banjar）** の温かな暮らしと美食文化を探訪しましょう。

## 1. 水上の奇観：小舟ジュクンが織りなす伝統水上マーケット

バンジャルマシンの生活の中心は常に川の上にありました。その象徴が、数百年の歴史を誇る **パサール・トラプン（Pasar Terapung）** です。
- **Pasar Terapung Lok Baintan**: 毎朝夜明けとともに、近郊の農村から野菜やバナナ、ランブータンを山積みにした手漕ぎ小舟 **ジュクン（Jukung）** が集まります。
- **Tanggui（巨大な日よけ笠）**: 舟を操る商人のお母さんたちは、ヤシの葉で編んだ円錐形の大きな帽子「タンゴイ」をかぶり、日差しや水しぶきを防ぎます。
- **Barter（物々交換の伝統）**: 現代でも現金だけでなく、米と野菜、果物と魚を船から船へと直接手渡して交換する古代の物々交換の風習が一部残されています。

## 2. ダイヤモンドの街マルタプラと名物ソト・バンジャル

水上文化のほか、南カリマンタンは鉱業と工芸の宝庫です。
- **Kota Intan Martapura（宝石の街）**: バンジャルマシンから車で約1時間。チュンパカ（Cempaka）地区には数世紀前から続くダイヤモンドの手掘り採掘場があり、採掘された原石は職人の手でブリリアントカットに研磨されます。国内最大級の宝石市場（Pasar Cahaya Bumi Selamat）には世界中からバイヤーが集まります。
- **Kain Sasirangan**: バンジャル伝統の絞り染め布。布地に下絵を描き、糸で細かく縫い絞ってから天然染料に浸すことで、波や雲、植物を模した美しい幾何学模様が浮かび上がります。
- **Soto Banjar**: スパイス（シナモン、クローブ、ナツメグ）と鶏肉の出汁に、隠し味として少量の牛乳や練乳を加えてまろやかに仕上げたスープ。ジャガイモの揚げ団子（perkedel）やアヒルのゆで卵を添え、ライムをキュッと絞って味わいます。

## 3. 南カリマンタン州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Pasar Terapung** | 水上マーケット | 川面に小舟が密集して生鮮品や朝食を販売するバンジャルの伝統市場 |
| **Jukung** | ジュクン | 櫂（オール）で漕ぐ伝統的な木造小型ボート |
| **Tanggui** | タンゴイ | ヤシの葉を編んで作られた日除け用の巨大な円錐形編み笠 |
| **Soto Banjar** | ソト・バンジャル | シナモンやナツメグが香り、鶏肉とポテトケーキを添えた名物スープ |
| **Kain Sasirangan** | サシランガン | 悪霊除けや病気治癒の祈りが込められたバンジャルの伝統絞り染め布 |

## まとめと旅のヒント

1. **水上マーケットのベストタイム**: 水上市場の活気は早朝6時から7時半頃がピークです。ホテルを朝5時台に出発してボートで向かうのが鉄則です。
2. **川沿いカフェと夕暮れ**: マルタプラ川沿いの展望塔（Menara Pandang）周辺には夕暮れ時に屋台が並び、川風を感じながらのんびり散策できます。
3. **サシランガンの服**: サシランガンのシャツやスカーフは、現代的なモダンデザインも増えており、お土産やビジネスカジュアルとして重宝されています。
