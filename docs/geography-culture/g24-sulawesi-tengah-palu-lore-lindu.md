# G24：中部スラウェシ州（Sulteng）— 巨石人像の谷ロレ・リンドゥ・マレオ鳥・牛骨スープ「カレド」

スラウェシ島の中央に位置し、多様な腕部が交差する結節点にある **中部スラウェシ州（Provinsi Sulawesi Tengah / Sulteng）**。

イースター島のモアイ像にも比肩する、数千年前の古代人が彫り残した謎の巨石像群が草原に佇む **ロレ・リンドゥ国立公園（Taman Nasional Lore Lindu）**、地熱の砂に卵を埋めて自力で羽ばたかせる神秘の固有鳥 **マレオ（Burung Maleo）**、そして州都 **パル（Palu）** の牛の骨髄をストローですする名物スープ **カレド（Kaledo）**。考古学のロマンと手付かずの大自然が広がる中部スラウェシを探訪しましょう。

## 1. 東南アジア最大のミステリー：ロレ・リンドゥの巨石彫刻群

標高1,000メートルを超える山岳盆地 **バダ渓谷（Lembah Bada）**、**ベソア渓谷（Lembah Besoa）**、**ナプ渓谷（Lembah Napu）** の草原には、数十基もの巨大な花崗岩の彫刻が静かにたたずんでいます。
- **Patung Megalitikum（巨石人像）**: 紀元前1000〜3000年頃に作られたと推定される丸みを帯びた人型石像。最も有名な高さ4メートルの **パリンディ（Palindo＝おどけ者/欺く者）** は、巨大な丸い目、微笑んだような口元、男性器が誇張して彫られています。誰が、何の目的で彫ったのかは今なお考古学上の謎に包まれています。
- **Kalamba（巨石の壺）**: 人が入れるほどの巨大な石桶。古代の首長や貴族の共同墓地、あるいは神聖な雨水を溜める儀式用の水槽として使われたと考えられています。

## 2. 奇跡の鳥マレオと骨髄をすする絶品「カレド」

中部スラウェシは、動物地理学上の境界「ウォレシア線」の真っ只中にあり、固有生物の宝庫です。
- **Burung Maleo（マレオ鳥）**: キジほどの大きさの黒い鳥。自ら卵を抱くことはせず、地熱帯（温泉地）や日当たりの良い砂浜に深さ約1メートルの穴を掘り、ニワトリの5〜6倍もある巨大な卵を埋めて太陽熱と地熱で孵化させます。生まれた雛は、誰の手も借りずに自力で砂を掘り起こして外に出て、その瞬間から空を飛べるという驚異の生態を持ちます。
- **Kaledo（牛骨髄スープ）**: パル市民のソウルフードで、**「Kaki Lembu Donggala（ドンガラ牛の脚）」** の頭文字から名付けられました。牛のスネ骨を肉付きのまま大きな鍋で煮込み、酸味の効いた未熟なタマリンド（asam jawa）と生青唐辛子で味付けします。肉をナイフで削ぎ落とし、骨の中にストローを差し込んでトロトロの濃厚な骨髄（sumsum tulang）を吸い上げるのが本場の食べ方です。

## 3. 中部スラウェシ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Megalit Lore Lindu** | ロレ・リンドゥ巨石群 | バダ渓谷などに点在する古代の巨石彫刻（パリンディ像、カランバ石桶など） |
| **Burung Maleo** | マレオ鳥 | 地熱を利用して卵を孵化させるスラウェシ固有の希少鳥類 |
| **Kaledo** | カレド | 牛のスネ肉と骨髄をタマリンドと青唐辛子で煮込んだパル名物のスープ |
| **Danau Poso** | ポソ湖 | インドネシア第3の深さを誇る巨大な古代湖。黄金色の砂浜と銀色のウナギ（Sogili）で有名 |
| **Bawang Goreng Palu** | パル産フライドエシャロット | パル谷特有の乾燥気候で育つ水分が少ない赤玉ねぎを揚げた最高級のトッピング |

## まとめと旅のヒント

1. **お土産の王様パル産揚げ玉ねぎ**: パル産「Bawang Goreng」は、サクサクした食感と上品な甘みでインドネシア全土で最も高級なフライドオニオンとして珍重されています。
2. **ポソ湖の静寂**: ポソ湖（Danau Poso）のほとりテンテナ（Tentena）では、淡水湖とは思えない波打ち際の砂浜と清らかな水辺のリゾートステイが楽しめます。
3. **バダ渓谷へのアクセス**: ロレ・リンドゥの巨石を訪ねるには、パルから車で数時間走り、山間部を四輪駆動車やトレッキングで巡る探検ルートが一般的です。
