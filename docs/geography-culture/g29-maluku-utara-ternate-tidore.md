# G29：北マルク州（Malut）— 双子火山島テルナテ＆ティドレ・丁子の黄金郷・世界一周の到達地

モルッカ海に美しく浮かぶ2つの円錐形火山島、**テルナテ（Ternate）** と **ティドレ（Tidore）** を擁する **北マルク州（Provinsi Maluku Utara / Malut）**。

古代ローマ皇帝や中国の皇帝たちがこぞって求めた魅惑の香薬 **クローブ（Cengkeh / 丁子）** の原産地であり、16世紀にはポルトガルやスペインの武装船団が激突した世界交易の中心でした。**マゼラン艦隊が人類史上初の世界一周航海** の途上で満身創痍の末に到達したのもこのティドレ島でした。悠久の火山と香料の歴史を旅しましょう。

## 1. 世界史を動かしたクローブの覇権とマゼラン艦隊の到達

クローブ（丁子）の乾燥した蕾は、肉の保存、歯痛の鎮痛剤、高貴な香気としてヨーロッパでは「黒いダイヤモンド」と呼ばれました。
- **Kesultanan Ternate & Tidore**: かつてパプアからスラウェシ東部まで勢力を誇ったイスラム王国。スルタン・バブッラー（Sultan Baabullah）は1575年、横暴なポルトガル軍を要塞から追放し、独立を回復した名君として知られます。
- **Pelayaran Keliling Dunia Magellan (1521)**: フェルディナンド・マゼラン率いるスペイン艦隊は、南米大陸最南端のマゼラン海峡を越えて太平洋を横断。マゼラン本人はフィリピンで戦死したものの、エルカーノ率いる残存船ビクトリア号が1521年11月、目的地であったティドレ島に奇跡的に到達しました。倉庫一杯のクローブを積み込み、喜望峰を回ってスペインへ帰還し、**人類初の世界一周航海を達成** したのです。

## 2. 旧千ルピア紙幣の絶景ンガデ湖と心温まる「アイル・グラカ」

テルナテ島は、どこからでも活火山 **ガマラマ山（Gunung Gamalama / 標高1,715m）** の雄姿が望めます。
- **Danau Ngade & Danau Tolire**: ガマラマ山の麓にあるカルデラ湖。ンガデ湖の展望台から望むティドレ島の円錐シルエットは、かつてのインドネシア1,000ルピア紙幣の裏面に描かれたことで国民的に有名です。
- **Benteng Tolukko & Kastela**: 16世紀初頭にポルトガル人によって築かれた石造要塞群。要塞の銃眼からは、香料船が行き交った群青の海を見渡せます。
- **Air Guraka（アイル・グラカ）**: テルナテの夜の定番ドリンク。叩いた生姜（jahe）を黒ヤシ砂糖で煮出し、仕上げに香ばしい特産のケナリナッツ（biji kenari）をたっぷり浮かべた温かいスパイシードリンク。揚げバナナ（Pisang Mulut Bebek）と一緒に夜風に吹かれながら味わうのが現地流です。

## 3. 北マルク州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Cengkeh (丁子)** | クローブ | 香料諸島の原産樹。未開花の蕾を乾燥させた甘く刺激的なスパイス |
| **Gunung Gamalama** | ガマラマ山 | テルナテ島の中央にそびえる活火山。山腹には樹齢数百年の古木「Cengkeh Afo」がある |
| **Benteng Tolukko** | トルッコ要塞 | 1540年にポルトガル人が築いたテルナテの石造要塞 |
| **Air Guraka** | アイル・グラカ | 生姜、ヤシ砂糖、シナモン、ケナリナッツで作る伝統の温熱ハーブティー |
| **Pulau Halmahera** | ハルマヘラ島 | 北マルク州最大の島。広大な熱帯雨林と世界最大のニッケル製錬コンプレックス（Weda Bay）を抱える |

## まとめと旅のヒント

1. **テルナテ〜ティドレ間の移動**: テルナテのバスタシ港（Pelabuhan Bastiong）からスピードボートでわずか10分でティドレ島へ渡ることができます。
2. **世界最古のクローブ樹**: ガマラマ山腹には、樹齢400年を超えるとされる歴史的巨樹「Cengkeh Afo」の遺構があり、香料の歴史を肌で実感できます。
3. **島一周の絶景ドライブ**: テルナテ島は外周道路が舗装されており、車やバイクで約2時間で海岸線や溶岩流の跡（Batu Angus）を一周できます。
