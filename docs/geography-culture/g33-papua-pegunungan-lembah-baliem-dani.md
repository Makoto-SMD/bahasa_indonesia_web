# G33：山岳パプア州（Papua Pegunungan）— 秘境バリエム渓谷・ダニ族・ホナイとバカル・バトゥ

インドネシアで唯一海に面していない内陸州であり、標高数千メートルの急峻なジャヤウィジャヤ山脈に抱かれた **山岳パプア州（Provinsi Papua Pegunungan）**。

その中心地 **ワメナ（Wamena）** が位置する **バリエム渓谷（Lembah Baliem）** は、1938年に米国の探検家リチャード・アーチボルドの飛行機によって「偶然発見」されるまで、外界と隔絶された石器時代さながらの伝統生活が営まれていた伝説の秘境です。勇敢で誇り高き **ダニ族（Suku Dani）**、伝統の円形住居 **ホナイ（Rumah Honai）**、男性の衣装 **コテカ（Koteka）**、そして部族の結束を誓う焼石蒸し焼き儀礼 **バカル・バトゥ（Bakar Batu）**。天空の大地が育んだ驚くべき文化を学びましょう。

## 1. ダニ族の伝統生活：ホナイとコテカ

バリエム渓谷の主食は、何十種類もの品種が栽培されるサツマイモ **ヒペレ（Hipere / Ubi Jalar）** です。ダニ族の人々は急峻な斜面に見事な段々畑と排水溝を築き、高度な農業を行ってきました。

- **Rumah Honai（ホナイ住居）**: 壁は二重の板張り、屋根は厚いススキなどの草（Jerami/Ilalang）を丸く葺いたキノコ型の伝統家屋。窓がなく出入口も非常に小さく作られているのは、夜間に10度近くまで冷え込む高地の冷気や強風を防ぎ、中央の炉（Perapian）で焚く薪の熱を逃がさないための優れた建築工学です。
- **Koteka / Holim（コテカ）**: ダニ族の男性が着用するヒョウタン（Labu Air）を乾燥させて作った伝統の陰茎サック。部族や階級によって形状が異なり、ダニ族のものはまっすぐ長く伸びた形状が特徴です。現在では日常着として洋服を着る人が増えていますが、長老たちや伝統儀式では今なお誇り高く着用されます。
- **Mumi Jiwika（ジウィカのミイラ）**: 渓谷北部のジウィカ村（Desa Jiwika）などには、数百年前に部族を守った偉大な首長（Kepala Suku）の遺体を特別な薪の煙で何ヶ月も燻製にして保存した黒光りするミイラが安置されており、現在も見学することができます。

## 2. 絆と和解の大饗宴：バカル・バトゥ（Barapen）

パプア山岳部族社会において、最も重要で神聖な伝統儀礼が **バカル・バトゥ（Tradisi Bakar Batu / バラペン Barapen）** です。

- **Makna Ritual（儀礼の意味）**: 豊作の感謝、結婚や誕生の祝福、長老の追悼、そして何よりもかつて部族同士の抗争（Perang Suku）が起きた際に、双方が和解と平和（Perdamaian）を誓い合うために執り行われます。
- **Proses Memasak（調理のプロセス）**:
  1. 地面に大きな穴を掘り、バナナの葉や草を敷き詰めます。
  2. 薪を高く組み上げ、その上に無数の大きな川石を置いて赤熱するまで数時間激しく加熱します。
  3. 木の大きなトング（Jepit Kayu）で熱々の石を穴の中に運び込みます。
  4. 石の上にサツマイモ、キャッサバの葉、野菜、そして儀礼のために捧げられた豚（Babi）の肉を重ね、さらに熱い石と草で何層にも覆って密閉します。
  5. 蒸気が立ち込める中で数時間じっくりと蒸し焼きにされた料理を、村人全員で分け合って笑顔で食します。

- **Batu-batu yang dibakar hingga membara digunakan untuk mematangkan daging dan ubi secara alami tanpa bumbu penyedap buatan.**<br>
  （真っ赤に熱せられるまで焼かれた石は、人工調味料を一切使わずに天然の力で肉や芋に火を通すために用いられる。）

  （社会的身分にかかわらず、全住民が車座になって座り、料理を公平に分け合って堪能する。）

## まとめと旅のヒント (Catatan Perjalanan)

山岳パプア州ワメナへの旅は、地球上で最もユニークな異文化体験の一つです。

- **アクセスと持ち物**: ワメナにはジャヤプラのセンタニ空港から小型機（ATR等）で約45分でアクセスします。標高1,600m以上のため、日中は過ごしやすい気温でも、朝晩は10〜15度近くまで冷え込むため、防寒着（フリースやウィンドブレーカー）が必須です。
- **無農薬ワメナ・コーヒー（Kopi Wamena）**: 高地特有の冷涼な気候と肥沃な火山灰土壌で、農薬や化学肥料を一切使わずに育てられるアラビカ種コーヒー。チョコレートやハーブのような深いコクとフルーティーな酸味が際立ち、お土産として最高級の評価を得ています。
