# G12：西ヌサ・トゥンガラ州（NTB）— 千のモスクの島ロンボク・ササック文化・聖峰リンジャニ

バリ島の東隣に位置する **西ヌサ・トゥンガラ州（Provinsi Nusa Tenggara Barat / NTB）** は、**ロンボク島（Pulau Lombok）** と広大な **スンバワ島（Pulau Sumbawa）** の2つの大島から構成されます。

ヒンドゥー文化のバリ島とは対照的に、ロンボク島は住民の大多数が熱心なイスラム教徒であり **「千のモスクの島（Pulau Seribu Masjid）」** と呼ばれます。壮大な聖峰 **リンジャニ山（Gunung Rinjani）**、ササック民族（Suku Sasak）の伝統集落、世界最高峰の二輪レースMotoGPが開催される国際サーキット **マンダリカ（Mandalika）**。活気と伝統が共存するNTBの魅力を探訪しましょう。

## 1. 聖峰リンジャニと伝説の海ゴカイ祭り「バウ・ニャレ」

ロンボク島北部にそびえる **Gunung Rinjani**（標高3,726m）は、インドネシア第2の高峰です。
- **Segara Anak（セガラ・アナック湖）**: 火口原に広がる三日月形のエメラルドグリーンのカルデラ湖。ササック族やバリ・ヒンドゥー教徒にとって神聖な祈りと瞑想の場であり、世界中のトレッカーの憧れの地です。
- **Festival Bau Nyale（バウ・ニャレ祭）**: 南部クア海岸で毎年2〜3月に開催される伝統行事。争いを避けるために海に身を投じた美しき **マンダリカ王女（Putri Mandalika）** が転生したとされる発光海ゴカイ（Nyale）を、数万人の人々が一晩中海に入って捕獲する幻想的な大祭です。

## 2. ササック民族の伝統集落サデ村と武術プレセアン

ロンボク中南部の **サデ村（Desa Sade）** では、数百年前の生活様式が今もそのまま守られています。
- **Rumah Adat Sasak**: 屋根は茅（alang-alang）、壁は竹編み、そして床には蚊や虫除けと清潔を保つために伝統的に水牛の糞（kotoran kerbau）を塗り磨く驚きの知恵が受け継がれています。独特のドーム型の高床式穀物倉は **ルンブン（Lumbung）** と呼ばれます。
- **Peresean（プレセアン）**: 2人の屈強な男性戦士が、藤の杖（penjalin）と牛革の盾（ende）を持ち、ガムランの太鼓のリズムに合わせて激しく打ち合うササック伝統の武術決闘。かつては雨乞いの儀式として行われました。
- **Kain Tenun Songket Sasak**: ササック人女性は「布を織れなければ一人前の嫁になれない」と言われ、精緻な手織り布（Tenun）の技術が母から娘へと伝承されます。

## 3. 西ヌサ・トゥンガラ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Suku Sasak** | ササック族 | ロンボク島の先住民族。独自の言語（Bahasa Sasak）と伝統工芸を持つ |
| **Ayam Taliwang** | アヤム・タリワン | 若鶏（Ayam Kampung）を唐辛子とトラシの激辛特製ダレで香ばしく直火焼きした名物料理 |
| **Gili Trawangan** | ギリ・トラワンガン | ロンボク北西部の3つの小島（Gili）の最大島。自動車・バイクの乗り入れが全面禁止（移動は馬車シドモか自転車） |
| **Sirkuit Mandalika** | マンダリカ・サーキット | 海岸沿いに建設された美しい国際モータースポーツサーキット（MotoGP公式開催地） |
| **Gunung Tambora** | タンボラ山 | スンバワ島の火山。1815年の大噴火は地球規模の「夏のない年（Year Without a Summer）」を引き起こした |

## まとめと旅のヒント

1. **バイクの楽園マンダリカ**: 国際サーキットの周辺には白砂の美しいビーチ（Kuta Mandalika, Tanjung Aan）が連なり、サーフィンや絶景ビューポイントが豊富です。
2. **スンバワ島の大自然**: 東側のスンバワ島は野生馬の放牧やクジラザメ（Hiu Paus）との遊泳ツアー（サレア湾 Teluk Saleh）で冒険者に愛されています。
3. **辛さの洗礼**: ロンボク料理はジャワ料理に比べて極めて辛い（pedas）ため、辛さに弱い人は注文時に「Jangan terlalu pedas（あまり辛くしないで）」と頼みましょう。
