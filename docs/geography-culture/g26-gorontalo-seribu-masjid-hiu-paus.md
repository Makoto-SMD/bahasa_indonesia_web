# G26：ゴロンタロ州（Gorontalo）— メディナのベランダ・ジンベエザメの海・トウモロコシスープの都

スラウェシ島北部のトミニ湾（Teluk Tomini）に抱かれた静穏なる港町 **ゴロンタロ州（Provinsi Gorontalo）**。2000年に北スラウェシ州から分立して誕生した独自の歴史と文化を誇る州です。

アチェが「メッカのベランダ」と呼ばれるのに対し、敬虔な信仰心から 「**メディナのベランダ（Serambi Madinah）**」 と称されるこの地には、海岸からわずか数十メートルの波打ち際で巨大な野生の **ジンベエザメ（Hiu Paus）** と一緒に泳げる世界的な奇跡のビーチ **ボツバラニ（Botubarani）** や、古代の湖を見下ろす **オタナハ要塞（Benteng Otanaha）** があります。トウモロコシの恵み豊かなゴロンタロを探訪しましょう。

## 1. 岸からすぐの野生体験：ボツバラニのジンベエザメ

ボネ・ボランゴ県にある **Pantai Botubarani** は、世界で最もアクセスが容易なジンベエザメの観察地として国際的に有名です。
- **Hiu Paus Dekat Pesisir**: 通常は外洋の深海に生息する世界最大の魚類 **ジンベエザメ（Rhincodon typus / Hiu Paus）** が、海岸からわずか数十〜百メートルの距離まで遊泳してきます。
- **Interaksi yang Tertata**: 小さな手漕ぎカヌーに乗って数分漕ぎ出すだけで、巨大な体躯のジンベエザメが船のすぐ横を優雅に泳ぎます。シュノーケリングでの接近や観察ルールが厳格に定められ、環境に配慮したエコツーリズムが実践されています。

## 2. 湖を見下ろす要塞と伝統刺繍「カラウォ」

ゴロンタロは、独自の防衛史と繊細な手工芸を誇ります。
- **Benteng Otanaha**: 1525年頃、ゴロンタロ王国のイルト（Ilato）王がポルトガル軍からの防衛と同盟の象徴としてリンボト湖（Danau Limboto）のほとりの丘の上に築いた石造要塞。卵白を接着剤にして積み上げられた石壁からは、湖と水田の大パノラマが広がります。
- **Kain Sulam Karawo**: ユネスコ無形文化遺産候補。織り上がった布地からタテ糸やヨコ糸を1本ずつピンセットで慎重に引き抜き、残った網目状の隙間に色糸で繊細な花鳥文様を手刺繍していく極めて手間の掛かる伝統刺繍工芸（Sulam Kerawang）です。
- **Binte Biluhuta（ビンテ・ビルフタ）**: ゴロンタロ語で「トウモロコシのスープ（現地名: Milu Siram）」を意味する名物料理。甘みのある白トウモロコシ、ほぐしたマグロ（Cakalang）、小エビ、削りココナッツに、ライム果汁とバジル（kemangi）を絞った、酸味と旨味が調和した爽快なスープです。

## 3. ゴロンタロ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Bumi Serambi Madinah** | メディナのベランダ | イスラムの伝統と平和的共生を重んじるゴロンタロ州の尊称 |
| **Hiu Paus (Whaleshark)** | ジンベエザメ | プランクトンを主食とする穏やかな海の巨人。ボツバラニ海岸に定着 |
| **Binte Biluhuta** | ビンテ・ビルフタ | トウモロコシ、魚、エビ、ココナッツ、ライムを合わせた伝統の酸味スープ |
| **Sulam Karawo** | カラウォ刺繍 | 経糸・緯糸を抜いて柄を縫い込むゴロンタロ特産の最高級手刺繍布 |
| **Ilabulo** | イラブロー | サゴヤシ粉と味付けした鶏肉・レバーをバナナの葉で包んで炭火焼きにしたスパイシーな軽食 |

## まとめと旅のヒント

1. **アクセス情報**: ジャカルタやマカッサルからゴロンタロのジャラルディン空港（GTO）へ直行便が就航しています。
2. **水上コテージ「プロー・チンタ」**: ボアレモ県沖には、ハート型の砂州の上に建てられたエコリゾート「Pulo Cinta（愛の島）」があり、インドネシアのモルディブとしてカップルに人気です。
3. **早朝のジンベエザメ**: ジンベエザメ観察は波が穏やかな早朝（6時半〜8時）が最も遭遇率が高く、水が透き通って美しく見えます。
