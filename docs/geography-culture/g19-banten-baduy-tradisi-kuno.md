# G19：バンテン州（Banten）— 文明を拒む隠遁者バドゥイ・ジャワサイの聖域・クラカタウ火山

ジャワ島の最西端に位置し、スンダ海峡（Selat Sunda）を挟んでスマトラ島と対峙する **バンテン州（Provinsi Banten）**。

現代文明のテクノロジー（電気、自動車、スマートフォン、化学洗剤）を一切拒絶し、古代スンダの掟を厳格に守り続ける **バドゥイ族（Suku Baduy / Urang Kanekes）**、世界で数十頭しか生き残っていない幻の絶滅危惧種 **ジャワサイ（Badak Jawa）** を育む世界遺産ウジュン・クロン国立公園、そして1883年に地球の気候を激変させた **クラカタウ火山（Gunung Krakatau）**。自然の原初的な力と太古の調和が息づく地を訪ねましょう。

## 1. 文明を拒み自然の掟を守る隠遁者：バドゥイ族（Suku Baduy）

レバック県ケネケス（Kanekes）の山奥に暮らす **Suku Baduy**（自称：Urang Kanekes）は、現代社会から完全に隔絶した伝統生活を守っています。
- **内バドゥイ（Baduy Dalam）**: 白い頭布と無染色の白い服（baju putih）を纏い、**電気、車輪、機械、履物（靴・サンダル）、石鹸、カメラ、学校教育の一切を禁止**。すべて徒歩で移動し、川の水で体を清め、竹とヤシの葉の家で暮らします。
- **外バドゥイ（Baduy Luar）**: 黒や青の服（baju hitam）を着て、内バドゥイと外部社会との間の緩衝地帯として暮らします。
- **Pikukuh（不変の掟）**: 「山を削ってはならぬ、谷を埋めてはならぬ、短きを伸ばしてはならぬ、長きを縮めてはならぬ」という自然の摂理への絶対服従の教えです。

## 2. 最後の聖域ウジュン・クロンとクラカタウ火山

バンテン州の海岸線には、地球の猛威と生態系の奇跡が刻まれています。
- **Taman Nasional Ujung Kulon**: ジャワ島最西端の半島。地球上にわずか約70〜80頭しか生息していない世界最希少動物の一つ **ジャワサイ（Badak Jawa / Badak bercula satu）** の最後の砦です。密猟防止レンジャー（Rhino Protection Unit）が厳重に警護しています。
- **Gunung Anak Krakatau**: 1883年8月、人類史上最大級の爆発（津波と地球の気温低下をもたらした）を起こしたクラカタウ火山のカルデラ跡から、海面上に誕生した「クラカタウの息子（Anak Krakatau）」。今なお噴火と成長を続ける生きた火山です。

## まとめと旅のヒント

1. **バドゥイ集落へのトレッキング**: 外バドゥイのチボオ村（Ciboleger）から徒歩で数時間歩いて内バドゥイへ向かいます。写真撮影禁止などのタブー（pantangan）を厳格に遵守することが絶対条件です。
2. **メラック港の連絡船**: ジャワ島とスマトラ島を結ぶ大動脈で、大型フェリーが24時間ひっきりなしにスンダ海峡を往来しています。
3. **歴史遺産オールド・バンテン**: スルタン・ハサヌディンが築いたかつての国際貿易港バンテンの遺跡や大モスクには、今も巡礼者が絶えません。
