# G15：中部カリマンタン州（Kalteng）— ダヤックの聖地・大森林のロングハウス・オランウータンの楽園

ボルネオ島の広大な熱帯雨林と泥炭湿地帯を抱える **中部カリマンタン州（Provinsi Kalimantan Tengah / Kalteng）**。

スカルノ初代大統領が1950年代に「真のインドネシア新首都」として自ら製図台に向かい設計した州都 **パランカラヤ（Palangka Raya）**、先住民族ダヤック（Suku Dayak）が大家族で共生する巨大高床式ロングハウス **ルマ・ベタン（Rumah Betang）**、祖霊の魂を天界へ導く壮大な儀礼 **チワー（Tiwah）**、そして世界最大の野生オランウータンのサンクチュアリ **タンジュン・プティン国立公園**。森の生命力と神秘に満ちた世界を探訪しましょう。

## 1. 共生の建築美「ルマ・ベタン」と聖なる葬送「チワー」

ダヤック社会の精神的中核は、巨大な高床式木造家屋 **ルマ・ベタン（Rumah Betang）** にあります。
- **Rumah Betang**: 長さ数十メートルから100メートルを超え、地面から数メートルの高さの丸太柱の上に建てられます。数十家族（数百人）が一つ屋根の下で暮らし、中央の広間で長老を中心に村の重要事項を話し合います。盗賊や野獣を防ぐだけでなく、「家族間の争いを禁じ、平等と連帯を守る」平和の象徴です。
- **Upacara Tiwah**: ダヤック・カハリンガン信仰における最大の通過儀礼。死者の埋葬から数年後、遺骨を掘り起こして聖水で洗い清め、彫刻が施された木造の小祠堂 **サンドゥン（Sandung）** に納める儀式です。これによって故人の魂（Liau）は天界の神々の住まう浄土（Lewu Tatau）へと無事に旅立つと信じられています。

## 2. 森の人オランウータンの聖域：タンジュン・プティン

南西部に位置する **Taman Nasional Tanjung Puting** は、世界で最も有名な霊長類研究・保護の拠点です。
- **Orangutan（森の人）**: マレー語・インドネシア語で「Orang（人）」と「Hutan（森）」が合わさった名の通り、人間の遺伝子と97%共通する知能の高い類人猿です。
- **Klotok（クロトック船）**: 静かなセコニエ川（Sungai Sekonyer）を伝統的な木造船クロトックに乗って数日間かけてクルーズします。川沿いのマングローブにはテングザル（Bekantan）が群れ、夜にはホタルがクリスマスツリーのように瞬きます。
- **Camp Leakey**: 霊長類学者ビルーテ・ガルディカス（Biruté Galdikas）博士が1971年に設立したリサーチセンター。餌付けの時間（feeding time）には、野生に戻されたオランウータンの母子が木々の梢を伝って姿を現します。

## まとめと旅のヒント

1. **クロトック船上での一夜**: タンジュン・プティンのツアーでは、船の甲板に蚊帳（kelambu）を吊って星空と虫の音に包まれて眠るロマンチックな滞在が人気です。
2. **鉄木の工芸品**: カリマンタン特産の鉄木（Kayu Ulin）や藤（Rotan）で編まれた伝統バッグ「Anjat」は、驚くほど丈夫で美しい民芸品です。
3. **川の街パランカラヤ**: カハヤン川沿いには水上レストランが立ち並び、新鮮な川魚料理を味わいながら雄大な夕陽を眺めることができます。
