# G17：東カリマンタン州（Kaltim）— 新首都IKNヌサンタラ・マハカム川のイルカ・楽園デラワン

インドネシア国家の未来を担う新首都 「**IKNヌサンタラ（Ibu Kota Nusantara）**」 の建設地として世界中から熱い視線を集める **東カリマンタン州（Provinsi Kalimantan Timur / Kaltim）**。

石炭、石油、天然ガスが豊富に埋蔵されるエネルギーの大動脈であり、4世紀末のインドネシア最古の碑文が残る **クタイ王国（Kerajaan Kutai）** の地でもあります。雄大な **マハカム川（Sungai Mahakam）** に棲む幻の淡水イルカ、そして手付かずのサンゴ礁と無毒クラゲが群れ泳ぐ **デラワン諸島（Kepulauan Derawan）**。東カリマンタンの歴史と未来を探訪しましょう。

## 1. 国家の新たな夜明け：新首都IKNヌサンタラ（Ibu Kota Nusantara）

ジャカルタの過密・地盤沈下を解消し、群島全体のバランスある発展（Indonesia Sentris）を実現するため、2020年代に建設が本格化した **IKN Nusantara**。
- **Smart Forest City（スマート森林都市）**: 全敷地の約70%以上を緑地・保護林として残し、100%再生可能エネルギーでの運行を目指すエコロジカルな未来型首都です。
- **Istana Garuda（ガルーダ宮殿）**: 新首都の象徴となる大統領府建築。国章である聖鳥ガルーダが大きく翼を広げた荘厳なデザインが丘の上にそびえ立ちます。2024年8月17日には、ジャカルタとIKNの両会場を結んで第79回独立記念式典が挙行されました。

## 2. マハカム川の淡水イルカと楽園デラワン諸島

東カリマンタンは、海と川の生態系の宝庫です。
- **Pesut Mahakam（マハカム・イルカ）**: マハカム川上流の内陸淡水域に生息する世界的に極めて珍しいカワゴンドウ（淡水イルカ）。丸みを帯びた頭部と愛らしい表情が特徴で、東カリマンタン州の公式マスコットになっています。
- **Kepulauan Derawan & Danau Kakaban**: ベラウ沖に浮かぶデラワン諸島はウミガメの世界的産卵地。特に **カカバン島（Pulau Kakaban）** の内陸塩水湖には、天敵がいない環境で何百万年も孤立した結果、**刺胞毒を完全に失った無毒クラゲ（ubur-ubur tidak menyengat）** が無数に群れ泳いでおり、世界中のダイバーが安全にクラゲと一緒に泳ぐことができます。

## まとめと旅のヒント

1. **二大都市の役割**: 国際便や近代的なホテル、商業施設が揃うゲートウェイは「バリクパパン（BPN空港）」、行政・歴史探訪の中心は川沿いの「サマリンダ」と機能が分かれています。
2. **マハカム川リバークルーズ**: サマリンダから内陸のクタイやダヤック伝統村（Tanjung Isuyなど）へ木造船で遡上するリバークルーズは、冒険好きに大人気です。
3. **海産物グルメ**: バリクパパンの海岸沿いにはオープンエアのシーフードレストランが並び、マングローブガニ（Kepiting Dandito / Kenari）のブラックペッパー炒めが絶品です。
