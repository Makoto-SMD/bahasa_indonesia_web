# G20：ランプン州（Lampung）— スマトラの玄関口・ウェイカンバスの象・ロブスタ珈琲の都

スンダ海峡を渡り、ジャワ島からスマトラ島へ足を踏み入れる最初の地 **ランプン州（Provinsi Lampung）**。

港町バカウヘニ（Bakauheni）から始まるトランス・スマトラ高速道路の起点であり、巨大な熱帯野生動物 **スマトラ象（Gajah Sumatera）** が群れ遊ぶ **ウェイ・カンバス国立公園（Taman Nasional Way Kambas）** を擁します。野生イルカが跳ねるキルアン湾（Teluk Kiluan）、インドネシア最大のロブスタ珈琲の産地、そしてジャワ島からの移民（Transmigrasi）が拓いた多文化共生の歴史を探求しましょう。

## 1. 密林の巨人を守る：ウェイ・カンバス国立公園

ランプン東部の平地林に広がる **Taman Nasional Way Kambas** は、1980年代から象の保護と人間との共生に取り組む世界的なサンクチュアリです。
- **Pusat Konservasi Gajah (PKG)**: 森林伐採や農地開発によって住処を追われたスマトラ象（Gajah Sumatera）を保護し、象使い（Mahout）が健康管理やリハビリを行う象の保護センターです。
- **Suaka Badak Sumatera (SRS)**: 極めて警戒心の強い希少なスマトラサイ（二角サイ）の半野生繁殖プログラムが行われており、近年も貴重な赤ちゃんの誕生が世界中でニュースとなりました。

## 2. 移住の歴史と美食：ロブスタコーヒーとバナナチップス

ランプン州は、インドネシアの社会史において最も大規模な **国内移住政策（Transmigrasi）** が行われた地域です。20世紀初頭のオランダ植民地時代からスハルト政権期にかけて、過密なジャワ島から多くの農民が入植し、荒野を開墾してコーヒー、ゴム、キャッサバの一大産地を築き上げました。

- **Kopi Robusta Lampung**: インドネシアのロブスタコーヒーの代名詞。どっしりとしたコクとビターな味わいが特徴で、国内外のインスタントコーヒーやカフェのブレンド豆として大量に供給されています。
- **Keripik Pisang Aneka Rasa**: ランプン名物のバナナチップス。特産のバナナをサクサクに揚げ、厚切りのチョコレート、チーズ、コーヒー、抹茶パウダーをたっぷりまぶしたスイーツで、観光客の必須のお土産です。
- **Seruit**: 焼き魚（イカン・パティンなど）を、唐辛子、マンゴー（mangga kweni）、発酵ドリアンペースト（tempoyak）のサンバルと手で豪快に混ぜ合わせて食べるランプン先住民族の伝統馳走です。

## 3. ランプン州を語る重要キーワード・用語集

| :--- | :--- | :--- |
| **Menara Siger** | シゲル塔 | バカウヘニ港の丘の上にそびえる黄金のモニュメント。ランプン花嫁の冠（Siger）を模している |
| **Gajah Sumatera** | スマトラ象 | アジア象の亜種。森林破壊で生息数が減少し、ウェイ・カンバスで手厚く保護されている |

| **Seruit** | スルイット | 焼き魚と発酵ドリアン（Tempoyak）サンバルを手で混ぜ合わせて野菜と食べる郷土料理 |

## まとめと旅のヒント

1. **トランス・スマトラ高速道路**: バカウヘニ港からパレンバンまで高速道路（Jalan Tol Trans-Sumatera）が開通し、車でのアクセスが飛躍的に快適になりました。
2. **クラカタウ火山へのボートツアー**: ランプン南部のチャンティ港（Pelabuhan Canti）からスピードボートをチャーターして、迫力満点のアナク・クラカタウ火山クルーズが楽しめます。
3. **島巡りパハワン**: パハワン島（Pulau Pahawang）は、透明度抜群の浅瀬でクマノミ（Nemo）と一緒に泳げるシュノーケリング天国です。
