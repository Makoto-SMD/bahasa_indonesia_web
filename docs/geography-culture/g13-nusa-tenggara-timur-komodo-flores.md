# G13：東ヌサ・トゥンガラ州（NTT）— 太古の巨竜コモド・三色火口湖クリムトゥ・伝統絣イカット

インドネシア南東部の海洋域に広がる **東ヌサ・トゥンガラ州（Provinsi Nusa Tenggara Timur / NTT）**。フローレス島、西ティモール、スンバ島、アロール諸島など500以上の島々からなり、キリスト教文化が深く根付くエキゾチックな秘境です。

地球上でここにしか生息しない「生きた恐竜」**コモドオオトカゲ（Komodo）**、色の変わる神秘の3色火口湖 **クリムトゥ山（Gunung Kelimutu）**、スンバ島の巨石墓と伝統騎馬戦 **パソラ（Pasola）**、そして熟練の女性たちが織り上げる伝統絣 **イカット（Tenun Ikat）**。NTTの圧倒的な大自然と古代の記憶を探求しましょう。

## 1. 太古の息吹：コモド国立公園とピンクビーチ

世界遺産 **Taman Nasional Komodo** は、世界最大のトカゲである **コモドオオトカゲ（Varanus komodoensis / 現地名: Ora）** が棲息する唯一のサンクチュアリです。体長3メートル、体重70キロを超え、強力な毒腺と鋭い嗅覚でシカや水牛を捕食します。

公園内には、4つの湾を一望する絶景の **パダール島（Pulau Padar）** や、赤サンゴの砕けた微小片が白砂と混ざり合って淡い桃色に輝く **ピンクビーチ（Pantai Pink）**、マンタが乱舞する世界屈指のダイビングポイントが点在します。

## 2. フローレスの精霊クリムトゥ湖とスンバ島のパソラ

NTTの内陸部には、古代の精霊信仰（アニミズム）が色濃く残っています。
- **Danau Tiga Warna Kelimutu**: フローレス島中央部にある3つの火口湖。含まれる鉱物と火山ガスの化学変化により、赤褐色、青緑色、漆黒へとそれぞれ不規則に色が変化します。地元住民は、死者の魂の善悪によって入る湖が異なると信じています。
- **Desa Adat Wae Rebo**: 標高1,200mの山奥にたたずむ孤高の村。円錐形のかやぶき巨大高床式住居「ムバル・ニャン（Mbaru Niang）」が立ち並び、ユネスコ文化遺産保全賞を受賞しました。
- **Pasola Sumba**: スンバ島で豊作を祈願して行われる伝統の騎馬槍試合。数百騎の戦士たちが馬を駆り、木槍を投げ合います。

## 3. 東ヌサ・トゥンガラ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Komodo (Ora)** | コモドオオトカゲ | 全長3mに達する世界最大のトカゲ。噛み付いた獲物に毒を回して仕留める |
| **Daging Se'i** | セイ | ティモール島発祥のスモークミート（牛肉 Se'i Sapi、豚肉 Se'i Babi）。サンバル・ルアッとともに食す |
| **Wae Rebo** | ワエレボ村 | マンガライ族の円錐形巨大家屋（Mbaru Niang）が山頂の霧の中に残る伝統集落 |
| **Tenun Ikat Sumba** | スンバ・イカット | 馬、ワニ、人間などの象徴文様を天然藍や茜で染め抜いた世界最高峰の伝統絣布 |
| **Kopi Flores Bajawa** | バジャワ・コーヒー | フローレス島火山灰土壌の高地で有機栽培される、ナッツやキャラメルの風味を持つ名品 |

## まとめと旅のヒント

1. **ボートトリップ（Live on Board）**: ラブアン・バジョ港から木造キャビンクルーザー（Pinisi）に2泊3日で宿泊しながらコモド諸島を巡るクルーズが世界中の旅人の定番です。
2. **乾季と雨季の景観変化**: 乾季（5〜10月）のコモド諸島はサバンナの黄金色に輝き、雨季（12〜3月）には鮮やかなエメラルドグリーンの丘に変貌します。
3. **敬意を持った布の購入**: イカット（手織り布）は、完成までに数ヶ月〜1年を要する芸術品です。安価な化学染料プリント品と本物の天然草木染め手織り布の違いを味わいましょう。
