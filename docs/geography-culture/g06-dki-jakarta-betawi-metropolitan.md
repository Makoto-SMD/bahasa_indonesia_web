# G06：ジャカルタ首都特別州（DKI Jakarta）— 巨大都市メガロポリス・ブタウィの魂・黄金の炎モナス

人口1,000万人を超え、都市圏（Jabodetabek）を含めると3,000万人以上のメガロポリスを形成する **ジャカルタ特別州（DKI Jakarta / 首都機能移転に伴いDKJ）**。摩天楼が林立する超近代的なビジネス街と、オランダ植民地時代の面影を残すコタ・トゥア（旧バタヴィア）が隣り合わせに息づいています。

そして、ジャカルタの真の精神的ルーツといえば、群島の多様な民族と外国人が交じり合って生まれた先住民族 **ブタウィ（Suku Betawi）** の文化です。首都ジャカルタの歴史と多層的な魅力を探訪しましょう。

## 1. 歴史の交差点：スンダ・クラパからメガロポリスへ

ジャカルタの歴史は、14世紀のスンダ王国の香辛料積出港 **スンダ・クラパ（Sunda Kelapa）** に始まります。1527年6月22日、ファタヒラー（Fatahillah）将軍がポルトガル軍を駆逐して **ジャヤカルタ（Jayakarta＝偉大なる勝利）** と改名（これが現在のジャカルタ市制記念日）。

1619年、オランダ東インド会社（VOC）のヤン・ピーテルスゾーン・クーンによって **バタヴィア（Batavia）** と名付けられ、運河が張り巡らされた城塞都市が建設されました。現在、旧市街 **コタ・トゥア（Kota Tua）** のファタヒラー広場には当時の旧市庁舎（ジャカルタ歴史博物館）やカフェ・バタヴィアが残されています。

## 2. 陽気で人情味あふれるブタウィ文化の魅力

先住民族 **Suku Betawi** は、オープンで飾らないユーモア精神（ceplas-ceplos）と、互いを家族のように助け合う人情味（gotong royong）で知られます。
- **Ondel-ondel**: 赤い顔の男性と白い顔の女性の巨大な張子の人形。太鼓や銅鑼の軽快な音楽に合わせて街を練り歩き、悪霊を払う厄除けのシンボルです。
- **Roti Buaya（ワニパン）**: 一夫一婦制を貫くワニの忠誠心にあやかり、ブタウィの結婚式で新郎から新婦へ必ず贈られる大きなパン。
- **Kerak Telor**: もち米、アヒルの卵、干しエビ（ebi）、揚げココナッツを小さな中華鍋で炭火焼きにした香ばしい伝統スナック。

## 3. ジャカルタを語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Monas (Monumen Nasional)** | モナス | 高さ132mの独立記念塔。地下には歴史ジオラマ展示、最上階に展望台がある |
| **Ondel-ondel** | オンデルオンデル | ブタウィ伝統の巨大な男女人形。竹で編んだ骨組みに人が入って踊る |
| **Kerak Telor** | クラック・テロール | アヒルの卵ともち米を炭火で香ばしく焼き上げた名物ストリートフード |
| **Bundaran HI** | ホテル・インドネシア前ロータリー | 歓迎の塔（Tugu Selamat Datang）が中央に立つジャカルタの中心広場 |
| **TransJakarta & MRT** | トランスジャカルタ / MRT | 渋滞（Macet）緩和のために整備された専用レーンBRTと地下鉄路線網 |

## まとめと旅のヒント

1. **移動の利便性**: MRTジャカルタやトランスジャカルタのバス網、グラブ・ゴジェック（配車アプリ）を使いこなせば、悪名高い渋滞（macet）を回避して快適に移動できます。
2. **北部の離島リゾート**: 北ジャカルタのアンチョール港からボートで渡る「千の島（Kepulauan Seribu）」には、青いサンゴ礁と白砂のビーチリゾートが広がっています。
3. **会話のトーン**: 若者の日常会話ではブタウィ語起源の表現（*Gue/Lu* = 俺/お前、語尾の *-kan* が *-in* になる口語文法）が日常的に使われます。
