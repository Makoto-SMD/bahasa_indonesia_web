# G25：南東スラウェシ州（Sultra）— サンゴ礁の楽園ワカトビ・世界最大のブトン城塞・ハングルの村

スラウェシ島の南東半島部と美しい島々からなる **南東スラウェシ州（Provinsi Sulawesi Tenggara / Sultra）**。

海洋学者ジャック＝イヴ・クストーが「水中の楽園」と絶賛した世界最高峰のサンゴ礁群 **ワカトビ国立公園（Taman Nasional Wakatobi）**、周囲2.7キロに及ぶ石垣でギネス世界記録に認定された世界最大の城塞 **ブトン王宮（Benteng Keraton Buton）**、そして独自の文字を持たなかった民族言語にハングル文字を採用して世界中を驚かせた **チアチア族（Suku Cia-Cia）**。知られざる歴史と豊かな海を持つ南東スラウェシを探訪しましょう。

## 1. 水中のワンダーランド：ワカトビ諸島

州の東南沖に浮かぶ **ワカトビ（Wakatobi）** の名称は、主要な4つの島 **Wa**ngi-wangi、**Ka**ledupa、**To**mia、**Bi**nongko の頭文字を組み合わせたものです。
- **Surga Terumbu Karang Dunia**: 世界に約850種あるサンゴのうち、なんと約750種（全体の約9割）がワカトビの海域に生息しています。色鮮やかなソフトコーラル、海底の洞窟、ウミガメやイルカの群れが泳ぐ世界有数のダイビング・サンクチュアリです。
- **Suku Bajau（漂海民バジャウ族）**: カレドゥパ島近郊のカンポ・サンプエラ（Kampung Sampela）などの水上集落（Kampung Terapung）に暮らすバジャウ族は、海の上に高床式の家を建て、驚異的な素潜り漁の能力で知られる「海の民」です。

## 2. 世界最大の城塞ブトンとハングルの村チアチア

ブトン島（Pulau Buton）の古都 **バウバウ（Baubau）** には、世界的にも極めて珍しい歴史と文化のモザイクが存在します。
- **Benteng Keraton Buton (Benteng Wolio)**: 16世紀末のブトン・スルタン国が築いた城塞。標高約100mの丘の上に、石灰岩の巨石を卵白を混ぜた漆喰で積み上げ、全長2,740メートル、敷地面積23.3ヘクタールに及ぶ巨大な石壁を巡らせています。2006年に **「世界で最も面積の広い城塞」としてギネス世界記録** に公式認定されました。
- **Bahasa Cia-Cia dengan Aksara Hangul**: ブトン島南部のバウバウ市近郊に暮らすチアチア族は、固有の話し言葉「チアチア語」を持ちながら独自の文字を持っていませんでした。言語の消滅を防ぎ発音を正確に表記するため、2009年に韓国のフンミンチョンウム学会と協力して **ハングル文字（Aksara Hangul）を公式採用**。学校の教科書や街の道路標識にハングルが表記され、世界的ニュースとなりました。

## 3. 南東スラウェシ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Taman Nasional Wakatobi** | ワカトビ国立公園 | 4島（Wangi-wangi, Kaledupa, Tomia, Binongko）からなる世界遺産級の海洋公園 |
| **Benteng Keraton Buton** | ブトン王宮要塞 | ギネス認定の世界最大の石造要塞（全長2.7km、敷地23.3ha） |
| **Bahasa Cia-Cia** | チアチア語 | ブトン島で話され、文字表記にハングル文字が使用される固有言語 |
| **Sinonggi** | シノンギ | トラキ族の伝統主食。熱湯で練ったサゴ椰子澱粉を箸で巻き取ってスープに浸して食べる |
| **Kasuami** | カスアミ | キャッサバの搾りかすを円錐形に蒸し上げたブトン・ワカトビの伝統主食 |

## まとめと旅のヒント

1. **ワカトビへのアクセス**: ワンギワンギ島（マタホラ空港 WNI）へマカッサルから国内線が就航しており、島間の移動はスピードボートを利用します。
2. **ケンダリの水上モスク**: ケンダリ湾の中央に浮かぶように建てられた「Masjid Al-Alam」は、夕暮れのライトアップが幻想的な名所です。
3. **天然アスファルトの島**: ブトン島は世界有数の天然アスファルト（Asbuton）の埋蔵地であり、インドネシアの道路舗装を支える重要資源拠点でもあります。
