# G10：東ジャワ州（Jawa Timur）— 英雄都市スラバヤ・ブロモの日の出・イジェンの青い炎とマジャパヒト

ジャワ島の東部を占める **東ジャワ州（Provinsi Jawa Timur）** は、産業と歴史、そして圧倒的な大自然のスペクタクルが融合する巨大な州です。

独立戦争の激戦地として知られるインドネシア第2の大都市 **スラバヤ（Surabaya / 英雄の街）**、かつて東南アジア全域に版図を広げた **マジャパヒト王国（Kerajaan Majapahit）** の故郷、月面のような砂漠に煙を上げる聖峰 **ブロモ山（Gunung Bromo）**、世界でも極めて稀な「青い炎（Blue Fire）」が揺らめく **イジェン火口（Kawah Ijen）**。東ジャワの力強い魅力とエネルギーを体感しましょう。

## 1. 英雄都市スラバヤと大帝国マジャパヒトの威風

東ジャワの人々は、飾らず率直で情熱的（Arekan）な気質を持ちます。
- **Kota Pahlawan（英雄の街スラバヤ）**: 1945年11月10日、イギリス軍の最後通告を拒否し、ブン・トモ（Bung Tomo）の熱烈なラジオ演説に鼓舞された市民や若者たちが圧倒的兵力に立ち向かい激戦を繰り広げました。この日は現在も国家の祝日 「**英雄の日（Hari Pahlawan）**」 として記念されています。
- **Kerajaan Majapahit（モジョケルト・トロウーラン遺跡）**: 13世紀末に興り、名宰相 **ガジャ・マダ（Gajah Mada）** の「パラパの誓い（Sumpah Palapa）」によって現在のインドネシア群島からマレー半島に至る広大な版図を束ねた大帝国。現在の国章「ガルーダ」や標語「Bhinneka Tunggal Ika（多様性の中の統一）」の直接のルーツです。

## 2. 驚異の火山スペクタクル：ブロモ山とイジェン火口

東ジャワは世界屈指の火山観光のメッカです。
- **Gunung Bromo**: テンゲル・カルデラ（Kaldera Tengger）と呼ばれる広大な砂の海（Lautan Pasir）の中にそびえる活火山。四輪駆動車（Jeep）と馬で火口縁まで登ることができ、ペナンジャカン山からの日の出（sunrise）は息を呑む絶景です。テンゲル族のヒンドゥー教徒は、毎年火口へ供物を投げ入れる伝統儀式 **ヤドニャ・カサダ（Yadnya Kasada）** を執り行います。
- **Kawah Ijen（イジェン火口）**: バニュワンギ県に位置する世界最大の酸性火口湖。深夜に火口の底へ降りると、高純度の硫黄ガスが自然発火して青い炎を吹き上げる幻想的な **ブルーファイア（Api Biru / Blue Fire）** を目撃できます。

- **Kawah Ijen merupakan satu dari dua tempat di dunia yang memperlihatkan fenomena alam langka berupa api biru di kegelapan malam.**<br>
  （イジェン火口は、夜の暗闇の中で青い炎という極めて稀な自然現象を目にすることができる世界にたった2箇所しかない場所の一つである。）
- **Masyarakat suku Tengger yang mendiami kawasan Bromo menganut agama Hindu dan hidup harmonis menjaga kearifan leluhur.**<br>
  （ブロモ山地域に暮らすテンゲル民族はヒンドゥー教を信奉し、先祖伝来の知恵を守りながら調和して暮らしている。）

## 3. 東ジャワ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Rawon** | ラウォン | クルアック（Kluwek）の黒い実を使って牛肉を煮込んだ真っ黒な名物スープ（世界一美味なスープに選出） |
| **Rujak Cingur** | ルジャック・チングール | 牛の鼻肉（cingur）、温野菜、フルーツ、豆腐をエビ発酵ペースト（Petis）ソースで和えた伝統料理 |
| **Karapan Sapi** | カラパン・サピ | マドゥラ島伝統の熱狂的な牛レース。騎手が2頭の牛を操り猛スピードで疾走する |
| **Jembatan Suramadu** | スラマドゥ橋 | 全長5,438mを誇るインドネシア最長の海上斜張橋（スラバヤ〜マドゥラ島間） |
| **Blue Fire (Api Biru)** | 青い炎 | イジェン火口で摂氏600度を超える高圧硫黄ガスが燃焼して放つ青色の幻想的な炎 |

## まとめと旅のヒント

1. **バニュワンギ経由バリ島ルート**: バニュワンギのクタパン港（Pelabuhan Ketapang）からフェリーでわずか30分でバリ島ギリマヌク港へ渡ることができ、ジャワ〜バリ縦断ルートとして大人気です。
2. **ブロモ山の防寒対策**: 熱帯インドネシアとはいえ、標高2,300mを超えるブロモ山の未明は気温が5度前後（時には氷点下）まで冷え込むため、ダウンジャケットや手袋が必須です。
3. **高原リゾート・バトゥ**: マラン近郊のバトゥ（Batu）はリンゴ狩りや巨大テーマパーク（Jatim Park）、冷涼な別荘地として家族連れに最適です。
