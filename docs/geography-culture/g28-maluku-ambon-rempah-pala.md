# G28：マルク州（Maluku）— 香料諸島の記憶・世界遺産バンダのナツメグ・音楽の都アンボン

大航海時代、ヨーロッパ列強（ポルトガル、スペイン、イギリス、オランダ）が富と覇権を求めて海を越えた伝説の 「**香料諸島（The Spice Islands / Kepulauan Rempah）**」 の中心地、**マルク州（Provinsi Maluku）**。

当時、金と同等の価値で取引されたナツメグ（Pala）の原産地 **バンダ諸島（Kepulauan Banda）**、美声と豊かなリズム感でユネスコ「音楽都市（City of Music）」に選定された州都 **アンボン（Ambon）**、キリスト教徒とイスラム教徒の兄弟愛を誓う伝統和平システム **ペラ・ガンドング（Pela Gandong）**、そしてサゴヤシの伝統食 **パペダ（Papeda）**。世界史を揺るがしたマルク諸島の栄光と記憶を探求しましょう。

## 1. 世界史を動かしたバンダ諸島：マンハッタン島と交換されたラン島

バンダ諸島（Banda Neiraなど）は、肉の防腐や医薬品、香水として珍重された **ナツメグ（Buah Pala）** とその種皮 **メース（Fuli）** が、かつて地球上で唯一自生していた奇跡の島です。
- **Perjanjian Breda 1667（ブレダ条約）**: イギリスとオランダがナツメグの独占をめぐって激突した第二次英蘭戦争。講和条約において、オランダは自らが占領していた北米のニューアムステルダム（**現在のニューヨーク・マンハッタン島**）をイギリスに譲渡する見返りとして、イギリス領だったバンダ諸島の小さな **ラン島（Pulau Run）** の領有権を獲得しました。歴史上、世界金融の中心マンハッタン島は、ナツメグ1粒のために交換されたのです。
- **Benteng Belgica**: バンダ・ネイラにそびえる17世紀のオランダの五角形要塞。旧1,000ルピア紙幣の裏面にも描かれ、眼前に富士山のような美しいバンダ火山（Gunung Api Banda）を望みます。

## 2. 音楽の都アンボンと和解の絆「ペラ・ガンドング」

アンボンの人々は、生まれた瞬間から歌い、ハワイアンギターやウクレレ、サックス、ゴングを奏でる天性のミュージシャンです。
- **Ambon City of Music**: 2019年、ユネスコ創造都市ネットワークの「音楽都市」にインドネシアで初めて公式認定されました。
- **Pela Gandong（兄弟和解の伝統）**: マルク社会に古くから伝わる知恵。キリスト教徒の村（Negeri Kristen）とイスラム教徒の村（Negeri Islam）が血を分けた兄弟の盟約（Pela）を結び、教会を建てる時はイスラム教徒が手伝い、モスクを改修する時はキリスト教徒が木材を運ぶという深い連帯を誇ります。かつて起きた宗教紛争の悲劇を乗り越え、真の平和を取り戻す心の支えとなりました。
- **Papeda & Ikan Kuah Kuning**: サゴヤシ（Pohon Sagu）の樹幹から採れるデンプンを熱湯で溶き、透明な餅状に練り上げた主食。細長い木の箸「ガタガタ（Gata-gata）」で巻き取り、ウコンとレモングラスの香る酸味豊かな魚の黄色いスープに浸して噛まずにつるりと飲み込みます。

## まとめと旅のヒント

1. **セラム島の秘境オラビーチ**: セラム島（Pulau Seram）北部のオラ海岸（Pantai Ora）には、水深数メートルのエメラルドグリーンの浅瀬の上に木造水上コテージが立ち並び、極上のリゾート体験ができます。
2. **ナツメグのお土産**: バンダ諸島やアンボンでは、ナツメグの果肉を砂糖漬けにした「Manisan Pala」やナツメグシロップ（Sirup Pala）が名物です。
3. **白樹油（Minyak Kayu Putih）**: ブル島（Pulau Buru）特産のカユプテ精油は、虫除けや風邪予防の万能アロマオイルとしてインドネシア中の家庭で常備されています。
