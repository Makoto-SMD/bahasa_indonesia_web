# G03：西スマトラ州（Sumatera Barat）— 母系制ミナンカバウ・水牛の角の屋根・パダン料理の故郷

スマトラ島西岸に位置する **西スマトラ州（Provinsi Sumatera Barat）** は、世界で最も洗練された食文化の一つ「パダン料理（Masakan Padang）」と、人類学的に極めて稀有な **世界最大の母系社会（Sistem Kekerabatan Matrilineal）** を誇るミナンカバウ民族（Suku Minangkabau）の故郷です。

天に向かって鋭く尖る水牛の角を模した伝統建築 **ルマ・ガダン（Rumah Gadang）**、若者が外の世界へ雄飛する伝統 **メルラントウ（Merantau）**、そして高原都市ブキティンギの雄大な渓谷。西スマトラの比類なき知恵と文化を探求しましょう。

## 1. 世界最大の母系社会（Matrilineal）と出稼ぎ（Merantau）の知恵

ミナンカバウ社会の最大の特徴は、「**財産（家屋・農地）や家系が母から娘へと継承される母系制**」 を敷いている点です。婚姻後、男性は妻の一族の家（Rumah Gadang）に迎えられます。

この母系制と表裏一体をなすのが **メルラントウ（Tradisi Merantau）** です。
- 家産を相続しない若い男性は、青雲の志を抱いて外の世界（ジャカルタや海外）へと旅立ち、商人、学者、政治家として身を立てる伝統があります。
- インドネシア独立の父の一人モハマッド・ハッタ（Mohammad Hatta）をはじめ、数多くの初代指導者・知識人を輩出しました。

## 2. 建築の美と世界一の美食：ルマ・ガダンとルンダン

西スマトラを訪れると、誰もがその特徴的な屋根の形に目を奪われます。
- **Rumah Gadang**: 屋根の両端が水牛の角のように反り返った「ゴンジョン（Gonjong）」を持ち、地震の揺れを逃す免震木造構造になっています。
- **Rendang**: ココナッツミルクと数十種類の香辛料で牛肉を長時間かけて黒褐色になるまで炒め煮詰めた料理。米CNNの「世界で最も美味しい料理（World's 50 Best Foods）」で第1位に選出された世界最高峰の肉料理です。

  （特製パダン風牛肉ルンダンは低温でじっくり調理されるため、スパイスの風味が肉の繊維の奥深くまで完璧に染み渡る。）

## 3. 西スマトラ州を語る重要キーワード・用語集

| インドネシア語 | 日本語 | 解説 |
| :--- | :--- | :--- |
| **Rumah Gadang** | ルマ・ガダン | ミナンカバウ伝統の大邸宅。柱や壁に華麗な幾何学植物彫刻が施される |
| **Gonjong** | ゴンジョン | 水牛の角を模して反り返った屋根の尖塔部分 |
| **Merantau** | メルラントウ | 故郷を離れて見聞を広め、独立自営を果たす伝統的慣習 |
| **Jam Gadang** | ジャム・ガダン | ブキティンギ中心部にある歴史的大時計塔（オランダ植民地時代に建設） |
| **Hidang (Manjunjung)** | ヒダン方式 | パダン料理店で、席に着くとテーブル一杯に全小皿を並べ、食べた分だけ精算する配膳様式 |

## まとめと旅のヒント

1. **涼風薫るブキティンギ**: 標高900メートルの高原都市ブキティンギは年間を通じて涼しく、日本軍が築いた地下防空壕「Lubang Jepang」も見学可能です。
2. **パダン料理の作法**: スプーンを使わず、右手（finger bowlの水で清める）でご飯とおかずを器用に混ぜて食べるのが現地流の最も美味しい味わい方です。
3. **哲学**: 「Adat basandi syarak, syarak basandi Kitabullah（伝統はイスラム法に依拠し、イスラム法は神の啓典に依拠する）」という言葉に象徴されるように、伝統と信仰の調和を誇りとしています。
