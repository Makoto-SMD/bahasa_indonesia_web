# 趣味・週末の過ごし方・休日の計画

同僚や友人と親しくなるための最高のきっかけが「**趣味（Hobi）**」と「**週末の過ごし方（Akhir Pekan）**」の話題です。

国民的スポーツであるバドミントン、毎週日曜の朝に目抜き通りが歩行者天国になる「カーフリーデー（Car Free Day / CFD）」、涼しいモールでのウインドウショッピングなど、インドネシアならではの休日の過ごし方があります。

本記事では、自分の趣味を語る表現から、週末の予定の尋ね方、そして相手を気軽に休日のイベントに誘うフレーズまでを網羅します。

---

## 1. 趣味を尋ねる・答える基本フレーズ

インドネシア語で「趣味」はそのまま **hobi** と言います。

<div class="id-example">
<div class="id-sentence">Apa hobi Anda? / Apa hobi kamu?</div>
<div class="id-translation">あなたの趣味は何ですか？</div>
</div>

<div class="id-example">
<div class="id-sentence">Hobi saya adalah bermain bulu tangkis dan mendengarkan musik.</div>
<div class="id-translation">私の趣味はバドミントンをすることと音楽を聴くことです。</div>
<div class="id-explanation">bermain（遊ぶ・スポーツをする）、mendengarkan（聴く）。</div>
</div>

### 「〜するのが好き」と言う（suka ...）
日常会話では「Hobi saya ...」よりも、単に **suka + 動詞**（〜するのが好き）と言う方が圧倒的に自然です。

<div class="id-example">
<div class="id-sentence">Kalau ada waktu luang, saya suka ngopi di kafe sambil baca buku.</div>
<div class="id-translation">自由時間（暇な時間）があれば、本を読みながらカフェでお茶するのが好きです。</div>
<div class="id-explanation">waktu luang（空き時間）、ngopi（コーヒーを飲む・お茶する）、sambil（〜しながら）。</div>
</div>

## 2. 定番の趣味・アクティビティ集

インドネシアで人気のアクティビティを表すボキャブラリーです。

| 分野 | インドネシア語表現 | 日本語訳 | 特徴・豆知識 |
|---|---|---|---|
| **スポーツ** | **main bulu tangkis** | バドミントンをする | インドネシアの国民的スポーツ。五輪金メダル常連。 |
| | **main futsal / sepak bola** | フットサル / サッカー | 若者男性の定番の集まり。夜間にコートを借りてプレー。 |
| | **lari pagi / jogging** | 朝のランニング | 涼しい早朝に行うのが一般的。 |
| | **bersepeda** | サイクリング・自転車 | 週末の早朝に愛好家が集まる。 |
| **エンタメ** | **nonton bioskop** | 映画館で映画を観る | モール内のシネコン（Cinema XXI）は大人気。 |
| | **main game online** | オンラインゲームをする | モバイルレジェンド（MLBB）が国民的人気。 |
| | **kulineran** | グルメ巡り・食べ歩き | 美味しいローカル飯を探訪する。 |
| **レジャー** | **jalan-jalan ke mall** | モールをぶらぶら散策する | 暑い日中は冷房の効いた巨大モールが憩いの場。 |

## 3. 週末の過ごし方（Akhir Pekan）の話題

金曜日の午後や月曜の朝によく交わされる質問です。

<div class="id-example">
<div class="id-sentence">Biasanya kalau akhir pekan kamu ngapain aja?</div>
<div class="id-translation">普段、週末は何をして過ごしているの？</div>
<div class="id-explanation">akhir pekan（週末）、ngapain aja（何をしてるの？ ※口語）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya cuma santai di rumah sambil rebahan dan nonton Netflix.</div>
<div class="id-translation">私は家でゴロゴロしながらNetflixを観てのんびりしているだけだよ。</div>
<div class="id-explanation">rebahan（ベッドやソファでゴロゴロ寝転がること ※若者頻出スラング）。</div>
</div>

### 日曜朝の風物詩：Car Free Day (CFD)
ジャカルタのスディルマン〜タムリン通りなど、インドネシアの主要都市では毎週日曜日の朝（6:00〜10:00頃）に大通りが全面車両通行止めになり、**Car Free Day（カーフリーデー / CFD）** が開催されます。

何万人もの市民が集まってジョギング、サイクリング、屋台グルメ、ストリートライブを楽しみます。

<div class="id-example">
<div class="id-sentence">Besok pagi mau ikut Car Free Day di Sudirman bareng saya gak?</div>
<div class="id-translation">明日の朝、私と一緒にスディルマンのカーフリーデーに参加しない？</div>
</div>

## 4. 休日の予定を誘う・提案する会話フレーズ

友人を食事や遊びに誘うときの定型パターンです。

### 相手の予定を確認する
- **Hari Sabtu besok kamu ada acara gak?**（今週の土曜日、何か用事はある？）
- **Malam Minggu nanti kamu sibuk?**（土曜の夜、忙しい？）
  ※「Malam Minggu（日曜の前の夜＝土曜の夜）」は若者のデートや集まりのゴールデンタイムです。

### 誘いかける・提案する
- **Mau ikut gak?**（一緒に行かない？）
- **Gimana kalau kita coba kafe baru dekat kantor?**（オフィスの近くに新しくできたカフェに行ってみない？）
- **Kita kumpul jam berapa dan di mana?**（何時にどこで集まる？）

<div class="id-example">
<div class="id-sentence">A: Hari Minggu nanti kita main bulu tangkis yuk!
B: Boleh banget! Jam berapa dan di lapangan mana?</div>
<div class="id-translation">A: 今週の日曜、バドミントンやろうよ！
B: いいね、もちろん！ 何時にどこのコートでやるの？</div>
<div class="id-explanation">lapangan（コート・競技場）。</div>
</div>

## まとめと練習問題

趣味や週末の話題を通じて、インドネシア人の生活文化や価値観をより深く知ることができます。

### 理解度チェック
次の場面で使えるインドネシア語フレーズを考えてみましょう。

1. 「私の趣味はバドミントンと映画を観ることです」と言うには？
2. 「今週の土曜日、何か予定はある？」と友人に尋ねるには？
3. 「明日の朝、一緒にカーフリーデーに行かない？」と誘うには？

<details>
<summary>解答と解説</summary>

1. **Hobi saya main bulu tangkis dan nonton film.**（または **Saya suka main bulu tangkis...**）
2. **Hari Sabtu ini kamu ada rencana gak?**（または **...ada acara gak?**）
3. **Besok pagi mau ikut Car Free Day bareng gak?**
</details>
