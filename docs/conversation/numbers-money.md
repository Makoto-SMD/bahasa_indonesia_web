# 数字・桁数・金額の数え方・両替フレーズ

インドネシアを訪れる日本人が最初に直面する大きな壁が、**「インドネシア・ルピア（IDR / Rp）の桁数の多さ」**です。

日本では1万円札が最高額紙幣ですが、インドネシアでは**10万ルピア札（約1,000円相当）**が日常的に飛び交います。ゼロが多いため、買い物やタクシー、両替で混乱しがちです。

本記事では、基本の数字（0〜99）から大きな桁数の変換術、日常会話で飛び交う短縮表現（50k、ceban等）、そして両替・レジでの必須フレーズまでを完全網羅します。

## 2. 2桁の数字（11〜99）

2桁の数字は規則的なシステムで成り立っています。

### 11〜19：接尾辞 -belas（〜代）
英語の "-teen" にあたるのが **-belas** です。
- **11**: **sebelas**（satu-belas ではなく se-belas）
- **12**: **dua belas**
- **13**: **tiga belas**
- **14**: **empat belas**
- **15**: **lima belas**
- **16**: **enam belas**
- **17**: **tujuh belas**
- **18**: **delapan belas**
- **19**: **sembilan belas**

### 20〜99：接尾辞 -puluh（〜十）
英語の "-ty" にあたるのが **-puluh** です。
- **20**: **dua puluh**
- **21**: **dua puluh satu**
- **30**: **tiga puluh**
- **45**: **empat puluh lima**
- **78**: **tujuh puluh delapan**
- **99**: **sembilan puluh sembilan**

## 3. 大きな桁数と3桁区切り（ribu, juta, miliar）

日本語は「万（4桁）」「億（8桁）」で桁が上がりますが、インドネシア語は英語と同じく**3桁（千）区切り**で単位が変わります。

```text
1.000        = seribu (1千)
10.000       = sepuluh ribu (1万)
100.000      = seratus ribu (10万)
1.000.000    = satu juta (100万)
10.000.000   = sepuluh juta (1000万)
100.000.000  = seratus juta (1億)
1.000.000.000= satu miliar (10億)
```

### 日本語の「万・億」とインドネシア語の対応早見表

| 日本の桁 | 金額（ルピア例） | インドネシア語表現 |
|---|---|---|
| **1千** | Rp 1.000 | **seribu** |
| **1万** | Rp 10.000 | **sepuluh ribu** |
| **5万** | Rp 50.000 | **lima puluh ribu** |
| **10万** | Rp 100.000 | **seratus ribu** |
| **50万** | Rp 500.000 | **lima ratus ribu** |
| **100万** | Rp 1.000.000 | **satu juta** |
| **1,000万** | Rp 10.000.000 | **sepuluh juta** |
| **1億** | Rp 100.000.000 | **seratus juta** |
| **10億** | Rp 1.000.000.000 | **satu miliar** |
| **1兆** | Rp 1.000.000.000.000 | **satu triliun** |

> [!IMPORTANT]
> **「万」は存在しない！「sepuluh ribu（10個の千）」と考える**
> 日本語の「1万円」を言うときは、頭の中で「10個の千（sepuluh ribu）」と変換する癖をつけましょう。

## 4. 表記の落とし穴：ピリオドとカンマの逆転！

インドネシアではオランダの記法を受け継いでいるため、**日本やアメリカとはピリオド（.）とカンマ（,）の使い方が逆**になります。

```text
日本・英語圏: Rp 10,000.00  (カンマが桁区切り、ピリオドが小数点)
インドネシア: Rp 10.000,00  (ピリオドが桁区切り、カンマが小数点)
```

スーパーのレシートやカフェの看板で `Rp 25.000,-` のように末尾にハイフンが書かれている場合、「端数の小銭（セン）はありません（ジャスト25,000ルピア）」という意味です。

## 5. 日常生活で飛び交う省略スラング

実際のカフェ、屋台、市場では、長い数字を省略して呼ぶのが一般的です。

### ① 「k」（キロ ＝ 千）
カフェのメニュー表などで `25k`、`50k` と書かれているのは、`25.000`（2万5千ルピア）、`50.000`（5万ルピア）のことです。

### ② 「ribu」の省略
店員さんに「Berapa?（いくら？）」と聞いて、「Lima puluh（50）」とだけ言われたら、50ルピアではなく **50.000ルピア（5万ルピア）** のことです。千（ribu）の単位は当たり前すぎて省略されます。

### ③ 中華系由来の金額スラング（ジャカルタ周辺）
ジャカルタのタクシー運転手や屋台のおじさんは、福建語（中国語方言）由来の金額スラングをよく使います。

- **goceng**（ゴチェン）：5.000ルピア（5千）
- **ceban**（チェバン）：10.000ルピア（1万）
- **goban**（ゴバン）：50.000ルピア（5万）
- **cepek**（チェペッ）：100ルピア / 100.000ルピア
- **seceng**（スチェン）：1.000ルピア（1千）

## まとめと練習問題

数字と金額は、買い物をスムーズにし、旅や生活のトラブルを防ぐ最大の武器です。

### 理解度チェック
次のインドネシア語の金額を日本円（1万ルピア＝約100円計算）または数字で答えてみましょう。

1. **dua puluh lima ribu Rupiah**
2. **seratus lima puluh ribu Rupiah**
3. **dua juta Rupiah**

<details>
<summary>解答と解説</summary>

1. **25.000ルピア**（約250円相当）
2. **150.000ルピア**（約1,500円相当）
3. **2.000.000ルピア**（約2万円相当）
</details>
