# 空港・出入国審査・フライトでのインドネシア語

ジャカルタのスカルノ・ハッタ国際空港（CGK）やバリ島のングラ・ライ国際空港（DPS）に降り立った瞬間、旅の最初の関門となるのが**「空港（Bandara）」**と**「出入国審査（Imigrasi）」**です。

自動化ゲート（Autogate）が普及しつつある現代でも、審査官に対面で滞在目的を尋ねられたり、預け入れ手荷物の超過料金、座席の希望（窓側・通路側）、ロストバゲージなどのトラブル対応など、インドネシア語で意思疎通を図る場面は多々あります。

本記事では、チェックインから入国審査、手荷物受取、機内でのリクエストまでを完全網羅します。

---

## 1. 空港（Bandara）の標識と重要ボキャブラリー

空港内の案内標識（Signboard）で頻繁に目にする公的用語です。

| 単語 | 日本語訳 | 補足 |
|---|---|---|
| **Keberangkatan** | 出発 | berangkat（出発する）から派生 |
| **Kedatangan** | 到着 | datang（来る・到着する）から派生 |
| **Penerbangan** | フライト・航空便 | terbang（飛ぶ）から派生 |
| **Internasional** | 国際線 | |
| **Domestik** | 国内線 | インドネシア国内の移動 |
| **Pemeriksaan Keamanan** | 保安検査（セキュリティチェック） | periksa（検査する）から派生 |
| **Pintu Masuk (Gate)** | 搭乗口・ゲート | pintu（ドア・門） |
| **Pengambilan Bagasi** | 手荷物受取所（バゲージクレーム） | ambil（取る）から派生 |
| **Bea Cukai** | 税関（Customs） | e-CD（電子税関申告）が必要 |

## 2. チェックインカウンターでの手続きと座席リクエスト

空港に着いたら、まずは航空会社のカウンターでチェックインを行います。

<div class="id-example">
<div class="id-sentence">Selamat siang, saya mau check-in untuk penerbangan ke Tokyo jam dua siang.</div>
<div class="id-translation">こんにちは、午後2時発の東京行きフライトのチェックインをお願いします。</div>
</div>

<div class="id-example">
<div class="id-sentence">Ini paspor dan tiket elektronik saya.</div>
<div class="id-translation">これが私のパスポートとEチケットです。</div>
</div>

### 座席のリクエスト（窓側 vs 通路側）
座席の希望がある場合は、発券前にカウンター係員に伝えましょう。

- **dekat jendela**: 窓側（jendela ＝ 窓）
- **dekat lorong**: 通路側（lorong ＝ 通路）

<div class="id-example">
<div class="id-sentence">Boleh minta tempat duduk di dekat jendela, tolong?</div>
<div class="id-translation">窓側の座席をお願いできますか？</div>
<div class="id-explanation">tempat duduk（座席）。</div>
</div>

### 手荷物の預け入れと超過料金
```text
係員: Ada bagasi yang mau dimasukkan? (預け入れ手荷物はありますか？)
客  : Ada satu koper, tolong. (スーツケースが1つあります、お願いします。)
```

重量オーバーの場合：
<div class="id-example">
<div class="id-sentence">Maaf Pak, bagasi Anda kelebihan tiga kilo. Harus bayar biaya kelebihan bagasi.</div>
<div class="id-translation">申し訳ありませんお客様、荷物が3キロ超過しています。超過手荷物料金をお支払いいただく必要があります。</div>
<div class="id-explanation">kelebihan（超過・過度）。</div>
</div>

## 3. 【最重要】出入国審査（Imigrasi）での定番問答

イミグレーションの審査ブースでは、審査官から滞在目的や期間について英語またはインドネシア語で質問されます。ハキハキと笑顔で簡潔に答えるのがコツです。

### 質問①：訪問目的は何ですか？
```text
審査官: Apa tujuan kunjungan Anda ke Indonesia?
客    : Untuk wisata / liburan. (観光・休暇です。)
客    : Untuk urusan bisnis. (ビジネス用件です。)
```

### 質問②：どのくらい滞在しますか？
```text
審査官: Berapa lama Anda akan tinggal di Indonesia?
客    : Selama satu minggu saja. (1週間だけです。)
客    : Sekitar sepuluh hari. (約10日間です。)
```

### 質問③：どこに宿泊しますか？
```text
審査官: Di mana Anda akan menginap?
客    : Saya menginap di Hotel Grand Hyatt Jakarta. (グランドハイアット東京に泊まります。)
客    : Di villa daerah Seminyak, Bali. (バリ島スミニャックのヴィラです。)
```

### 質問④：帰りの航空券（出国便）を見せてください
```text
審査官: Boleh lihat tiket pulang Anda?
客    : Ini tiket pulangnya, Pak. Tanggal 25 Oktober naik Garuda.
        (これが帰りのチケットです。10月25日発のガルーダ航空です。)
```

> [!NOTE]
> **到着ビザ（VOA）と電子税関（e-CD）**
> 現在のインドネシア入国では、オンライン事前申請の **e-VOA（観光ビザ）** と **e-CD（電子税関申告）** のQRコードを事前にスマホに保存しておくことで、入国審査が極めてスムーズになります。

## 4. バゲージクレームとトラブル対応（ロストバゲージ）

預けたスーツケースを受け取る際、ターンテーブルが見つからない場合や、荷物が出てこない時のフレーズです。

<div class="id-example">
<div class="id-sentence">Pengambilan bagasi untuk penerbangan GA875 di sebelah mana ya?</div>
<div class="id-translation">GA875便の手荷物受取（ターンテーブル）はどのあたりですか？</div>
</div>

### 荷物が出てこない・破損していたとき
ターンテーブル横の「Lost & Found」窓口で係員に申し出ます。

<div class="id-example">
<div class="id-sentence">Koper saya belum keluar sampai sekarang, boleh tolong dicek?</div>
<div class="id-translation">私のスーツケースが今までまだ出てきません。確認していただけますか？</div>
<div class="id-explanation">dicek（チェックされる・調べられる）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Ini bukti tanda terima bagasi saya. Koper saya berwarna biru tua.</div>
<div class="id-translation">これが私の手荷物預け入れ控え（バゲージタグ）です。私のスーツケースは濃い青色です。</div>
<div class="id-explanation">tanda terima（受領証・引換証）。</div>
</div>

## 5. フライト機内（Dalam Pesawat）でのCAとの会話

機内で客室乗務員（Pramugari / Pramugara）に飲み物や毛布をお願いする表現です。

<div class="id-example">
<div class="id-sentence">Mbak, boleh minta segelas air putih hangat?</div>
<div class="id-translation">お姉さん、温かいお水を一杯いただけますか？</div>
</div>

<div class="id-example">
<div class="id-sentence">Boleh minta selimut? Di dalam kabin agak dingin.</div>
<div class="id-translation">毛布をいただけますか？ 機内が少し寒いです。</div>
<div class="id-explanation">selimut（毛布・ブランケット）。</div>
</div>

## まとめと練習問題

空港や出入国審査での会話は、「目的」「期間」「宿泊先」の3点セットを落ち着いて答えられれば百点満点です。

### 理解度チェック
次の質問に対する適切なインドネシア語の返答を作ってみましょう。

1. 審査官から「Apa tujuan kunjungan Anda?」と聞かれて「観光です」と答えるには？
2. 「Berapa lama Anda tinggal di sini?」と聞かれて「10日間です」と答えるには？
3. チェックインカウンターで「窓側の席をお願いできますか？」と頼むには？

<details>
<summary>解答と解説</summary>

1. **Untuk liburan.**（または **Untuk wisata.**）
2. **Selama sepuluh hari.**
3. **Boleh minta tempat duduk di dekat jendela?**
</details>
