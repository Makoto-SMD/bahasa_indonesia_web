# 緊急事態（事故・盗難・紛失・警察）のサバイバルフレーズ

万が一のトラブルに巻き込まれたとき、慌てず周囲に助けを求め、警察（Polisi）や病院で的確に対処するための**緊急サバイバルフレーズ**です。

スリやひったくり、パスポートやスマートフォンの紛失、交通事故、火災など、非常事態では短い単語を大きな声で叫ぶことや、警察署で公式の**「紛失届証明書（Surat Laporan Kehilangan）」**を取得する手続きが極めて重要になります。

---

## 1. 大声で助けを呼ぶ叫び声（呼救フレーズ）

危険を感じたときや事件・事故を目撃したときは、迷わず大きな声で周囲の人々に叫びましょう。

| 叫び声 | カタカナ読みの目安 | 意味・使う状況 |
|---|---|---|
| **Tolong!** | トロン！ | 助けて！ 手を貸して！（最も基本） |
| **Ada copet!** | アダ チョペッ！ | スリだ！ 財布をすられた！ |
| **Ada maling!** | アダマリン！ | 泥棒だ！ 空き巣だ！ |
| **Ada jambret!** | アダ ジャンブレッ！ | ひったくりだ！（バイクからの強盗） |
| **Kebakaran!** | クバカラン！ | 火事だ！ |
| **Awas! / Hati-hati!** | アワス！ / ハティハティ！ | 危ない！ 気をつけて！ |

<div class="id-example">
<div class="id-sentence">Tolong panggilkan polisi sekarang juga!</div>
<div class="id-translation">今すぐ警察を呼んでください！</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong panggilkan ambulans, ada orang terluka parah!</div>
<div class="id-translation">救急車を呼んでください、重傷を負った人がいます！</div>
<div class="id-explanation">terluka parah（重傷を負った）。</div>
</div>

## 2. 【保存版】インドネシアの主要緊急電話番号

スマートフォンから通報できる全国共通の緊急通報ダイヤルです。

- **110**: 警察（Polisi）
- **118 / 119**: 救急車（Ambulans）
- **113**: 消防署（Pemadam Kebakaran）
- **112**: 統合型緊急通報ダイヤル（警察・消防・救急の総合窓口）
- **115**: 国家捜索救助庁（BASARNAS / 遭難救助）

> [!IMPORTANT]
> **ジャカルタ日本国大使館の連絡先**
> パスポートの紛失・盗難時には、在インドネシア日本国大使館（Kedutaan Besar Jepang di Indonesia）へ直ちに連絡する必要があります。
> - 電話番号: +62-21-3192-4301（領事部代表）

## 3. 盗難・紛失の被害届（警察署での手続き）

パスポートやクレジットカード、高額な電子機器を紛失・盗難された場合、**警察署（Kantor Polisi / Polsek）で「紛失届証明書」**を作成してもらわなければ、大使館でのパスポート再発行や海外旅行保険の請求ができません。

### 紛失・盗難を説明するフレーズ
- **kehilangan**: 紛失した・なくした
- **dicopet**: スリに遭った
- **dijambret**: ひったくられた
- **kemalingan**: 泥棒に入られた

<div class="id-example">
<div class="id-sentence">Selamat siang Pak Polisi, saya kehilangan paspor dan dompet saya di daerah pasar.</div>
<div class="id-translation">こんにちは警察官さん、私は市場のあたりでパスポートと財布をなくしてしまいました。</div>
</div>

### 証明書の発行依頼（最重要！）
<div class="id-example">
<div class="id-sentence">Saya perlu Surat Tanda Penerimaan Laporan Kehilangan untuk klaim asuransi dan lapor ke Kedutaan Besar Jepang.</div>
<div class="id-translation">保険の請求と日本大使館への届出のために、「紛失届受領証明書」が必要です。</div>
<div class="id-explanation">Surat Tanda Penerimaan Laporan Kehilangan（紛失届証明書）。</div>
</div>

## 4. 交通事故（Kecelakaan Lalu Lintas）の現場対応

バイクの交通量が極めて多いインドネシアでは、交通事故のリスクが常に存在します。

- **kecelakaan**: 事故
- **menabrak**: 衝突する・はねる
- **ditabrak**: はねられる・追突される
- **berdarah**: 出血している

<div class="id-example">
<div class="id-sentence">Terjadi kecelakaan antara sepeda motor dan mobil di perempatan depan.</div>
<div class="id-translation">前の交差点でバイクと車の交通事故が発生しました。</div>
</div>

<div class="id-example">
<div class="id-sentence">Jangan gerakkan korban, tunggu ambulans dan paramedis datang!</div>
<div class="id-translation">被害者（負傷者）を動かさないでください、救急車と救急隊員が来るのを待ちましょう！</div>
<div class="id-explanation">korban（被害者・負傷者）。</div>
</div>
