# 銀行・ATM・送金・電子決済（QRIS）の手続き会話

インドネシアで生活や長期滞在を始めると、銀行口座の開設、ATMでの現金引き出し、送金（振込）、そしてあらゆる店舗で導入されている電子決済「**QRIS（クリス）**」の利用が日常の一部になります。

特に、ATM機にカードが吸い込まれて出てこなくなる「カード吸い込み（Kartu tertelan）」トラブルや、モバイルバンキングでの送金手続きなど、お金に関わる正確なインドネシア語表現は知っておく必要があります。

本記事では、ATM操作の基本用語から銀行窓口での手続き、トラブル対応、QRISのスマートな使い方までを完全網羅します。

---

## 1. 主要銀行とATM画面の基本操作用語

インドネシアの金融を牽引する4大メガバンクです。

- **BCA (Bank Central Asia)**: 民間最大手。アプリの使いやすさとATM網の充実度で圧倒的人気。
- **Bank Mandiri**: 資産規模最大の国営銀行。
- **BNI (Bank Negara Indonesia)**: 国営銀行。
- **BRI (Bank Rakyat Indonesia)**: 地方や農村部まで強大なネットワークを持つ国営銀行。

### ATM画面に表示される重要単語
ATM機（Mesin ATM）の前に立ったら、画面に表示される用語を選択して操作します。

| 画面表示用語 | 日本語訳 | 機能・説明 |
|---|---|---|
| **Tarik Tunai** | 現金引き出し（出金） | tarik（引く） + tunai（現金） |
| **Setor Tunai (CDM)** | 現金預け入れ（入金） | 入金対応のATM（Setor Tarik）でのみ可能 |
| **Transfer** | 振込・送金 | 他口座または他行への送金 |
| **Informasi Saldo** | 残高照会 | 口座残高の確認 |
| **Ubah PIN** | 暗証番号変更 | PIN（暗証番号 6桁）の変更 |
| **Pecahan Rp 100.000** | 10万ルピア札出金 | 出てくる紙幣の券種（Pecahan）指定 |
| **Pecahan Rp 50.000** | 5万ルピア札出金 | 5万ルピア札で出金したい場合 |

<div class="id-example">
<div class="id-sentence">Silakan masukkan PIN ATM Anda dan jangan sampai terlihat orang lain.</div>
<div class="id-translation">ATMの暗証番号を入力してください。周囲の人に見られないようご注意ください。</div>
</div>

## 2. 銀行窓口（Teller / CS）での手続き

口座開設や高額な送金手続きを行う際は、カスタマーサービス（Customer Service / CS）または窓口係（Teller）と対面でやり取りします。

### 口座開設（Buka Rekening）
<div class="id-example">
<div class="id-sentence">Selamat pagi, saya ingin membuka rekening tabungan baru di bank ini.</div>
<div class="id-translation">おはようございます、この銀行で新しい普通預金口座を開設したいです。</div>
<div class="id-explanation">buka rekening（口座開設）、rekening tabungan（普通預金口座）。</div>
</div>

**外国人の口座開設に必要な主な書類**:
- **Paspor**: パスポート原本
- **KITAS / ITAS**: 滞在許可証
- **NPWP**: インドネシアの納税者番号（Tax ID）
- **Surat Keterangan Domisili**: 居住証明書

### 窓口での送金（Transfer Uang）
<div class="id-example">
<div class="id-sentence">Saya mau transfer uang sebesar lima juta Rupiah ke rekening BCA ini.</div>
<div class="id-translation">このBCAの口座へ、500万ルピアの送金をしたいです。</div>
</div>

- **nomor rekening tujuan**: 振込先口座番号
- **nama pemilik rekening**: 口座名義人氏名
- **biaya administrasi**: 振込手数料（他行宛てなど）
- **bukti transfer**: 振込明細書・受領証

## 3. 【トラブル対応】ATMにカードが吸い込まれたとき！

インドネシアのATMで稀に発生するのが、機械の不具合や一定時間カードを抜き取らなかったことで生じる「**カード吸い込み（Kartu ATM tertelan）**」です。

焦らずに、ATM機に記載されている公式コールセンター番号へ直ちに電話してカードを停止させます。

<div class="id-example">
<div class="id-sentence">Halo HaloBCA, tolong bantuannya. Kartu ATM saya tertelan di mesin ATM dekat Grand Indonesia.</div>
<div class="id-translation">もしもしHaloBCA（コールセンター）ですか、助けてください。グランドインドネシア近くのATM機に私のカードが吸い込まれてしまいました。</div>
<div class="id-explanation">tertelan（誤って飲み込まれる・吸い込まれる）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong segera blokir kartu ATM saya agar tidak disalahgunakan.</div>
<div class="id-translation">不正利用されないように、私のATMカードを今すぐ利用停止（ブロック）してください。</div>
<div class="id-explanation">diblokir（利用停止される）、disalahgunakan（悪用される）。</div>
</div>

### 暗証番号を間違えてロックされたとき
<div class="id-example">
<div class="id-sentence">Kartu saya terblokir karena saya salah memasukkan PIN tiga kali berturut-turut.</div>
<div class="id-translation">暗証番号を3回連続で間違えて入力してしまったため、カードがロックされました。</div>
<div class="id-explanation">berturut-turut（連続して）。</div>
</div>

## 4. 国家統一QR決済「QRIS（クリス）」の完全理解

現在、インドネシアのキャッシュレス決済は「**QRIS（Quick Response Code Indonesian Standard）**」の独壇場です。屋台から高級デパートまで、どこでも1枚の共通QRコードが掲示されています。

### なぜ便利なのか？
利用者が **GoPay**、**OVO**、**ShopeePay**、**Dana**、あるいは **BCA Mobile** や **Livin' by Mandiri** のどれを使っていても、お店にあるたった1つのQRISコードをスキャンするだけで即座に決済が完了します。

### 店舗での注文・決済フレーズ
<div class="id-example">
<div class="id-sentence">Mas, apakah bisa bayar pakai QRIS?</div>
<div class="id-translation">お兄さん、QRISで支払えますか？</div>
</div>

```text
店員: Bisa, Kak. Silakan scan barcode QRIS yang di meja kasir ya.
      (できますよ。レジのテーブルにあるQRISバーコードをスキャンしてください。)
客  : Totalnya 65 ribu ya? (合計65,000ルピアですね？)
店員: Iya betul.
客  : Sudah berhasil masuk, ini bukti transaksinya ya.
      (決済成功しました、これが完了画面［明細］です。)
店員: Baik, sudah masuk. Terima kasih!
```

> [!TIP]
> **支払いが完了したら画面を見せるのがマナー**
> スマホでQRコードを読み取り、金額を入力して暗証番号を押すと、画面に緑色のチェックマークと「Berhasil（成功）」が表示されます。この画面を店員に見せて「Sudah ya（完了しました）」と伝えるのが現地のルールです。
