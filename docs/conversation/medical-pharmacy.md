# 体調不良・病院・薬局での症状説明

慣れない気候や環境の変化、食あたりや冷房の効きすぎなど、滞在中に体調を崩してしまうことは誰にでもあります。

特に熱帯のインドネシアでは、激しい下痢（いわゆる「バリ腹」）や発熱、デング熱などのリスクがあり、自分の症状を的確に医師や薬剤師に伝えるスキルは**安全な滞在のための最重要サバイバル知識**です。

本記事では、痛みの部位の伝え方から、薬局（Apotek）での薬の買い方・飲み方の確認、病院（Rumah Sakit）での海外旅行保険手続きまでを分かりやすく整理します。

---

## 1. 体調不良・痛みの基本構文（sakit ...）

「痛い」「病気だ」を表す万能な単語が **sakit**（サキッ）です。「**sakit ＋ 体の部位**」で、どこが痛むのかを即座に説明できます。

<div class="id-example">
<div class="id-sentence">Saya merasa kurang sehat / tidak enak badan.</div>
<div class="id-translation">体調が優れません / 体がだるいです。</div>
</div>

### 身体の部位と痛みの表現
| 部位 | インドネシア語表現 | 日本語訳 |
|---|---|---|
| **頭** | **sakit kepala / pusing** | 頭痛 / めまい・クラクラする |
| **お腹** | **sakit perut** | 腹痛・お腹が痛い |
| **胃** | **sakit maag** | 胃痛・胃酸過多・胃もたれ |
| **喉** | **sakit tenggorokan** | 喉の痛み・喉が痛い |
| **歯** | **sakit gigi** | 歯痛・歯が痛い |
| **目** | **sakit mata** | 目の痛み・充血・眼病 |
| **腰・背中** | **sakit pinggang / punggung** | 腰痛 / 背中の痛み |

## 2. 熱帯で遭遇しやすい主な症状と病気

旅行者や滞在者がかかりやすい病気と、その具体的な症状を表す言葉です。

### 消化器系のトラブル（下痢・吐き気）
インドネシア旅行で最も多いのが、水や油、香辛料による胃腸炎（通称：Bali Belly）です。

- **diare**: 下痢
- **mencret / buang air besar terus**: 激しい水下痢・頻繁な排便
- **mual**: 吐き気・気持ち悪い
- **muntah**: 嘔吐する・吐く

<div class="id-example">
<div class="id-sentence">Perut saya melilit dan mual, sudah diare dari kemarin malam.</div>
<div class="id-translation">お腹がキリキリ痛んで吐き気がし、昨夜からずっと下痢が続いています。</div>
<div class="id-explanation">melilit（お腹がよじれるように痛む）。</div>
</div>

### 風邪・発熱・感染症
- **demam / badan panas**: 発熱・熱がある（demam tinggi = 高熱）
- **menggigil**: 悪寒がする・寒気で震える
- **batuk kering / berdahak**: 空咳 / 痰（たん）のからむ咳
- **pilek / hidung tersumbat**: 鼻水 / 鼻づまり
- **Demam Berdarah Dengue (DBD)**: デング熱（蚊が媒介する高熱病）

## 3. 【インドネシア特有の健康概念】Masuk Angin とは？

インドネシアで体調が悪いと話すと、現地の人から100%の確率で「**Pasti masuk angin ya!（きっと風が入ったんだね！）**」と言われます。

```text
【Masuk Angin（風邪気味・冷え・胃腸の張り）】
「体に悪い風が入った」とされるインドネシア特有の民間概念。
冷房に当たりすぎたり、疲労や寝不足、バイクの夜風に当たったことで生じる「だるさ・頭痛・お腹の張り・微熱・吐き気」を指します。
```

### 国民的生薬「Tolak Angin」と伝統療法「Kerokan」
- **Tolak Angin（トラッ・アンギン）**:
  ミントやショウガ、ハチミツが配合された黄色い小袋の液体ハーブ薬（Jamu）。コンビニや薬局で買え、インドネシア人は少しでも体調がおかしいとこれを飲みます。
- **Kerokan（クロカン）**:
  背中にオイルやバームを塗り、コインの角で首から背中にかけて赤い筋ができるまでこすり、「体から風を追い出す」伝統民間療法。

## 4. 薬局（Apotek）での薬の購入と服用方法

街中にある薬局チェーン（**Kimia Farma**, **Century**, **Guardian**, **Watsons**）では、薬剤師に症状を伝えて適切な市販薬を購入できます。

<div class="id-example">
<div class="id-sentence">Permisi, apakah ada obat untuk sakit diare?</div>
<div class="id-translation">すみません、下痢止めの薬はありますか？</div>
<div class="id-explanation">obat（薬）。</div>
</div>

### よく使う薬の種類
- **obat diare**: 下痢止め薬（炭製剤の Norit や Imodium 等）
- **obat penurun panas / parasetamol**: 解熱鎮痛剤（パラセタモール）
- **obat flu dan batuk**: 風邪薬・咳止め
- **obat maag**: 胃薬（Antasida 等）

### 服用方法（用法・用量）の確認
<div class="id-example">
<div class="id-sentence">Obat ini diminum berapa kali sehari?</div>
<div class="id-translation">この薬は1日何回服用しますか？</div>
<div class="id-explanation">diminum（飲まれる・服用される）。</div>
</div>

| 服用指示 | 日本語訳 |
|---|---|
| **Sehari tiga kali** | 1日3回 |
| **Sehari dua kali** | 1日2回 |
| **Satu tablet sekali minum** | 1回につき1錠 |
| **Sesudah makan / setelah makan** | 食後に |
| **Sebelum makan** | 食前に |
| **Sebelum tidur** | 就寝前に |

## 5. 病院（Rumah Sakit）での受診と保険手続き

症状が重い場合や高熱が続く場合は、総合病院（Rumah Sakit / RS）を受診します。夜間や緊急時は救急外来（UGD / IGD）へ向かいましょう。

- **Rumah Sakit (RS)**: 病院
- **UGD (Unit Gawat Darurat) / IGD**: 救急治療室・救急外来
- **Dokter**: 医師
- **Perawat**: 看護師

### 海外旅行保険の請求に必要な書類
日本の海外旅行傷害保険を適用する場合、病院で書類を発行してもらう必要があります。

<div class="id-example">
<div class="id-sentence">Saya punya asuransi perjalanan internasional. Tolong buatkan surat keterangan dokter dan kuitansi pembayaran.</div>
<div class="id-translation">私は海外旅行保険を持っています。医師の診断書と支払い領収書を作成してください。</div>
<div class="id-explanation">surat keterangan dokter（診断書）、kuitansi（領収書）。</div>
</div>

## まとめと練習問題

健康を守るための言葉は、知っておくだけでいざという時の安心感が全く違います。

### 理解度チェック
次の症状をインドネシア語で医師や薬剤師に伝えてみましょう。

1. 「頭が痛くて熱があります。」
2. 「昨夜から下痢が続いています。」
3. 薬の飲み方を聞くとき、「1日何回、いつ飲みますか？」と尋ねるには？

<details>
<summary>解答と解説</summary>

1. **Saya sakit kepala dan demam.**（または **...badan saya panas.**）
2. **Saya diare sejak semalam.**（または **...sejak kemarin malam.**）
3. **Diminum berapa kali sehari dan kapan?**（食前・食後の確認は **Sebelum atau sesudah makan?**）
</details>
