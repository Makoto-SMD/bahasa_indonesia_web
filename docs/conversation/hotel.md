# ホテル・ヴィラでのチェックイン・要望・トラブル対応

バリ島やロンボク島のリゾートヴィラから、ジャカルタやスラバヤのモダンなビジネスホテルまで、快適な滞在を送るために**ホテルでのコミュニケーション**は欠かせません。

チェックインの手続きだけでなく、「エアコンが効かない」「お湯が出ない」といった東南アジア特有の部屋トラブルへの対処法、さらにはチェックアウト後の荷物預かりまで、滞在中のあらゆるシーンをカバーする実践フレーズをまとめました。

---

## 1. フロント（Resepsionis）でのチェックイン手続き

ホテルに到着したら、フロントカウンター（Front Desk / Meja Resepsionis）へ向かいます。

<div class="id-example">
<div class="id-sentence">Selamat siang, saya mau check-in. Saya sudah pesan kamar lewat Agoda atas nama Kenji Tanaka.</div>
<div class="id-translation">こんにちは、チェックインをお願いします。Agoda経由でケンジ・タナカの名前で部屋を予約しています。</div>
<div class="id-explanation">atas nama ...（〜の名前で）。</div>
</div>

### デポジット（保証金）とパスポート提示
チェックイン時には、身分証のコピーとデポジット（Uang Jaminan）を求められます。

```text
係員: Boleh pinjam paspor Anda untuk difotokopi?
      (コピーをとるためにパスポートをお借りできますか？)
客  : Ini paspor saya.
      (これが私のパスポートです。)
係員: Untuk depositnya sebesar Rp 500.000, bisa bayar tunai atau pakai kartu kredit.
      (デポジットは50万ルピアです。現金またはクレジットカードで承ります。)
```

### 朝食とWi-Fiの確認
<div class="id-example">
<div class="id-sentence">Sarapan pagi dimulai jam berapa dan di restoran sebelah mana?</div>
<div class="id-translation">朝食は何時から始まりますか？また、どのあたりのレストランですか？</div>
<div class="id-explanation">sarapan pagi（朝食）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Boleh tahu nama dan password Wi-Fi di kamar?</div>
<div class="id-translation">お部屋のWi-Fiの名前とパスワードを教えていただけますか？</div>
</div>

## 2. 部屋のタイプ・アメニティのリクエスト

チェックイン時、または部屋に入った後にアメニティや部屋の変更を希望する場合のフレーズです。

### 部屋の環境指定
- **kamar bebas rokok**: 禁煙ルーム（non-smoking room）
- **kamar merokok**: 喫煙可能ルーム
- **tempat tidur ukuran king / twin**: キングサイズベッド / ツインベッド
- **kamar di lantai atas**: 高層階の部屋（lantai = 階）
- **pemandangan laut / kota**: オーシャンビュー / シティビュー（pemandangan = 眺望・景色）

<div class="id-example">
<div class="id-sentence">Bisa tolong berikan kamar bebas rokok di lantai atas?</div>
<div class="id-translation">高層階の禁煙のお部屋にしていただけますか？</div>
</div>

### アメニティの追加リクエスト（Housekeepingへの電話）
部屋の内線電話（Telepon Kamar）でフロントや客室係（Housekeeping）に連絡します。

- **handuk tambahan**: 追加のバスタオル
- **sikat gigi dan pasta gigi**: 歯ブラシと歯磨き粉
- **air mineral botol**: ボトルのミネラルウォーター
- **colokan listrik / adaptor**: コンセント・変換プラグ

<div class="id-example">
<div class="id-sentence">Halo, tolong kirimkan dua handuk tambahan ke kamar 502 ya.</div>
<div class="id-translation">もしもし、502号室に追加のタオルを2枚届けていただけますか。</div>
<div class="id-explanation">kirimkan（送る・届ける）。</div>
</div>

## 3. 【トラブル対応】部屋の設備故障を伝える

海外滞在で最もストレスになりやすいのが設備のトラブルです。落ち着いて具体的に症状を伝えましょう。

| 故障・トラブルの症状 | インドネシア語表現 | 直訳・ニュアンス |
|---|---|---|
| **エアコンが効かない / 冷えない** | **AC di kamar tidak dingin / rusak.** | rusak = 壊れている |
| **お湯が出ない** | **Air panasnya tidak keluar.** | keluar = 出る |
| **水圧が弱い** | **Tekanan air di shower sangat kecil.** | tekanan air = 水圧 |
| **トイレが詰まった** | **Toiletnya mampet / tersumbat.** | mampet = 詰まった |
| **蛇口から水漏れしている** | **Kran airnya bocor.** | bocor = 漏れている |
| **カードキーが反応しない** | **Kunci kartu kamar tidak bisa dipakai.** | tidak bisa dipakai = 使えない |

<div class="id-example">
<div class="id-sentence">Halo resepsionis, AC di kamar saya mengeluarkan bunyi berisik dan tidak dingin sama sekali. Bisa tolong kirim teknisi untuk memperbaikinya?</div>
<div class="id-translation">もしもしフロントですか、部屋のエアコンが騒音を出していて全く冷えません。修理のために技術スタッフを派遣してもらえますか？</div>
<div class="id-explanation">teknisi（技術者・修理スタッフ）、memperbaiki（修理する）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Kalau tidak bisa diperbaiki, bolehkah saya pindah ke kamar lain?</div>
<div class="id-translation">もし修理できない場合、別の部屋に移動（ルームチェンジ）させていただけますか？</div>
<div class="id-explanation">pindah kamar（部屋を変える）。</div>
</div>

## 4. チェックアウト（Check-out）と荷物の一時預かり

チェックアウト当日の手続きと、フライトまでの観光時に役立つ荷物預かりのフレーズです。

### レイトチェックアウトの相談
<div class="id-example">
<div class="id-sentence">Apakah bisa minta late check-out sampai jam 2 siang? Apakah ada biaya tambahan?</div>
<div class="id-translation">午後2時までレイトチェックアウトをお願いできますか？ 追加料金はかかりますか？</div>
<div class="id-explanation">biaya tambahan（追加料金）。</div>
</div>

### チェックアウト手続き
<div class="id-example">
<div class="id-sentence">Saya mau check-out sekarang dari kamar 308. Ini kunci kartunya.</div>
<div class="id-translation">308号室から今チェックアウトします。これがカードキーです。</div>
</div>

### 荷物預かり（Penitipan Bagasi）
チェックアウト後もホテルにスーツケースを預けて身軽に観光できます。

<div class="id-example">
<div class="id-sentence">Bolehkah saya menitipkan koper di sini sampai jam lima sore?</div>
<div class="id-translation">夕方の5時まで、ここにスーツケースを預けておいてもよろしいですか？</div>
<div class="id-explanation">menitipkan（預ける）、koper（スーツケース）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Ini nomor tanda terima penitipan barangnya, tolong disimpan baik-baik ya.</div>
<div class="id-translation">こちらが手荷物預かり証の番号札です。大切に保管してくださいね。</div>
</div>

## まとめと練習問題

ホテルでの滞在会話は、礼儀正しく落ち着いて要件を伝えることが鍵です。

### 理解度チェック
次の場面でフロント係に伝えるべきインドネシア語フレーズを考えてみましょう。

1. 「タナカの名前で部屋を予約しています」と伝えるには？
2. 部屋からフロントに電話して「お湯が出ません」と伝えるには？
3. チェックアウト後に「夕方までスーツケースを預かってもらえますか？」と頼むには？

<details>
<summary>解答と解説</summary>

1. **Saya sudah pesan kamar atas nama Tanaka.**
2. **Air panas di kamar saya tidak keluar.**
3. **Bolehkah saya menitipkan koper di sini sampai sore?**
</details>
