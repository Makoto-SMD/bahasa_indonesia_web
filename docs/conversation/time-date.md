# 時間・曜日・日付・スケジュールの表現

待ち合わせ、電車の予約、仕事のアポイントメントなど、日常やビジネスで正確なコミュニケーションをとるために**「時間・曜日・日付」**の表現は不可欠です。

特にインドネシア語の時刻表現には、オランダ語の影響を受けた**「jam setengah ...（〜時半）」という日本人が必ず引っかかる罠**があります。

本記事では、時刻の言い方から曜日、月、過去・未来の相対的な表現、待ち合わせの交渉フレーズまでを分かりやすく整理します。

---

## 1. 時刻の言い方（Jam vs Pukul）

インドネシア語で時刻を表す単語には **jam** と **pukul** の2つがあります。

- **jam**: 日常会話全般で最も広く使われる。「〜時」「時計」「〜時間」のすべてを兼ねる。
- **pukul**: ニュース、案内放送、招待状、航空券などで使われる公式な表現。「打つ・打鐘」が原義。

```text
会話: Sekarang jam berapa? (今何時ですか？)
公式: Acara dimulai pukul 09.00 WIB. (イベントは西インドネシア時間9時ちょうどに始まります。)
```

### 基本の時刻のバリエーション

| 時刻 | インドネシア語表現 | 直訳・仕組み |
|---|---|---|
| **7:00** | **Jam tujuh tepat** | 7時ちょうど（tepat = 正確に） |
| **7:10** | **Jam tujuh lewat sepuluh** | 7時10分過ぎ（lewat / lebih = 過ぎる） |
| **7:15** | **Jam tujuh lewat seperempat** | 7時15分（seperempat = 4分の1） |
| **7:30** | **Jam setengah delapan** | 8時の半分前（※超重要！） |
| **7:45** | **Jam delapan kurang seperempat** | 8時15分前（kurang = 足りない・前） |
| **7:50** | **Jam delapan kurang sepuluh** | 8時10分前 |

---

## 2. 【超重要】「jam setengah ...（〜時半）」の罠

日本人が最も間違えやすいのが「〜時半」の言い方です。

日本語では「7時 ＋ 半」と考えますが、インドネシア語では**「次の時間の30分前（半分手前）」**という発想をします。

```text
× Jam setengah tujuh  →  6時半 (7時の半分手前)
○ Jam setengah delapan →  7時半 (8時の半分手前)
○ Jam setengah satu    → 12時半 (1時の半分手前)
```

> [!CAUTION]
> **待ち合わせの1時間ズレに注意！**
> 友人に「Jam setengah sembilan（9時の半分前＝8時半）」と言われて、9時半と勘違いして大遅刻する日本人が後を絶ちません。「setengah の後ろの数字からマイナス1時間引いた半」と脳内変換しましょう。

<div class="id-example">
<div class="id-sentence">Kita berangkat jam setengah delapan pagi ya.</div>
<div class="id-translation">私たちは朝の7時半に出発しますよ。</div>
<div class="id-explanation">setengah delapan ＝ 7:30。</div>
</div>

## 3. 曜日（Nama-nama Hari）

インドネシア語の曜日の名前は、アラビア語の数詞（1日目、2日目…）に由来しています（日曜日の「Minggu」のみポルトガル語の「主の日（Domingo）」に由来）。

| 曜日 | 単語 | 由来・備考 |
|---|---|---|
| **月曜日** | **Senin** | アラビア語の「2」 |
| **火曜日** | **Selasa** | アラビア語の「3」 |
| **水曜日** | **Rabu** | アラビア語の「4」 |
| **木曜日** | **Kamis** | アラビア語の「5」 |
| **金曜日** | **Jumat** | イスラム教の集団礼拝（合同礼拝）の日 |
| **土曜日** | **Sabtu** | 安息日（シャバット） |
| **日曜日** | **Minggu** | ポルトガル語由来（「週」の意味も持つ） |

### 曜日に関連する重要表現
- **hari kerja**（平日・就業日）
- **akhir pekan**（週末 ※英語の weekend も会話で多用）
- **hari libur**（休日・祝日）
- **tanggal merah**（祝日 ※カレンダーの赤文字から）

<div class="id-example">
<div class="id-sentence">Besok hari apa? Besok hari Jumat.</div>
<div class="id-translation">明日は何曜日ですか？ 明日は金曜日です。</div>
</div>

## 4. 月（Bulan）と日付・年の語順

インドネシア語の日付は、英語（イギリス式）と同様に**「日 $\rightarrow$ 月 $\rightarrow$ 年」**の順序で並べます。

### 12ヶ月の名称
英語に似ているため覚えやすいのが特徴です。

- **Januari**（1月）
- **Februari**（2月）
- **Maret**（3月）
- **April**（4月）
- **Mei**（5月）
- **Juni**（6月）
- **Juli**（7月）
- **Agustus**（8月）
- **September**（9月）
- **Oktober**（10月）
- **November**（11月）
- **Desember**（12月）

### 日付の表し方
日付の前には **tanggal**（日）を付けます。

```text
tanggal 17 Agustus 1945
（1945年8月17日 ※インドネシア独立宣言記念日）

tanggal 1 Januari 2026
（2026年1月1日）
```

<div class="id-example">
<div class="id-sentence">Ulang tahun saya tanggal dua puluh lima Maret.</div>
<div class="id-translation">私の誕生日は3月25日です。</div>
</div>

## 5. 相対的な時間の表現（過去・現在・未来）

「昨日」「今日」「明日」や「先週」「来週」などの相対的な時間のボキャブラリーです。

### 日・時間帯の前後関係
| 過去 | 現在 | 未来 |
|---|---|---|
| **kemarin dulu**（一昨日） | **hari ini**（今日） | **besok**（明日） |
| **kemarin**（昨日） | **sekarang**（今） | **lusa**（明後日） |
| **tadi pagi**（今朝・さっきの朝） | **siang ini**（今日の昼） | **besok pagi**（明日の朝） |
| **tadi malam / semalam**（昨夜） | **malam ini**（今夜） | **nanti malam**（今夜・後ほど） |

> [!NOTE]
> **tadi（過去）と nanti（未来）の対比**
> 「先ほど・さっき」には **tadi**（tadi siang = さっきの昼）を使い、「後で・これから」には **nanti**（nanti sore = 今日の夕方）を使います。

### 週・月・年の前後関係
- **minggu lalu**（先週） $\leftarrow$ **minggu ini**（今週） $\rightarrow$ **minggu depan**（来週）
- **bulan lalu**（先月） $\leftarrow$ **bulan ini**（今月） $\rightarrow$ **bulan depan**（来月）
- **tahun lalu**（昨年） $\leftarrow$ **tahun ini**（今年） $\rightarrow$ **tahun depan**（来年）

## まとめと練習問題

時間と日時の表現は、約束を正しく守るための第一歩です。

### 理解度チェック
次のインドネシア語の時刻を24時間表記（例：07:30）で答えてみましょう。

1. **jam setengah sembilan pagi**
2. **jam dua belas kurang seperempat siang**
3. **jam setengah satu siang**

<details>
<summary>解答と解説</summary>

1. **08:30**（9時の30分前＝8時半）
2. **11:45**（12時の15分前＝11時45分）
3. **12:30**（1時の30分前＝12時半）
</details>
