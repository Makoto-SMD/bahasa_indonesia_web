# N02: ニッケル鉱石の下流化（Hilirisasi）とEVサプライチェーン

未加工鉱石の輸出禁止から始まったインドネシアの「下流化（Hilirisasi）」政策と、世界的な電気自動車（EV）バッテリーサプライチェーンにおける同国のプレゼンス拡大に関するニュースです。付加価値向上と環境課題（ESG）の両面を読み解きます。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Hilirisasi** | 下流化 / 高度加工化 | 原料輸出から国内高付加価値加工への産業転換政策 |
| **Bijih nikel mentah** | 未加工ニッケル原鉱 | 2020年1月より全面輸出禁止（larangan ekspor）となった対象 |
| **Fasilitas pemurnian (*smelter*)** | 精錬所 / スメルター | 鉱石を溶融・精錬して中間製品や高純度金属を生成する工場 |
| **Mendongkrak nilai tambah** | 付加価値をテコ入れする / 押し上げる | *dongkrak*（ジャッキ）から派生した比喩表現 |
| **Lonjakan devisa negara** | 国家外貨収入の急増 | 貿易黒字（surplus perdagangan）に直結する要因 |
| **Pembangkit Listrik Tenaga Uap (PLTU)** | 石炭火力発電所 | インドネシアの産業用自家発電（Captive Power）の主流 |
| **Teknologi HPAL** | HPAL技術（高圧酸浸出法） | 低品位ニッケル（リモナイト）からMHP（EV電池原料）を抽出する技術 |
| **Bahan baku baterai** | バッテリー原材料 | リチウムイオン電池に必要な正極材原料など |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 受動態の接頭辞 di-...-kan：dicanangkan
- **dicanangkan** (語根: *canang* = 銅鑼を鳴らして布告する) : 「（国家計画や政策が）鳴り物入りで宣言される、打ち出される」
- 政策報道において、`Kebijakan yang dicanangkan pemerintah...` は「政府によって打ち出された政策」という定番の修飾表現です。

### 2. 手段・付帯状況を示す前置詞句「Dengan melarang... dan mewajibkan...」
動名詞的に前置詞 `dengan` に動詞原形を接続し、手段や前提条件を示します。「〜を禁止し、かつ〜を義務付けることによって」と訳し、複文構造をすっきりと整理できます。

## ニュースの背景知識 (Latar Belakang Berita)

インドネシアは世界最大のニッケル埋蔵量と生産量を誇ります。従来は未加工鉱石を安価に輸出していましたが、国内産業育成のため輸出禁止に踏み切り、中国企業を中心とする大規模なスメルター投資（スラウェシ島モロワリやハルマヘラ島ウェダベイなど）を誘致しました。欧州市場や米国市場（IRA法）への輸出を見据え、脱炭素化（グリーンニッケル）への対応が現在の焦点となっています。
