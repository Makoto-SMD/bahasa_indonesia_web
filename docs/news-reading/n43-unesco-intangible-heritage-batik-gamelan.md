# N43: ユネスコ無形文化遺産（バティック・ガムラン）の継承と若者クリエイター

ユネスコ（UNESCO）無形文化遺産に登録されているインドネシアの伝統蝋けつ染め布「バティック（Batik）」や伝統青銅打楽器合奏「ガムラン（Gamelan）」を、Z世代や若手クリエイターが現代ファッションやエレクトロニック・ミュージックと融合させて国内外へ発信する文化イノベーションのニュースです。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Warisan budaya takbenda** | 無形文化遺産 | UNESCOの無形文化遺産代表一覧表記載遺産 |
| **Batik tulis** | 手描きバティック（蝋筆染め） | 伝統的なチャンティン（canting）を用いた最高級品 |
| **Sarat filosofi leluhur** | 先祖の哲学が詰まった | 模様ごとに祈りや意味が込められていること |
| **Orkestra gamelan** | ガムラン管弦楽団 | ジャワ、バリ、スンダ等の青銅打楽器アンサンブル |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 比喩表現「menemukan napas baru」（新たな息吹を見出す）
- **napas**（息・呼吸）を用い、衰退の危機にあった伝統文化が新たな活力を得て息を吹き返す様子を情緒豊かに描く表現です。

### 2. 「tidak lagi dipandang sebagai A, melainkan bermutasi menjadi B」
- `bermutasi`（変異する・進化する）を前向きな文脈で使用し、伝統が固定化されず現代的にアップデートされているダイナミズムを伝えています。

## ニュースの背景知識 (Latar Belakang Berita)

バティックは2009年、ガムランは2021年にユネスコ無形文化遺産に登録されました。インドネシアでは毎週金曜日が「バティックの日（Hari Batik）」として官民問わずバティック着用が推奨されており、スーツに代わる最高格式の正装として定着しています。近年は「Berbatik（バティックを着よう）」運動がTikTokやInstagramで流行し、若者がスニーカーに現代的バティックシャツを合わせるなど、ナショナル・プライドの象徴として世界に誇る文化産業となっています。
