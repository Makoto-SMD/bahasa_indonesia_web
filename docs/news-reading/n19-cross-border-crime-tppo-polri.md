# N19: 越境人身売買（TPPO）とオンライン詐欺組織の摘発

東南アジア地域で深刻化するオンライン詐欺拠点（スキャム・コンパウンド）へのインドネシア人労働者の不法送り出し・監禁と、インドネシア国家警察（Polri）およびASEAN諸国治安機関、インターポールによる人身売買犯罪（Tindak Pidana Perdagangan Orang: TPPO）撲滅作戦に関するニュースです。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Tindak Pidana Perdagangan Orang (TPPO)** | 人身売買犯罪 | 欺罔や強制によって人間を搾取・売買する重大犯罪 |
| **Bareskrim Polri** | 国家警察刑事捜査局 | 重大事件や国際犯罪捜査を管轄する警察中枢部 |
| **Sindikat internasional** | 国際シンジケート（国際犯罪組織） | 複数国にまたがる地下犯罪ネットワーク |
| **Iming-iming gaji tinggi** | 高給の甘い誘い文句 | *iming-iming*（甘言・エサ）による勧誘手口 |
| **Penipuan siber (*online scam*)** | オンライン詐欺 / ロマンス詐欺 | 偽投資アプリや恋愛感情を悪用した詐欺 |
| **Merepatriasi korban** | 被害者を自国へ送還・救出する | 外交ルートや治安機関を通じて帰国させること |
| **Penyekapan dan eksploitasi** | 監禁と搾取 | パスポートを没収し移動の自由を奪う行為 |
| **Dalang intelektual** | 首謀者 / 知能犯的な黒幕 | *dalang*（ワヤン劇の人形操者）から転じた表現 |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 比喩表現の代表格「dalang」（人形遣い＝黒幕・首謀者）
インドネシアの伝統影絵芝居（Wayang）で人形を操る演者を **dalang** と呼びますが、刑事事件や政治報道では「背後で糸を引く首謀者、黒幕」の比喩として定着しています。`menyasar dalang intelektual`（黒幕を狙い撃つ）は警察報道の王道フレーズです。

### 2. 「dengan iming-iming... untuk menjerat...」
- `dengan iming-iming + 名詞句` : 「〜という甘言・誘い文句を用いて」
- `menjerat`（罠にかける、網に引っ掛ける）と呼応し、詐欺の手口を克明に描写する表現です。

## ニュースの背景知識 (Latar Belakang Berita)

近年、カンボジアのシアヌークビルやミャンマー国境地帯（カレン州シュエコッコ等）において、武装組織の庇護のもとで中国系マフィアが運営する大規模なサイバー詐欺拠点が乱立しています。ITスキルのある若者が「カスタマーサポートの高収入求人」に騙されて渡航し、現地でパスポートを奪われ監禁・虐待されながら世界中の人々を騙すスキャム作業を強要される事件がASEAN全域で社会問題化しています。
