# N31: デジタル決済QRISの爆発的普及とASEAN越境QR決済連携

インドネシア銀行（BI）が導入した統一QRコード決済規格「QRIS（Quick Response Code Indonesian Standard）」の国内普及率の飛躍的向上と、タイ、マレーシア、シンガポールとの間で実現した二国間越境QR決済（Cross-Border QR Payment）による脱ドル化・現地通貨決済（LCT）を報じるニュースです。

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 普及指標の定番構文「Jumlah ... telah menembus..., di mana sebagian besar...」
- `telah menembus lebih dari...` : 「〜を突破した」。統計やユーザー数のマイルストーンを力強く表現するメディアの王道表現です。
- 関係副詞節 `di mana sebagian besar di antaranya merupakan...`（そのうちの大部分は〜である）が、政策が零細庶民層にまで届いている実態を補足しています。

### 2. 「tanpa perlu + 動詞句」（〜する必要なしに）
- `tanpa perlu menukar uang tunai` : 「現金を両替する必要なしに」。旅行者や消費者の利便性向上を強調する実用表現です。

## ニュースの背景知識 (Latar Belakang Berita)

かつてインドネシアの電子マネーは、GoPay、OVO、DANAなどが各社独自のQRコードを乱立させ、レジ前がQRスタンドだらけになる混乱を招いていました。中銀が「1つのQRコードですべての銀行・電子マネーからスキャンできるQRIS」を義務付けたことで、地方の屋台やバジャイ（三輪タクシー）に至るまで爆発的にキャッシュレスが浸透しました。さらにASEAN諸国と中銀間で直結させ、米ドル決済をバイパスするLCTネットワークを構築したことは、国際金融界からも大絶賛されています。
