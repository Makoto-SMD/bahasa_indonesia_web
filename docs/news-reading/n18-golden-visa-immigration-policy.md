# N18: ゴールデンビザ制度の創設と富裕層・先端人材の誘致

法務人権省出入国管理局（Ditjen Imigrasi）が導入した「ゴールデンビザ（Golden Visa）」制度を通じて、外国人富裕層、グローバル投資家、スタートアップ創業者、世界的著名人材（talenta global）に対して最長10年間の長期滞在許可を付与し、国内経済への資本投資を促進する政策ニュースです。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Kebijakan Golden Visa** | ゴールデンビザ政策 | 多額の投資を行う外国人に長期居住権を与える制度 |
| **Ditjen Imigrasi** | 入国管理総局 | ビザ・滞在許可・出入国審査を統括する法務人権省の機関 |
| **Talenta global** | グローバル人材 | 世界的な科学者、技術者、起業家など |
| **Izin Tinggal Terbatas (KITAS)** | 限定滞在許可 | 通常外国人が就労・滞在する際に取得する査証（年次更新） |
| **Dana investasi signifikan** | 多額の投資資金 | 個人で数十万ドル〜数百万ドル、法人で数千万ドル規模 |
| **Jalur pemeriksaan prioritas** | 優先審査レーン | 空港のVIP・専用イミグレーション審査ブース |
| **Penyaringan ketat (*screening*)** | 厳格な審査・フィルタリング | 犯罪歴や資金の透明性を調査する身元調査 |
| **Pencucian uang (*money laundering*)** | 資金洗浄（マネーロンダリング） | 不正資金の出所偽装犯罪（TPPU） |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 権利と便宜の付与「berhak menikmati berbagai kemudahan...」
- `berhak + 動詞原形` : 「〜する権利がある、資格を有する」
  - 行政や法制度の恩恵を説明する際の標準的なフレーズです。

### 2. 「Kendati demikian, S menerapkan... untuk memastikan bahwa... tidak disalahgunakan...」
- 前半で手厚い優遇措置（インセンティブ）を提示した上で、`Kendati demikian`（しかしながら）で国家安全・犯罪抑止の防壁（バックグラウンド・スクリーニング）を説明するバランスの取れた公的発表の文体です。

## ニュースの背景知識 (Latar Belakang Berita)

インドネシアは従来、外国人の土地・不動産所有や長期滞在ビザに関して非常に慎重で保護主義的な姿勢を取ってきました。しかし、UAE（ドバイ）やシンガポールなどの海外富裕層・高度IT人材誘致策に対抗し、バリ島を拠点とする富裕層ノマドワーカーや生成AI等の世界的スタートアップ創業者の資本を取り込むため、制度の大刷新に踏み切りました。第1号のゴールデンビザはOpenAIのサム・アルトマンCEOに授与されたことでも話題となりました。
