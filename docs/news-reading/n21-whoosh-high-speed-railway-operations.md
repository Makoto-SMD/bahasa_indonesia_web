# N21: 東南アジア初の高速鉄道「Whoosh」運行実績と採算性

インドネシアおよび東南アジアで初となるジャカルタ〜バンドン間高速鉄道「Whoosh（Kereta Cepat Jakarta-Bandung: KCIC）」の運行開始、利用者数の急増と定時運行率、ならびに建設費超過（cost overrun）の返済とスラバヤ延伸構想をめぐるニュースです。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Kereta Cepat "Whoosh"** | 高速鉄道「ウーシュ」 | Waktu Hemat, Operasi Optimal, Sistem Hebat の頭文字 |
| **Transportasi massal** | 公共大量輸送機関 | MRT, LRT, 高速鉄道等の都市間・都市交通 |
| **Tingkat keterisian kursi (*load factor*)** | 運行座席利用率 / 乗車率 | 旅客便の採算性を測る最重要KPI |
| **Memangkas waktu tempuh** | 所要時間をバッサリ短縮する | *pangkas*（刈り込む・切り落とす）の比喩 |
| **Pembengkakan biaya (*cost overrun*)** | 建設費用の超過・膨張 | 当初予算を大幅に上回った追加工事費 |
| **Pendapatan non-tiket (*non-farebox*)** | 非運賃収入 | 駅構内商業施設、広告、不動産開発等による収益 |
| **Kawasan Berorientasi Transit (TOD)** | 公共交通指向型開発（TOD） | 駅を中心に商業・住宅を高密度開発する都市計画 |
| **Kajian kelayakan (*feasibility study*)** | 実現可能性調査 / F/S | 採算性や技術的妥当性を事前検証する調査 |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 比喩動詞「membengkak」（膨らむ、腫れ上がる）
- 語根 **bengkak**（腫れる、むくむ）は、予算超過（`pembengkakan biaya`）や借金の増大（`utang yang membengkak`）など、経済・財政ニュースの「望ましくない数値の肥大化」を描写する頻出語です。

### 2. 「menuntut A untuk + 動詞句」（Aに対して〜するよう求める・強いる）
- 主語が無生物（返済負担など）であっても、客観的必然性を述べるため `menuntut KCIC untuk memaksimalkan...` と擬人的に使われます。

## ニュースの背景知識 (Latar Belakang Berita)

ジャカルタ〜バンドン間（約142km）を結ぶWhooshは、中国の「一帯一路（Belt and Road）」構想のもとで建設され、最高時速350kmで営業運転を行っています。日本との受注競争を経て中国案が採用された経緯がありますが、地盤不良や土地収用の難航による工期遅延とコスト増、国費投入への是非が議論を呼びました。現在は通勤・観光の足として定着しつつあり、ジャワ島を横断して東ジャワ州スラバヤまで延伸する計画の議論が加速しています。
