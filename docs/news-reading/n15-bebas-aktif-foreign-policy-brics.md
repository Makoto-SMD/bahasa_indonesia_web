# N15: 伝統的非同盟外交「自由・能動（Bebas-Aktif）」とBRICS加盟方針

インドネシア外交の神髄である「自由で積極的な外交原則（Politik Luar Negeri Bebas-Aktif）」と、新興国グループBRICSへの正式加盟に向けた意思表明、ならびにグローバルサウス（Global South）における独自の立ち位置を報じるニュースです。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Prinsip Bebas-Aktif** | 自由・能動の外交原則 | 1948年ハッタ元副大統領提唱のインドネシア外交の基礎哲学 |
| **Blok ekonomi BRICS** | BRICS新興国ブロック | ブラジル、ロシア、インド、中国、南ア等の経済同盟 |
| **Perwujudan konkret** | 具体的な具現化 / 体現 | 理念や憲法精神を目に見える政策に落とし込むこと |
| **Tidak memihak** | 偏らない / 中立を保つ | 語根 *pihak*（側・派）。冷戦や対立に与しない姿勢 |
| **Menjauhkan diri dari...** | 〜から距離を置く / 離れる | 対立を避けバランスを取る文脈で使われる動詞句 |
| **Bridge-builder** | 架け橋 / 橋渡し役 | 対立する陣営の間を取り持つ外交的役割 |
| **Global South** | グローバルサウス | アジア、アフリカ、中南米の新興国・途上国の総称 |
| **Diversifikasi mitra dagang** | 貿易相手国の多角化 | 特定国への過度な依存を回避する通商戦略 |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 否定と対比の構文「tidak berarti A, sebaliknya B」
- `tidak berarti A`（Aを意味するわけではない）に続けて、`Sebaliknya, S memposisikan diri...`（それどころか、Sは自らを〜と位置付けている）と展開します。誤解や批判を先回りして否定し、本来の意図を浮き彫りにする高度な論理構文です。

### 2. 「memperjuangkan A, memperluas B, serta memajukan C」
- 接頭辞 `meN-` の他動詞を並列させて、多面的な外交目的をリズミカルに列挙しています。公的演説や外交声明で頻出の修辞技法です。

## ニュースの背景知識 (Latar Belakang Berita)

インドネシアは1955年のバンドン・アジア・アフリカ会議の主催国であり、非同盟運動（Gerakan Non-Blok: GNB）の精神を外交の不変の柱としています。西側諸国主導のOECD加盟手続きを進める一方で、中国やロシア、ブラジルなど主導のBRICS加盟にも手を挙げる姿勢は、一見矛盾するように見えますが、インドネシアにとっては「全方位外交・等距離外交」の論理的帰結です。「千の友は少なすぎ、一人の敵は多すぎる（*sejuta kawan, satu musuh terlalu banyak*）」という伝統的箴言が息づいています。
