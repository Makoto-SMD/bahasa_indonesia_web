# N37: オンライン賭博（Judi Online）撲滅タスクフォースと口座凍結

低所得者層や若者を中心に社会問題化し、家計破綻や犯罪の温床となっている違法オンラインギャンブル（Judi Online: Judol）に対し、大統領令で設置された「オンライン賭博撲滅タスクフォース（Satgas Pemberantasan Judi Online）」が主導する数千の賭博サイト遮断、銀行口座凍結、海外サーバー摘発を報じるニュースです。

## 重要語彙とコロケーション (Kosakata Penting)

| インドネシア語 | 日本語対応 | 用例・時事コンテキスト |
| :--- | :--- | :--- |
| **Judi online / Judol** | オンライン賭博 / ネットカジノ | インドネシア刑法で厳格に禁止されている違法賭博 |
| **Judi slot** | オンラインスロット | スマホで手軽に賭けられるため被害が拡大したゲーム形態 |
| **Pusat Pelaporan dan Analisis Transaksi Keuangan (PPATK)** | 金融取引報告分析センター | マネーロンダリングや不正資金の流れを追跡するFIU機関 |
| **Perputaran dana** | 資金の循環規模 / 売上高 | 賭け金の総移動額 |
| **Memutus urat nadi keuangan** | 資金の動脈（命綱）を断ち切る | 犯罪組織の銀行口座や送金ルートを遮断すること |
| **Rekening penampung (*nominee*)** | 名義人口座 / 受け皿口座 | 他人の名義を買い取って犯罪収益をプールする口座 |
| **Transaksi mencurigakan** | 不審な取引（STR） | マネロン疑いとして銀行が当局に報告する取引 |
| **Otoritas Jasa Keuangan (OJK)** | 金融サービス庁 | 銀行・証券・保険を監督する金融監督機関 |

## 時事構文・読解のポイント (Poin Tata Bahasa & Struktur Kalimat)

### 1. 比喩表現「memutus urat nadi keuangan」（資金の命綱を断つ）
- **urat nadi** は「動脈・血管」を意味し、転じて「組織や活動を維持するための不可欠なライフライン」を指します。金融制裁や不正口座凍結報道の定番コロケーションです。

### 2. 被害の深刻さを伝える動詞「menjangkiti...」
- 語根 **jangkit**（感染する、広がる）から派生した他動詞で、「（伝染病のように）〜を蝕む、社会に蔓延する」という強い批判的ニュアンスを持ちます。

## ニュースの背景知識 (Latar Belakang Berita)

イスラム教徒が多数を占めるインドネシアでは、刑法（KUHP）上あらゆる賭博が完全非合法です。しかし近年、フィリピンやカンボジアに拠点を置く中国系胴元が、インフルエンサーを使ったSNS宣伝や少額入金（1万ルピア〜）を武器に急速に浸透。生活費や借金で首が回らなくなった一般市民の破産、家庭内暴力、闇金融（Pinjol ilegal）からの借入多重債務、果ては警察官や公務員による横領・自殺事件が多発し、国家安全保障上の重大危機として軍・警察・各省庁を挙げた大掃討作戦が展開されています。
