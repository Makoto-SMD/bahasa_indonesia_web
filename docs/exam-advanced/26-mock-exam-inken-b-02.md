## 1. 試験の傾向と出題意図

インドネシア語技能検定B級の完全想定問題集第2回です。今回は特に受験生が苦戦する「使役（meN--kan）と適用・反復（meN--i）の識別」「受動態構文（di- vs 倒置受動態）の書き換え」、および「契約・取引におけるビジネス読解」に焦点を当てた実戦演習を実施します。

## 2. 攻略フレームワーク・解法セオリー

### 2.1. B級突破のための文法急所チェック

1. **meN--kan vs meN--i の対立**: 
   - memanaskan air（水を温める：対象を熱い状態にする＝使役）
   - memanasi sup（スープを温め直す：対象に熱を加える＝場所・適用）
   - menugasi dia（彼に任務を課す：人を目的語にとる meN--i）
   - menugaskan pekerjaan kepadanya（彼に仕事を割り当てる：物を目的語にとる meN--kan）
2. **三人称被動態と一人称・二人称被動態の厳格な区別**:
   - 正: Surat itu **sudah saya baca** kemarin.
   - 誤: Surat itu sudah dibaca oleh saya kemarin.（B級では減点対象）

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【meN--kan / meN--i の識別問題】次の文の空所に入る正しい動詞の組み合わせはどれか？
"Direktur utama [______] sekretarisnya untuk mengatur jadwal pertemuan, kemudian beliau [______] tugas baru tersebut kepadanya."

- A. menugasi / membebankan
- B. menugaskan / membebani
- C. ditugasi / membebankan
- D. bertugas / berbeban

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. menugasi / membebankan**」

**解説**:
人を直接の目的語とする場合は「menugasi sekretarisnya（秘書に命じる）」となり、任務や重荷を相手に課す場合は「membebankan tugas（仕事を負わせる）」となります。したがってAが正解です。
</details>

### 第2問

【語順・受動態識別問題】「当社はこの提案を慎重に検討いたしました」をインドネシア語にする際、最も自然で適切なB級標準文はどれか？

- A. Proposal ini telah kami pertimbangkan secara saksama.
- B. Proposal ini telah dipertimbangkan oleh kami secara saksama.
- C. Proposal ini kami telah mempertimbangkan secara saksama.
- D. Kami telah dipertimbangkan oleh proposal ini secara saksama.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Proposal ini telah kami pertimbangkan secara saksama.**」

**解説**:
一人称複数「kami」が動作主となる受動文では、助動詞（telah）＋代名詞（kami）＋語根動詞（pertimbangkan）という前置代名詞受動構文（Pasif Persona）にするのが鉄則です。Bの「di-... oleh kami」は不自然と見なされます。
</details>

### 第3問

【ビジネス長文読解】
"Pihak Pertama berhak memutuskan kontrak secara sepihak apabila Pihak Kedua terbukti melakukan wanprestasi yang tidak diperbaiki dalam tenggat waktu 14 hari kalender kerja."
この文の「wanprestasi」の意味として最も正確なものはどれか？

- A. 債務不履行・契約違反（default / breach of contract）
- B. 不正会計・粉飾決算（fraudulent accounting）
- C. 破産宣告・会社更生（bankruptcy declaration）
- D. 機密漏洩・スパイ行為（leak of confidential info）

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. 債務不履行・契約違反（default / breach of contract）**」

**解説**:
「wanprestasi」はオランダ法（wanprestatie）に由来する法律・契約上の重要専門用語で、「債務不履行（契約上の義務を履行しないこと）」を意味します。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **menugasi bawahan** | 部下に任務を命じる（対象は人） |
| **menugaskan proyek** | プロジェクトを任せる（対象は仕事・事象） |
| **secara saksama** | 綿密に・慎重に（dengan cermat/teliti） |
| **wanprestasi** | 債務不履行・契約不履行 |
| **memutuskan sepihak** | 一方的に契約を解除・破棄する |
| **tenggat waktu** | 猶予期間・期限（deadline/grace period） |
