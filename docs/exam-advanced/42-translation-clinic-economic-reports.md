# 1442. 【翻訳演習】中央銀行レポート・経済白書の日イ相互翻訳

<div class="article-meta">

  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 技能検定A級〜特A級（CEFR C1〜C2）</span>

## 1. 試験の傾向と出題意図

インドネシア中央銀行（Bank Indonesia）の金融政策報告書や財務省の経済白書（Nota Keuangan）は、高度な経済マクロ用語、指標分析、政策意図が凝縮されたテキストです。検定A級・特A級の翻訳大問で頻出する「金融引き締め・緩和」「為替相場防衛」「インフレ圧力」「経常収支」の精密翻訳を伝授します。

---

## 2. 攻略フレームワーク・解法セオリー

### 2.1. マクロ経済・中央銀行レポートの頻出構文と定訳

1. **金融政策スタンス**: 
   - 利上げ（menaikkan suku bunga acuan） ⇔ 利下げ（menurunkan suku bunga acuan）
   - 金融引き締め（pengetatan moneter） ⇔ 金融緩和（pelonggaran moneter）
2. **インフレ・物価動向**: 
   - インフレ圧力（tekanan inflasi）、物価安定（stabilitas harga）、購買力（daya beli）。
3. **国際収支・為替市場**: 
   - 為替介入（intervensi pasar valas）、外貨準備高（cadangan devisa）、経常収支赤字/黒字（defisit/surplus transaksi berjalan）。

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【経済翻訳演習】次の文の最も的確な日本語訳はどれか？
"Bank Indonesia memutuskan untuk mempertahankan BI-Rate sebesar 6,00 persen guna memastikan inflasi tetap terkendali dalam sasaran dan mendukung stabilitas nilai tukar rupiah di tengah ketidakpastian pasar keuangan global."

- A. インドネシア銀行は、インフレ率が目標値内に抑制されていることを確実にし、世界的な金融市場の不確実性の中でルピア相場の安定を支援するため、政策金利（BIレート）を6.00パーセントに据え置くことを決定した。
- B. 中央銀行は、インフレが目標通りに行くようにするため、また世界の金融が不安定な中でルピアを守るために、金利を6%のままにしておくことに決めた。
- C. インドネシアの中央銀行はインフレを抑え込み、ルピア為替レートを安定させる目的で、BI金利を6%で持ち続ける判断を下した。
- D. 世界金融の不透明感に対処してルピアを安定化させ、インフレを目標に入れるため、中銀は6%のレートを保つことを確定させた。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. インドネシア銀行は、インフレ率が目標値内に抑制されていることを確実にし、世界的な金融市場の不確実性の中でルピア相場の安定を支援するため、政策金利（BIレート）を6.00パーセントに据え置くことを決定した。**」

**解説**:
「mempertahankan... sebesar 6,00 persen（〜を6.00%に据え置く）」「suku bunga acuan / BI-Rate（政策金利）」「sasaran inflasi（インフレ目標）」「stabilitas nilai tukar rupiah（ルピア相場の安定）」という経済公用語の厳格な定訳を完全に網羅しているのはAのみです。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **suku bunga acuan** | 政策金利・基準金利（benchmark interest rate） |
| **mempertahankan suku bunga** | 金利を据え置く（maintain interest rate） |
| **cadangan devisa** | 外貨準備高（foreign exchange reserves） |
| **transaksi berjalan** | 経常収支（current account） |
| **ketidakpastian pasar global** | 世界市場の不確実性・不透明感 |
| **daya beli masyarakat** | 国民の購買力（purchasing power） |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 経済ニュースで「mempertahankan」は「維持する」だけでなく、金利文脈では「据え置く」と訳出するのが経済翻訳の業界基準です。
