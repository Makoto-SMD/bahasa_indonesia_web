# 1414. 【UKBI第1セクション】リスニング攻略：日常会話・インタビューの聞き取り

<div class="article-meta">

  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: UKBI Seksi I（CEFR B1〜B2）</span>

---

## 1. 試験の傾向と出題意図

UKBIの第1セクション（Mendengarkan）前半では、公共交通機関のアナウンス、職場の同僚間の打ち合わせ、ラジオインタビューなどが出題されます。自然な発話スピード、地域のアクセント（ジャワ訛り、スンダ訛り等）、および間投詞や口語短縮形が混入する会話から、話者の意図（tujuan）、時間・場所、トラブルの核心を即座に聞き分けるテクニックを解説します。

---

## 2. 攻略フレームワーク・解法セオリー

### Seksi I 前半の3大頻出シチュエーション
1. **公共交通・インフラ・気象アナウンス**: 列車の遅延理由、搭乗口の変更、豪雨や強風による運行見合わせ。
2. **オフィス・業務調整の対話**: 会議の日程繰り上げ（dimajukan）、資料の差し替え、予算配分の修正。
3. **ラジオ・ポッドキャストの専門家インタビュー**: 健康管理、伝統食の保存、若手起業家の成功体験。

### 聞き取りの重要アンカーワード
- **逆接・転換**: tetapi, namun, sayangnya, padahal（話者の本音・真のトラブルはここ以降に来る）。
- **時間・条件**: ditunda（延期）, dialihkan（振り替え）, dibatalkan（中止）。

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

#### 第1問
【リスニング音声スクリプト想定問題】
(Suara Petugas Stasiun): "Perhatian para penumpang Kereta Api Argo Parahyangan tujuan Bandung. Sehubungan dengan adanya perbaikan bantalan rel di km 45, keberangkatan kereta yang semula dijadwalkan pukul 14.15 terpaksa kami tunda selama tiga puluh menit. Kami mohon maaf atas ketidaknyamanan ini."

**設問: Kapan Kereta Api Argo Parahyangan diperkirakan berangkat?**

- A. Pukul 14.15
- B. Pukul 14.30
- C. Pukul 14.45
- D. Pukul 15.15

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**C. Pukul 14.45**」

**解説**:
当初の出発予定は14時15分（14.15）で、線路改修のため30分延期（ditunda selama tiga puluh menit）されたため、実際の出発予定時刻は14時45分（14.45）となります。
</details>
