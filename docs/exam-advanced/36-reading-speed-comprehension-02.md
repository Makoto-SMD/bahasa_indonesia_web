## 1. 試験の傾向と出題意図

速読演習第2弾では、事実確認問題にとどまらず「筆者の主観的態度（sikap penulis）」「文章の主眼・トーン（nada tulisan）」「言外の意図（makna tersirat）」を高速で見極める高度な推論テクニックを伝授します。論理標識（Signpost words）を追跡することで、文脈の急旋回を察知します。

---

## 2. 攻略フレームワーク・解法セオリー

### 2.1. 論理標識（Signpost Words）によるトーンの察知

- **逆接・転換（Shift）**: namun, kendati demikian, alih-alih, alangkah naifnya。→ *ここから筆者の本音が語られる！*
- **強調・着目（Focus）**: ironisnya, patut disayangkan, fakta tak terbantahkan bahwa。→ *筆者の強い感情・批判的視点！*
- **結論・提言（Claim）**: oleh sebab itu, sudah saatnya, tiada jalan lain selain。→ *文章の主眼（Tesis）！*


---

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【筆者の態度推論演習】次の文章を読み、設問に答えよ。

"Pemberian bantuan sosial secara masif menjelang perhelatan pemilu kerap diklaim sebagai bentuk kepedulian negara terhadap kaum marjinal. Namun, alih-alih memberdayakan ekonomi rakyat secara berkelanjutan, kebijakan populis jangka pendek ini justru berpotensi membudayakan ketergantungan dan menggerogoti ketahanan fiskal negara dalam jangka panjang."

問: この文章における筆者の社会支援（bansos）政策に対する姿勢・態度はどのようなものか？

- A. 貧困層の生活向上に直結するとして全面的な賛意を示している。
- B. 短期的ポピュリズムであり、財政と国民の自立を損ねるとして極めて批判的である。
- C. 選挙前の政策としてはやむを得ない措置であると一定の理解を示している。
- D. 社会支援の内容を現金給付から現物支給に切り替えるべきだと提言している。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. 短期的ポピュリズムであり、財政と国民の自立を損ねるとして極めて批判的である。**」

**解説**:
「Namun, alih-alih memberdayakan...（〜を自立させるどころか）」「kebijakan populis jangka pendek（短期的ポピュリスト政策）」「membudayakan ketergantungan（依存を定着させる）」「menggerogoti ketahanan fiskal（国家財政を蝕む）」という極めて批判的な語彙連鎖から、Bが明白な正解です。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **alih-alih...** | 〜どころか・〜する代わりに |
| **kebijakan populis** | ポピュリズム政策・大衆迎合策 |
| **memberdayakan** | エンパワーする・自立させる |
| **menggerogoti** | 蝕む・侵食する・少しずつ損なう |
| **ketahanan fiskal** | 財政健全性・財政耐力 |
| **sikap kritis** | 批判的な態度・姿勢 |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 「alih-alih（〜どころか）」「menggerogoti（蝕む）」などのマイナス感情を帯びた動詞（Loaded words）は、筆者の批判的スタンスを特定するための決定打になります。
