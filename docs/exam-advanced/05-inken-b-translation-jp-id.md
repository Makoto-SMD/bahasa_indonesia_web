# 1405. 【技能検定B級対策】日イ翻訳：日本語特有の表現を自然なインドネシア語に移す

<div class="article-meta">
  <span class="meta-item"><i class="fas fa-clock"></i> 読了目安: 15分</span>
  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 技能検定B級（CEFR B1〜B2）</span>
</div>

## 1. 試験の傾向と出題意図

B級の記述試験（日イ翻訳）では、直訳すると意味不明になる日本語特有の「配慮・意図・受身・無生物主語」を、インドネシア語の自然な統語構造（S-V-O）へと転換する構文変換力が採点の決定打となります。

---

## 2. 攻略フレームワーク・解法セオリー

### 日イ翻訳の3大処方箋
1. **「〜ておく」「〜てしまう」の処理**: 事前準備の「ておく」は事前を表す副詞 terlebih dahulu / sebelumnya で処理。望ましくない「てしまう」は無意志接頭辞 ter- または不幸を表す副詞 sayangnya で表現。
2. **日本語の受動文を能動文に再構築する**: 「新制度が導入された」→「Pemerintah memperkenalkan sistem baru（政府が新制度を導入した）」のように明確な能動態に直す方が自然な場合が多い。
3. **「〜することになっている」などの制度表現**: sudah disepakati / dijadwalkan / diwajibkan を用いて、規程・合意事項として表現する。

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

#### 第1問
【課題文1】来週の会議で使用する資料を、明日までに印刷しておいてください。

- A. Tolong cetak dokumen yang akan digunakan dalam rapat minggu depan sebelum besok.
- B. Harap mencetakkan terlebih dahulu dokumen untuk rapat minggu depan paling lambat besok.
- C. Silakan Anda sudah mencetak materi rapat depan sebelum besok tiba.
- D. Dokumen rapat minggu depan harus dicetak disimpan besok hari.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. Harap mencetakkan terlebih dahulu dokumen untuk rapat minggu depan paling lambat besok.**」

**解説**:
「印刷しておいてください」という事前準備のニュアンスは mencetakkan terlebih dahulu、期限の「明日までに」は paling lambat besok（遅くとも明日まで）と表現するのが最も格調高く自然なビジネス表現です。Aも通じますが「〜ておく」のニュアンスが弱く、Bが満点答案です。
</details>

---

#### 第2問
【課題文2】技術革新の進展に伴い、人々の生活様式は急速に変化しつつある。

- A. Seiring dengan kemajuan inovasi teknologi, pola hidup masyarakat sedang berubah secara pesat.
- B. Bersama inovasi teknologi maju, hidup orang berubah banyak sekali.
- C. Mengikuti teknologi baru, gaya masyarakat menjadi lain cepat.
- D. Karena kemajuan inovasi teknologi membuat orang berganti hidup.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Seiring dengan kemajuan inovasi teknologi, pola hidup masyarakat sedang berubah secara pesat.**」

**解説**:
「〜に伴い」は Seiring dengan...、「生活様式」は pola hidup、「急速に」は secara pesat と表現するのが定型です。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **〜に伴い、〜とともに** | seiring dengan / sejalan dengan |
| **〜に基づいて、〜に準拠して** | berdasarkan pada / sesuai dengan |
| **〜を目的として、〜のために** | bertujuan untuk / demi |
| **遅くとも〜までに** | paling lambat / selambat-lambatnya |
| **〜という点において** | dalam hal / dari segi |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 日本語の「〜をお願いします」をすべて tolong で訳すのではなく、ビジネス文書や公式な依頼では「Kami mohon agar...」「Harap...」を使い分けると加点対象になります。
