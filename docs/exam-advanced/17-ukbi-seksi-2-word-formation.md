## 1. 試験の傾向と出題意図

UKBI Seksi II において文法知識の深さが最も露骨に試されるのが、接頭辞・接尾辞・周囲辞の音韻変化規則（morfofonemik）および外来語の借用接尾辞（-isasi, -itas, -al）の正誤判定です。大辞典KBBI（Kamus Besar Bahasa Indonesia）の基準に準拠した正当な造語法を体系化します。

---

## 2. 攻略フレームワーク・解法セオリー

### 音韻同化・鼻音化の厳格ルール（meN- / peN-）
1. **K-P-S-Tの脱落規則**: 語根の頭文字が k, p, s, t で、第2母音が母音の場合、頭文字は鼻音化して脱落する（例: tulis → menulis, kirim → mengirim, sapu → menyapu, potong → memotong）。
2. **脱落の例外（二重子音クラスタ）**: 語根頭文字が二重子音（kr, pr, sk, st, tr等）の外来語の場合、脱落しない（例: kritik → mengkritik, proses → memproses, transfer → mentransfer）。
3. **二重接頭辞 memper- の注意点**: memper- の後ろに形容詞が来る場合、接尾辞 -kan を重ねてはならない（誤: memperbesarkan → 正: memperbesar）。

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

#### 第1問
次の動詞表現のうち、KBBIおよびEYD第5版の造語規則に照らして「誤っているもの（不適切な重複）」はどれか？

- A. memperbesar
- B. memperluas
- C. mempercepatkan
- D. memperindah

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**C. mempercepatkan**」

**解説**:
二重接頭辞 memper- に形容詞（cepat）が付く場合、それ自体で「〜をより速くする（比較使役）」意味を持つため、使役接尾辞 -kan を重ねて「mempercepatkan」とするのは文法的な重複誤用（pleonasme）です。正しくは「mempercepat」または「mencepatkan」です。
</details>

---

#### 第2問
外来語語根「konfirmasi（確認）」に接頭辞 meN- と接尾辞 -kan が結合した正しい表記はどれか？

- A. mengonfirmasikan
- B. mengkonfirmasikan
- C. menkonfirmasi
- D. mekonfirmasikan

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. mengonfirmasikan**」

**解説**:
語根 konfirmasi の頭文字 k の後ろは母音 o であるため、K-P-S-T脱落規則（鼻音化 ng への置換）が適用され、「mengonfirmasikan」となるのが公的標準語法（Bahasa Baku）です。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **memper- + 形容詞（正）** | memperbesar, memperluas, memperdalam, memperjelas |
| **memper- + 形容詞 + -kan（誤）** | memperbesarkan, memperluaskan, memperdalamkan |
| **外来語 k 脱落（正）** | mengonfirmasi, mengoordinasi, mengonsumsi |
| **外来語 二重子音維持（正）** | mempromosikan, mengkritik, mentransfer, memprogram |
| **名詞借用接尾辞** | -isasi（globalisasi）, -itas（aktivitas）, -isme（patriotisme） |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 日常のニュースや口語では「mengkonfirmasi」「memperbaiki」などの誤用や混同が散見されますが、UKBIの正書法試験ではKBBIに厳格に準拠して「mengonfirmasi」が正解となります。
