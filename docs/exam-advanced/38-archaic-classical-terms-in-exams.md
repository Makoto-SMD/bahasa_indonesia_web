## 1. 試験の傾向と出題意図

検定最上級（A級・特A級）の読解問題やUKBI最上位バンドでは、マレー古典文学（Hikayat）の抜粋や、伝統的な文語・古風表現（kata arkais / klasik）が突如として登場します。「syahdan」「alkisah」「sebermula」などの物語導入語や「bahwasanya」「nan」などの古典的接続詞の用法を知っておくことで、慌てず冷静に対処できます。

---

## 2. 攻略フレームワーク・解法セオリー

### 2.1. 古典マレー語由来の頻出接続詞・談話標識（Penanda Wacana Klasik）

1. **物語の開始**: 
   - **Alkisah / Tersebutlah perkataan**: 物語の始まり。「昔々、あるところに…」
   - **Sebermula**: 物語の端緒。「そもそも、事の起こりは…」
2. **話題の転換・継続**: 
   - **Syahdan / Hatta**: 話題の転換。「さて、それから…」「一方で…」
   - **Kalakian**: 時間の経過。「その後、やがて…」
3. **文語的強調・関係詞**: 
   - **Bahwasanya**: 「〜であるということは誠に…」「実に〜である（bahwaの強調古語）」
   - **Nan**: 文語的「yang」。「gadis nan rupawan（美しき乙女）」

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【古典文語読解問題】次の古典物語の冒頭文における「Hatta」の意味・役割として最も適切なものはどれか？
"Hatta beberapa lamanya baginda bersemayam di atas takhta, maka datanglah seorang saudagar kaya membawa persembahan yang tiada bertara."

- A. 時間の経過や場面の転換を表す「さて、それから／やがて」
- B. 理由や原因を表す「〜のせいで／〜のために」
- C. 否定を表す「決して〜ない／〜はずがない」
- D. 比較を表す「〜と同じくらい／〜に匹敵する」

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. 時間の経過や場面の転換を表す「さて、それから／やがて」**」

**解説**:
古典文学で多用される「Hatta」は、アラビア語・ペルシア語影響下で発達した古典マレー語の談話標識で、「さて／それから／やがて（maka kemudian）」という場面転換・時間経過を示します。
</details>

---

### 第2問

現代の公用文や憲法前文などでも用いられる文語表現「bahwasanya」と同義の標準現代語はどれか？

- A. sesungguhnya bahwa
- B. barangkali jika
- C. seandainya bila
- D. meskipun demikian

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. sesungguhnya bahwa**」

**解説**:
「Bahwasanya」はアラビア語借用語に由来し、インドネシア憲法（UUD 1945）の冒頭文（"Bahwa sesungguhnya kemerdekaan itu..."）などに見られる通り、「sesungguhnya bahwa（真に〜であることには）」という意味を持ちます。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **Alkisah** | 物語の始まり・むかしむかし（once upon a time） |
| **Hatta / Syahdan** | さて・それから・一方（meanwhile / then） |
| **Sebermula** | そもそも・事の起こりは（in the beginning） |
| **Kalakian** | その後・やがて（thereafter） |
| **Bahwasanya** | まことに〜である（verily / truly that） |
| **Nan** | 〜なる・〜である（yangの文語・詩的表現） |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 古典テキストが出題された場合、HattaやSyahdanなどの接続語は「場面の区切り」に過ぎないため、これらに惑わされず直後の動詞と主語に焦点を当てることが正解への近道です。
