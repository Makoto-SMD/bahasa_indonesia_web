## 1. 試験の傾向と出題意図

誤文訂正ドリル第2弾では、より構造的・統語的な難所である「主語欠落文（Kalimat Tanpa Subjek）」「従属節の孤立（Anak Kalimat Menggantung）」「受動態における人称代名詞の語順破壊」にメスを入れます。複雑な公用文の骨格を正確に見抜く訓練です。

---

## 2. 攻略フレームワーク・解法セオリー

### 2.1. 上級者が引っかかる構造トラップ Vol. 2

1. **前置詞による主語の埋没（Subjek Terhalang Preposisi）**:
   - 誤: **Dalam rapat itu** memutuskan untuk membatalkan proyek.
   - 正: **Rapat itu** memutuskan... または **Dalam rapat itu diputuskan** untuk...
   ※文頭の前置詞句（Keterangan）のせいで、能動他動詞「memutuskan」の主語が存在しない破綻文。
2. **従属節のみで独立した破綻文**:
   - 誤: Meskipun inflasi menurun drastis. Tetapi daya beli masyarakat belum pulih.
   - 正: Meskipun inflasi menurun drastis, daya beli masyarakat belum pulih.
3. **一人称受動態の助動詞配置エラー**:
   - 誤: Laporan itu sudah dikerjakan oleh saya.（口語・非標準）
   - 正: Laporan itu **sudah saya kerjakan**.

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【主語欠落エラー問題】次の文の中で、文法的に正しい完全文（kalimat efektif）はどれか？

- A. Melalui penelitian ini diharapkan dapat memberikan kontribusi nyata bagi pengembangan energi terbarukan.
- B. Penelitian ini diharapkan dapat memberikan kontribusi nyata bagi pengembangan energi terbarukan.
- C. Untuk para peserta seminar dimohon segera memasuki auditorium.
- D. Bagi yang kehilangan dompet dapat mengambilnya di pos keamanan.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. Penelitian ini diharapkan dapat memberikan kontribusi nyata bagi pengembangan energi terbarukan.**」

**解説**:
Aは文頭に「Melalui」が付いているため副詞句となり主語が存在しません（主語欠落文）。Cも「Untuk」が主語を隠しており誤り、Dも「Bagi」により主語が欠けています。正しく名詞主語（Penelitian ini）から始まっているBのみが完全文です。
</details>

---

### 第2問

【受動態語順エラー】「この提案書は私たちが昨日精査いたしました」の正しい公用文受動態はどれか？

- A. Proposal ini kami kemarin telaah secara cermat.
- B. Proposal ini kemarin telah kami telaah secara cermat.
- C. Proposal ini ditelaah oleh kami kemarin secara cermat.
- D. Kemarin proposal ini kami telah menelaah secara cermat.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. Proposal ini kemarin telah kami telaah secara cermat.**」

**解説**:
前置代名詞受動文では、助動詞（telah）の直後に代名詞（kami）が密着し、その直後に語根動詞（telaah）が来ます（telah kami telaah）。時を表す副詞（kemarin）は助動詞の前に置くのが正統です。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **kalimat tanpa subjek** | 主語欠落文（前置詞で主語が消えた悪文） |
| **kalimat efektif** | 有効文（簡潔で文法的に完璧な規範文） |
| **anak kalimat menggantung** | 主節を伴わず孤立した従属節 |
| **pasif persona** | 人称代名詞受動構文（代名詞＋語根） |
| **telah kami telaah** | 私たちが精査した（正統な前置受動態） |
| **memberikan kontribusi** | 貢献を果たす・寄与する |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 文頭が「Dengan...」「Dalam...」「Melalui...」「Berdasarkan...」で始まっている文を見たら、コンマの後にきちんとした『名詞の主語』があるかを必ず確認してください。主語がなくいきなり動詞が来ている文は100%主語欠落エラーです。
