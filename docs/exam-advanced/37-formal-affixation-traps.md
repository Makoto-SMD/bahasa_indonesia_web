# 1437. 検定で狙われる「不規則鼻音化・特殊接辞」の落とし穴完全網羅

<div class="article-meta">
  <span class="meta-item"><i class="fas fa-clock"></i> 読了目安: 15分</span>
  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 技能検定B級〜A級 / UKBI Seksi II（CEFR B2〜C1）</span>
</div>

## 1. 試験の傾向と出題意図

インドネシア語の接頭辞 meN- および peN- における鼻音化規則（K-P-S-Tの脱落）は学習初期に習得しますが、検定上級やUKBIでは『規則が適用されない外来子音結合語』や『特殊な二重子音語』が出題され、多くの受験生が足をすくわれます。例外パターンを完全網羅して失点をゼロにします。

---

## 2. 攻略フレームワーク・解法セオリー

### 2.1. K-P-S-Tが「脱落しない」外来借用語の二重子音（Kluster Konsonan）

語根の先頭が「子音＋子音（kluster）」で始まる外来語は、K-P-S-Tであっても**脱落せず**そのまま残る！
- **k-**: kritik → **mengkritik** (×mengritik), kristal → **mengkristal**, konfirmasi → **mengonfirmasi** (単一子音扱いで脱落)。
- **p-**: produksi → **memproduksi** (×memroduksi), proses → **memproses**, protes → **memprotes**。
- **s-**: skala → **mengkala / menskalakan**, steril → **mensterilkan**, stabil → **menstabilkan**。
- **t-**: traksi → **mentraksi**, transfer → **mentransfer** (×menransfer)。

### 2.2. 1音節語根（Monosilabel）の特殊鼻音化（menge- / penge-）

- bom → **mengebom** / **pengeboman**
- cat → **mengecat** / **pengecatan**
- cek → **mengecek** / **pengecekan**
- las → **mengelas** / **pengelasan**
- klik → **mengeklik** / **pengeklikan**

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【不規則鼻音化正誤問題】次の選択肢の中で、EYD第5版基準で綴りが完全に正しい動詞はどれか？

- A. Perusahaan itu berencana memroduksi massal kendaraan listrik tahun depan.
- B. Perusahaan itu berencana memproduksi massal kendaraan listrik tahun depan.
- C. Tim auditor sedang mengevaluasikan laporan keuangan tahunan.
- D. Pihak bank telah menransfer dana kompensasi ke rekening korban.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. Perusahaan itu berencana memproduksi massal kendaraan listrik tahun depan.**」

**解説**:
語根「produksi」は語頭が二重子音「pr-」であるため、pは脱落せず「memproduksi」となります（Aは誤り）。Dの「transfer」も「tr-」のため脱落せず「mentransfer」が正解です。Cは「mengevaluasi」が標準形です。
</details>

---

### 第2問

語根「sertifikasi（認証・資格付与）」に接辞 meN--kan が付いた正しい派生語はどれか？

- A. menyertifikasikan
- B. mensertifikasikan
- C. mengsertifikasikan
- D. besertifikasi

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. menyertifikasikan**」

**解説**:
語根「sertifikasi」の頭文字「s」の後ろは母音「e」であり二重子音ではありません。したがって通常規則通り s は脱落して ny に鼻音化し、「menyertifikasikan」となります。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **memproduksi** | 生産する（pr-のためpは脱落しない） |
| **memproses** | 処理する・加工する（pr-のためpは脱落しない） |
| **mengkritik** | 批判する（kr-のためkは脱落しない） |
| **mentransfer** | 振り込む・移転する（tr-のためtは脱落しない） |
| **mengeklik** | クリックする（1音節語のため menge-） |
| **menyertifikasikan** | 認証する（se-は単一子音＋母音なのでs脱落） |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 「memproduksi」「mengkritik」「mentransfer」は毎年必ずどこかの試験で問われます。「子音＋r/l（kluster）で始まる語は脱落しない」と暗記してください。
