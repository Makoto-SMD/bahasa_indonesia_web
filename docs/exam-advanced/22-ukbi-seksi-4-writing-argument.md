## 1. 試験の傾向と出題意図

UKBI記述試験（Seksi IV）のもう一つの頻出パターンが「現代社会の論争的トピック（isu kontroversial）に対する意見論述文（Esai Argumentatif）」です。人工知能の労働市場への影響、再生可能エネルギー移行のコスト、リモートワークの是非などのテーマに対し、自らの立場を明確にしつつ、対立する意見（kontra-argumen）にも配慮した説得力ある構成が求められます。

---

## 2. 攻略フレームワーク・解法セオリー

### 2.1. 説得力ある意見論述文（Esai Argumentatif）の段落展開

1. **導入部（Pendahuluan）**: トピックの現代的意義（kontekstualisasi）を提示し、自己の明確な主張（tesis）を打ち出す。
2. **論拠の提示（Argumen Pendukung）**: 根拠、事実データ、具体例（bukti empiris）を挙げて主張を裏付ける。
3. **反対意見への言及と反論（Sanggahan / Counter-argument）**: 反対派の視点に「確かに〜という側面はある（Kendati demikian / Memang benar bahwa...）」と一定の理解を示した上で、自説の優位性を論証する。
4. **結論（Penutup）**: 主張の再確認（reafirmasi）と今後の展望・提言を述べる。

### 2.2. 論述文で必須の論理マーカー（Penanda Hubungan Wacana）

- **対比・譲歩**: kendati demikian（それにもかかわらず）、di satu sisi... di sisi lain...（一方では…他方では…）、sungguhpun demikian（そうではあるが）。
- **因果関係**: sebagai konsekuensinya（結果として）、oleh karenanya（それゆえに）、berimplikasi pada（〜に影響を及ぼす）。
- **補足・強調**: terlebih lagi（さらに言えば）、bahkan lebih jauh lagi（さらに進んで）、perlu digarisbawahi bahwa（強調すべき点は〜）。

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【論述構成問題】「新首都移転（Pemindahan Ibu Kota）」の経済的影響に関する論述文において、反対派の懸念に配慮しつつ自説を展開する譲歩構文として最も格調高いものはどれか？

- A. Kendati membebani anggaran belanja negara dalam jangka pendek, pemindahan ibu kota berpotensi mengakselerasi pemerataan pembangunan antarwilayah.
- B. Walaupun mahal banget biayanya sekarang, tapi ibu kota baru bikin daerah luar Jawa jadi maju juga kok.
- C. Biar kata duit negara habis banyak, pokoknya kita harus pindah biar nggak numpuk di Jakarta terus.
- D. Memang sih biayanya sangat besar, namun menurut hemat saya ya sudahlah tidak apa-apa demi masa depan.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Kendati membebani anggaran belanja negara dalam jangka pendek, pemindahan ibu kota berpotensi mengakselerasi pemerataan pembangunan antarwilayah.**」

**解説**:
Aは「Kendati 〜, ... berpotensi mengakselerasi...」という極めてフォーマルかつ論理的な構文で対比を表現しています。他選択肢は口語表現や俗語が混入しています。
</details>

---

### 第2問

論述文の結論部分で自らの主張を再確認する表現として最も適切なものはどれか？

- A. Berdasarkan elaborasi argumen di atas, dapat ditegaskan kembali bahwa mitigasi risiko iklim merupakan imperatif moral dan ekonomi.
- B. Jadi begitu saja tulisan saya, pokoknya kalian harus setuju dengan apa yang saya bilang di atas.
- C. Dari omongan tadi, jelas sekali kalau masalah iklim itu gawat banget dan harus segera diberesin.
- D. Sekian dan terima kasih, semoga para pembaca paham maksud saya tentang iklim.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Berdasarkan elaborasi argumen di atas, dapat ditegaskan kembali bahwa mitigasi risiko iklim merupakan imperatif moral dan ekonomi.**」

**解説**:
「elaborasi argumen（議論の詳述）」「ditegaskan kembali（再確認・強調される）」「imperatif moral dan ekonomi（道徳的・経済的至上命題）」といった高度な論述語彙が適切に用いられています。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 項目・表現 | 解説・ニュアンス・共起表現 |
| :--- | :--- |
| **isu kontroversial** | 論争的トピック・議論の的となる問題 |
| **bukti empiris** | 実証的根拠・証拠 |
| **mengakselerasi** | 加速させる（mempercepatの学術語） |
| **pemerataan pembangunan** | 開発の公平・均等な配分 |
| **kendati demikian** | それにもかかわらず・そうではあるが |
| **imperatif** | 至上命令・不可欠な要件 |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> UKBIの意見論述では、感情論（saya merasa, saya benci など）は大幅減点です。「データや事実が示している通り（Sebagaimana ditunjukkan oleh data）」と第三者的な客観性を保つことがPeringkat Unggul（優等）獲得の絶対条件です。
