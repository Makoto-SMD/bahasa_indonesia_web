# 1403. 【技能検定B級対策】誤文訂正セクション：文法的な不整合を即座に発見する法

## 1. 試験の傾向と出題意図

技能検定B級の筆記試験で多くの受験者が時間を浪費してしまうのが「下線部A〜Dのうち文法的に誤っているものを1つ選ぶ」誤文訂正問題です。出題される誤りのパターンは限定されており、5つの典型トラップを頭に叩き込んでおけば、5秒で正解を見抜くことが可能です。

---

## 2. 攻略フレームワーク・解法セオリー

### 誤文訂正の5大頻出パターン
1. **受動態の主語・動詞・行為者の不整合**: 一人称・二人称の語幹受動態（buku ini saya baca）と三人称の di-...-nya/oleh（buku ini dibaca oleh mereka）の混同。
2. **前置詞の二重使用・欠落**: tentang, terhadap, kepada, untuk などの前置詞が他動詞の直後に不要に挿入されているケース（例: membicarakan tentang masalah → membicarakan masalah）。
3. **重複強調の不自然さ**: sangat...sekali, amat...sekali, para...sekalian などの重複誤用。
4. **接辞の誤用**: 自動詞に不要な -kan が付いている、または名詞化接辞の取り違え（peN-...-an vs per-...-an）。
5. **時間詞・アスペクトの衝突**: sudah と belum の矛盾、kemarin と akan の時制不一致。

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

#### 第1問
次の文の下線部(A)〜(D)のうち、文法的に誤っているものはどれか？

Komite pengawas (A) [sedang mendiskusikan] (B) [tentang] langkah strategis (C) [untuk mengatasi] defisit anggaran yang (D) [semakin membengkak].

- A. sedang mendiskusikan
- B. tentang
- C. untuk mengatasi
- D. semakin membengkak

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. tentang**」

**解説**:
他動詞 mendiskusikan は直接目的語をとるため、前置詞 tentang を直後に置くことはできません（mendiskusikan tentang は典型的な誤用）。正しくは「mendiskusikan langkah strategis」とするか、自動詞を用いて「berdiskusi tentang langkah strategis」とします。
</details>

---

#### 第2問
次の文の下線部(A)〜(D)のうち、文法的に誤っているものはどれか？

Laporan keuangan tahunan (A) [tersebut] (B) [sudah diselesaikan oleh saya] (C) [sebelum] rapat umum pemegang saham (D) [dimulai].

- A. tersebut
- B. sudah diselesaikan oleh saya
- C. sebelum
- D. dimulai

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. sudah diselesaikan oleh saya**」

**解説**:
行為者が一人称代名詞「saya」の場合、di- 動詞受動態（diselesaikan oleh saya）ではなく、語幹受動態を用いて「sudah saya selesaikan」とするのが標準語法（bahasa baku）の厳格な規則です。
</details>

---

#### 第3問
次の文の下線部(A)〜(D)のうち、文法的に誤っているものはどれか？

(A) [Para peserta-peserta seminar] (B) [sangat antusias sekali] (C) [mendengarkan paparan] dari (D) [pakar ekonomi terkemuka] tersebut.

- A. Para peserta-peserta seminar
- B. sangat antusias sekali
- C. mendengarkan paparan
- D. pakar ekonomi terkemuka

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Para peserta-peserta seminar**」

**解説**:
複数の人称を表す「para」の直後に重複名詞「peserta-peserta」を重ねることは二重複数（redundansi）の重大な誤用です。正しくは「Para peserta seminar」または「Peserta-peserta seminar」のいずれかに統一しなければなりません。
</details>

## 4. 重要語彙・構文対比テーブル

本セクションのテーマに関連する最重要語彙・成句の対比一覧です。

| 誤用例 | 正用例 | 文法解説 |
| :--- | :--- | :--- |
| **誤: membicarakan tentang...** | **正: membicarakan... / berbicara tentang...** | 他動詞は前置詞不要 |
| **誤: surat ini ditulis oleh saya** | **正: surat ini saya tulis** | 一人称行為者の語幹受動態 |
| **誤: sangat indah sekali** | **正: sangat indah / indah sekali** | 二重強調の回避 |
| **誤: demi untuk kepentingan bersama** | **正: demi kepentingan / untuk kepentingan** | 目的接続詞の重複禁止 |
| **誤: bertujuan untuk memajukan** | **正: bertujuan memajukan** | bertujuan の直後は動詞直接接続 |

## 5. 合格者の着眼点・プロのアドバイス

> [!TIP]
> **合格のためのワンポイント・アドバイス**:
> 誤文訂正では、まず「動詞の直後に前置詞（tentang, akan, dengan）がないか」「di-... oleh saya/kami になっていないか」「para + 重複形になっていないか」の3点を真っ先にスキャンしてください。
