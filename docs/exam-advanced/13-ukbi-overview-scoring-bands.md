# 1413. 【UKBI能力評価試験】試験構成・評価基準（Peringkat）とスコアアップ戦略

## 1. 試験の傾向と出題意図

インドネシア共和国教育文化研究技術省・言語育成開発局（Badan Bahasa）が主催する国家公認のインドネシア語能力検定「UKBI（Uji Kemahiran Berbahasa Indonesia）」。外国人専門職の就労ビザ取得や大学院進学、国費留学生選考で必須となる本試験の全体構成と、最上位ランク（Unggul / Istimewa）を奪取するための総合戦略を解説します。

---

## 2. 攻略フレームワーク・解法セオリー

### UKBIの試験構成（5つのセクション）
1. **Seksi I: Mendengarkan（リスニング・聴解）**: 40問（日常会話、アナウンス、学術講義、インタビュー）。音声は1回のみ再生。
2. **Seksi II: Merespons Kaidah（文法規則・正書法）**: 25問（EYD第5版、接辞、語彙、助詞、構文の正誤選択）。
3. **Seksi III: Membaca（リーディング・読解）**: 40問（図表、案内文、学術論文、論説、文学作品）。
4. **Seksi IV: Menulis（記述・エッセイ）**: パケット選択式（学術要約・論述）。
5. **Seksi V: Berbicara（スピーキング・口頭発表）**: テーマ別プレゼンテーション。

### UKBI評価ランク（Peringkat）とスコア対比
- **Istimewa（特級・最高峰）**: 725〜800点（母語話者の学者・プロ通訳水準 / CEFR C2）
- **Sangat Unggul（最優等）**: 641〜724点（高度な学術・政策・報道の完全運用 / CEFR C1）
- **Unggul（優等）**: 578〜640点（大学院教育・専門職就労に十分な水準 / CEFR B2）
- **Madya（中等）**: 482〜577点（一般的なビジネス・日常実務 / CEFR B1）
- **Semenjana（初等）**: 405〜481点（日常サバイバル会話 / CEFR A2）

## 3. 実戦想定問題と詳細解説

本番試験と同等レベルのオリジナル想定問題です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

#### 第1問
UKBI試験において、外国人専門職や大学院進学で標準的に求められる「Peringkat Unggul（優等）」の獲得に必要なスコア範囲はどれか？

- A. 405〜481点
- B. 482〜577点
- C. 578〜640点
- D. 725〜800点

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**C. 578〜640点**」

**解説**:
UKBIの「Peringkat Unggul」は578〜640点です。482〜577点はMadya、641〜724点はSangat Unggul、725点以上が最高位のIstimewaです。
</details>
