# 命令文・禁止文・依頼文（tolong, silakan, coba, jangan）

インドネシア社会は「和（けい愛・調和）」を重んじる文化を持っており、相手に対して直接的すぎる強い命令をぶつけることは滅多にありません。

そのため、文頭に**依頼・促し・禁止を表すキーワード（tolong, silakan, coba, jangan 等）を添えて、丁寧度や距離感を適切にコントロールする**ことが極めて重要です。

---

## 1. 命令・依頼・禁止キーワード一覧マップ

| 単語 | ニュアンス・丁寧度 | 意味 | 英語相当 | 例文 |
| :--- | :--- | :--- | :--- | :--- |
| **tolong** | 親切・日常の丁寧な依頼 | 〜してください、お願いします | `please / could you` | `Tolong tutup pintu.`（ドアを閉めてください） |
| **silakan** | 相手に快く促す | どうぞ〜してください | `please go ahead` | `Silakan masuk.`（どうぞお入りください） |
| **mohon** | 改まった公的・公式な依頼 | 〜してくださいますようお願い申し上げます | `kindly request` | `Mohon perhatian.`（ご注目願います） |
| **coba** | 気軽な促し・試み | ちょっと〜してみて | `try to` | `Coba rasakan ini.`（これちょっと味見してみて） |
| **jangan** | 禁止 | 〜してはいけない、〜しないで | `don't` | `Jangan lupa!`（忘れないで！） |
| **mari** / **ayo** | 勧誘・誘い | 〜しましょう、〜しよう | `let's` | `Mari kita makan.`（さあ食べましょう） |

---

## 2. 命令文の文法ルール：他動詞は「語根（カタダサール）」に戻る！

命令文を作るときの最大の文法特徴は、**接頭辞 `meN-` のついた他動詞から `meN-` が取れ、元の語根（Kata Dasar）の形になる**という点です。

- `membaca`（読む） ➔ **`Baca!`**（読め！ / 読んでください）
- `membeli`（買う） ➔ **`Beli!`**（買いなさい）
- `menulis`（書く） ➔ **`Tulis nama di sini!`**（ここに名前を書いてください！）

> [!NOTE]
> 自動詞（`ber-` 動詞など）の場合は、接頭辞が取れずにそのまま使われることが一般的です（例: `Berdiri!`＝立ちなさい、`Berangkat!`＝出発せよ）。

### 接尾辞 `-lah` による語調の緩和
単語の語根だけで命令するとぶっきらぼうに聞こえるため、後ろに強調・緩和の接尾辞 **`-lah`** を添えて響きを柔らかくします。
- `Duduk!`（座れ！） ➔ **`Duduklah.`**（お座りなさい）
- `Makan!`（食え！） ➔ **`Makanlah.`**（召し上がりなさい）

## 3. 場面別の実践表現

### 3.1 丁寧なお願い：tolong と mohon
日常生活では **`tolong`**、公の場や案内板では **`mohon`** を使います。

<div class="id-example" markdown>

<div class="id-sentence">
Tolong bantu saya membawakan koper ini.
</div>
<div class="id-reading">
トロン バントゥ サヤ ムンバワカン コペル イニ
</div>
<div class="id-meaning">
このスーツケースを運ぶのを手伝ってください。
</div>

</div>

### 3.2 どうぞ：silakan
客人を招き入れるとき、食事を勧めるとき、順番を譲るときに必須の言葉です。

<div class="id-example" markdown>

<div class="id-sentence">
Silakan duduk dan nikmati teh hangat ini.
</div>
<div class="id-reading">
シラカン ドゥドゥッ ダン ニクマティ テー ハンガッ イニ
</div>
<div class="id-meaning">
どうぞお座りになって、この温かいお茶をお楽しみください。
</div>

</div>

### 3.3 禁止：jangan と dilarang
- **`jangan`**: 会話での一般的な禁止。「〜しないで」。
  - 丁寧に言う場合: `Tolong jangan...`（どうか〜しないでください）
- **`dilarang`**: 標識・看板・規則での受動態禁止表現。「〜禁止」。
  - `Dilarang merokok.`（禁煙）
  - `Dilarang masuk.`（立入禁止）
  - `Dilarang parkir.`（駐車禁止）

<div class="id-example" markdown>

<div class="id-sentence">
Jangan khawatir, semuanya akan baik-baik saja.
</div>
<div class="id-reading">
ジャンガン カワティール スムアニャ アカン バイッ バイッ サジャ
</div>
<div class="id-meaning">
心配しないで、すべて順調にいきますよ。
</div>

</div>

### 3.4 勧誘：mari（丁寧） vs ayo / yuk（カジュアル）
- 目上の人や公の場: **`Mari kita...`**（〜いたしましょう）
- 友人同士・家族: **`Ayo...`** または文末に **`... yuk!`**（〜しようよ！）
  - `Makan, yuk!`（ご飯食べようよ！）
  - `Ayo cepat!`（さあ早く！）
