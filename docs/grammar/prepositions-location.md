# 基本前置詞（di, ke, dari）の場所表現

インドネシア語の場所・移動に関する表現は、**di**（〜で・〜に）、**ke**（〜へ）、**dari**（〜から）の**3つの基本前置詞**がすべての土台となっています。

これらは英語の `in / at / on`、`to`、`from` に相当しますが、英語のように「乗り物の中は on で、部屋の中は in…」といった煩雑な使い分けはなく、「**静止**」「**移動の先**」「**移動の元**」の3方向だけで極めてシンプルに整理されています。

---

## 1. 3大基本前置詞のコア概念

```
[起点]                [所在・静止]               [到達・方向]
 DARI                 ---- DI ----                --> KE
（〜から）              （〜に / 〜で）              （〜へ）
```

| 前置詞 | 役割 | 英語相当 | 例文 | 意味 |
| :--- | :--- | :--- | :--- | :--- |
| **di** | 場所の所在・静止（〜に、〜で） | `at`, `in`, `on` | `di Jakarta` | ジャカルタで / ジャカルタに |
| **ke** | 移動の方向・目的地（〜へ、〜に） | `to` | `ke kantor` | オフィスへ |
| **dari** | 移動の出発点・起源（〜から） | `from` | `dari Jepang` | 日本から |

## 2. 正書法の最重要ルール：前置詞 di と接頭辞 di- の違い

インドネシア語の正書法（EYD）において、**検定試験やビジネス文書で最も厳しくチェックされる点**がこれです。

> 【**分かち書きの鉄則**】
> - **場所を表す前置詞の `di` は、後ろの名詞と【スペースを空けて離して書く】！**
>   - ⭕ `di rumah`（家で）、`di sekolah`（学校で）
>   - ❌ `dirumah`、`disekolah`
> - **受動態を作る接頭辞の `di-` は、後ろの動詞と【くっつけて書く】！**
>   - ⭕ `dimakan`（食べられる）、`ditulis`（書かれる）
>   - ❌ `di makan`、`di tulis`

※ 同様に、前置詞の `ke` も場所の前ではスペースを空けます（例: ⭕ `ke pasar`、❌ `kepasar`）。

---

## 3. 位置名詞と組み合わせる「複合前置詞」

「〜の上」「〜の下」「〜の中」など、具体的な空間の相対位置を表したいときは、【** di / ke / dari ＋ [位置名詞] ＋ [目的物] **】の公式を使います。

| 位置名詞 | 意味 | 複合表現の例（di ...） | 意味 |
| :--- | :--- | :--- | :--- |
| **atas** | 上 | `di atas meja` | 机の上に |
| **bawah** | 下 | `di bawah pohon` | 木の下に |
| **dalam** | 中 | `di dalam tas` | カバンの中に |
| **luar** | 外 | `di luar kantor` | オフィスの外に |
| **depan** | 前 | `di depan stasiun` | 駅の前に |
| **belakang** | 後ろ | `di belakang rumah` | 家の後ろに |
| **samping** / **sebelah** | 横・隣 | `di samping toko` | 店の横（隣）に |
| **antara** | 間 | `di antara A dan B` | AとBの間に |

<div class="id-sentence">
Kucing tidur di bawah meja di dalam kamar.
</div>
<div class="id-reading">
クチン ティドゥール ディ バワ メジャ ディ ダラム カマル
</div>
<div class="id-meaning">

</div>

</div>

## 4. 要注意：相手が「人」の場合は kepada / dari を使う

「彼**へ**手紙を送る」「先生**から**本をもらう」のように、移動の終点や起点が**「場所」ではなく「人間」である場合**、前置詞の使い分けに注意が必要です。

- ❌ `Kirim surat ke dokter.` ➔ （病院という建物ではなく「医師という人」宛てなら不自然）
- ⭕ **`Kirim surat kepada dokter.`**（医師**へ**手紙を送る）
- ⭕ **`Terima hadiah dari teman.`**（友達**から**プレゼントをもらう＝起点「人」にも `dari` を使用）
