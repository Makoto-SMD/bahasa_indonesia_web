# 基本語順（SVO）と後置修飾の絶対原則

インドネシア語の文法は、世界の言語の中でも**最もシンプルで論理的**と言われています。
日本語のような「助詞（てにをは）」による語順の自由さはなく、英語と同じ「**語順そのものが意味を決める言語**」です。

そして、インドネシア語を操る上で最初に叩き込むべき2大原則が、「**SVO語順**」と「**後置修飾（DMの法則）**」です。

---

## 1. 原則①：文の基本構造は「SVO型」

インドネシア語の基本語順は、英語と同様に【**主語（S） ＋ 動詞・述語（V） ＋ 目的語・補語（O）**】です。

```
Saya      makan    nasi goreng.
[主語 S]   [動詞 V]  [目的語 O]
私は      食べる    ナシゴレンを
```

<div class="id-sentence">
Saya belajar bahasa Indonesia.
</div>
<div class="id-reading">
サヤ ブラジャール バハサ インドネシア
</div>
<div class="id-meaning">
私はインドネシア語を勉強しています。
</div>

</div>

### 「be動詞」は基本的に存在しない！
英語では `I am a student.` や `She is beautiful.` のように `am` や `is` が必須ですが、インドネシア語では**主語の隣に名詞や形容詞を直接置くだけ**で立派な文になります。

- `Saya mahasiswa.`（私 ＋ 学生 ＝ 私は学生です）
- `Dia cantik.`（彼女 ＋ 美しい ＝ 彼女は綺麗です）
- `Rumah ini besar.`（家・この ＋ 大きい ＝ この家は大きいです）

---

## 2. 原則②：修飾はすべて「後ろから前へ」（後置修飾・DMの法則）

日本人学習者が最も慣れを必要とするのが、この「**後置修飾**」です。

インドネシア語教育では、これを「**DMの法則（Hukum D-M）**」と呼びます。
- **D（Diterangkan）**: 修飾**される**語（中心となる名詞）
- **M（Menerangkan）**: 修飾**する**語（説明を加える語）

> **【公式】: [メインの名詞] ＋ [説明する言葉]**
> 日本語とは語順が「真逆」になります！

### 2.1 [名詞] ＋ [形容詞]
日本語では「赤い車」ですが、インドネシア語では「車 ＋ 赤い」の順になります。

| 日本語の語順 | インドネシア語の語順 | 単語 |
| :--- | :--- | :--- |
| 赤い車 | 車 ＋ 赤い | `mobil merah` |
| 熱いコーヒー | コーヒー ＋ 熱い | `kopi panas` |
| 親切な人 | 人 ＋ 親切な | `orang baik` |
| 新しい本 | 本 ＋ 新しい | `buku baru` |

<div class="id-sentence">

</div>
<div class="id-reading">

</div>
<div class="id-meaning">

</div>

### 2.2 [名詞] ＋ [名詞]（所有格・所属）
「〜の…」という所有を表す場合も、日本語の助詞「の」は使わず、単に【**所有される物 ＋ 所有者**】の順に並べます。

- `rumah saya`（家 ＋ 私 ＝ 私の家）
- `nama Anda`（名前 ＋ あなた ＝ あなたのお名前）
- `kantor ayah`（オフィス ＋ 父 ＝ 父の職場）
- `guru bahasa Indonesia`（先生 ＋ インドネシア語 ＝ インドネシア語の先生）

---

## 3. 修飾語が重なるときの「配置ルール」

1つの名詞に「形容詞」「所有者」「指示詞（これ・あれ）」が複数つく場合、配置する順番は厳格に決まっています。

> 【**語順の黄金方程式**】  
> **[名詞] ＋ ①[形容詞] ＋ ②[所有者] ＋ ③[指示詞 (ini / itu)]**

例：「この私の新しい赤い車」を表現したい場合：
1. メイン名詞: `mobil`（車）
2. 形容詞: `merah baru`（新しい赤い）
3. 所有者: `saya`（私の）
4. 指示詞: `ini`（この）

➔ **`mobil merah baru saya ini`**
