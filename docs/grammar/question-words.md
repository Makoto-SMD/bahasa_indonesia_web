# 疑問詞（5W1H：apa, siapa, di mana, kapan, kenapa, bagaimana, berapa）

インドネシア語の疑問詞は、英語の 5W1H に対応する明快な語彙が揃っています。
英語のように複雑な倒置（助詞や助動詞を文頭に出す構文）を必要とせず、**「知りたい部分を疑問詞に置き換えるだけ」**で疑問文が作れるのが最大の特徴です。

---

## 1. 疑問詞一覧マスター表

| 疑問詞 | 意味 | 英語相当 | 主な尋ねる対象 | 例文 |
| :--- | :--- | :--- | :--- | :--- |
| **Apa** | 何 | what | 事物・内容 | `Apa ini?`（これは何？） |
| **Siapa** | 誰 | who | 人物・名前 | `Siapa nama Anda?`（お名前は誰？） |
| **Di mana** | どこで / どこに | where | 所在・居場所 | `Di mana toilet?`（トイレはどこ？） |
| **Ke mana** | どこへ | where to | 目的・移動先 | `Mau ke mana?`（どこ行くの？） |
| **Dari mana** | どこから | where from | 出身・出発地 | `Dari mana asalnya?`（出身はどこ？） |
| **Kapan** | いつ | when | 時間・日程 | `Kapan berangkat?`（いつ出発する？） |
| **Mengapa** / **Kenapa** | なぜ・どうして | why | 理由・原因 | `Kenapa terlambat?`（なぜ遅刻したの？） |
| **Bagaimana** | どのように・どう | how | 方法・状態 | `Bagaimana rasanya?`（味はどう？） |
| **Berapa** | いくら・いくつ | how much/many | 数量・価格・時間 | `Berapa harganya?`（いくらですか？） |

---

## 2. 疑問詞の2大配置ルール

インドネシア語で疑問詞を使う場合、**「文頭に置く」**方法と、**「元の語順のまま置く」**方法の2通りがあり、どちらも日常的に広く使われます。

### 2.1 文頭に置くパターン（疑問の焦点化）
疑問詞を文の先頭に持ってきて、何を知りたいかを真っ先に伝える構造です。改まった文章や、明確に質問したい場面でよく使われます。

<div class="id-example" markdown>

<div class="id-sentence">
Di mana stasiun kereta api terdekat?
</div>
<div class="id-reading">
ディ マナ スタシウン クレタ アピ トゥルデカッ
</div>
<div class="id-meaning">
最寄りの鉄道駅はどこにありますか？
</div>

</div>

> [!TIP]
> 文頭の疑問詞をさらに強調したり、フォーマルな文にする場合は、疑問接尾辞 **`-kah`** を添えることがあります（例: `Apakah ini?`, `Siapakah beliau?`）。

### 2.2 元の語順のまま置くパターン（口語・会話で最も自然！）
平叙文の語順のまま、質問したい単語の場所に疑問詞をそのまま入れるパターンです。
日本語の「あなたの名前は誰（何）？」と同じ感覚で発話できるため、会話で極めて便利です。

- 平叙文: `Nama saya Taro.`（私の名前はタロウです）
- 疑問文: `Nama Anda siapa?`（あなたのお名前は誰ですか？ ＝ お名前は何とおっしゃいますか？）

<div class="id-example" markdown>

<div class="id-sentence">
Kamu mau pergi ke mana?
</div>
<div class="id-reading">
カム マウ プルギ ク マナ
</div>
<div class="id-meaning">
君はどこに行きたいの？
</div>

</div>

## 3. なぜ・どうして：Mengapa（公式）vs Kenapa（口語）

「理由」を尋ねる疑問詞には2種類あります。

- **`Mengapa`**: ニュース、ビジネス文書、試験などで使われる標準的・フォーマルな表現。
- **`Kenapa`**: 日常会話で圧倒的に使われる口語表現。「どうしたの？」「なんで？」と軽く聞く時も `Kenapa?` だけで通じます。

<div class="id-example" markdown>

<div class="id-sentence">
Kenapa kamu tidak datang kemarin?
</div>
<div class="id-reading">
クナパ カム ティダッ ダタン クマリン
</div>
<div class="id-meaning">
昨日どうして来なかったの？
</div>

</div>

---

## 4. 万能の数字疑問詞：Berapa

`Berapa` は、価格（いくら）、数量（何個・何人）、時間（何時）、年齢（何歳）、電話番号（何番）など、**「数字で答える質問」のすべて**に対応する超重要単語です。

| 尋ねる内容 | 組み合わせ | 意味 |
| :--- | :--- | :--- |
| **価格** | `Berapa harganya?` | （これの）値段はいくらですか？ |
| **時間** | `Jam berapa sekarang?` | 今何時ですか？ |
| **人数** | `Berapa orang?` | 何名様ですか？ |
| **年齢** | `Berapa umur Anda?` | おいくつですか？ |
| **電話番号** | `Nomor HP-nya berapa?` | スマホの電話番号は何番？ |

<div class="id-example" markdown>

<div class="id-sentence">
Berapa lama perjalanan dari sini ke bandara?
</div>
<div class="id-reading">
ブラパ ラマ プルジャラナン ダリ スィニ ク バンダラ
</div>
<div class="id-meaning">
ここから空港までの所要時間はどれくらいですか？
</div>

</div>
