# 従属接続詞（karena, kalau/jika, sehingga, supaya/agar, meskipun）

従属接続詞（Konjungsi Subordinatif）は、1つの文（主節）に理由、条件、結果、目的、譲歩などの「副詞的な節（従属節）」をつなげて、**論理的で長い複文を作るための接着剤**です。

インドネシア語の複文は、接続詞の置く位置が比較的自由で、文頭にも文中にも置ける柔軟性を持っています。

---

## 1. 従属接続詞の5大機能一覧

| 機能 | 接続詞 | 意味 | 英語相当 | 口語形 / 類義語 |
| :--- | :--- | :--- | :--- | :--- |
| **理由・原因** | **karena** | 〜なので、〜だから | `because` | `soalnya` / `sebab` |
| **条件・仮定** | **kalau** / **jika** | もし〜なら | `if` | `kalo` / `bila` |
| **結果・帰結** | **sehingga** | その結果〜、したがって | `so that` / `therefore` | `makanya` / `sampai` |
| **目的** | **supaya** / **agar** | 〜するために、〜するように | `in order to` / `so that` | `biar` |
| **譲歩** | **meskipun** / **walaupun** | 〜にもかかわらず、〜だが | `although` / `even though` | `walau` / `biarpun` |

---

## 2. 各接続詞の詳しい用法と例文

### 2.1 karena（理由：〜なので、〜だから）
原因や理由を説明します。「主節 ➔ karena 従属節」の順でも、「Karena 従属節 ➔ 主節」の順でも成立します。

<div class="id-example" markdown>

<div class="id-sentence">
Saya tidak masuk kantor kemarin karena sakit demam.
</div>
<div class="id-reading">
サヤ ティダッ マスク カントール クマリン カレナ サキッ ドゥムム
</div>
<div class="id-meaning">
私は昨日、熱を出して体調が悪かったため出社しませんでした。
</div>

</div>

> 日常会話では、文頭で理由を言い始める時に **`soalnya`**（ソアルニャ＝実は〜だからさ）が極めてよく使われます。

### 2.2 kalau / jika（条件：もし〜なら）
仮定や条件を提示します。

- **`kalau`（口語・日常会話）**: 日常会話の 9 割以上は `kalau`（または `kalo`）です。
- **`jika`（フォーマル・書き言葉）**: 契約書、学術論文、ニュースなどで使われます。

<div class="id-example" markdown>

<div class="id-sentence">
Kalau besok hujan, kita batalkan rencana piknik.
</div>
<div class="id-reading">
カラウ ベソッ フジャン キタ バタルカン レンチャナ ピクニッ
</div>
<div class="id-meaning">
もし明日雨が降ったら、ピクニックの予定を中止しましょう。
</div>

</div>

### 2.3 sehingga（結果：その結果〜、〜するほどに）
前の事象によって生じた結果を導きます。

<div class="id-example" markdown>

<div class="id-sentence">
Jalanan sangat macet sehingga saya terlambat tiba di bandara.
</div>
<div class="id-reading">
ジャラナン サンガッ マチェッ スヒンガ サヤ トゥルラムバッ ティバ ディ バンダラ
</div>
<div class="id-meaning">
道路がひどい渋滞だったため、その結果空港への到着が遅れてしまいました。
</div>

</div>

> 口語では、「だから〜なんだよ」と結果を述べる時に **`makanya`**（マカニャ）が多用されます。

### 2.4 supaya / agar（目的：〜するために、〜するように）
ある目的を達成するための意図を表します。

- 会話では短縮形の **`biar`**（ビアール）が親しまれています。

<div class="id-example" markdown>

<div class="id-sentence">
Makan sayur dan buah supaya badan tetap sehat.
</div>
<div class="id-reading">
マカン サユル ダン ブア スパヤ バダン トゥタップ スハッ
</div>
<div class="id-meaning">
健康な体を保つために、野菜と果物を食べましょう。
</div>

</div>

### 2.5 meskipun / walaupun（譲歩：〜にもかかわらず）
逆境や予想に反する事実を述べるときに使います。

<div class="id-example" markdown>

<div class="id-sentence">
Meskipun harga barang naik, toko ini selalu ramai pembeli.
</div>
<div class="id-reading">
ムスキプン ハルガ バラン ナイス トコ イニ スラル ラマイ プンブリ
</div>
<div class="id-meaning">
物価が上がったにもかかわらず、この店はいつも買い物客で賑わっています。
</div>

</div>

## 3. 実践対話：雨の日の約束変更

  <span>Halo, Eka! Di luar hujan lebat banget, nih.（もしもしエカ！外、ものすごい大雨だよ。）</span>
</div>

<div class="dialogue-item">
  <span class="dialogue-speaker dialogue-speaker--b">Eka</span>
  <span>Iya, betul. Kalau hujannya belum reda, bagaimana?（うん、そうだね。もし雨が止まなかったら、どうする？）</span>
</div>

<div class="dialogue-item">
  <span class="dialogue-speaker">Hadi</span>
  <span>Biar aman, kita tunda satu jam ya, supaya tidak terjebak banjir.（安全のために、洪水に巻き込まれないよう1時間遅らせようか。）</span>
</div>

<div class="dialogue-item">
  <span class="dialogue-speaker dialogue-speaker--b">Eka</span>

</div>

</div>
