# 人称代名詞と親称・敬称システム

インドネシア語の人称代名詞は、文法的には性別（男性・女性）の区別が一切ない（「彼」も「彼女」も同じ `dia`）というシンプルさを持つ一方、**「相手との距離感・年齢・社会的立場」による使い分け**が極めて発達しています。

特に、日常会話では英語の「You」のように二人称代名詞を連呼するのではなく、**親族名称を呼称（親称）として使う文化**が根付いています。

---

## 1. 人称代名詞一覧マップ

| 人称 | 代名詞 | 丁寧度 / ニュアンス | 意味 |
| :--- | :--- | :--- | :--- |
| **一人称単数** | `saya` | 標準・丁寧（ビジネス・初対面） | 私 |
| | `aku` | 親密・くだけた表現（家族・恋人・同年代の友人） | 僕・私 |
| **一人称複数** | **`kami`** | **【聞き手を含まない】** 私たち | 私ども・我々 |
| | **`kita`** | **【聞き手を含む】** 私たち（あなたと私） | 私たち（みんな） |
| **二人称単数** | `Anda` | 改まった敬称（広告・公式案内・初対面） | あなた・貴方 |
| | `kamu` | 親密・同年代または年下向け | 君・あんた |
| **二人称複数** | `kalian` | くだけた表現（友人グループなど） | 君たち・お前ら |
| **三人称単数** | `dia` | 一般的（性別の区別なし） | 彼・彼女 |
| | `beliau` | 目上・尊敬語（大統領・先生・両親など） | そのお方・先生 |
| **三人称複数** | `mereka` | 一般的 | 彼ら・彼女ら |

---

## 2. 最重要の区別：kami vs kita（私たち）

日本語では「私たち」とひと括りにしますが、インドネシア語では**「今話している相手（聞き手）」がその輪に入っているかどうか**で単語が分かれます。

- **`kami`（排他）**: 「私たち（あなたたちは含まない）」
- **`kita`（包括）**: 「私たち（あなたも一緒）」

<div class="id-example" markdown>

<div class="id-sentence">
Mari kita berangkat!
</div>
<div class="id-reading">
マリ キタ ブランカッ
</div>
<div class="id-meaning">
（相手に向かって）さあ、一緒に出発しましょう！
</div>

</div>

> もしここで `Mari kami berangkat!` と言ってしまうと、「（あなたを残して）私たちだけで出発しましょう」という奇妙な意味になってしまいます。

逆に、相手に対して自社の紹介をするときは：
- `Kami dari perusahaan XYZ.`（私たちはXYZ社から参りました＝相手は客先なので `kami`）

---

## 3. 実践の極意：二人称は「代名詞」ではなく「親称」を使う！

インドネシア社会では、相手に対して `Anda`（あなた）を連発すると「他人行儀で冷たい」、`kamu`（君）を使うと「馴れ馴れしい・失礼」と感じられることがあります。

そこで、会話では**相手の年齢・性別に合わせた親族呼称（親称）**を相手の名前のように使います。

| 呼称 | 本来の意味 | 実際の用法（呼びかけ・主語） |
| :--- | :--- | :--- |
| **Bapak** (Pak) | 父・お父さん | 成人男性、年上の男性、上司、客先男性への敬称（〜さん・Mr.） |
| **Ibu** (Bu) | 母・お母さん | 成人女性、既婚女性、上司、先生への敬称（〜さん・Ms.） |
| **Mas** | 兄（ジャワ語起源） | 同年代〜やや年上の若い男性（店員やドライバーなど） |
| **Mbak** | 姉（ジャワ語起源） | 同年代〜やや年上の若い女性（カフェの店員など） |
| **Kak** (Kakak) | 兄・姉 | 年齢の近い若者同士、SNS、カスタマーサポートでの親しみある敬称 |
| **Bang** (Abang) | 兄（バタウィ起源） | 屋台のお兄さん、バイクタクシーの運転手など |

<div class="id-example" markdown>

<div class="id-sentence">
Bapak sudah makan?
</div>
<div class="id-reading">
バパッ スダ マカン
</div>
<div class="id-meaning">
（年上男性・お客様に向かって）もうお食事は召し上がりましたか？
</div>

</div>

> 「あなたの本」と言いたいときも、`buku Anda` より `buku Bapak`（バパッの本）や `buku Mas` と言う方がはるかに自然で敬意が伝わります。

---

## 4. 三人称 `dia` に性別がない利点

英語の `he` / `she`、日本語の「彼」「彼女」のような区別はなく、**すべて `dia`（または口語で `ia`）**です。

- `Dia dokter.` ➔ 彼は医師です / 彼女は医師です（どちらでも通じる）
- 文脈で性別を明示したい場合は、`teman laki-laki`（男友達）や `teman perempuan`（女友達）と後ろに修飾語を添えます。
