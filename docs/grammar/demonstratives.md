# 指示詞（ini / itu）と指示代名詞の使い方

インドネシア語の指示詞は、基本的に **ini**（これ・この）と **itu**（あれ・それ・あの・その）の2つしかありません。
日本語のように「これ（近称）・それ（中称）・あれ（遠称）」という3区分ではなく、英語の `this` と `that` に近い2区分です。

しかし、**置く位置（文頭か名詞の後ろか）によって働きが劇的に変化する**ため、正確な語順の理解が不可欠です。

---

## 1. 2つの指示詞の基本概念

| 指示詞 | 距離感 | 英語の相当語 | 意味 |
| :--- | :--- | :--- | :--- |
| **ini** | 話し手に近い（近称） | `this` / `these` | これ、この、現在（今） |
| **itu** | 話し手から離れている（中・遠称） | `that` / `those` / `the` | あれ、それ、あの、その |

---

## 2. 語順による役割の変化

### 2.1 文頭に置く場合：主語（指示代名詞「これは〜です」）
文頭に `Ini` や `Itu` を置くと、文全体の**主語（「これは〜」「あれは〜」）**になります。

<div class="id-example" markdown>

<div class="id-sentence">
Ini kopi Indonesia.
</div>
<div class="id-reading">
イニ コピ インドネシア
</div>
<div class="id-meaning">
これはインドネシアのコーヒーです。
</div>

</div>

- `Itu mobil baru.`（あれは新しい車です）
- `Ini siapa?`（こちらはどなたですか？）

### 2.2 名詞の後ろに置く場合：修飾語（指示形容詞「この本」「その人」）
名詞の後ろに置くと、**前にある名詞を特定・修飾する言葉（後置修飾）**になります。

<div class="id-example" markdown>

<div class="id-sentence">
Kopi ini sangat enak.
</div>
<div class="id-reading">
コピ イニ サンガッ エナッ
</div>
<div class="id-meaning">
このコーヒーはとても美味しいです。
</div>

</div>

- `mobil itu`（その車・あの車）
- `orang ini`（この人）
- `hari ini`（日 ＋ この ＝ 今日）
- `waktu itu`（時 ＋ その ＝ 当時・その時）

---

## 3. 英語の定冠詞 `the` として働く `itu`

インドネシア語には英語の `the` にあたる冠詞はありませんが、会話ですでに話題に上った特定の名詞を指す場合、名詞の後ろに `itu` を添えることで「その〜」という定冠詞のニュアンスを表します。

- `Ada kucing di taman. Kucing itu sangat lucu.`  
  （公園に猫がいます。**その（その話題の）**猫はとても可愛いです。）

---

## 4. 場所の指示詞（sini, situ, sana）

モノを指す `ini / itu` に対し、**場所（空間）を指す指示語**は3段階に分かれます。前置詞（`di`＝〜に、`ke`＝〜へ、`dari`＝〜から）と組み合わせて使います。

| 単語 | 指す場所 | 前置詞との組み合わせ | 意味 |
| :--- | :--- | :--- | :--- |
| **sini** | ここ（話し手の至近距離） | `di sini`<br>`ke sini`<br>`dari sini` | ここで・ここに<br>ここへ<br>ここから |
| **situ** | そこ（聞き手の近く・中距離） | `di situ`<br>`ke situ`<br>`dari situ` | そこに<br>そこへ<br>そこから |
| **sana** | あそこ（両者から離れた遠い場所） | `di sana`<br>`ke sana`<br>`dari sana` | あそこに<br>あそこへ<br>あそこから |

<div class="id-example" markdown>

<div class="id-sentence">
Silakan duduk di sini.
</div>
<div class="id-reading">
シラカン ドゥドゥッ ディ スィニ
</div>
<div class="id-meaning">
どうぞこちら（ここ）にお座りください。
</div>

</div>
