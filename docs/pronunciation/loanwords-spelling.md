# 外来語の綴りと発音ルール（英語・オランダ語・アラビア語起源）

インドネシアは歴史的に東西交易の十字路であり、様々な文化圏と深く交流してきました。
そのため、現代のインドネシア語の語彙には、**オランダ語、英語、アラビア語、ポルトガル語、サンスクリット語、中国語**などからの借用語（外来語＝Kata Serapan）が極めて多く取り入れられています。

外来語の「変換ルール」を知ると、一度に何百もの単語を理解・推測できるようになります。

---

## 1. 英語・オランダ語からの変換ルール（公式正書法）

インドネシア国家言語開発育成センター（Badan Bahasa）により、外来語をインドネシア語のアルファベットに適合させる標準的な変換規則（EYD）が定められています。

| 原語（英語/蘭語） | インドネシア語化 | 原語の例 | インドネシア語の単語 | 意味 |
| :--- | :--- | :--- | :--- | :--- |
| **-tion** / **-tie** | **-si** | action / natie | `aksi` / `nasional` | 行動 / 国家の |
| **-ty** / **-teit** | **-tas** | university / universiteit | `universitas` | 大学 |
| **-ism** / **-isme** | **-isme** | modernism / optimisme | `modernisme` / `optimisme` | 近代主義 / 楽天主義 |
| **-ic** / **-isch** | **-ik** / **-is** | realistic / logisch | `realistis` / `logis` | 現実的な / 論理的な |
| **c**（カ行音） | **k** | music, communication | `musik`, `komunikasi` | 音楽、通信 |
| **c**（サ行音） | **s** | central, cinema | `sentral`, `sinema` | 中央、映画 |
| **ph** | **f** | photograph, telephone | `foto`, `telepon` | 写真、電話 |
| **x** | **ks** | extra, taxi | `ekstra`, `taksi` | 追加の、タクシー |
| **y**（母音） | **i** | system, rhythm | `sistem`, `ritme` | システム、リズム |

## 2. オランダ語由来の身近な日常語

インドネシアは約350年にわたるオランダ植民地支配の歴史を経験したため、日常生活、行政、法制度、自動車関連などに大量のオランダ語が定着しています。

| インドネシア語 | オランダ語語源 | 意味 | 備考 |
| :--- | :--- | :--- | :--- |
| `kantor` | kantoor | 事務所・オフィス | 英語の office ではなく蘭語 |
| `kamar` | kamer | 部屋 | 寝室・ホテルの部屋 |
| `handuk` | handdoek | タオル | 手拭きタオル |
| `gratis` | gratis | 無料の・タダの | 街中の看板で最頻出 |
| `bensin` | benzine | ガソリン | 給油所で使う必須単語 |
| `knalpot` | knalpot | マフラー（車の排気管） | 日本語の感覚と異なる外来語 |
| `wortel` | wortel | ニンジン | 野菜の名前 |
| `kartu` | kaart | カード・切符 | 交通系ICカードなど |

## 3. ポルトガル語・アラビア語由来の単語

### 3.1 ポルトガル語由来（16世紀の大航海時代に伝来）
キリスト教や生活必需品、食品の名前が多く定着しています。

- `sepatu`（sapato＝靴）
- `keju`（queijo＝チーズ）
- `sabun`（sabão＝石鹸）
- `mentega`（manteiga＝バター）
- `gereja`（igreja＝教会）
- `meja`（mesa＝机・テーブル）

### 3.2 アラビア語由来（イスラム教や宗教・時間・知性に関する語彙）
- `selamat`（سلام salām＝安全・無事・おめでとう）
- `kabar`（خبر khabar＝知らせ・便り・ニュース）
- `waktu`（وقت waqt＝時間・時刻）
- `izin`（إذن idhn＝許可・承諾）
- `musim`（موسم mawsim＝季節・モンスーン）
- `maklum`（معلوم ma'lūm＝理解する・承知する）

## 4. 現代IT用語：英語の直輸入 vs 固有語の対立

近年はIT・インターネットの普及に伴い、英語がそのまま使われる一方で、公的な純インドネシア語（固有造語）も制定されています。

| 英語 | 日常の会話・口語 | 公式・公用語（純インドネシア語） | 意味 |
| :--- | :--- | :--- | :--- |
| download | `download`（ダウンロッド） | `unduh`（ウンドゥ） | ダウンロード |
| upload | `upload`（アップロッド） | `unggah`（ウンガ） | アップロード |
| online | `online`（オンライン） | `daring`（ダーリン: dalam jaringan） | オンライン |
| offline | `offline`（オフライン） | `luring`（ルーリン: luar jaringan） | オフライン |
| smartphone | `smartphone` / `HP`（ハーパー） | `gawai`（ガワイ） | スマートフォン・端末 |
