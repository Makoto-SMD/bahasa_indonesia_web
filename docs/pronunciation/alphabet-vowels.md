# アルファベットと基本母音（a, i, u, e, o）

インドネシア語の文字表記には、日本語のような独自の文字（ひらがな・カタカナ・漢字）はなく、英語と同じ**ラテンアルファベット（26文字）**が使用されます。

最大の特徴は、**「ほぼローマ字読みでそのまま発音できる」**という点です。英語のようにスペルと発音の不一致に悩まされることが少なく、日本人にとって最も学習しやすい言語の1つと言われる大きな理由がここにあります。

---

## 1. アルファベット26文字の読み方一覧

インドネシア語でアルファベット1文字ずつを読む時の名前（呼称）です。電話やホテルのフロントで名前のスペルを伝える際などに役立ちます。

| 文字 | インドネシア語の読み | カタカナ発音 | 備考・注意点 |
| :--- | :--- | :--- | :--- |
| **A a** | a | ア | 日本語の「ア」より少し口を大きく開ける |
| **B b** | bé | ベ | 唇をしっかり閉じて弾く |
| **C c** | cé | チェ | **「セ」ではなく「チェ」**（超重要！） |
| **D d** | dé | デ | 舌先を上の前歯の裏につけて発音 |
| **E e** | é / e | エ / 弱く「ウ」 | 2種類の発音がある（詳細は別講） |
| **F f** | èf | エフ | 上の前歯を下唇に軽く当てる |
| **G g** | gé | ゲ | 常に濁音「ガ行」（「ジ」にはならない） |
| **H h** | ha | ハ | 息をしっかり吐き出す |
| **I i** | i | イ | 日本語の「イ」と同様 |
| **J j** | jé | ジェ | 英語のJ（ジャ行）の音 |
| **K k** | ka | カ | 語尾にくると喉で音を止める促音になる |
| **L l** | èl | エル | 舌先を上の歯茎にしっかりつける |
| **M m** | èm | エム | 唇をしっかり閉じる |
| **N n** | èn | エン | 舌先を歯茎につけて鼻に抜く |
| **O o** | o | オ | 口を丸くすぼめて発音 |
| **P p** | pé | ペ | 唇を閉じて勢いよく弾く |
| **Q q** | ki | キ | 外来語・宗教用語に多い |
| **R r** | èr | エル（巻き舌） | 舌先を細かく震わせる巻き舌 |
| **S s** | ès | エス | 常に澄んだ「サ行」（「ザ」にはならない） |
| **T t** | té | テ | 舌先を歯の裏に当てて弾く |
| **U u** | u | ウ | 口を少し丸めて「ウ」 |
| **V v** | vé | フェ / ヴェ | 日常会話では F と同音になりやすい |
| **W w** | wé | ウェ | 唇を突き出して「ワ行」 |
| **X x** | èks | エクス | 外来語のみに使われる |
| **Y y** | yé | イェ | 日本語の「ヤ行」子音 |
| **Z z** | zèt | ゼット | 濁音の「ザ行」 |

> [!TIP]
> **初心者がまず覚えるべき文字「C」**:
> インドネシア語の「C」は英語のような「ク」や「ス」ではなく、**必ず「チャ・チ・チュ・チェ・チョ」**の音になります。
> 例：`cokelat`（チョコラッ＝チョコレート）、`cinta`（チンタ＝愛）。

## 2. 基本母音（A, I, U, E, O）の解説

インドネシア語には基本的に5つの母音字（A, I, U, E, O）があり、6つの母音（Eに2種類あるため）を持ちます。ここではまず基本となる5つの響きをマスターしましょう。

### 2.1 A（ア）
日本語の「ア」よりも口をしっかりと縦横に大きく開けて、クリアに発声します。

<div class="id-example" markdown>

<div class="id-sentence">
Ada apa?
</div>
<div class="id-reading">
アダ アパ
</div>
<div class="id-meaning">
何がありますか？ / どうしたの？
</div>

</div>

### 2.2 I（イ）
日本語の「イ」とほぼ同等ですが、口角を左右にやや強めに引いて発音すると自然なインドネシア語になります。

<div class="id-example" markdown>

<div class="id-sentence">
Ini ibu saya.
</div>
<div class="id-reading">
イニ イブ サヤ
</div>
<div class="id-meaning">
こちらは私の母です。
</div>

</div>

### 2.3 U（ウ）
日本語の「ウ」は唇をあまり丸めませんが、インドネシア語の「U」は**唇を前方に突き出して丸くすぼめて**発音します。

<div class="id-example" markdown>

<div class="id-sentence">
Buku itu bagus.
</div>
<div class="id-reading">
ブク イトゥ バグス
</div>
<div class="id-meaning">
その本は素晴らしいです。
</div>

</div>

### 2.4 E（エ / 曖昧母音）
E には「エ（/e/）」と「弱く曖昧なウ（/ə/）」の2種類があります。基本母音としては、まず日本語の「エ」に近い音を押さえましょう。

<div class="id-example" markdown>

<div class="id-sentence">
Enak!
</div>
<div class="id-reading">
エナッ
</div>
<div class="id-meaning">
美味しい！
</div>

</div>

### 2.5 O（オ）
日本語の「オ」よりも口を縦に大きく開けつつ、唇をしっかりと丸めて発音します。

<div class="id-example" markdown>

<div class="id-sentence">
Orang Jepang.
</div>
<div class="id-reading">
オラン ジュパン
</div>
<div class="id-meaning">
日本人。
</div>

</div>

## 3. 実践会話：名前のスペルを確認する

ホテルや空港のチェックインで、自分の名前をアルファベットで1文字ずつ伝える場面です。

  <span class="dialogue-speaker">Staff</span>
  <span>Siapa nama Anda?（お名前は何とおっしゃいますか？）</span>
</div>

- [ ] 自分の名前をインドネシア語のアルファベット読みでスペルアウトできる
- [ ] 基本母音（A, I, U, E, O）をクリアに発声できる
