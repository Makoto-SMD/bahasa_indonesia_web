# U03: 接頭辞 ter- の4大機能（無意志受動・完了状態・可能・最上級）

接頭辞 `ter-` が持つ「思わず〜してしまう（無意志）」、「すでに〜された状態にある（完了状態）」、「〜できる（可能否定）」、「もっとも〜（最上級）」という4つの重要機能の識別と文脈読解演習です。

---

## 実戦問題 (Soal Latihan)

次の下線部の `ter-` の意味・用法として最も適切なものをそれぞれ選びなさい。

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 1]</strong><br>
    Karena terburu-buru mengejar kereta pagi, dompetnya <u>tertinggal</u> di atas meja makan.
  </div>
  <div class="id-translation">
    朝の列車に急いで乗ろうとしたため、彼の財布は食卓の上に置き忘れられてしまった。
  </div>
</div>

- (A) Menyatakan paling (最上級)
- (B) Menyatakan ketidaksengajaan / spontan (無意志・偶発)
- (C) Menyatakan kesanggupan / dapat di- (可能)
- (D) Menyatakan perbuatan berulang (反復動作)

---

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 2]</strong><br>
    Tulisan dokter di resep obat itu sangat kabur sehingga <u>tidak terbaca</u> oleh pasien.
  </div>
  <div class="id-translation">
    その処方箋の医師の筆跡は非常に不鮮明で、患者には読めなかった。
  </div>
</div>

- (A) Tidak sengaja dibaca (うっかり読まれた)
- (B) Sudah selesai dibaca (読み終えられた)
- (C) Tidak dapat dibaca (読むことができない)
- (D) Paling jelas dibaca (最も明瞭に読まれた)

---

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### [Soal 1] の正答: (B) Menyatakan ketidaksengajaan / spontan (無意志・偶発)

> **文法法則: 無意志受動の `ter-`（意図せず、うっかり〜してしまう）**

- **tertinggal** は語根 **tinggal**（残る・置く）に接頭辞 `ter-` が付いた形です。
- 「故意に置いた」のではなく、「急いでいたために**うっかり置き忘れた**」という**無意志・過失・突発的事態（ketidaksengajaan）**を表します。
- 類例:
  - *terjatuh*（転ぶ・落っこちる）
  - *tertidur*（居眠りしてしまう・寝落ちする）
  - *terlupa*（うっかり失念する）
  - *terinjak*（うっかり踏んでしまう）

したがって、正解は **(B)** です。

---

### [Soal 2] の正答: (C) Tidak dapat dibaca (読むことができない)

> **文法法則: 否定詞 `tidak / belum` と呼応する「可能（dapat di-）」の `ter-`**

- `ter-` 動詞が否定詞 **tidak** や **belum**、あるいは疑問文を伴う場合、「**〜できる（dapat di-...）**」という意味になります。
  - **tidak terbaca** = *tidak dapat dibaca*（読めない、判読不能である）
  - **tidak terangkat** = *tidak dapat diangkat*（重すぎて持ち上がらない）
  - **tidak ternilai** = *tidak dapat dinilai*（計り知れない、プライスレスな）
  - **tidak tertahankan** = *tidak dapat ditahan*（耐えられない）

したがって、正解は **(C)** です。

## 接頭辞 ter- の4大機能整理テーブル (Tabel 4 Fungsi ter-)

| 機能分類 | 意味 | 例文と解説 |
| :--- | :--- | :--- |
| **1. Ketidaksengajaan (無意志・偶発)** | うっかり〜した、思わず〜された | *Kacamatanya **terinjak** oleh adik.*<br>(メガネが弟にうっかり踏まれた) |
| **2. Keadaan / Perfektif (状態・完了)** | すでに〜されている、〜してある | *Pintu kamar masih **terkunci** rapat.*<br>(部屋のドアはまだ固く施錠されている) |
| **3. Potensialitas (可能・受動能力)** | (tidak...) 〜できる / できない | *Masalah rumit ini **tidak terselesaikan**.*<br>(この複雑な問題は解決できない) |
| **4. Superlatif (最上級)** | もっとも〜である (paling) | *Ia adalah siswa **terpandai** di sekolah.*<br>(彼は学校で一番頭の良い生徒だ) |
