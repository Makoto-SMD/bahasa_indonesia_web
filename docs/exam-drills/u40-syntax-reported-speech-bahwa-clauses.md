# U40：引用節構文（bahwa節・直接話法 vs 間接話法）の代名詞・時制転換

報道記事（Berita）、公的議事録（Notula Rapat）、法廷記録、そして検定試験（UKBI・インドネシア語技能検定）の長文読解では、他者の発言や決定を報告する **直接話法（Kalimat Langsung）から間接話法（Kalimat Tak Langsung）への書き換え** が頻繁に登場します。

間接話法では、名詞節を導く接続詞 **`bahwa`**（〜ということ）が中心となりますが、直接話法から間接話法に移行する際に、**人称代名詞（saya → ia/dia/beliau）** や **指示詞・時制副詞（sekarang → saat itu / waktu itu, besok → keesokan harinya, di sini → di sana）** の転換規則を厳格に適用しなければなりません。

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### Soal 1 の解説
**正答: B**

- **B（正解＝すべての指示語が完璧に転換されている）**: 
  - 話者の一人称 `Saya`（大統領） → 敬意を込めた三人称 **`beliau`** に転換。
  - 近称の指示詞 `ini` → 遠称・既出の **`tersebut`** に転換。
  - 発話時点基準の時制副詞 `besok pagi` → 客観的時間枠 **`keesokan harinya`** に転換。
  - 発話場所基準の場所副詞 `di sini` → 伝達者の視点 **`di sana`** に転換。
  すべての要素が間接話法の公的標準ルールに厳格に従って変換されています。

- **A（誤り）**: 代名詞 `saya` や指示語 `besok pagi di sini` がそのまま残っており、間接話法として成立していません。
- **C（不適切）**: 国家元首（大統領）に対して普通三人称 `dia` を使うのは公的文体として敬意を欠きます。また `ini` や `di sini` が未転換です。
- **D（不適切）**: 意思・確定未来の助動詞 `akan` を口語的な `mau` に置き換えるのは公的文体として不適切です。

---

### Soal 2 の解説
**正答: B**

- **B（正解＝カンマなしの完全な bahwa 節）**: 
  動詞 `meragukan`（〜を疑う）の直接目的語節として接続詞 `bahwa` が直結しており、余計なカンマが一切なく完璧です。

- **A（誤り＝不要なカンマ）**: 
  英語の `that` の前と同様に、インドネシア語の接続詞 **`bahwa` の直前にカンマ（`,`）を打つのは明確な誤用** です（× `menegaskan, bahwa ...`）。
- **C（誤り＝不要なカンマ）**: 
  `menunjukkan, bahwa ...` と直前にカンマを打っているため誤りです。
- **D（誤り＝不要なカンマ）**: 
  `bahwa, telah terjadi ...` と `bahwa` の直後にカンマを打つのも誤りです。

## 直接話法から間接話法への転換対照表 (Tabel Konversi Langsung ke Tak Langsung)

| 要素 | 直接話法（Langsung） | 間接話法（Tak Langsung） |
| :--- | :--- | :--- |
| **一人称代名詞** | *saya, aku* | *ia, dia*（目上の場合は *beliau*） |
| **複数一人称** | *kami* | *mereka* |
| **近称指示詞** | *ini* | *itu, tersebut* |
| **場所指示詞** | *di sini / ke sini* | *di sana / ke sana, di tempat itu* |
| **時間副詞（今日）** | *hari ini* | *pada hari itu* |
| **時間副詞（明日）** | *besok* | *keesokan harinya, hari berikutnya* |
| **時間副詞（昨日）** | *kemarin* | *hari sebelumnya* |
| **時間副詞（今）** | *sekarang* | *saat itu, waktu itu, ketika itu* |

<details class="id-quiz">
<summary>練習問題：疑問文の直接話法から間接話法への変換（クリックで解説を表示）</summary>

**問題:**
次の直接疑問文を間接話法に直す場合、空欄に入る最も適切な接続詞は何か。
> Direktur bertanya kepada manajer: *"Apakah target kuartal ini sudah tercapai?"*
> ＝ Direktur menanyakan kepada manajer ( ... ) target kuartal tersebut sudah tercapai.

**解答・解説:**
- **解答:** **`apakah`**（または文語的に **`tentang`** を用いて `tentang pencapaian...`）
- **解説:** 
  Yes/No 疑問文を間接話法に直す場合、平叙文を導く `bahwa` は使えず、疑問接続詞 **`apakah`**（〜かどうか）をそのまま名詞節導入詞として使います（*Direktur menanyakan kepada manajer apakah target kuartal tersebut sudah tercapai.*）。決して `bahwa apakah` のように重ねてはなりません。

</details>

## まとめと検定攻略のツボ

1. **`bahwa` の前後にカンマ（`,`）を絶対に置かない**：検定の正書法・記号問題の最頻出トラップ。
2. **間接話法では時間と場所の視点を移し替える**：`besok` は `keesokan harinya`、`hari ini` は `pada hari itu`、`di sini` は `di sana` に自動変換。
3. **主語の敬称レベルを保つ**：大統領や大臣、高僧などの高位者は `dia` ではなく **`beliau`** に置き換える。
