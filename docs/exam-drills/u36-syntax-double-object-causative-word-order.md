# U36：二重目的語構文における使役動詞の語順制約

インドネシア語の授与動詞（Verba Dwirentang / Ditransitif）や使役動詞において、「誰かに何かを与える」「誰かに何かを着せる／提供する」を表す文は、**2つの目的語（Objek 1 / Objek dan Pelengkap）**をとります。

ここで学習者を最も悩ませるのが、**接尾辞 `-kan` と `-i` による語順の逆転現象**です。動詞の接辞によって「人（受益者・相手）」が先に来るのか、「物（対象）」が先に来るのか、そして前置詞（`kepada` や `dengan` など）が必要かどうかが厳密に決まっています。検定試験（UKBI・技能検定A級・B級）では、この語順混同が格好の出題ポイントとなります。

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### Soal 1 の解説
**正答: D**

- **D（正解）**: 
  - 動詞 `memberikan`（語根 `beri` ＋ 接尾辞 `-kan`）は、「**物を主たる対象（直接目的語）**」にとるため、動詞の直後に「物」が来ます。そして相手（受益者）を導くためには前置詞 **`kepada`** が必須です。
  構造: `memberikan + [物] + kepada + [人]`（*memberikan bantuan kepada masyarakat*）

- **A（誤り）**: `memberikan` の直後に「人（`masyarakat`）」を直接置くことはできません。人を直後に置くなら接頭辞・語根のみの `memberi` を使います（`Pemerintah memberi masyarakat miskin bantuan langsung tunai.`）。
- **B（文脈不適切）**: 構文としては成立しますが、「政府が妹にプレゼントを買ってあげる」という文脈的に不自然な例です。
- **C（誤り）**: 語根動詞 `memberi` を使って「物」を直後に置く場合、後続に `kepada` を伴う形よりも、前置詞なしで直接二重目的語をとる形（`memberi [人] [物]`）が本来の標準用法です。公的文書で最も美しく標準的とされるのは D の形です。

---

### Soal 2 の解説
**正答: A**

- **A（正解＝-kan と -i の完全な対照）**: 
  - (1) `menugaskan + [物/任務] + kepada + [人]`（*menugaskan tugas berat itu kepada manajer baru*）
  - (2) `menugasi + [人] + [物/任務]`（*menugasi manajer baru tugas berat itu*）
  接尾辞 **`-kan` は「物・任務」を直後**にとり（動作の対象）、接尾辞 **`-i` は「人・対象」を直後**にとる（場所・方向の着点）という規則に完璧に合致します。

- **B（誤り）**: 
  (1) は `menghadiahkan [物] kepada [人]` でなければならず、(2) は `menghadiahi [人] [物]` でなければなりません（逆になっています）。
- **C（誤り）**: 
  (2) で受益を表す場合、前置詞は `kepada`（〜へ）ではなく `untuk`（〜のために）を使うべきです（*membuatkan baju baru untuk adik*）。
- **D（誤り）**: 
  `meminjamkan` が「物を人に貸す（`meminjamkan [物] kepada [人]`）」であり、`meminjami` が「人に物を貸す（`meminjami [人] [物]`）」です。選択肢では接尾辞が逆転しています。

## 二重目的語構文の公式まとめ表 (Rumus Pola Verba Ditransitif)

| 接辞パターン | 動詞の型 | 基本構文公式 | 例文 |
| :--- | :--- | :--- | :--- |
| **接尾辞 -kan** | 物・事の移動・使役 | `[S] + [V-kan] + [物] + kepada/untuk + [人]` | *Ayah mengirimkan uang kepada nenek.*<br>*Ibu membelikan mainan untuk adik.* |
| **接尾辞 -i** | 人・場所の着点・対象化 | `[S] + [V-i] + [人] + [物]` （前置詞不要） | *Ayah mengirimi nenek uang.*<br>*Guru menugasi siswa pekerjaan rumah.* |
| **基本語根（beri）** | 直接授与 | `[S] + memberi + [人] + [物]` （前置詞不要） | *Presiden memberi atlet bonus medali.* |

**問題:**
次の2つの文の空欄に入る最も適切な語（前置詞またはなし）を選びなさい。
1. Perusahaan mengirimi klien berkas penawaran ( ... ).
2. Perusahaan mengirimkan berkas penawaran ( ... ) klien.

**解答・解説:**
- **1 の空欄: なし（前置詞不要）**
  - 動詞が `mengirimi`（接尾辞 `-i`）の場合、`klien`（人・相手）が直後に来ており、その後の `berkas penawaran`（物）との間に前置詞は不要です。
- **2 の空欄: `kepada`**
  - 動詞が `mengirimkan`（接尾辞 `-kan`）の場合、直後に `berkas penawaran`（物）が来ており、相手である `klien` の前には方向・相手を示す前置詞 **`kepada`** が必要です。

## まとめと検定攻略のツボ

1. **`-kan` の後ろは「物（Objek）」＋ 前置詞 `kepada / untuk` ＋「人」**。
2. **`-i` の後ろは「人（Objek）」＋ 前置詞なしで直接「物（Pelengkap）」**。
3. **`memberi` は直後に「人」、`memberikan` は直後に「物」**：検定の誤文訂正で最も狙われる頻出ペア。
