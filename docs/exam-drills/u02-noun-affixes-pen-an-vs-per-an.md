# U02: 名詞接辞 peN-...-an vs per-...-an の使い分け演習

語根は同じでありながら、`peN-...-an`（meN-動詞に対応する「動作・行為のプロセス」）と `per-...-an`（ber-動詞に対応する「状態・結果・集合・場所」）という決定的な意味の差異を持つ名詞派生接辞の識別演習です。

---

## 実戦問題 (Soal Latihan)

次の各文の空欄に入る最も適切な名詞を選びなさい。

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 1]</strong><br>
    Proses ______ jembatan layang itu memakan waktu dua tahun karena kendala cuaca buruk dan pembebasan lahan.
  </div>
  <div class="id-translation">
    その高架橋の建設作業プロセスは、悪天候や用地買収の障壁が原因で2年の歳月を要した。
  </div>
</div>

- (A) pembangunan
- (B) bangunan
- (C) perbangunan
- (D) pembangun

---

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 2]</strong><br>
    ______ bilateral antara Indonesia dan Jepang telah berlangsung harmonis selama lebih dari enam dekade.
  </div>
  <div class="id-translation">
    インドネシアと日本の二国間関係（友好関係）は、60年以上にわたり調和を保って継続している。
  </div>
</div>

- (A) Penghubungan
- (B) Perhubungan
- (C) Hubungan
- (D) Keterhubungan

---

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### [Soal 1] の正答: (A) pembangunan

> **文法法則: `peN-...-an` は動詞 `meN-` の「動作・プロセスの進行（プロセス名詞）」**

語根 **bangun**（建つ・起きる）から派生する名詞を比較します。
- **membangun**（建てる、建設する：他動詞）
  - → **pembangunan**（建設すること、建設作業、開発プロセス）
- **bangunan**（建物、建造物：物そのもの）
- **pembangun**（建設者、創設者：人）

文頭に **Proses**（プロセス・工程）という語があり、道路や橋梁を「建設する行為そのもの」を指しているため、**pembangunan** が唯一の正解です。

---

### [Soal 2] の正答: (C) Hubungan（または文脈により Perhubungan）

本問の文脈（二国間の友好関係・外交関係）では **(C) Hubungan** が標準的です。
派生接辞の体系を整理すると：
- **menghubungkan**（〜を繋ぐ・接続する）
  - → **penghubungan**（接続作業、連結すること：プロセス）
- **berhubungan**（関係がある、連絡を取り合う）
  - → **perhubungan**（交通・通信、運輸関係：機関・分野。例: *Kementerian Perhubungan* = 運輸省）
  - → **hubungan**（関係、間柄、つながり：抽象名詞）

国同士の友好関係は **hubungan bilateral** と言うため、正解は **(C) Hubungan** です。

## peN-...-an vs per-...-an 決定版比較表 (Tabel Perbandingan)

検定・UKBIで絶対に落とせない頻出語根ペアです。

| 語根 | meN-動詞 → peN-...-an (プロセス・行為) | ber-動詞 → per-...-an (事柄・状態・結果・集合) |
| :--- | :--- | :--- |
| **ubah** (変わる/変える) | **pengubahan** (変更する作業・改定行為) | **perubahan** (変化そのもの、変動した結果) |
| **kembang** (発展する) | **pengembangan** (開発すること、育成プロセス) | **perkembangan** (発展・進歩・進化の様子) |
| **tumbuh** (育つ) | **penumbuhan** (成長させること・促す行為) | **pertumbuhan** (成長そのもの、成長率: *pertumbuhan ekonomi*) |
| **satup** (一つになる) | **penyatuan** (統合する作業、合併のプロセス) | **persatuan** (団結、統一、結束状態: *Persatuan Indonesia*) |
| **temu** (会う) | **penemuan** (発見すること、見つけ出した成果) | **pertemuan** (会合、会議、出会い: *rapat/pertemuan*) |
| **beda** (異なる) | **pembedaan** (区別・差別する行為) | **perbedaan** (相違点、違いそのもの) |
| **janji** (約束する) | **perjanjian** (条約・協定・契約書) ※per- | （*penjanjian* という形は一般的ではない） |

## 類題トレーニング (Latihan Pengayaan)

<details class="id-quiz">
<summary>【類題】次の文の空欄に入るのはどちらですか？<br>Laju ______ ekonomi nasional diproyeksikan mencapai lima persen tahun ini. (pertumbuhan / penumbuhan)</summary>
<strong>正解: pertumbuhan</strong><br>
「経済成長（率）」という結果・状態を表す名詞は <code>pertumbuhan ekonomi</code> です。<code>penumbuhan</code> は「（政策等によって意図的に）成長させる行為」を指すため不適切です。
</details>
