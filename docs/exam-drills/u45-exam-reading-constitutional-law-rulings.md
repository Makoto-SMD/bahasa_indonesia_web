# U45：政治・法制分野の難解長文読解演習（憲法裁判所判決・法制審議）

インドネシア語技能検定の最高峰（A級・特A級）や UKBI の最上位レベルでは、**憲法裁判所（Mahkamah Konstitusi：MK）の判決文（Putusan Perkara）や法律制定・司法審査（Uji Materi / Judicial Review）に関する専門的読解問題**が出題されます。

法律文特有の重層的な修飾構文、ラテン語由来の法律格言、および「条件付き合憲（Inkonstitusional Bersyarat）」「却下（Ditolak）」と「不受理（Tidak Dapat Diterima：NO）」の厳密な法意識別をマスターしましょう。

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### Soal 1 の解説
**正答: B**

- **B（正解＝条件付き違憲の正確な解釈）**: 
  本文の主文（Amar Putusan）に `tidak mempunyai kekuatan hukum mengikat secara bersyarat, sepanjang tidak dimaknai bahwa pengawasan tersebut wajib mengikutsertakan representasi lembaga swadaya masyarakat independen` と明記されています。
  これは憲法裁判所判決の典型的な 「**条件付き違憲（Inkonstitusional Bersyarat）**」 です。条文そのものを全面破棄（Batal Mutlak）するのではなく、「独立系NGOの代表を含めると解釈されない限りは違憲（＝含めると解釈される限りにおいては合憲・有効）」という法的判断です。

- **A（事実誤認）**: `beralasan menurut hukum untuk sebagian`（一部に法的理由がある）とされており、全棄却（ditolak seluruhnya）ではありません。
- **C（事実誤認）**: 絶対的無効（batal mutlak）ではなく、解釈を付与した条件付き違憲です。
- **D（事実誤認）**: 不受理判決（NO）ではなく、本案の実質審理に進んで一部認容されています。

---

### Soal 2 の解説
**正答: B**

- **B（正解＝法律用語 a quo の定義）**: 
  インドネシアの判決文や訴状で頻出するラテン語由来の法律用語 **`a quo`** は、「当該の／問題となっている（*yang sedang dipersengketakan / yang bersangkutan*）」を意味します。したがって `pasal a quo` とは「**審理の対象となっている当該の条項**」のことです。同様に `pengadilan a quo`（当該原審裁判所）、`perkara a quo`（当該事件）などの形で多用されます。

## 政治・司法・判決文の最重要専門用語対照表

| 専門用語 | 読み・語源 | 法的意味・日本語訳 |
| :--- | :--- | :--- |
| **Amar Putusan** | アマル・プトゥサン | **判決主文**（判決の結論部分） |
| **Beralasan menurut hukum** | インドネシア語 | **法的理由がある**（原告の主張に法的な正当性がある） |
| **Inkonstitusional Bersyarat** | 憲法学用語 | **条件付き違憲**（特定の解釈の下でのみ有効性を認める） |
| **Konstitusional Bersyarat** | 憲法学用語 | **条件付き合憲** |
| **Tidak dapat diterima (NO)** | *Niet ontvankelijke verklaard* | **申立却下（門前払い）**：法的資格欠如や管轄違い |
| **Ditolak** | インドネシア語 | **請求棄却**：本案審理の結果、原告の主張を退ける |
| **Kedudukan hukum** | *Legal standing* | **原告適格**（訴えを起こす正当な当事者資格） |
| **Kaidah hukum a quo** | ラテン語借用 | **当該の法準則** |
| **Keterangan pihak terkait** | 訴訟用語 | **利害関係人の陳述** |
| **Menimbang (Konsiderans)** | 判決書式 | **〜を考慮して（判決理由の導入部）** |

## 類題トレーニング (Latihan Pengayaan)

<details class="id-quiz">
<summary>練習問題：法律用語「Ditolak」と「Tidak Dapat Diterima」の識別（クリックで解説を表示）</summary>

**問題:**
憲法裁判所における判決で、原告に当事者適格（Legal Standing）が認められなかった場合に下される主文の宣告はどれか。
1. *Menyatakan permohonan Pemohon ditolak untuk seluruhnya.*
2. *Menyatakan permohonan Pemohon tidak dapat diterima.*
3. *Menyatakan pasal a quo bertentangan dengan UUD 1945.*

**解答・解説:**
- **正答: 2**
- **解説:** 
  インドネシアの裁判実務において、形式要件（原告適格、管轄権、提訴期間など）に不備がある場合の門前払い判決は **`tidak dapat diterima`（不受理・却下：NO）** と宣告されます。実体的な憲法判断を行い原告の主張に理由がないと退ける場合は **`ditolak`（棄却）** となります。この2つの法律用語の厳格な区別は、技能検定上級の読解で頻繁に問われます。

</details>

## まとめと検定攻略のツボ

1. **判決文は `Menimbang`（理由）と `Mengadili`（主文）の2層に分かれる**：結論を急ぐ場合は `Mengadili` の直後を真っ先に確認する。
2. **`a quo` は「当該の」という意味**：*pasal a quo* は「当事案の対象条項」と自動翻訳。
3. **`tidak dapat diterima`（形式的却下）と `ditolak`（実質的棄却）を混同しない**。
