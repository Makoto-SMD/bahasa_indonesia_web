# U35：受動構文における動作主標識 oleh の必須・省略条件

インドネシア語の三人称受動態（接頭辞 **`di-`** を伴う受動文）では、動作を行う主体（Pelaku / Agent）を導く前置詞 **`oleh`**（〜によって）の扱いが問題となります。

日常会話では `Buku itu dibeli Budi.`（その本はブディによって買われた）のように `oleh` が省略されることが一般的ですが、検定試験（UKBI・技能検定）や公的標準語法（Tata Bahasa Baku Bahasa Indonesia）では、**「oleh を省略できる条件」と「oleh を絶対に省略してはならない（必須となる）条件」** が明確に規定されています。この境界線を理解していないと、構文正誤問題で手痛い失点を招きます。

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### Soal 1 の解説
**正答: B**

- **B（誤り＝oleh が必須の文で脱落）**: 
  受動動詞 `diambil` と動作主 `dewan komisaris` の間に、副詞句 **`secara sepihak`（一方的に）** が割り込んでいます。
  受動動詞の直後に動作主が密着する場合は `oleh` を省略できますが、**受動動詞と動作主の間に他の語句（副詞や修飾語句）が挟まる場合は、前置詞 `oleh` を絶対に省略してはなりません**。
  正しい形: `Keputusan kontroversial itu diambil secara sepihak OLEH dewan komisaris ...`

- **A（正しい）**: 受動動詞 `disetujui` の直後に動作主 `pimpinan instansi` が隣接しているため、`oleh` の省略が認められます。
- **C（正しい）**: 受動動詞 `diselidiki` の直後に動作主 `pihak kejaksaan agung` が隣接しています。
- **D（正しい）**: 受動動詞 `dijual` の直後に動作主 `paman` が隣接しています。

---

### Soal 2 の解説
**正答: C**

- **C（正解＝一人称受動態の正統形）**: 
  動作主が**一人称（saya, kami, aku）または二人称（kamu, Anda, kalian）**の場合、接頭辞 `di-` ではなく、**語幹受動態（Passif Persona：代名詞＋動詞語幹）**を用いなければなりません。
  `telah kami susun` は「助動詞/副詞 ＋ 代名詞 ＋ 動詞語幹（語根）」の規則に厳格に従った美しい標準形です。

- **A（誤り）**: 一人称 `saya` に対して `di- ... oleh saya` を使うのは非標準（口語的・誤用）です。正しくは `Surat perjanjian ... sudah saya tandatangani ...` です。
- **B（誤り）**: 二人称複数 `kalian` に対して `di- ... oleh kalian` を使うのは非標準です。正しくは `... harus kalian kerjakan secara mandiri.` です。
- **D（誤り）**: 二人称 `kamu` に対して `di- ... oleh kamu` を使うのは非標準です。正しくは `... telah kamu perbaiki tadi pagi.` です。

## 受動態における oleh の要否ルール一覧 (Kaidah 'oleh' dalam Kalimat Pasif)

| 条件 | 規則 | 例文（適格例） |
| :--- | :---: | :--- |
| **動詞直後に動作主が密着** | 省略可能（Manasuka） | *Surat itu dikirim (oleh) sekretaris.* |
| **動詞と動作主の間に修飾語が介在** | **必須（Wajib Hadir）** | *Surat itu dikirim kemarin **oleh** sekretaris.*<br>（× *dikirim kemarin sekretaris*） |
| **主語が文頭から遠く離れている場合** | **原則配置（Dianjurkan）** | 意味の混同を防ぐため明示する |
| **接頭辞 ter- による無意図受動** | **原則配置（Umumnya Wajib）** | *Kunci rumah terbawa **oleh** adik.* |
| **動作主が一人称・二人称** | **di- 構文自体が不可** | 代名詞＋動詞語幹（*saya baca*, *kamu tulis*）を使用 |

## まとめと検定攻略のツボ

1. **受動動詞と動作主の間に何か挟まったら必ず `oleh` を置く**：`di-... [副詞] [動作主]` は検定の誤文訂正で最も狙われる構文トラップ。
2. **動作主が私（一人称）やあなた（二人称）のときは `di- ... oleh` を使わない**：必ず `sudah saya lakukan`, `harus Anda perhatikan` の語幹受動態にする。
3. **`ter-` 受動態の動作主には `oleh` を付けるのが原則**：無意図や自発を表す文では `oleh` を補うことで主語と動作主の識別を明確にする。
