# U17: 完了アスペクト副詞 sudah vs telah のレジスター（文体差）と公的文書用法

動作や事態の完了（パーフェクティブ）を表す2大時制副詞 `sudah` と `telah` について、会話体（口語）とフォーマル文体（公文書・法令・ニュース記事）の厳格なレジスター識別、および接頭辞との結合語（sesudah vs setelah）の演習です。

---

## 実戦問題 (Soal Latihan)

次の公文書および報道文の空欄に入る最も格調高く適切な完了副詞を選びなさい。

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 1]</strong><br>
    Perjanjian kerja sama bilateral antara kedua negara sahabat ini ______ ditandatangani secara resmi oleh para menteri luar negeri di hadapan para kepala negara.
  </div>
  <div class="id-translation">
    この2つの友好国間の二国間協力協定は、両首脳の面前で各外務大臣によって公式に署名された（完了した）。
  </div>
</div>

- (A) sudah
- (B) telah
- (C) sedang
- (D) bakal

---

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 2]</strong><br>
    ______ menyelesaikan seluruh tahapan audit kepatuhan, tim auditor independen menyerahkan laporan final kepada dewan komisaris.
  </div>
  <div class="id-translation">
    コンプライアンス監査の全工程を完了させた後、独立監査人チームは最終報告書を監査役会へ提出した。
  </div>
</div>

- (A) Sesudah
- (B) Setelah
- (C) Telah
- (D) Sudah

---

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### [Soal 1] の正答: (B) telah

> **文法法則: 公的文書・条約・報道では完了副詞として `telah` が標準**

- どちらも「すでに〜した（完了）」を表しますが、**文体（レジスター）**が大きく異なります。
  - **telah** : 外交協定、法律、大統領令、裁判所の判決文、正式なニュース記事（ragam resmi / formal）で原則的に用いられます。
  - **sudah** : 日常会話、一般的な手紙、気軽なやり取り（ragam percakapan / netral）で広く使われます。
- 本問は「二国間条約の調印」という最高度にフォーマルな公的発表文脈であるため、**telah** が最も格調高く自然です。

したがって、正解は **(B) telah** です。

---

### [Soal 2] の正答: (B) Setelah

> **文法法則: 「〜した後に」を表す接続詞句「Setelah / Sesudah」**

- 文頭に置いて従属節「〜を終えた後で」を導く接続詞です。
- ビジネス文書、監査報告、ニュース記事などのフォーマル文脈では、**Setelah** が標準的です。
  - **Setelah + [動詞句], [主節]**
  - （*Sesudah* も文法的に正しいが、より日常的・口語的なニュアンスを帯びる）
- 選択肢 (C) *Telah* や (D) *Sudah* は副詞であり、文頭で従属節を導く接続詞として機能させることはできません。

したがって、正解は **(B) Setelah** です。

## sudah vs telah の対比対照テーブル (Tabel Register)

| 項目 | telah (公式文体・公文書) | sudah (一般文体・日常会話) |
| :--- | :--- | :--- |
| **文体水準** | 公式・格調高い (Ragam Resmi) | 中立・口語的 (Ragam Santai/Netral) |
| **主な使用媒体** | 法律、公的発表、学術論文、ニュース速報 | 日常対話、SNS、チャット、小説の会話文 |
| **疑問文への応答** | ❌ 単独で「*Telah.*」とは答えない | ⭕ 「*Sudah?*」「*Sudah.*」と返答可能 |
| **否定「まだ〜ない」** | *belum*（共通） | *belum*（共通） |
| **接続詞化** | **setelah** (〜の後に ※公式) | **sesudah** (〜の後に ※やや口語的) |
| **強調接語 -lah** | ❌ *telah-lah* (存在しない) | ⭕ **sudahlah** (もういいよ、済んだことだ) |

## 類題トレーニング (Latihan Pengayaan)

<details class="id-quiz">
<summary>【類題】「ご飯もう食べた？」という日常の問いかけに対して、「うん、もう食べたよ」と答える場合、最も自然なのはどれですか？<br>(A) Ya, saya telah makan.<br>(B) Ya, saya sudah makan.<br>(C) Telah, terima kasih.</summary>
<strong>正解: (B) Ya, saya sudah makan.</strong><br>
日常会話の口頭応答では <code>sudah</code> が唯一自然です。日常会話で <code>telah</code> を使うと過度に堅苦しく不自然に聞こえます。
</details>
