# U49：成句・ことわざ（Peribahasa / Ungkapan）の完全攻略演習

インドネシア語の検定試験（技能検定B級〜A級・UKBI）では、**ことわざ（Peribahasa）や慣用句・成句（Ungkapan / Idiom）** の意味を問う問題が毎年確実に一定数出題されます。

直訳しただけでは文脈の意味が全く掴めないものが多く、動植物（牛、カエル、エビ、稲穂など）や自然（水と油、雨、風）、身体部位（頭、手、耳）を用いた比喩表現のストックが合否を左右します。本演習では、検定頻出の最重要ことわざを厳選して徹底演習します。

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### Soal 1 の解説
**正答: B**

- **B（正解＝実るほど頭を垂れる稲穂かな）**: 
  - `Seperti ilmu padi, makin berisi makin merunduk`（稲穂の学問の如く、実が入るほど頭を垂れる）
  学問や地位、富を極めれば極めるほど、謙虚で慎み深い態度をとる立派な人格者を称える、インドネシアで最も有名なことわざです。ハルトノ氏の謙虚な態度を完璧に言い表しています。

- **A（誤り）**: `Seperti air di daun talas`（タロイモの葉の上の水滴）＝「定見がなく、あちこちフラフラと意見を変える優柔不断な人」。
- **C（誤り）**: `Air beriak tanda tak dalam`（波立つ水は浅い証拠）＝「浅薄な知識しかない者ほど、得意げに騒ぎ立てる」。
- **D（誤り）**: `Bagai katak dalam tempurung`（ヤシ殻の中のカエル）＝「井の中の蛙大海を知らず」。

---

### Soal 2 の解説
**正答: A**

- **A（正解＝空き樽は音が高い）**: 
  - `Tong kosong nyaring bunyinya`（空のドラム缶は大きな音を響かせる）
  中身（知識や実力）がない人間に限って、大声で自慢話をしたり偉そうに騒ぎ立てたりすることを風刺したことわざです。物静かだが奥が深い `Air tenang menghanyutkan` の対極（アントニム）として完璧に呼応します。

- **B（無関係）**: `Ada udang di balik batu`（石の裏にエビがいる）＝「言動の裏に隠された下心や企みがある」。
- **C（無関係）**: `Menepuk air di dulang terpercik muka sendiri`（たらいの水を叩けば自分の顔に跳ね返る）＝「他人の悪口を言えば、自分や身内の恥をさらすことになる（天に唾する）」。
- **D（無関係）**: `Pungguk merindukan bulan`（フクロウが月を恋しがる）＝「叶わぬ高望みをする」。

## 検定必出！最重要ことわざ・成句マスター表 (Koleksi Peribahasa Wajib)

| ことわざ（Peribahasa） | 直訳のイメージ | 実際の慣用的意味・日本語のことわざ |
| :--- | :--- | :--- |
| **Seperti ilmu padi, makin berisi makin merunduk** | 稲穂の実 | **実るほど頭を垂れる稲穂かな**（偉い人ほど謙虚） |
| **Tong kosong nyaring bunyinya** | 空の樽 | **浅瀬に仇波 / 能なしの犬ほどよく吠える** |
| **Ada udang di balik batu** | 石の裏のエビ | **下心がある・魂胆がある** |
| **Bagai pinang dibelah dua** | 2つに割ったビンロウ樹の実 | **瓜二つ**（見た目がそっくりなこと） |
| **Bagai air dengan minyak** | 水と油 | **水と油**（決して打ち解け合わない関係） |
| **Besar pasak daripada tiang** | 柱より大きな杭 | **支出が収入を上回る（赤字家計・身の丈知らず）** |
| **Gali lubang tutup lubang** | 穴を掘って穴を埋める | **借金を返すために新たな借金を重ねる自転車操業** |
| **Sudah jatuh tertimpa tangga** | 転んだ上に梯子が倒れてくる | **泣き面に蜂 / 弱り目に祟り目** |
| **Habis manis sepah dibuang** | 甘い汁を吸い尽くして搾りかすを捨てる | **用が済んだらポイ捨てする（恩知らず）** |
| **Nasi sudah menjadi bubur** | 炊いた米が既にお粥になってしまった | **覆水盆に返らず**（取り返しのつかないこと） |

## 類題トレーニング (Latihan Pengayaan)

<details class="id-quiz">
<summary>練習問題：借金返済の自転車操業を表す成句（クリックで解説を表示）</summary>

**問題:**
「給料が少ないため、クレジットカードの借金を別のカードローンで借りて返すという自転車操業を続けている」という状況を表すのに最も適したインドネシア語の成句はどれか。
1. *Besar pasak daripada tiang*
2. *Gali lubang tutup lubang*
3. *Sudah jatuh tertimpa tangga*

**解答・解説:**
- **正答: 2 (Gali lubang tutup lubang)**
- **解説:** 
  既存の穴（借金）を埋めるために別の新しい穴（借金）を掘る行為そのものを指す成句が **`gali lubang tutup lubang`** です。1の *Besar pasak daripada tiang* は「収入より支出が多いこと全般」、3は「不運が重なること」です。

</details>

## まとめと検定攻略のツボ

1. **動物と植物のことわざはイメージで覚える**：稲穂（謙虚）、カエル（世間知らず）、エビ（下心）。
2. **`Gali lubang tutup lubang` と `Besar pasak daripada tiang` は金銭問題の鉄板**。
3. **`Nasi sudah menjadi bubur`（覆水盆に返らず）**：後悔しても遅い場面で使われる。
