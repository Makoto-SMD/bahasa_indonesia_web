# U07: 接尾辞 -kan の二大用法（使役使嗾 vs 利益受益）と目的語配置

動詞接頭辞 `meN-...-kan` が表す「〜させる・移動させる（使役: kausatif）」と「〜のためにしてあげる（利益受益: benefaktif）」の文型構造と二重目的語の配置ルール演習です。

---

## 実戦問題 (Soal Latihan)

次の下線部の動詞構文の意味・機能として最も適切なものをそれぞれ選びなさい。

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 1]</strong><br>
    Ayah <u>membelikan</u> adik sebuah sepeda baru sebagai hadiah ulang tahun.
  </div>
  <div class="id-translation">
    父は弟に誕生日プレゼントとして新しい自転車を買ってあげた。
  </div>
</div>

- (A) Kausatif (membuat adik membeli sepeda / 使役)
- (B) Benefaktif (membeli sepeda untuk adik / 利益受益)
- (C) Resiprokal (saling membeli / 相互)
- (D) Lokatif (tempat membeli / 場所)

---

<div class="id-example">
  <div class="id-sentence">
    <strong>[Soal 2]</strong><br>
    Pemerintah berencana <u>menaikkan</u> tarif dasar listrik mulai bulan depan.
  </div>
  <div class="id-translation">
    政府は来月から基礎電気料金を引き上げる（高からしめる）ことを計画している。
  </div>
</div>

- (A) Benefaktif (menaikkan untuk seseorang)
- (B) Kausatif (membuat menjadi naik / 使役)
- (C) Refleksif (diri sendiri)
- (D) Komparatif (perbandingan)

---

## 正答と徹底解説 (Kunci Jawaban & Pembahasan)

### [Soal 1] の正答: (B) Benefaktif (membeli sepeda untuk adik / 利益受益)

> **文法法則: ベネファクティフ（利益受益）の文型ルール**

語根 **beli**（買う）のような本来目的語をとる動詞に `-kan` が付くと、「〜のために（untuk）」という**利益受益（benefaktif）**の意味になります。

二重目的語の語順ルール：
1. **S + V-kan + [人（受益者）] + [物]**
   - 例: *Ayah membelikan **adik** sebuah sepeda.*（父は弟に自転車を買ってやる）
2. **S + V + [物] + untuk + [人]**
   - 例: *Ayah membeli sebuah sepeda **untuk adik**.*

本問では動詞の直後に受益者である **adik（弟）** が来ており、「弟のために買ってあげた」という意味であるため、正解は **(B) Benefaktif** です。

---

### [Soal 2] の正答: (B) Kausatif (membuat menjadi naik / 使役)

> **文法法則: コウザティフ（使役）の文型ルール**

形容詞や自動詞（naik = 上がる）に `-kan` が付くと、「〜させる、〜の状態に変化させる（membuat jadi...）」という**使役（kausatif）**になります。
- **naik**（上がる）→ **menaikkan**（〜を引き上げる、上げる）
- **turun**（下がる）→ **menurunkan**（〜を下げる）
- **bersih**（清潔な）→ **membersihkan**（〜を掃除して綺麗にする）
- **hidup**（生きている・点灯している）→ **menghidupkan**（スイッチを入れて点ける）

本問は「電気料金を上がる状態にさせる（引き上げる）」という意味なので、正解は **(B) Kausatif** です。

## -kan の機能整理テーブル (Tabel Fungsi -kan)

| 機能 | 意味 | 語根の品詞 | 例文と書き換え |
| :--- | :--- | :--- | :--- |
| **1. Kausatif (使役)** | 〜させる、〜にする | 形容詞・自動詞 | *Ibu **membangunkan** anak.*<br>(母は子を起こす ＝ *membuat anak bangun*) |
| **2. Benefaktif (受益)** | 〜のために〜してあげる | 他動詞 | *Ia **membuatkan** tamu secangkir kopi.*<br>(客にコーヒーを淹れてあげる ＝ *membuat kopi untuk tamu*) |
| **3. Lokatif / Gerak (移動)** | 〜を（目的地へ）送る・動かす | 名詞・動詞 | *Ayah **memasukkan** mobil ke garasi.*<br>(父は車を車庫に入れる) |
| **4. Instrumental (道具視)** | 〜を道具・手段として使う | 名詞 | *Polisi **menembakkan** pistolnya ke udara.*<br>(警官はピストルを空に向けて撃った) |

## 類題トレーニング (Latihan Pengayaan)

<details class="id-quiz">
<summary>【類題】次の文を「untuk」を使わずに書き換えた場合、空欄に入る語順はどれですか？<br>Kakak memasak nasi goreng untuk kakek.<br>→ Kakak memasakkan ______ ______.</summary>
<strong>正解: kakek nasi goreng</strong><br>
利益受益の <code>memasakkan</code> の直後には、必ず「受益者（kakek）」を置き、その後に「物（nasi goreng）」を配置します（memasakkan kakek nasi goreng）。
</details>
