# 【瞬間作文】様態副詞・確信度（mungkin, pasti, tentu, rupanya, agaknya）

話者の確信の度合い（100%の確信から50%の推測、外見からの判断）を文に付加する様態副詞（Modal Adverbs）のドリルです。pasti / tentu（確実に）、mungkin（たぶん・おそらく）、rupanya / tampaknya（どうやら〜らしい）を瞬時に差し込みます。

## 1. 産出メカニズムと文法公式

### 確信度 100%: pasti / tentu（必ず・絶対に・もちろん）
Dia pasti datang（彼は絶対に来る）、Tentu saja（もちろんです）。

### 確信度 50%: mungkin / barangkali（たぶん・おそらく）
Mungkin dia lupa（たぶん彼は忘れたのだろう）。

### 外見・証拠からの推量: rupanya / tampaknya（どうやら〜のようだ）
Rupanya hujan sudah reda（どうやら雨は止んだようだ）、Tampaknya dia lelah（どうやら彼は疲れているようだ）。

## 3. 理解度チェッククイズ

**Q1. 「絶対に、必ず（確信度100%）」を表す副詞は？**

- 1. pasti (正解)
- 2. mungkin
- 3. barangkali
- 4. agaknya

**Q2. 「どうやら〜のようだ（状況から見て）」を表す副詞は？**

- 1. rupanya (正解)
- 2. tentunya
- 3. pastinya
- 4. pastilah

**Q3. 「たぶん、おそらく（確信度50%）」を表す最も一般的な語は？**

- 1. mungkin (正解)
- 2. pasti
- 3. tentu
- 4. mutlak
