# 【瞬間作文】接頭辞 meN- 他動詞の鼻音化と即時発話（membeli, menulis, melihat）

インドネシア語の能動他動詞を作る接頭辞「meN-」は、語根の語頭子音によって 6種類（me-, mem-, men-, meng-, meny-, menge-）に鼻音化変化します。頭で規則を計算するのではなく、語根を聞いた瞬間に正しい音で口から飛び出す反射神経を養います。

## 1. 産出メカニズムと文法公式

### 鼻音化の基本4大脱落（K, T, S, P）
語根の先頭が K, T, S, P の場合、子音が脱落して鼻音に同化します：kirim → mengirim、tulis → menulis、siram → menyiram、pakai → memakai。

### 有声子音の同化（B, D, J, G）
脱落せずに残ります：beli → membeli、dengar → mendengar、jual → menjual、goreng → menggoreng。

### 母音・H・R・L・W・Y
meng- または me- に接続：ambil → mengambil、lihat → melihat、rawat → merawat。

## 3. 理解度チェッククイズ

**Q1. 語根 tulis（書く）に meN- がついた時の正しい形は？**

- 1. menulis (正解)
- 2. mentulis
- 3. metulis
- 4. mengtulis

**Q2. 語根 kirim（送る）に meN- がついた時の正しい形は？**

- 1. mengirim (正解)
- 2. menkirim
- 3. mekirim
- 4. memkirim

**Q3. 語根 pakai（使う・着る）に meN- がついた時の正しい形は？**

- 1. memakai (正解)
- 2. mempakai

- 4. menpakai
