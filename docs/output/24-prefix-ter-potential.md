# 【瞬間作文】接頭辞 ter- の可能・不可能否定（tidak terhitung, terjangkau）

接頭辞「ter-」のもう一つの極めて重要な機能は「可能（〜できる）」、特に否定詞 tidak とセットになった「不可能（〜しきれない）」の表現です。tidak terhitung（数え切れない）、terjangkau（手が届く・手頃な）などの必須語句を反射生成します。

## 1. 産出メカニズムと文法公式

### 肯定の可能（〜できる・〜の手が届く）
terjangkau（手が届く・購入できる）、terbaca（読める・判読できる）。

### 否定の不可能（tidak / tak ter- ＝ 〜しきれない）
tidak terhitung（数え切れない）、tidak tertahankan（耐えられない）、tidak ternilai（値段がつけられないほど貴重な）、tidak terduga（予期できない）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 価格が「手頃である（手が届く）」を表す頻出語は？**

- 1. terjangkau (正解)
- 2. terhitung
- 3. terbaca
- 4. terdengar

**Q2. 「数え切れないほど多い」を表す表現は？**

- 1. tidak terhitung (正解)
- 2. tidak terbaca
- 3. tidak terduga
- 4. tidak tercapai

**Q3. 「言葉では言い表せない」を表すフレーズは？**

- 1. tidak terkatakan (正解)
- 2. tidak tertulis
- 3. tidak terdengar
- 4. tidak tercium
