# 【瞬間作文】条件節・仮定法（jika, kalau, seandainya, asalkan）の瞬時産出

現実の条件（jika / kalau: もし〜なら）から、事実と異なる仮定（seandainya / sekiranya: もしも〜だったら）、必要条件（asalkan: 〜でありさえすれば）まで、条件表現のレパートリーを瞬時に使い分けるドリルです。

## 1. 産出メカニズムと文法公式

### jika / kalau（現実的条件・もし〜なら）
Jika ada waktu, kita pergi（時間があれば行こう）。kalau は日常口語、jika は標準的。

### seandainya / andaikata（反実仮想・もしも〜だったら）
現実と異なる願望や仮定。「Seandainya saya punya sayap（もし私に翼があったなら）」。

### asalkan（条件限定・〜でさえあれば）
「Asalkan kamu jujur, saya maafkan（君が正直でありさえすれば許す）」。

## 3. 理解度チェッククイズ

**Q1. 事実と異なる「もしも〜だったら（仮定法）」を表す接続詞は？**

- 1. seandainya (正解)
- 2. jika
- 3. kalau
- 4. asalkan

**Q2. 「〜でありさえすれば」という最低限の必要条件を表す接続詞は？**

- 1. asalkan (正解)
- 2. meskipun
- 3. sehingga
- 4. karena

**Q3. 「もし時間があれば」の標準的な表現は？**

- 1. Jika ada waktu (正解)
- 2. Seandainya ada waktu
- 3. Asalkan ada waktu
- 4. Walaupun ada waktu
