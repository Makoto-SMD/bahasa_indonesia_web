# 【瞬間作文】二人称語幹受動態（Tugas ini harus kamu selesaikan）の反射出力

相手（あなた・君）に対して「あなたが〜する」という行為を、目的語を主語にして優しく促したり確認したりする表現です。「Tugas ini harus kamu kerjakan（この課題は君がやらなきゃ）」のように、二人称でも語幹受動態を用います。

## 1. 産出メカニズムと文法公式

### 二人称語幹受動態の公式
【目的物（主語） ＋ (助動詞) ＋ kamu / Anda ＋ 語幹動詞】。

### 相手への配慮・依頼のトーン
命令形「Beli ini!（これ買え）」よりも「Ini bisa kamu beli（これは君が買えるよ）」の方が柔らかく響きます。

### di- を使わない鉄則
一人称同様、❌ Ini harus dibeli oleh kamu とは言いません。Ini harus kamu beli とします。

## 3. 理解度チェッククイズ

**Q1. 「この本はあなたが読むべきだ」の正しい語幹受動態は？**

- 1. Buku ini harus Anda baca. (正解)
- 2. Buku ini harus dibaca oleh Anda.
- 3. Anda harus membaca buku ini.
- 4. Buku ini Anda dibaca.

**Q2. 二人称語幹受動態の動詞の接頭辞は？**

- 1. 接頭辞なし（語幹のみ） (正解)
- 2. di-
- 3. meN-
- 4. ter-

**Q3. 「鍵は君が持ってる？」の自然な口語語幹受動態は？**

- 1. Kuncinya kamu bawa? (正解)
- 2. Kuncinya dibawa oleh kamu?
- 3. Kamu membawa kuncinya?
- 4. Kuncinya membawakan kamu?
