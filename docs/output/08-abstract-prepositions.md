# 【瞬間作文】抽象前置詞（untuk, bagi, demi, tentang, menurut）の文脈適用

単なる場所移動にとどまらず、目的・対象・観点・根拠などの論理関係を構築する抽象前置詞のパターンドリルです。論文やビジネス実務で必須の思考ツールを瞬時に口から出せるようにします。

## 1. 産出メカニズムと文法公式

### untuk vs bagi（目的と対象）
untuk は「〜のための（目的・用途）」、bagi は「〜にとって（評価の対象者）」を明快に区別します。

### demi（献身・理由）
「〜のために（国のため、正義のため、子供の未来のため）」という崇高な目的や大義名分。

### tentang vs menurut（話題と情報源）
tentang は「〜について（話題）」、menurut は「〜によれば（観点・情報源）」を表します。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「〜によれば（情報源）」を表す前置詞は？**

- 1. menurut (正解)
- 2. tentang
- 3. untuk
- 4. bagi

**Q2. 「私にとって（評価）」を表す最も自然な語句は？**

- 1. Bagi saya (正解)
- 2. Demi saya
- 3. Tentang saya
- 4. Untuk saya

**Q3. 「国のために（大義名分）」を表す前置詞は？ ___ tanah air**

- 1. demi (正解)
- 2. tentang
- 3. menurut
- 4. bagi
