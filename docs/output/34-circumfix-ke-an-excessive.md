# 【瞬間作文】周囲辞 ke-...-an の過度形容詞用法（kemanisan, kebesaran）

周囲辞「ke-...-an」の3つ目の機能は、形容詞を挟んで「あまりにも〜すぎる（過度・超過）」を表す用法です。terlalu manis（甘すぎる）を1語で「kemanisan」、terlalu besar（大きすぎる）を「kebesaran」とスマートに表現する口頭反射を鍛えます。

## 1. 産出メカニズムと文法公式

### 形容詞 ＋ ke-...-an ＝ 過度（〜すぎる）
kemanisan（甘すぎる：manis）、keasinan（塩辛すぎる：asin）、kebesaran（大きすぎる：besar）、kekecilan（小さすぎる：kecil）、kemahalan（高すぎる：mahal）。

### 日常会話での頻度
レストランでの味の感想や、試着室でのサイズ確認でネイティブが最も好んで使う言い回しです。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 料理を味見して「甘すぎる」と言う時の1単語は？**

- 1. kemanisan (正解)
- 2. memaniskan
- 3. kemanisan-an
- 4. termanis

**Q2. 試着して「サイズが大きすぎる」と言う時の表現は？**

- 1. kebesaran (正解)
- 2. membesarkan
- 3. terbesar
- 4. sebesar

**Q3. スープが「塩辛すぎる」と言う時の単語は？**

- 1. keasinan (正解)
- 2. memasinkan
- 3. asin-asin
- 4. paling asin
