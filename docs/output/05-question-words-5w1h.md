# 【瞬間作文】疑問詞（apa, siapa, di mana, kapan, kenapa, bagaimana）の即座疑問文

疑問詞を使った問いかけはコミュニケーションの起点です。語順（文頭に置くか文末に置くか）と助詞 -kah によるフォーマル化の即時判断をトレーニングします。

## 1. 産出メカニズムと文法公式

### 基本疑問詞 6選
apa（何）、siapa（誰）、di mana（どこ）、kapan（いつ）、kenapa / mengapa（なぜ）、bagaimana（どうやって・どんな）。

### 語順の柔軟性
日常会話では疑問詞を文末に置くことも非常に自然です（Mau makan apa? / Tinggal di mana?）。文頭に置く場合は焦点化されます。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「お名前は何ですか？」の正しいインドネシア語は？**

- 1. Siapa nama Anda? (正解)
- 2. Apa nama Anda?
- 3. Di mana nama Anda?
- 4. Bagaimana nama Anda?

**Q2. 「どうやってそこに行きますか？」の疑問詞は？**

- 1. Bagaimana (正解)
- 2. Kapan
- 3. Kenapa
- 4. Berapa

**Q3. 「どちら（どれ）が好きですか？」の疑問詞句は？**

- 1. Yang mana (正解)
- 2. Di mana
- 3. Ke mana
- 4. Dari mana
