# 【瞬間作文】結果節（sehingga, akibatnya, sampai-sampai）の即時産出

原因を受けて「その結果〜になった」「あまりに…なので〜するほどだ」と帰結を導く結果節（Result）のドリルです。sehingga（その結果）、akibatnya（結果として・悪影響）、sampai-sampai（〜するほどだ）、makanya（口語：だから〜なのだ）を反射出力します。

## 1. 産出メカニズムと文法公式

### sehingga（中立的・論理的結果：その結果〜）
原因節 ＋ sehingga ＋ 結果節。「Dia belajar keras sehingga lulus（勉強したので合格した）」。

### akibatnya（否定的な帰結・結果として）
事故や過失による悪影響を導く。「Dia ceroboh, akibatnya dompetnya hilang（不注意だったので結果として財布を失くした）」。

### sampai-sampai（度合いの極限・〜するほど）
「あまりに…で、〜するほどだった」。「Sangat lucu sampai-sampai saya menangis（面白すぎて涙が出るほどだった）」。

### makanya（口語：だから言ったでしょ・だから〜なのだ）
Makanya jangan terlambat!（だから遅刻するなと言ったのに！）

## 3. 理解度チェッククイズ

**Q1. 「その結果〜になった（標準的）」を導く接続詞は？**

- 1. sehingga (正解)
- 2. karena
- 3. agar
- 4. meskipun

**Q2. 不注意などによる「悪い結果として〜」を表す副詞は？**

- 1. akibatnya (正解)
- 2. untungnya
- 3. akhirnya
- 4. rupanya

**Q3. 「〜するほど極端だった」を表す結果構文は？**

- 1. sampai-sampai (正解)
- 2. kira-kira
- 3. kadang-kadang
- 4. lama-lama
