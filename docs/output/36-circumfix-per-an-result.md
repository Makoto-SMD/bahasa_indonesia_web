# 【瞬間作文】周囲辞 per-...-an の状態・集約名詞化（perjanjian, perjalanan）

周囲辞「per-...-an」は、自動詞 ber- に対応し、「行為の結果・状態・制度・集約された場所（〜契約、旅路、集合体）」を名詞化します。peN-...-an が動的な「プロセス」であるのに対し、per-...-an は静的な「フレーム・結果」を提示します。

## 1. 産出メカニズムと文法公式

### ber- 自動詞に対応する名詞化
berjalan → perjalanan（旅路・道程）、berjanji → perjanjian（約束・条約・契約）、bertemu → pertemuan（会合・面会）。

### 名詞語根 ＋ per-...-an（場所・集合・制度）
hotel → perhotelan（ホテル業界）、air → perairan（水域・海域）、kota → perkotaan（都市部）、toko → pertokoan（商店街）。

- 3. keperjanjian
- 4. janjian

- 3. kehotelan
