# 【瞬間作文】接尾辞 -kan の使役構文（membersihkan, membesarkan）

接尾辞「-kan」の最も中心的な機能が「使役（〜に…させる、〜を…の状態にする）」です。形容詞や動詞の語根に -kan をつけることで、他動詞として対象をその状態へ導く表現を瞬時に組み立てます。

## 1. 産出メカニズムと文法公式

### 形容詞語根 ＋ -kan（〜の状態にする）
bersih（清潔な）→ membersihkan（掃除する・清潔にする）、besar（大きい）→ membesarkan（大きくする・育てる）、panas（熱い）→ memanaskan（温める）。

### 自動詞語根 ＋ -kan（〜を行動させる・行かせる）
masuk（入る）→ memasukkan（中に入れる）、bangun（起きる）→ membangunkan（起こす）、turun（下りる）→ menurunkan（降ろす）。

## 3. 理解度チェッククイズ

**Q1. 形容詞 bersih（清潔な）に -kan をつけて「掃除する」にする動詞は？**

- 1. membersihkan (正解)
- 2. berbersih
- 3. terbersih
- 4. kebersihan

**Q2. 「私を降ろしてください」の命令形動詞は？**

- 1. Turunkan saya (正解)
- 2. Naikkan saya
- 3. Masukkkan saya
- 4. Bangunkan saya

**Q3. 「音量を小さくする」を表す動詞は？**

- 1. mengecilkan (正解)
- 2. membesarkan
- 3. memanaskan
- 4. menjauhkkan
