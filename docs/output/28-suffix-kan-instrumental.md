# 【瞬間作文】接尾辞 -kan の道具・対象移動構文（melemparkan batu）

接尾辞「-kan」の3番目の機能は「道具・対象の移動（目的語そのものをどこかへ移動・投擲・接触させる）」です。「石を投げる（melemparkan batu）」や「荷物を車に積む（memasukkan barang）」など、空間的な運動を表す表現を瞬時に出力します。

## 1. 産出メカニズムと文法公式

### 移動・投擲の -kan
melemparkan batu（石を投げる：batuが移動する）、menerbangkan layang-layang（凧を飛ばす）。

### -i との決定的対比
melemparkan batu ke anjing（石を犬に向かって投げる：移動するのは石） vs melempari anjing dengan batu（犬に石を投げつける：動作の対象・場所は犬）。

## 3. 理解度チェッククイズ

**Q1. 「石を投げる（石が移動する）」を表す文は？**

- 1. Dia melemparkan batu. (正解)
- 2. Dia melempari batu.
- 3. Dia berlempar batu.
- 4. Dia terlempar batu.

**Q2. 「凧を空へ飛ばす」の正しい動詞は？**

- 1. menerbangkan (正解)
- 2. menerbangi
- 3. berterbang
- 4. deterbangkan

**Q3. 「荷物を車に積み込む（移動させる）」の動詞は？**

- 1. memasukkan (正解)
- 2. memasuki
- 3. bermasuk
- 4. termasuk
