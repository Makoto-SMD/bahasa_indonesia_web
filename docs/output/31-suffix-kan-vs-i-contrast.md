# 【瞬間作文】接尾辞 -kan と -i の対比瞬間産出（menugaskan vs menugasi）

接尾辞「-kan」と「-i」は、同一の語根から異なる構文構造を生み出すインドネシア語の最難関ポイントです。目的語が「移動するもの（-kan）」なのか、「作用を受ける対象・場所（-i）」なのかを0.5秒で見極め、正しく使い分けるドリルです。

## 1. 産出メカニズムと文法公式

### 対象移動の -kan vs 場所・対象の -i
melemparkan batu ke anjing（犬に石を投げる：batuが移動） vs melempari anjing dengan batu（犬に石を投げつける：anjingが対象）。

### 使役の -kan vs 場所付与の -i
menugaskan pekerjaan kepada staf（仕事をスタッフに割り振る） vs menugasi staf dengan pekerjaan（スタッフに仕事を割り振る）。

### 感情の -kan（使役） vs 感情の -i（直接対象）
menakutkan（怖がらせる・恐ろしい） vs menakuti（脅す・怖がらせる対象に迫る）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

## 3. 理解度チェッククイズ

**Q1. 「石を投げる（石が移動する）」文は？**

- 1. Dia melemparkan batu. (正解)
- 2. Dia melempari batu.
- 3. Dia berlempar batu.
- 4. Dia terlempar batu.

**Q2. 「犬に石を投げつける（犬が直接目的語）」文は？**

- 1. Dia melempari anjing dengan batu. (正解)
- 2. Dia melemparkan anjing dengan batu.
- 3. Dia terlempar anjing.
- 4. Dia berlempar anjing.

**Q3. 「友達にプレゼントをあげる（友達が直接目的語）」は？**

- 1. menghadiahi teman (正解)
- 2. menghadiahkan teman
- 3. berhadiah teman
- 4. terhadiah teman
