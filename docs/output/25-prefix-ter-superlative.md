# 【瞬間作文】接頭辞 ter- の最上級表現の瞬間生成（terbaik, terbesar）

形容詞の語頭に接頭辞「ter-」をつけると、「最も〜（最上級）」を1単語でエレガントに表現できます。paling besar よりも簡潔で格調高い terbaik, terbesar, tertinggi などを反射出力します。

## 1. 産出メカニズムと文法公式

### ter- ＋ 形容詞 ＝ 最上級
terbaik（最高・一番良い）、terbesar（最大）、terkecil（最小）、tertinggi（最高度・最高峰）、termahal（最も高価な）、termurah（最も安価な）。

### 修飾位置の原則
名詞の「後ろ」に置きます。produk terbaik（最高の製品）、gunung tertinggi（最も高い山）。

## 3. 理解度チェッククイズ

**Q1. 「最高の、最も良い」を表す接頭辞 ter- の単語は？**

- 1. terbaik (正解)
- 2. terbagus
- 3. terindah
- 4. tercocok

**Q2. 「最も近い病院」の語順は？**

- 1. rumah sakit terdekat (正解)
- 2. terdekat rumah sakit
- 3. rumah terdekat sakit
- 4. sakit terdekat rumah

**Q3. 「最新のニュース」の表現は？**

- 1. berita terkini (正解)
- 2. berita terlama
- 3. berita termurah
- 4. berita terluas
