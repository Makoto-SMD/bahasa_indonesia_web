# 【瞬間作文】周囲辞 ke-...-an の名詞化の瞬間生成（kesehatan, kebebasan）

周囲辞「ke-...-an」は、形容詞や動詞を抽象名詞（〜性、〜であること、状態）に転換する最も重要な造語法です。sehat（健康な）→ kesehatan（健康）、bebas（自由な）→ kebebasan（自由）など、抽象概念を瞬時に名詞化して主語や目的語に据えるドリルです。

## 1. 産出メカニズムと文法公式

### 形容詞 ＋ ke-...-an（抽象的性質・状態）
sehat → kesehatan（健康）、bersih → kebersihan（清潔）、indah → keindahan（美しさ）、adil → keadilan（正義・公平）、nyata → kenyataan（現実）。

### 動詞・名詞 ＋ ke-...-an（領域・概念）
hidup → kehidupan（生活・生命）、anggota → keanggotaan（会員資格）、pulau → kepulauan（諸島・列島）。
