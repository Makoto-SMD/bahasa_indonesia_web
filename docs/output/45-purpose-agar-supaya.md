# 【瞬間作文】目的節（agar, supaya, untuk）による論理的表現の瞬間生成

「〜するために」「〜になるように」という目的節（Purpose）は、理由と並んで日常・ビジネスの会話で頻出します。agar, supaya, untuk, biar（口語）の自然な配置と動詞句の接続を反射化します。

## 1. 産出メカニズムと文法公式

### agar / supaya ＋ [文]（主語 ＋ 述語）
主語を明示して「〜が…できるように」と導く。「Agar anak-anak sehat（子供たちが健康であるように）」。

### untuk ＋ [動詞/名詞]（目的）
動詞の原形や名詞に直結して「〜するために」。「Untuk belajar（勉強するために）」。

### 口語の biar（〜するように・〜させるために）
会話で大人気の「biar cepat（早く済むように）」「biar tahu（知っておくように）」。

## 3. 理解度チェッククイズ

**Q1. 「〜できるように（目的）」を導く標準的接続詞は？**

- 1. agar (正解)
- 2. sehingga
- 3. karena
- 4. sebab

**Q2. 日常会話で「〜なように（手っ取り早く）」を意味する口語接続詞は？**

- 1. biar (正解)
- 2. agar
- 3. untuk
- 4. oleh

**Q3. 「忘れないように」を表すフレーズは？**

- 1. supaya tidak lupa (正解)
- 2. karena tidak lupa
- 3. sehingga tidak lupa
- 4. walaupun tidak lupa
