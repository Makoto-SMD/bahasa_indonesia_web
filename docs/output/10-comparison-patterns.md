# 【瞬間作文】比較級・最上級・同等比較（lebih, paling, ter-, sama...dengan）

物事の性質や度合いを比べる表現は、日常会話や商談で頻出します。「lebih（より〜）」「paling / ter-（最も〜）」「sama ... dengan（〜と同じくらい）」の基本型を即座に組み立てるドリルです。

## 1. 産出メカニズムと文法公式

### 比較級: lebih ＋ 形容詞 ＋ daripada
「A lebih besar daripada B（AはBより大きい）」。daripada は dari と略されることもあります。

### 最上級: paling ＋ 形容詞 / ter- ＋ 形容詞
paling murah / termurah（最も安い）、paling tinggi / tertinggi（最も高い）。

### 同等比較: sama ＋ 形容詞 ＋ nya ＋ dengan / se- ＋ 形容詞
sama tingginya dengan dia（彼と同じ高さ）、setinggi dia（彼と同じ高さ）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「AはBより大きい」の正しい構文は？**

- 1. A lebih besar daripada B. (正解)
- 2. A paling besar daripada B.
- 3. A sama besar daripada B.
- 4. A ter-besar daripada B.

**Q2. 「一番安い」を表す単語は？**

- 1. termurah (正解)
- 2. se-murah
- 3. lebih murah
- 4. sama murah

**Q3. 「彼と同じくらい背が高い」を表す同等比較は？**

- 1. setinggi dia (正解)
- 2. lebih tinggi dia
- 3. paling tinggi dia
- 4. daripada tinggi dia
