# 【瞬間作文】peN-...-an と per-...-an の使い分け対比ドリル（pemeriksaan vs periksaan）

同一の語根から peN-...-an（動作・能動プロセス）と per-...-an（結果・制度・場所）の両方が派生するペアは、検定上級や公的文書で最も差がつく領域です。「検査する行為（pemeriksaan）」と「検査結果/尋問調書（periksaan）」のように、文脈に応じた即時選択を鍛えます。

## 1. 産出メカニズムと文法公式

### 動作プロセス（peN-...-an） vs 結果・制度（per-...-an）
penyatuan（統一する行為・統合プロセス） vs persatuan（団結・統一状態・連合体）。

### pembentukan（設立する作業） vs perbentukan（形態・体制）
pengaturan（規則を整理する作業・調整） vs peraturan（定められた規則・ルールそのもの）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。
