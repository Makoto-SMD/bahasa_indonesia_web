# 【瞬間作文】周囲辞 peN-...-an の動作・過程名詞化（pembangunan, pengembangan）

周囲辞「peN-...-an」は、能動他動詞 meN- に対応し、「動作のプロセス・過程・行為そのもの（〜すること・建設・開発・調査）」を名詞化します。ニュース報道や学術論文で必ず主語・目的語になる重要名詞を反射的に生成します。

## 1. 産出メカニズムと文法公式

### meN- の鼻音化と完全一致
語頭変化は meN- と同じ規則をたどります：bangun → membangun → pembangunan（建設）、kembang → mengembangkan → pengembangan（開発）、tulis → menulis → penulisan（執筆）。

### 「動作・過程（Process）」を表す
pembangunan（建設すること・建設工事）、pemeriksaan（検査すること・検査手続き）。per-...-an が「結果・状態」を表すのと対照的です。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

**Q1. 動詞 membangun（建設する）に対応する名詞「建設（プロセス）」は？**

- 1. pembangunan (正解)
- 2. perbangunan
- 3. kebangunan
- 4. terbangun

**Q2. 動詞 mengirim（送る）に対応する名詞「配送・送付」は？**

- 1. pengiriman (正解)
- 2. perkiriman
- 3. kekiriman
- 4. kiriman

**Q3. 動詞 menyelesaikan（解決する）に対応する名詞「解決プロセス」は？**

- 1. penyelesaian (正解)
- 2. perselesaian
- 3. keselesaian
- 4. selesaian
