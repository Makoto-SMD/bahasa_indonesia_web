# 【瞬間作文】譲歩節（meskipun, walaupun, sungguhpun）による複文構築

「〜にもかかわらず」「たとえ〜だとしても」という譲歩（Concession）は、相手の意見を受け止めつつ自分の主張を通す大人の会話に不可欠です。meskipun, walaupun, kendatipun を使った滑らかな論理展開をトレーニングします。

## 1. 産出メカニズムと文法公式

### 譲歩の主要接続詞
meskipun（〜だけれども）、walaupun（〜にもかかわらず）、kendatipun（格式高い譲歩：たとえ〜でも）、sungguhpun（文語的譲歩）。

### 主節の namun / tetapi / tetap との呼応
「Meskipun [譲歩節], [主語] tetap [述語]（〜だけれど、依然として…だ）」。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「〜にもかかわらず（譲歩）」を表す接続詞ペアは？**

- 1. meskipun / walaupun (正解)
- 2. karena / sebab
- 3. sehingga / akibatnya
- 4. supaya / agar

**Q2. 「雨だけれど、依然として行く」の呼応副詞は？ Meskipun hujan, kita ___ pergi.**

- 1. tetap (正解)
- 2. sudah
- 3. belum
- 4. sedang

**Q3. 文語的・格式の高い譲歩接続詞は？**

- 1. kendatipun (正解)
- 2. soalnya
- 3. kalo
- 4. abisnya
