# 【瞬間作文】三人称 di- 受動態の瞬間組み立て（Diperiksa oleh dokter）

インドネシア語の受動態は、三人称（彼、彼女、彼ら、人名、物）が動作主の場合に接頭辞「di-」を使います。客観的な事実報道やビジネス文書の主役である di- 受動態を反射的に組み立てるドリルです。

## 1. 産出メカニズムと文法公式

### di- 構文の公式
【被行為者（主語） ＋ di-動詞 ＋ (oleh) ＋ 動作主（三人称）】。oleh は動作主が動詞の直後に来る場合は省略可能です。

### 動作主の制限
di- は原則として「三人称」のみに適用されます。一人称（saya）や二人称（kamu）には語幹受動態を使います。

### アスペクトの位置
sudah, belum, akan などの副詞は必ず di-動詞の「前」に置きます（Sudah diperbaiki）。

## 3. 理解度チェッククイズ

**Q1. 接頭辞 di- を使った受動態の動作主として文法的に正しいのは？**

- 1. 三人称（dokter, mereka, dia） (正解)
- 2. 一人称（saya）
- 3. 二人称（kamu, Anda）
- 4. 常に省略しなければならない

**Q2. 「その本は彼によって読まれた」の正しい文は？**

- 1. Buku itu dibaca oleh dia. (正解)
- 2. Buku itu saya dibaca.
- 3. Buku itu kamu dibaca.
- 4. Buku itu membaca dia.

**Q3. 「会議は延期された」の受動態は？**

- 1. Rapat ditunda. (正解)
- 2. Rapat menunda.
- 3. Rapat bertunda.
- 4. Rapat tertunda.
