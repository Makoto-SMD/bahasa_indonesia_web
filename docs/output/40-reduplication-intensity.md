# 【瞬間作文】重複語の強調・度合い表現（cepat-cepat, pagi-pagi, mati-matian）

形容詞や副詞を繰り返すことで、「非常に〜」「急いで〜」「徹底的に〜」という強烈な度合いや真剣味を表現できます。cepat-cepat（急いで）、pagi-pagi（朝早くに）、mati-matian（死に物狂いで）など、感情のこもった発話を瞬時に繰り出します。

## 1. 産出メカニズムと文法公式

### 形容詞・副詞の単純重複（度合いの強調）
cepat-cepat（大急ぎで）、pagi-pagi（朝早くから）、kecil-kecil（小さいくせに・小柄なのに）、diam-diam（こっそりと・密かに）。

### 重複 ＋ 接尾辞 -an（極限・徹底の強調）
mati-matian（死に物狂いで・必死に）、habis-habisan（徹底的に・全力を尽くして）、gila-gilaan（狂ったように・破天荒に）。

> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。
