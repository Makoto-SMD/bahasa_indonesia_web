# 【瞬間作文】定型チャンク（pada dasarnya, setahu saya, tidak heran jika）の反射発話

単語を1つずつ組み立てるのではなく、頭にストックした完成された定型表現（Formulaic Chunks）をそのままブロックとして繰り出すことで、発話の流暢性（Fluency）とネイティブらしさが爆発的に高まります。「pada dasarnya（基本的には）」「setahu saya（私の知る限り）」を瞬時に引き出します。

## 1. 産出メカニズムと文法公式

### 視点・前提のチャンク
pada dasarnya（基本的には・原理的には）、pada kenyataannya（実際には）、setahu saya（私の知る限りでは）、menurut saya（私の考えでは）。

### 評語・接続のチャンク
tidak heran jika（〜なのも不思議ではない・当然だ）、seperti yang kita ketahui（ご存知の通り）、dengan kata lain（言い換えれば）、mau tidak mau（嫌でも・否応なく）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。
