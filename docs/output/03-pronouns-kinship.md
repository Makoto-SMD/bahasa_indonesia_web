# 【瞬間作文】親称代名詞（Anda, Bapak, Ibu, Mas, Mbak）の適切な使い分け

インドネシア語には英語の「you」に当たる単純な単一語がありません。相手の社会的地位、年齢、性別、親密さに応じて敬称・親称を自然に切り替える必要があります。失礼にならず、かつ親密な距離感を瞬時に選択するドリルです。

## 1. 産出メカニズムと文法公式

### Bapak / Ibu（最上級の敬意・公の場）
成人男性には Bapak（Pak）、成人女性には Ibu（Bu）。目上、顧客、上司、公式な場での標準二人称。

### Mas / Mbak（親密な同世代・サービス店）
ジャワ発祥で全国に定着。若い男性・同世代には Mas、若い女性には Mbak。カフェ、屋台、同僚間での必須呼称。

### Anda（公的・距離のある改まった二人称）
広告、アナウンス、初対面の距離を置いた場。日常会話で多用すると冷たい印象を与えるので注意。

## 3. 理解度チェッククイズ

- 1. Mas (正解)
- 2. Anda
- 3. Kamu
- 4. Tuan

**Q2. 商談相手の40代男性社長に「あなた」と呼びかける自然な表現は？**

- 1. Bapak (正解)
- 2. Anda
- 3. Kamu
- 4. Saudara

**Q3. 女性の同僚（年上・同世代）への親しみやすい呼びかけは？**

- 1. Mbak (正解)
- 2. Nyonya
- 3. Ibu guru
