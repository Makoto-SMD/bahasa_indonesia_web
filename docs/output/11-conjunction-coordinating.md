# 【瞬間作文】等位接続詞（dan, atau, tetapi, melainkan）の論理接続

単語や文を対等に結ぶ等位接続詞は、会話の展開を支える骨格です。特に「逆接」において、肯定文を受ける tetapi と、否定文を受ける melainkan（〜ではなくて…だ）の決定的な違いを0.5秒で使い分ける反射神経を鍛えます。

## 1. 産出メカニズムと文法公式

### dan（並列・〜と） / atau（選択・または）
Saya dan dia（私と彼）、teh atau kopi（お茶またはコーヒー）。

### tetapi / tapi（逆接・しかし）
肯定の内容に反する事態を接続。「Dia kaya, tetapi tidak sombong（彼は裕福だが傲慢ではない）」。

### melainkan（対比逆接・〜ではなくて）
否定詞 bukan / tidak の後に続き、「AではなくてBだ」と訂正する。「Bukan dia yang salah, melainkan saya（彼が悪いのではなく私が悪い）」。

## 3. 理解度チェッククイズ

**Q1. 「AではなくB」の構文で空欄に入るのは？ Bukan dia, ___ saya.**

- 1. melainkan (正解)
- 2. tetapi
- 3. dan
- 4. atau

**Q2. 「〜または…」を表す接続詞は？**

- 1. atau (正解)
- 2. dan
- 3. tetapi
- 4. karena

**Q3. 「彼は背が高いが力は弱い」の接続詞は？**

- 1. tetapi (正解)
- 2. melainkan
- 3. atau
- 4. sehingga
