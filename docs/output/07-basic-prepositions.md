# 【瞬間作文】前置詞（di, ke, dari, pada, kepada）の場所・方向マッピング

場所と移動を表す基本前置詞は「di（静止・場所）」「ke（方向・目的地）」「dari（起点・出所）」の3本柱です。これに人物や時間を対象とする「pada」「kepada」を加えた正確な使い分けを反射化します。

## 1. 産出メカニズムと文法公式

### 空間の3大前置詞
di Jakarta（ジャカルタで）、ke kantor（オフィスへ）、dari stasiun（駅から）。

### pada vs kepada の厳格な使い分け
pada は「時（pada jam 9）」または「物・機関（pada dokumen）」に接続。kepada は「人への伝達・送付（surat kepada Bapak）」に接続します。

## 3. 理解度チェッククイズ

**Q1. 人に対して手紙を送る際の「〜へ」は？ kirim surat ___ Ibu.**

- 1. kepada (正解)
- 2. ke
- 3. pada
- 4. di

**Q2. 「午前8時に」を表す前置詞は？ ___ pukul 08.00**

- 1. pada (正解)
- 2. di
- 3. ke
- 4. kepada

**Q3. 「駅へ行く」を表す前置詞は？ pergi ___ stasiun**

- 1. ke (正解)
- 2. di
- 3. dari
- 4. pada
