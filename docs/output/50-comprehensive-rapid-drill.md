# 【総合口頭作文】実戦スピード作文テスト：全文法パターン50本連続ノック

セクション25の集大成として、基本語順から接辞、語幹受動態、複文、クッション言葉、定型チャンクに至るまで、全50の重要構文を網羅した実戦総合ノックです。1問につき1〜2秒以内の即時産出で、頭の中に構築されたインドネシア語の自動化回路を総テストします。

## 1. 産出メカニズムと文法公式

### テストのルール
日本語の刺激を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。ためらわずに口から音を出す反射神経を測定します。

### 合格基準
全50問中、40問以上が即座に正しく発話できれば「SLA自動化レベル達成（B1/B2実戦運用可能）」と認定されます。

**Q1. 瞬間作文で最も重要な学習態度は？**

- 1. 文法を紙に書いてからゆっくり話す
- 2. 1〜2秒以内に即座に口頭で発声して自動化する (正解)
- 3. 辞書を引いて珍しい単語を探す
- 4. 黙読だけで満足する

- 1. Buku itu sudah saya baca. (正解)
- 2. Buku itu dibaca oleh saya.
- 3. Saya sudah membaca buku itu.
- 4. Buku itu membaca saya.

**Q3. 「〜なのも不思議ではない（当然だ）」の定型チャンクは？**

- 1. Tidak heran jika (正解)
- 2. Pada dasarnya
- 3. Dengan kata lain
- 4. Setahu saya
