# 【瞬間作文】基本語順（SVO）と名詞修飾（DM則）の即時産出

インドネシア語の骨格は「SVO語順」と「後置修飾（DMの法則）」です。日本語の「SOV（主語・目的語・動詞）」および「前置修飾」の発想を頭の中で瞬時に反転させ、1秒以内に文を口から出す反射神経を鍛えます。

## 1. 産出メカニズムと文法公式

### SVOの原則
主語（S）＋ 動詞（V）＋ 目的語（O）の順。英語と同様の語順ですが、be動詞が不要なため、名詞・形容詞を直接置くだけで述語になります。

### DMの法則（Hukum D-M）
Diterangkan（修飾される主名詞）が先、Menerangkan（説明する語）が後。「赤い車」は mobil merah、「私の本」は buku saya、「新しい家」は rumah baru となります。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

**日本語**: 「**私はコーヒーを飲みます。**」

<div class="id-sentence">

</div>
<div class="id-reading">

</div>
<div class="id-meaning">

</div>

## 3. 理解度チェッククイズ

**Q1. 「私の白い猫」の正しいインドネシア語順は？**

- 1. kucing putih saya (正解)
- 2. saya putih kucing
- 3. putih kucing saya
- 4. kucing saya putih

**Q2. 「私は甘い紅茶を飲む」をSVOで組み立てると？**

- 1. Saya minum teh manis. (正解)
- 2. Saya teh manis minum.
- 3. Minum saya teh manis.
- 4. Teh manis saya minum.

**Q3. 「あの古い車」の正しい表現は？**

- 1. mobil tua itu (正解)
- 2. tua mobil itu
- 3. itu mobil tua
- 4. mobil itu tua
