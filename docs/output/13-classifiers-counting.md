# 【瞬間作文】助数詞（orang, ekor, buah, batang, lembar）と数量詞の即時産出

物を数える時、インドネシア語では「数 ＋ 助数詞 ＋ 名詞」の順で並べます。数詞「1」と助数詞が合体して「se-」になる規則（seorang, seekor, sebuah）を反射的に口から出せるようにします。

## 1. 産出メカニズムと文法公式

### 主要助数詞 5選
orang（人間）、ekor（動物）、buah（一般の物・建物・果物・抽象名詞）、batang（細長い棒状の物・タバコ・木）、lembar（薄い紙・布・チケット）。

### 数詞 1 の接頭辞 se- 化
satu orang → seorang、satu ekor → seekor、satu buah → sebuah、satu lembar → selembar。2以上は dua orang, tiga buah と通常通り。
