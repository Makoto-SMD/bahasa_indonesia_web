# 【瞬間作文】否定詞 tidak と bukan の反射的使い分け

日本語の「〜ない / 〜ではない」に対して、インドネシア語は述語の品詞によって厳密に使い分けます。動詞・形容詞は「tidak」、名詞・代名詞・前置詞句は「bukan」です。迷わず0.5秒で選ぶ反射回路を構築します。

## 1. 産出メカニズムと文法公式

### tidak ＋ 動詞 / 形容詞
動作や状態を否定します。tidak makan（食べない）、tidak mahal（高くない）、tidak bisa（できない）。

### bukan ＋ 名詞 / 代名詞 / 指示詞
「AではなくBである」という本質・属性を否定します。bukan guru（教師ではない）、bukan saya（私ではない）、bukan ini（これではない）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「私は先生ではありません」の空欄に入るのは？ Saya ___ guru.**

- 1. bukan (正解)
- 2. tidak
- 3. belum
- 4. jangan

**Q2. 「このスープは美味しくない」の空欄に入るのは？ Sup ini ___ enak.**

- 1. tidak (正解)
- 2. bukan
- 3. jangan
- 4. tanpa

**Q3. 「これではなくあれです」の正しい構文は？**

- 1. Bukan ini, melainkan itu. (正解)
- 2. Tidak ini, melainkan itu.
- 3. Jangan ini, melainkan itu.
- 4. Belum ini, melainkan itu.
