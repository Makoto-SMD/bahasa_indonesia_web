# 【瞬間作文】重複語の相互行為表現（bersalam-salaman, tolong-menolong）

接頭辞「ber-」や「meN-」と重複語を組み合わせることで、「お互いに〜し合う（相互行為）」を生き生きと表現できます。bersalaman（握手する）→ bersalam-salaman（互いに次々と握手し合う）、tolong-menolong（助け合う）を瞬時に発話します。

## 1. 産出メカニズムと文法公式

### ber- 語根 -語根 -an（相互行為・和気あいあい）
bersalam-salaman（互いに握手を交わし合う）、bermaaf-maafan（お互いに許し合う：レバランの定番）、kejar-kejaran / berkejar-kejaran（追いかけっこする）。

### 語根 ＋ meN-語根（相互助け合い・反復的連動）
tolong-menolong（互いに助け合う）、tarik-menarik（互いに引き合う・綱引きする）、pukul-memukul（殴り合う）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

### 第1問
**日本語**: 「**断食明け大祭で、人々は互いに許し合いました。**」

<div class="id-example" markdown>

<div class="id-sentence">

</div>
<div class="id-reading">

</div>
<div class="id-meaning">

</div>
</div>

- **構造解説**: 相互 bermaaf-maafan。

## 3. 理解度チェッククイズ

**Q1. レバランで人々が「お互いに許し合う」伝統行為を表す言葉は？**

- 1. bermaaf-maafan (正解)
- 2. memaafkan
- 3. termaafkan
- 4. maaf-maaf

**Q2. 「互いに助け合う」を表す頻出成句は？**

- 1. tolong-menolong (正解)
- 2. tolong-tolongan
- 3. menolong-nolong
- 4. pertolongan

**Q3. 子供たちが「追いかけっこをする」を表す動詞は？**

- 1. berkejar-kejaran (正解)
- 2. mengejar-ngejar
- 3. terkejar-kejar
- 4. kejar-mengejar
