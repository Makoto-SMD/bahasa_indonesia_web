# 【瞬間作文】接尾辞 -i の場所・方向への作用構文（mendatangi, menaiki）

接尾辞「-i」は、前置詞（di, ke）の機能を動詞の中に内包し、「ある場所・対象に向かって直接働きかける（場所性・対象性）」他動詞を作ります。「datang ke（〜へ来る）」を「mendatangi（〜を訪れる）」へと洗練させるドリルです。

## 1. 産出メカニズムと文法公式

### 前置詞内包の -i
datang ke rumah → mendatangi rumah（家を訪れる）、duduk di kursi → menduduki kursi（椅子に座る・占領する）、naik ke tangga → menaiki tangga（階段を登る）。

### 目的語が「静止した場所・対象」
動作が向かう場所や人が直接の目的語になります。Buku ini dia kirimi surat（彼に手紙を送る）。

## 3. 理解度チェッククイズ

**Q1. 「場所を訪れる（datang ke）」を -i 動詞にすると？**

- 1. mendatangi (正解)
- 2. mendatangkan
- 3. berdatang
- 4. terdatang

**Q2. 「階段を登る（naik ke tangga）」を -i 動詞にすると？**

- 1. menaiki tangga (正解)
- 2. menaikkan tangga
- 3. bernaik tangga
- 4. ternaik tangga

**Q3. 「花に水をやる（水をかける）」を表す動詞は？**

- 1. menyirami bunga (正解)
- 2. menyiramkan bunga
- 3. tersiram bunga
- 4. bersiram bunga
