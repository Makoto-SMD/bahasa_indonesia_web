# 【瞬間作文】接尾辞 -kan の受益構文（membuatkan, membelikan kopi）

接尾辞「-kan」のもう一つの極めて重要で温かい機能が「受益（〜のために…してあげる・してくれる）」です。日本語の「買ってあげる」「作ってあげる」を memberi で直訳せず、membuatkan kopi（コーヒーを淹れてあげる）とサラリと言える構文力を鍛えます。

## 1. 産出メカニズムと文法公式

### 受益構文の語順公式
【主語 ＋ 動詞-kan ＋ 受益者（人） ＋ 目的物】。Saya membelikan adik buku（私は妹に本を買ってあげた）。

### 前置詞 untuk を使う言い換え
【主語 ＋ 動詞 ＋ 目的物 ＋ untuk ＋ 受益者】。Saya membeli buku untuk adik。-kan 構文の方が口語でスマートです。

## 2. 瞬間口頭作文トレーニング（15本ノック）

## 3. 理解度チェッククイズ

**Q1. 「私にコーヒーを淹れてくれる？」の最も自然な表現は？**

- 1. Bisa buatkan saya kopi? (正解)
- 2. Bisa memberi saya kopi buat?
- 3. Bisa membuat kopi saya?
- 4. Bisa berikan saya kopi?

**Q2. 動詞 beli（買う）に受益の -kan がついた形は？**

- 1. membelikan (正解)
- 2. membeli-beli
- 3. terbeli
- 4. berbeli

**Q3. 「荷物を持ってあげましょうか？」のフレーズは？**

- 1. Biar saya bawakan barangnya? (正解)
- 2. Biar saya dibawakan barangnya?
- 3. Barangnya bawa saya?
- 4. Bawa saya barangnya?
