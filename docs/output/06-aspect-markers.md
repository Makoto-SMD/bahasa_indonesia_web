# 【瞬間作文】アスペクト副詞（sudah, belum, sedang, akan, pernah）の反射文生成

インドネシア語には動詞の活用（過去形・現在形・未来形）がありません。その代わりにアスペクト副詞を動詞の直前に置くことで、完了・未完了・進行・未来・経験を表現します。1秒で正確な副詞を差し込むドリルです。

## 1. 産出メカニズムと文法公式

### sudah（完了・すでに）
動作が完了している、または状態が実現していることを示します（Sudah makan）。

### belum（未完了・まだ〜ない）
否定 tidak と違い、「今後する予定だが現時点ではまだ」という前向きな未完了を示します（Belum makan）。

### sedang / lagi（進行・〜しているところ）
動作が今まさに行われている最中であることを示します。口語では lagi。

### akan / mau（未来・〜する予定/つもり）
将来の予定や意志を示します。口語では mau が多用されます。

### pernah / tidak pernah（経験・〜したことがある/ない）
過去の経験の有無を示します。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「まだ食べていません」に対する自然な返答は？**

- 1. Belum. (正解)
- 2. Tidak.
- 3. Bukan.
- 4. Jangan.

**Q2. 「今〜している最中」を表す副詞は？**

- 1. sedang (正解)
- 2. sudah
- 3. akan
- 4. pernah

**Q3. 「〜したことがある」を表す経験の副詞は？**

- 1. pernah (正解)
- 2. sudah
- 3. akan
- 4. masih
