# 【瞬間作文】助動詞（harus, boleh, bisa, mau, ingin）のニュアンス即座出力

義務（harus）、許可（boleh）、可能（bisa / dapat）、意志（mau）、願望（ingin）の助動詞は、文の意図やトーンを決定づける最重要パーツです。相手への丁寧さや強制力の強弱を意識しながら瞬時に発話します。

## 1. 産出メカニズムと文法公式

### harus（義務・〜しなければならない）
強い義務や必要性。否定の tidak harus は「〜しなくてもよい（不必要）」、禁止の「〜してはならない」は tidak boleh / jangan です。

### bisa vs dapat（可能と許可・状況）
bisa は口語でも頻出の一般的可能、dapat は公的な場での獲得・可能。

### mau vs ingin（意志と願望）
mau は「〜するつもり/〜する（具体的意志）」、ingin は「〜したい（心の中の願望・控えめな希望）」。

## 3. 理解度チェッククイズ

**Q1. 「〜してはならない（禁止）」を表す助動詞句は？**

- 1. tidak boleh (正解)
- 2. tidak harus
- 3. tidak bisa
- 4. tidak mau

**Q2. 「試着してもいいですか？」の丁寧な切り出しは？**

- 1. Boleh saya coba? (正解)
- 2. Harus saya coba?
- 3. Mau saya coba?
- 4. Pasti saya coba?

**Q3. 「〜する必要はない（不必要）」を表すのは？**

- 1. tidak harus (正解)
- 2. jangan
- 3. tidak boleh
- 4. dilarang
