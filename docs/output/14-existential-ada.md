# 【瞬間作文】存在表現 ada の多機能構文（所有・存在・強調）の瞬間生成

インドネシア語の「ada」は、物理的「存在（〜がある/いる）」だけでなく、「所有（〜を持っている）」や「事実の強調（確かに〜である）」など多彩な顔を持ちます。日本語の直訳癖を捨てて ada 構文を自由自在に操るドリルです。

## 1. 産出メカニズムと文法公式

### 存在の ada（場所に〜がある/いる）
「Ada [物/人] di [場所]」または「Di [場所] ada [物/人]」。Ada kucing di bawah meja（机の下に猫がいる）。

### 所有の ada（主語には〜がある＝持っている）
「[人] ada [物]」。Saya ada uang（私にはお金がある＝お金を持っている）。punya とほぼ同義ですが、より日常的。

### 有無の確認（〜はありますか？）
Ada gula?（砂糖はありますか？）

### 否定（ない/いない）
tidak ada を使用。Tidak ada masalah（問題ありません）。

## 3. 理解度チェッククイズ

**Q1. 店員が客に「何かお手伝いしましょうか？」と声をかける定番表現は？**

- 1. Ada yang bisa saya bantu? (正解)
- 2. Punya apa Anda?
- 3. Bisa apa di sini?
- 4. Mau apa kamu?

**Q2. 「問題ありません」の正しい表現は？**

- 1. Tidak ada masalah. (正解)
- 2. Bukan ada masalah.
- 3. Jangan ada masalah.
- 4. Belum ada masalah.

**Q3. 「誰もいない」を表すフレーズは？**

- 1. tidak ada siapa-siapa (正解)
- 2. tidak ada apa-apa
- 3. bukan siapa-siapa
- 4. belum siapa-siapa
