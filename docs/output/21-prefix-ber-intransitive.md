# 【瞬間作文】接頭辞 ber- 自動詞・状態動詞の即時産出（berjalan, berbicara）

接頭辞「ber-」は、主語自身が主体となって行う自動詞（berjalan: 歩く、berbicara: 話す）や、所有・身につける状態（berbaju: 服を着ている、berambut panjang: 髪が長い）を瞬時に形成します。能動他動詞 meN- と混同せず、目的語をとらない自律した動作を0.5秒で出力します。

## 1. 産出メカニズムと文法公式

### 自発的動作の自動詞
berjalan（歩く）、berlari（走る）、berenang（泳ぐ）、berhenti（止まる）。目的語を後ろに直接とりません。

### 所有・装着の状態
berbaju merah（赤い服を着ている）、bersepatu（靴を履いている）、beruang（金持ちだ：お金を持っている）。

### 相互行為（互いに〜する）
bertemu（会う）、berpisah（別れる）、bersalaman（握手し合う）。

## 3. 理解度チェッククイズ

**Q1. 接頭辞 ber- 動詞の最大の特徴は？**

- 1. 直接の目的語をとらない自動詞になる (正解)
- 2. 必ず目的語が必要な他動詞になる
- 3. 受動態専用の動詞になる
- 4. 過去形専用の動詞になる

**Q2. 「赤い服を着ている」を表す動詞句は？**

- 1. berbaju merah (正解)
- 2. membaju merah
- 3. terbaju merah
- 4. dibaju merah

**Q3. 「駅で会う」を表す自然な表現は？**

- 1. bertemu di stasiun (正解)
- 2. menemukan di stasiun
- 3. ditemu di stasiun
- 4. tertemu di stasiun
