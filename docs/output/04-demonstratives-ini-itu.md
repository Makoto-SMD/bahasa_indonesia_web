# 【瞬間作文】指示詞 ini / itu と場所表現（di sini / ke sana）の瞬発力

近称「ini（これ・この）」と遠称「itu（あれ・それ・あの・その）」、および場所前置詞「di / ke / dari」と組み合わさる場所副詞（sini, situ, sana）の反射的出力ドリルです。

## 1. 産出メカニズムと文法公式

### ini と itu の位置
名詞を修飾する場合は必ず名詞の「後ろ」に置きます（mobil ini, rumah itu）。単独で主語になる場合は文頭に置きます（Ini buku saya）。

### 場所表現の3階層
sini（ここ・話し手の領域）、situ（そこ・聞き手の領域）、sana（あそこ・双方から離れた遠い領域）。前置詞 di（〜で）、ke（〜へ）、dari（〜から）と合体します。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「この赤いペン」の正しい語順は？**

- 1. pulpen merah ini (正解)
- 2. ini pulpen merah
- 3. merah pulpen ini
- 4. pulpen ini merah

**Q2. 「あそこへ行く」を表す前置詞句は？**

- 1. ke sana (正解)
- 2. di sana
- 3. dari sana
- 4. ke sini

**Q3. 「そこ（聞き手の近く）に置いて」の表現は？**

- 1. di situ (正解)
- 2. di sini
- 3. di mana
- 4. ke sana
