# 【瞬間作文】一人称語幹受動態（Buku ini sudah saya baca）の自動発話化

日本人学習者が最もつまずきやすく、かつネイティブが日常会話で最も多用するのが「一人称語幹受動態」です。「Saya sudah membaca buku ini（能動態）」よりも「Buku ini sudah saya baca（語幹受動態）」の方が圧倒的に自然です。この語順を無意識に繰り出すドリルです。

## 1. 産出メカニズムと文法公式

### 一人称語幹受動態の鉄則
【目的物（主語） ＋ (アスペクト/助動詞) ＋ saya / aku ＋ 語幹動詞（接頭辞なし）】。Buku ini saya baca。

### 絶対にやってはいけない誤用
❌ Buku ini dibaca oleh saya（三人称の di- を一人称に使うのは不自然・誤用）。

### 人称代名詞と語幹の不可分性
saya と動詞の語幹の間には、原則として副詞を挟みません。「sudah saya baca」であり、「saya sudah baca」も可能ですが、アスペクトを前に置くのが標準的です。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「その手紙は私が書いた」の最も自然なインドネシア語は？**

- 1. Surat itu sudah saya tulis. (正解)
- 2. Surat itu ditulis oleh saya.
- 3. Saya sudah ditulis surat itu.
- 4. Surat itu menulis saya.

**Q2. 一人称語幹受動態で使われる動詞の形は？**

- 1. 語幹（接頭辞なし） (正解)
- 2. di- 動詞
- 3. meN- 動詞
- 4. ber- 動詞

**Q3. 「この件は私が処理します」を語幹受動態で言うと？**

- 1. Hal ini akan saya urus. (正解)
- 2. Hal ini diurus oleh saya.
- 3. Saya diurus hal ini.
- 4. Hal ini mengurus saya.
