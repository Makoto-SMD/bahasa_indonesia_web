# 【瞬間作文】重複語（Kata Ulang）の複数・多様性表現（anak-anak, rumah-rumah）

インドネシア語で名詞を繰り返す「重複語（Kata Ulang）」は、単なる「複数（〜たち）」にとどまらず、「様々な種類の〜（多様性）」を表します。anak-anak（子供たち）、buah-buahan（色々な果物）など、重複による豊かな表現を瞬時に産出します。

## 1. 産出メカニズムと文法公式

### 単純重複（名詞の複数・集合）
anak → anak-anak（子供たち）、rumah → rumah-rumah（家々）、mobil → mobil-mobil（車輪・車たち）。数詞がある場合は重複させない点に注意（tiga anak ⭕, tiga anak-anak ❌）。

### 重複 ＋ 接尾辞 -an（様々な種類）
buah → buah-buahan（色々な果物）、sayur → sayur-sayuran（色々な野菜）、obat → obat-obatan（医薬品類）。

## 3. 理解度チェッククイズ

**Q1. 「様々な種類の果物」を表す重複語は？**

- 1. buah-buahan (正解)
- 2. buah-buah
- 3. berbuah-buah
- 4. kebuan-buahan

**Q2. 数詞 tiga（3）と名詞 anak（子供）を組み合わせる正しい文法は？**

- 1. tiga anak (正解)
- 2. tiga anak-anak
- 3. anak-anak tiga
- 4. tiga beranak

**Q3. 「様々な野菜」を表す正しい形は？**

- 1. sayur-sayuran (正解)
- 2. sayur-sayur
- 3. bersayur-sayur
- 4. kesayur-sayuran
