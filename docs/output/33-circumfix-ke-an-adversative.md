# 【瞬間作文】周囲辞 ke-...-an の被災・不本意受動（kehujanan, ketinggalan）

周囲辞「ke-...-an」の2つ目の顔は、意志に反して不本意な災難に遭う「被災受動（〜に遭う、〜されて困る）」です。雨に降られる（kehujanan）、電車に乗り遅れる（ketinggalan kereta）、熱が出る（kemasukan）など、日常の不運を瞬時に発話します。

## 1. 産出メカニズムと文法公式

### 被災・不本意の ke-...-an
kehujanan（雨に降られる）、kepanasan（暑さにやられる）、kedinginan（寒さに凍える）、ketinggalan（乗り遅れる・置き忘れられる）、kecopetan（スリに遭う）、kemalingan（泥棒に入られる）。

### 主語は「被災者（被害を受けた人）」
Saya kehujanan（私は雨に降られた）。受身の di- と違い、「自然現象や偶発的な不運」に特化します。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「雨に降られてずぶ濡れになった」を表す動詞は？**

- 1. kehujanan (正解)
- 2. menghujani
- 3. dihujankan
- 4. berhujan

**Q2. 「電車に乗り遅れる」を表すフレーズは？**

- 1. ketinggalan kereta (正解)
- 2. meninggalkan kereta
- 3. ditinggalkan kereta
- 4. bertinggal kereta

**Q3. 「市場でスリの被害に遭った」を表す動詞は？**

- 1. kecopetan (正解)
- 2. mencopet
- 3. dicopetkan
- 4. bercopet
