# 【瞬間作文】従属接続詞（karena, sehingga, agar, jika, walaupun）の複文組み立て

理由（karena）、結果（sehingga）、目的（agar / supaya）、条件（jika / kalau）、譲歩（walaupun / meskipun）の従属接続詞を使いこなすと、幼稚な短文から論理的な複文へと表現力が飛躍します。条件と結果を瞬時に繋ぐトレーニングです。

## 1. 産出メカニズムと文法公式

### karena（理由・〜なので） vs sehingga（結果・その結果〜）
karena は原因を導き、sehingga はその原因から生じた帰結を導きます。

### agar / supaya（目的・〜するために）
望ましい状態を実現させるための目的節を導きます。口語では biar。

### jika / kalau（条件・もし〜なら）
仮定・条件節。文頭に置くことも文中に置くことも可能です。

### walaupun / meskipun（譲歩・〜にもかかわらず）
反対の事実を提示しながら主節を強調します。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「〜するために（目的）」を導く接続詞は？**

- 1. agar (正解)
- 2. karena
- 3. sehingga
- 4. walaupun

**Q2. 「その結果〜（帰結）」を導く接続詞は？**

- 1. sehingga (正解)
- 2. karena
- 3. jika
- 4. meskipun

**Q3. 「〜にもかかわらず（譲歩）」を導く接続詞は？**

- 1. walaupun (正解)
- 2. karena
- 3. supaya
- 4. kalau
