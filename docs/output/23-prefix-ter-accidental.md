# 【瞬間作文】接頭辞 ter- の無意識・偶発用法の瞬間作文（terbawa, tertidur）

接頭辞「ter-」の代表的機能の一つが「無意識・偶発（うっかり〜してしまう、意図せず〜になる）」です。自分の意志ではなく事故や不可抗力で発生した事態を言い表す、インドネシア語特有の心理描写を瞬時に発話します。

## 1. 産出メカニズムと文法公式

### 無意識・偶発の ter-
tertidur（寝落ちする・うっかり眠る）、terbangun（ふと目が覚める）、terlupa（うっかり忘れる）、terbawa（うっかり持っていってしまう）。

### 事故・突発の受動
tertabrak（車に撥ねられる）、terinjak（踏まれる）、terjatuh（転ぶ・落ちる）。意志的受動 di- と違い「不慮の事故」のニュアンス。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> [!TIP]
> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 「うっかり眠ってしまう（寝落ち）」を表す動詞は？**

- 1. tertidur (正解)
- 2. meniduri
- 3. ditidurkan
- 4. bertidur

**Q2. 「車に撥ねられる（不慮の事故）」を表す受動態は？**

- 1. tertabrak (正解)
- 2. menabrak
- 3. ditabrakkan
- 4. bertabrak

**Q3. 「傘をうっかり持ってきてしまった」を表す語句は？**

- 1. terbawa (正解)
- 2. membawa
- 3. dibawakan
- 4. berbawa
