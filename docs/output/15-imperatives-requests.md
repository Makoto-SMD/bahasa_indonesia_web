# 【瞬間作文】依頼・指示・禁止（tolong, silakan, harap, jangan, dilarang）

人に何かを頼む・促す・禁止する表現は、語気や敬意の度合いを誤ると重大な人間関係トラブルになります。最も丁寧な「tolong / silakan」から、公的指示「harap」、厳格な禁止「dilarang / jangan」までを即時選別します。

## 1. 産出メカニズムと文法公式

### tolong（〜してください・お願い）
相手に行動を依頼する最も一般的で丁寧な言葉。Tolong bantu saya（助けてください）。

### silakan（どうぞ〜してください・勧奨）
相手に許可や推奨を与える丁寧な表現。Silakan masuk（どうぞお入りください）。

### harap / mohon（〜してください・公的要請）
アナウンスや公的掲示、ビジネス文書での強い丁寧要請。Harap tenang（お静かに願います）。

### jangan（〜しないで・禁止）
日常会話での禁止。「Jangan lupa（忘れないで）」。

### dilarang（〜禁止・公的標識）
公の規則・法律による禁止。「Dilarang merokok（喫煙禁止）」。

## 3. 理解度チェッククイズ

**Q1. 「どうぞ〜してください（勧奨）」を表す丁寧な言葉は？**

- 1. silakan (正解)
- 2. tolong
- 3. jangan
- 4. dilarang

**Q2. 公共標識で「立ち入り禁止」を表す語句は？**

- 1. Dilarang masuk (正解)
- 2. Jangan masuk
- 3. Silakan masuk
- 4. Harap masuk

**Q3. 「忘れないでね」の自然な日常会話フレーズは？**

- 1. Jangan lupa ya. (正解)
- 2. Dilarang lupa ya.
- 3. Harap lupa ya.
- 4. Silakan lupa ya.
