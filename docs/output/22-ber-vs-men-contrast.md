# 【瞬間作文】ber- と meN- の使い分け対比ドリル（berubah vs mengubah）

同一の語根から ber-（自動詞・状態・自発）と meN-（他動詞・意図的行為）が派生するペアは、インドネシア語の最もダイナミックな語彙体系です。「何かが自然に変わる（berubah）」のか、「誰かが何かを変える（mengubah）」のかを瞬時に切り替えるドリルです。

## 1. 産出メカニズムと文法公式

### ber- は自動詞（主語自身が変わる）
Situasi berubah（状況が変わる）、Dia bercukur（彼は髭を剃る：自分自身の髭）。

### meN- は他動詞（対象・目的語に働きかける）
Dia mengubah rencana（彼は計画を変える）、Tukang cukur mencukur rambutnya（理髪師が彼の髪を刈る）。

## 3. 理解度チェッククイズ

**Q1. 「状況が変わる」に適切な動詞は？ Situasi ___.**

- 1. berubah (正解)
- 2. mengubah
- 3. diubah
- 4. terubah

**Q2. 「計画を変更する」に適切な動詞は？ ___ rencana.**

- 1. mengubah (正解)
- 2. berubah
- 3. terubah
- 4. seubah

**Q3. 「生徒を集める」に適切な動詞は？ ___ siswa.**

- 1. mengumpulkan (正解)
- 2. berkumpul
- 3. terkumpul
- 4. kumpulan
