# 【瞬間作文】接頭辞 meN- 自動詞と状態変化（menangis, mendarat, menguning）

meN- は他動詞だけでなく、目的語をとらない「自動詞」や、自然な「状態変化（〜になる）」、音の発声などを表す重要動詞群を形成します。日常会話で感情や状況を生き生きと描写する自動詞を反射出力します。

## 1. 産出メカニズムと文法公式

### 感情・生理的動作の自動詞
menangis（泣く）、merintih（うめく）、menguap（あくびをする/蒸発する）。

### 場所・目標への移動・到達
mendarat（着陸する：darat=陸）、melaut（出漁する：laut=海）、menepi（端に寄る：tepi=端）。

### 状態変化・色彩化（〜になる）
menguning（黄色くなる：kuning=黄色）、membesar（大きくなる：besar=大きい）、mengecil（小さくなる）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

> **トレーニング手順**: 日本語の文を見て、**1〜2秒以内**に声に出してインドネシア語を発話してください。その後、正解の文と解説を確認して口頭で3回リピートします。

## 3. 理解度チェッククイズ

**Q1. 飛行機が「着陸する」を表す動詞は？**

- 1. mendarat (正解)
- 2. melaut
- 3. menepi
- 4. menangis

**Q2. 「黄色くなる」という色の変化を表す動詞は？**

- 1. menguning (正解)
- 2. memerah
- 3. membiru
- 4. menghijau

**Q3. 「良くなる・改善する」を表す meN- 自動詞は？**

- 1. membaik (正解)
- 2. memburuk
- 3. membesar
- 4. mengecil
