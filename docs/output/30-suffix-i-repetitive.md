# 【瞬間作文】接尾辞 -i の反復・複数対象構文（memukuli, menciumi）

接尾辞「-i」のもう一つの極めて特徴的な用法が「動作の反復（何度も繰り返す）」および「複数の対象への連続的適用」です。1回の動作 memukul（殴る）に対して、何度もボコボコに殴る memukuli のような生々しい動作描写を反射出力します。

## 1. 産出メカニズムと文法公式

### 反復・継続の -i（何度も繰り返す）
memukul（1回殴る）→ memukuli（何度も殴り続ける）、mencium（1回キスする）→ menciumi（何度もキスしまくる）、melempar（1回投げる）→ melempari（何度も投げつける）。

### 複数対象への動作（あちこちに〜する）
mengambil（取る）→ mengambili（あちこちから次々と拾い集める）、mencabuti（草を何本も抜きまくる）。

## 2. 瞬間口頭作文トレーニング（15本ノック）

- 1. memukuli (正解)
- 2. memukulkan
- 3. berpukul
- 4. terpukul

**Q2. 「石を何度も相手に投げつける」を表す動詞は？**

- 1. melempari (正解)
- 2. melemparkan

- 4. terlempar

**Q3. 「草を何本も次々に引き抜く」を表す動詞は？**

- 1. mencabuti (正解)
- 2. mencabutkan
- 3. bercabut
- 4. tercabut
