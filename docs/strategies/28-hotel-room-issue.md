# 【戦略会話】ホテル設備トラブル：エアコン故障・お湯が出ない・異臭時の部屋変更交渉術

ホテルの客室に入った直後、エアコンが効かない、シャワーからお湯が出ない、排水溝から異臭がする、Wi-Fiが繋がらないなどの設備トラブルに直面した際、我慢して泣き寝入りしてはいけません。フロントに冷静かつ断固として状況を伝え、修理スタッフの手配や部屋変更（Pindah kamar）を勝ち取る交渉術を学びます。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `AC di kamar tidak dingin sama sekali.` | **AC-nya rusak mas, panas bgt!** | エアコン故障の訴え |
| 2 | `Air panas di kamar mandi tidak menyala.` | **Air panasnya gak keluar sama sekali.** | 温水不具合の訴え |
| 3 | `Bolehkah kami meminta pindah kamar?` | **Bisa tolong pindah kamar aja gak?** | 部屋変更の要求 |
| 4 | `Tolong kirimkan staf teknisi sekarang.` | **Kirim teknisi ke kamar skrg ya.** | 修理スタッフの派遣要請 |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

## 4. 理解度チェッククイズ

### 問1: ホテルの部屋の設備が壊れていて、別の部屋に変えてほしいと要求する際の最重要フレーズは？

- [x] 1. Bolehkah kami meminta pindah kamar? (Bisa pindah kamar?) (正解)
- [ ] 2. Saya mau tidur di lobi
- [ ] 3. Tolong tutup hotel ini
- [ ] 4. Berapa harga gedung ini?

### 問2: エアコンが冷えず、生温い風しか出ない状態をフロントに説明する表現は？

- [x] 1. AC tidak dingin sama sekali, hanya keluar angin panas (正解)
- [ ] 2. AC-nya sangat dingin seperti kutub utara
- [ ] 3. Saya suka sekali dengan udaranya
- [ ] 4. Tolong matikan semua lampu

### 問3: シャワーのお湯が出ない時、「お湯（air panas）」の反対で水しか出ないことを表す単語は？

- [x] 1. hanya mengalir air dingin (正解)
- [ ] 2. air sirup
- [ ] 3. air kelapa
- [ ] 4. air teh manis
