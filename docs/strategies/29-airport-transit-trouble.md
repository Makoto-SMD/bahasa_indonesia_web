# 【戦略会話】空港・フライトトラブル：ロストバゲージ・乗り遅れ・遅延時の航空会社カウンター交渉

海外旅行や出張で最もパニックに陥りやすいのが空港（Bandara）でのトラブルです。預け荷物が出てこない（Lost baggage）、乗り継ぎ便の遅延で接続便に乗り遅れた（Missed connection）、フライトが急遽欠航した際の航空会社カウンターでの補償・振替便交渉サバイバル術を体得します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Bagasi saya tidak keluar di konveyor.` | **Koper saya hilang / belum keluar nih!** | ロストバゲージの申告 |
| 2 | `Penerbangan tertunda sehingga saya tertinggal transit.` | **Ketinggalan pesawat lanjutan gara-gara delay!** | 乗り継ぎ失敗の訴え |
| 3 | `Mohon aturkan penerbangan pengganti berikutnya.` | **Bisa carikan penerbangan berikutnya?** | 振替便の手配要求 |
| 4 | `Apakah disediakan kompensasi hotel dan makanan?` | **Dapet hotel sama makan gratis kan?** | 補償・宿泊・食事の要求 |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

### 問1: 空港の荷物受け取りターンテーブルからスーツケースが出てこない（ロストバゲージ）時の申告表現は？

- [ ] 2. Saya mau beli koper baru
