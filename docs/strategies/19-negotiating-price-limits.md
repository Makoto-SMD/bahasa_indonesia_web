# 【戦略会話】予算限界の提示：「これ以上は予算オーバーです」と角を立てずに伝える

買い物の値引き交渉やビジネスでの価格折衝において、「高すぎる！」「そんな金はない！」と直接的に突き放すと、相手のプライドを傷つけ関係が破綻します。「こちらの予算枠がここまででして…」「上司の承認が下りる上限がこの金額です」と、客観的な限界ラインを示して相手の譲歩を引き出す洗練された交渉術を学びます。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Anggaran yang dialokasikan terbatas pada...` | **Budget kami mentok di angka...** | 予算上限の提示 |
| 2 | `Jika melebihi nominal ini, persetujuan sulit didapat.` | **Kalo lewat dari ini, bos gak bakal acc.** | 決裁権限の理由付け |
| 3 | `Apakah ada opsi penyesuaian spesifikasi?` | **Bisa kurangin fiturnya biar masuk budget?** | 仕様変更の打診 |
| 4 | `Harga pas untuk kami adalah...` | **Harga pasnya mentok berapa nih mas?** | 最終価格の探り |

## 2. 意味交渉（Negotiation of Meaning）のメカニズム

第二言語習得論（SLA）におけるインターアクション仮説（Long）が示す通り、コミュニケーションの破綻を修復し、相手と意味をすり合わせる「意味交渉」のプロセスこそが、言語能力を飛躍的に高める最大の触媒です。

## 4. 理解度チェッククイズ

### 問1: 交渉で「こちらの予算の上限は〜で頭打ちです（限界です）」と伝える時の定番語「mentok」の意味は？

- [x] 1. 限界・突き当たり・頭打ち (正解)
- [ ] 2. まだ余裕がある
- [ ] 3. 無料である
- [ ] 4. 倍増する

### 問2: 価格がどうしても下げられない時に、実質的にお得にするための優れた交渉アプローチは？

- [x] 1. 価格はそのままで、オマケや付帯サービス（bonus / aksesoris）を付けてもらう (正解)
- [ ] 2. 店員を罵倒する
- [ ] 3. 警察を呼ぶ
- [ ] 4. 商品を壊す

### 問3: インドネシアの露店や市場で、これ以上安くならない時に「ご縁がなかったということで諦めます」と笑顔で言う慣用句は？

- [x] 1. Kalo gak dapet yaudah belum jodoh berarti (正解)
- [ ] 2. Kamu jahat sekali
- [ ] 3. Toko ini jelek
- [ ] 4. Saya mau bakar pasar
