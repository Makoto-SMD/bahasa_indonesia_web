# 【戦略会話】食事制限・アレルギー：宗教規定（ハラル）・食物アレルギー・苦手食材を確実に伝える

世界最大のムスリム人口を抱えるインドネシアでは、ハラル（Halal: イスラム法で許された食品）とハラム（Haram: 豚肉やアルコールなど禁止された食品）の峻別が日常的に極めて重要です。また、エビ・カニ、ナッツ、グルテンなどのアレルギーやベジタリアン宣言を、命に関わる誤解なく確実に店員へ伝えるフレーズを学びます。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Makanan ini mengandung babi atau alkohol?` | **Ada babinya gak mas?** | 豚・酒の含有確認 |
| 2 | `Saya memiliki alergi parah terhadap...` | **Saya alergi berat sama...** | アレルギーの申告 |
| 3 | `Tolong jangan pakai...` | **Jangan pake... ya, tolong pisahkan.** | 特定食材の抜き・別皿依頼 |
| 4 | `Apakah minyak yang digunakan halal?` | **Minyak gorengnya pake minyak apa mas?** | 調理油の確認 |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

### 問1: イスラム法で許された食品（Halal）と禁止された食品（Haram）のうち、最も厳重に確認すべき豚肉のインドネシア語は？

- [x] 1. babi (正解)
- [ ] 2. ayam
- [ ] 3. sapi
- [ ] 4. kambing

### 問2: 東南アジアの食堂で、氷でお腹を壊さないために「穴の空いた製氷機の安全な氷（es kristal）」か確認する表現は？

- [x] 1. Es batunya dibuat dari air matang kan ya? (正解)
- [ ] 2. Es batunya sangat dingin ya?
- [ ] 3. Berapa harga es batunya?
- [ ] 4. Saya mau beli kulkas

### 問3: 唐辛子（cabai）の辛さに極端に弱い日本人が、屋台で「辛さゼロ（唐辛子を一切入れないで）」と念押しするキーワードは？

- [x] 1. nol cabai / tanpa cabai sama sekali (正解)
- [ ] 2. tambah cabai sepuluh
- [ ] 3. sambal yang banyak
- [ ] 4. pedas level lima
