# 【戦略会話】アルファベット綴り確認：人名・地名・メールアドレスを1文字ずつ確実に伝える

インドネシア語のアルファベット読み（A: アー, B: ベー, C: チェー, D: デー, E: エー, G: ゲー, H: ハー, J: ジェー, K: カー, P: ペー, Q: キー, V: フェー, W: ウェー, Y: イー・グラエック, Z: ゼット）は、英語と母音・子音の読み方が大きく異なります。名前やメールアドレスのスペルを1文字ずつ正確に聞き取り・伝達する技術を磨きます。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Boleh tolong dieja huruf demi huruf?` | **Dieja dong satu-satu hurufnya!** | スペル確認要請の差 |
| 2 | `Pakai huruf besar atau kecil?` | **Huruf kapital apa bukan?** | 大文字・小文字の確認 |
| 3 | `Apakah menggunakan spasi atau tanda hubung?` | **Pake strip apa spasi?** | 記号・ハイフンの確認 |
| 4 | `Huruf 'C' seperti pada kata 'Cinta'?` | **'C' untuk 'Cacing' kan ya?** | フォネティック確認の差 |

## 2. 意味交渉（Negotiation of Meaning）のメカニズム

第二言語習得論（SLA）におけるインターアクション仮説（Long）が示す通り、コミュニケーションの破綻を修復し、相手と意味をすり合わせる「意味交渉」のプロセスこそが、言語能力を飛躍的に高める最大の触媒です。

## 3. 場面別サバイバル・プラクティス（15問ノック）

### 第1問: 【ビジネス】「**お名前のアルファベットの綴りを1文字ずつ教えていただけますか？**」（Boleh tolong eja nama lengkapnya huruf demi huruf?）

<div class="id-example">
<div class="id-sentence"><strong>Boleh tolong dieja nama lengkap Bapak satu per satu hurufnya agar tidak keliru?</strong></div>

<div class="id-translation">解説: 氏名スペルの公式確認。</div>
</div>

<div class="id-translation">解説: 日本姓の正確な発音伝達。</div>
</div>

- [ ] 2. シー (See)
- [ ] 3. クー (Koo)
- [ ] 4. ツァー (Tsa)

### 問2: 電話などで字母「B」と「D」の聞き間違いを防ぐために使われる最も一般的な工夫は？

- [x] 1. 「BandungのB」「DenpasarのD」のように有名な都市名とセットで伝える (正解)
- [ ] 2. 大声で怒鳴る
- [ ] 3. 適当に想像で書く
- [ ] 4. アルファベットを廃止する

### 問3: 電子メールアドレスの記号「@（アットマーク）」はインドネシアの日常会話で何と呼ばれる？

- [x] 1. et / tanda keong (カタツムリマーク) (正解)
- [ ] 2. tanda bintang
- [ ] 3. tanda seru
- [ ] 4. tanda panah
