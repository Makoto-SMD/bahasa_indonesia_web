# 【戦略会話】緊急SOS救助要請：盗難・スリ・事故・急病の現場で周囲の助けを即座に呼ぶ

海外滞在中に最も命に関わるのが、スリ・強盗、交通事故、急病、火災などの緊急事態（situasi darurat）です。パニックに陥って声が出なくなるのを防ぎ、「Tolong!（助けて！）」「Maling!（泥棒！）」「Panggil ambulans!（救急車を呼んで！）」など、最短の音節で周囲の人々を動員し救助を勝ち取るサバイバル命令文を訓練します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Tolong panggilkan polisi / ambulans!` | **Panggil polisi / ambulans cepet!** | 緊急通報の要請 |
| 2 | `Telah terjadi kecelakaan / pencopetan!` | **Ada copet / tabrakan tuh!** | 事件・事故の叫び |
| 3 | `Saya membutuhkan pertolongan medis segera.` | **Butuh dokter cepet, gak kuat!** | 医療救護の要請 |
| 4 | `Tolong amankan pelaku ini!` | **Tangkap tuh orang, maling!** | 犯人逮捕の叫び |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

## 4. 理解度チェッククイズ

### 問1: 街頭でスリや泥棒を発見した際、周囲の市民を一瞬で動員して犯人を捕まえさせる叫び言葉は？

- [x] 1. Maling! / Copet! (正解)
- [ ] 2. Halo apa kabar!
- [ ] 3. Selamat makan!
- [ ] 4. Terima kasih banyak!

### 問2: 急病人や負傷者が発生した際、救急車を呼ぶための正確な指示フレーズは？

- [x] 1. Tolong panggilkan ambulans sekarang! (正解)
- [ ] 2. Tolong belikan es krim!
- [ ] 3. Tolong nyalakan televisi!
- [ ] 4. Tolong tutup jendelanya!

### 問3: 緊急事態（盗難・事故・急病）において、最も生存率を高める初期行動は？

- [x] 1. 躊躇や恥じらいを捨て、大声で周囲に助け（Tolong!）を求め、具体的に警察や病院への連絡を指示すること (正解)
- [ ] 2. 隅っこで小さくなって一人で泣くこと
- [ ] 3. SNSに愚痴を投稿して待つこと
- [ ] 4. 諦めて寝ること
