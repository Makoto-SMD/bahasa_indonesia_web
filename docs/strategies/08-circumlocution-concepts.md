# 【戦略会話】迂回表現（概念編）：抽象名詞や専門用語を具体例とメタファーで切り抜ける

「インフレ」「持続可能性」「既得権益」「自己肯定感」などの抽象概念や専門用語は、辞書的な難解語（inflasi, keberlanjutan, hak istimewa, kepercayaan diri）を暗記していなくても、具体例や日常のたとえ話（メタファー）を用いて説明することで相手に確実に伝えることができます。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Situasi di mana hal ini terjadi... (これが起きる状況)` | **Kondisi pas orang ngerasa...** | 状況描写のフレーム |
| 2 | `Bisa diibaratkan seperti... (〜のように例えられる)` | **Bisa diumpamain kayak...** | メタファー・比喩のフレーム |
| 3 | `Dampaknya membuat... (その結果〜になる)` | **Efeknya bikin keadaan jadi...** | 結果・影響説明のフレーム |
| 4 | `Konsep yang berhubungan dengan... (〜に関する概念)` | **Konsep yang nyangkut soal...** | 関連領域のフレーム |

## 2. 意味交渉（Negotiation of Meaning）のメカニズム

第二言語習得論（SLA）におけるインターアクション仮説（Long）が示す通り、コミュニケーションの破綻を修復し、相手と意味をすり合わせる「意味交渉」のプロセスこそが、言語能力を飛躍的に高める最大の触媒です。

## 3. 場面別サバイバル・プラクティス（15問ノック）

> **トレーニング手順**: 提示されたシチュエーションと日本語を見て、1〜2秒以内に口頭で適切なサバイバルフレーズを声に出してください。

### 第1問: 【インフレ】「**物価がどんどん上がってお金の価値が下がる現象。**」（Kondisi saat harga barang naik dan nilai uang turun.）

<div class="id-example">
<div class="id-sentence"><strong>Fenomena di mana harga-harga barang kebutuhan naik terus, jadi uang sejuta sekarang cuma dapet dikit.</strong></div>

## 4. 理解度チェッククイズ

### 問1: 物価が上がり通貨の価値が落ちる「インフレ」を具体例で説明する場合、最も分かりやすい表現は？

- [x] 1. harga barang naik terus, jadi uang sejuta sekarang cuma dapat sedikit (正解)
- [ ] 2. semua orang belajar bahasa asing di sekolah
- [ ] 3. hujan turun sangat deras kemarin malam
- [ ] 4. mobil berjalan cepat di jalan tol

### 問2: 抽象的な専門用語を説明する際、「〜のように例えられる」と比喩を導入する表現は？

- [x] 1. Bisa diibaratkan / diumpamakan seperti... (正解)
- [ ] 2. Sama sekali tidak ada hubungannya...
- [ ] 3. Harganya sangat murah...
- [ ] 4. Siapa nama penulis buku ini...

### 問3: 全体の進行を滞らせている「ボトルネック（障害箇所）」の的確な比喩的説明は？

- [x] 1. titik paling macet yang bikin seluruh proses ikutan mandek (正解)
- [ ] 2. kunci untuk membuka pintu rumah
- [ ] 3. hadiah ulang tahun dari teman
- [ ] 4. makanan penutup setelah makan malam
