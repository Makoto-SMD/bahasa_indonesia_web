# 【戦略会話】沈黙回避フィラー：発話権を維持し「ええと、つまり…」と時間を稼ぐ戦略

外国語で話している際、言いたい単語や構文を頭の中で組み立てている間の「不自然な沈黙（awkward silence）」は、会話が途切れたり相手に発話権を奪われたりする最大の要因です。「Anu...」「Gini lho...」「Maksud saya...」などのフィラーを効果的に配置し、発話権（floor）をキープしながら思考時間を稼ぐ技術を習得します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Bagaimana menjelaskannya ya...` | **Gimana ya ngomongnya...** | 思考時間の確保 |
| 2 | `Hal yang ingin saya garis bawahi adalah...` | **Intinya tuh gini sebenernya...** | 要点整理のフィラー |
| 3 | `Sebentar, saya sedang memikirkannya...` | **Bentar-bentar, apa tuh namanya...** | 記憶想起のフィラー |
| 4 | `Dapat dikatakan bahwa...` | **Bisa dibilang kayak...** | 曖昧化・クッションのフィラー |

## 2. 意味交渉（Negotiation of Meaning）のメカニズム

第二言語習得論（SLA）におけるインターアクション仮説（Long）が示す通り、コミュニケーションの破綻を修復し、相手と意味をすり合わせる「意味交渉」のプロセスこそが、言語能力を飛躍的に高める最大の触媒です。

## 3. 場面別サバイバル・プラクティス（15問ノック）

## 4. 理解度チェッククイズ

### 問1: 言いたいことを考えている間、沈黙を埋めて発話権を維持するインドネシア語の定番フィラーは？

- [x] 1. Gimana ya ngomongnya... / Jadi gini lho... (正解)
- [ ] 2. Selamat pagi semuanya!
- [ ] 3. Tolong jangan ganggu saya!
- [ ] 4. Berapa nomor telepon Anda?

### 問2: 相手からの鋭い質問に対し、時間を稼ぎながら威厳を保つスマートな切り返しは？

- [x] 1. Pertanyaan yang sangat bagus dan menarik nih... (正解)
- [ ] 2. Saya tidak mau menjawab!
- [ ] 3. Pertanyaan Anda sangat bodoh!
- [ ] 4. Saya mau pulang sekarang!

### 問3: 不自然な沈黙（awkward silence）が会話にもたらす最大のデメリットは？

- [x] 1. 相手に会話終了と誤解されたり、発話の主導権を奪われたりすること (正解)
- [ ] 2. 話すスピードが速くなりすぎること
- [ ] 3. 文法が正しくなりすぎること
- [ ] 4. 相手が怒り狂って暴れ出すこと
