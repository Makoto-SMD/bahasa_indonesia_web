# 【戦略会話】角を立てない拒絶：「前向きに検討しますが、現時点では困難です」の外交辞令

インドネシア文化（特にジャワ的社会規範）において、「Tidak bisa!（無理です！）」と直接的に拒絶することは相手のメンツ（muka）を潰すタブーとされます。「Kami pertimbangkan dulu...（まず検討させていただきます）」「Untuk saat ini agak berat...（現時点では少々厳しく…）」など、角を立てずに礼儀正しく断る外交辞令ストラテジーを体得します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Akan kami pertimbangkan terlebih dahulu.` | **Dipikir-pikir dulu ya...** | 保留・前向き検討の建前 |
| 2 | `Untuk saat ini agak sulit bagi kami.` | **Kayaknya agak berat deh buat skrg.** | 現時点での困難提示 |
| 3 | `Jadwal kami sudah terisi penuh.` | **Jadwalnya udah padet bgt nih.** | 多忙を理由にした辞退 |
| 4 | `Mohon maaf belum berjodoh saat ini.` | **Belum jodoh kali ya kali ini.** | 文化的な縁の表現 |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

### 問1: インドネシアで相手のメンツを潰さずに提案を断る際、最も一般的な前置きは？

- [x] 1. Akan kami pertimbangkan terlebih dahulu / Untuk saat ini agak sulit... (正解)
- [ ] 2. Pasti saya tolak mentah-mentah!
- [ ] 3. Tidak sudi saya bekerjasama!

### 問2: 友人からの誘いを断る際、関係を悪化させないための最も重要なマナーは？

- [x] 1. 誘ってくれたことへの感謝（Makasih udah diajak）を述べてから理由を添える (正解)
