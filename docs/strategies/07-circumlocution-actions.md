# 【戦略会話】迂回表現（動作編）：動詞が出てこない時に平易な語彙を組み合わせて説明する

「うがいをする」「見せびらかす」「盗み聞きする」「つまずく」など、特定の高度な動詞がパッと出ない時でも、基本動詞（bikin, buat, ambil, jalan, lihat）と状況描写を組み合わせれば100%意図を伝えることができます。動詞のド忘れをスマートに切り抜ける迂回術を体得します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Melakukan gerakan... (〜という動きをする)` | **Bikin gerakan kayak gini...** | 動作模倣のフレーム |
| 2 | `Proses dari kondisi A menjadi B (AからBへの変化)` | **Dari yang tadinya... terus jadi...** | 状態変化のフレーム |
| 3 | `Sama artinya dengan... (〜と同じ意味の動作)` | **Mirip kayak kata... tapi lebih...** | 類義動詞の微調整 |
| 4 | `Apa istilah untuk tindakan... (〜する行為は何て言う？)` | **Kalo orang lagi... itu istilahnya apa ya?** | 語彙逆引き質問 |

## 2. 意味交渉（Negotiation of Meaning）のメカニズム

第二言語習得論（SLA）におけるインターアクション仮説（Long）が示す通り、コミュニケーションの破綻を修復し、相手と意味をすり合わせる「意味交渉」のプロセスこそが、言語能力を飛躍的に高める最大の触媒です。

## 3. 場面別サバイバル・プラクティス（15問ノック）

## 4. 理解度チェッククイズ

### 問1: 喉を水でガラガラ洗う「うがいをする」の動詞が出ない時、最もわかりやすい迂回説明は？

- [x] 1. bersihin tenggorokan pake air sambil bunyi 'glogok-glogok' (正解)
- [ ] 2. lari kencang di lapangan
- [ ] 3. membaca buku tebal di kamar
- [ ] 4. membeli baju di toko

### 問2: 「列に横入りする・割り込む」を平易な言葉で説明する表現は？

- [x] 1. tiba-tiba masuk barisan tanpa antre dari belakang (正解)
- [ ] 2. memberi uang kepada pengemis
- [ ] 3. berenang di sungai yang dalam
- [ ] 4. menutup pintu secara perlahan

### 問3: 動詞をド忘れした時の対処法として、SLA理論で推奨される戦略は？

- [x] 1. 具体的な動作プロセスや前後の状態変化を分解して易しい言葉で描写する (正解)
- [ ] 2. 黙り込んで相手が察するのを待つ
- [ ] 3. 日本語の動詞をそのまま大声で叫ぶ
- [ ] 4. 会話を諦めてその場を立ち去る
