# 【戦略会話】発話の本題復帰：「話が逸れましたが、元の話に戻すと…」の軌道修正

雑談や割り込み、突発的な電話などで本題から大きく脱線してしまった後、スムーズに会話のレールを元の位置に戻す「発話の本題復帰（Resuming after Interruption）」は、会議を脱線させず時間内にゴールへ導くファシリテーションの最重要スキルです。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Kembali ke topik utama pembahasan...` | **Balik lagi ke topik tadi ya...** | 本題復帰の前置き |
| 2 | `Melanjutkan apa yang saya sampaikan tadi...` | **Ngelanjutin omongan gue tadi...** | 直前の発言継続 |
| 3 | `Sebelum teralihkan, kita sedang membahas...` | **Tadi kan kita lagi ngomongin...** | 脱線前の話題想起 |
| 4 | `Mari kita fokuskan kembali perhatian pada...` | **Fokus ke sini dulu yuk...** | 注意集中への誘導 |

## 2. 意味交渉（Negotiation of Meaning）のメカニズム

第二言語習得論（SLA）におけるインターアクション仮説（Long）が示す通り、コミュニケーションの破綻を修復し、相手と意味をすり合わせる「意味交渉」のプロセスこそが、言語能力を飛躍的に高める最大の触媒です。

## 3. 場面別サバイバル・プラクティス（15問ノック）

> [!TIP]
> **トレーニング手順**: 提示されたシチュエーションと日本語を見て、1〜2秒以内に口頭で適切なサバイバルフレーズを声に出してください。

### 第1問: 【ビジネス】「**さて、本題に戻りましょう。**」（Baiklah, mari kita kembali ke pokok pembahasan semula.）

<div class="id-example">
<div class="id-sentence"><strong>Baiklah Bapak dan Ibu, mari kita kembali memfokuskan perhatian pada agenda utama kita hari ini.</strong></div>
<div class="id-pronunciation">発音: バイッラ バパッ ダン イブ、マリ キタ クンバリ ムムフォーカスカン プルハティアン パダ アジェンダ ウタマ キタ ハリ イニ</div>
<div class="id-translation">解説: 公式な本題復帰。</div>
</div>

### 第2問: 【日常会話】「**あ、話が逸れちゃったね！元の話に戻すと…**」（Eh malah ngelantur kemana-mana! Balik ke topik ya...）

<div class="id-example">

<div class="id-translation">解説: 雑談脱線からの復帰。</div>
</div>

### 第3問: 【会議】「**先ほどの電話で中断されましたが、発言を続けさせていただきます。**」（Melanjutkan paparan yang sempat terinterupsi.）

<div class="id-example">

<div class="id-translation">解説: 電話中断からの再開。</div>

### 第4問: 【質問後】「**ご質問への回答が終わりましたので、元のスライドに戻ります。**」（Kembali ke tayangan salindia utama.）

<div class="id-translation">解説: 質疑後のスライド復帰。</div>
</div>

### 第5問: 【同僚】「**さっきどこまで話したっけ？**」（Tadi nyampe mana ya kita ngomongnya?）

### 第6問: 【脱線制止】「**話が本筋から離れすぎているので、一旦整理しましょう。**」（Pembahasan sudah terlalu jauh melebar.）

### 第7問: 【意思決定】「**雑談はランチの時にして、まず結論を決めましょう。**」（Ngobrol santainya pas makan siang aja.）

</div>

## 4. 理解度チェッククイズ

### 問1: 話が脱線した後に「さて、元の本題に戻りましょう」と軌道修正する定番フレーズは？

- [x] 1. Mari kita kembali ke pokok pembahasan / topik utama... (正解)
- [ ] 2. Mari kita tidur sekarang...
- [ ] 3. Mari kita lari keliling lapangan...
- [ ] 4. Mari kita berkelahi di luar...

### 問2: 日常会話で「あ、話があちこち脱線しちゃったね！」と笑いながら自戒する表現は？

- [x] 1. Eh kok malah ngelantur kemana-mana... (正解)
- [ ] 2. Eh kok makanannya enak sekali...
- [ ] 3. Eh kok bajunya bagus...
- [ ] 4. Eh kok hari ini mendung...

### 問3: ファシリテーターが議論を時間内にゴールへ導くために不可欠なスキルは？

- [x] 1. 脱線した話題を適切に打ち切り、アジェンダの本題へ引き戻すこと (正解)
- [ ] 2. 全員に好きなだけ雑談を続けさせること
- [ ] 3. 怒って途中で会議を放り出すこと
- [ ] 4. 自分一人だけで喋り続けること
