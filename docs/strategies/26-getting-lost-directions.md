# 【戦略会話】道迷いサバイバル：現在地を特定し、目的地への行き方を道行く人から引き出す

スマートフォンの充電が切れたりGPSが狂ったりして見知らぬ街で迷子になった際、地元の人に声をかけて現在地を把握し、安全に目的地へ辿り着くための「道迷いサバイバル技術」を学びます。「Saya tersesat（道に迷いました）」「Patokannya apa ya?（目印は何ですか？）」など、的確な道案内を引き出す質問術を訓練します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Mohon maaf, saya tersesat.` | **Nyasar nih mas, numpang tanya.** | 道迷い申告 |
| 2 | `Bagaimana cara menuju ke...?` | **Arah ke... lewat mana ya?** | 経路質問の差 |
| 3 | `Apa patokan yang paling mudah?` | **Patokannya apa ya biar gampang?** | 目印・ランドマーク確認 |
| 4 | `Apakah tempat tersebut bisa ditempuh jalan kaki?` | **Bisa jalan kaki apa mesti naek ojek?** | 移動手段の確認 |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

## 3. 場面別サバイバル・プラクティス（15問ノック）

## 4. 理解度チェッククイズ

### 問1: 道に迷って人に尋ねる時の最も有名なインドネシアのことわざ「Malu bertanya sesat di jalan」の意味は？

- [x] 1. 尋ねるのを恥ずかしがると道に迷う（聞くは一時の恥、聞かぬは一生の恥） (正解)
- [ ] 2. 道を聞くとお金を取られる
- [ ] 3. 走れば必ず目的地に着く
- [ ] 4. 地図を見れば誰でも分かる

### 問2: 道案内をしてもらう際、「一番わかりやすい目印・ランドマークは何ですか？」と尋ねる語「patokan」の意味は？

- [x] 1. 目印・基準・ランドマーク (正解)
- [ ] 2. 靴のサイズ
- [ ] 3. 料理の味
- [ ] 4. 警察署の電話番号

### 問3: 裏路地を通る際、治安が不安な時に「この道を通っても安全ですか？」と確認する表現は？

- [x] 1. Apakah aman lewat jalan ini? (正解)
- [ ] 2. Apakah jalan ini sangat mahal?
- [ ] 3. Apakah jalan ini terbuat dari kue?
- [ ] 4. Berapa banyak mobil di sini?
