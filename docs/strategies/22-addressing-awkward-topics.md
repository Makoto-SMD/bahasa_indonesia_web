# 【戦略会話】気まずい話題の切り出し：納期遅延・金銭・ミスの報告を申し訳なさそうに切り出す

言いにくいこと（納期の遅延、作業ミス、貸したお金の催促、契約の不備）を伝える際、前置きなしに直球で切り出すと相手の防衛本能を刺激し、怒りや摩擦を生みます。「Sebenarnya agak berat menyampaikannya...（実は申し上げにくいのですが…）」「Ada hal yang perlu kami luruskan...（修正が必要な点がありまして…）」と、心理的クッションを置いてスマートに切り出す技術を訓練します。

## 1. 戦略的キラーフレーズ対比表（公式・ビジネス ⇄ 日常会話 ⇄ 緊急サバイバル）

| No | 公式・ビジネス表現 | 日常・カジュアル口語 | 状況・ニュアンス |
|---|---|---|---|
| 1 | `Sebenarnya ada hal yang agak berat untuk disampaikan...` | **Sebenernya agak gak enak nih ngomongnya...** | 切り出しクッション |
| 2 | `Terkait kendala yang tidak kami duga...` | **Ada kendala tak terduga nih...** | 不測の事態の前置き |
| 3 | `Mohon maaf bila hal ini menimbulkan ketidaknyamanan.` | **Sori ya kalo bikin gak nyaman.** | 事前のお詫び |
| 4 | `Boleh minta waktu empat mata sebentar?` | **Bisa ngobrol berdua bentar gak?** | 個別相談の打診 |

## 2. サバイバル戦略・交渉心理のメカニズム

海外や異文化の現場において、予期せぬトラブルや摩擦は避けられません。しかし、適切な言語ストラテジー（意味交渉、クッション言葉、ユーモア、代替案提示、毅然とした権利主張）を用いることで、トラブルは相手との絆を深める最高の機会へと転換されます。

## 4. 理解度チェッククイズ

### 問1: 相手に言いにくい重大な話題を切り出す際、最も適切なクッション言葉は？

- [x] 1. Sebenarnya agak berat / tidak enak menyampaikan hal ini... (正解)
- [ ] 2. Hei kamu bodoh!
- [ ] 3. Dengarkan saya sekarang juga!
- [ ] 4. Tertawalah bersamaku!

### 問2: デリケートな問題（身だしなみやプライベートなミス）を指摘する際のマナーとして鉄則なのは？

- [x] 1. 他人のいない場所で1対1（bicara empat mata）で伝えること (正解)
- [ ] 2. 全員の前で大声でバカにすること
- [ ] 3. SNSで拡散して晒すこと
- [ ] 4. 黙って陰口を叩くこと

### 問3: 納期遅延やミスを報告する際、相手の怒りを最小限に抑えるための必須要素は？

- [x] 1. ミスの事実だけでなく、具体的な打開策や新しい完了見込み日程をセットで提示すること (正解)
- [ ] 2. すべて他人のせいにして逃げること
- [ ] 3. 泣き真似をして同情を引くこと
- [ ] 4. 会社を無断欠勤すること
