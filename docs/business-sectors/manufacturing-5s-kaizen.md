# B01: 製造現場の5S活動（Ringkas, Rapi, Resik, Rawat, Rajin）と改善活動

インドネシアに進出する日系製造業（自動車、二輪、電機、化学、食品等）の工場において、生産性向上と安全確保の基盤となるのが「5S活動」と「カイゼン（Kaizen）」です。

現地工場では、日本の5S概念に対応するインドネシア語訳として **5R（Ringkas, Rapi, Resik, Rawat, Rajin）**、または **5S（Seiri, Seiton, Seiso, Seiketsu, Shitsuke）** の用語がそのまま浸透しています。本記事では、工場現場での5S巡回点検、不要品撤去、定位置管理、日常清掃の徹底を促すための実務インドネシア語を体系的に学びます。

---

## 1. 5S・5R・カイゼンに関する重要現場語彙

| インドネシア語 / 略語 | 日本語対応 | 現場での定義・実務メモ |
| :--- | :--- | :--- |
| **Ringkas (Seiri)** | 整理 | 必要なものと不要なものを明確に分け、不要なものを現場から撤去する |
| **Rapi (Seiton)** | 整頓 | 必要なものを誰もがすぐに取り出せるよう、指定位置・定量を明示する |
| **Resik (Seiso)** | 清掃 | ゴミやホコリ、油汚れを清掃し、機械の微小な不具合を発見する |
| **Rawat (Seiketsu)** | 清潔 | 上記3Rを徹底して維持し、標準化（Standardisasi）された状態を保つ |
| **Rajin (Shitsuke)** | 躾（習慣化） | 決められた規則やルールを現場作業員が自発的に正しく守る習慣をつける |
| **Kaizen / Perbaikan Berkelanjutan** | カイゼン・継続的改善 | ムダ（pemborosan）を排除し、小さな改善を積み重ねる活動 |
| **pemborosan (Muda)** | ムダ・ロス | 動作のムダ、過剰生産、在庫のムダ、手待ち、運搬のムダなど |
| **patroli 5R / inspeksi visual** | 5Sパトロール / 目視点検 | 管理者・リーダーが定期的に現場を巡回し、基準違反を発見・指導する |
| **label merah (red tag)** | 赤札作戦 | 不要品や滞留在庫に赤札を貼り、処分または隔離エリアへ移動させる手法 |
| **area karantina / penampungan sementara** | 一時保管エリア / 隔離区画 | 要否判定中の品物や不良品を一時的に隔離する指定場所 |
| **papan pengumuman 5R (shadow board)** | 5S掲示板 / 姿置きボード | 工具の形をくり抜いて所定位置を視覚化（Visual Management）する板 |

## 2. 現場実践対話 (Percakapan di Lantai Pabrik)

### 場面1: 5Sパトロール時の現場リーダーへの指導

工場長（日本人マネージャー）が現場リーダー（Supervisor / Leader）とともに組立ラインを巡回し、工具の散乱と未分類の部品箱について是正を指示する場面です。

:::id-example
**Manajer**: Selamat pagi, Pak Budi. Ayo kita mulai patroli 5R mingguan untuk area Line 2.  
**Supervisor**: Selamat pagi, Pak. Baik, semua tim sudah siap untuk evaluasi hari ini.  
**Manajer**: Tolong perhatikan meja kerja di stasiun perakitan ini. Kunci pas dan obeng berserakan di atas meja, tidak dikembalikan ke papan bayangan (shadow board).  
**Supervisor**: Maaf, Pak. Tadi operator sedang terburu-buru mengganti komponen karena mengejar target pergantian shift.  
**Manajer**: Saya paham mereka sibuk, tetapi prinsip *Rapi* (Seiton) justru untuk mempercepat kerja agar tidak membuang waktu mencari alat. Tolong instruksikan operator untuk selalu mengembalikan alat ke posisinya segera setelah selesai digunakan.  
**Supervisor**: Siap, Pak. Saya akan kumpulkan para operator sekarang dan menegaskan kembali pentingnya pengembalian alat secara disiplin.
:::

- **patroli 5R mingguan**: 週間5Sパトロール
- **berserakan**: 散らかっている、散乱している
- **papan bayangan**: 姿置きボード（shadow board）
- **pergantian shift**: シフト交代

---

### 場面2: 不要品処分（赤札作戦）と保管場所の明確化

保管倉庫の一角に正体不明の古い治具や段ボールが山積みになっているのを発見し、赤札を貼って処分手続きを協議する場面です。

:::id-example
**Supervisor**: Pak, di sudut gudang bahan baku ini banyak tumpukan kardus dan *jig* bekas proyek tahun lalu yang berdebu.  
**Manajer**: Apakah barang-barang ini masih ada rencana untuk digunakan dalam produksi model baru?  
**Supervisor**: Menurut tim engineering, cetakan ini sudah kedaluwarsa dan spesifikasinya tidak cocok lagi dengan model terkini.  
**Manajer**: Kalau begitu, ini masuk kategori *pemborosan tempat*. Segera pasang label merah (red tag) pada semua kardus ini dan pindahkan ke area karantina sementara.  
**Supervisor**: Baik, Pak. Setelah diberi label merah, apakah kami bisa langsung mengajukan surat permohonan pemusnahan (disposal) ke bagian akuntansi?  
**Manajer**: Ya, foto kondisinya terlebih dahulu untuk lampiran laporan, lalu buat formulir pemusnahan aset agar tidak membebani laporan inventaris kita.
:::

- **kedaluwarsa**: 期限切れの、時代遅れになった
- **pemborosan tempat**: スペースのムダ
- **surat permohonan pemusnahan**: 廃棄申請書（disposal request）

## 3. 工場現場で即座に使える指示・報告フレーズ集

### 是正指示・指導のフレーズ

- **Tolong singkirkan barang-barang yang tidak terpakai dari jalur evakuasi.**  
  （避難通路から不要な物品を直ちに撤去してください。）
- **Garis batas area kerja ini sudah pudar, tolong dicat ulang dengan warna kuning cerah.**  
  （この作業エリアの境界線が薄くなっています。鮮やかな黄色で再塗装してください。）
- **Tentukan jumlah batas maksimum untuk stok perantara (WIP) di stasiun ini.**  
  （この工程における中間仕掛品（WIP）の最大保管数量を決定してください。）
- **Pastikan setiap wadah komponen memiliki label identifikasi yang jelas dan terbaca.**  
  （各部品コンテナに明確で読み取り可能な識別ラベルが貼られていることを確認してください。）

### 改善提案・報告のフレーズ

- **Kami berhasil mengurangi waktu pencarian cetakan dari sepuluh menit menjadi dua menit.**  
  （金型の探索時間を10分から2分に短縮することに成功しました。）
- **Dengan menerapkan tata letak baru ini, jarak tempuh operator berkurang drastis.**  
  （この新しいレイアウトを適用したことで、作業者の歩行距離が大幅に削減されました。）

---

> [!IMPORTANT]
> **5R活動を定着させるコツ（Kunci Sukses 5R）**  
> 単に「掃除しろ」「片付けろ」と号令をかけるだけでは、インドネシアの現場スタッフは「仕事が増えた」と感じて形骸化しがちです。なぜ5Rが必要なのか（事故防止、探す時間の削減、残業削減）という作業者側のメリットを説明し、月間ベスト5Rチームの表彰制度などを設けて現場のモチベーションを高める運用が効果的です。

## 4. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシアの製造現場における「5R」のなかで、「Seiton（整頓：定位置・定量管理）」に相当する単語はどれでしょう？</summary>

1. Ringkas  
2. Rapi  
3. Resik  

**正解: 2**  
**解説**: Ringkas＝整理（Seiri）、Rapi＝整頓（Seiton）、Resik＝清掃（Seiso）、Rawat＝清潔（Seiketsu）、Rajin＝躾（Shitsuke）です。
</details>

<details class="id-quiz">
<summary>Q2. 工場の保管スペースを圧迫する不要品や使わない治具に対して、要否判定を行うために貼る目印を何と呼ぶでしょう？</summary>

1. Kartu garansi  
2. Label merah (red tag)  
3. Faktur pajak  

**正解: 2**  
**解説**: 不要品を視覚的に特定し処分・隔離を促す手法は「赤札作戦（label merah / red tag）」と呼ばれます。
</details>
