## 1. 理論的課題と背景

歴史小説、宮廷劇、叙事詩、伝統儀礼のスピーチでは、現代標準語だけでは醸し出せない「歴史の重厚感と王者の威厳」を表現するために、宮廷語（Bahasa Keraton）や古風語（Kata Arkais）が巧みに用いられます。ジョグジャカルタやソロの王室伝統、古代マタラム・マジャパヒトの息吹を現代文に吹き込む文体技法を学びます。

---

## 2. プロの技法・実践フレームワーク

### 2.1. 宮廷風文体（Bahasa Istana / Keraton）の重要語彙群

1. **王と王族の行為**: 
   - 王の命令（titah / sabda baginda） ⇔ 臣下の伺い（sembah hamba）。
   - 王の怒り（murka） ⇔ 王の慈悲（kurnia / karunia）。
   - 滞在・御座す（bersemayam di atas takhta）。
   - 巡幸・行幸（berangkat / mangkat: 王の崩御）。
2. **古風な人称体系**: 
   - 臣下が王に対する一人称: **Patek / Hamba / Sahaya**（僕・臣）。
   - 王に対する二人称: **Tuanku / Duli Tuanku**（陛下・主上）。
3. **文語的装飾詞（Partikel Arkais）**: 
   - gerangan（一体〜であろうか: "Siapakah gerangan orang itu?"）。
   - alangkah（なんと〜であろうか）。

## 3. 実戦演習・ケーススタディ

言語の真髄に迫る最高峰の実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【宮廷語翻訳演習】歴史劇のセリフ「王様、臣下の申し上げますことを何卒お聞き届けください。」の最も格調高い宮廷語訳はどれか？

- A. "Ampun Tuanku, perkenankanlah hamba menyampaikan sembah puji ke hadapan Duli Baginda."
- B. "Halo Raja, tolong dengar omongan saya ya, ini penting banget."
- C. "Hei bos besar, saya mau bicara tolong dengarkan baik-baik ya."
- D. "Tuan Presiden, kami minta waktu bicara sebentar di depan Anda."

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. "Ampun Tuanku, perkenankanlah hamba menyampaikan sembah puji ke hadapan Duli Baginda."**」

**解説**:
「Ampun Tuanku（陛下、ご容赦を）」「hamba（臣）」「sembah（拝謁の言葉）」「Duli Baginda（主上）」という完全な宮廷語（Bahasa Istana）の語彙体系に合致しているのはAのみです。
</details>

## 4. 重要構文・専門語彙対比テーブル

本講のテーマに関連する最高峰の構文・専門語彙一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **titah baginda** | 王の仰せ・勅命・詔（Royal Decree） |
| **mangkat** | 王が崩御する（王族の死） |
| **bersemayam** | 王座に御座す・鎮座する |
| **murka** | 王が激怒する・怒り狂う |
| **hamba / patek** | 臣・下僕（王に対する一人称） |
| **siapakah gerangan...** | 一体誰であろうか（文語的疑問） |

## 5. プロ翻訳者・通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **最高峰を目指すワンポイント・アドバイス**:
> 日常会話で「mangkat（崩御）」や「titah（勅命）」を使うと滑稽ですが、歴史物や伝統文化行事の通訳・翻訳では、これらを正確に用いることで作品の品格が一瞬で跳ね上がります。
