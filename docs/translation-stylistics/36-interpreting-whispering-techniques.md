# 1486. 【通訳技術】ウィスパリング通訳の作法：小声で明瞭に伝える発声と距離感

## 1. 専門領域の課題と認知プロセス

専用ブースや音響設備のない役員会議、工場視察、法廷、ディナーの席で、特定クライアントの耳元で小声で同時通訳を行う「ウィスパリング（Chuchotage / Bisik-bisik）」。会議の進行を妨げず、クライアントの耳を疲れさせず、かつ自分自身の声帯を守るためのポジショニング、無声音発声、距離感の作法を解説します。

---

## 2. プロ通訳者の思考法・トレーニングフレームワーク

### 2.1. ウィスパリング通訳の3大プロフェッショナル作法

1. **適切な物理的ポジショニング（Duduk / Berdiri）**: 
   - クライアントの斜め後方45度、耳から30〜40cmの距離が黄金位置。真正面から話しかけたり、耳元に息を吹きかけるのは厳禁。
2. **無声音を主体とした腹式発声（Vokal Tanpa Desah）**: 
   - 単なる「ヒソヒソ声（息混じり声）」は摩擦音が強く耳障りで喉を痛める。声帯をあまり振動させず、子音の輪郭（アーティキュレーション）を口先で明瞭に発音する。
3. **パナガイド（携帯型送信機）の活用**: 
   - 聞き手が2名以上の場合は、ピンマイクと小型送信機（Infoport / Panaguide）を用いて通常の静かな声で発話する。

## 3. 実戦通訳シミュレーション演習

実務の現場で直面するリアルな対話・スピーチを完璧に通訳する実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【ウィスパリング作法問題】重要顧客の隣でウィスパリング通訳を行う際、マナーおよび身体技法として最も適切なものはどれか？

- A. クライアントの利き耳側の斜め後ろに位置取り、息が直接耳にかからないよう配慮しつつ、子音を明瞭に発音して静かに語りかける。
- B. 相手の耳に口を密着させて、できる限り大きな息を吹き込みながらヒソヒソ声で話す。
- C. 会議室の全員に聞こえるように、通常のプレゼンテーションと同じ大声で話す。
- D. クライアントの前に立ちふさがって、相手の視界を遮りながら通訳する。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. クライアントの利き耳側の斜め後ろに位置取り、息が直接耳にかからないよう配慮しつつ、子音を明瞭に発音して静かに語りかける。**」

**解説**:
クライアントのパーソナルスペースを尊重し、息を吹きかけず、子音の明瞭度を高めて疲労を与えないAがウィスパリングの基本作法です。
</details>

## 4. 重要通訳用語・状況対応テーブル

本講のテーマに関連する重要通訳用語・現場対応表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **chuchotage (bisik-bisik)** | ウィスパリング通訳・耳元通訳 |
| **artikulasi konsonan** | 子音の調音・明瞭な発音 |
| **sudut 45 derajat** | 斜め45度の位置取り |
| **perangkat pemancar nirkabel** | ワイヤレス送信機（パナガイド） |
| **kelelahan pita suara** | 声帯の疲労 |
| **ruang pribadi (personal space)** | パーソナルスペース・適切な対人距離 |

## 5. プロ通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **通訳現場で役立つワンポイント・アドバイス**:
> ウィスパリングを長時間（30分以上）1人で続けると、通常の発声よりも急速に喉が渇き疲弊します。常温の水を手元に用意し、小まめに喉を潤してください。
