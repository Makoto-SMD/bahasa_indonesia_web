# 1457. 【翻訳技法】「〜てくれる・〜てもらう」受益表現の翻訳ストラテジー

## 1. 言語対照分析と翻訳の課題

日本語の対人コミュニケーションの中核を成すのが「〜てくれる」「〜てあげる」「〜てもらう」という『授受・受益表現（Benefactive）』です。インドネシア語には日本語のような精緻な受益動詞体系が存在しないため、直訳しようとして「memberi」を乱用すると極めて幼稚な文になります。前置詞（untuk, bagi）、助動詞（bersedia, sudi）、あるいは受動態を活用して恩恵ニュアンスをエレガントに訳出する技法を習得します。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 受益表現のプロフェッショナル翻訳3大パターン

1. **「〜てくれる」（相手の好意による行為） → bersedia / dengan senang hati / sudi**:
   - 日: 「専門家が親切にアドバイスをしてくれた。」
   - 直訳: *Ahli memberi nasihat untuk saya secara baik. (稚拙)
   - 名訳: **Pakar tersebut bermurah hati memberikan masukan berharga kepada kami**.
2. **「〜てもらう」（依頼して恩恵を受ける） → meminta / memohon / bantuan**:
   - 日: 「弁護士に契約書を確認してもらった。」
   - 直訳: *Saya dapat konfirmasi kontrak dari pengacara. (誤謬)
   - 名訳: **Kami meminta pengacara untuk menelaah draf perjanjian tersebut** (または Draf perjanjian telah **ditelaah oleh pengacara kami**).
3. **「〜てあげる」（相手への親切） → 動詞 + untuk / demi**:
   - 日: 「同僚の仕事を手伝ってあげた。」
   - 名訳: **Saya membantu rekan kerja menyelesaikan tugasnya** (untuk dia は不要).

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【受益表現翻訳問題】「現地のパートナー企業が、工場用地の選定を快く手伝ってくれた。」の自然で洗練されたインドネシア語訳はどれか？

- A. Mitra lokal dengan senang hati membantu kami dalam memilih lokasi lahan pabrik.
- B. Teman lokal memberi tolong pada kita buat pilih tanah pabrik secara senang.
- C. Perusahaan partner kasih bantuan kepada saya untuk cari tanah pabrik.
- D. Kami dapat tolong dari teman lokal untuk pemilihan tanah pabrik.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Mitra lokal dengan senang hati membantu kami dalam memilih lokasi lahan pabrik.**」

**解説**:
「快く〜してくれた」を「dengan senang hati membantu kami（喜んで私たちを助けてくれた）」と品格ある語彙で再現したAが正解です。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **dengan senang hati** | 快く・喜んで（with pleasure） |
| **bermurah hati** | 寛大にも・親切にも〜してくれる |
| **menelaah draf** | 草案を精査・吟味する |
| **lahan pabrik** | 工場用地・敷地 |
| **masukan berharga** | 貴重な意見・有益なアドバイス |
| **rekan kerja** | 同僚・仕事仲間 |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> インドネシア語では、動詞そのもの（membantu, mendukung, mendampingi）に既に「支援・恩恵」の意味が含まれているため、無理に「memberi」を重ねる必要はありません。
