## 1. 専門領域の課題と認知プロセス

パンデミック以降、国際会議の標準となった「リモート同時通訳（Remote Simultaneous Interpreting: RSI / Zoom, Kudo, Interprefy）」。現場ブースとは異なる特有の課題（音声のレイテンシ、急な回線切断、パートナーとの非対面連携）を克服し、自宅やリモートハブから完璧なパフォーマンスを発揮するためのRSIプロトコルを体系化します。

---

## 2. プロ通訳者の思考法・トレーニングフレームワーク

### 2.1. RSI成功のための3大インフラ＆連携ルール

1. **絶対的な有線接続と機材環境（Infrastruktur Hardwire）**: 
   - Wi-Fiは厳禁。LANケーブル直結の光回線、単一指向性コンデンサーマイク、密閉型モニターヘッドホンが必須要件。
2. **裏チャット（Backchannel）によるパートナー連携**: 
   - WhatsAppやSlackに通訳ペア専用の裏チャンネルを開設。
   - 数字、固有名詞、略語の瞬時共有（例: 「IKN=Nusantara」「$12M=120億ドル」とパートナーが即座に打ち込んで助け合う）。
3. **交代プロトコル（Handover Rule）**: 
   - 15〜20分ごとの厳格な交代。交代の2分前に「2 menit lagi siap?」「OK, siap di slide berikutnya」と合図し、発話の句切れでスムーズにマイク権限をバトンタッチする。

## 3. 実戦通訳シミュレーション演習

実務の現場で直面するリアルな対話・スピーチを完璧に通訳する実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【RSI連携問題】自分がZoom同時通訳を担当中、パートナーが裏チャットに「BI-Rate 6,25% (naik 25 bps)」と打ち込んでくれた。この時、自分が取るべき最もプロフェッショナルな対応はどれか？

- A. チャット画面を一瞥して数字を確認し、音声通訳の中で「インドネシア銀行は政策金利を0.25%引き上げ、6.25%としました」と滑らかに訳出に反映させる。
- B. 通訳を中断して「チャットありがとう！」とマイクに向かって叫ぶ。
- C. パートナーのチャットを無視して、自分の聞き取った不確かな数字を話す。
- D. Zoomの全体チャットに「パートナーからメモが来ました」と書き込む。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. チャット画面を一瞥して数字を確認し、音声通訳の中で「インドネシア銀行は政策金利を0.25%引き上げ、6.25%としました」と滑らかに訳出に反映させる。**」

**解説**:
同時通訳はペア（2名）によるチーム戦です。パートナーがアシストしてくれた重要数字を即座に視覚で拾い、何事もなかったかのように滑らかに発話に組み込むAが最高峰のチームプレイです。
</details>

## 4. 重要通訳用語・状況対応テーブル

本講のテーマに関連する重要通訳用語・現場対応表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Remote Simultaneous Interpreting (RSI)** | リモート同時通訳（遠隔同通） |
| **saluran komunikasi cadangan (backchannel)** | 裏連絡チャット（WhatsApp等） |
| **pergantian giliran (handover)** | 通訳交代（通常15〜20分間隔） |
| **latensi audio** | 音声遅延・レイテンシ |
| **koneksi kabel LAN (hardwire)** | 有線LAN接続 |
| **mikrofon kondensor terarah** | 単一指向性マイク |

## 5. プロ通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **通訳現場で役立つワンポイント・アドバイス**:
> RSIでは、自分がマイクオフ（Mute）の時こそがパートナーへの貢献のチャンスです。登場した固有名詞や数字を裏チャットに即座にタイピングして相方をサポートしてください。
