# 1496. AI翻訳時代における機械翻訳ポストエディット（MTPE）の実践

## 1. 理論的課題と背景

ChatGPTやDeepLなどのニューラル機械翻訳（NMT）や生成AIが普及した現代、プロ翻訳者に最も求められているのはゼロからの翻訳ではなく「AI生成訳文の誤謬を瞬時に見抜き、完璧な公用文へ磨き上げるポストエディット（MTPE: Machine Translation Post-Editing）」能力です。AIの典型的弱点（ハルシネーション、用語の不統一、文化的不適合）を外科手術のように修正する技術を確立します。

---

## 2. プロの技法・実践フレームワーク

### 2.1. ライトPE（Light PE） vs フルPE（Full PE）の基準

1. **ライトPE（Light Post-Editing）**: 
   - 社内情報把握目的。文法エラーと致命的誤訳（Mistranslation）のみを修正し、文体の洗練度は追求しない。
2. **フルPE（Full Post-Editing）**: 
   - 出版・契約・公式開示用。人手翻訳（Human Translation）と同等の完全無欠な品質を保証する。
3. **AI翻訳が最も引き起こしやすい3大トラップ**: 
   - **用語のブレ（Inconsistency）**: 同一文書内で「董事長」が Direktur と Presiden Komisaris に揺れる。
   - **受動態の乱用**: 日本語の「〜された」を直訳して di- を不自然に連発する。
   - **幻覚（Hallucination）**: 原文にない数字や否定語（tidak）を勝手に出力・欠落させる。

## 3. 実戦演習・ケーススタディ

言語の真髄に迫る最高峰の実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【MTPE実践演習】
原文: 「本協定は、双方の署名の日から効力を発する。」
AIの初期出力: *"Perjanjian ini mulai berlaku dari hari penandatanganan kedua belah pihak."*
プロ翻訳者としてフルPE（最高品質修正）を施した訳文はどれか？

- A. "Perjanjian ini mulai berlaku pada tanggal ditandatanganinya oleh Para Pihak."
- B. "Perjanjian ini jalan terus dari tanggal kedua orang tanda tangan bersama."
- C. "Surat ini sah mulai hari ketika dua pihak menulis nama mereka."
- D. "Perjanjian ini aktif sejak hari ditandatangani oleh semuanya."

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. "Perjanjian ini mulai berlaku pada tanggal ditandatanganinya oleh Para Pihak."**」

**解説**:
AIの拙い直訳（dari hari... kedua belah pihak）を、契約書公用文の厳格な定型句「pada tanggal ditandatanganinya oleh Para Pihak（両当事者により署名された日をもって発効する）」へ完璧にブラッシュアップしたAが模範的なフルPEです。
</details>

## 4. 重要構文・専門語彙対比テーブル

本講のテーマに関連する最高峰の構文・専門語彙一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Machine Translation Post-Editing (MTPE)** | 機械翻訳ポストエディット |
| **Light Post-Editing (LPE)** | ライト・ポストエディット（最低限の誤り修正） |
| **Full Post-Editing (FPE)** | フル・ポストエディット（人手翻訳同等品質化） |
| **halusinasi AI** | AIのハルシネーション（もっともらしい事実無根の出力） |
| **inkonsistensi terminologi** | 用語の不統一・表記揺れ |
| **kelancaran bahasa (fluency)** | 訳文の流暢さ・自然さ |

## 5. プロ翻訳者・通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **最高峰を目指すワンポイント・アドバイス**:
> MTPE作業で最も重要なのは「数字の照合（Number Check）」です。AIは文脈が流暢であればあるほど、数字（桁や日付）のすり替わりに気づきにくいため、数字だけを目視で徹底突合してください。
