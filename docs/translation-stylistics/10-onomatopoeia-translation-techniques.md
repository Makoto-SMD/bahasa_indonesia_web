# 1460. 【翻訳技法】日本語オノマトペ・擬音語擬態語のインドネシア語描写技法

## 1. 言語対照分析と翻訳の課題

日本語には4,000語以上ものオノマトペ（擬音語・擬態語）が存在し、感情、触覚、動作の機微を鮮やかに表現します（ドキドキ、キラキラ、サクサク、イライラなど）。インドネシア語には同等の一対一対応語が存在しないことが多いため、プロの翻訳者は「具体的な動詞」「副詞的描写句」「比喩表現」を駆使して情景を生き生きと描き出します。オノマトペ翻訳の極意を伝授します。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 日本語オノマトペのインドネシア語パラフレーズ技術

1. **感情・心理オノマトペ**: 
   - 「ドキドキする（緊張・不安）」 → **berdebar-debar** / jantung berdegup kencang
   - 「イライラする」 → **kesal** / merasa jengkel / naik darah
   - 「ワクワクする」 → **sangat bersemangat** / tak sabar menantikan
   - 「ホッとする」 → **merasa lega**
2. **状態・質感オノマトペ**: 
   - 「キラキラ輝く」 → **berkilauan** / gemerlap
   - 「サクサクした食感」 → tekstur yang **renyah** (krispi)
   - 「モチモチした食感」 → tekstur yang **kenyal**
   - 「ツルツルした肌」 → kulit yang **halus mulus**
3. **動作・進捗オノマトペ**: 
   - 「仕事がサクサク進む」 → pekerjaan **berjalan lancar tanpa hambatan**
   - 「ウロウロ歩き回る」 → **berjalan mondar-mandir** tanpa tujuan

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【オノマトペ翻訳問題】「面接の順番を待つ間、心臓がドキドキして手が汗でびっしょりになった。」の最も文学的・情景描写として優れたインドネシア語訳はどれか？

- A. Saat menunggu giliran wawancara, jantung saya berdegup kencang dan telapak tangan saya basah oleh keringat.
- B. Waktu tunggu giliran wawancara, hati saya doki-doki dan tangan penuh air.
- C. Pas antre wawancara, jantung saya bunyi keras sekali dan tangan saya basah kuyup.
- D. Ketika nunggu wawancara, saya berdebar dan tangan keluar banyak keringat.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Saat menunggu giliran wawancara, jantung saya berdegup kencang dan telapak tangan saya basah oleh keringat.**」

**解説**:
「ドキドキする → jantung berdegup kencang」「びっしょり → basah oleh keringat」と、オノマトペの感覚を生理的・身体的描写へ精密に翻訳しているAが正解です。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **jantung berdegup kencang** | 心臓がドキドキ・激しく鼓動する |
| **merasa lega** | ホッとする・胸をなでおろす |
| **renyah / krispi** | サクサク・カリカリした（食感） |
| **kenyal** | モチモチ・弾力のある（食感） |
| **halus mulus** | ツルツル・スベスベした（肌触り） |
| **mondar-mandir** | ウロウロ・行ったり来たりする |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> オノマトペを訳すときは、「音」を訳そうとせず、「その時、身体や心や物がどんな状態にあるのか」という『現象の本質』にフォーカスして描写語を選ぶのがプロのコツです。
