# 1455. 【翻訳技法】インドネシア語の被動構文を自然な日本語能動文に変換する定石

## 1. 言語対照分析と翻訳の課題

前講とは逆に、イ日翻訳（インドネシア語→日本語）において頻出する落とし穴が「インドネシア語の受動態（di- および前置代名詞受動態）の直訳癖」です。インドネシア語では客観的事実や公用報告において受動態が極めて好まれますが、日本語で「〜された」「〜によって行われた」を連発すると、極めて拙劣な翻訳調の悪文になります。自然な日本語の能動文へ変換するノウハウを解説します。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. イ日翻訳における脱・受動態化テクニック

1. **前置代名詞受動構文（Pasif Persona） → 日本語能動態**:
   - イ: "Rencana ini **telah kami diskusikan** dengan pihak mitra."
   - 拙訳: 「この計画は、私たちによって提携先と議論された。」
   - 名訳: 「当社は、本計画について提携先と協議を重ねてまいりました。」
2. **三人称受動構文（di-...） → 日本語の名詞述語・能動文**:
   - イ: "Pembangunan jembatan tersebut **diselesaikan** dalam waktu enam bulan."
   - 拙訳: 「その橋の建設は6ヶ月の時間の中で完了された。」
   - 名訳: 「同橋の建設工事は、わずか6ヶ月で完了しました。」
3. **指示・要請の受動態（Diharapkan... / Dimohon...） → 丁寧な依頼能動文**:
   - イ: "Pengunjung **dilarang merokok** di area ini."
   - 拙訳: 「来場者はこのエリアでタバコを吸うことを禁じられる。」
   - 名訳: 「当エリア内での喫煙はご遠慮ください。」

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【イ日受動態転換問題】
"Laporan pertanggungjawaban tahunan telah disetujui oleh seluruh pemegang saham dalam Rapat Umum Pemegang Saham (RUPS)."
最もプロフェッショナルで自然な日本語ビジネス訳はどれか？

- A. 年次報告書は定時株主総会において全株主によって承認された。
- B. 定時株主総会（RUPS）において、全株主が年次活動報告書を満場一致で承認いたしました。
- C. 株主総会の中で全株主が年次報告書を承認した状態になった。
- D. 年次責任報告書が株主総会で株主たちからオッケーをもらった。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. 定時株主総会（RUPS）において、全株主が年次活動報告書を満場一致で承認いたしました。**」

**解説**:
受動態直訳の「全株主によって承認された」を排し、「全株主が〜を承認いたしました」と自然な能動文に再構成しているBがプロの実務翻訳基準を満たしています。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Rapat Umum Pemegang Saham (RUPS)** | 定時株主総会（Annual General Meeting of Shareholders） |
| **laporan pertanggungjawaban** | 業務報告書・活動報告書・決算報告 |
| **disetujui secara aklamasi** | 満場一致で承認される |
| **pihak mitra** | 提携先・パートナー企業 |
| **dimohon dengan hormat** | 何卒〜していただきますようお願い申し上げます |
| **dilarang keras** | 固くお断りいたします・厳禁 |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> 日本語の公用文やビジネス報告では、「誰が何を承認した」「誰が何を決定した」という能動の骨格が最も明快で信頼感を与えます。受動態の「〜された」は可能な限り削ぎ落としましょう。
