# 1453. 【翻訳技法】日本語の接尾辞型抽象名詞（〜性、〜化、〜感）のインドネシア語変換

  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 実務翻訳者・上級学習者（CEFR B2〜C1）</span>

## 1. 言語対照分析と翻訳の課題

日本語のビジネス・学術文章には「安全性、可能性、利便性（〜性）」「デジタル化、都市化、合法化（〜化）」「危機感、連帯感、清潔感（〜感）」といった漢字の接尾辞による抽象名詞が頻出します。これらを機械的に直訳するのではなく、インドネシア語の造語接辞体系（ke--an, peN--an, rasa/nuansa）と的確に結びつける変換技術を体系化します。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 3大抽象接尾辞のインドネシア語対応パターン

1. **「〜性」（性質・状態・可能性） → ke--an または -itas**:
   - 安全性 → **keamanan**
   - 可能性 → **kemungkinan**
   - 柔軟性 → **fleksibilitas** / **kelenturan**
   - 実現可能性（フィージビリティ） → **kelayakan**
2. **「〜化」（プロセス・変革・作為） → peN--an または -isasi**:
   - デジタル化 → **digitalisasi**
   - 効率化 → **pengefisienan** / **peningkatan efisiensi**
   - 義務化 → **kewajiban** / **penjadikan wajib**
3. **「〜感」（感覚・感情・雰囲気） → rasa / nuansa / sensasi**:
   - 危機感 → **rasa krisis** / **urgensi**
   - 連帯感 → **rasa solidaritas**
   - 達成感 → **rasa pencapaian** / **kepuasan tersendiri**
   - 清潔感 → **kesan bersih** / **kebersihan**

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【抽象名詞翻訳問題】「我が社は業務プロセスの合理化を通じて、コスト競争力の強化を図る。」の自然なインドネシア語訳はどれか？

- A. Perusahaan kami berupaya memperkuat daya saing biaya melalui rasionalisasi proses operasional.
- B. Perusahaan kita mau bikin kuat kompetisi harga lewat rasional operasional.
- C. Kami mencoba memperbesar menang biaya dari jalan merasionalkan proses.
- D. Perusahaan mau menguatkan lomba harga melalui pembikinan proses yang masuk akal.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Perusahaan kami berupaya memperkuat daya saing biaya melalui rasionalisasi proses operasional.**」

**解説**:
「合理化 → rasionalisasi」「競争力 → daya saing」「強化を図る → berupaya memperkuat」という学術・経営語彙が的確に選ばれているAが正解です。
</details>

---

### 第2問

「リーダーは組織全体に危機感を共有させることが求められる。」の「危機感」の訳語として最も適切なものはどれか？

- A. rasa urgensi / kesadaran krisis
- B. rasa bahaya akut
- C. perasaan takut rugi
- D. nuansa celaka

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. rasa urgensi / kesadaran krisis**」

**解説**:
ビジネス・組織論における「危機感（事態が急迫しているという認識）」は「rasa urgensi（切迫感）」または「kesan/kesadaran akan krisis」と表現するのがプロの定訳です。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **rasionalisasi proses** | プロセスの合理化（〜化） |
| **daya saing** | 競争力（〜力） |
| **kelayakan proyek** | プロジェクトの実現可能性（フィージビリティ：〜性） |
| **rasa solidaritas** | 連帯感（〜感） |
| **transparansi** | 透明性（akuntabilitas=説明責任） |
| **efektivitas** | 有効性・実効性 |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> 「〜化」を訳す際、単に「-isasi」を多用するのではなく、動詞句に開いて「peningkatan kualitas（品質向上＝高度化）」のように名詞句として具体化すると、より自然なインドネシア語になります。
