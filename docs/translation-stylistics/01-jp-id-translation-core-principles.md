# 1451. 【翻訳技法】日イ翻訳の根本原理：日本語の主語省略とインドネシア語の主語復元

## 1. 言語対照分析と翻訳の課題

日本語は「話題優勢言語（Topic-prominent Language）」であり、文脈から明らかな主語や行為者を徹底的に省略する特徴を持ちます。一方、インドネシア語は英語と同様に「主語・述語の明確な結合（S-V構造）」を厳格に要求する言語です。日本語の文をそのまま直訳すると主語欠落の不自然な悪文（kalimat pincang）になるため、文脈から適切な主語（kami, kita, perusahaan, pemerintah など）を特定・復元するプロの翻訳技法を解説します。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 主語復元（Restorasi Subjek）の判断基準

1. **発信者の視点（一人称復元）**: 
   - 日: 「検討の上、明日までにご連絡いたします。」
   - 誤: *Akan menghubungi sampai besok setelah mempertimbangkan.
   - 正: **Kami akan menghubungi Anda** paling lambat besok setelah mempertimbangkannya.
2. **包括的共同体（包括的一人称 kita の活用）**: 
   - 日: 「地球環境を守るために、省エネに取り組む必要があります。」
   - 正: **Kita perlu** melakukan penghematan energi demi menjaga kelestarian lingkungan bumi.
3. **組織・制度・一般主体（Institusi / Pelaku Umum）**: 
   - 日: 「申請書は窓口で受理されます。」
   - 正: **Petugas loket akan menerima** berkas permohonan tersebut (または Berkas permohonan **diterima di loket**).

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【主語復元翻訳問題】次の日本文のビジネスインドネシア語訳として最も自然で文法的に完全なものはどれか？
「来週水曜日までに修正版の図面を再提出していただけますと幸甚に存じます。」

- A. Kami sangat menghargai apabila Anda dapat menyerahkan kembali revisi gambar rancangan paling lambat hari Rabu depan.
- B. Sangat bahagia kalau bisa kirim lagi gambar revisi sampai hari Rabu depan.
- C. Jika menyerahkan revisi gambar hari Rabu depan, maka merasa sangat senang.
- D. Tolong ya gambar revisinya dikirim balik Rabu depan biar kita senang.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Kami sangat menghargai apabila Anda dapat menyerahkan kembali revisi gambar rancangan paling lambat hari Rabu depan.**」

**解説**:
日本語で省略されている「私たち（Kami）」と「あなた（Anda）」の主語を明確に復元し、公式ビジネス定型句「Kami sangat menghargai apabila Anda dapat...（〜していただけますと幸いです）」に落とし込んだAが完璧な名訳です。
</details>

---

### 第2問

「本件についてご不明な点がございましたら、いつでもお問い合わせください。」の自然なインドネシア語訳はどれか？

- A. Apabila Anda memiliki pertanyaan terkait hal ini, jangan ragu untuk menghubungi kami kapan saja.
- B. Kalau ada tidak jelas soal ini, kontak saja kapan pun.
- C. Jika bingung tentang hal ini, silakan tanya terus.
- D. Menghubungi kami kapan saja apabila tidak paham hal ini.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Apabila Anda memiliki pertanyaan terkait hal ini, jangan ragu untuk menghubungi kami kapan saja.**」

**解説**:
主語「Anda」と「kami」を補い、「jangan ragu untuk menghubungi kami（ご遠慮なくお問い合わせください）」というビジネスの定型表現を用いたAが模範です。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Kami sangat menghargai...** | 〜していただけますと幸甚です（主語Kamiを復元） |
| **Jangan ragu untuk...** | ご遠慮なく〜してください（敬意を込めた依頼） |
| **kalimat pincang** | 主語欠落などの不完全文・破綻文 |
| **restorasi subjek** | 主語の復元・明示化 |
| **paling lambat...** | 遅くとも〜までに（by no later than） |
| **berkas permohonan** | 申請書類一式 |
