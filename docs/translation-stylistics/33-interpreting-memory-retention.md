# 1483. 【通訳技術】通訳者の短期記憶トレーニング：シャドーイングとリプロダクション

## 1. 専門領域の課題と認知プロセス

逐次通訳で話者が30秒〜1分間話している間、ノートを取りつつ内容を脳内に保持するためには強靭な「短期記憶・作業記憶（Working Memory）」が必須です。脳の認知的キャパシティを劇的に拡張し、記憶の脱落（Memory Loss）を防ぐための『プロ式シャドーイング』と『リプロダクション（再生演習）』の科学的トレーニング法を公開します。

---

## 2. プロ通訳者の思考法・トレーニングフレームワーク

### 2.1. 記憶保持力を鍛える3段階エクスサイズ

1. **プロディレイ・シャドーイング（Delayed Shadowing）**: 
   - 音声の直後ではなく、あえて「3〜4語遅れ（2〜3秒遅れ）」で音声を影のように追唱する。常に数語分の音声を脳内バッファに溜める負荷をかける。
2. **キーファクト・リプロダクション（Fact Reproduction）**: 
   - メモを取らずに2〜3文のインドネシア語ニュースを聴き、主語、動詞、数字、固有名詞の事実関係だけを即座に同じ言語（インドネシア語）で復元して発話する。
3. **イメージ・マッピング法（Mental Visualization）**: 
   - 単語を文字列として覚えるのではなく、話者の語るストーリーを頭の中で「動画・絵」として映画のスクリーンに映し出すように記憶する。

## 3. 実戦通訳シミュレーション演習

実務の現場で直面するリアルな対話・スピーチを完璧に通訳する実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【リテンション・数字保持問題】音声で「Kuartal lalu, volume ekspor nikel olahan mencapai 450 ribu ton senilai 1,2 miliar dolar AS, naik 15 persen dibanding tahun sebelumnya.」と流れた。保持すべき中核ファクトの組み合わせとして最も正確なものはどれか？

- A. ニッケル加工品輸出: 45万トン / 12億米ドル / 15%増
- B. ニッケル鉱石輸出: 450万トン / 120億米ドル / 50%増
- C. 銅加工品輸出: 4万5千トン / 1.2兆ルピア / 15%減
- D. 原油輸出: 45万バレル / 12億ドル / 1.5%増

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. ニッケル加工品輸出: 45万トン / 12億米ドル / 15%増**」

**解説**:
450 ribu ton（45万トン）、1,2 miliar dolar AS（12億ドル）、naik 15 persen（15%増）という重要数値を正確に保持できているのはAです。
</details>
