# 1458. 【翻訳技法】日本語の使役「〜させる」と接辞 -kan/-i のニュアンス適合性

## 1. 言語対照分析と翻訳の課題

日本語の使役助動詞「〜させる」には、「強制（〜させる）」「放任・許可（〜させておく／〜させてあげる）」「原因・誘発（〜という状態に至らせる）」という全く異なる意味合いが含まれます。インドネシア語でこれらをすべて「menyuruh」や「membuat」で訳すと重大なニュアンスの誤解を招きます。使役接辞（-kan）と使役動詞（membiarkan, menyuruh, mendorong, memicu）の精密な適合性を分析します。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 「〜させる」の4大ニュアンスと訳し分け

1. **状態変化の使役（対象を〜な状態にする） → 接尾辞 -kan**:
   - 「部屋を暖かくさせる（暖める）」 → **menghangatkan** ruangan.
   - 「作業を容易にさせる（容易にする）」 → **memudahkan** pekerjaan.
2. **強制・命令の使役（人に〜することを命じる） → menyuruh / mewajibkan / memerintahkan**:
   - 「部下にレポートを再提出させた。」 → **memerintahkan / meminta bawahan** untuk menyerahkan ulang laporan.
3. **許可・放任の使役（〜したいようにさせる） → membiarkan / mengizinkan**:
   - 「子供たちを自由に遊ばせておく。」 → **membiarkan** anak-anak bermain dengan bebas.
4. **原因・心理的誘発の使役（〜という感情を抱かせる） → membuat / memicu / membuahkan**:
   - 「その決定は市民に失望をもたらさせた（失望させた）。」 → Keputusan tersebut **membuat masyarakat kecewa** (または **memicu kekecewaan publik**).

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【使役識別演習】「政府の急な方針転換が、市場に混乱を生じさせた。」の翻訳として最も格調高いものはどれか？

- A. Perubahan kebijakan pemerintah yang mendadak memicu kekacauan pasar.
- B. Pemerintah ganti aturan cepat bikin pasar jadi bingung.
- C. Kebijakan pemerintah suruh pasar bikin ribut.
- D. Perubahan aturan membiarkan pasar jadi kacau balau.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Perubahan kebijakan pemerintah yang mendadak memicu kekacauan pasar.**」

**解説**:
原因・誘発の使役「〜を生じさせた・引き起こした」には、動詞「memicu（引き金を引く→引き起こす）」または「menimbulkan」を用いるAが完璧な経済公用文です。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **memicu kekacauan** | 混乱を引き起こす・生じさせる（誘発） |
| **memudahkan proses** | プロセスを円滑化・容易にする（状態化 -kan） |
| **mengizinkan akses** | アクセスを許可する・認めさせる（許可） |
| **mewajibkan karyawan** | 従業員に義務付ける（強制） |
| **membiarkan berkembang** | 自然に発展させる・放任する（放任） |
| **kekecewaan publik** | 世論・市民の失望 |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> 学術論文やビジネス報告では、「membuat（作る）」という汎用動詞を避け、「mendorong（促進させる）」「memicu（引き起こす）」「mengakibatkan（結果を生じさせる）」などの因果動詞を使うと文章の格調が一気に跳ね上がります。
