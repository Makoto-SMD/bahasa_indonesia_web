# 1490. 【通訳技術】医療通訳・患者アテンド：問診票・インフォームドコンセントと心理ケア

<div class="article-meta">

  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 医療通訳者・国際病院アテンド（CEFR C1〜C2）</span>

## 1. 専門領域の課題と認知プロセス

インドネシア人患者の日本での高度医療受診、または在留邦人の現地総合病院（Siloam, Pondok Indah, Medistra等）受診を支援する「医療通訳（Penerjemahan Medis）」。問診票の記入、病状の聴取、医師からのインフォームド・コンセント（説明と同意）、および不安を抱える患者への心理的ケアの作法を伝授します。

---

## 2. プロ通訳者の思考法・トレーニングフレームワーク

### 2.1. 医療通訳の3大プロフェッショナル原則

1. **解剖学・症状表現の精密な聴取（Anamnesis）**: 
   - 痛みの性質の識別: ズキズキ（nyeri berdenyut）、キリキリ・差し込む痛み（nyeri melilit）、チクチク（nyeri menusuk）、重苦しい痛み（pegal / linu）。
2. **インフォームド・コンセントの完全性（Informed Consent）**: 
   - 手術のリスク、合併症（komplikasi）、代替治療法（terapi alternatif）を過不足なく患者に母国語で理解させ、自由意思に基づく同意書への署名を支援する。
3. **感情的共感と医療倫理の調和**: 
   - 不安がる患者の心に寄り添いつつも、勝手な医学的判断や気休めの予断（「大丈夫ですよ、すぐ治ります」等）は口にしない。

## 3. 実戦通訳シミュレーション演習

実務の現場で直面するリアルな対話・スピーチを完璧に通訳する実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【医療問診通訳問題】患者が「昨日の夜から、胃がキリキリと差し込むように痛んで、冷や汗が出ます。」と訴えた。医師への正確なインドネシア語訳出（または現地医師への説明）はどれか？

- A. "Sejak kemarin malam, perut bagian atas saya terasa nyeri melilit yang tajam dan disertai keringat dingin."
- B. "Perut saya sakit sekali kemarin malam dan ada air keluar dari kulit saya."
- C. "Tadi malam perut saya rusak seperti dipotong dan badan saya dingin sekali."
- D. "Lambung saya menangis sejak semalam dan keluar keringat es banyak."

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. "Sejak kemarin malam, perut bagian atas saya terasa nyeri melilit yang tajam dan disertai keringat dingin."**」

**解説**:
「キリキリ差し込む痛み」を「nyeri melilit yang tajam（内臓が捻れるような鋭い痛み）」と正確に医学表現化し、「冷や汗（keringat dingin）」を適切に結びつけたAが医療通訳の模範です。
</details>

## 4. 重要通訳用語・状況対応テーブル

本講のテーマに関連する重要通訳用語・現場対応表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **nyeri melilit** | キリキリ・差し込むような腹痛（colicky pain） |
| **nyeri berdenyut** | ズキズキする脈打つ痛み（throbbing pain） |
| **keringat dingin** | 冷や汗（cold sweat） |
| **persetujuan tindakan medis (Informed Consent)** | インフォームドコンセント・侵襲的医療行為への同意 |
| **komplikasi pasca-operasi** | 術後合併症 |
| **riwayat alergi obat** | 薬物アレルギー歴 |

## 5. プロ通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **通訳現場で役立つワンポイント・アドバイス**:
> 医療通訳では、患者が医師の前で遠慮して症状を控えめに言ってしまう傾向があります。患者の「実は…」という微細な呟きを絶対に聞き漏らさず医師に伝えることが命を救います。
