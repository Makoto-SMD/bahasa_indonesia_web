# 1464. 【契約書翻訳】雇用契約書・就業規則の条文対訳と労働法規語彙

## 1. 実務領域の課題と背景

インドネシア雇用創出法（UU Cipta Kerja）および労働法（UU Ketenagakerjaan）に基づく「有期雇用契約（PKWT）」「無期雇用契約（PKWTT）」「就業規則（Peraturan Perusahaan: PP）」「解雇（PHK）」「退職手当（Pesangon）」の法規用語と翻訳定型句を完全解説します。

---

## 2. プロの翻訳ストラテジー・対比フレームワーク

### 2.1. 労働法規の重要概念と契約書条文

1. **雇用形態の区分**: 
   - **PKWT** (Perjanjian Kerja Waktu Tertentu): 有期雇用契約（試用期間の設置は法律上禁止）。
   - **PKWTT** (Perjanjian Kerja Waktu Tidak Tertentu): 無期・正社員雇用契約（最大3ヶ月の試用期間: masa percobaan 可）。
2. **賃金・手当の体系**: 
   - 基本給（upah pokok）、固定手当（tunjangan tetap）、変動手当（tunjangan tidak tetap）、宗教大祭手当（THR: Tunjangan Hari Raya Keagamaan）。
3. **契約終了と解雇（PHK）に伴う補償金**: 
   - 解雇予告手当・退職金（uang pesangon: UP）、勤続報奨金（uang penghargaan masa kerja: UPMK）、権利補償金（uang penggantian hak: UPH）、有期雇用満了補償金（uang kompensasi PKWT）。

## 3. 実戦翻訳比較演習

実務の現場で通用する正確無比なプロの訳文を練り上げる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【労務条文翻訳問題】「会社は、社員が就業規則に定める重大な規律違反を犯した場合、書面による事前の警告なしに即時解雇することができる。」の法的に正確な訳はどれか？

- A. Perusahaan berhak melakukan Pemutusan Hubungan Kerja (PHK) secara serta-merta tanpa surat peringatan terlebih dahulu apabila Karyawan terbukti melakukan pelanggaran berat sebagaimana diatur dalam Peraturan Perusahaan.
- B. Kantor boleh pecat karyawan langsung tanpa surat peringatan kalau orang itu nakal sekali.
- C. Perusahaan bisa keluarkan pegawai cepat-cepat jika ada kesalahan besar menurut aturan kantor.
- D. Majikan dapat memberhentikan buruh seketika tanpa peringatan jika dia bikin ribut besar.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Perusahaan berhak melakukan Pemutusan Hubungan Kerja (PHK) secara serta-merta tanpa surat peringatan terlebih dahulu apabila Karyawan terbukti melakukan pelanggaran berat sebagaimana diatur dalam Peraturan Perusahaan.**」

**解説**:
「Pemutusan Hubungan Kerja (PHK)（雇用関係の終了/解雇）」「secara serta-merta（即時に）」「surat peringatan（警告書）」「pelanggaran berat（重大な違反）」「Peraturan Perusahaan（就業規則）」という労働法の厳格な専門用語に合致しているのはAのみです。
</details>

## 4. 重要専門用語・条文対比テーブル

本講のテーマに関連する重要専門用語・公用表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Perjanjian Kerja Waktu Tertentu (PKWT)** | 有期雇用契約（契約社員） |
| **Perjanjian Kerja Waktu Tidak Tertentu (PKWTT)** | 無期雇用契約（正社員） |
| **Tunjangan Hari Raya (THR)** | 宗教大祭手当（ボーナス手当） |
| **uang pesangon** | 退職手当・解雇補償金（severance pay） |
| **uang penghargaan masa kerja** | 勤続功労報奨金（service pay） |
| **masa percobaan** | 試用期間（最大3ヶ月） |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **実務翻訳の現場で役立つワンポイント・アドバイス**:
> 「PHK」は単なるクビ（pemecatan）ではなく、自己都合退職、定年退職、契約満了、懲戒解雇を含む「雇用関係終了全般」を指す包括的な法律概念です。
