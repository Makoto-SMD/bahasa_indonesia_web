## 1. 専門領域の課題と背景

スマートフォンアプリやWebサービスのUI（User Interface）ローカライゼーションでは、「ボタン幅の制限」「画面の視認性」「用語の一貫性」が極めて厳格に求められます。日本語の短い漢字（例:「保存」「設定」「削除」）を、文字数が長くなりがちなインドネシア語へと直感的かつコンパクトに落とし込むプロのローカライズ技術を体系化します。

---

## 2. プロの翻訳・通訳ストラテジー

### 2.1. 主要UIアクション文字列の標準定訳と文字数最適化

1. **基本アクションボタン**: 
   - 保存: **Simpan** (×Menyimpan)
   - キャンセル・戻る: **Batal** / **Kembali**
   - 削除: **Hapus** (×Menghapus)
   - 設定: **Pengaturan** (×Setelan: Google系はSetelanだが一般はPengaturan)
   - 編集: **Edit** / **Ubah**
2. **状態・トグル・通知**: 
   - 有効 / 無効: **Aktif** / **Nonaktif**
   - 成功しました: **Berhasil** (例: Profil berhasil diperbarui)
   - 失敗しました: **Gagal** (例: Gagal memuat data)
3. **プレースホルダーとエラーメッセージ**: 
   - 「メールアドレスを入力」: Masukkan alamat email
   - 「必須項目です」: Bidang ini wajib diisi

## 3. 実戦翻訳・通訳比較演習

実務の現場で通用する正確無比なプロの訳文・訳出を練り上げる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【UIローカライズ演習】モバイルアプリのポップアップダイアログ「このアカウントを完全に削除しますか？この操作は取り消せません。」のUI文案として最も直感的で洗練されたものはどれか？

- A. Hapus akun ini secara permanen? Tindakan ini tidak dapat dibatalkan.
- B. Apakah Anda mau menghapus akun ini selamanya? Ini tidak bisa kembali lagi ya.
- C. Mau buang akun ini sekarang? Nanti tidak bisa dibikin balik lho.
- D. Apakah betul-betul ingin menghapuskan akun? Kalau sudah hapus selesai.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Hapus akun ini secara permanen? Tindakan ini tidak dapat dibatalkan.**」

**解説**:
「Hapus akun... secara permanen?（アカウントを恒久的に削除しますか？）」「Tindakan ini tidak dapat dibatalkan（この操作は取り消せません）」というグローバルIT企業の標準的UIローカライズ基準に完全に合致しているのはAです。
</details>

## 4. 重要専門用語・構文対比テーブル

本講のテーマに関連する重要専門用語・公用表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Simpan** | 保存（Save） |
| **Batal** | キャンセル（Cancel） |
| **Hapus secara permanen** | 完全に削除（Delete permanently） |
| **Pengaturan** | 設定（Settings） |
| **Wajib diisi** | 必須（Required field） |
| **Gagal memuat data** | データの読み込みに失敗しました |

## 5. プロ翻訳者・通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **実務現場で役立つワンポイント・アドバイス**:
> ボタンなどのラベルには、接頭辞 meN- を付けた動詞（Menyimpan, Menghapus）ではなく、語根動詞（Simpan, Hapus）を用いるのがUIローカライズの鉄則です。
