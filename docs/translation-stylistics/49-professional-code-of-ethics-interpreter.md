# 1499. 通訳者・翻訳者の国際職業倫理規定：守秘義務と専門的誠実さ

<div class="article-meta">

  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: プロ通訳者・実務翻訳者・AIIC/HPI会員（全言語専門家対象）</span>
</div>

## 1. 理論的課題と背景

言語の職人である通訳者・翻訳者が、多国籍企業、国家機関、裁判所から絶対的な信頼を勝ち得るための根幹にあるのが「職業倫理規定（Kode Etik Profesi / Code of Professional Ethics）」です。国際会議通訳者連盟（AIIC）やインドネシア翻訳者協会（HPI: Himpunan Penerjemah Indonesia）の国際基準に準拠した、守秘義務、利益相反の回避、中立性の倫理を学びます。

---

## 2. プロの技法・実践フレームワーク

### 2.1. 国際通訳・翻訳者の4大倫理義務（AIIC / HPI 基準）

1. **絶対的守秘義務（Kerahasiaan Mutlak）**: 
   - 業務上知り得た機密情報（M&A情報、未公開決算、個人情報）は、契約終了後も生涯にわたり第三者への漏洩・自己の利益利用を固く禁じる（インサイダー取引の厳禁）。
2. **忠実性と正確性（Fidelitas & Akurasi）**: 
   - 自己の思想・信条・好悪を差し挟まず、原発話者の意図、ニュアンス、感情のトーンを忠実に母国語へ再現する。
3. **能力の限界の開示（Kompetensi Profesional）**: 
   - 自己の能力や準備時間を超える専門外の案件は、無責任に引き受けず辞退するか、事前の専門資料開示を誠実に要求する。
4. **利益相反の回避と中立性（Netralitas & Konflik Kepentingan）**: 
   - 紛争当事者の双方と利害関係がある場合は即座に開示し、中立な第三者としての立場を死守する。

## 3. 実戦演習・ケーススタディ

言語の真髄に迫る最高峰の実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【職業倫理ケーススタディ】通訳中、ある上場企業の未発表M&A交渉を担当した通訳者が、会議終了後に知人に「あの会社、近々買収されるから株を買っておいた方がいいよ」と漏らした。この行為の倫理的・法的判断として正しいものはどれか？

- A. 職業倫理規定における絶対的守秘義務に明白に違反するだけでなく、金融商品取引法上のインサイダー取引（insider trading）として刑事罰の対象となる重大な違法行為である。
- B. 知人に親切で教えただけなので、金銭を受け取っていなければ倫理上問題ない。
- C. 会議が終了した時点で通訳者の守秘義務は消滅するため法的に自由である。
- D. 会社の名前を出さずに業種だけ話したのであれば守秘義務違反には当たらない。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. 職業倫理規定における絶対的守秘義務に明白に違反するだけでなく、金融商品取引法上のインサイダー取引（insider trading）として刑事罰の対象となる重大な違法行為である。**」

**解説**:
通訳者・翻訳者が業務上得た未公開重要事実を漏らすことは、職業倫理（Kode Etik）の最も重篤な違反であり、法律上のインサイダー取引として実刑・巨額の賠償責任を負う犯罪行為です。
</details>
