# 1467. 【財務翻訳】財務諸表（貸借対照表・損益計算書）の用語対訳と注記の翻訳

## 1. 実務領域の課題と背景

インドネシア会計基準（PSAK / SAK: Standar Akuntansi Keuangan）および国際財務報告基準（IFRS）に完全準拠した「財政状態計算書（Neraca / Laporan Posisi Keuangan）」「包括利益計算書（Laporan Laba Rugi dan Penghasilan Komprehensif Lain）」、および会計方針注記（Catatan atas Laporan Keuangan）の財務対訳を体系的に解説します。

---

## 2. プロの翻訳ストラテジー・対比フレームワーク

### 2.1. 財務諸表主要科目の日英イ対照表

1. **資産の部（Aset / Assets）**: 
   - 流動資産（Aset Lancar）: 現金及び現金同等物（Kas dan Setara Kas）、売掛金（Piutang Usaha）、棚卸資産（Persediaan）。
   - 非流動資産（Aset Tidak Lancar）: 有形固定資産（Aset Tetap）、減価償却累計額（Akumulasi Penyusutan）、のれん（Goodwill）。
2. **負債及び純資産の部（Liabilitas & Ekuitas / Liabilities & Equity）**: 
   - 流動負債（Liabilitas Jangka Pendek）: 買掛金（Utang Usaha）、短期借入金（Pinjaman Jangka Pendek）。
   - 固定負債（Liabilitas Jangka Panjang）: 社債（Obligasi）、退職給付引当金（Liabilitas Imbalan Kerja）。
   - 資本（Ekuitas）: 資本金（Modal Saham）、利益剰余金（Saldo Laba / Retained Earnings）。
3. **損益計算書科目（Laba Rugi）**: 
   - 売上高（Pendapatan / Penjualan Bersih）、売上原価（Beban Pokok Pendapatan）、売上総利益（Laba Bruto）、営業利益（Laba Usaha / Operasional）、当期純利益（Laba Bersih Tahun Berjalan）。

## 3. 実戦翻訳比較演習

実務の現場で通用する正確無比なプロの訳文を練り上げる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【財務諸表対訳問題】インドネシアの決算書における「Beban Pokok Pendapatan」に相当する日本の会計用語はどれか？

- A. 売上原価（Cost of Goods Sold）
- B. 販管費（Selling & Administrative Expenses）
- C. 営業外費用（Non-operating Expenses）
- D. 特別損失（Extraordinary Loss）

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. 売上原価（Cost of Goods Sold）**」

**解説**:
「Beban Pokok Pendapatan」または「Beban Pokok Penjualan」は、商品やサービスの提供に直接かかった原価である「売上原価（Cost of Sales / COGS）」の正式な会計基準用語です。
</details>

## 4. 重要専門用語・条文対比テーブル

本講のテーマに関連する重要専門用語・公用表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Laporan Posisi Keuangan** | 財政状態計算書・貸借対照表（Balance Sheet） |
| **Laporan Laba Rugi** | 損益計算書（Income Statement） |
| **piutang usaha** | 売掛金・受取手形（Accounts Receivable） |
| **utang usaha** | 買掛金・支払手形（Accounts Payable） |
| **beban pokok pendapatan** | 売上原価（Cost of Sales） |
| **laba bersih tahun berjalan** | 当期純利益（Net Profit for the Year） |
