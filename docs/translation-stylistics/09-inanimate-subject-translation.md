## 1. 言語対照分析と翻訳の課題

インドネシア語や英語の学術・報道記事では「Penelitian ini membuktikan...（この研究は〜を証明している）」「Kecelakaan tersebut menewaskan...（その事故は〜人を死に至らしめた）」といった無生物主語構文（Inanimate Subject）が頻出します。しかし、日本語では事物を主語として人間のような動作をさせる表現は不自然です。日本語への翻訳において主客転換（因果構文・手段構文への変換）を行うプロの技法を学びます。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 無生物主語の日本語への構造転換 3大パターン

1. 「**研究・調査が〜を示している」 → 「〜によると／〜を通じて判明した**」:
   - イ: "Survei ini mengindikasikan bahwa kepuasan pelanggan menurun."
   - 拙訳: 「この調査は、顧客満足度が低下していることを示している。」
   - 名訳: 「**今回の調査結果によると**、顧客満足度の低下が明らかになりました。」
2. 「**事故・災害が〜を死亡させた」 → 「〜により、〜人が死亡した**」:
   - イ: "Bencana tanah longsor tersebut menewaskan lima warga."
   - 拙訳: 「その土砂崩れ災害は5人の住民を死亡させた。」
   - 名訳: 「**同土砂崩れ災害により**、住民5名が命を落としました。」
3. 「**テクノロジーが〜を可能にする」 → 「〜のおかげで、〜できるようになった**」:
   - イ: "Aplikasi ini memungkinkan pengguna untuk mentransfer uang secara instan."
   - 拙訳: 「このアプリはユーザーが瞬時に送金することを可能にする。」
   - 名訳: 「**本アプリを利用することで**、利用者は即時送金が可能となります。」

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【無生物主語の転換問題】
"Laporan Bank Dunia memperingatkan bahwa kenaikan suku bunga global akan memperlambat pertumbuhan ekonomi negara berkembang."
最も自然な日本語の報道文はどれか？

- A. 世界銀行の報告書は、世界的な金利上昇が途上国の経済成長を減速させると警告している。
- B. 世界銀行が発表した最新報告書によると、世界的な金利上昇に伴い、途上国の経済成長が減速する恐れがあると警鐘を鳴らしています。
- C. 世界銀行の書類は、世界の金利が上がって途上国の成長が遅くなると注意した。
- D. 世界銀行レポートは途上国の成長遅延を世界金利上昇によって警告させた。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**B. 世界銀行が発表した最新報告書によると、世界的な金利上昇に伴い、途上国の経済成長が減速する恐れがあると警鐘を鳴らしています。**」

**解説**:
「報告書によると（手段・根拠）」＋「金利上昇に伴い（原因）」＋「減速する恐れがあると警鐘を鳴らしている（客観報道）」と見事に日本語の報道文体へ再構成されているBが卓越した名訳です。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **memungkinkan pengguna** | 利用者が〜できるようにする（可能構文） |
| **menewaskan korban** | 犠牲者の命を奪う・死に至らしめる |
| **memperingatkan bahwa...** | 〜であると警告を発する・警鐘を鳴らす |
| **tanah longsor** | 土砂崩れ・地すべり |
| **memperlambat pertumbuhan** | 成長を減速・鈍化させる |
| **negara berkembang** | 発展途上国・新興国 |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> 無生物主語の文を見たら、主語を「〜によって」「〜のおかげで」「〜によると」という副詞句（原因・理由・手段）に置き換えるだけで、日本語の文章の硬さが一瞬で消え去ります。
