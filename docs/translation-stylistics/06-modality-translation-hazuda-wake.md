## 1. 言語対照分析と翻訳の課題

日本語の文末に現れるモダリティ（話し手の認識・判断）は、文脈によって極めて精緻な意味のグラデーションを持ちます。「〜はずだ（論理的当然・期待）」「〜わけだ（納得・必然の帰結）」「〜に違いない（強い推量・確信）」を、インドネシア語の助動詞・副詞（seharusnya, sudah sewajarnya, pasti, tentulah）へと過不足なく訳し分ける技術を学びます。

---

## 2. プロの翻訳ストラテジー・変換フレームワーク

### 2.1. 日本語モダリティのインドネシア語対応チャート

1. 「**〜はずだ**」（**客観的根拠に基づく当然の期待・予定**）:
   - 「書類は昨日届いたはずです。」 → Berkas itu **seharusnya sudah tiba** kemarin.
   - 「彼は来ないはずがない（絶対に来る）。」 → Tidak mungkin dia tidak datang / **Pasti dia datang**.
2. 「**〜わけだ**」（**理由を知って納得する・論理的帰結**）:
   - 「なるほど、それで電車が遅れたわけだ。」 → Pantas saja / **Wajarlah kalau keretanya terlambat**.
   - 「つまり、契約は無効というわけですね。」 → Jadi artinya, perjanjian ini batal demi hukum.
3. 「**〜に違いない**」（**話し手の主観的な強い確信**）:
   - 「この戦略は必ず成功するに違いない。」 → Strategi ini **pasti / niscaya akan berhasil**.
   - 「犯人は内部の事情に詳しい人物に違いない。」 → Pelakunya **tentulah orang yang sangat memahami** seluk-beluk internal.

## 3. 実戦翻訳比較演習

直訳の不自然さを解消し、プロの自然な訳文へ昇華させる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【モダリティ翻訳問題】「昨夜から激しい雨が降り続いていたのだから、川が氾濫したのも当然のわけだ。」のニュアンスを最も見事に再現したインドネシア語訳はどれか？

- A. Mengingat hujan lebat mengguyur sejak tadi malam, sangatlah wajar jika sungai meluap.
- B. Karena hujan deras kemarin malam, sungainya harus banjir.
- C. Tadi malam hujan banyak, jadi sungai banjir itu harusnya begitu.
- D. Kalau hujan lebat semalam, maka sungai meluap adalah pasti.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Mengingat hujan lebat mengguyur sejak tadi malam, sangatlah wajar jika sungai meluap.**」

**解説**:
「〜なのだから（Mengingat...）」「当然のわけだ（sangatlah wajar jika...）」という納得・因果帰結のモダリティが格調高く表現されています。
</details>

## 4. 重要構文・表現対比テーブル

本講のテーマに関連する重要構文・定型表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **seharusnya sudah...** | 〜したはずだ（当然の期待） |
| **pantas saja / wajarlah kalau...** | 〜なのも納得のわけだ・道理だ |
| **tentulah...** | 〜に違いない（強い推量・確信） |
| **niscaya...** | 確実に〜する・必ずや〜となる（文語的確信） |
| **meluap** | 氾濫する・あふれ出る（河川） |
| **seluk-beluk internal** | 内部の事情・詳細な内情 |

## 5. プロ翻訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **名訳を生み出すワンポイント・アドバイス**:
> 「はずだ」を訳す際、単に pasti（確信）とするのではなく、期待や規範が未達である文脈では「seharusnya（〜すべき／〜のはず）」を用いるのが重要な識別ポイントです。
