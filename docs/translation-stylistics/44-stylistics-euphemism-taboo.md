# 1494. 高度文体論：婉曲表現（Eufemisme）の美学：死・病・金銭・失敗を品良く語る

## 1. 理論的課題と背景

インドネシア社会は「調和（Kerukunan）」と「礼節（Kesantunan）」を至上命題とする高コンテキスト文化です。死、病気、貧困、解雇、身体障害などの重い現実を、角を立てず品格を保ってオブラートに包む『婉曲表現（Eufemisme）』は、大人のインドネシア語の教養の証です。その精緻な語彙体系をマスターします。

---

## 2. プロの技法・実践フレームワーク

### 2.1. 領域別・公用婉曲表現（Eufemisme）の対照表

1. **死（Kematian）**: 
   - mati / tewas（粗野） → **meninggal dunia** / **berpulang ke rahmatullah**（召される） / **tutup usia**（天寿を全うする）。
2. **貧困・困窮（Kemiskinan）**: 
   - orang miskin（直截） → **masyarakat prasejahtera**（前福祉層） / **keluarga kurang mampu**。
3. **身体的ハンディキャップ（Disabilitas）**: 
   - buta（盲目） → **tunanetra** / tuli（聾） → **tunarungu** / cacat（障害） → **penyandang disabilitas**。
4. **解雇・失業（PHK）**: 
   - dipecat（クビ） → **dirumahkan**（自宅待機） / **diberhentikan dengan hormat**（依願退職）。
5. **物価・料金の値上げ**: 
   - kenaikan harga → **penyesuaian tarif**（料金の適正化・調整）。

## 3. 実戦演習・ケーススタディ

言語の真髄に迫る最高峰の実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【婉曲表現選択問題】公的プレスリリースにおいて「当社は業績悪化に伴い、やむを得ず貧困家庭の従業員を解雇した」を、最も品格高く人権と社会規範に配慮してリライトしたものはどれか？

- A. Sehubungan dengan rasionalisasi bisnis, Perusahaan terpaksa melakukan perampingan organisasi terhadap sebagian karyawan dari kelompok masyarakat kurang mampu.
- B. Karena toko mau bangkrut, kami pecat orang-orang miskin yang kerja di sini.
- C. Perusahaan memberhentikan orang cacat dan orang susah sebab tidak ada uang gaji.
- D. Lantaran rugi banyak, majikan buang buruh-buruh yang tidak punya uang makan.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Sehubungan dengan rasionalisasi bisnis, Perusahaan terpaksa melakukan perampingan organisasi terhadap sebagian karyawan dari kelompok masyarakat kurang mampu.**」

**解説**:
「業績悪化 → rasionalisasi bisnis」「解雇 → perampingan organisasi（組織のスリム化）」「貧困層 → masyarakat kurang mampu」という最高水準の公用婉曲表現でまとめられたAが模範です。
</details>

## 4. 重要構文・専門語彙対比テーブル

本講のテーマに関連する最高峰の構文・専門語彙一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **tutup usia / berpulang** | 逝去する・他界する（死の婉曲） |
| **masyarakat prasejahtera** | 生活困窮層・低所得層（貧困の婉曲） |
| **penyandang disabilitas** | 障がい者（身体の婉曲） |
| **penyesuaian tarif** | 料金・価格の改定・調整（値上げの婉曲） |
| **perampingan organisasi** | 組織再編・人員適正化（解雇の婉曲） |
| **kesantunan berbahasa** | 言語的礼節・ポライトネス（Politeness） |

## 5. プロ翻訳者・通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **最高峰を目指すワンポイント・アドバイス**:
> インドネシアの公文書で「penyesuaian tarif（料金調整）」と書かれていたら、100%「値上げ（kenaikan tarif）」を意味します。社会的反発を和らげる行政の定番Eufemismeです。
