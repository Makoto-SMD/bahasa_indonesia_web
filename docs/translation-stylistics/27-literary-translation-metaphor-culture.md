# 1477. 【文化翻訳】比喩・文化的暗号の翻訳：注釈をつけずに文脈で溶け込ませる職人技

  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 文芸翻訳者・上級学習者（CEFR C1〜C2）</span>

## 1. 専門領域の課題と背景

「秋の日は釣瓶落とし」「清水の舞台から飛び降りる」のような文化固有の比喩を、欄外注釈（footnote）だらけにしては読書の没入感を破壊してしまいます。異文化のメタファーを、インドネシアの読者が自然に追体験できるように文脈内で溶け込ませる『文化的脱中心化・現地化（Domestikasi vs Foreignisasi）』の職人技を解説します。

---

## 2. プロの翻訳・通訳ストラテジー

### 2.1. 文化的メタファー処理の3大翻訳アプローチ

1. **機能的等価物への置換（Functional Equivalence）**: 
   - 日: 「カエルの子はカエル」 → イ: **Air cucuran atap jatuhnya ke pelimbahan juga**（または Buah jatuh tidak jauh dari pohonnya: 親の血を引く）。
   - 日: 「喉元過ぎれば熱さを忘れる」 → イ: **Habis manis sepah dibuang**（用が済めば捨てられる）。
2. **文脈内での解きほぐし・語義の埋め込み（Textual Integration）**: 
   - 注釈をつけず、比喩の持つ感情・意味を本文の中に自然に補いながら描写する。
3. **異国情緒の保持（Foreignizing with Context Clues）**: 
   - 文化固有の単語（Tatami, Yukata, Wayang）をそのまま残しつつ、前後の動詞や形容詞で読者にその質感や役割を直感させる。

## 3. 実戦翻訳・通訳比較演習

実務の現場で通用する正確無比なプロの訳文・訳出を練り上げる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【ことわざ・比喩翻訳問題】「彼は一度の失敗に懲りて、すっかり臆病になってしまった（羹に懲りて膾を吹く）。」のインドネシア語の等価的ことわざとして最も適切なものはどれか？

- A. Sekali terantuk, dua kali tengadah.（一度つまずけば、二度目は上を向いて注意する）
- B. Bagai air di daun talas.（里芋の葉の上の水滴のように定まらない）
- C. Bagai kerakap tumbuh di batu.（岩の上に生える植物のように悲惨な境遇）
- D. Ada udang di balik batu.（岩の裏にエビがいる＝下心がある）

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Sekali terantuk, dua kali tengadah.（一度つまずけば、二度目は上を向いて注意する）**」

**解説**:
「一度痛い目に遭ったことで過剰に警戒する」という教訓の等価的なインドネシアのことわざは「Sekali terantuk, dua kali tengadah（一度つまずいたら、次は用心深くなる）」です。
</details>

## 4. 重要専門用語・構文対比テーブル

本講のテーマに関連する重要専門用語・公用表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **sekali terantuk, dua kali tengadah** | 一度の失敗に懲りて用心深くなる |
| **buah jatuh tidak jauh dari pohonnya** | 蛙の子は蛙・親の血は争えない |
| **ada udang di balik batu** | 下心がある・裏がある |
| **bagai air di daun talas** | 優柔不断・意見が定まらない |
| **domestikasi** | 自文化化（読者に馴染む表現に置き換える技法） |
| **foreignisasi** | 異文化化（現地の文化色をそのまま残す技法） |

## 5. プロ翻訳者・通訳者の着眼点・ワンポイントアドバイス

> [!TIP]
> **実務現場で役立つワンポイント・アドバイス**:
