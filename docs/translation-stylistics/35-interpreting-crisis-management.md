# 1485. 【通訳技術】通訳現場のトラブル対処法：聞き逃し・専門用語不明時のスマートリカバリー

## 1. 専門領域の課題と認知プロセス

どれほど経験を積んだプロ通訳者であっても、「音響トラブルで声が聞き取れなかった」「未知の専門略語が登場した」「早口すぎて数字を取りこぼした」という危機的状況は必ず発生します。パニックに陥ってフリーズすることなく、エレガントに聞き返し（Klarifikasi）、文脈から安全にリカバリーするプロの危機管理プロトコルを伝授します。

---

## 2. プロ通訳者の思考法・トレーニングフレームワーク

### 2.1. 通訳現場のトラブル別リカバリー・プロトコル

1. **完全に聞き取れなかった時（音声不良・雑音） → 即座の丁寧な確認**: 
   - 会議を止めずにスマートに促す: "Mohon maaf, suara Bapak sempat terputus. Bisakah diulangi angka terakhir?"（恐れ入ります、少々お声が途切れました。最後の数字をもう一度お願いできますでしょうか？）
2. **未知の専門用語・略語が登場した時 → 概念的パラフレーズ**: 
   - 単語を捏造せず、前後の文脈から「〜に関する制度／〜の装置」と上位概念（kategori umum）で安全に着地させる。
3. **自分が言い間違えた時 → 堂々とした即時訂正**: 
   - 取り乱さず、落ち着いたトーンで「Maksud saya, 15 triliun rupiah.（失礼いたしました、15兆ルピアでございます）」と訂正して進める。

## 3. 実戦通訳シミュレーション演習

実務の現場で直面するリアルな対話・スピーチを完璧に通訳する実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【現場トラブルシミュレーション】大臣のスピーチ中、会場のマイクが一瞬ハウリングを起こし、肝心な政策目標の年号（tahun target）が聞き取れなかった。通訳者として取るべき最も適切な行動はどれか？

- A. 発言終了直後、礼儀正しく「Mohon izin Bapak Menteri, untuk tahun target program tersebut tadi tertutup dengung mikrofon, apakah tahun 2030?」と事実確認を行い、正確な年号を訳出する。
- B. 聞こえなかったふりをして、年号の部分を完全に省いて通訳を終わらせる。
- C. 自分の勘で「おそらく2030年だろう」と推測してそのまま通訳する。
- D. その場でマイクを叩いて音響スタッフに向かって怒鳴る。

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. 発言終了直後、礼儀正しく「Mohon izin Bapak Menteri, untuk tahun target program tersebut tadi tertutup dengung mikrofon, apakah tahun 2030?」と事実確認を行い、正確な年号を訳出する。**」

**解説**:
数字や年号の誤訳・捏造は政策決定において致命的です。音響トラブルという客観的理由を添えて礼儀正しく確認を求めるAが、クライアントから最も信頼されるプロの立ち振る舞いです。
</details>

## 4. 重要通訳用語・状況対応テーブル

本講のテーマに関連する重要通訳用語・現場対応表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **manajemen krisis** | 危機管理・トラブルシューティング |
| **klarifikasi yang santun** | 礼儀正しい確認・聞き返し |
| **suara terputus** | 音声の途切れ・通信障害 |

| **koreksi mandiri** | 自己訂正（Self-correction） |
| **kategori umum** | 上位概念・包括的カテゴリー |
