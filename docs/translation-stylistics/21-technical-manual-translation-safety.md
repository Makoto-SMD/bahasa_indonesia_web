# 1471. 【産業翻訳】機械操作マニュアル・安全衛生規程の正確かつ明瞭な翻訳

<div class="article-meta">
  <span class="meta-item"><i class="fas fa-clock"></i> 読了目安: 15分</span>
  <span class="meta-item"><i class="fas fa-graduation-cap"></i> 対象レベル: 産業技術翻訳者・製造業現場管理者（CEFR B2〜C1）</span>
</div>

---

## 1. 専門領域の課題と背景

自動車・重機・電子機器の操作説明書（Buku Panduan Pengoperasian）や労働安全衛生（K3: Keselamatan dan Kesehatan Kerja）マニュアルは、作業員の生命と工場の安全に直結する最高度の明瞭性（Kejelasan）が求められます。曖昧な指示や誤解を生む表現を排除し、誰が読んでも直感的に理解できる命令構文（Kalimat Perintah Baku）の翻訳技法を解説します。

---

## 2. プロの翻訳・通訳ストラテジー

### 2.1. 安全警告表示の4段階国際規格とインドネシア語定訳

1. **【危険】BAHAYA (DANGER)**: 回避しないと死亡または重傷を招く切迫した危険。「Matikan sumber listrik utama sebelum membuka penutup mesin!（機械カバーを開ける前に主電源を切れ！）」
2. **【警告】PERINGATAN (WARNING)**: 死亡または重傷を招くおそれがある潜在的危険。「Gunakan kacamata pelindung saat mengoperasikan mesin gerinda!（グラインダー操作時は保護メガネを着用せよ！）」
3. **【注意】PERHATIAN (CAUTION)**: 軽傷または物的損害を招くおそれがある危険。「Jangan menyentuh bagian ini selama mesin beroperasi karena suhu tinggi!」
4. **【注記・指示】CATATAN (NOTICE)**: 操作上の重要な補足・製品寿命延長のための指示。

### 2.2. マニュアル翻訳の文体ルール

- 動詞原形または受動態で簡潔に記述する（Pastikan... / Tekan tombol... / Bersihkan filter...）。
- 「〜してください」を機械的に「Tolong...」と訳さず、公用指示語「Harap...」「Pastikan...」を用いる。

## 3. 実戦翻訳・通訳比較演習

実務の現場で通用する正確無比なプロの訳文・訳出を練り上げる実戦演習です。選択肢を吟味して解答した後、アコーディオンを開いて論理的解説を確認してください。

### 第1問

【安全マニュアル翻訳問題】「可燃性ガスの漏洩を防ぐため、バルブが完全に閉じていることを必ず確認してください。」の最も正確な産業マニュアル訳はどれか？

- A. Pastikan katup tertutup rapat guna mencegah kebocoran gas yang mudah terbakar.
- B. Tolong cek keran tutup rapat biar gas tidak keluar dan kebakaran.
- C. Harap Anda melihat katup sudah mati supaya gas yang gampang api tidak lepas.
- D. Harus yakin kalau pintu gas tertutup agar tidak ada gas meledak.

<details>
<summary>正解と解説を見る</summary>

**正解**: 「**A. Pastikan katup tertutup rapat guna mencegah kebocoran gas yang mudah terbakar.**」

**解説**:
「必ず確認せよ（Pastikan...）」「バルブが完全に閉じている（katup tertutup rapat）」「可燃性ガスの漏洩を防ぐため（guna mencegah kebocoran gas yang mudah terbakar）」という技術マニュアルの標準定型句を満たすのはAです。
</details>

## 4. 重要専門用語・構文対比テーブル

本講のテーマに関連する重要専門用語・公用表現一覧です。

| 表現・項目 | 解説・対応用法 |
| :--- | :--- |
| **Pastikan...** | 〜であることを確実に確認せよ（Make sure that...） |
| **katup tertutup rapat** | バルブが完全に密閉されている |
| **mudah terbakar** | 可燃性の・引火しやすい（flammable） |
| **Alat Pelindung Diri (APD)** | 個人防護具（PPE: ヘルメット・安全靴・メガネ等） |
| **Keselamatan dan Kesehatan Kerja (K3)** | 労働安全衛生（Occupational Health & Safety） |
| **matikan sumber listrik** | 主電源を遮断せよ・電源を切れ |
