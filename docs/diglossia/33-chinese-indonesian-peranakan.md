# 【二重言語】中華系インドネシア語（プラナカン語彙）：cuan, hoki, cincai, cici, koko

インドネシアの商業都市やビジネス界、若者カルチャーには、閩南語（ホッケン語）などの中華系方言にルーツを持つ語彙（プラナカン語彙）が深く定着しています。「cuan（利益・儲け）」「hoki（幸運）」「cincai（適当に・お任せで）」「koko / cici（お兄さん・お姉さん）」など、商談や投資、日常会話で頻出する必須語彙を学びます。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `keuntungan (利益・儲け)` | **cuan** | 株・ビジネス・副業の利益 |
| 2 | `keberuntungan (幸運・ラッキー)` | **hoki** | 運の良さ・ツキ |
| 3 | `mudah / fleksibel (柔軟に・適当に)` | **cincai** | 細かいことは気にせず融通を利かせる |
| 4 | `kakak laki-laki / perempuan` | **koko / cici** | 親愛を込めた呼称 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
