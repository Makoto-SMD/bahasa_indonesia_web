# 【二重言語】人称代名詞の3大レジスター（Baku: saya/Anda ⇄ Akrab: aku/kamu ⇄ Gaul: gue/lu）の境界線

インドネシア語の人称代名詞は、話し手と聞き手の社会的距離・心理的親密さ・地域性を如実に表します。目上に gue/lu を使うと致命的な無礼になり、親友に saya/Anda を使い続けると冷たい壁を作ります。3大レジスターの境界線を整理します。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Saya ingin bertanya kepada Anda.` | **Gue mau nanya dong sama lu.** | 私とあなた（saya/Anda ⇄ gue/lu） |
| 2 | `Aku sangat menyayangi kamu.` | **Gue sayang banget sama lu.** | 恋人・友人（aku/kamu ⇄ gue/lu） |
| 3 | `Nama saya Budi, senang bertemu.` | **Kenalin, gue Budi nih.** | 自己紹介のレジスター差 |
| 4 | `Silakan Anda masuk duluan.` | **Lu masuk duluan aja santai.** | 相手への呼びかけ（Anda ⇄ lu） |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
