# 【二重言語総括】標準語（Baku）⇄ 街角口語（Gaul）50問総合変換診断クリニック

セクション27で学んだ「日常動作、動詞meN-脱落、ke-受動態、代名詞、否定詞、アスペクト、疑問詞、助詞連打、WA略語、プロケム、方言借用（ジャワ・スンダ・プラナカン・スラバヤ・メダン）、南ジャカルタ言葉（Jaksel）、若者世代スラング、感情表出」の全領域を総括する、50問の完全双方向リライト総合診断クリニックです。

## 1. 総合レベル判定基準

| スコア（正答数） | レベル称号 | 診断結果と学習アドバイス |
|---|---|---|
| **45 〜 50 問** | **ネイティブ・バイリンガル級 (Master)** | 公式スピーチから街角の砕けたスラングまで完璧に制御。TPO判断も万全です。 |
| **35 〜 44 問** | **上級ストリートマスター (Advanced)** | 日常の会話やチャット、方言借用にも柔軟に対応可能。更なる洗練を目指しましょう。 |
| **25 〜 34 問** | **中級口語実践者 (Intermediate)** | 基本的な短縮形や助詞は理解できているが、スラングや方言の即応に課題があります。 |
| **0 〜 24 問** | **教科書固定化レジスター (Beginner)** | 標準語（Baku）に偏りすぎており、口語の聞き取りや砕けた会話に壁を感じる段階です。 |
