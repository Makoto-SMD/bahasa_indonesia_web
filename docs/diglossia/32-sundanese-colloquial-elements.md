# 【二重言語】スンダ語借用語の西ジャワ口語：teh, mah, atuh, euy, punten, nuhun

バンドンをはじめとする西ジャワ州（スンダ地方）のインドネシア語には、独特の柔らかなイントネーションとともに、スンダ語（Bahasa Sunda）の小詞や挨拶が濃厚に混じります。「punten（すみません）」「nuhun（ありがとう）」「atuh（〜だよ）」「mah（〜はね）」など、会話に柔らかさと愛嬌を添えるスンダ要素を学びます。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `permisi / maaf (すみません)` | **punten** | 道を通る時・声かけの丁寧な前置き |
| 2 | `terima kasih (ありがとう)` | **hatur nuhun / nuhun** | スンダ式の心温まる感謝 |
| 3 | `dong / tentu saja (〜ですよ)` | **atuh** | 柔らかく念を押す文末小詞 |
| 4 | `ya ampun / kawan (おい/まあ)` | **euy** | 親しい呼びかけ・感嘆の文末詞 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
