# 【二重言語】時間表現の口語短縮：sekarang → skrg / bentar, nanti → ntar, kemarin → kemaren

日常の会話やテキストチャット（WhatsApp）では、時間表現が驚くほど短縮されます。sebentar は bentar、nanti は ntar、kemarin は kemaren、tadi malam は semalem と音が縮まり、テンポの良い会話が生まれます。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Tunggu sebentar ya.` | **Tunggu bentar ya. / Bentar ya.** | ちょっと待って（sebentar ⇄ bentar） |
| 2 | `Nanti kita bicarakan lagi.` | **Ntar kita omongin lagi.** | あとで話そう（nanti ⇄ ntar） |
| 3 | `Kemarin saya pergi ke mall.` | **Kemaren gue cabut ke mal.** | 昨日（kemarin ⇄ kemaren） |
| 4 | `Tadi malam hujan sangat deras.` | **Semalem hujannya deres parah.** | 昨夜（tadi malam ⇄ semalem） |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
