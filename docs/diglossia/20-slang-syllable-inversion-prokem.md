# 【二重言語】ストリートスラング「プロケム（Prokem）音節反転法」（yuk → kuy, bisa → sabi）

ジャカルタの若者言葉やストリートカルチャーには、単語の音節や文字を逆さまにして発音する「バハサ・プロケム（Bahasa Prokem / Bahasa Terbalik）」の伝統があります。yuk が kuy、bisa が sabi、balik が libab など、ルールを知ると一瞬で解読できます。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `yuk (〜しよう)` | **kuy** | 音節反転（y-u-k → k-u-y） |
| 2 | `bisa (できる)` | **sabi** | 音節入替（bi-sa → sa-bi） |
| 3 | `balik (帰る)` | **kibal / libab** | 音節反転（ba-lik → kibal） |
| 4 | `suka (好き)` | **kusa** | 音節入替（su-ka → ku-sa） |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

- [ ] 3. Satu
