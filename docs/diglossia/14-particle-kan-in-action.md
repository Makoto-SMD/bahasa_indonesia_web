# 【二重言語】確認詞「kan」の説得術：「〜でしょ？」「ほらね！」の同意と共感形成

「kan」は bukan の短縮形から発展した確認詞です。「君も知ってるでしょ？（付加疑問）」「ほら、言った通りでしょ！（ほらね）」と、相手との共通認識を確認し、会話の同調・共感を瞬時に生み出す最強のコミュニケーションツールです。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Anda juga sudah tahu, bukan?` | **Lu juga udah tahu kan?** | 確認（君も知ってるでしょ？） |
| 2 | `Bukankah saya sudah memberitahu Anda?` | **Tuh kan, gue bilang juga apa!** | ほらね（ほら見たことか！） |
| 3 | `Hari ini hari Minggu, bukan?` | **Sekarang hari Minggu kan ya?** | 曜日確認（今日日曜日だよね？） |
| 4 | `Dia orang yang sangat baik.` | **Dia baik banget kan orangnya.** | 共感の同意（あの人すごく良い人だよね） |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 4. 理解度チェッククイズ

### 問1: 予想が的中した時に「ほらね、言った通りでしょ！」と言う定番スラングは？

- [x] 1. Tuh kan! (正解)
- [ ] 2. Iya sih!
- [ ] 3. Bisa dong!
- [ ] 4. Bukan deh!

### 問2: 文末に「kan?」を添える主要な役割は？

- [x] 1. 相手への確認・同調・共感を求める（〜でしょ？） (正解)
- [ ] 2. 強い命令を下す
- [ ] 3. 過去形にする
- [ ] 4. 敬語にする

### 問3: 「Kan gue udah bilang tadi（だってさっき言ったじゃん）」の文頭 kan の働きは？

- [x] 1. 既知の前提や理由の提示 (正解)
- [ ] 2. 未来の推量
- [ ] 3. 謝罪の言葉
- [ ] 4. 場所の指定
