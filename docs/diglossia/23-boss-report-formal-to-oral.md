# 【二重言語】上司への口頭進捗報告：かしこまりすぎず失礼にならない敬語ブレンド術

インドネシアの上司（Bapak / Ibu）への口頭報告は、格式ばった公文書の言葉そのままではぎこちなく、かといって友人言葉（Gaul）を使うと不敬になります。「敬称（Pak / Bu）＋丁寧な口語構文」の黄金バランスを身につけます。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Laporan telah selesai saya buat.` | **Laporannya sudah beres saya buat, Pak.** | 完了報告のブレンド |
| 2 | `Klien telah menyetujui kontrak.` | **Kliennya sudah setuju dengan kontraknya, Bu.** | 進捗報告のブレンド |
| 3 | `Ada sedikit kendala dalam proyek.` | **Mohon maaf Pak, ada sedikit kendala di lapangan.** | トラブル報告の配慮 |
| 4 | `Apakah saya boleh meminta persetujuan?` | **Bolehkah saya minta tanda tangan Bapak?** | 承認依頼の丁寧口頭 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 4. 理解度チェッククイズ

### 問1: 男性の上司に口頭で完了報告をする時の最も自然な切り出しは？

- [x] 1. Pak, laporannya sudah beres saya buat ya. (正解)
- [ ] 2. Bro, udah kelar nih.
- [ ] 3. Gue udah selesai kerjaan.
- [ ] 4. Woi bos, liat nih.

### 問2: 上司への提案で「〜はいかがでしょうか？」と柔らかく尋ねる表現は？

- [x] 1. Bagaimana menurut arahan Bapak jika... (正解)
- [ ] 2. Lu harus setuju ya Pak.
- [ ] 3. Pasti Bapak mau ini.
- [ ] 4. Wajib Bapak terima.

### 問3: 上司に書類の確認・承認をお願いする際の敬語表現は？

- [x] 1. Mohon kesediaan Bapak untuk memeriksa draf ini. (正解)
- [ ] 2. Tolong periksa cepat ya Pak.
