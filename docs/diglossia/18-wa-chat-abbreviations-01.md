# 【二重言語】WhatsAppチャット略語辞典①：子音短縮形（yg, bgt, tdk, dpt, spy, kpd, bsk）

インドネシア人の WhatsApp や SNS チャット画面を見ると、母音が極端に省略された暗号のような略語が飛び交っています。これはテキスト入力の高速化から生まれた文化的書法です。頻出の子音短縮形を完璧に解読できるようにします。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `yang (関係詞)` | **yg** | 最も頻出の関係詞短縮形 |
| 2 | `banget (とても)` | **bgt** | 強調詞 banget の子音短縮 |
| 3 | `tidak (ない)` | **tdk / g / gak** | 否定詞のチャット表記 |
| 4 | `besok (明日)` | **bsk** | 時間表現のチャット略語 |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 4. 理解度チェッククイズ

### 問1: チャットで「yg bgt」と書かれていた場合の元の標準語は？

- [x] 1. yang banget (とても〜な) (正解)
- [ ] 2. yang bagi
- [ ] 3. yang bagus
- [ ] 4. yang begitu

### 問2: 「bsk jm brp?」というメッセージの解読として正しいのは？

- [x] 1. Besok jam berapa? (明日何時？) (正解)
- [ ] 2. Bisa jam berapa?
- [ ] 3. Besok jalan berapa?
- [ ] 4. Biasa jam berapa?

### 問3: 否定の「tidak」をチャットで最も短く表記する記号は？

- [x] 1. tdk / gak / g (正解)
- [ ] 2. td
- [ ] 3. tk
