# 【二重言語】感情爆発の感嘆詞スラング：anjir, anjay, gokil, mantul, parah の度合いとTPO

インドネシアの街角で若者が驚いた時やテンションが上がった時に飛び交う感嘆詞（interjeksi）には、激しいニュアンスからユーモラスな表現まで幅広いグラデーションがあります。「anjir / anjay（うわっ！やばっ！）」「gokil（イカれてる・すごい！）」「mantul（超最高！）」「parah（ひどい・やばい）」など、感情の強さと使うべきTPOを学びます。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Luar biasa mengejutkan! (うわっ！やばい！)` | **Anjir / Anjay!** | 驚き・呆れ・感嘆の若者スラング |
| 2 | `Luar biasa hebat / gila! (イカれてる・すげえ！)` | **Gokil abis!** | 規格外の凄さや面白さを賞賛 |
| 3 | `Mantap betul! (超最高・ドンピシャ！)` | **Mantul bgt!** | 「mantap betul」の短縮語 |
| 4 | `Sangat parah / keterlaluan! (ひどすぎる・ヤバい！)` | **Parah sih ini!** | 呆れ返るほどの度を超えた状況 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 3. 双方向コード変換ドリル（15問ノック）

> **トレーニング手順**: 日本語と提示された文を見て、指定されたレジスター（Baku → Gaul または Gaul → Baku）へ1〜2秒以内に口頭で言い換えてください。
