# 【二重言語】口語助詞「kok」の心理：驚き、不審、「どうして？」の感情表出

文頭に置く「Kok... ?」は「えっ、どうして？なんで？（驚き・不審）」を表し、文末の「... kok」は「大丈夫だよ、本当に〜だから（安心・弁明）」を表します。置く位置によって役割がダイナミックに変わる口語の最重要ワードです。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Mengapa Anda belum tidur?` | **Kok belom tidur sih?** | 文頭kok: えっ、なんでまだ寝てないの？（驚き・疑問） |
| 2 | `Saya tidak apa-apa, jangan khawatir.` | **Nggak apa-apa kok, santai aja.** | 文末kok: 大丈夫だよ、心配いらないから（安心させる） |
| 3 | `Mengapa harganya bisa semahal ini?` | **Kok mahal banget ya?** | 文頭kok: なんでこんなに高いの？（不満・不審） |
| 4 | `Saya sungguh-sungguh tidak tahu.` | **Beneran nggak tahu kok.** | 文末kok: 本当に知らないんだってば（弁明） |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 4. 理解度チェッククイズ

### 問1: 相手を安心させて「大丈夫だよ、心配しないで」と言う時の文末詞は？

- [x] 1. Nggak apa-apa kok. (正解)
- [ ] 2. Nggak apa-apa dong.
- [ ] 3. Nggak apa-apa deh.
- [ ] 4. Nggak apa-apa sih.

### 問2: 思いがけない出来事に「えっ、なんで？（どうしてそんなことが？）」と驚く文頭詞は？

- [x] 1. Kok bisa?! (正解)
- [ ] 2. Bisa dong?!
- [ ] 3. Bisa deh?!
- [ ] 4. Bisa kan?!

### 問3: 文頭の「Kok...」と文末の「...kok」の機能差として正しいものは？

- [x] 1. 文頭は「驚き・疑問」、文末は「安心・弁明・念押し」 (正解)
- [ ] 2. 文頭は「命令」、文末は「過去形」
- [ ] 3. 文頭は「禁止」、文末は「願望」
- [ ] 4. どちらも全く同じ意味
