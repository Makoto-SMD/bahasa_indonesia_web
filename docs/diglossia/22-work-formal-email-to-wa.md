# 【二重言語】ビジネス文書 ⇄ 社内チャット変換：メール文体を同僚向けSlack/WAに変換

インドネシアの職場では、顧客や経営陣宛ての「公式ビジネスメール（Bahasa Baku）」と、同僚同士の「社内チャット（Slack / WhatsApp）」で劇的なコードスイッチングが行われます。同じ案件をいかに適切にレジスター変換するかを訓練します。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Dengan hormat, mohon konfirmasi.` | **Pagi bro/sis, minta konfirmasinya ya.** | 確認依頼のレジスター差 |
| 2 | `Dokumen terlampir untuk diperiksa.` | **Ini file-nya ya, tolong dicek.** | 添付ファイル共有の差 |
| 3 | `Terima kasih atas kerja samanya.` | **Tengkyu bgt bantuannya ya!** | 感謝の表現差 |
| 4 | `Mohon maaf atas keterlambatan ini.` | **Sori bgt baru sempet bales ya.** | 返信遅延の詫びの差 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 4. 理解度チェッククイズ

### 問1: 社内チャット（Slack/WA）で同僚に添付ファイルを送る時の最も自然な挨拶は？

- [x] 1. Ini file-nya ya, tolong dicek bro/sis. (正解)
- [ ] 2. Dengan hormat kami lampirkan berkas.
- [ ] 3. Kepada Yang Terhormat Saudara.
- [ ] 4. Bersama surat ini kami haturkan.

### 問2: クライアントが承認を出したことを社内チャットで「acc（アクセプト）」と言うが、元の語は？

- [x] 1. acc (dari kata Belanda: akkoord / accept) (正解)
- [ ] 2. account
- [ ] 3. accident
- [ ] 4. accelerate

- [x] 1. Terima kasih banyak atas kerja sama dan bantuan Bapak/Ibu. (正解)
- [ ] 2. Makasih bnyk bro.
- [ ] 3. Sip tengkyu.
