# 【二重言語】コードスイッチング作法：相手・場面・関係性に応じた切り替え境界と失礼回避術

インドネシア語の二重言語（Baku vs Gaul）において最も重要なのは、「どちらか一方だけを話すこと」ではなく、「相手の立場・年齢・場面に応じて適切なレジスターを選択し、失礼にならず親愛を示す切り替え（Code-Switching）ができること」です。失礼を回避し、好感度を高める大人の切り替え作法を訓練します。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Kepada atasan / klien (上司・顧客向け)` | **Bahasa Baku / Santun** | 敬意とプロ意識の維持 |
| 2 | `Kepada rekan sebaya (同僚・友人向け)` | **Bahasa Santai / Gaul Halus** | 親近感と円滑なチームワーク |
| 3 | `Di forum rapat resmi (公式会議の場)` | **Register Formal Tertib** | 正確な議論と記録の担保 |
| 4 | `Di sesi makan siang santai (ランチの雑談)` | **Register Kasual Akrab** | 本音の交流と心理的安全性 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
