# 【二重言語】同一シナリオ完全パラレル対比：同一の商談・雑談シーンを Baku と Gaul で演じ分ける

全く同じ内容の会話（プロジェクトの進捗確認、スケジュールの相談、問題解決、ランチの誘い）を、「完全公式標準語（Bahasa Baku）」と「完全ストリート口語（Bahasa Gaul）」の完全パラレルな2つのスクリプトで対比します。語彙、語順、助詞、代名詞がどう連動して変換されるかの総決算を行います。

|---|---|---|---|

| 3 | `Skenario 3: Penanganan Krisis (トラブル対応)` | **Baku: Analisis mitigasi risiko ⇄ Gaul: Gercep gerak cepat** | 危機対応のレジスター差 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
