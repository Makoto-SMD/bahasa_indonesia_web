# 【二重言語】疑問詞の口語変換：bagaimana → gimana, mengapa → kenapa, apakah → apa / apaan

標準語の疑問詞 bagaimana, mengapa, di mana は、日常会話では gimana, kenapa, mana に短縮・変容します。さらに「何それ？」と驚く apaan tuh? などの感情表現も豊富です。口語疑問詞のバリエーションを使いこなしましょう。

## 1. コードスイッチング対比表（Baku標準語 ⇄ Gaul口語）

| No | 公式標準語 (Bahasa Baku) | 街角口語 (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Bagaimana kabar Anda?` | **Gimana kabarnya? / Gimana kabarmu?** | 調子はどう？（bagaimana ⇄ gimana） |
| 2 | `Mengapa Anda terlambat datang?` | **Kenapa telat dateng?** | なぜ遅刻した？（mengapa ⇄ kenapa） |
| 3 | `Apakah ini milik Anda?` | **Ini punya lu bukan? / Apa ini?** | これは君の？（apakah ⇄ apa / apaan） |
| 4 | `Di mana Anda tinggal?` | **Tinggal di mana sih?** | どこに住んでるの？（di mana ⇄ di mana / mana） |

## 2. 構文・音韻変化のメカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。

## 3. 双方向コード変換ドリル（15問ノック）

> [!TIP]
> **トレーニング手順**: 日本語と提示された文を見て、指定されたレジスター（Baku → Gaul または Gaul → Baku）へ1〜2秒以内に口頭で言い換えてください。

### 第1問: 【Baku→Gaul】「**どうやって行くの？**」（Bagaimana cara perginya?）

<div class="id-example">
<div class="id-sentence"><strong>Gimana naiknya ke sana?</strong></div>
<div class="id-pronunciation">発音: ギマナ ナイスニャ ク サナ</div>
<div class="id-translation">解説: bagaimana cara ⇄ gimana。</div>
</div>

## 4. 理解度チェッククイズ

### 問1: 日常会話で「どうして？（why）」を尋ねる最も一般的な語は？

- [x] 1. kenapa (正解)
- [ ] 2. mengapa
- [ ] 3. sebab apa
- [ ] 4. alasan

### 問2: 「何だよそれ！」とくだけた調子でツッコミを入れる定番疑問詞は？

- [x] 1. Apaan tuh?! (正解)
- [ ] 2. Apakah gerangan?
- [ ] 3. Bagaimanakah itu?
- [ ] 4. Mengapa begitu?

### 問3: 「どう？（how）」を気軽に尋ねる口語疑問詞は？

- [x] 1. gimana (正解)
