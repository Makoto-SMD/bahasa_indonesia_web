# 【二重言語】怒り・不満のレジスター：Kami sangat menyayangkan ⇄ Parah banget sih / Kesel gue

不満や怒りを表す際、ビジネスや公の場での「冷静かつ客観的な抗議（Bahasa Baku）」と、親しい間柄での「感情を露わにする憤慨（Bahasa Gaul）」では使われる構文が劇的に異なります。「Kami sangat menyayangkan（遺憾に思う）」から「Kesel gue（超むかつく）」まで、レジスターの適切な切り替えを体得します。

## 1. コードスイッチング対比表（公式標準表現 ⇄ 口語・スラング）

| No | 公式標準表現 (Bahasa Baku) | 口語・スラング (Bahasa Gaul) | 意味・ニュアンス |
|---|---|---|---|
| 1 | `Kami sangat menyayangkan hal ini.` | **Parah bgt sih ini, kesel gue!** | 遺憾の意 ⇄ 強い怒りと苛立ち |
| 2 | `Mohon pertanggungjawabannya.` | **Gimana sih lu, kok lepas tanggung jawab?!** | 責任追及の公式表現 ⇄ 口語の問い詰め |
| 3 | `Hal ini tidak dapat kami toleransi.` | **Gak bisa dibiarin nih kelakuan kayak gini!** | 不容認の宣言 ⇄ 口語の制裁感情 |
| 4 | `Tindakan ini sangat mengecewakan.` | **Kecewa berat gue liat hasilnya.** | 失望の公式表明 ⇄ 率直な口語失望 |

## 2. 構文・文脈心理メカニズム

公式標準語の文法構造が、口語においてどのように短縮・脱落・母音変容（音韻融合）を起こしているかを理解することで、リスニングの「聞き取れない壁」を突破し、自然な発話が可能になります。
