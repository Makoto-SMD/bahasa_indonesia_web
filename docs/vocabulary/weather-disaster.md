# 天気・気候・自然現象・防災災害に関するインドネシア語単語集

赤道直下に位置する熱帯気候のインドネシアでは、日本のような春夏秋冬の四季はなく、「**雨季（musim hujan）**」と「**乾季（musim kemarau）**」の2つの季節が1年を二分しています。

また、環太平洋火山帯に位置することから、地震や火山の噴火、大雨に伴う洪水や冠水といった自然現象が日常の生活や交通に密接に関わってきます。気象予報機関 **BMKG（気象気候地球物理庁）** の発する情報や現地のニュースを正しく理解することは、安全管理上も不可欠です。

本記事では、日常の天気表現から雨・嵐の用語、季節の推移、自然災害・防災の専門単語までを網羅して解説します。

---

## 1. 基本の天気と空の状態（Cuaca Sehari-hari）

日々の天候を表す基本表現です。

| 単語 | 日本語の意味 | 用例・補足 |
| :--- | :--- | :--- |
| **cerah** | 快晴、晴天 | cuaca cerah berawan（晴れのち曇り、晴れ時々曇り） |
| **berawan** | 雲が多い、曇りがち | langit berawan（曇り空） |
| **mendung** | どんより曇った、雨が降りそうな | Langit sudah mendung gelap.（空がすでに薄暗く曇っている。） |
| **hujan** | 雨（あめ） | turun hujan（雨が降る）, sedia payung sebelum hujan（降らぬ先の傘・備えあれば憂いなし） |
| **panas** | 暑い、日差しが強い | terik matahari（照りつける太陽光） |
| **sejuk** | 涼しい、過ごしやすい | udara sejuk di pegunungan（山の涼しい空気） |
| **lembab / lembap** | 湿気がある、蒸し暑い | kelembapan udara tinggi（湿度が高い） |
| **angin** | 風（かぜ） | angin kencang（強風・突風）, semilir angin（そよ風） |

<div class="id-example">
<div class="id-sentence">Pagi ini cuaca sangat cerah, tetapi menjelang siang langit mulai mendung dan kemungkinan besar akan turun hujan.</div>
<div class="id-translation">今朝はとても良い天気ですが、昼前には空がどんより曇り始め、雨が降る可能性が非常に高いです。</div>
<div class="id-explanation">menjelang siang（昼前に） / kemungkinan besar（可能性が高い）。</div>
</div>

## 2. 雨の種類と熱帯気象現象（Jenis Hujan & Fenomena Tropis）

熱帯特有のスコールや雷雨に関する単語です。

| 単語 | 日本語の意味 | 特徴・解説 |
| :--- | :--- | :--- |
| **hujan deras / lebat** | 豪雨、激しい大雨 | 視界が遮られるほどの熱帯スコール。 |
| **hujan gerimis** | 霧雨、小雨 | gerimis rintik-rintik（パラパラと降る小雨）。 |
| **hujan es** | 雹（ひょう）、霰（あられ） | 積乱雲の発達により熱帯でも稀に発生する。 |
| **petir / kilat** | 雷、稲妻（光） | menyambar（落雷する）。 |
| **guntur / guruh** | 雷鳴（音、ゴロゴロ） | suara guntur menggelegar（雷鳴がとどろく）。 |
| **badai** | 嵐、暴風雨 | badai tropis（熱帯低気圧・サイクロン）。 |
| **pelangi** | 虹（にじ） | pelangi muncul setelah hujan（雨上がりに虹が出る）。 |
| **kabut** | 霧（きり）、もや | kabut tebal（濃霧）。 |

<div class="id-example">
<div class="id-sentence">Hati-hati saat berkendara karena hujan lebat disertai petir dan angin kencang sering melanda Jakarta di sore hari.</div>
<div class="id-translation">夕方にジャカルタを頻繁に襲う雷と突風を伴う大雨のため、車の運転には注意してください。</div>
<div class="id-explanation">disertai（〜を伴った） / melanda（〜を襲う、見舞う）。</div>
</div>

## 3. 季節・気候区分（Musim & Iklim）

インドネシアの2大季節と季節の変わり目です。

- **musim hujan**: 雨季（概ね10月〜4月頃。モンスーンの影響で午後に激しいスコールが降る）
- **musim kemarau**: 乾季（概ね5月〜9月頃。降水量が少なくカラッとした晴天が続く）
- **iklim tropis**: 熱帯気候
- **masa pancaroba**: 季節の変わり目（雨季から乾季、または乾季から雨季への移行期。天候が不安定で体調を崩しやすい）

<div class="id-example">
<div class="id-sentence">Selama musim kemarau, suhu udara pada malam hari di Bandung bisa terasa cukup dingin.</div>
<div class="id-translation">乾季の間、バンドンでの夜間の気温はかなり肌寒く感じられることがあります。</div>
<div class="id-explanation">suhu udara（気温） / musim kemarau（乾季）。標高の高い都市では乾季の夜間に冷え込みます。</div>
</div>

## 4. 自然災害と緊急防災用語（Bencana Alam & Evakuasi）

現地で生活・旅行する上で必須となる防災用語です。

| 単語 | 日本語の意味 | 実情・対策 |
| :--- | :--- | :--- |
| **banjir** | 洪水、大水害 | 河川の氾濫や都市の排水能力超過による大規模浸水。 |
| **genangan air** | 冠水、水たまり | スコール直後に道路が一時的に冠水する現象。車高の低い車は浸水に注意。 |
| **gempa bumi** | 地震 | gempa susulan（余震）, pusat gempa（震源地）。 |
| **tsunami** | 津波 | peringatan dini tsunami（津波警報）。 |
| **gunung meletus** | 火山噴火 | abu vulkanik（火山灰。空港閉鎖の原因になる）。 |
| **tanah longsor** | 土砂崩れ、地滑り | 山間部で雨季に多発する。 |
| **kebakaran hutan** | 森林火災 | スマトラやカリマンタンで乾季に発生する野火。ヘイズ（煙害 kabut asap）を引き起こす。 |
| **evakuasi** | 避難 | jalur evakuasi（避難経路）, posko pengungsian（避難所）。 |
| **korban** | 被害者、被災者 | korban jiwa（死者・犠牲者）。 |

<div class="id-example">
<div class="id-sentence">BMKG mengeluarkan peringatan dini adanya potensi gempa bumi dan banjir bandang di wilayah pesisir.</div>
<div class="id-translation">気象気候地球物理庁（BMKG）は、沿岸地域における地震および鉄砲水の可能性に関する早期警戒（警報）を発令しました。</div>
<div class="id-explanation">BMKG（気象気候地球物理庁） / peringatan dini（早期警戒・警報） / banjir bandang（鉄砲水）。</div>
</div>

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシアの気候を特徴づける2つの季節（雨季と乾季）をそれぞれインドネシア語で何と言う？</summary>
<strong>正解: musim hujan（雨季） / musim kemarau（乾季）</strong><br>
解説: 雨（hujan）の季節と、日照り・乾燥（kemarau）の季節という構成です。
</details>

<details class="id-quiz">
<summary>Q2. 雨季のスコール後に道路が一時的に冠水し、車輪の半分ほどまで水が浸かる現象を日常的に何と呼ぶ？</summary>
<strong>正解: genangan air</strong><br>
解説: 大規模な「banjir（洪水）」と区別して、一時的な道路の冠水・水たまりは「genangan air」と呼ばれ、交通情報で頻出します。
</details>

<details class="id-quiz">
<summary>Q3. 地震、津波、天気予報、火山活動などの公式気象情報を一手に管轄するインドネシア政府機関の略称は？</summary>
<strong>正解: BMKG (Badan Meteorologi, Klimatologi, dan Geofisika)</strong><br>
解説: 日本の気象庁に相当し、地震速報や津波警報、大雨警報を公式アプリやSNSで即時配信しています。
</details>
