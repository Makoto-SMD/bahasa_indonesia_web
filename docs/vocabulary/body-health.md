# 身体の部位と健康・医療・症状の単語集完全まとめ

海外生活や旅行中、体調を崩した際やスパ・マッサージ店で「どこが痛いか」「どんな症状があるか」を正確に伝えることは、健康と安全に直結する極めて重要なスキルです。

インドネシア語では、痛む部位の前に「**sakit（痛い・病気の）**」を置くだけで「sakit kepala（頭痛）」「sakit perut（腹痛）」「sakit gigi（歯痛）」のように直感的に症状を表現できます。

本記事では、頭から足先までの身体の各パーツ名から、内臓の名称、頻出する症状・病気の単語、そして医療機関で即座に役立つ実践フレーズまでを完全網羅します。

---

## 1. 頭部・顔のパーツ（Kepala & Wajah）

顔や頭まわりの名称です。

| 単語 | 日本語の意味 | 関連する症状・表現 |
| :--- | :--- | :--- |
| **kepala** | 頭 | sakit kepala（頭痛）, pusing（めまい・クラクラする） |
| **rambut** | 髪の毛 | rambut rontok（抜け毛） |
| **mata** | 目 | mata merah（充血した目）, tetes mata（目薬） |
| **hidung** | 鼻 | hidung tersumbat（鼻づまり）, pilek（鼻水・鼻風邪） |
| **telinga** | 耳 | sakit telinga（耳の痛み） |
| **mulut** | 口 | sariawan（口内炎） |
| **gigi** | 歯 | sakit gigi（歯痛）, dokter gigi（歯科医） |
| **lidah** | 舌 | lidah pahit（舌が苦い・味覚不調） |
| **bibir** | 唇 | bibir kering / pecah-pecah（唇の乾燥・荒れ） |
| **dahi / jidat** | 額、おでこ | kompres dahi（おでこを冷やす） |
| **pipi** | 頬、ほっぺた | pipi bengkak（頬の腫れ） |
| **dagu** | 顎（あご） | dagu |

<div class="id-example">
<div class="id-sentence">Kepala saya terasa sangat pusing dan hidung saya tersumbat sejak kemarin malam.</div>
<div class="id-translation">昨夜から頭がひどくクラクラして、鼻がつまっています。</div>
<div class="id-explanation">pusing（めまいがする・頭が重い） / hidung tersumbat（鼻づまり）。</div>
</div>

## 2. 体幹・手足の部位（Badan, Tangan & Kaki）

マッサージ店や診察で触れることの多い身体の部位です。

| 単語 | 日本語の意味 | 関連表現・補足 |
| :--- | :--- | :--- |
| **leher** | 首 | leher kaku（首のこり・寝違え） |
| **tenggorokan** | 喉（のど） | radang tenggorokan（咽頭炎・喉の痛み） |
| **pundak / bahu** | 肩 | pegal di pundak（肩こり） |
| **dada** | 胸 | nyeri dada（胸の痛み）, sesak dada（胸の圧迫感） |
| **perut** | お腹、腹部 | sakit perut（腹痛）, kembung（お腹の張り・ガス） |
| **pinggang** | 腰 | sakit pinggang（腰痛・ぎっくり腰） |
| **punggung** | 背中 | nyeri punggung（背中の痛み） |
| **lengan** | 腕 | lengan atas（上腕） |
| **siku** | 肘（ひじ） | cedera siku（肘の怪我） |
| **tangan** | 手、手首 | pergelangan tangan（手首）, cuci tangan（手洗い） |
| **jari** | 指 | jari tangan（手の指）, jari kaki（足の指） |
| **kaki** | 足、脚 | telapak kaki（足の裏）, pergelangan kaki（足首） |
| **lutut** | 膝（ひざ） | nyeri lutut（膝の痛み） |
| **kulit** | 皮膚、肌 | gatal-gatal pada kulit（皮膚のかゆみ） |

<div class="id-example">
<div class="id-sentence">Pundak dan pinggang saya terasa sangat pegal karena terlalu lama duduk di depan komputer.</div>
<div class="id-translation">パソコンの前に長時間座りすぎたため、肩と腰がとても凝っています（重だるいです）。</div>
<div class="id-explanation">pegal（筋肉痛・凝り・重だるさ）。マッサージ店で一番使う単語です。</div>
</div>

## 3. 内臓・生体・循環器の用語（Organ Dalam & Cairan Tubuh）

病院の血液検査や内科診察で使われる医学単語です。

| 単語 | 日本語の意味 | 関連病名・補足 |
| :--- | :--- | :--- |
| **jantung** | 心臓 | serangan jantung（心臓発作）, detak jantung（心拍数） |
| **lambung** | 胃 | sakit maag / asam lambung（胃炎・胃酸過多） |
| **hati** | 肝臓（※比喩で心） | penyakit hati（肝臓病） |
| **paru-paru** | 肺 | radang paru-paru（肺炎） |
| **ginjal** | 腎臓 | batu ginjal（腎臓結石） |
| **darah** | 血液 | tekanan darah tinggi（高血圧）, tes darah（血液検査） |
| **tulang** | 骨 | patah tulang（骨折） |
| **otot** | 筋肉 | kram otot（筋肉の痙攣・こむら返り） |

<div class="id-example">
<div class="id-sentence">Asam lambung saya naik, jadi ulu hati terasa perih dan mual.</div>
<div class="id-translation">胃酸が上がってきて、みぞおちがヒリヒリ痛み、吐き気がします。</div>
<div class="id-explanation">asam lambung naik（胃酸逆流・胃酸過多） / ulu hati（みぞおち） / mual（吐き気）。</div>
</div>

## 4. 症状・体調不良の表現（Gejala Penyakit）

不調を訴える際の必須形容詞・動詞です。

| 症状単語 | 意味 | 例文 |
| :--- | :--- | :--- |
| **demam / panas** | 発熱、熱がある | Anak saya demam tinggi 39 derajat.（私の子どもが39度の高熱を出しています。） |
| **batuk** | 咳（せき） | batuk kering（空咳）, batuk berdahak（痰の絡む咳） |
| **pilek / flu** | 鼻風邪、インフル | Masuk angin dan pilek.（風邪を引いて鼻水が出る。） |
| **mual** | 吐き気がある | Perut terasa mual mau muntah.（お腹がムカムカして吐きそうです。） |
| **muntah** | 吐く、嘔吐する | muntaber（下痢と嘔吐・食あたり胃腸炎） |
| **diare / mencret** | 下痢（げり） | diare parah（ひどい下痢） |
| **gatal** | 痒い（かゆい） | Kulit saya gatal karena digigit nyamuk.（蚊に刺されて肌が痒いです。） |
| **luka** | 傷、怪我 | luka bakar（火傷）, luka berdarah（出血した傷） |
| **bengkak** | 腫れた（はれた） | Kakinya bengkak karena terkilir.（足をくじいて腫れています。） |
| **sesak napas** | 息苦しい、呼吸困難 | Tiba-tiba sesak napas.（突然息が苦しくなった。） |

## 5. 医療機関・薬局での実践会話

<div class="id-example">
<div class="id-sentence">Dokter, saya merasa demam tinggi, badan menggigil, dan ada bintik-bintik merah di kulit. Apakah ini gejala demam berdarah (DBD)?</div>
<div class="id-translation">先生、高熱があり、体が悪寒で震え、皮膚に赤い発疹（斑点）が出ています。これはデング熱（DBD）の症状でしょうか？</div>
<div class="id-explanation">menggigil（悪寒で震える） / demam berdarah / DBD（デング出血熱。熱帯地域で要注意の感染症）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Tolong berikan obat pereda nyeri (penghilang rasa sakit) dan obat untuk menurunkan demam.</div>
<div class="id-translation">痛み止め（鎮痛剤）と解熱剤をいただけますでしょうか。</div>
<div class="id-explanation">pereda nyeri（鎮痛剤） / penurun demam（解熱剤）。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. マッサージ店などで「肩や腰が重だるい・凝っている」と伝える最重要単語は？</summary>
<strong>正解: pegal</strong><br>
解説: 激痛（sakit）ではなく、筋肉疲労や凝りによる重だるさを表す言葉として常用されます。
</details>

<details class="id-quiz">
<summary>Q2. 熱帯地域で蚊を媒介として発症する「デング熱」のインドネシア語略称は？</summary>
<strong>正解: DBD (Demam Berdarah Dengue)</strong><br>
解説: 高熱と血小板減少を伴うため、現地の病院で極めて迅速な検査が行われます。
</details>

<details class="id-quiz">
<summary>Q3. 「胃酸過多・胃痛」を意味する、インドネシア人が最もよく口にする病名は？</summary>
<strong>正解: sakit maag / asam lambung</strong><br>
解説: オランダ語起源の maag（胃）から「sakit maag」と呼ばれ、日常的な胃の不快感を指します。
</details>
