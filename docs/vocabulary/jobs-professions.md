# 職業・役職・産業・専門分野のインドネシア語完全ガイド

初対面での自己紹介、ビジネスでの名刺交換、社内での役割分担や組織図の確認など、相手や自分の職業・肩書きを正しく理解することは信頼関係の構築に直結します。

インドネシア語の職業名は、接頭辞 **pe- / peN-（〜する人）** を伴う派生語（語根 ajar「教える」→ pengajar「指導者」、語根 usaha「努力・事業」→ pengusaha「実業家」）が多く、接辞の知識とも密接に連動しています。

本記事では、一般的な職業から企業組織の役職、現場やサービス業の職種、主要産業分野、そして仕事を尋ねる・答える会話表現までを完全網羅します。

---

## 1. 一般的な職業・公職・専門職（Profesi Umum & Spesialis）

社会で幅広く活躍する一般的な職業名です。

| 職業名（インドネシア語） | 日本語の意味 | 関連動詞・語根 |
| :--- | :--- | :--- |
| **guru** | 教師、学校の先生 | mengajar（教える） |
| **dosen** | 大学教授、講師 | perguruan tinggi / universitas（大学） |
| **dokter** | 医師、医者 | dokter umum（一般内科医）, dokter spesialis（専門医） |
| **perawat** | 看護師 | merawat（世話する・看護する） |
| **pegawai negeri (PNS)** | 公務員（国家公務員） | Pegawai Negeri Sipil（安定した人気職種） |
| **pengusaha / wirausaha** | 実業家、起業家 | berusaha（努力する・ビジネスを興す） |
| **wartawan / jurnalis** | 記者、ジャーナリスト | meliput berita（ニュースを取材する） |
| **pengacara / advokat** | 弁護士 | hukum（法律） |
| **hakim** | 裁判官、判事 | pengadilan（裁判所） |
| **polisi** | 警察官 | kantor polisi（警察署） |
| **tentara (TNI)** | 軍人（国軍兵士） | Tentara Nasional Indonesia（インドネシア国軍） |
| **peneliti / ilmuwan** | 研究者、科学者 | meneliti（研究・調査する） |
| **penerjemah** | 翻訳者、通訳者 | menerjemahkan（翻訳する・通訳する） |
| **seniman** | 芸術家、アーティスト | seni（芸術） |
| **atlet / olahragawan** | アスリート、スポーツ選手 | bertanding（試合をする） |

<div class="id-example">
<div class="id-sentence">Kakak saya bekerja sebagai dosen di salah satu universitas negeri terkemuka di Yogyakarta.</div>
<div class="id-translation">私の兄（姉）はジョグジャカルタの著名な国立大学の一つで大学講師（准教授）として働いています。</div>
<div class="id-explanation">bekerja sebagai（〜として働く） / universitas negeri（国立大学） / terkemuka（著名な、一流の）。</div>
</div>

## 2. 会社・オフィス内の役職・肩書（Jabatan di Perusahaan）

ビジネスシーンで名刺（kartu nama）に記載される重要肩書です。

| 役職・肩書 | 日本語の対応役職 | 職務内容・特徴 |
| :--- | :--- | :--- |
| **Komisaris** | 監査役、コミサリス | インドネシア会社法上の最高監督機関。Komisaris Utama（筆頭監査役）。 |
| **Direktur Utama (Dirut)** | 社長、代表取締役、CEO | 企業の業務執行トップ。 |
| **Direktur** | 取締役、役員、ディレクター | Direktur Keuangan（CFO/財務担当役員）等。 |
| **Manajer / Manager** | 部長、課長、マネージャー | Manajer Pemasaran（マーケティング部長）等。 |
| **Kepala Bagian (Kabag)** | 課長、セクションチーフ | kepala（頭・長）＋ bagian（部門）。 |
| **Supervisor (SPV)** | 主任、係長、現場監督者 | penyelia（公用語）とも呼ばれる。 |
| **Staf / Karyawan** | 一般社員、スタッフ | staf administrasi（事務スタッフ）。 |
| **Sekretaris** | 秘書 | jadwal pimpinan（役員スケジュール管理）。 |
| **Akuntan** | 会計士、経理担当者 | pembukuan（帳簿・記帳）。 |
| **Karyawan Kontrak** | 契約社員 | perjanjian kerja waktu tertentu (PKWT)。 |
| **Karyawan Tetap** | 正社員 | perjanjian kerja waktu tidak tertentu (PKWTT)。 |
| **Anak Magang / Magang** | インターン、実習生 | program magang（インターンシップ制度）。 |

<div class="id-example">
<div class="id-sentence">Perkenalkan, beliau adalah Bapak Tanaka, Direktur Utama dari kantor pusat kami di Tokyo.</div>
<div class="id-translation">ご紹介いたします、こちらは東京の当社本社から参りました代表取締役社長の田中様です。</div>
<div class="id-explanation">beliau（三人称敬称「このお方」） / kantor pusat（本社・本店）。</div>
</div>

## 3. サービス・現業・職人・現場の職種（Pekerja Lapangan & Jasa）

日々の生活や工場、店舗で接する現場職の名称です。

| 職種名 | 日本語の意味 | 役割・業務 |
| :--- | :--- | :--- |
| **sopir / supir** | 運転手、ドライバー | sopir pribadi（専属運転手）, sopir taksi（タクシー運転手） |
| **satpam (satuan pengaman)** | 警備員、セキュリティ | マンション、オフィス、モールの安全管理。 |
| **asisten rumah tangga (ART)** | 家事代行、お手伝いさん | 日常会話では「pembantu」とも呼ばれるが、公的にはARTが好まれる。 |
| **kurir** | 配達員、宅配ドライバー | pengantar paket（荷物配達員） |
| **koki / juru masak** | 料理人、シェフ | restoran / dapur（厨房） |
| **pelayan / pramusaji** | ウェイター、給仕スタッフ | melayani pelanggan（客に給仕する） |
| **kasir** | レジ係、出納係 | pembayaran di kasir（レジでの支払い） |
| **tukang bangunan** | 大工、建築作業員 | tukang は手作業・職人を表す冠詞。 |
| **tukang listrik / pipa** | 電気工 / 水道配管工 | perbaikan pipa bocor（水漏れ修理） |
| **mekanik / montir** | 整備士、自動車工 | bengkel mobil / motor（修理工場） |
| **petani** | 農家、農業従事者 | bercocok tanam di sawah（田畑で耕作する） |
| **nelayan** | 漁師、漁民 | menangkap ikan di laut（海で魚を獲る） |

<div class="id-example">
<div class="id-sentence">Kami membutuhkan jasa tukang pipa untuk memperbaiki saluran air yang tersumbat di dapur.</div>
<div class="id-translation">台所の詰まった排水管を修理するために、配管工の手配が必要です。</div>
<div class="id-explanation">jasa（サービス・役務） / saluran air（排水路・水道管） / tersumbat（詰まった）。</div>
</div>

## 4. 主要産業・業種（Sektor Industri & Bisnis）

企業が属する業界分野の名称です。

- **manufaktur / pabrik**: 製造業、工場
- **otomotif**: 自動車産業
- **perdagangan**: 商業、貿易業
- **pertanian & perkebunan**: 農業・プランテーション農園（アブラヤシ・ゴム等）
- **pertambangan**: 鉱業（石炭、ニッケル、金、銅等）
- **energi & kelistrikan**: エネルギー・電力
- **pariwisata & perhotelan**: 観光・ホテル産業
- **keuangan & perbankan**: 金融・銀行業
- **teknologi informasi (TI)**: IT・情報通信産業
- **konstruksi**: 建設・土木業

## 5. 職業を尋ねる・答える会話表現

相手の仕事を尋ねる自然な表現と、自己紹介のフレーズです。

<div class="id-example">
<div class="id-sentence">Apa pekerjaan Anda? / Anda bekerja di bidang apa?</div>
<div class="id-translation">あなたのお仕事は何ですか？ / どのような分野で働いていらっしゃいますか？</div>
<div class="id-explanation">bidang（分野・業界）。「Kerja di mana?（どこで働いているの？）」も日常で多用されます。</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya bekerja sebagai manajer produksi di perusahaan manufaktur komponen otomotif Jepang di Cikarang.</div>
<div class="id-translation">私はチカランにある日系自動車部品製造会社で製造部長として勤務しています。</div>
<div class="id-explanation">komponen otomotif（自動車部品） / perusahaan Jepang（日本企業・日系企業）。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシアの企業における「代表取締役社長 / CEO」に相当する公式役職名は？</summary>
<strong>正解: Direktur Utama (Dirut)</strong><br>
解説: Direktur（取締役）のトップ（Utama＝主要な、第一の）であり、日常会話やビジネス文書では「Dirut」と略されます。
</details>

<details class="id-quiz">
<summary>Q2. オフィスビルやマンションの入口に必ず常駐している「警備員」の通称・略称は？</summary>
<strong>正解: satpam</strong><br>
解説: Satuan Pengamanan（保安部隊）の略称で、インドネシアの生活で最も親しまれ頼りにされる存在の一つです。
</details>

<details class="id-quiz">
<summary>Q3. インドネシア語で「〜する人」を表す接頭辞 pe- / peN- を使って「研究者」を意味する単語は？</summary>
<strong>正解: peneliti</strong><br>
解説: 語根 teliti（緻密な、綿密な）に接頭辞 peN- がつき、t が消失して鼻音化し「peneliti（研究者）」となります。
</details>
