# 効率倍増！必須対義語・反対語（Antonim）ペア100選

外国語のボキャブラリーを短期間で倍増させる最も効果的な学習法は、**「反対の意味を持つ単語（対義語・Antonim）をセットで覚えること」**です。

対比のフックがあることで脳内の記憶定着率が飛躍的に高まり、会話の際に「これは大きい、あれは小さい」「以前はこうだったが、今はこうだ」と表現の幅が瞬時に広がります。

本記事では、日常会話・ビジネス・描写で頻出する最重要の対義語ペアをカテゴリー別に完全整理しました。

---

## 1. 大きさ・数量・度合い（Ukuran & Jumlah）

物のサイズや量を表す基本ペアです。

| 単語 A | 意味 | 単語 B | 意味 |
| :--- | :--- | :--- | :--- |
| **besar** | 大きい | **kecil** | 小さい |
| **banyak** | 多い、たくさん | **sedikit** | 少ない、少し |
| **panjang** | 長い | **pendek** | 短い |
| **tinggi** | 高い（身長・山・ビル） | **rendah** | 低い（※身長には pendek） |
| **jauh** | 遠い | **dekat** | 近い |
| **luas** | 広い（面積） | **sempit** | 狭い |
| **tebal** | 厚い（本・板） | **tipis** | 薄い |
| **berat** | 重い | **ringan** | 軽い |
| **penuh** | 満杯の、いっぱいの | **kosong** | 空の、空席の |
| **dalam** | 深い | **dangkal** | 浅い |

<div class="id-example">
<div class="id-sentence">Ruang rapat ini terlalu sempit untuk orang sebanyak itu, tolong cari ruangan yang lebih luas.</div>
<div class="id-translation">この会議室はあんなに大勢の人に対して狭すぎます。もっと広い部屋を探してください。</div>
<div class="id-explanation">sempit（狭い） ⇄ luas（広い）。</div>
</div>

## 2. 速度・時間・新旧・年齢（Kecepatan, Waktu & Usia）

時間の流れやスピード、年代を表すペアです。

| 単語 A | 意味 | 単語 B | 意味 |
| :--- | :--- | :--- | :--- |
| **cepat** | 速い、早い | **lambat / pelan** | 遅い、ゆっくり |
| **awal** | 初め、早い時期 | **akhir** | 終わり、末 |
| **dulu** | 以前、昔 | **sekarang** | 今、現在 |
| **sebelum** | 〜の前 | **sesudah / setelah** | 〜の後 |
| **baru** | 新しい | **lama** | 古い、長い時間（※物に使う） |
| **muda** | 若い | **tua** | 年老いた、年配の（※人に使う） |
| **pagi** | 朝 | **malam** | 夜 |
| **siang** | 昼 | **sore** | 夕方 |

> [!TIP]
> **「古い」の使い分けに注意！**
> - **lama**: 「古い物」「長年の友人」「長い時間」を表します。（Contoh: mobil lama＝古い車, teman lama＝旧友）
> - **tua**: 「年齢が高い・年老いた人」「成熟した」を表します。（Contoh: orang tua＝親・老人）
> ※古い車を *mobil tua* と言うと「オンボロの年代物クラシックカー」のニュアンスになります。

<div class="id-example">
<div class="id-sentence">Dulu dia sangat lambat dalam belajar, tetapi sekarang kemampuannya meningkat sangat cepat.</div>
<div class="id-translation">以前は彼の勉強のペースはとても遅かったですが、今では能力が非常に速く向上しています。</div>
<div class="id-explanation">dulu（以前） ⇄ sekarang（今） / lambat（遅い） ⇄ cepat（速い）。</div>
</div>

## 3. 温度・質感・状態（Suhu & Kondisi Fisik）

触覚や物理的な状態を表すペアです。

| 単語 A | 意味 | 単語 B | 意味 |
| :--- | :--- | :--- | :--- |
| **panas** | 熱い、暑い | **dingin** | 冷たい、寒い |
| **hangat** | 温かい、ポカポカする | **sejuk** | 涼しい、爽やかな |
| **basah** | 濡れた | **kering** | 乾いた |
| **bersih** | 清潔な、綺麗な | **kotor** | 汚れた、汚い |
| **keras** | 硬い、固い | **lembut / empuk** | 柔らかい、ふんわりした |
| **terang** | 明るい | **gelap** | 暗い |
| **halus** | 滑らかな、きめの細かい | **kasar** | 粗い、ザラザラした |
| **mentah** | 生の、未調理の | **matang** | 煮えた、熟した、火が通った |

<div class="id-example">
<div class="id-sentence">Hawa di Jakarta sangat panas, tetapi udara di Puncak sangat sejuk dan nyaman.</div>
<div class="id-translation">ジャカルタの気候はとても暑いですが、プンチャック（高原避暑地）の空気はとても涼しく心地よいです。</div>
<div class="id-explanation">panas（暑い） ⇄ sejuk（涼しい）。冷たいは dingin です。</div>
</div>

## 4. 価値・価格・難易度・正誤（Nilai & Kualitas）

判断や評価を下す際の最重要形容詞ペアです。

| 単語 A | 意味 | 単語 B | 意味 |
| :--- | :--- | :--- | :--- |
| **mahal** | （値段が）高い | **murah** | （値段が）安い |
| **mudah / gampang** | 簡単な、易しい | **sulit / susah** | 難しい、困難な |
| **baik / bagus** | 良い（人柄/品質） | **buruk / jelek** | 悪い、粗悪な |
| **benar / betul** | 正しい、その通り | **salah** | 間違い、誤り |
| **asli / orisinal** | 本物の、純正の | **palsu** | 偽物の、コピーの |
| **kuat** | 強い、丈夫な | **lemah** | 弱い |
| **aman** | 安全な | **bahaya** | 危険な |
| **sama** | 同じ | **beda / berbeda** | 異なる、違う |

<div class="id-example">
<div class="id-sentence">Barang ini harganya memang murah, tetapi kualitasnya tidak buruk sama sekali.</div>
<div class="id-translation">この商品は値段こそ確かに安いですが、品質は決して悪くありません。</div>
<div class="id-explanation">murah（安い） ⇄ mahal（高い） / buruk（悪い） ⇄ bagus/baik（良い）。</div>
</div>

## 5. 性格・感情・人間性（Sifat & Kepribadian）

人の性格や感情を表す対比です。

| 単語 A | 意味 | 単語 B | 意味 |
| :--- | :--- | :--- | :--- |
| **rajin** | 勤勉な、まめな | **malas** | 怠惰な、めんどくさがり |
| **senang / bahagia** | 嬉しい、幸せな | **sedih** | 悲しい |
| **ramah** | 愛想が良い、気さくな | **galak / judes** | 怒りっぽい、意地悪な |
| **sombong** | 傲慢な、高飛車な | **rendah hati** | 謙虚な（文字通り: 低い心） |
| **berani** | 勇敢な | **takut / penakut** | 怖がりな、臆病な |
| **jujur** | 正直な、誠実な | **bohong / pembohong** | 嘘つきな |
| **pelit / kikir** | ケチな | **dermawan / murah hati** | 気前が良い、寛大な |

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「暑い（熱い）」を意味する panas の反対で、「涼しい」を意味する単語は？</summary>
<strong>正解: sejuk</strong><br>
解説: 「冷たい・寒い」は dingin ですが、高原などで心地よい涼しさを表す時は「sejuk」が適切です。
</details>

<details class="id-quiz">
<summary>Q2. 「勤勉な、真面目な」を意味する rajin の対義語で、「めんどくさがり、怠惰な」を意味する単語は？</summary>
<strong>正解: malas</strong><br>
解説: 若者言葉の流行語「mager（males gerak＝動くのがめんどくさい）」の語源でもあります。
</details>

<details class="id-quiz">
<summary>Q3. インドネシア語で「本物の、純正品」を表す asli の反対で、「偽物、フェイク」を指す単語は？</summary>
<strong>正解: palsu</strong><br>
解説: paspor palsu（偽造パスポート）、uang palsu（偽札）などの表現で使われます。
</details>
