# 家族・親族・人間関係の呼び名完全ガイド（呼称・親族呼称システム）

インドネシア社会は、家族や親族の絆（Kekeluargaan）を何よりも大切にする文化を持っています。

インドネシア語の親族呼称には、「**年齢の上下（年上か年下か）を厳格に区別する一方で、単語そのものには男女の区別がない（性別を表す単語を後ろに添える）**」という興味深い特徴があります。また、これらの家族用語（Bapak, Ibu, Kakak, Mas, Mbak 等）は、血縁関係のない街の人々や同僚に対しても敬意や親愛を込めた「呼びかけ（Sapaan）」として日常的に使われます。

本記事では、直系家族から親戚・姻族の名称、そして家族を紹介する実践フレーズや他人への親称ルールまでを体系的に解説します。

---

## 1. 直系家族（Keluarga Inti）の呼び名

核家族および直系親族を表す基本用語です。

| 親族名 | 日本語の意味 | 補足・日常の呼びかけ |
| :--- | :--- | :--- |
| **ayah / bapak / papa** | 父、お父さん | 日常では Bapak / Pak / Papa と呼ぶ |
| **ibu / mama** | 母、お母さん | 日常では Ibu / Bu / Mama と呼ぶ |
| **orang tua** | 両親、親 | 直訳は「年老いた人」だが「両親」を意味する |
| **anak** | 子ども | anak-anak（子どもたち） |
| **anak laki-laki** | 息子、男児 | laki-laki（男性）を後置修飾 |
| **anak perempuan** | 娘、女児 | perempuan（女性）を後置修飾 |
| **kakak** | 兄、姉（年上のきょうだい） | 男女共通。呼びかけは Kak |
| **adik** | 弟、妹（年下のきょうだい） | 男女共通。呼びかけは Dik |
| **kakek / oma** | 祖父、おじいちゃん | 呼びかけは Kakek / Opa |
| **nenek / opa** | 祖母、おばあちゃん | 呼びかけは Nenek / Oma |
| **cucu** | 孫 | cucu laki-laki / perempuan |

### 「兄」「弟」「姉」「妹」の表し方
インドネシア語の `kakak`（年上）と `adik`（年下）は性別を含みません。性別を特定したい場合は、後ろに `laki-laki`（男）または `perempuan`（女）を添えます。

- **兄**: `kakak laki-laki`（親しい呼びかけ：Kak / Mas / Bang）
- **姉**: `kakak perempuan`（親しい呼びかけ：Kak / Mbak）
- **弟**: `adik laki-laki`
- **妹**: `adik perempuan`

<div class="id-example">
<div class="id-sentence">Saya punya satu kakak laki-laki dan satu adik perempuan.</div>
<div class="id-translation">私には兄が1人と妹が1人います。</div>
</div>

## 2. 親族・親類・姻族（Kerabat & Hubungan Pernikahan）

おじ・おば、いとこ、義理の家族などを表す語彙です。

| 親族名 | 日本語の意味 | 補足・別称 |
| :--- | :--- | :--- |
| **paman / om** | 叔父・伯父（おじ） | オランダ語由来の Om（オム）も広く使われる |
| **bibi / tante** | 叔母・伯母（おば） | オランダ語由来の Tante（タンテ）も一般的 |
| **sepupu** | いとこ（従兄弟・従姉妹） | saudara sepupu とも言う |
| **keponakan** | 甥（おい）、姪（めい） | keponakan laki-laki / perempuan |
| **suami** | 夫 | suami saya（私の夫） |
| **istri** | 妻 | istri saya（私の妻） |
| **mertua** | 義理の父母（配偶者の親） | bapak mertua（義父）, ibu mertua（義母） |
| **menantu** | 婿（むこ）、嫁（よめ） | anak menantu（義理の息子・娘） |
| **ipar** | 義理のきょうだい（義兄・義弟・義姉・義妹） | kakak ipar（義兄・義姉）, adik ipar（義弟・義妹） |

<div class="id-example">
<div class="id-sentence">Akhir pekan ini kami sekeluarga akan berkunjung ke rumah paman dan bibi di Bandung.</div>
<div class="id-translation">今週末、私たち家族一同はバンドンにある叔父と叔母の家を訪問する予定です。</div>
<div class="id-explanation">kami sekeluarga（私たち家族一同） / berkunjung（訪問する）。</div>
</div>

## 3. 「血縁のない他人」に対する親族呼称の転用ルール

インドネシアでは、赤の他人であっても「あなた（Anda）」や相手の名前を呼び捨てにせず、親族呼称を用いて敬意と親しみを表します。

| 呼称 | 対象者・ニュアンス | 使用シーン |
| :--- | :--- | :--- |
| **Pak / Bapak** | 目上の男性、成人男性、顧客、上司 | ビジネス、公共の場、タクシー運転手など全般 |
| **Bu / Ibu** | 目上の女性、成人女性、既婚女性 | ビジネス、店舗の店員、先生など全般 |
| **Mas** | 同年代〜年下の男性（ジャワ語起源） | カフェの男性店員、同僚、 Grab運転手など |
| **Mbak** | 同年代〜年下の女性（ジャワ語起源） | レストランやコンビニの女性店員、同僚など |
| **Kak / Kakak** | 若者全般、同世代（ジェンダーレス） | ショッピングモール、おしゃれなカフェ、SNS |
| **Bang** | 親しみのある男性（バタウィ・スマトラ起源） | 屋台（カキリマ）のオヤジ、バイクタクシー |
| **Om / Tante** | 友人の両親、年配の知人（親愛を込めて） | プライベート、親しい間柄の年長者 |

<div class="id-example">
<div class="id-sentence">Mas, tolong minta menu dan air putihnya ya.</div>
<div class="id-translation">お兄さん（店員さん）、メニューとお水をいただけますか？</div>
</div>

## 4. 家族構成を尋ねる・紹介する会話フレーズ

インドネシア人はスモールトークで「何人きょうだい？」「子どもは何人いるの？」とよく質問してきます。

### 何人きょうだいかを尋ねる・答える
<div class="id-example">
<div class="id-sentence">Berapa bersaudara kamu? / Kamu anak ke berapa?</div>
<div class="id-translation">何人きょうだいですか？ / 何番目の子どもですか？</div>
<div class="id-explanation">bersaudara（きょうだいがいる） / anak ke berapa（何番目の子）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Saya tiga bersaudara. Saya anak pertama (sulung), dan saya punya dua adik.</div>
<div class="id-translation">私は3人きょうだいです。私が長男（長女）で、下に弟（妹）が2人います。</div>
<div class="id-explanation">anak sulung / pertama（一番上の子・長子） / anak bungsu / terakhir（末っ子）。</div>
</div>

### 婚姻関係・子どもの有無
<div class="id-example">
<div class="id-sentence">Apakah Anda sudah berkeluarga / menikah?</div>
<div class="id-translation">ご結婚されていますか（ご家庭をお持ちですか）？</div>
</div>

<div class="id-example">
<div class="id-sentence">Ya, saya sudah menikah dan punya dua orang anak, satu laki-laki dan satu perempuan.</div>
<div class="id-translation">はい、結婚しており子どもが2人います。男の子が1人と女の子が1人です。</div>
</div>

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシア語で「兄」と「姉」を言い分けたいときの正しい表現は？</summary>
<strong>正解: 兄＝kakak laki-laki、姉＝kakak perempuan</strong><br>
解説: kakak単体では年上のきょうだい全般を指すため、性別を特定する場合は laki-laki / perempuan を後ろに添えます。
</details>

<details class="id-quiz">
<summary>Q2. レストランやコンビニで、若い男性店員や同世代の男性に呼びかける最も一般的な呼称は？</summary>
<strong>正解: Mas（マス）</strong><br>
解説: ジャワ語由来ですが、現代ではジャカルタを含む全国で若い男性への親愛を込めた呼称として定着しています。
</details>

<details class="id-quiz">
<summary>Q3. きょうだいの中で「末っ子」を表す特別な単語は？</summary>
<strong>正解: anak bungsu</strong><br>
解説: 一番上の子（長男・長女）を `anak sulung`、末っ子を `anak bungsu` と呼びます。
</details>
