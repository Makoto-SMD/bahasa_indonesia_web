# 日常生活の基本名詞（衣食住・身の回りの物）完全マスター

外国語の習得において、最も手っ取り早く会話の解像度を上げてくれるのが**「身の回りの名詞（Kata Benda Sehari-hari）」**です。

部屋にある家具、毎日持ち歩く荷物、身につける衣類や日用品の名前がパッと出てくるようになると、「〜はどこ？」「〜を取って」「〜を買いたい」といった日常のあらゆる意思表示が格段にスムーズになります。

本記事では、衣食住にまつわる最頻出の名詞をカテゴリ別に体系化し、日常でそのまま使える例文とともに解説します。

---

## 1. 家・部屋の中の家具・設備（Rumah & Kamar）

生活空間で毎日目にする家具や設備の名詞です。

| 単語 | 日本語の意味 | 関連表現・補足 |
| :--- | :--- | :--- |
| **rumah** | 家、住居 | rumah makan（飲食店・大衆食堂） |
| **kamar** | 部屋 | kamar tidur（寝室）, kamar mandi（浴室・トイレ） |
| **pintu** | ドア、扉 | pintu masuk（入口）, pintu keluar（出口） |
| **jendela** | 窓 | buka jendela（窓を開ける） |
| **meja** | 机、テーブル | meja kerja（作業机）, meja makan（食卓） |
| **kursi** | 椅子 | kursi malas（リクライニングチェア） |
| **kasur / tempat tidur** | マットレス、ベッド | seprei（シーツ）, bantal（枕）, guling（抱き枕） |
| **lemari** | タンス、クローゼット、棚 | lemari pakaian（衣装棚）, lemari es / kulkas（冷蔵庫） |
| **lantai** | 床、階（フロア） | lantai 1（1階）, sapu lantai（床を掃く） |
| **lampu** | ランプ、電灯、照明 | nyalakan lampu（電気をつける）, matikan lampu（消す） |
| **dinding / tembok** | 壁 | jam dinding（掛け時計） |
| **atap** | 屋根 | atap bocor（雨漏り） |

<div class="id-example">
<div class="id-sentence">Tolong matikan lampu kamar tidur sebelum tidur ya.</div>
<div class="id-translation">寝る前に寝室の電気を消してくださいね。</div>
</div>

<div class="id-example">
<div class="id-sentence">Kunci kamar saya tertinggal di atas meja kerja.</div>
<div class="id-translation">私の部屋の鍵が作業机の上に置き忘れられていました。</div>
<div class="id-explanation">tertinggal（置き忘れられた・残された）。</div>
</div>

## 2. 身の回りの持ち物・日用品（Barang Pribadi）

外出時に持ち歩く必需品の名詞です。

| 単語 | 日本語の意味 | 関連表現・補足 |
| :--- | :--- | :--- |
| **tas** | かばん、バッグ | tas ransel（リュック）, tas selempang（ショルダーバッグ） |
| **dompet** | 財布 | dompet ketinggalan（財布を忘れた） |
| **kunci** | 鍵 | anak kunci（鍵の本体）, gantungan kunci（キーホルダー） |
| **kacamata** | 眼鏡 | kacamata hitam / surya（サングラス） |
| **ponsel / HP** | スマートフォン、携帯 | pengisi daya / charger（充電器）, pulsa（通話チャージ） |
| **jam tangan / arloji** | 腕時計 | baterai jam（時計の電池） |
| **payung** | 傘 | payung lipat（折りたたみ傘） |
| **buku** | 本、書籍 | buku catatan（メモ帳・手帳） |
| **pulpen / pena** | ボールペン | isi pulpen（ペンの替え芯） |
| **kartu** | カード | kartu identitas / KTP（身分証）, kartu kredit（クレカ） |

<div class="id-example">
<div class="id-sentence">Waduh, dompet saya ketinggalan di rumah! Boleh saya bayar pakai QRIS?</div>
<div class="id-translation">うわっ、家に財布を忘れてきてしまいました！ QRISで支払ってもいいですか？</div>
</div>

<div class="id-example">
<div class="id-sentence">Jangan lupa bawa payung lipat di dalam tas ransel, sekarang sedang musim hujan.</div>
<div class="id-translation">リュックの中に折りたたみ傘を入れて持参するのを忘れないでね、今は雨季だから。</div>
</div>

## 5. 日常名詞を使った実践表現集

日常のよくあるシチュエーションでの活用例です。

### 探し物をする（Mencari Barang）
<div class="id-example">
<div class="id-sentence">Kamu lihat kacamata saya tidak? Tadi saya taruh di dekat laptop di atas meja.</div>
<div class="id-translation">私の眼鏡を見かけなかった？ さっき机の上のノートPCの近くに置いたんだけど。</div>
<div class="id-explanation">taruh（置く） / di dekat...（〜の近くに）。</div>
</div>

### 物を借りる・頼む（Meminjam / Meminta Tolong）
<div class="id-example">
<div class="id-sentence">Boleh saya pinjam pulpen sebentar untuk tanda tangan?</div>
<div class="id-translation">署名をするために、少しボールペンをお借りしてもよろしいですか？</div>
<div class="id-explanation">pinjam（借りる） / sebentar（少し・ちょっと）。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「財布を家に忘れてきてしまった！」をインドネシア語で言うと？</summary>
<strong>正解: Dompet saya ketinggalan di rumah!</strong><br>
解説: ketinggalan（置き忘れる・取り残される）と dompet（財布）を組み合わせた定番フレーズです。
</details>

<details class="id-quiz">
<summary>Q2. インドネシアの公式ビジネスや式典で、男性の正装として着用される衣服は？</summary>
<strong>正解: Kemeja batik lengan panjang（長袖バティックシャツ）</strong><br>
解説: スーツ（Jas）と同等、あるいはそれ以上の格式を持つインドネシアの伝統的フォーマルウェアです。
</details>

<details class="id-quiz">
<summary>Q3. レストランなどで「スプーンとフォーク」をセットで呼ぶ定番の組み合わせは？</summary>
<strong>正解: Sendok dan garpu</strong><br>
解説: インドネシアでは箸やナイフよりも、右手にスプーン、左手にフォークを持って食事をするのが最も一般的です。
</details>
