# インドネシアの祝日・宗教・年中行事・文化用語の完全理解

インドネシアは憲法で信教の自由が保障され、国民の約87%がイスラム教徒であると同時に、キリスト教、ヒンドゥー教、仏教、儒教の信徒が共生する「多様性の中の統一（Bhinneka Tunggal Ika）」を国是とする国です。

そのため、公定の祝日（Hari Libur Nasional）には主要な宗教それぞれの祝祭日が含まれており、現地のビジネスや生活リズムはこれら宗教行事と深く連動しています。

本記事では、六大公認宗教の基本用語から、ラマダン・断食明け大祭（レバラン）、バリ島のニュピ、国家祝祭日、そして各行事で交わされるお祝いの言葉までを完全解説します。

---

## 1. 六大公認宗教と基本用語（Agama Resmi & Tempat Ibadah）

インドネシア政府が公認している6つの宗教と、それぞれの礼拝所の名称です。

| 宗教名 | 日本語 | 信徒の呼称 | 礼拝所（Tempat Ibadah） |
| :--- | :--- | :--- | :--- |
| **Islam** | イスラム教 | orang Islam / Muslim | **masjid**（モスク）, musala（礼拝小部屋） |
| **Kristen Protestan** | キリスト教（プロテスタント） | orang Kristen | **gereja**（教会） |
| **Kristen Katolik** | キリスト教（カトリック） | orang Katolik | **gereja**（教会） |
| **Hindu** | ヒンドゥー教（バリ・ヒンドゥー） | orang Hindu | **pura**（寺院） |
| **Buddha** | 仏教 | orang Buddha | **vihara / wihara**（寺院） |
| **Konghucu** | 儒教 | orang Konghucu | **klenteng**（道観・廟） |

<div class="id-example">
<div class="id-sentence">Indonesia memiliki enam agama resmi, dan semboyan nasional negara ini adalah "Bhinneka Tunggal Ika".</div>
<div class="id-translation">インドネシアには6つの公認宗教があり、国の標語は「多様性の中の統一（異なるが、一つである）」です。</div>
<div class="id-explanation">semboyan（標語・スローガン） / Bhinneka Tunggal Ika（古ジャワ語の国是）。</div>
</div>

## 2. イスラム教の最重要行事と用語（Ramadan & Idul Fitri）

国民の大多数が参加する年間最大の行事です。

| 単語 | 日本語の意味 | 背景・文化知識 |
| :--- | :--- | :--- |
| **Ramadan** | ラマダン（断食月） | ヒジュラ暦（イスラム暦）第9月。約1ヶ月間、日の出から日没まで飲食・喫煙等を断つ。 |
| **puasa / berpuasa** | 断食（サウム） / 断食する | 日中の飲食を断つ義務。体調不良者・妊婦等は免除。 |
| **sahur** | 夜明け前の食事（サフール） | 断食が始まる前の午前3時〜4時頃にとる朝食。 |
| **buka puasa (iftar)** | 日没後の断食明け食事（ブカプアサ） | 日没のアザーン（日没の合図）とともに、まず甘いナツメヤシ（kurma）や甘い茶で胃を潤す。 |
| **Idul Fitri / Lebaran** | 断食明け大祭（レバラン） | ラマダン終了を祝う年間最大の祝祭。学校や企業は長期休暇（Cuti Bersama）に入る。 |
| **mudik** | 帰省ラッシュ | 都市で働く数千万人が一斉に地方の故郷（kampung halaman）へ帰省する大移動現象。 |
| **THR (Tunjangan Hari Raya)** | 宗教祝日手当（レバランボーナス） | 法律で義務付けられた、レバラン前に支給される1ヶ月分相当の特別手当。 |
| **Idul Adha / Lebaran Haji** | 犠牲祭（イード・アル＝アドハー） | 牛や山羊を屠殺（kurban）し、貧しい人々に肉を配給する祭礼。 |
| **halal** | ハラール（合法的・許された） | イスラム法に適合した食品や商品。豚肉やアルコールを含まない。 |
| **haram** | ハラーム（禁止された・タブー） | イスラム教徒にとって禁忌となるもの。 |

<div class="id-example">
<div class="id-sentence">Menjelang hari raya Idul Fitri, jutaan orang melakukan mudik ke kampung halaman untuk berkumpul dengan keluarga.</div>
<div class="id-translation">断食明け大祭（レバラン）を前に、家族と集まるために数百万人の人々が故郷へ帰省（mudik）します。</div>
<div class="id-explanation">menjelang（〜の直前に） / melakukan mudik（帰省を行う）。</div>
</div>

## 3. その他の宗教の祝日・祭礼（Hari Besar Keagamaan Lain）

多民族・多宗教国家ならではの祝祭日です。

| 祝祭日名 | 所属宗教 | 時期・特徴 |
| :--- | :--- | :--- |
| **Natal** | キリスト教 | 12月25日。クリスマス。ショッピングモールが装飾される。 |
| **Nyepi** | ヒンドゥー教 | サカ暦の新年（3月頃）。バリ島全体で24時間、火・灯火・外出・労働・娯楽が全面禁止され、空港も閉鎖される「静寂の日」。 |
| **Waisak** | 仏教 | 5月頃。釈迦の生誕・悟り・入滅を祝う。ボロブドゥール寺院に世界中から僧侶が集まりランタンを打ち上げる。 |
| **Tahun Baru Imlek** | 儒教・中華系 | 旧正月（春節）。アンパオ（お年玉袋）を配り、バロンサイ（獅子舞）が舞う。 |
| **Jumat Agung** | キリスト教 | 聖金曜日（グッドフライデー）。イエス・キリストの受難日。 |
| **Kenaikan Isa Almasih** | キリスト教 | キリスト昇天祭。 |

<div class="id-example">
<div class="id-sentence">Saat Hari Raya Nyepi di Bali, seluruh pulau menjadi sangat gelap dan hening tanpa ada aktivitas apa pun di luar rumah.</div>
<div class="id-translation">バリ島のニュピの日は、島全体が真っ暗になり、家の外でのいかなる活動もなく極めて静まり返ります。</div>
<div class="id-explanation">hening（静まり返った、静寂な） / seluruh pulau（島全体）。</div>
</div>

## 4. 国家の祝祭日（Hari Libur Nasional）

歴史と独立を記念する国家的な祝日です。

- **Hari Kemerdekaan RI（8月17日）**: インドネシア共和国独立記念日（1945年8月17日スカルノらが独立宣言）。全土で国旗が掲げられ、独立記念運動会（ヤシの木登り panjat pinang や煎餅早食い lomba makan kerupuk）で大いに盛り上がる。
- **Hari Buruh Internasional（5月1日）**: メーデー、労働者の日。
- **Hari Lahir Pancasila（6月1日）**: 建国5原則（パンチャシラ）制定記念日。
- **Hari Pahlawan（11月10日）**: 英雄の日（※祝日ではないが国家記念日）。

## 5. 祝祭日に交わされる挨拶フレーズ

相手の宗教や祝日に応じた適切な祝福の挨拶です。

<div class="id-example">
<div class="id-sentence">Selamat Hari Raya Idul Fitri, mohon maaf lahir dan batin.</div>
<div class="id-translation">断食明け大祭おめでとうございます。心身ともにお許しを乞います（過去の過ちを許し合いましょう）。</div>
<div class="id-explanation">mohon maaf lahir dan batin: レバランの絶対定番フレーズ。外見的（lahir＝行動や言動）にも内面的（batin＝心の中の悪感情）にも全て許し合ってリセットしようという崇高な挨拶。</div>
</div>

<div class="id-example">
<div class="id-sentence">Selamat Hari Natal dan Tahun Baru untuk Anda dan keluarga tercinta.</div>
<div class="id-translation">あなたと愛するご家族にとって良きクリスマスと新年でありますように。</div>
<div class="id-explanation">Selamat Hari Natal（メリークリスマス）。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. レバラン（Idul Fitri）の際に交わされる、過去の言動や心の中の過ちを互いに許し合う伝統的な挨拶言葉は？</summary>
<strong>正解: Mohon maaf lahir dan batin</strong><br>
解説: lahir（肉体・表向き）と batin（精神・内面）の双方において無礼をお許しくださいという意味です。
</details>

<details class="id-quiz">
<summary>Q2. バリ島で新年を祝うため、24時間にわたり外出や灯火の使用が一切禁止され、国際空港すら閉鎖される祝日は？</summary>
<strong>正解: Nyepi（ニュピ）</strong><br>
解説: ヒンドゥー・サカ暦の新年で、「静寂の日」と呼ばれます。観光客もホテルの敷地外へ出ることはできません。
</details>

<details class="id-quiz">
<summary>Q3. インドネシアの法律により、レバラン等の宗教祝日前に会社から従業員に支給が義務付けられている特別手当の略称は？</summary>
<strong>正解: THR (Tunjangan Hari Raya)</strong><br>
解説: 勤続年数に応じて基本給1ヶ月分相当が支給され、帰省やレバランの準備費用に充てられます。
</details>
