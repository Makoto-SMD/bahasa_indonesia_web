# 心の動きを伝える！感情・心理状態を表すインドネシア語表現集

人間関係を深め、自分の気持ちや共感をリアルに伝えるためには、感情（perasaan）を表す多彩な語彙が欠かせません。

インドネシア語には、日本語の「ほっとした」「どうしていいか分からない」「気まずい」「照れくさい」といった繊細な心の揺れを言い表す便利な単語が豊富に存在します。

本記事では、喜び・安心、悲しみ・落胆、怒り・苛立ち、不安・恐れ、そして困惑や恥ずかしさを表す感情ボキャブラリーを整理して解説します。

---

## 1. 喜び・幸福・安心感（Kegembiraan & Ketenangan）

前向きでポジティブな心の状態を表す単語です。

| 単語 | 日本語の意味 | ニュアンス・用例 |
| :--- | :--- | :--- |
| **senang** | 嬉しい、楽しい、好む | senang hati（喜んで）, Saya sangat senang.（とても嬉しいです。） |
| **bahagia** | 幸せな、幸福な | hidup bahagia（幸せに暮らす。senangより深い持続的幸福） |
| **gembira** | 大喜びの、陽気な | kabar gembira（嬉しい知らせ、朗報） |
| **puas** | 満足した | puas dengan hasilnya（結果に満足している） |
| **lega** | ほっとした、安心した | lega rasanya（ほっとした気分だ。不安が解消された安堵感） |
| **tenang** | 落ち着いた、冷静な、穏やかな | tenang saja（落ち着いて、心配しないで） |
| **semangat** | やる気、元気、気合い | tetap semangat（諦めずに頑張ろう！） |

<div class="id-example">
<div class="id-sentence">Setelah mendengar bahwa operasinya berjalan lancar, saya merasa sangat lega dan tenang.</div>
<div class="id-translation">手術が無事に終わったと聞いて、私はとても安心し（lega）、心が落ち着きました（tenang）。</div>
<div class="id-explanation">berjalan lancar（順調に進む） / lega（心配事が解消した安堵）。</div>
</div>

## 2. 悲しみ・失望・寂しさ（Kesedihan & Kekecewaan）

沈んだ気分や孤独感を表す単語です。

| 単語 | 日本語の意味 | ニュアンス・用例 |
| :--- | :--- | :--- |
| **sedih** | 悲しい | film yang sedih（悲しい映画） |
| **kecewa** | 失望した、がっかりした | kecewa berat（ひどく失望した） |
| **kesepian** | 寂しい、孤独な | merasa kesepian di kota besar（大都市で寂しさを感じる） |
| **hampa** | 虚しい、心が空っぽな | hati terasa hampa（心が空虚に感じる） |
| **patah hati** | 失恋した、心が折れた | lagu patah hati（失恋ソング） |
| **menyesal** | 後悔している | menyesali perbuatannya（自分の行いを後悔する） |

<div class="id-example">
<div class="id-sentence">Saya sangat kecewa karena proyek penting yang sudah kami siapkan berbulan-bulan tiba-tiba dibatalkan.</div>
<div class="id-translation">何ヶ月も準備してきた重要なプロジェクトが突然キャンセルされ、私は大変落胆しています。</div>
<div class="id-explanation">kecewa（がっかりする、失望する） / dibatalkan（中止にされた）。</div>
</div>

---

## 3. 怒り・苛立ち・不満（Kemarahan & Kekesalan）

感情が高ぶったり、不満が募った時の表現です。

| 単語 | 日本語の意味 | ニュアンス・用例 |
| :--- | :--- | :--- |
| **marah** | 怒っている | Jangan marah dulu ya.（まず怒らないでね。） |
| **kesal / jengkel** | イライラする、むかつく | kesal karena macet（渋滞でイライラする） |
| **emosi** | 感情的になる、カッとなる | mudah terpancing emosi（すぐにカッとなりやすい） |
| **kecewa** | 不満である | pelayanan yang mengecewakan（不満な接客） |
| **muak / bosan** | うんざりした、嫌気が差した | Saya sudah muak dengan janjinya.（彼の約束にはもううんざりだ。） |

<div class="id-example">
<div class="id-sentence">Wajar saja dia kesal karena harus menunggu lebih dari dua jam tanpa ada kejelasan apa pun.</div>
<div class="id-translation">何の説明もないまま2時間以上も待たされれば、彼がイライラする（kesal）のも当然です。</div>
<div class="id-explanation">wajar saja（当然だ、もっともだ） / kejelasan（明確な説明・明確さ）。</div>
</div>

---

## 4. 不安・心配・恐れ（Kekhawatiran & Ketakutan）

先の見えない状況や恐怖に対する感情です。

| 単語 | 日本語の意味 | ニュアンス・用例 |
| :--- | :--- | :--- |
| **takut** | 怖い、恐れている | takut kegelapan（暗闇が怖い）, takut gagal（失敗を恐れる） |
| **khawatir / cemas** | 心配している、不安な | jangan khawatir（心配しないで） |
| **gelisah** | そわそわした、落ち着かない | tidur tidak nyenyak karena gelisah（不安で寝付けない） |
| **panik** | パニックになる、狼狽する | Jangan panik saat terjadi gempa.（地震のときにパニックにならないで。） |
| **curiga** | 疑わしく思っている、不審に思う | merasa curiga（怪しいと感じる） |

<div class="id-example">
<div class="id-sentence">Jangan terlalu khawatir, semua dokumen sudah diperiksa dengan teliti oleh tim ahli.</div>
<div class="id-translation">あまり心配しないでください。すべての書類は専門家チームによって入念に確認済みです。</div>
<div class="id-explanation">jangan terlalu khawatir（あまり心配しすぎないで）。日常会話の超頻出フレーズです。</div>
</div>

## 5. 驚き・困惑・恥ずかしさ（Keterkejutan & Kebingungan）

日常で頻繁に遭遇する心理状態です。

| 単語 | 日本語の意味 | ニュアンス・用例 |
| :--- | :--- | :--- |
| **kaget / terkejut** | びっくりした、驚いた | Kaget saya!（びっくりした！） |
| **heran** | 不思議に思う、呆れる | heran melihat tingkah lakunya（彼の行動に呆れる・不思議がる） |
| **bingung** | 混乱している、どうしていいか分からない | Saya bingung mau pilih yang mana.（どれを選べばいいか迷う・困惑する） |
| **malu** | 恥ずかしい、照れくさい | jangan malu-malu（遠慮しないで、恥ずかしがらないで） |
| **canggung** | 気まずい、ぎこちない | suasana terasa canggung（空気が気まずい） |
| **penasaran** | 好奇心がある、気になって仕方ない | Saya sangat penasaran dengan rasanya.（どんな味なのか気になってたまらない） |

<div class="id-example">
<div class="id-sentence">Saya merasa sangat bingung karena jalan di persimpangan ini tidak ada rambu petunjuk arah sama sekali.</div>
<div class="id-translation">この交差点の道路には案内標識が全くないため、私はどう進めばいいか非常に困惑しています（bingung）。</div>
<div class="id-explanation">bingung: 道に迷った時、判断に迷った時、混乱した時に万能で使われる最頻出単語です。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 心配事が解決したり、危険が去った時に「ほっと胸をなでおろした、安心した」と表現する単語は？</summary>
<strong>正解: lega</strong><br>
解説: 試験が終わった後や、無事を確認した際に「Lega rasanya（あー安心した）」とよく口にします。
</details>

<details class="id-quiz">
<summary>Q2. 選択肢が多すぎたり、状況が理解できずに「混乱している、どうすればいいか迷っている」を表す必須語は？</summary>
<strong>正解: bingung</strong><br>
解説: 「Saya bingung（迷っちゃう、混乱する）」は、レストランのメニュー選びから仕事のトラブルまで日常で最も使われる感情語の一つです。
</details>

<details class="id-quiz">
<summary>Q3. 他人の家で食事を勧められた際などに「遠慮しないで、恥ずかしがらないで食べてね」と言う時の決まり文句は？</summary>
<strong>正解: Jangan malu-malu</strong><br>
解説: malu（恥ずかしい）を重ねることで「遠慮する」の意味になり、「Jangan malu-malu ya」はホスピタリティあふれる親切な勧め言葉です。
</details>
