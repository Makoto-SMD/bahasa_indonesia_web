# 家電・スマートフォン・PC・インターネット用語完全まとめ

日常生活から職場での業務まで、電化製品やスマートフォン、パソコン、インターネットに関する言葉は現代の生活に不可欠です。

インドネシアでは英語起源の外来語（download, upload, password等）がそのまま使われる一方で、政府の言語標準化（KBBI）によって制定された固有語（unduh, unggah, kata sandi等）も公式文書やアプリの設定画面で広く定着しています。

本記事では、家庭の家電製品からスマートフォンの通信用語、オフィスPC、ネット・アプリ操作の動詞、トラブル時の表現までを完全整理します。

---

## 1. 家庭用電化製品（Alat Elektronik Rumah Tangga）

家やアパートで日常的に使用する家電製品の名称です。

| 単語 | 日本語の意味 | 用例・関連語 |
| :--- | :--- | :--- |
| **kulkas / lemari es** | 冷蔵庫 | kulkas rusak（冷蔵庫が壊れた）, pembeku / freezer（冷凍庫） |
| **mesin cuci** | 洗濯機 | mencuci baju dengan mesin cuci（洗濯機で服を洗う） |
| **AC (Air Conditioner)** | エアコン、クーラー | nyalakan AC（エアコンをつける）, cuci AC（エアコンクリーニング） |
| **setrika** | アイロン | setrika baju（服にアイロンをかける） |
| **televisi / TV** | テレビ | menonton televisi（テレビを見る） |
| **penanak nasi / rice cooker** | 炊飯器 | masak nasi di rice cooker（炊飯器でご飯を炊く） |
| **kipas angin** | 扇風機 | kipas angin gantung（シーリングファン） |
| **pemanas air / water heater** | 給湯器、湯沸かし器 | air panas tidak keluar（お湯が出ない） |
| **dispenser** | ウォーターサーバー | air galon（ガロンボトルの水）をセットして冷水・温水が出る機械。 |
| **oven / microwave** | オーブン / 電子レンジ | menghangatkan makanan di microwave（レンジで温める） |

<div class="id-example">
<div class="id-sentence">Tolong panggil teknisi untuk servis AC karena kamarnya tidak terasa dingin sama sekali.</div>
<div class="id-translation">部屋が全く冷えないので、エアコン修理の技術者を呼んでください。</div>
<div class="id-explanation">teknisi（技術者・修理業者） / servis（点検・修理） / sama sekali（全く〜ない）。</div>
</div>

## 2. スマートフォン・通信・契約用語（Ponsel & Telekomunikasi）

スマホの操作やSIMカード、データ通信に関する必須用語です。

| 単語 | 日本語の意味 | 解説・実務知識 |
| :--- | :--- | :--- |
| **hp (handphone) / ponsel** | スマホ、携帯電話 | 日常会話では圧倒的に「hp（ハーパー）」と略称で呼ばれる。 |
| **pulsa** | 通話クレジット・通話料 | プリペイド通信の度数。通話やSMS、データプラン購入の元手となる。 |
| **kuota / paket data** | データ通信容量、ギガ | kuota habis（ギガがなくなった）, beli paket internet（ネットプラン購入） |
| **kartu SIM** | SIMカード | Telkomsel, Indosat, XL などの通信事業者のSIM。 |
| **sinyal / jaringan** | 電波、通信シグナル | sinyal jelek / lemah（電波が悪い・弱い） |
| **isi ulang** | チャージ、トップアップ | isi pulsa（プルサをチャージする） |
| **baterai** | バッテリー、電池 | baterai lemah / habis（バッテリー切れ）, baterai drop（バッテリー劣化） |
| **pengisi daya / charger** | 充電器 | pinjam charger（充電器を借りる） |
| **layar sentuh** | タッチスクリーン | layar pecah / retak（画面が割れた） |
| **colokan** | コンセント差込口、プラグ | colokan listrik（電源コンセント。インドネシアは丸ピンCタイプ） |

<div class="id-example">
<div class="id-sentence">Kuota internet saya sudah habis, bolehkah saya minta kata sandi Wi-Fi di kafe ini?</div>
<div class="id-translation">インターネットの通信容量を使い切ってしまったのですが、このカフェのWi-Fiパスワードを教えていただけますか？</div>
<div class="id-explanation">kuota habis（通信容量切れ） / minta kata sandi（パスワードを求める）。</div>
</div>

## 3. PC・オフィスIT・周辺機器（Komputer & Perangkat Keras）

パソコンやオフィス周辺機器の名称です。

| インドネシア語（公用語 / 慣用語） | 日本語の意味 | 補足 |
| :--- | :--- | :--- |
| **laptop / komputer jinjing** | ノートパソコン | 会話では「laptop」が一般的。 |
| **komputer meja / PC** | デスクトップパソコン | PC（ペーセー）と呼ばれる。 |
| **tetikus / mouse** | マウス | 公式用語は「tetikus（小ネズミ）」。日常では mouse も多用。 |
| **papan ketik / keyboard** | キーボード | 公式表記は papan ketik。 |
| **layar monitor** | モニター画面 | resolusi layar（画面解像度）。 |
| **pencetak / printer** | プリンター | tinta printer（プリンターのインク）。 |
| **pemindai / scanner** | スキャナー | memindai dokumen（書類をスキャンする）。 |
| **kabel HDMI / USB** | HDMI/USBケーブル | colokkan kabel（ケーブルを挿す）。 |
| **penyimpanan awan / cloud** | クラウドストレージ | simpan file di cloud（クラウドにファイルを保存する）。 |

<div class="id-example">
<div class="id-sentence">Printer di kantor tidak bisa mencetak dokumen karena kehabisan kertas dan tinta.</div>
<div class="id-translation">オフィスのプリンターは紙とインクが切れているため、書類を印刷できません。</div>
<div class="id-explanation">mencetak（印刷する） / kehabisan（〜を切らす、〜が尽きる）。</div>
</div>

## 4. インターネット・アプリ・操作動詞（Aplikasi & Perintah Digital）

アプリやWebサイトの設定画面で頻繁に登場する標準操作用語です。

| 公式標準語（KBBI） | 英語併用表現 | 日本語の意味 |
| :--- | :--- | :--- |
| **unduh / mengunduh** | download | ダウンロードする |
| **unggah / mengunggah** | upload | アップロードする |
| **masuk log / masuk** | login / sign in | ログインする、サインインする |
| **keluar log / keluar** | logout / sign out | ログアウトする |
| **kata sandi** | password | パスワード、暗証番号 |
| **nama pengguna** | username | ユーザー名 |
| **simpan** | save | 保存する |
| **hapus** | delete | 削除する、消去する |
| **salin & tempel** | copy & paste | コピー＆ペーストする |
| **perbarui** | update | 更新する、アップデートする |
| **kirim** | send / submit | 送信する |
| **pengaturan / setelan** | settings | 設定 |

<div class="id-example">
<div class="id-sentence">Silakan unduh aplikasi ini di Play Store, lalu masukkan alamat email dan buat kata sandi baru.</div>
<div class="id-translation">Playストアでこのアプリをダウンロードし、メールアドレスを入力して新しいパスワードを作成してください。</div>
<div class="id-explanation">unduh（ダウンロードする） / masukkan（入力する） / kata sandi baru（新しいパスワード）。</div>
</div>

## 5. 家電・ITトラブルで役立つフレーズ集

機械や通信に不具合が生じた際に使える実践的な表現です。

<div class="id-example">
<div class="id-sentence">Komputer saya tiba-tiba macet (hang) dan layarnya membeku, jadi tidak bisa diklik apa pun.</div>
<div class="id-translation">パソコンが突然フリーズして画面が固まってしまい、何もクリックできません。</div>
<div class="id-explanation">macet / hang（フリーズする、固まる） / membeku（凍りつく、固まる）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Koneksi internet di sini sangat lambat dan sering putus-putus sejak tadi pagi.</div>
<div class="id-translation">今朝からここのインターネット接続が非常に遅く、頻繁に途切れます。</div>
<div class="id-explanation">koneksi（接続） / putus-putus（途切れ途切れになる）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Apakah ada stopkontak kosong di dekat sini? Saya perlu mengisi baterai laptop saya.</div>
<div class="id-translation">この近くに空いている電源コンセントはありますか？ノートパソコンを充電する必要があります。</div>
<div class="id-explanation">stopkontak（壁面コンセント） / mengisi baterai（充電する）。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. アプリの設定やWeb画面で「ダウンロード（Download）」と「アップロード（Upload）」に対応するインドネシア公式標準語は？</summary>
<strong>正解: unduh（ダウンロード） / unggah（アップロード）</strong><br>
解説: どちらも古典語由来の造語で、現代のインドネシア語OSや公式アプリで標準的に使用されています。
</details>

<details class="id-quiz">
<summary>Q2. スマホのプリペイド通話・通信の度数（クレジット）を指すインドネシア特有の単語は？</summary>
<strong>正解: pulsa</strong><br>
解説: pulsa（プルサ）はコンビニや電子決済（GoPay, OVO, Dana）でチャージし、ネット容量（paket data）の購入にも使われます。
</details>

<details class="id-quiz">
<summary>Q3. インドネシアの一般家庭やカフェで使われている電源プラグ・コンセントの形状タイプは？</summary>
<strong>正解: Cタイプ（丸ピン2本）</strong><br>
解説: 電圧は220V、周波数は50Hzです。日本の平行2ピン（Aタイプ）製品をそのまま挿すことはできないため、変換アダプタが必要です。
</details>
