# インドネシアの料理・食材・香辛料・調味料の必須単語集

インドネシアは「香辛料諸島（Spices Islands）」とも呼ばれるほど豊かなスパイス文化を持ち、地方ごとに多様で魅力的な郷土料理が存在します。

屋台（Kaki lima）やワルン（Warung）、地元のスーパーマーケットや市場（Pasar）で、食べたい料理を正しく注文し、好みの味付けや辛さを伝えるためには、食材と香辛料の基本ボキャブラリーが欠かせません。

本記事では、代表的な名物料理から主食、肉・魚介類、野菜、伝統調味料、そして味覚・調理法の表現までを網羅して解説します。

---

## 1. 代表的な名物料理（Makanan Khas Indonesia）

まずはインドネシア全土で親しまれている代表的なメニュー名です。

| 料理名 | 日本語の概要 | 特徴・解説 |
| :--- | :--- | :--- |
| **nasi goreng** | インドネシア風炒飯 | 甘口醤油（kecap manis）やトラシ（小エビペースト）で炒めた国民食。目玉焼き（telur mata sapi）が乗ることが多い。 |
| **mie goreng** | インドネシア風焼きそば | 中華麺を甘辛く炒めた定番麺料理。インスタント麺（Indomie）も有名。 |
| **sate** | 串焼き（サテ） | 鶏肉（sate ayam）や山羊肉（sate kambing）を炭火で焼き、甘辛ピーナッツソース（bumbu kacang）や唐辛子醤油で食べる。 |
| **rendang** | ルンダン（牛肉のスパイシー煮込み） | ココナッツミルクと数十種のスパイスで何時間も煮込んだパダン料理の至宝。世界一美味しい料理に選ばれた実績。 |
| **soto** | スープ料理（ソト） | 鶏肉ベースの澄んだスープ（soto ayam）や牛肉スープ（soto daging）。春雨やキャベツが入る。 |
| **gado-gado** | 温野菜のピーナッツソース和え | 茹でたインゲン、もやし、ジャガイモ、ゆで卵、厚揚げに濃厚なピーナッツソースをかけたインドネシア版温野菜サラダ。 |
| **bakso** | 肉団子（バクソ）スープ | 牛肉のすり身団子が入ったスープ麺。屋台の定番軽食。 |
| **ayam goreng** | 揚げ鶏、フライドチキン | スパイスに漬け込んでから揚げた香ばしいチキン。サンバルと生野菜（lalapan）を添えて食べる。 |

<div class="id-example">
<div class="id-sentence">Saya ingin mencoba rendang sapi khas Padang yang pedas dan gurih ini.</div>
<div class="id-translation">私はこのスパイシーで旨味のあるパダン名物の牛ルンダンを食べてみたいです。</div>
<div class="id-explanation">khas（〜特有の、名物の） / pedas（辛い） / gurih（コク・旨味がある）。</div>
</div>

## 2. 主食・肉・魚介・タンパク質（Makanan Pokok, Daging & Lauk）

料理のベースとなる主食と、具材となるタンパク質源の単語です。

| 単語 | 日本語の意味 | 用例・補足 |
| :--- | :--- | :--- |
| **nasi** | （炊いた）ご飯 | nasi putih（白米）, nasi uduk（ココナッツミルク炊き込みご飯） |
| **beras** | 生米（炊く前の米） | beli beras di pasar（市場で米を買う） |
| **mie / mi** | 麺（めん） | mie kuah（汁麺）, mie instan（即席ラーメン） |
| **roti** | パン | roti bakar（トースト・ホットサンド） |
| **ayam** | 鶏肉、チキン | daging ayam（鶏肉）, ayam bakar（焼き鳥） |
| **sapi** | 牛肉、ビーフ | daging sapi（牛肉）, iga sapi（牛リブ肉） |
| **kambing** | 山羊肉、羊肉 | sate kambing（山羊の串焼き。マトンより臭みが少ない） |
| **babi** | 豚肉（※ポーク） | イスラム教徒はハラール（禁忌）のため食べない。中華系やバリ島（babi guling）で親しまれる。 |
| **ikan** | 魚（全般） | ikan bakar（焼き魚）, ikan goreng（揚げ魚） |
| **udang** | エビ | kerupuk udang（エビせんべい） |
| **cumi-cumi** | イカ | cumi goreng tepung（イカの天ぷら・フライ） |
| **telur** | 卵 | telur dadar（卵焼き・オムレツ）, telur rebus（ゆで卵） |
| **tahu** | 豆腐（タフ） | インドネシアの豆腐は水分が少なく、揚げ物に適している。 |
| **tempe** | テンペ | 大豆をテンペ菌で発酵させた伝統健康食。揚げて食べるのが定番。 |

<div class="id-example">
<div class="id-sentence">Untuk makan siang, saya memesan nasi putih dengan lauk tahu goreng, tempe bacem, dan ayam bakar.</div>
<div class="id-translation">昼食には、白ご飯におかずとして揚げ豆腐、甘煮テンペ、焼きチキンを注文しました。</div>
<div class="id-explanation">lauk（おかず） / bacem（パームシュガーとスパイスで甘辛く煮た伝統調理法）。</div>
</div>

## 3. 野菜・キノコ・果物（Sayuran & Buah-buahan）

料理に入っている野菜や市場で見かける南国フルーツの名前です。

| 単語 | 日本語の意味 | 特徴・料理での使われ方 |
| :--- | :--- | :--- |
| **kangkung** | 空心菜（カンクン） | cah kangkung（空心菜炒め）はレストランの超定番野菜料理。 |
| **bayam** | ほうれん草 | sayur bening bayam（ほうれん草とトウモロコシの澄ましスープ）。 |
| **wortel** | 人参（にんじん） | オランダ語起源の単語。スープや炒め物に入る。 |
| **kentang** | ジャガイモ | kentang goreng（フライドポテト）。 |
| **tomat** | トマト | サンバル（sambal tomat）の原料にもなる。 |
| **mentimun / timun** | きゅうり | 揚げ物や辛い料理の箸休め（lalapan）として生で添えられる。 |
| **kubis / kol** | キャベツ | 炒め物やスープ、屋台のバクソに入る。 |
| **jamur** | キノコ | jamur krispi（サクサクのキノコフライ）。 |
| **pisang** | バナナ | pisang goreng（揚げバナナ）はおやつの大定番。 |
| **mangga** | マンゴー | jus mangga（マンゴージュース）。雨季が旬。 |
| **pepaya** | パパイヤ | 消化を助ける甘い南国フルーツ。 |
| **durian** | ドリアン | 「果物の王様」。強烈な香りと濃厚なカスタードのような味。 |
| **kelapa** | ココナッツ、ヤシの実 | air kelapa muda（ヤシの実ジュース）, santan（ココナッツミルク）。 |

<div class="id-example">
<div class="id-sentence">Tolong hidangkan tumis kangkung terasi dan jus mangga tanpa gula.</div>
<div class="id-translation">空心菜のトラシ炒めと、砂糖抜きのマンゴージュースを出してください。</div>
<div class="id-explanation">tumis（炒め物） / tanpa gula（砂糖なし。現地のジュースは大量のシロップが入るため指定が有効）。</div>
</div>

## 4. 香辛料・調味料（Bumbu & Rempah-rempah）

インドネシア料理独特の風味を作り出すスパイスとソースです。

| 調味料・スパイス名 | 日本語の意味 | 特徴と使い方 |
| :--- | :--- | :--- |
| **bawang merah** | エシャロット（赤わけぎ） | 小さな赤玉ねぎ。香味油や薬味、炒め物のベース。フライドエシャロット（bawang goreng）はご飯にかける定番。 |
| **bawang putih** | ニンニク | ほぼすべての料理のベースとなる最重要香味野菜。 |
| **cabai / cabe** | 唐辛子 | 赤唐辛子（cabai merah）や激辛小唐辛子（cabai rawit）がある。 |
| **kecap manis** | 甘口醤油（ケチャップマニス） | ヤシ糖（gula merah）が入った黒くドロッとした甘い醤油。照り焼きやサテのタレ、ナシゴレンに不可欠。 |
| **kecap asin** | 薄口醤油（しょっぱい醤油） | 日本の醤油に近い塩辛い醤油。 |
| **sambal** | サンバル（唐辛子ペースト） | 食卓に必ず置かれる万能辛味調味料。トマト入り、生サンバル（sambal matah）など多彩。 |
| **terasi** | トラシ（発酵エビペースト） | 小エビを発酵させた独特の強い香りと深い旨味を持つ調味料。炒め物やサンバルにコクを出す。 |
| **santan** | ココナッツミルク | カレーやルンダン、スープにまろやかさとコクを与える。 |
| **jahe** | 生姜（しょうが） | 煮込み料理や生姜湯（wedang jahe）に使う。 |
| **kunyit** | ターメリック（ウコン） | 黄色いご飯（nasi kuning）の色付けや、臭み消しに多用。 |
| **serai / sereh** | レモングラス | 爽やかな柑橘系の香りを添えるハーブ。 |
| **garam** | 塩 | garam dapur（食塩）。 |
| **gula** | 砂糖 | gula pasir（白砂糖）, gula merah / gula jawa（ヤシ糖・黒糖）。 |

<div class="id-example">
<div class="id-sentence">Sambal matah khas Bali dibuat dari irisan bawang merah, serai, cabai rawit, dan terasi yang disiram minyak panas.</div>
<div class="id-translation">バリ島名物のサンバル・マタは、刻んだエシャロット、レモングラス、生唐辛子、トラシに熱い油をかけて作られます。</div>
<div class="id-explanation">sambal matah（バリの生サンバル） / irisan（薄切り） / disiram（〜をかけられた）。</div>
</div>

## 5. 味覚と調理法の表現（Rasa & Cara Memasak）

注文時や味の感想を伝える際に役立つ形容詞と調理法です。

### 5.1 味覚（Rasa）
- **pedas**: 辛い（※唐辛子の辛さ）
- **manis**: 甘い
- **asin**: 塩辛い、しょっぱい
- **asam**: 酸っぱい
- **pahit**: 苦い
- **gurih**: 旨味がある、コクがある、香ばしい（MSGや出汁、ココナッツの効いた美味しさ）
- **hambar**: 味が薄い、水っぽい

### 5.2 調理法（Cara Memasak）
- **goreng**: 油で揚げる、炒める（ayam goreng, nasi goreng）
- **bakar**: 炭火で直火焼きする（ikan bakar, jagung bakar）
- **panggang**: オーブン等で焼く（roti panggang）
- **rebus**: 茹でる、煮る（telur rebus, mie rebus）
- **kukus**: 蒸す（bolu kukus）
- **tumis**: 少量の油でさっと炒める（tumis sayur）

<div class="id-example">
<div class="id-sentence">Tolong jangan buat terlalu pedas ya, saya tidak kuat makan cabai banyak.</div>
<div class="id-translation">あまり辛くしないでくださいね。私は唐辛子をたくさん食べるのが得意ではありません。</div>
<div class="id-explanation">tidak kuat（耐えられない、苦手である）。辛さを抑えてほしい時の定番フレーズです。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシア料理に欠かせない、ヤシ糖が入った甘く粘り気のある伝統醤油の名称は？</summary>
<strong>正解: kecap manis</strong><br>
解説: ナシゴレンやサテのタレに使われる調味料で、日本の照り焼きのタレに似た甘みがあります。塩辛い醤油は「kecap asin」です。
</details>

<details class="id-quiz">
<summary>Q2. 大豆を菌で発酵させたブロック状の伝統食品で、高タンパク・低脂質な健康食として世界中で注目されている食材は？</summary>
<strong>正解: tempe</strong><br>
解説: インドネシア発祥の発酵大豆食品で、薄切りにしてカリッと揚げた「tempe goreng」は日々の食卓の定番です。
</details>

<details class="id-quiz">
<summary>Q3. インドネシアの激辛調味料「サンバル（sambal）」の中で、バリ島発祥の生ハーブ（エシャロットやレモングラス）を使ったものは？</summary>
<strong>正解: sambal matah</strong><br>
解説: matah はバリ語で「生の」を意味し、火を通さず刻んだ香味野菜に熱した油を注いで香りを引き出します。
</details>
