# 日常必須形容詞50選（感情・状態・性質・対義語ペア）完全まとめ

会話に豊かな表現力と感情のニュアンスをもたらすのが**「形容詞（Kata Sifat）」**です。

名詞の後に形容詞を置くというインドネシア語の基本原則（DMの法則：後置修飾）さえ知っていれば、形容詞を覚えるだけで「美味しい料理（makanan enak）」「高い車（mobil mahal）」「親切な人（orang ramah）」といった無限の表現を作ることができます。

本記事では、日常生活で最もよく使われる必須形容詞50個を**「対義語（Antonim）ペア」**やカテゴリ別に整理し、感情表現から状態・評価、そして程度を強める副詞の使い方までを徹底解説します。

---

## 1. 感情・気分を表す形容詞（Perasaan & Suasana Hati）

自分の感情や体調を伝える表現です。

| 形容詞 | 日本語の意味 | 対義語・関連語 | 例文 |
| :--- | :--- | :--- | :--- |
| **senang / bahagia** | 嬉しい、楽しい、幸せ | sedih（悲しい） | Saya sangat senang bertemu dengan Anda.（お会いできてとても嬉しいです。） |
| **sedih** | 悲しい | senang（嬉しい） | Jangan sedih, semuanya akan baik-baik saja.（悲しまないで、全てうまくいくよ。） |
| **marah** | 怒っている | sabar（我慢強い・穏やか） | Kenapa dia marah-marah?（なぜ彼はカンカンに怒っているの？） |
| **takut** | 怖い、恐れている | berani（勇敢な） | Saya takut ketinggian.（私は高所恐怖症です／高い所が怖いです。） |
| **bingung** | 混乱した、困惑した | yakin（確信した） | Saya bingung memilih menu yang mana.（どのメニューを選べばいいか迷っています。） |
| **capek / lelah** | 疲れた | segar（爽やかな） | Hari ini badan saya capek sekali.（今日私の体はとても疲れています。） |
| **bosan** | 退屈な、飽きた | seru（ワクワクする） | Saya bosan menunggu di sini sendirian.（ここで一人で待つのは退屈です。） |
| **kecewa** | がっかりした、失望した | puas（満足した） | Kami agak kecewa dengan hasilnya.（私たちは結果に少し落胆しました。） |
| **kaget** | びっくりした、驚いた | tenang（落ち着いた） | Saya kaget mendengar berita gempa tadi.（さっきの地震のニュースを聞いて驚きました。） |
| **khawatir** | 心配な、不安な | tenang（安心した） | Ibu sangat khawatir tentang keselamatanmu.（母はあなたの安全をとても心配しています。） |

<div class="id-example">
<div class="id-sentence">Setelah bekerja seharian di kantor, wajar kalau kamu merasa sangat lelah.</div>
<div class="id-translation">オフィスで一日中働いた後なんだから、とても疲れるのは当然ですよ。</div>
<div class="id-explanation">seharian（一日中） / wajar kalau...（〜なのは自然・当然だ）。</div>
</div>

## 2. 大きさ・数量・寸法の対義語ペア（Ukuran & Jumlah）

物の外見や規模を表す必須の反対語ペアです。

| 形容詞A | 意味 | 形容詞B | 意味 | 例文 |
| :--- | :--- | :--- | :--- | :--- |
| **besar** | 大きい | **kecil** | 小さい | Rumahnya cukup besar, tapi halamannya kecil.（家は結構大きいが庭は小さい。） |
| **banyak** | 多い | **sedikit** | 少ない | Banyak orang suka makanan pedas di sini.（ここでは多くの人が辛い物が好きです。） |
| **panjang** | 長い | **pendek** | 短い | Jembatan ini sangat panjang.（この橋は非常に長いです。） |
| **tinggi** | 高い（背・建物） | **rendah / pendek** | 低い（背・高度） | Gedung tinggi di Jakarta.（ジャカルタの高層ビル。） |
| **berat** | 重い | **ringan** | 軽い | Koper ini terlalu berat untuk dibawa.（このスーツケースは運ぶには重すぎます。） |
| **tebal** | 分厚い | **tipis** | 薄い | Kamus ini sangat tebal.（この辞書はとても分厚いです。） |
| **luas** | 広い | **sempit** | 狭い | Kamar mandinya agak sempit.（浴室が少々狭いです。） |
| **jauh** | 遠い | **dekat** | 近い | Stasiun tidak jauh dari sini, sangat dekat.（駅はここから遠くなく、とても近いです。） |

<div class="id-example">
<div class="id-sentence">Apartemen ini memiliki ruang tamu yang luas, tetapi dapurnya sedikit sempit.</div>
<div class="id-translation">このアパートは広いリビングを持っていますが、キッチンは少し狭いです。</div>
</div>

## 3. 温度・天候・味覚の形容詞（Suhu, Cuaca & Rasa）

飲食や環境に関する形容詞です。

| 形容詞 | 日本語の意味 | 対義語・関連語 | 例文 |
| :--- | :--- | :--- | :--- |
| **panas** | 暑い、熱い | dingin（寒い・冷たい） | Cuaca di Jakarta hari ini sangat panas.（今日のジャカルタの天気はとても暑いです。） |
| **dingin** | 寒い、冷たい | panas（熱い） | Tolong minta air dingin ya.（冷たいお水をください。） |
| **hangat** | 温かい、ぬるい | sejuk（涼しい） | Teh hangat tanpa gula.（温かい無糖茶。） |
| **enak / lezat** | 美味しい | hambar（味がしない） | Masakan Padang ini luar biasa enak!（このパダン料理は驚くほど美味しい！） |
| **pedas** | 辛い | manis（甘い） | Sambal ini sangat pedas tapi bikin nagih.（このサンバルは激辛ですが病みつきになります。） |
| **manis** | 甘い | pahit（苦い） | Kopi ini terlalu manis karena banyak gula.（砂糖が多いためこのコーヒーは甘すぎます。） |
| **asin** | 塩辛い | tawar（無味・薄味） | Sayur sopnya agak keasinan.（スープが少ししょっぱすぎます。） |
| **asam** | 酸っぱい | manis（甘い） | Mangga muda ini rasanya sangat asam.（この若いマンゴーは味がとても酸っぱいです。） |
| **pahit** | 苦い | manis（甘い） | Jamu tradisional rasanya pahit tapi sehat.（伝統生薬ジャムーは苦いですが体に良いです。） |

<div class="id-example">
<div class="id-sentence">Saya suka kopi panas yang pahit tanpa gula, bukan kopi dingin yang manis.</div>
<div class="id-translation">私が好きなのは甘いアイスコーヒーではなく、砂糖の入っていない苦いホットコーヒーです。</div>
</div>

## 4. 速度・難易度・評価・価格の対義語ペア（Kualitas, Kecepatan & Harga）

日常やビジネスでの判断基準となる対義語ペアです。

| 形容詞A | 意味 | 形容詞B | 意味 | 例文 |
| :--- | :--- | :--- | :--- | :--- |
| **cepat** | 速い、早い | **lambat / pelan** | 遅い、ゆっくり | Internetnya cepat sekali.（インターネットがとても速いです。） |
| **mudah / gampang** | 簡単な、易しい | **sulit / susah** | 難しい、困難な | Ujian ini tidak semudah yang saya bayangkan.（この試験は想像したほど簡単ではありません。） |
| **bagus / baik** | 良い、素晴らしい | **jelek / buruk** | 悪い、見栄えが悪い | Pelayanannya sangat bagus.（サービスがとても素晴らしいです。） |
| **mahal** | （値段が）高い | **murah** | （値段が）安い | Barang bermerek harganya mahal.（ブランド品は値段が高いです。） |
| **bersih** | 清潔な、綺麗な | **kotor** | 汚れた、不潔な | Tolong jaga toilet ini tetap bersih.（このトイレを綺麗に保ってください。） |
| **baru** | 新しい | **lama / tua** | 古い、長年の | Saya baru beli sepatu baru.（私は新しい靴を買ったばかりです。） |
| **terang** | 明るい | **gelap** | 暗い | Lampunya terang sekali.（電灯がとても明るいです。） |
| **ramai** | 賑やかな、混雑した | **sepi** | 静かな、閑散とした | Mal ini selalu ramai saat akhir pekan.（このモールは週末いつも賑わっています。） |

<div class="id-example">
<div class="id-sentence">Meskipun tata bahasa Indonesia relatif mudah dipelajari, sistem afiksnya cukup menantang.</div>
<div class="id-translation">インドネシア語の文法は比較的学びやすいものの、接辞システムはかなりやりがいがあります（難しいです）。</div>
<div class="id-explanation">cukup menantang（かなり手応えがある・挑戦的だ）。</div>
</div>

## 5. 人柄・性格・外見の形容詞（Sifat & Penampilan）

人物を描写する好感度の高い表現です。

| 形容詞 | 日本語の意味 | 補足 | 例文 |
| :--- | :--- | :--- | :--- |
| **ramah** | 親切な、愛想が良い | インドネシア人の美徳 | Orang Indonesia terkenal sangat ramah.（インドネシア人は非常に親切で有名です。） |
| **pintar / cerdas** | 賢い、頭が良い | bodoh（愚かな）の対義語 | Anak itu sangat pintar dalam matematika.（その子は数学がとても得意で賢いです。） |
| **rajin** | 勤勉な、真面目な | malas（怠惰な）の対義語 | Dia karyawan yang sangat rajin.（彼はとても勤勉な社員です。） |
| **sopan** | 礼儀正しい | sopan santun（礼儀作法） | Anak muda itu bicaranya sangat sopan.（その若者は話し方がとても礼儀正しいです。） |
| **cantik** | 美しい、可愛い（女性） | 女性への褒め言葉 | Senyumnya sangat cantik.（彼女の笑顔はとても美しいです。） |
| **ganteng / tampan** | かっこいい、ハンサム（男性） | 男性への褒め言葉 | Aktor itu sangat ganteng.（その俳優はとてもハンサムです。） |

## 6. 形容詞の程度を強める・和らげる副詞

形容詞のニュアンスを自在にコントロールする重要副詞です。

| 副詞 | 位置 | 意味・ニュアンス | 例文 |
| :--- | :--- | :--- | :--- |
| **sangat** | 形容詞の前 | とても、非常に（フォーマル） | **sangat** indah（とても美しい） |
| **sekali** | 形容詞の後 | とても、すごく（日常・口語） | mahal **sekali**（すごく高い） |
| **terlalu** | 形容詞の前 | 〜すぎる（過剰・ネガティブ） | **terlalu** pedas（辛すぎる） |
| **agak** | 形容詞の前 | やや、少し（控えめな表現） | **agak** mahal（少々高い） |
| **cukup** | 形容詞の前 | かなり、十分に | **cukup** besar（かなり大きい） |

<div class="id-example">
<div class="id-sentence">Mobil ini <strong>sangat</strong> nyaman, tapi harganya <strong>terlalu</strong> mahal untuk anggaran saya.</div>
<div class="id-translation">この車は<strong>とても</strong>乗り心地が良いですが、私の予算には値段が高<strong>すぎます</strong>。</div>
</div>

## 7. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「辛すぎる（過剰に辛い）」を表す正しい形容詞の組み合わせは？</summary>
<strong>正解: terlalu pedas</strong><br>
解説: terlalu（〜すぎる）を形容詞の前に置くことで、許容範囲を超えているネガティブな過剰さを表現します。
</details>

<details class="id-quiz">
<summary>Q2. 「親切な、愛想が良い」を意味する、インドネシアの人柄を語る最重要形容詞は？</summary>
<strong>正解: ramah</strong><br>
解説: 「Orang Indonesia sangat ramah（インドネシア人はとてもフレンドリーで親切）」は国を代表する代名詞的フレーズです。
</details>

<details class="id-quiz">
<summary>Q3. 「（値段が）高い」と「安い」の対義語ペアは？</summary>
<strong>正解: mahal（高い） / murah（安い）</strong><br>
解説: 買い物や価格交渉で毎日のように使う基本中の基本形容詞ペアです。
</details>
