# バリ島から世界遺産まで！旅・観光・アクティビティの旅行単語集

インドネシアは、世界的人気リゾートのバリ島をはじめ、世界遺産ボロブドゥールやプランバナン寺院、コモドドラゴンが生息するコモド諸島、秘境ラジャ・アンパットなど、世界屈指の観光資源を誇ります。

現地での移動、ホテルやツアーの手配、マリンスポーツや登山、伝統工芸品のお土産探しなどをスムーズに楽しむためには、観光・レジャーの専門用語が役立ちます。

本記事では、主要な名所旧跡の呼称から、予約・手配用語、アクティビティ、お土産・伝統文化品、そして旅行中の実践フレーズまでを網羅して解説します。

---

## 1. 観光スポット・名所旧跡（Tempat Wisata & Cagar Budaya）

旅の目的地となるスポットの分類と呼称です。

| 単語 | 日本語の意味 | 背景・実例 |
| :--- | :--- | :--- |
| **tempat wisata / objek wisata** | 観光地、名所 | objek wisata alam（自然景勝地） |
| **candi** | 仏教・ヒンドゥー教の石造寺院遺跡 | ジャワ島の遺跡群（Candi Borobudur, Candi Prambanan） |
| **pura** | バリ・ヒンドゥー寺院 | バリ島の寺院（Pura Besakih, Pura Tanah Lot, Pura Uluwatu） |
| **keraton / kraton** | 王宮、スルタン宮殿 | ジョグジャカルタやソロの王宮（Keraton Yogyakarta） |
| **pantai** | ビーチ、海岸 | Pantai Kuta, Pantai Sanur（バリ島のビーチ） |
| **taman nasional** | 国立公園 | Taman Nasional Komodo（コモド国立公園） |
| **kawah** | 火口、カルデラ | Kawah Ijen（イジェン火口。青い炎で有名）, Kawah Putih |
| **air terjun** | 滝（たき） | Air Terjun Tegenungan |
| **desa wisata** | 観光村、伝統村 | Desa Penglipuran（バリの伝統集落） |

> [!NOTE]
> **candi と pura の違い**
> - **candi**: 主に古代ジャワ王国時代の「石造寺院・遺跡」（歴史的遺産）を指します。
> - **pura**: 主にバリ島で現在も信仰されている「現役のヒンドゥー教寺院」を指します。

<div class="id-example">
<div class="id-sentence">Candi Borobudur di Jawa Tengah adalah candi Buddha terbesar di dunia yang masuk dalam daftar Warisan Dunia UNESCO.</div>
<div class="id-translation">中部ジャワのボロブドゥール寺院は、ユネスコ世界遺産リストに登録されている世界最大の仏教寺院です。</div>
<div class="id-explanation">candi Buddha（仏教寺院） / Warisan Dunia UNESCO（ユネスコ世界文化遺産）。</div>
</div>

## 2. 旅行手配・宿泊・チケット（Pemesanan & Akomodasi）

旅程の手配や宿泊に関する用語です。

| 単語 | 日本語の意味 | 用例・補足 |
| :--- | :--- | :--- |
| **tiket / karcis** | チケット、入場券 | tiket masuk（入場料・入場券） |
| **pemesanan / reservasi** | 予約（リザベーション） | konfirmasi pemesanan（予約確認） |
| **biro perjalanan / agen travel** | 旅行代理店、ツアー会社 | paket wisata / tour（ツアーパッケージ） |
| **pemandu wisata / guide** | ツアーガイド、案内人 | pemandu wisata berbahasa Jepang（日本語ガイド） |
| **penginapan** | 宿泊施設（総称） | mencari penginapan murah（安宿を探す） |
| **hotel bintang lima** | 5つ星ホテル | kamar suite（スイートルーム） |
| **losmen / homestay** | 民宿、ゲストハウス | penginapan tradisional |
| **paspor & visa** | パスポートとビザ | Visa on Arrival / e-VOA（到着ビザ） |
| **asuransi perjalanan** | 海外旅行保険 | klaim asuransi（保険請求） |

<div class="id-example">
<div class="id-sentence">Berapa harga tiket masuk ke objek wisata ini untuk wisatawan mancanegara?</div>
<div class="id-translation">この観光地の外国人観光客向けの入場料はいくらですか？</div>
<div class="id-explanation">wisatawan mancanegara / wisman（外国人観光客）。インドネシアの遺跡では国内客（wisatawan domestik）と外国人で料金設定が異なる場合があります。</div>
</div>

## 3. アクティビティ・アウトドア・レジャー（Aktivitas Rekreasi）

旅先での体験やスポーツに関する表現です。

- **menyelam / diving**: スキューバダイビング（alat selam: ダイビング器材）
- **snorkeling**: シュノーケリング
- **berselancar / surfing**: サーフィン（papan selancar: サーフボード）
- **mendaki gunung / trekking**: 登山、トレッキング（Gunung Bromo, Gunung Rinjani）
- **melihat lumba-lumba**: イルカウォッチング（Lovina, Bali）
- **arung jeram / rafting**: ラフティング（渓流下り）
- **pijat & spa**: マッサージ＆スパ（relaksasi: リラクゼーション）
- **berfoto-foto**: 写真撮影する、インスタ映えスポット巡り（spot foto menarik）

<div class="id-example">
<div class="id-sentence">Pulau Komodo dan Labuan Bajo sangat terkenal dengan pemandangan laut yang spektakuler dan tempat menyelam kelas dunia.</div>
<div class="id-translation">コモド島とラブアンバジョは、息をのむような海の絶景と世界屈指のダイビングスポットとして大変有名です。</div>
<div class="id-explanation">spektakuler（壮観な、見事な） / tempat menyelam（ダイビングスポット）。</div>
</div>

## 4. お土産・特産品・伝統工芸（Oleh-oleh & Kerajinan Tradisional）

旅の終わりに欠かせないお土産選びの単語です。

| 単語 | 日本語の意味 | 特徴・産地 |
| :--- | :--- | :--- |
| **oleh-oleh** | お土産（手土産） | pusat oleh-oleh（お土産センター） |
| **batik** | バティック（ろうけつ染め布） | ユネスコ無形文化遺産。ジャワ島（ソロ、ジョグジャ、ペカロンガン）が本場。 |
| **tenun** | 手織り布（イカット等） | スンバ島やフローレス島、バリ島の手織り伝統布。 |
| **kopi luwak** | コピ・ルアク（ジャコウネココーヒー） | 希少で高価な世界最高峰の芳醇コーヒー。 |
| **kerajinan perak** | 銀細工 | チュルク（Celuk, Bali）やコタゲデ（Kotagede, Jogja）が名産。 |
| **wayang kulit** | ワヤン・クリ（影絵芝居の人形） | 水牛の革で作られた伝統人形。 |
| **aromaterapi** | アロマオイル、インセンス | バリ島のエッセンシャルオイル、フランジパニの香り。 |

<div class="id-example">
<div class="id-sentence">Saya ingin membeli kain batik tulis asli dan kopi luwak khas Indonesia sebagai oleh-oleh untuk keluarga.</div>
<div class="id-translation">家族へのお土産として、本物の手描きバティック布とインドネシア特産のコピ・ルアクを買いたいです。</div>
<div class="id-explanation">batik tulis（手描きバティック。手作業のため高価で高品質） / sebagai oleh-oleh（お土産として）。</div>
</div>

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシア語で「お土産」を意味する最も一般的な名詞は？</summary>
<strong>正解: oleh-oleh</strong><br>
解説: 旅先から家族や同僚に買って帰るお土産を「oleh-oleh」と言い、街には「Pusat Oleh-oleh（お土産センター）」が多数存在します。
</details>

<details class="id-quiz">
<summary>Q2. ユネスコ無形文化遺産にも指定されている、インドネシアの伝統的なろうけつ染め布の名称は？</summary>
<strong>正解: batik（バティック）</strong><br>
解説: 毎週金曜日は「Hari Batik」として多くの会社員や学生がバティックシャツを着用します。
</details>

<details class="id-quiz">
<summary>Q3. バリ島で「寺院」を意味し、タナロットやウルワツの前に付く言葉は？</summary>
<strong>正解: Pura（プラ）</strong><br>
解説: バリ・ヒンドゥー寺院は「Pura」、ジャワの古代仏教・ヒンドゥー遺跡は「Candi」と呼び分けられます。
</details>
