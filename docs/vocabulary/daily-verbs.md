# 日常生活の必須動詞50選（基本動作・生活行動）完全まとめ

インドネシア語の会話力を最短で伸ばす鍵は、**「一日の生活行動をすべてインドネシア語の動詞で言えるようにすること」**です。

朝起きて顔を洗うことから、出勤、仕事、食事、買い物、そして夜眠りにつくまでの動作動詞（Kata Kerja）をマスターすれば、自分の行動やスケジュールを驚くほど自然に伝えられるようになります。

本記事では、日常生活で最も頻繁に使われる必須動詞50個を生活シーン別に厳選し、実践的な例文とともにわかりやすく解説します。

---

## 1. 朝の目覚めと身支度（Rutinitas Pagi）

朝起きてから家を出るまでの基本動作です。

| 動詞 | 日本語の意味 | 例文 |
| :--- | :--- | :--- |
| **bangun** | 起きる、目を覚ます | Saya biasa bangun jam 6 pagi.（私は普段朝6時に起きます。） |
| **cuci muka** | 顔を洗う | Jangan lupa cuci muka dengan air dingin.（冷たい水で顔を洗うのを忘れないで。） |
| **sikat gigi** | 歯を磨く | Saya sikat gigi dua kali sehari.（私は1日2回歯を磨きます。） |
| **mandi** | 水浴びをする、シャワーを浴びる | Mandi pagi bikin badan segar.（朝シャワーを浴びると体がシャキッとします。） |
| **pakai baju** | 服を着る | Dia sedang pakai kemeja rapi.（彼はきちんとしたシャツを着ているところです。） |
| **sisir rambut** | 髪をとかす | Tolong sisir rambutmu dulu.（まず髪をとかしてね。） |
| **sarapan** | 朝食を食べる | Pagi ini saya sarapan roti dan telur.（今朝はパンと卵の朝食をとりました。） |
| **berangkat** | 出発する | Jam berapa kamu berangkat ke kantor?（何時にオフィスへ出発しますか？） |

<div class="id-example">
<div class="id-sentence">Setelah bangun tidur, saya langsung mandi air hangat dan sikat gigi.</div>
<div class="id-translation">起床後、私はすぐに温かいシャワーを浴びて歯を磨きます。</div>
</div>

## 2. 移動・交通・外出（Bepergian & Mobilitas）

移動や通勤・通学で使う動詞です。

| 動詞 | 日本語の意味 | 例文 |
| :--- | :--- | :--- |
| **pergi** | 行く | Saya mau pergi ke supermarket.（スーパーに行きたいです。） |
| **datang** | 来る、到着する | Kereta cepat Whoosh datang tepat waktu.（高速鉄道ウーシュは時間通りに来ます。） |
| **jalan / berjalan** | 歩く | Kami jalan kaki ke stasiun terdekat.（私たちは最寄り駅まで歩きます。） |
| **naik** | （乗り物に）乗る、上がる | Dia naik ojek online setiap hari.（彼は毎日バイクタクシーに乗ります。） |
| **turun** | （乗り物から）降りる、下がる | Tolong turunkan saya di depan halte.（バス停の前で降ろしてください。） |
| **menyetir** | （車を）運転する | Ayah sedang menyetir mobil.（父は車を運転しています。） |
| **mampir / singgah** | 立ち寄る、寄り道する | Boleh kita mampir ke kafe sebentar?（ちょっとカフェに寄り道してもいい？） |
| **sampai / tiba** | 到着する | Akhirnya kami sampai di hotel.（ついに私たちはホテルに到着しました。） |
| **pulang** | 帰る | Saya biasanya pulang kerja jam 6 sore.（私は普段夕方6時に退勤・帰宅します。） |
| **masuk** | 入る | Silakan masuk ke dalam ruangan.（どうぞ部屋の中にお入りください。） |
| **keluar** | 出る | Dia baru saja keluar dari kantor.（彼はたった今オフィスを出ました。） |

<div class="id-example">
<div class="id-sentence">Sebelum pulang ke rumah, saya mau mampir dulu ke minimarket untuk beli air mineral.</div>
<div class="id-translation">家に帰る前に、ミネラルウォーターを買うためにミニマーケットへ少し寄り道したいです。</div>
</div>

| :--- | :--- | :--- |

| **tanya / bertanya** | 質問する、尋ねる | Boleh saya tanya sesuatu?（少し質問してもよろしいですか？） |
| **jawab / menjawab** | 答える、返事をする | Tolong jawab pesan WhatsApp saya ya.（私のWAメッセージに返信してくださいね。） |
| **dengar / mendengar** | 聞く、聞こえる | Apakah suara saya terdengar jelas?（私の声がはっきりと聞こえますか？） |
| **lihat / melihat** | 見る | Mari kita lihat pemandangan yang indah ini.（この美しい景色を見ましょう。） |
| **cerita / bercerita** | 語る、話を聞かせる | Dia suka bercerita tentang pengalamannya di Bali.（彼女はバリ島での体験を語るのが好きです。） |
| **telepon / menelepon** | 電話をかける | Nanti malam saya telepon kamu ya.（今夜電話するね。） |
| **kirim / mengirim** | 送る、送信する | Saya sudah kirim dokumen lewat email.（メールで書類を送信しました。） |

| :--- | :--- | :--- |
| **makan** | 食べる | Sudah makan siang belum?（もう昼ごはん食べた？） |

| **masak / memasak** | 料理する | Ibu sedang masak nasi goreng di dapur.（母は台所でナシゴレンを作っています。） |

| :--- | :--- | :--- |
| **kerja / bekerja** | 働く、仕事をする | Saya bekerja di perusahaan otomotif.（私は自動車関連企業で働いています。） |
| **belajar** | 学ぶ、勉強する | Saya sedang rajin belajar bahasa Indonesia.（私は今インドネシア語を熱心に勉強しています。） |
| **baca / membaca** | 読む | Dia suka membaca berita online setiap pagi.（彼は毎朝オンラインニュースを読むのが好きです。） |
| **tulis / menulis** | 書く | Tolong tulis nama dan alamat Anda di sini.（ここにお名前とご住所を書いてください。） |
| **pikir / memikirkan** | 考える、思い巡らす | Saya perlu waktu untuk memikirkannya.（それについて考える時間が必要です。） |
| **ingat** | 覚えている、思い出す | Apakah kamu masih ingat nama guru kita?（私たちの先生の名前をまだ覚えていますか？） |

| 動詞 | 日本語の意味 | 例文 |
| :--- | :--- | :--- |
| **istirahat** | 休む、休憩する | Mari kita istirahat sejenak setelah rapat panjang ini.（長い会議の後、一息休憩しましょう。） |

## 7. 一日の行動スケジュールのまとめ例文

これまでに学んだ動詞を組み合わせると、一日の日記や行動スケジュールを語ることができます。

<div class="id-example">
<div class="id-sentence">Pagi-pagi saya <strong>bangun</strong> jam 6, lalu <strong>mandi</strong> dan <strong>sarapan</strong>. Jam 7 saya <strong>berangkat</strong> kerja <strong>naik</strong> kereta. Di kantor saya <strong>bekerja</strong> sampai sore, <strong>membaca</strong> email, dan <strong>bertemu</strong> klien. Malamnya saya <strong>pulang</strong>, <strong>makan</strong> malam bersama keluarga, lalu <strong>istirahat</strong> dan <strong>tidur</strong>.</div>

## 8. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「（乗り物に）乗る」と「降りる」の反対語のペアは？</summary>
<strong>正解: naik（乗る） / turun（降りる）</strong><br>
解説: 電車、バス、車、バイクなどあらゆる乗り物の乗降に使われる超頻出動詞です。
</details>

<details class="id-quiz">
<summary>Q2. 「少し寄り道する・立ち寄る」を意味する日常動詞は？</summary>
<strong>正解: mampir</strong><br>
解説: 帰宅途中にコンビニやカフェへ立ち寄る際に「Mampir dulu ya（ちょっと寄ってくね）」のように日常的に使われます。
</details>

<details class="id-quiz">
<summary>Q3. 「少々お待ちください」を意味する定番の丁寧フレーズは？</summary>
<strong>正解: Tolong tunggu sebentar ya.</strong><br>
解説: tunggu（待つ）と sebentar（少し・短時間）を組み合わせた日常・ビジネス必須表現です。
</details>
