# 都市・建物・施設・地理・自然環境の単語一覧

街歩きや移動、旅行、地理的な話題で適切な名詞を使うことは、スムーズなコミュニケーションの基本です。

インドネシアは1万7,000以上の島々からなる世界最大の群島国家であり、巨大都市ジャカルタの高層ビル群から熱帯雨林、火山、美しいサンゴ礁の海まで、極めてダイナミックな景観を有しています。

本記事では、都市のインフラや建物施設、地形・地理、自然現象、そして東西南北の方位表現までを整理して解説します。

---

## 1. 都市・道路・交通インフラ（Kota & Infrastruktur）

街中を歩いたり移動したりする際に目にする建造物や施設の名称です。

| 単語 | 日本語の意味 | 用例・補足 |
| :--- | :--- | :--- |
| **kota** | 都市、街 | kota besar（大都市）, ibu kota（首都） |
| **desa / kampung** | 村、集落、下町 | kampung halaman（故郷・実家） |
| **jalan** | 道、通り、道路 | jalan raya（幹線道路・大通り）, nama jalan（通りの名前） |
| **jalan tol** | 高速道路（有料道路） | tarif tol（高速道路料金）, gerbang tol（料金所） |
| **jembatan** | 橋（はし） | jembatan penyeberangan orang / JPO（歩道橋） |
| **gang** | 路地、小道 | gang sempit（狭い路地。車が通れないバイク・歩行者用通路） |
| **trotoar** | 歩道 | berjalan di trotoar（歩道を歩く） |
| **gedung** | ビル、建物 | gedung pencakar langit（超高層ビル） |
| **stasiun** | （鉄道の）駅 | stasiun kereta api（鉄道駅） |
| **halte** | バス停 | halte bus TransJakarta（トランスジャカルタのバス停） |
| **bandara (bandar udara)** | 空港 | bandara internasional（国際空港） |
| **pelabuhan** | 港（みなと） | pelabuhan kapal laut（旅客船の港） |

<div class="id-example">
<div class="id-sentence">Untuk menghindari kemacetan parah di jalan raya, sopir memilih lewat jalan tol.</div>
<div class="id-translation">大通りの激しい渋滞を避けるため、運転手は高速道路を通ることを選びました。</div>
<div class="id-explanation">menghindari（避ける） / kemacetan（渋滞） / lewat（〜を通る）。</div>
</div>

## 2. 商業施設・公共機関（Fasilitas Umum & Komersial）

生活や観光で立ち寄る施設・機関の名前です。

| 単語 | 日本語の意味 | 用例・補足 |
| :--- | :--- | :--- |
| **pusat perbelanjaan / mal** | ショッピングモール | mal mewah（高級モール）。会話では「mal」が定番。 |
| **pasar** | 市場（いちば） | pasar tradisional（伝統市場）, pasar malam（夜市） |
| **swalayan / supermarket** | スーパーマーケット | belanja di swalayan（スーパーで買い物する） |
| **toko** | 店、商店 | toko kelontong（日用品雑貨店）, toko buku（書店） |
| **rumah sakit (RS)** | 病院 | ruang gawat darurat / IGD（救急外来） |
| **klinik / puskesmas** | クリニック / 地域保健所 | puskesmas（Pusat Kesehatan Masyarakat: 公立保健センター） |
| **kantor pos** | 郵便局 | kirim paket lewat kantor pos（郵便局で小包を送る） |
| **kantor polisi** | 警察署 | lapor ke kantor polisi（警察署に届ける） |
| **kantor imigrasi** | 出入国管理局（イミグレ） | perpanjang visa di imigrasi（ビザ更新手続き） |
| **kedutaan besar (Kedubes)** | 大使館 | Kedubes Jepang di Jakarta（ジャカルタの日本国大使館） |
| **taman** | 公園、庭 | taman kota（都市公園） |
| **bioskop** | 映画館 | nonton film di bioskop（映画館で映画を観る） |

<div class="id-example">
<div class="id-sentence">Kantor pos dan kantor polisi terletak tepat di seberang pusat perbelanjaan ini.</div>
<div class="id-translation">郵便局と警察署は、ちょうどこのショッピングモールの真向かいに位置しています。</div>
<div class="id-explanation">terletak（位置している） / tepat di seberang（ちょうど真向かいに）。</div>
</div>

## 3. 地理・地形・水域（Geografi & Bentang Alam）

自然環境や地形を表す単語です。

| 単語 | 日本語の意味 | 代表例・補足 |
| :--- | :--- | :--- |
| **pulau** | 島（しま） | kepulauan（群島・列島）, Pulau Jawa（ジャワ島）, Pulau Bali（バリ島） |
| **pantai** | 海岸、ビーチ | pantai pasir putih（白砂のビーチ） |
| **laut** | 海（うみ） | laut dalam（深い海）, tepi laut（海辺） |
| **samudra** | 大洋、海洋 | Samudra Hindia（インド洋）, Samudra Pasifik（太平洋） |
| **gunung** | 山（やま） | gunung berapi（活火山）。インドネシアには130以上の活火山がある。 |
| **bukit** | 丘（おか） | perbukitan（丘陵地帯） |
| **sungai** | 川（かわ） | Sungai Musi（スマトラのムシ川） |
| **danau** | 湖（みずうみ） | Danau Toba（スマトラのトバ湖。世界最大のカルデラ湖） |
| **lembah** | 谷、盆地 | lembah hijau（緑の渓谷） |
| **hutan** | 森、森林 | hutan hujan tropis（熱帯雨林） |
| **sawah** | 水田、田んぼ | sawah bertingkat（棚田・ライステラス） |
| **air terjun** | 滝（たき） | air terjun yang indah（美しい滝） |

<div class="id-example">
<div class="id-sentence">Danau Toba di Pulau Sumatra adalah danau vulkanik terbesar di Asia Tenggara dan dikelilingi oleh pegunungan yang asri.</div>
<div class="id-translation">スマトラ島のトバ湖は東南アジア最大の火山湖であり、緑豊かな美しい山々に囲まれています。</div>
<div class="id-explanation">vulkanik（火山の） / dikelilingi oleh（〜に囲まれている） / asri（緑美しく清々しい）。</div>
</div>

## 4. 方位・方角（Arah Mata Angin）

インドネシアの地名（Jawa Barat, Jakarta Selatan等）の理解にも直結する東西南北の方位です。

| 方位（インドネシア語） | 日本語 | 地名での実例 |
| :--- | :--- | :--- |
| **Utara** | 北（きた） | Jakarta Utara（北ジャカルタ）, Sumatra Utara（北スマトラ州） |
| **Selatan** | 南（みなみ） | Jakarta Selatan（南ジャカルタ）, Sulawesi Selatan（南スラウェシ州） |
| **Timur** | 東（ひがし） | Jawa Timur（東ジャワ州）, Nusa Tenggara Timur（東ヌサトゥンガラ州） |
| **Barat** | 西（にし） | Jawa Barat（西ジャワ州）, Papua Barat（西パプア州） |
| **Tenggara** | 南東（なんとう） | Asia Tenggara（東南アジア）, Nusa Tenggara（小スンダ列島） |
| **Barat Daya** | 南西（なんせい） | barat daya |
| **Barat Laut** | 北西（ほくせい） | barat laut |
| **Timur Laut** | 北東（ほくとう） | timur laut |
| **Tengah** | 中央、真ん中 | Jawa Tengah（中部ジャワ州）, Kalimantan Tengah（中部カリマンタン州） |

<div class="id-example">
<div class="id-sentence">Kota Bandung terletak di Provinsi Jawa Barat, sekitar 150 kilometer di sebelah tenggara Jakarta.</div>
<div class="id-translation">バンドン市は西ジャワ州に位置し、ジャカルタの南東約150キロメートルにあります。</div>
<div class="id-explanation">provinsi（州） / di sebelah tenggara（南東の方向に）。</div>
</div>

## 5. 天体・自然の要素（Benda Langit & Elemen Alam）

空や自然の根源的要素です。

- **matahari**: 太陽（matahari terbit: 日の出 / matahari terbenam: 日没）
- **bulan**: 月（bulan purnama: 満月 / bulan sabit: 三日月）
- **bintang**: 星（bintang jatuh: 流れ星）
- **langit**: 空（langit biru: 青空）
- **awan**: 雲（berawan: 曇りがちの）
- **tanah**: 土、土地、地面（tanah air: 祖国・国土）
- **batu**: 石、岩（batu karang: サンゴ礁）
- **api**: 火（kebakaran: 火事）
- **udara**: 空気（udara segar: 新鮮な空気）

## 6. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. インドネシア語の東西南北（Utara, Selatan, Timur, Barat）で、「Timur」が意味する方角は？</summary>
<strong>正解: 東（ひがし）</strong><br>
解説: Timor Leste（東ティモール）の Timor も同じ語根です。なお、Utara=北、Selatan=南、Barat=西 です。
</details>

<details class="id-quiz">
<summary>Q2. 東南アジア最大のカルデラ湖で、世界遺産にも登録されているスマトラ島の名所は？</summary>
<strong>正解: Danau Toba（トバ湖）</strong><br>
解説: Danau は「湖」を意味します。カルデラの中央にはサモシール島（Pulau Samosir）が浮かんでいます。
</details>

<details class="id-quiz">
<summary>Q3. インドネシアの歩道橋を表す略称「JPO」は何の略？</summary>
<strong>正解: Jembatan Penyeberangan Orang</strong><br>
解説: jembatan（橋）＋ penyeberangan（横断・渡ること）＋ orang（人）で「歩行者用横断歩道橋」を指します。
</details>
