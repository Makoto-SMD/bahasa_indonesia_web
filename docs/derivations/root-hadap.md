# 語根 hadap の全派生語図鑑（**menghadapi**, **menghadap**, **terhadap**, **berhadapan**）

インドネシア語の重要語根 **hadap（向く、直面する）** は、空間的方向から困難への対峙、法律関係の対象を形成する語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
