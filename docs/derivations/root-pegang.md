# 語根 pegang の全派生語図鑑（**memegang**, **berpegang**, **pegangan**, **pemegang**）

インドネシア語の重要語根 **pegang（握る、保持する）** は、手で掴む動作から職務の担当、理念の堅持を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
