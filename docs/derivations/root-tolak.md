# 語根 tolak の全派生語図鑑（**menolak**, **penolakan**, **tertolak**, **bertolak**, **bertolak belakang**）

インドネシア語の重要語根 **tolak（拒否する、退ける）** は、提案の拒絶から出発点、押し返す動作までを表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

語根 **tolak**（意味: 拒否する、退ける）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menolak** | 他動詞 | 拒否する、断る、却下する |
| **penolakan** | 名詞 | 拒絶、却下、否認 |
| **tertolak** | 受動 | 却下された、断られた |
| **bertolak** | 自動詞 | 出発する、〜を出発点とする |
