# 語根 panjang の全派生語図鑑（**memperpanjang**, **perpanjangan**, **berkepanjangan**, **sepanjang**）

インドネシア語の重要語根 **panjang（延長する、長い）** は、物理的長さからビザや契約の更新・期間延長を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
