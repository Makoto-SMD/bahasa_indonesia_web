# 語根 lihat の全派生語図鑑（melihat, terlihat, penglihatan, memperlihatkan, kelihatan）

「目で見る、眺める」という視覚から、「〜のように見える」「見せびらかす」「視力・見解」まで派生する基本語根 **lihat** のネットワークです。

---

## 1. 語根 lihat からの派生語ファミリー

語根 **lihat**（意味: 見る、視覚）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **melihat** | 他動詞 | 見る、眺める、目撃する |
| **terlihat** | 可能/状態 | 目に入る、見える、〜のように見受けられる |
| **kelihatan** | 口語状態動詞 | 見える、〜そうに見える |
| **memperlihatkan** | 使役他動詞 | 見せる、示す、提示する |
| **penglihatan** | 名詞 | 視力、視覚、視座、視野 |
| **penglihatan jauh** | 派生語 | 遠視 |

---

## 2. 各派生語の詳細解説と例文

### ① terlihat vs kelihatan（見える、〜のようだ）
- **terlihat**: やや改まった文語（Terlihat jelas bahwa...＝...ということが明確に見受けられる）。
- **kelihatan**: 口語・日常会話（Kelihatan lelah ya＝疲れてそうに見えるね）。
<div class="id-example">
<div class="id-sentence">Dari kejauhan, puncak Gunung Merapi terlihat sangat megah dengan asap putih yang mengepul tipis.</div>
<div class="id-translation">遠くから、ムラピ山の山頂は薄く立ち上る白煙とともに極めて荘厳に見受けられます（terlihat）。</div>
<div class="id-explanation">terlihat megah（荘厳に見える） / mengepul（立ち上る）。</div>
</div>

### ② memperlihatkan（他動詞: 見せる、提示する、誇示する）
<div class="id-example">
<div class="id-sentence">Peserta pameran memperlihatkan prototipe mobil listrik pintar kepada para investor potensial.</div>
<div class="id-translation">展示会の参加者は、有力な投資家たちに向けてスマート電気自動車のプロトタイプを提示しました（見せました）。</div>
<div class="id-explanation">memperlihatkan prototipe（試作機を提示する・見せる）。</div>
</div>

### ③ penglihatan（名詞: 視力、視覚）
<div class="id-example">
<div class="id-sentence">Dokter mata menyarankan kacamata khusus karena daya penglihatan pasien mulai menurun akibat usia.</div>
<div class="id-translation">眼科医は、年齢に伴い患者の視力が低下し始めているため、専用の眼鏡を勧めました。</div>
<div class="id-explanation">dokter mata（眼科医） / daya penglihatan（視力）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「（他人に）見せる、提示する」を表す使役他動詞は？</summary>
<strong>正解: memperlihatkan</strong><br>
解説: 接頭辞 per- と接尾辞 -kan がつき「見えるようにさせる＝見せる」となります。
</details>

<details class="id-quiz">
<summary>Q2. 友人に「今日元気そうに見えるね！」と口語で声をかける際の単語は？</summary>
<strong>正解: Kelihatan segar ya!</strong><br>
解説: kelihatan は「〜そうに見える」を表す日常会話の最頻出語です。
</details>
