# 語根 sebar の全派生語図鑑（**menyebar**, **menyebarkan**, **tersebar**, **penyebaran**, **persebaran**）

インドネシア語の重要語根 **sebar（広める、散布する）** は、情報の拡散から病気の流行、製品の流通網まで広がりを表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
