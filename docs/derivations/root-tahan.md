# 語根 tahan の全派生語図鑑（bertahan, menahan, tertahan, pertahanan, ketahanan）

「耐久・抑制・防衛・耐える」という強靭さを司る語根 **tahan** の派生語ネットワークです。

---

## 1. 語根 tahan からの派生語ファミリー

```mermaid
graph TD
    T["語根: tahan（耐える、我慢する、長持ちする）"]
    T --> B["bertahan（自動詞: 耐え忍ぶ、持ちこたえる、生き残る）"]
    T --> M["menahan（他動詞: 耐える、抑える、引き留める、拘束する）"]
    T --> TT["tertahan（受動/偶発動詞: 滞る、足止めされる、抑え込まれる）"]
    T --> PT["pertahanan（名詞: 防衛、守備、国防）"]
    T --> KT["ketahanan（名詞: 耐久力、強靭性、レジリエンス）"]
    T --> TH["tahanan（名詞: 勾留者、囚人、拘束状態）"]
```

## 2. 各派生語の詳細解説と例文

### ① bertahan（持ちこたえる） vs menahan（抑える・拘束する）
<div class="id-example">
<div class="id-sentence">Banyak usaha mikro kecil mampu bertahan di tengah krisis ekonomi berkat inovasi produk.</div>
<div class="id-translation">多くの零細中小企業は、製品のイノベーションのおかげで経済危機の中でも持ちこたえることができました。</div>
<div class="id-explanation">mampu bertahan（持ちこたえることができる） / krisis ekonomi（経済危機）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Petugas imigrasi terpaksa menahan paspor penumpang tersebut karena visa kedaluwarsa.</div>
<div class="id-translation">入国審査官は、ビザが失効していたためやむを得ずその乗客のパスポートを差し押さえ（留め置き）ました。</div>
<div class="id-explanation">menahan paspor（パスポートを差し押さえる・留置する） / visa kedaluwarsa（失効したビザ）。</div>
</div>

### ② ketahanan pangan（食料安全保障）
- 国家政策ニュースの頻出キーワードです。
<div class="id-example">
<div class="id-sentence">Pemerintah memprioritaskan program ketahanan pangan nasional guna mengantisipasi krisis pangan global.</div>
<div class="id-translation">政府は、世界的な食料危機を未然に防ぐため、国家食料安全保障プログラムを最優先課題としています。</div>
<div class="id-explanation">ketahanan pangan（食料安全保障・食料自給耐力） / mengantisipasi（見越して対処する）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. ニュースで頻出の「食料安全保障」のインドネシア語は？</summary>
<strong>正解: ketahanan pangan</strong><br>
解説: ketahanan（耐性・安全保障能力）＋ pangan（食料）。
</details>

<details class="id-quiz">
<summary>Q2. 「怒りや涙をぐっとこらえる・抑える」ときの他動詞は？</summary>
<strong>正解: menahan（menahan amarah / menahan tangis）</strong><br>
解説: 感情や物体を内側に抑え留める他動詞は menahan です。
</details>
