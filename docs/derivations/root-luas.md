# 語根 luas の全派生語図鑑（**memperluas**, **perluasan**, **meluas**, **keluasan**）

インドネシア語の重要語根 **luas（拡大する、広大な）** は、面積の広さから事業のスケールアップ、視野の拡大を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
