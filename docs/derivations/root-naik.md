# 語根 naik の全派生語図鑑（**menaikkan**, **kenaikan**, **menaiki**, **naik kelas**）

インドネシア語の重要語根 **naik（上昇する、乗る）** は、乗り物に乗る動作から価格上昇、役職の昇進を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 naik からの派生語ファミリー

語根 **naik**（意味: 上昇する、乗る）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menaikkan** | 使役他動詞 | 上げる、引き上げる、積載する |
| **kenaikan** | 名詞 | 上昇、引き上げ、昇進 |
| **menaiki** | 他動詞 | 〜に乗る、登る |
