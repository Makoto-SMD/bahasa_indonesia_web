# 語根 jaga の全派生語図鑑（menjaga, terjaga, penjaga, penjagaan）

「防護・用心・警備・目覚めている」という警戒と維持の語根 **jaga** の派生語ネットワークです。

---

## 1. 語根 jaga からの派生語ファミリー

語根 **jaga**（意味: 起きている、見張り、用心）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menjaga** | 他動詞 | 守る、維持する、見張る、保つ |
| **terjaga** | 状態動詞 | 守られている／目が覚める、起きている |
| **penjaga** | 名詞 | 警備員、守衛、門番、看病人 |
| **penjagaan** | 名詞 | 警備体制、警戒、見守り |
| **jaga-jaga** | 重複副詞 | 念のため、万一に備えて |

---

## 2. 各派生語の詳細解説と例文

### ① menjaga（守る、保つ、維持する）
- 健康維持（menjaga kesehatan）、秘密保持（menjaga rahasia）など、抽象的な維持・防護にも必須です。
<div class="id-example">
<div class="id-sentence">Kita harus senantiasa menjaga kebersihan lingkungan agar terhindar dari berbagai wabah penyakit.</div>
<div class="id-translation">私たちは、様々な伝染病の流行を避けるために、常に環境の清潔さを維持しなければなりません。</div>
<div class="id-explanation">menjaga kebersihan（清潔さを保つ） / terhindar dari wabah（疫病を免れる）。</div>
</div>

### ② jaga-jaga（念のため、用心のため）
- 口語・会話で極めてよく使われるフレーズです（buat jaga-jaga＝念のために）。
<div class="id-example">
<div class="id-sentence">Bawalah payung di dalam tas untuk jaga-jaga kalau nanti sore turun hujan deras.</div>
<div class="id-translation">今日の夕方に大雨が降った時の用心（念のため）として、カバンの中に傘を入れておきなさい。</div>
<div class="id-explanation">untuk jaga-jaga（念のため、用心として） / hujan deras（豪雨）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「念のために傘を持っていこう」の「念のため」は？</summary>
<strong>正解: untuk jaga-jaga / buat jaga-jaga</strong><br>
解説: 語根 jaga を重複させた口語表現です。
</details>

<details class="id-quiz">
<summary>Q2. 「健康を維持する」の動詞は？</summary>
<strong>正解: menjaga kesehatan</strong><br>
解説: 状態や秩序を維持・保持する動詞 menjaga を使います。
</details>
