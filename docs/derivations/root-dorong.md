# 語根 dorong の全派生語図鑑（**mendorong**, **pendorong**, **dorongan**, **terdorong**）

インドネシア語の重要語根 **dorong（押す、推進する）** は、物理的に押す動作から政策・経済の推進・後押しまで広がる語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
