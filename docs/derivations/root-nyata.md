# 語根 nyata の全派生語図鑑（**menyatakan**, **pernyataan**, **ternyata**, **kenyataan**）

インドネシア語の重要語根 **nyata（明確な、表明する）** は、事実の宣言、声明、現実の具現化を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
