# 語根 kabur の全派生語図鑑（**mengaburkan**, **pengaburan**, **kabur**）

インドネシア語の重要語根 **kabur（曖昧にする、逃亡する）** は、視界のぼやけから意図的な論点ずらし、容疑者の逃亡を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
