# 語根 bina の全派生語図鑑（**membina**, **pembinaan**, **pembina**, **terbina**）

インドネシア語の重要語根 **bina（育成する、構築する）** は、人材育成、国家建設、組織の指導教育を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 bina からの派生語ファミリー

語根 **bina**（意味: 育成する、構築する）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **membina** | 他動詞 | 育成する、指導する、構築する |
| **pembinaan** | 名詞 | 育成、指導、能力開発 |
| **pembina** | 名詞 | 指導員、育成者、顧問 |
| **terbina** | 受動 | 育成された、構築された |
