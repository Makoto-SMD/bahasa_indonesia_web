# 語根 tutup の全派生語図鑑（menutup, tertutup, penutupan, penutup）

buka の対義語であり、「閉める、覆い隠す、閉鎖する、幕を閉じる」という意味を展開する語根 **tutup** の派生語ネットワークです。

---

## 1. 語根 tutup からの派生語ファミリー

語根 **tutup**（意味: 閉まる、閉じる、蓋）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menutup** | 他動詞 | 閉める、覆う、閉鎖する |
| **tertutup** | 状態動詞/形容詞 | 閉まっている、閉鎖的な、非公開の |
| **penutupan** | 名詞 | 閉会式、閉鎖、締め切り |
| **penutup** | 道具/修飾名詞 | 蓋、締めくくり、最後の |
| **ketertutupan** | 名詞 | 閉鎖性、秘密主義 |
| **menutup-nutupi** | 反復他動詞 | 隠蔽する、もみ消す |

---

## 2. 各派生語の詳細解説と例文

### ① menutup（他動詞: 閉める、閉鎖する、赤字を補填する）
<div class="id-example">
<div class="id-sentence">Pemerintah terpaksa menutup sementara akses jalan raya akibat longsor yang menutupi badan jalan.</div>
<div class="id-translation">政府は、車道を覆った土砂崩れのため、幹線道路のアクセスを一時閉鎖せざるを得ませんでした。</div>
<div class="id-explanation">menutup sementara（一時閉鎖する） / menutupi badan jalan（車道を覆い塞ぐ）。</div>
</div>

### ② tertutup（形容詞・状態: 閉鎖的な、秘密の、非公開の）
<div class="id-example">
<div class="id-sentence">Sidang kasus korupsi tingkat tinggi itu digelar secara tertutup untuk menjaga kerahasiaan saksi kunci.</div>
<div class="id-translation">その重大汚職事件の裁判は、重要証人の秘密を守るため非公開で実施されました。</div>
<div class="id-explanation">digelar secara tertutup（非公開で開催される） / saksi kunci（重要証人）。</div>
</div>

### ③ penutupan（名詞: 閉会、閉鎖、決算・締め）
<div class="id-example">
<div class="id-sentence">Acara penutupan festival budaya berlangsung sangat meriah dengan pesta kembang api yang memukau.</div>
<div class="id-translation">文化フェスティバルの閉会式は、息をのむような花火大会とともに極めて華やかに進行しました。</div>
<div class="id-explanation">acara penutupan（閉会イベント） / kembang api（花火）。</div>
</div>

### ④ menutup-nutupi（他動詞: 隠蔽する、ごまかす）
<div class="id-example">
<div class="id-sentence">Pihak manajemen dituduh berusaha menutup-nutupi laporan keuangan palsu dari para pemegang saham.</div>
<div class="id-translation">経営陣は、偽造された財務報告を株主たちから隠蔽しようとしたとして告発されました。</div>
<div class="id-explanation">dituduh（〜として告発される） / menutup-nutupi（隠蔽する） / pemegang saham（株主）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「閉会式」を表すインドネシア語は？</summary>
<strong>正解: Upacara penutupan</strong><br>
解説: penutupan は閉幕、閉会を意味します。
</details>

<details class="id-quiz">
<summary>Q2. 真実や不正を「隠蔽する、もみ消す」を表す反復動詞は？</summary>
<strong>正解: menutup-nutupi</strong><br>
解説: 語根 tutup を重ねることで「何重にも覆い隠す・隠蔽する」という意味になります。
</details>
