# 語根 tingkat の全派生語図鑑（**meningkatkan**, **peningkatan**, **meningkat**, **bertingkat**）

インドネシア語の重要語根 **tingkat（向上させる、段階）** は、建物の階数からスキル向上、進歩のステップを表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
