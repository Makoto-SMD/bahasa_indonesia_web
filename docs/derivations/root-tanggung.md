# 語根 tanggung の全派生語図鑑（**menanggung**, **tanggung jawab**, **bertanggung jawab**, **pertanggungjawaban**, **tanggungan**）

インドネシア語の重要語根 **tanggung（責任を負う、引き受ける）** は、義務や責任、費用の負担、保証を語る上で欠かせない語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
