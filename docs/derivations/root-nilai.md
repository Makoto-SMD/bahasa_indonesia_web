# 語根 nilai の全派生語図鑑（**menilai**, **penilaian**, **bernilai**, **nilai**）

インドネシア語の重要語根 **nilai（評価する、値する）** は、金銭的価値から人事評価、倫理的価値観まで広く扱う語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 nilai からの派生語ファミリー

語根 **nilai**（意味: 評価する、値する）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menilai** | 他動詞 | 評価する、採点する、鑑定する |
| **penilaian** | 名詞 | 評価、査定、アセスメント |
| **bernilai** | 自動詞/形容詞 | 価値がある、貴重な |
| **nilai** | 名詞 | 価値、点数、価格 |
