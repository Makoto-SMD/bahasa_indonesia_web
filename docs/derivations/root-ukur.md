# 語根 ukur の全派生語図鑑（**mengukur**, **pengukuran**, **ukuran**, **terukur**）

インドネシア語の重要語根 **ukur（測定する、測る）** は、寸法・重量の計測から基準、成果の定量的把握を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

## 1. 語根 ukur からの派生語ファミリー

| **pengukuran** | 名詞 | 測定、計測、測量 |
