# 語根 ubah の全派生語図鑑（mengubah, berubah, perubahan, pengubah）

「変化・改定・推移」を表現する変革の語根 **ubah** の派生語ネットワークです。

---

## 1. 語根 ubah からの派生語ファミリー

語根 **ubah**（意味: 変化、改変）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **berubah** | 自動詞 | 変わる、変化する |
| **mengubah** | 他動詞 | 変える、修正する、改訂する |
| **perubahan** | 名詞 | 変化、変動、変革、推移 |
| **pengubah** | 名詞 | 変化をもたらす要因、変革者 |
| **mengubahsuai** | 複合他動詞 | 改造する、適応させる |

---

## 2. 各派生語の詳細解説と例文

### ① berubah（自動詞: 変わる） vs mengubah（他動詞: 〜を変える）
- **Rencana berubah**: 予定が変わる（自発・自然現象）。
- **Manajemen mengubah rencana**: 経営陣が計画を変更する（主体が変える）。
<div class="id-example">
<div class="id-sentence">Cuaca di daerah pegunungan dapat berubah drastis hanya dalam hitungan menit.</div>
<div class="id-translation">山岳地帯の天候は、ほんの数分のうちに劇的に変わることがあります。</div>
<div class="id-explanation">berubah drastis（劇的に変わる） / dalam hitungan menit（数分のうちに）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Perusahaan teknologi ini berhasil mengubah cara hidup jutaan masyarakat modern.</div>
<div class="id-translation">このテック企業は、何百万人もの現代市民の生き方を変えることに成功しました。</div>
<div class="id-explanation">mengubah cara hidup（生き方・ライフスタイルを変える）。</div>
</div>

### ② perubahan（名詞: 変化・気候変動）
- perubahan iklim（気候変動）は環境ニュースの定番語彙です。
<div class="id-example">
<div class="id-sentence">Perubahan iklim global memicu terjadinya gelombang panas dan cuaca tak menentu di berbagai belahan dunia.</div>
<div class="id-translation">地球規模の気候変動は、世界各地で熱波や不安定な天候を引き起こしています。</div>
<div class="id-explanation">perubahan iklim（気候変動） / gelombang panas（熱波）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「時代は変わった」と言う場合、どちらを使う？（zaman sudah berubah / zaman sudah mengubah）</summary>
<strong>正解: zaman sudah berubah</strong><br>
解説: 時代自身が変化する自動詞なので berubah を用います。
</details>

<details class="id-quiz">
<summary>Q2. 「気候変動」のインドネシア語は？</summary>
<strong>正解: perubahan iklim</strong><br>
解説: 語根 ubah に接頭辞 per- と接尾辞 -an がついた名詞 perubahan（変化）＋ iklim（気候）。
</details>
