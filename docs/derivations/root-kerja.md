# 語根 kerja の全派生語図鑑（bekerja, mengerjakan, pekerjaan, pekerja, mempekerjakan）

「労働、作業、任務」という人間の生産活動の全領域をカバーする、社会生活最重要語根 **kerja** の派生語ネットワークです。

---

## 1. 語根 kerja からの派生語ファミリー

語根 **kerja**（意味: 仕事、労働、作用）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **bekerja** | 自動詞 | 働く、勤務する、機能する |
| **mengerjakan** | 他動詞 | 仕上げる、作業を行う、宿題をする |
| **mempekerjakan** | 使役他動詞 | 雇用する、雇い入れる |
| **pekerjaan** | 名詞 | 職業、仕事、職務、案件 |
| **pekerja** | 名詞 | 労働者、従業員、ワーカー |
| **kerja sama** | 複合名詞/動詞 | 協力、提携、協業する |
| **kinerja** | 派生名詞 | 業績、パフォーマンス、実績 |

---

## 2. 各派生語の詳細解説と例文

### ① bekerja（自動詞: 働く） vs mengerjakan（他動詞: 手掛ける、片付ける）
- **bekerja di [場所]**: 〜で働く（自動詞）。
- **mengerjakan [タスク]**: タスクを仕上げる、取り組む（他動詞）。
<div class="id-example">
<div class="id-sentence">Seluruh anggota tim sedang fokus mengerjakan revisi proposal proyek hingga larut malam.</div>
<div class="id-translation">チーム全員が深夜までプロジェクト提案書の修正作業に集中して取り組んでいます。</div>
<div class="id-explanation">mengerjakan revisi（修正作業を行う） / larut malam（夜遅く）。</div>
</div>

### ② mempekerjakan（使役他動詞: 雇用する、雇う）
<div class="id-example">
<div class="id-sentence">Pabrik baru ini berkomitmen mempekerjakan lebih dari seribu tenaga kerja lokal di sekitar wilayah industri.</div>
<div class="id-translation">この新工場は、工業団地周辺の1,000人以上の地元労働者を雇用することを確約しています。</div>
<div class="id-explanation">mempekerjakan tenaga kerja lokal（地元労働者を雇用する）。</div>
</div>

### ③ kinerja（名詞: 業績、パフォーマンス）
- 古ジャワ語の接中辞 -in- が kerja に入って生まれた、ビジネス・経済の超重要単語（kinerja keuangan＝財務業績）。
<div class="id-example">
<div class="id-sentence">Evaluasi kinerja tahunan menunjukkan peningkatan produktivitas yang signifikan di seluruh departemen.</div>
<div class="id-translation">年次業績評価は、全事業部における顕著な生産性の向上を示しています。</div>
<div class="id-explanation">evaluasi kinerja（業績評価・人事評価） / peningkatan produktivitas（生産性向上）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 企業や個人の「業績、パフォーマンス」を意味する派生語は？</summary>
<strong>正解: kinerja</strong><br>
解説: 語根 kerja に接中辞 -in- が挿入された語で、ビジネスの業績・実績を表します。
</details>

<details class="id-quiz">
<summary>Q2. 「宿題をする」と言う場合、「( bekerja / mengerjakan ) PR」のどちらが適切？</summary>
<strong>正解: mengerjakan PR</strong><br>
解説: PR（Pekerjaan Rumah＝宿題）という目的語を取る他動詞なので mengerjakan が正解です。
</details>
