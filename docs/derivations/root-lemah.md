# 語根 lemah の全派生語図鑑（**melemahkan**, **kelemahan**, **melemah**, **pelemahan**）

インドネシア語の重要語根 **lemah（弱める、衰退）** は、身体の衰弱から通貨安、論理の弱点を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 lemah からの派生語ファミリー

語根 **lemah**（意味: 弱める、衰退）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **melemahkan** | 使役他動詞 | 弱める、骨抜きにする |
| **kelemahan** | 名詞 | 弱点、短所、脆さ |
| **melemah** | 自動詞 | 弱まる、（相場が）下落する |
