# 語根 tuntut の全派生語図鑑（**menuntut**, **tuntutan**, **penuntut**, **tertuntut**）

インドネシア語の重要語根 **tuntut（要求する、訴求する）** は、権利の要求、学問の探求、法廷での起訴まで厳格な意志を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 tuntut からの派生語ファミリー

語根 **tuntut**（意味: 要求する、訴求する）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menuntut** | 他動詞 | 要求する、起訴する、探求する |
| **tuntutan** | 名詞 | 要求、請求、訴因 |
| **penuntut** | 名詞 | 原告、検察官（penuntut umum） |
| **tertuntut** | 受動 | 要求された、義務付けられた |
