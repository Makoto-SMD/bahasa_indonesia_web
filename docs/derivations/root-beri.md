# 語根 beri の全派生語図鑑（memberi, memberikan, pemberian, pemberi, memberitakan）

「与える、授ける、提供する、情報をもたらす」という授受と報道の核となる語根 **beri** の派生語ネットワークです。

---

## 1. 語根 beri からの派生語ファミリー

語根 **beri**（意味: 与える、あげる）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **memberi** | 他動詞 | 与える、あげる、寄付する |
| **memberikan** | 使役/受益他動詞 | 提出する、手渡す、授与する |
| **pemberian** | 名詞 | 贈り物、付与、寄贈品、授与 |
| **pemberi** | 名詞 | 与える人、提供者、ドナー |
| **memberitakan** | 他動詞 | 報道する、ニュースとして報じる |
| **berita** | 派生名詞 | ニュース、報道、便り |
| **pemberitaan** | 名詞 | 報道活動、ニュース報道 |

---

## 2. 各派生語の詳細解説と例文

### ① memberi vs memberikan（与える・手渡すの使い分け）
- **memberi**: [受取人]に[物]を与える（二重目的語構文）。
  - *Ibu memberi adik uang.*（母は弟にお金をあげた。）
- **memberikan**: [物]を[受取人]に手渡す（前置詞 kepada を伴う）。
  - *Ibu memberikan uang itu kepada adik.*（母はそのお金を弟に渡した。）
<div class="id-example">
<div class="id-sentence">Pemerintah memberikan bantuan subsidi langsung tunai kepada warga yang terdampak krisis ekonomi.</div>
<div class="id-translation">政府は、経済危機の影響を受けた住民たちに現金直接給付（補助金）を支給しました。</div>
<div class="id-explanation">memberikan bantuan kepada（〜に支援を与える） / terdampak（影響を受けた）。</div>
</div>

### ② berita / memberitakan / pemberitaan（ニュース・報道）
- 語根 beri から派生して「他者に知らしめるもの＝ニュース」となった重要な広がりです。
<div class="id-example">
<div class="id-sentence">Media massa nasional secara luas memberitakan keberhasilan peluncuran satelit komunikasi terbaru Indonesia.</div>
<div class="id-translation">全国の大手メディアは、インドネシアの最新通信衛星の打ち上げ成功を大々的に報道しました。</div>
<div class="id-explanation">media massa（マスメディア） / memberitakan（報道する） / peluncuran satelit（衛星打ち上げ）。</div>
</div>

### ③ pemberian（名詞: 贈り物、施し、付与）
<div class="id-example">
<div class="id-sentence">Jam tangan mewah ini adalah pemberian istimewa dari kakek saat saya lulus universitas.</div>
<div class="id-translation">この高級腕時計は、私が大学を卒業した際に祖父から贈られた特別なプレゼント（いただき物）です。</div>
<div class="id-explanation">pemberian istimewa（特別な贈り物）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「メディアがニュースを報道する」を表す他動詞は？</summary>
<strong>正解: memberitakan</strong><br>
解説: 語根 beri から生まれた berita（ニュース）に接頭辞 meN- と接尾辞 -kan がつき「ニュースとして報じる」となります。
</details>

<details class="id-quiz">
<summary>Q2. 「memberikan」を用いる際、受け取る人（対象）の直前に置く前置詞は？</summary>
<strong>正解: kepada（〜に対して）</strong><br>
解説: memberikan [物] kepada [人] という語順が文法規則です。
</details>
