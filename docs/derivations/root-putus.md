# 語根 putus の全派生語図鑑（memutuskan, terputus, keputusan, pemutusan）

「切断・決定・中絶・決断」を司る二大意味（物が切れる / 意思決定する）を持つ語根 **putus** の派生語ネットワークです。

---

## 1. 語根 putus からの派生語ファミリー

語根 **putus**（意味: 切れた、途絶えた、決定した）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **memutuskan** | 他動詞 | 決める、決断する、切断する、解約する |
| **terputus** | 受動/状態動詞 | 途切れた、切断された、途絶する |
| **keputusan** | 名詞 | 決定、決議、判定、判決 |
| **pemutusan** | 名詞 | 解除、解雇、切断手続き |
| **putus asa** | 慣用句 | 絶望する、諦める |

---

## 2. 各派生語の詳細解説と例文

### ① memutuskan（決定する） vs keputusan（決定・決断）
- インドネシア語では「思い切って決める（英語のdecide）」を「切る（putus）」から派生させます。
<div class="id-example">
<div class="id-sentence">Dewan direksi akhirnya memutuskan untuk menunda ekspansi bisnis ke luar negeri hingga tahun depan.</div>
<div class="id-translation">取締役会は最終的に、海外への事業拡大を来年まで延期することを決定しました。</div>
<div class="id-explanation">dewan direksi（取締役会） / memutuskan untuk menunda（延期することを決定する）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Keputusan yang bijaksana ini mendapat dukungan penuh dari seluruh pemegang saham.</div>
<div class="id-translation">この賢明な決定は、全株主から全面的な支持を得ました。</div>
<div class="id-explanation">keputusan bijaksana（賢明な決断） / pemegang saham（株主）。</div>
</div>

### ② terputus（途切れる） vs pemutusan hubungan kerja（PHK: 解雇）
- ビジネスニュース頻出の **PHK** は **P**emutusan **H**ubungan **K**erja（雇用関係の解除＝解雇）の略です。
<div class="id-example">
<div class="id-sentence">Aliran listrik di kawasan industri sempat terputus selama dua jam akibat sambaran petir.</div>
<div class="id-translation">工業団地の送電網は、落雷の影響により2時間にわたって一時途絶（停電）しました。</div>
<div class="id-explanation">aliran listrik（電流・電力供給） / terputus（途切れる）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. ニュースで頻出する「解雇（リストラ）」の略語 PHK の「P」は何の略？</summary>
<strong>正解: Pemutusan（Pemutusan Hubungan Kerja）</strong><br>
解説: 関係（hubungan）を断ち切る（putus）こと＝雇用終了・解雇です。
</details>

<details class="id-quiz">
<summary>Q2. 「重大な決定」の「決定」にあたる名詞は？</summary>
<strong>正解: keputusan</strong><br>
解説: 接頭辞 ke- と接尾辞 -an で「決定、判決」を意味します。
</details>
