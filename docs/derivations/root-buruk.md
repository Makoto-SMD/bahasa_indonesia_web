# 語根 buruk の全派生語図鑑（**memburuk**, **memperburuk**, **keburukan**, **perburukan**）

インドネシア語の重要語根 **buruk（悪化する、悪い）** は、品質の悪さから治安・病状・景気の悪化を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
