# 語根 lupa の全派生語図鑑（**melupakan**, **kelupaan**, **terlupakan**, **pelupa**）

インドネシア語の重要語根 **lupa（忘れる、忘却）** は、記憶の喪失から約束のうっかり失念、恩知らずを表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 lupa からの派生語ファミリー

語根 **lupa**（意味: 忘れる、忘却）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **melupakan** | 他動詞 | 忘れる、水に流す、度外視する |
| **kelupaan** | 口語名詞/自発 | うっかり忘れる、失念 |
| **terlupakan** | 受動・可能 | 忘れ去られた、見落とされた |
| **pelupa** | 名詞/形容詞 | 忘れっぽい人、健忘 |
