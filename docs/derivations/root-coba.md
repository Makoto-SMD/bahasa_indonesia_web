# 語根 coba の全派生語図鑑（**mencoba**, **percobaan**, **cobaan**, **mencobai**）

インドネシア語の重要語根 **coba（試す、試みる）** は、試行錯誤や挑戦、そして人生の試練を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
