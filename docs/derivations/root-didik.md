# 語根 didik の全派生語図鑑（mendidik, pendidik, pendidikan）

「教育・育成・しつけ・学問」を司る文教の国家最重要語根 **didik** の派生語ネットワークです。

---

## 1. 語根 didik からの派生語ファミリー

語根 **didik**（意味: 教え育てる、しつける）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mendidik** | 他動詞 | 教育する、育てる、教え導く |
| **pendidik** | 名詞 | 教育者、教員、講師 |
| **pendidikan** | 名詞 | 教育、学歴、教育機関 |
| **peserta didik** | 名詞 | 学習者、生徒、学生 |

---

## 2. 各派生語の詳細解説と例文

### ① pendidikan（名詞: 教育、学歴）
- **Kementerian Pendidikan, Kebudayaan, Riset, dan Teknologi (Kemendikbudristek)**: 教育文化研究技術省。
<div class="id-example">
<div class="id-sentence">Pemerintah mengalokasikan dua puluh persen dari APBN untuk sektor pendidikan nasional.</div>
<div class="id-translation">政府は国家予算法（APBN）の20パーセントを国家教育分野に割り当てています。</div>
<div class="id-explanation">mengalokasikan（割り当てる） / APBN（国家歳入歳出予算） / sektor pendidikan（教育分野）。</div>
</div>

### ② mendidik（教育する、育てる）
<div class="id-example">
<div class="id-sentence">Orang tua memiliki peran utama dalam mendidik karakter moral dan etika anak-anak sejak usia dini.</div>
<div class="id-translation">親は幼少期から子どもたちの道徳的品格と倫理観を育てる（教育する）上で、主要な役割を担っています。</div>
<div class="id-explanation">peran utama（主要な役割） / mendidik karakter（人格を育成する） / usia dini（幼少期）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 履歴書の「学歴」欄に書かれる単語は？</summary>
<strong>正解: Riwayat Pendidikan / Pendidikan Terakhir</strong><br>
解説: pendidikan（教育・学歴）を用います。
</details>

<details class="id-quiz">
<summary>Q2. 教員や指導者を公的に指す「教育者」は？</summary>
<strong>正解: pendidik（tenaga pendidik）</strong><br>
解説: 語根 didik に接頭辞 peng- が鼻音化して pendidik となります。
</details>
