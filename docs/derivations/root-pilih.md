# 語根 pilih の全派生語図鑑（**memilih**, **pilihan**, **pemilihan**, **terpilih**）

インドネシア語の重要語根 **pilih（選ぶ、選択する）** は、購買の選択、意思決定、国政選挙を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 pilih からの派生語ファミリー

語根 **pilih**（意味: 選ぶ、選択する）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **memilih** | 他動詞 | 選ぶ、選択する、投票する |
| **pilihan** | 名詞/形容詞 | 選択肢、チョイス、特選の |

| **terpilih** | 受動 | 選ばれた、当選した |
