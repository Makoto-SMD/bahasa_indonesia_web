# 語根 tawar の全派生語図鑑（menawar, menawarkan, tawaran, penawaran）

「値引き交渉・オファー・提供・味がない」という商業交渉の根幹語根 **tawar** の派生語ネットワークです。

---

## 1. 語根 tawar からの派生語ファミリー

語根 **tawar**（意味: 値切る、差し出す、淡白な・味が薄い）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menawar** | 他動詞 | 値切る、買い値を提示する |
| **menawarkan** | 他動詞 | 提案する、オファーする、売り込む |
| **tawaran** | 名詞 | オファー、提示条件、提案 |
| **penawaran** | 名詞 | 供給、見積もり、価格提示、入札 |
| **air tawar** | 名詞句 | 淡水、真水 |
| **tawar-menawar** | 名詞/動詞 | 値段交渉、駆け引き |

---

## 2. 各派生語の詳細解説と例文

### ① menawar（値切る） vs menawarkan（提案・オファーする）
- 方向性が逆になる超重要ペアです。
- **menawar**: 買い手が「安くして」と値を叩く。
- **menawarkan**: 売り手や提案者が「これをどうぞ」とオファーする。
<div class="id-example">
<div class="id-sentence">Wisatawan dapat menawar harga suvenir khas di pasar seni hingga memperoleh diskon menarik.</div>
<div class="id-translation">観光客はアートマーケットで、魅力的な割引を得られるまで特産お土産の値段を値切ることができます。</div>
<div class="id-explanation">menawar harga（値段を値切る） / pasar seni（アートマーケット）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Perusahaan mitra menawarkan paket kerja sama bisnis yang sangat menguntungkan kedua belah pihak.</div>
<div class="id-translation">提携先企業は、双方にとって非常に有益なビジネス協力パッケージを提案（オファー）してきました。</div>
<div class="id-explanation">menawarkan paket kerja sama（提携パッケージを提案する） / kedua belah pihak（双方）。</div>
</div>

### ② penawaran harga（見積書） vs tawar-menawar（駆け引き）
<div class="id-example">
<div class="id-sentence">Pihak vendor telah mengirimkan surat penawaran harga resmi untuk pengadaan suku cadang mesin.</div>
<div class="id-translation">ベンダー側は、機械予備部品の調達に関する公式見積書（価格提案書）を送付しました。</div>
<div class="id-explanation">surat penawaran harga（見積書、オファーレター） / pengadaan suku cadang（スペアパーツ調達）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. ビジネスの「見積書（Quotation）」をインドネシア語で言うと？</summary>
<strong>正解: surat penawaran harga</strong><br>
解説: 価格（harga）の提示（penawaran）＋書面（surat）。
</details>

<details class="id-quiz">
<summary>Q2. 市場で「値段をまけてもらう、値切る」の動詞は？</summary>
<strong>正解: menawar harga</strong><br>
解説: 買い手が値を叩く行為は menawar です（相手にオファーするのは menawarkan）。
</details>
