# 語根 ambil の全派生語図鑑（mengambil, terambil, pengambilan, pengambilalihan）

物理的な「物を取る」から、意思決定の「決断を下す」、企業の「買収・接収」まで多角的に派生する重要語根 **ambil** のネットワークです。

---

## 1. 語根 ambil からの派生語ファミリー

語根 **ambil**（意味: 取る、受け取る）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mengambil** | 他動詞 | 取る、手に取る、引き出す、受講する |
| **terambil** | 無意図/受動 | うっかり取られた、取れてしまった |
| **pengambilan** | 名詞 | 取得、引き出し、決定 |
| **mengambilkan** | 受益他動詞 | 〜のために取ってあげる |
| **pengambilalihan** | 複合名詞 | 買収、乗っ取り、接収、引き継ぎ |
| **mengambil bagian** | 熟語 | 参加する、役割を担う |

---

## 2. 各派生語の詳細解説と例文

### ① mengambil（他動詞: 取る、下す、取得する）
- **意思決定**: *mengambil keputusan*（決断を下す）。
- **休暇取得**: *mengambil cuti*（有給休暇を取る）。
- **預金引き出し**: *mengambil uang di ATM*（ATMでお金を引き出す）。
<div class="id-example">
<div class="id-sentence">Direksi harus segera mengambil keputusan tegas terkait kelanjutan investasi di pabrik baru.</div>
<div class="id-translation">役員会は、新工場での投資継続に関して直ちに断固たる決断を下さなければなりません。</div>
<div class="id-explanation">mengambil keputusan tegas（断固たる決断を下す）。</div>
</div>

### ② pengambilan keputusan（名詞句: 意思決定）
<div class="id-example">
<div class="id-sentence">Proses pengambilan keputusan dalam organisasi ini melibatkan masukan dari seluruh pemangku kepentingan.</div>
<div class="id-translation">この組織における意思決定プロセスには、すべてのステークホルダーからの意見・インプットが関与しています。</div>
<div class="id-explanation">pengambilan keputusan（意思決定） / pemangku kepentingan（ステークホルダー・利害関係者）。</div>
</div>

### ③ pengambilalihan（名詞: 買収、M&A、事業承継）
- **構成**: peN- ＋ [ambil ＋ alih（移管・交代）] ＋ -an。
<div class="id-example">
<div class="id-sentence">Berita tentang pengambilalihan perusahaan rintisan lokal oleh raksasa teknologi asing mengejutkan pasar modal.</div>
<div class="id-translation">外国の巨大IT企業による現地のスタートアップ企業の買収に関するニュースは、株式市場を驚かせました。</div>
<div class="id-explanation">pengambilalihan（買収、M&A） / perusahaan rintisan（スタートアップ企業）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. ビジネスで「決断を下す、決定する」を表す最頻出のコロケーションは？</summary>
<strong>正解: mengambil keputusan</strong><br>
解説: mengambil（取る）＋ keputusan（決定）で「決断を下す」となります。
</details>

<details class="id-quiz">
<summary>Q2. 企業の「買収、M&A」を表す高度な派生語は？</summary>
<strong>正解: pengambilalihan</strong><br>
解説: ambil（取る）と alih（移す・替わる）が複合し、周囲辞 peN-...-an がついて「買収・接収」となります。
</details>
