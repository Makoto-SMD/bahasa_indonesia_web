# 語根 mati の全派生語図鑑（**mematikan**, **kematian**, **mati rasa**, **pematian**）

インドネシア語の重要語根 **mati（停止する、死亡）** は、生命の死から電気・機械のスイッチ停止、麻痺を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 mati からの派生語ファミリー

語根 **mati**（意味: 停止する、死亡）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mematikan** | 使役他動詞 | 消す、電源を切る、殺傷する |
| **kematian** | 名詞 | 死亡、死期、致死 |
| **mati rasa** | 熟語 | 無感覚になる、麻痺する |
| **pematian** | 名詞 | シャットダウン、消去 |
