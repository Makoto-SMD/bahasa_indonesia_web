# 語根 tarik の全派生語図鑑（**menarik**, **tertarik**, **ketertarikan**, **penarikan**）

インドネシア語の重要語根 **tarik（引く、引きつける）** は、物理的な牽引から預金の引き出し、関心や魅力の喚起までを表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
