# 語根 dengar の全派生語図鑑（mendengar, terdengar, pendengaran, mendengarkan）

「耳に入る」「注意深く聴く」「噂を耳にする」「聴力」へと派生する聴覚の語根 **dengar** のネットワークです。

---

## 1. 語根 dengar からの派生語ファミリー

語根 **dengar**（意味: 聞く、聞こえる）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mendengar** | 他動詞 | 聞く、耳にする、噂を聞く |
| **mendengarkan** | 傾聴動詞 | 注意深く聴く、耳を傾ける、従う |
| **terdengar** | 自然発生/自発 | 聞こえる、耳に届く、〜と聞こえる |
| **pendengaran** | 名詞 | 聴覚、聴力 |
| **pendengar** | 名詞 | リスナー、聴取者、聞き手 |
| **kedengaran** | 口語自発動詞 | 聞こえる |

---

## 2. 各派生語の詳細解説と例文

### ① mendengar（聞く） vs mendengarkan（聴く）の絶対原則
- **mendengar**: 英語の hear（音が自然と耳に入ってくる、情報として聞く）。
- **mendengarkan**: 英語の listen to（意識して耳を傾ける、音楽を聴く、先生の言うことをよく聞く）。
<div class="id-example">
<div class="id-sentence">Siswa-siswi diminta duduk dengan tenang dan mendengarkan penjelasan guru secara saksama.</div>
<div class="id-translation">生徒たちは静かに着席し、先生の説明に注意深く耳を傾ける（聴く）よう求められました。</div>
<div class="id-explanation">mendengarkan（傾聴する） / secara saksama（注意深く、綿密に）。</div>
</div>

### ② terdengar（聞こえる、耳に届く）
<div class="id-example">
<div class="id-sentence">Dari kejauhan terdengar suara deburan ombak pantai yang menenangkan jiwa.</div>
<div class="id-translation">遠くから、心を落ち着かせる海岸の波の砕ける音が聞こえてきました（terdengar）。</div>
<div class="id-explanation">terdengar suara（音が聞こえる） / deburan ombak（波の砕ける音）。</div>
</div>

### ③ pendengar setia（名詞句: 熱心なリスナー・愛聴者）
<div class="id-example">
<div class="id-sentence">Radio komunitas ini memiliki jutaan pendengar setia yang selalu menantikan siaran berita sore.</div>
<div class="id-translation">このコミュニティラジオ局には、夕方のニュース放送をいつも楽しみにしている何百万人もの熱心なリスナー（pendengar setia）がいます。</div>
<div class="id-explanation">pendengar setia（熱心なリスナー） / siaran berita（ニュース放送）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「音楽を聴く」と言う場合、「( mendengar / mendengarkan ) musik」のどちらが文法的に正確？</summary>
<strong>正解: mendengarkan musik</strong><br>
解説: 意図を持って意識的に聴く動作には、接尾辞 -kan を伴う「mendengarkan」を用います。
</details>

<details class="id-quiz">
<summary>Q2. 「かすかに音が聞こえてくる」を表す自発動詞は？</summary>
<strong>正解: terdengar（口語では kedengaran）</strong><br>
解説: 接頭辞 ter- が自然発生を表し「耳に入ってくる、聞こえる」となります。
</details>
