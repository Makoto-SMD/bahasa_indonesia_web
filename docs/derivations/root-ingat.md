# 語根 ingat の全派生語図鑑（mengingat, mengingatkan, teringat, peringatan, ingatan）

「記憶・想起・警告」を網羅する認知系超重要語根 **ingat**（覚えている）の派生語ネットワークです。

---

## 1. 語根 ingat からの派生語ファミリー

語根 **ingat**（意味: 覚えている、記憶）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mengingat** | 他動詞 | 記憶している／前置詞的: 〜を考慮すると |
| **mengingatkan** | 使役他動詞 | 思い出させる、注意・警告する |
| **teringat** | 偶発動詞 | ふと思い出される、脳裏をよぎる |
| **peringatan** | 名詞 | 警告、注意喚起、記念、式典 |
| **ingatan** | 名詞 | 記憶力、思い出、脳裏 |

---

## 2. 各派生語の詳細解説と例文

### ① mengingatkan（他動詞: 思い出させる、注意する）
- 日常・ビジネスともに必須の単語です。
<div class="id-example">
<div class="id-sentence">Tolong ingatkan saya untuk mengirim laporan bulanan sebelum jam lima sore nanti.</div>
<div class="id-translation">今日の午後5時前に月次レポートを送信するよう、私にリマインドしてください（注意を促してください）。</div>
<div class="id-explanation">ingatkan saya（私にリマインドして） / laporan bulanan（月次報告書）。</div>
</div>

### ② teringat（ふと思い出す） vs ingatan（記憶力）
<div class="id-example">
<div class="id-sentence">Mendengar lagu klasik itu, saya langsung teringat pada masa kecil di kampung halaman.</div>
<div class="id-translation">そのクラシック音楽を聴いて、私はふと故郷での幼少期を思い出しました。</div>
<div class="id-explanation">teringat pada（〜がふと思い出される） / masa kecil（幼少期）。</div>
</div>

### ③ peringatan（名詞: 警告、記念日）
- peringatan bahaya（危険警告）、peringatan hari kemerdekaan（独立記念式典）など多方面で使われます。
<div class="id-example">
<div class="id-sentence">Pemerintah mengeluarkan peringatan dini terkait potensi cuaca ekstrem di pesisir barat.</div>
<div class="id-translation">政府は西海岸における異常気象の可能性に関する早期警報（警戒警報）を発令しました。</div>
<div class="id-explanation">peringatan dini（早期警報） / cuaca ekstrem（異常気象）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「誰かに予定を思い出させる、リマインドする」はどれ？</summary>
<strong>正解: mengingatkan</strong><br>
解説: 接頭辞 me- と使役接尾辞 -kan がつき「思い出させる」という意味になります。
</details>

<details class="id-quiz">
<summary>Q2. 「早期警報（警戒情報）」のインドネシア語は？</summary>
<strong>正解: peringatan dini</strong><br>
解説: peringatan（注意・警告）＋ dini（早期の）。
</details>
