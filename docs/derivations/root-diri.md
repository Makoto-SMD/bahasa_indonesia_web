# 語根 diri の全派生語図鑑（**berdiri**, **mendirikan**, **pendirian**, **terdiri dari**）

インドネシア語の重要語根 **diri（立つ、自己）** は、起立の動作から会社の設立、自己自身を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
