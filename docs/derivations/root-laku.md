# 語根 laku の全派生語図鑑（berlaku, melakukan, perlakuan, pelaku, kelakuan）

「行動・実行・有効・売れ行き」という四大領域（行動・行為・通用・商業）を支配する最強多義語根 **laku** の派生語ネットワークです。

---

## 1. 語根 laku からの派生語ファミリー

語根 **laku**（意味: 売れ行き、有効、振る舞い）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **berlaku** | 自動詞 | 有効である、通用する、〜として振る舞う |
| **melakukan** | 他動詞 | 行う、実行する、仕出かす |
| **pelaku** | 名詞 | 実行者、犯人、アクター、当事者 |
| **perlakuan** | 名詞 | 待遇、扱い、処遇 |
| **kelakuan** | 名詞 | 素行、行儀、行状 |

---

## 2. 各派生語の詳細解説と例文

### ① berlaku（有効である・通用する）
- パスポートや契約書の「有効期限（masa berlaku）」は頻出です。
<div class="id-example">
<div class="id-sentence">Masa berlaku paspor ini masih tersisa lebih dari enam bulan sebelum tanggal kedaluwarsa.</div>
<div class="id-translation">このパスポートの有効期間は、失効日までまだ6ヶ月以上残っています。</div>
<div class="id-explanation">masa berlaku（有効期限・有効期間） / tanggal kedaluwarsa（満了日・失効期日）。</div>
</div>

### ② melakukan（他動詞: 行う、実施する）
<div class="id-example">
<div class="id-sentence">Pemerintah daerah sedang melakukan inspeksi mendadak ke pasar tradisional terkait harga beras.</div>
<div class="id-translation">地方自治体は、米の価格に関して伝統的市場への抜き打ち立ち入り検査を実施しています。</div>
<div class="id-explanation">melakukan inspeksi mendadak（抜き打ち立ち入り検査を行う） / harga beras（米の価格）。</div>
</div>

### ③ pelaku ekonomi（経済主体） vs pelaku kejahatan（犯罪者）
<div class="id-example">
<div class="id-sentence">Para pelaku usaha mikro dan kecil mendapatkan kemudahan perizinan dari pemerintah pusat.</div>
<div class="id-translation">零細・中小ビジネスの事業主（経済主体）たちは、中央政府から営業許可手続きの便宜供与を受けています。</div>
<div class="id-explanation">pelaku usaha（事業者、ビジネスアクター） / kemudahan perizinan（許認可の利便化）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. パスポートや身分証明書の「有効期限」を表す名詞句は？</summary>
<strong>正解: masa berlaku</strong><br>
解説: masa（期間）＋ berlaku（有効である）。
</details>

<details class="id-quiz">
<summary>Q2. 経済記事で「事業者、ビジネス当事者」を表す言葉は？</summary>
<strong>正解: pelaku usaha</strong><br>
解説: 行為者・主体を表す pelaku ＋ usaha（事業）。
</details>
