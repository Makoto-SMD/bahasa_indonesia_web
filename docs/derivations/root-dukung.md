# 語根 dukung の全派生語図鑑（mendukung, pendukung, dukungan）

「支持・支援・後援・サポーター」を司る政治・スポーツ・ビジネス頻出語根 **dukung** の派生語ネットワークです。

---

## 1. 語根 dukung からの派生語ファミリー

語根 **dukung**（意味: 抱きかかえる、支持）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mendukung** | 他動詞 | 支持する、応援する、賛同する、バックアップする |
| **pendukung** | 名詞 | 支持者、サポーター、ファン、補足要因 |
| **dukungan** | 名詞 | 支持、支援、バックアップ、エール |

---

## 2. 各派生語の詳細解説と例文

### ① mendukung（他動詞: 支持する、支援する）
<div class="id-example">
<div class="id-sentence">Mayoritas masyarakat sangat mendukung program pembangunan transportasi massal perkotaan.</div>
<div class="id-translation">市民の大多数は、都市大量高速交通機関（MRT/LRT等）の整備計画を強く支持しています。</div>
<div class="id-explanation">sangat mendukung（強く支持する） / transportasi massal perkotaan（都市大量公共交通）。</div>
</div>

### ② dukungan dana（資金援助） vs pendukung setia（熱狂的サポーター）
<div class="id-example">
<div class="id-sentence">Proyek riset bioteknologi ini berhasil mendapatkan dukungan dana hibah dari lembaga internasional.</div>
<div class="id-translation">このバイオテクノロジー研究プロジェクトは、国際機関から助成金支援を獲得することに成功しました。</div>
<div class="id-explanation">dukungan dana hibah（助成金・資金援助） / lembaga internasional（国際機関）。</div>
</div>

<div class="id-example">
<div class="id-sentence">Ribuan pendukung setia tim nasional sepak bola memadati stadion sejak siang hari.</div>
<div class="id-translation">何千人ものサッカー代表チームの忠実なサポーターたちが、昼からスタジアムを埋め尽くしました。</div>
<div class="id-explanation">pendukung setia（熱烈なサポーター） / memadati stadion（スタジアムを埋め尽くす）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「サッカーのサポーター・ファン」を表す単語は？</summary>
<strong>正解: pendukung（suporter / pendukung）</strong><br>
解説: 接頭辞 peng- がついて「支持する人＝サポーター」を表します。
</details>

<details class="id-quiz">
<summary>Q2. 「皆様のご支援に感謝します」の「支援」は？</summary>
<strong>正解: dukungan（Terima kasih atas dukungan Anda）</strong><br>
解説: 接尾辞 -an を伴う dukungan が「支持、応援、支援」を意味します。
</details>
