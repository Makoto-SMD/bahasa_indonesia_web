# 語根 susun の全派生語図鑑（**menyusun**, **tersusun**, **susunan**, **penyusun**）

インドネシア語の重要語根 **susun（組み立てる、構成する）** は、計画の策定、文章の作成、組織の階層化を意味する語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
