# 語根 rawat の全派生語図鑑（merawat, perawat, perawatan）

「看護・介護・養生・メンテナンス」を司る医療・ケアの根幹語根 **rawat** の派生語ネットワークです。

---

## 1. 語根 rawat からの派生語ファミリー

語根 **rawat**（意味: 世話、看護、手入れ）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **merawat** | 他動詞 | 看護する、手入れする、育てる、養生する |
| **perawat** | 名詞 | 看護師、ナース、介護者 |
| **perawatan** | 名詞 | 治療、スキンケア、メンテナンス、入院加療 |
| **rawat jalan** | 医療用語 | 外来診療、通院治療 |
| **rawat inap** | 医療用語 | 入院治療 |

---

## 2. 各派生語の詳細解説と例文

### ① rawat inap（入院） vs rawat jalan（外来通院）
- 海外旅行保険や病院受付で最も重要な区別です。
<div class="id-example">
<div class="id-sentence">Pasien demam berdarah tersebut memerlukan tindakan rawat inap di rumah sakit selama beberapa hari.</div>
<div class="id-translation">そのデング熱の患者は、病院で数日間の入院治療を受ける必要があります。</div>
<div class="id-explanation">demam berdarah（デング熱） / rawat inap（入院治療）。</div>
</div>

### ② merawat（手入れする、世話する） vs perawatan kulit（スキンケア）
<div class="id-example">
<div class="id-sentence">Merawat mesin mobil secara berkala dapat mencegah terjadinya kerusakan parah di perjalanan.</div>
<div class="id-translation">車のエンジンを定期的にメンテナンス（手入れ）することで、走行中の深刻な故障を防ぐことができます。</div>
<div class="id-explanation">merawat mesin（エンジンを手入れ・整備する） / secara berkala（定期的に）。</div>
</div>

## 3. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 病院での「入院」を意味するインドネシア語は？</summary>
<strong>正解: rawat inap</strong><br>
解説: 泊まる（inap）＋ ケア（rawat）＝入院です。通院・外来は rawat jalan と言います。
</details>

<details class="id-quiz">
<summary>Q2. 病院で患者をケアする「看護師（ナース）」は？</summary>
<strong>正解: perawat</strong><br>
解説: 接頭辞 pe- がついて看護する人＝看護師となります。
</details>
