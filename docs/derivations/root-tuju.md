# 語根 tuju の全派生語図鑑（**menuju**, **bertujuan**, **tujuan**, **setuju**, **persetujuan**）

インドネシア語の重要語根 **tuju（向かう、意図する）** は、物理的な移動の目的地から、人生の目標、合意まで幅広く派生する語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 tuju からの派生語ファミリー

語根 **tuju**（意味: 向かう、意図する）から派生する主要な単語一覧です。

| **menuju** | 他動詞/前置詞 | 〜に向かう、〜を目指す |
| **bertujuan** | 自動詞 | 〜を目的とする、目指している |

| **persetujuan** | 名詞 | 合意、承認、許可 |
