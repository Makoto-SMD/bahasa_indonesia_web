# 語根 hitung の全派生語図鑑（**menghitung**, **perhitungan**, **terhitung**, **berhitung**）

インドネシア語の重要語根 **hitung（計算する、数える）** は、見積もり、会計計算、統計的算定を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 hitung からの派生語ファミリー

語根 **hitung**（意味: 計算する、数える）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menghitung** | 他動詞 | 数える、計算する、算出する |
| **perhitungan** | 名詞 | 計算、見積もり、打算 |
| **terhitung** | 受動/副詞 | 〜付で（日付）、計算に入る |
| **berhitung** | 自動詞 | 算数をする、暗算する |
