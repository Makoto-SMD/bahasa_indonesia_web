# 語根 sempit の全派生語図鑑（**menyempit**, **mempersempit**, **penyempitan**, **kesempitan**）

インドネシア語の重要語根 **sempit（狭める、窮屈な）** は、空間の狭小から時間的切迫、視野の狭さを表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---
