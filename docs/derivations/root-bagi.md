# 語根 bagi の全派生語図鑑（**membagi**, **berbagi**, **pembagian**, **sebagian**）

インドネシア語の重要語根 **bagi（分配する、共有する）** は、分割やシェア、前置詞としての「〜にとって」を導く多機能語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
