# 語根 rusak の全派生語図鑑（**merusak**, **kerusakan**, **perusak**）

インドネシア語の重要語根 **rusak（破壊する、損害）** は、機械の故障から自然環境の破壊、人間関係の破綻を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
