# 語根 adil の全派生語図鑑（**mengadili**, **keadilan**, **pengadilan**, **peradilan**）

インドネシア語の重要語根 **adil（公平な、正義）** は、司法制度、裁判所、平等の理念を語る法学・社会の中心語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
