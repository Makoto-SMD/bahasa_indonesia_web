# 語根 kuat の全派生語図鑑（**memperkuat**, **kekuatan**, **menguat**, **terkuat**）

インドネシア語の重要語根 **kuat（強化する、強固な）** は、筋力・強度から経済・法的効力の強化を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 kuat からの派生語ファミリー

語根 **kuat**（意味: 強化する、強固な）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **memperkuat** | 使役他動詞 | 強化する、補強する、固める |
| **kekuatan** | 名詞 | 力、強さ、勢力 |
| **menguat** | 自動詞 | 強まる、（通貨が）上昇する |
| **terkuat** | 最上級 | 最も強い、最強の |
