# 語根 turun の全派生語図鑑（**menurunkan**, **penurunan**, **menurun**, **keturunan**）

インドネシア語の重要語根 **turun（低下する、降りる）** は、階段を降りる動作から価格の下落、子孫への継承を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 turun からの派生語ファミリー

語根 **turun**（意味: 低下する、降りる）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **menurunkan** | 使役他動詞 | 下げる、降ろす、軽減する |
| **penurunan** | 名詞 | 下落、低下、減少 |

| **keturunan** | 名詞 | 子孫、血統、〜系（keturunan Jepang） |
