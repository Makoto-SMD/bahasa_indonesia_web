# 語根 serah の全派生語図鑑（**menyerahkan**, **penyerahan**, **pasrah / berserah**, **terserah**）

インドネシア語の重要語根 **serah（引き渡す、委ねる）** は、業務の引き継ぎ、提出、運命への降伏・帰依を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
