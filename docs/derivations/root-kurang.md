# 語根 kurang の全派生語図鑑（**mengurangi**, **berkurang**, **kekurangan**, **pengurangan**）

インドネシア語の重要語根 **kurang（減らす、欠ける）** は、数量の減少、不足、否定辞（あまり〜ない）を表す語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。

---

## 1. 語根 kurang からの派生語ファミリー

語根 **kurang**（意味: 減らす、欠ける）から派生する主要な単語一覧です。

| 派生語 | 品詞・分類 | 主な日本語の意味・ニュアンス |
| :--- | :--- | :--- |
| **mengurangi** | 他動詞 | 減らす、削減する、引き算する |
| **berkurang** | 自動詞 | 減る、減少する、衰退する |
| **kekurangan** | 名詞 | 不足、欠点、短所 |
| **pengurangan** | 名詞 | 削減、減税、マイナス |
