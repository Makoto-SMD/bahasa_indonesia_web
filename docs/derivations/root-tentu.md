# 語根 tentu の全派生語図鑑（**menentukan**, **tertentu**, **ketentuan**, **penentuan**, **tentunya**）

インドネシア語の重要語根 **tentu（定まる、確実な）** は、方針の決定から法的規則、確信の表現まで日常・実務に不可欠な語根。
日常会話からビジネス実務、公的文書、検定試験で必須となる派生語を体系的に完全整理します。
