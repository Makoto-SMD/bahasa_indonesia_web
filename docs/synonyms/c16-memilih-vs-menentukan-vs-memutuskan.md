# C16：memilih vs menentukan vs memutuskan vs menetapkan（選択・特定・決断・公的制定の「決める」比較）

日本語の「決める」「選ぶ」は日常会話からビジネス、法律まで幅広く使われますが、インドネシア語では決定のプロセスや権限、拘束力に応じて **`memilih`**、**`menentukan`**、**`memutuskan`**、**`menetapkan`** の4動詞が厳密に区別されます。

メニューから料理を「選ぶ」のか、スケジュールや方針を「特定・決定する」のか、議論の末に「最終決断を下す」のか、あるいは大統領令や省令として「公的に制定・公布する」のか、それぞれの文脈に応じた正確な使い分けを整理しましょう。

---

## 4動詞の決定権限・プロセス比較表 (Tahapan Pengambilan Keputusan)

| 動詞（語根） | 決定のプロセスと権限 | 対象 | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **memilih (pilih)** | **複数の選択肢の中から吟味して1つを選ぶ（select / vote）** | 商品、候補者、道、選択肢 | 選ぶ・選択する・投票する | *memilih presiden*, *memilih menu makanan* |
| **menentukan (tentu)** | **不確定な要素を「特定・確定」する（determine / identify）** | 日程、場所、方針、運命 | 決める・特定する・決定づける | *menentukan jadwal rapat*, *faktor penentu* |
| **memutuskan (putus)** | **葛藤や審議の末に「最終決断」を下す（decide / rule）** | 方針の決断、裁判の判決 | 決断する・思い切って決める・判決を下す | *memutuskan untuk berhenti kerja*, *keputusan hakim* |
| **menetapkan (tetap)** | **公的権限・法的効力をもって「公式制定」する（establish / enact）** | 法律、規則、定員、価格、基準 | 制定する・規定する・公布・設定する | *menetapkan undang-undang*, *menetapkan UMR* |

## 1. memilih（複数肢からの選択・投票）

`memilih` の中核義は 「**目の前に複数のオプション（選択肢）が存在し、その中から最も良いものを取り出す（choose / select）**」 ことです。民主的な選挙での「投票」にもこの語が使われます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'memilih'</span>
</div>
<div class="id-example-body">

- **Konsumen bebas memilih produk yang sesuai dengan selera dan anggaran mereka.**<br>
  （消費者は自身の好みと予算に合った製品を自由に選ぶことができる。）
- **Rakyat Indonesia menggunakan hak pilihnya untuk memilih presiden dan wakil presiden.**<br>
  （インドネシア国民は正副大統領を選ぶために投票権[hak pilih]を行使する。）
- **Dia memilih untuk melanjutkan studi S2 daripada langsung bekerja.**<br>
  （彼はすぐに就職するよりも、修士課程への進学を選んだ。）

</div>
</div>

## 2. menentukan（不確定な事柄を特定・確定する）

`menentukan`（語根: *tentu*＝確実な・一定の）の中核義は 「**まだ確定していない日時、場所、要因、方向性を明確に特定する（determine / fix）**」 ことです。また「勝敗を決定づける（*faktor penentu*）」という因果関係にも使われます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'menentukan'</span>
</div>
<div class="id-example-body">

- **Kita harus segera menentukan tanggal dan tempat penyelenggaraan seminar tahunan.**<br>
  （私たちは年次セミナーの開催日と開催場所を至急決定[特定]しなければならない。）
- **Kualitas sumber daya manusia menjadi faktor penentu kemajuan suatu bangsa.**<br>
  （人材の質こそが、ある国家の発展を決定づける要因[faktor penentu]となる。）
- **Pemerintah sedang menentukan kriteria penerima bantuan sosial beras gratis.**<br>
  （政府は無料の米の社会福祉支援の受給者基準を特定・確定しているところだ。）

</div>
</div>

## 3. memutuskan（迷いや議論の末に「最終決断を下す」）

`memutuskan`（語根: *putus*＝切る、断ち切る）の中核義は 「**迷い、議論、裁判審理を経て、一つの結論に断を下す（decide / conclude / make a decision）**」 ことです。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'memutuskan'</span>
</div>
<div class="id-example-body">

- **Setelah berdiskusi panjang lebar, dewan direksi akhirnya memutuskan untuk menutup pabrik itu.**<br>
  （長時間の議論の末、取締役会はついにその工場を閉鎖することを決断した。）
- **Pengadilan telah memutuskan bahwa terdakwa terbukti bersalah melakukan korupsi.**<br>
  （裁判所は被告が汚職を行った有罪であるとの判決を下した[決定した]。）
- **Jangan mengambil keputusan saat Anda sedang dalam keadaan marah.**<br>
  （怒りの感情の中にいるときに、決断を下して[mengambil keputusan]はならない。）

</div>
</div>

## 4. menetapkan（公的権限をもって「公式制定・規定する」）

`menetapkan`（語根: *tetap*＝不変の、確固たる）の中核義は 「**国家、大臣、組織のトップが、公的な法的効力や恒久的な拘束力を持たせて制度や価格を制定・公布する（establish / enact / stipulate）**」 ことです。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 4</span>
<span class="id-example-title">Penggunaan 'menetapkan'</span>
</div>
<div class="id-example-body">

- **Gubernur telah menetapkan Upah Minimum Provinsi (UMP) untuk tahun depan.**<br>
  （州知事は来年度の州最低賃金[UMP]を公的に制定・告示した。）
- **Pemerintah menetapkan hari Senin depan sebagai hari libur nasional cuti bersama.**<br>
  （政府は来週月曜日を一斉有給休暇の国民の祝日として公式指定・制定した。）
- **Menteri Keuangan menetapkan tarif pajak pertambahan nilai baru melalui peraturan menteri.**<br>
  （財務大臣は省令を通じて新たな付加価値税率を規定・制定した。）

</div>
</div>

## 決定のプロセスの連続シナリオ（国家プロジェクト）

1. **Pemerintah memilih lokasi ibu kota baru dari beberapa kandidat pulau.**<br>
   → 複数の候補地の中から新首都の場所を「選ぶ（memilih）」。
2. **Kementerian menentukan tata ruang dan zonasi pembangunan kota cerdas.**<br>
   → 省庁がスマートシティの都市計画と区域を具体的に「特定・確定する（menentukan）」。
3. **Presiden memutuskan untuk memulai peletakan batu pertama tahun ini.**<br>
   → 大統領が今年中の起工式着工を「決断する（memutuskan）」。
4. **DPR menetapkan undang-undang pemindahan ibu kota negara.**<br>
   → 国会が新首都移転に関する法律を「公式制定・可決する（menetapkan）」。

## 実戦ミニクイズ (Latihan Soal)

**問題:**
1. Sebelum memesan makanan di restoran, silakan ( ... ) menu yang Anda sukai.
2. Kementerian Agama akan menggelar sidang isbat untuk ( ... ) awal bulan Ramadan.
3. Presiden telah ( ... ) peraturan pemerintah pengganti undang-undang tentang penanggulangan terorisme.

**解答・解説:**
1. **memilih**（メニューの複数肢から好きなものを「選ぶ」ため `memilih`）。
2. **menentukan**（天体観測と審議に基づきラマダン月の開始日を「特定・確定する」ため `menentukan`）。
3. **menetapkan**（テロ対策に関する政府規則を法的効力をもって「公的制定・公布した」ため `menetapkan`）。

</details>

## まとめと使い分けのツボ

1. **複数の選択肢から選ぶのは `memilih`**（選挙投票＝*pemilu*）。
2. **日程、場所、基準を特定・確定するのは `menentukan`**。
3. **議論や葛藤の末に決断を下す、裁判所の判決は `memutuskan`**。
4. **最低賃金、法律、祝日などを公的に制定・規定するのは `menetapkan`**。
