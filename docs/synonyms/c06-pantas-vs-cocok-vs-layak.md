# C06：pantas vs cocok vs layak（似合う・適切・相応しい・妥当の評価基準）

日本語の「似合う」「ぴったりだ」「ふさわしい」「妥当だ」に対応するインドネシア語の代表格が **`cocok`**、**`pantas`**、**`layak`** の3語です。

服のサイズが合うのか、性格の相性が良いのか、当然の報いとして相応しいのか、あるいは法的・社会的な基準を満たして資格があるのかによって、選ぶべき単語がまったく異なります。日常会話のコーディネートから、人事評価、公的基準の審査に至るまで、評価基準の境界線を整理しましょう。

---

## 3語の比較対照サマリー表 (Tabel Perbandingan)

| 単語 | 評価の基準 | 主な対象 | 日本語の対応 | 代表的なコロケーション |
| :--- | :--- | :--- | :--- | :--- |
| **cocok** | **個人的適合・相性・一致**<br>2つのものの調和・サイズ・趣味の合致 | 服、薬、性格、値段、相性 | 似合う・ぴったりだ・合う | *cocok untuk Anda*, *obat ini cocok*, *tidak cocok sifatnya* |
| **pantas** | **道徳的妥当性・因果の当然性**<br>「〜して当然だ」「マナーとしてふさわしい」 | 行動、言葉遣い、業績に対する結果 | 相応しい・当然だ・道理にかなう | *pantas mendapat pujian*, *tidak pantas diucapkan*, *pantas saja...* |
| **layak** | **客観的基準・公的資格・人道的最低水準**<br>公的規格や最低限の生活水準への合致 | 住居、給与、施設、候補者の適格性 | 妥当な・適格な・人間らしい | *upah layak*, *rumah layak huni*, *layak dipromosikan* |

---

## 1. cocok（適合・相性・似合う）

`cocok` の中核義は 「**AとBの2つの要素がぴったり調和・一致すること（match / fit / suitable）**」 です。主観的・感覚的な相性の良さに最も広く使われます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'cocok'</span>
</div>
<div class="id-example-body">

- **Warna baju batik ini sangat cocok dengan warna kulit Anda.**<br>
  （このバティックの服の色は、あなたの肌の色にとてもよく似合っています。）
- **Saya merasa obat batuk ini sangat cocok untuk saya, batuk langsung reda.**<br>
  （この咳止め薬は私によく合っているようで、咳がすぐに治まった。）
- **Kedua pasangan itu saling melengkapi karena sifat mereka sangat cocok.**<br>
  （あのカップルはお互いの性格の相性がとても良いので、補い合っている。）

## 2. pantas（道徳的妥当・相応しい・当然だ）

`pantas` の中核義は 「**社会規範、倫理、努力、身分に照らして道理にかなっていること（proper / worthy / appropriate）**」 です。

### (1) 「〜にふさわしい・値する」
- **Dengan kerja kerasnya selama bertahun-tahun, dia pantas menjadi direktur.**<br>
  （長年のハードワークを考えれば、彼が社長になるのは当然ふさわしい。）
- **Kata-kata kasar seperti itu tidak pantas diucapkan oleh seorang pendidik.**<br>
  （あのような下品な言葉は、教育者が口にするのにふさわしくない。）

### (2) 「道理で〜なわけだ（Pantas saja...）」
原因を知って納得したときの「なるほど、どうりで！」という感嘆表現です。
- **Pantas saja dia pintar bahasa Indonesia, ternyata ibunya orang Jakarta!**<br>
  （道理で彼がインドネシア語が上手なわけだ、お母さんがジャカルタの人だったのか！）

---

## 3. layak（客観的基準・公的適格・人道的水準）

`layak` の中核義は 「**公的規格、安全基準、人権、あるいは法定基準を満たして適格であること（eligible / decent / qualified）**」 です。公式な政策や法律、基準判定で多用されます。

- **Pemerintah memperjuangkan upah minimum yang layak bagi para buruh.**<br>
  （政府は労働者のための適正な[人間らしい生活が送れる]最低賃金を求めて闘っている。）
- **Pesawat tua itu dinyatakan sudah tidak layak terbang oleh kementerian perhubungan.**<br>
  （その旧型飛行機は運輸省によってすでに耐空性なし[飛行不適格]と判定された。）
- **Rumah tidak layak huni (RTLH) ini akan direnovasi melalui program bantuan sosial.**<br>
  （この居住不適格住宅[RTLH]は、社会福祉支援プログラムを通じて改修される予定だ。）

## 3語の判定基準の違いまとめ

同じ「給料」を話題にする場合：
1. **Gajinya cocok.** → 私の希望額と合致している（個人的満足）。
2. **Gajinya pantas.** → 彼の仕事ぶりや実績に相応しい妥当な額だ（成果への正当な評価）。
3. **Gajinya layak.** → 法定基準や生活費を満たした適正水準の額だ（客観的基準）。

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に cocok, pantas, layak を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Sepatu olahraga ini ukurannya pas dan warnanya sangat ( ... ) dipakai saat lari pagi.
2. Jembatan gantung yang sudah lapuk itu dinilai tidak ( ... ) lagi dilewati kendaraan bermotor.
3. Setelah berhasil meraih medali emas olimpiade, atlet itu ( ... ) menerima penghargaan tertinggi dari presiden.

**解答・解説:**
1. **cocok**（靴のサイズや色がランニングに「似合っている・合っている」ため `cocok`）。
2. **layak**（安全基準を満たしておらず「通行不適格」であるため `layak`：*tidak layak dilewati*）。
3. **pantas**（偉業を成し遂げた当然の報いとして「受けるに相応しい」ため `pantas`）。

</details>

## まとめと使い分けのツボ

1. **服のセンス、薬の効き目、性格の相性は `cocok`**。
2. **「道理で〜なわけだ」「努力相応の評価」「マナー違反」は `pantas`**。
3. **「最低賃金（upah layak）」「耐空性（layak terbang）」「居住適格（layak huni）」など公的基準は `layak`**。
