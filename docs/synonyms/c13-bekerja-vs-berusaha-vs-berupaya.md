# C13：bekerja vs berusaha vs berupaya vs berikhtiar（労働・努力・奮闘・人知の最善の使い分け）

「働く」「努力する」「最善を尽くす」という行動は、ビジネスや自己実現において最も重要な概念です。インドネシア語には、**`bekerja`**、**`berusaha`**、**`berupaya`**、**`berikhtiar`** の4つの動詞があり、それぞれが持つ語源や精神的背景、文体（レジスター）が大きく異なります。

単なる日々の労働なのか、困難を打破するための奮闘努力なのか、国家や企業が公的に掲げる戦略的取り組みなのか、あるいは「人事を尽くして天命を待つ」という宗教的信念に基づく最善の尽力なのかを正確に識別しましょう。

---

## 4動詞の精神的深度・文体比較表 (Nuansa & Register Ikhtiar)

| 動詞（語根） | 中核的ニュアンス | 文体・レジスター | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **bekerja (kerja)** | **「職業労働・機能する」**<br>給与や対価を得るための日常の仕事 | 一般日常・実務 | 働く・勤務する・機能する | *bekerja di bank*, *mesin bekerja baik* |
| **berusaha (usaha)** | **「努力する・試みる・起業する」**<br>目標達成や困難克服のためにエネルギーを注ぐ | 日常会話〜一般ビジネス | 努力する・頑張る・起業する | *berusaha keras*, *perusahaan*（会社） |
| **berupaya (upaya)** | **「戦略的努力・施策を講じる」**<br>組織や政府が多角的な手段を尽くして取り組む | 公的文書・報道・学術（格調高い） | 尽力する・施策を尽くす・奮闘する | *pemerintah berupaya menekan inflasi* |
| **berikhtiar (ikhtiar)** | **「人知を尽くす・全力を尽くす」**<br>結果を神（神意）に委ねつつ人間のベストを尽くす | 宗教的・倫理的・格調高い文脈 | 人事を尽くす・全力を尽くす | *berikhtiar semaksimal mungkin dan berdoa* |

## 1. bekerja（職業として働く・機械が作動する）

`bekerja` は最も具体的かつ物理的な動詞です。
1. **人間が給与を得て職務を果たす（work / labor）**
2. **機械やシステム、薬が正常に「作動する・効く（function / operate）」**

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'bekerja'</span>
</div>
<div class="id-example-body">

- **Ayah saya bekerja sebagai pegawai negeri di kementerian keuangan.**<br>
  （私の父は財務省で公務員として働いている。）
- **Sistem pendingin ruangan ini tidak dapat bekerja secara optimal karena rusak.**<br>
  （このエアコンシステムは故障のため最適に作動することができない。）
- **Obat penurun panas ini mulai bekerja meredakan demam pasien.**<br>
  （この解熱剤が効き始めて[作動して]、患者の熱を下げている。）

## 2. berusaha（目標達成に向けて努力する・起業する）

`berusaha` は、語根 `usaha`（努力、試み、事業）から派生した動詞で、**「困難な障害や課題に対して、意志を持って一生懸命取り組む（strive / try / make an effort）」** ことを表します。また「商売・ビジネスを興す」という意味も持ちます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'berusaha'</span>
</div>
<div class="id-example-body">

- **Saya akan berusaha sekuat tenaga untuk lulus ujian seleksi beasiswa tersebut.**<br>
  （その奨学金選抜試験に合格するため、全力で努力するつもりです。）
- **Jangan menyerah begitu saja, kita harus terus berusaha mencari jalan keluar.**<br>
  （そう簡単に諦めるな、私たちは解決策を探すために努力し続けなければならない。）
- **Banyak sarjana muda yang memilih berusaha di bidang kuliner daripada menjadi karyawan.**<br>
  （会社員になるよりも、飲食分野で起業する[berusaha]若手大卒者が多い。）

</div>
</div>

## 3. berupaya（公的・戦略的に施策を尽くす）

`berupaya` は `berusaha` のフォーマル・文語的（Ragam Resmi）な類義語です。新聞記事、社説、公的政策声明などで、**「政府、機関、企業経営陣が目標達成のために多角的な手立てや戦略を講じる」** 際に好んで用いられます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'berupaya'</span>
</div>
<div class="id-example-body">

- **Kementerian Kesehatan berupaya keras menurunkan angka stunting pada balita.**<br>
  （保健省は乳幼児の発育不全率を引き下げるため懸命に尽力している。）
- **Manajemen maskapai penerbangan berupaya memperbaiki kualitas layanan penumpang.**<br>
  （航空会社の経営陣は乗客向けサービスの品質を改善すべく施策を講じている。）
- **Berbagai upaya mitigasi bencana telah disiapkan oleh pemerintah daerah.**<br>
  （様々な災害軽減の取り組み[upaya]が地方自治体によって準備された。）

</div>
</div>

## 4. berikhtiar（人事を尽くす・神への祈りと連動する最善の努力）

アラビア語 *ikhtiyār*（選択、自由意志の行使）に由来する格調高い宗教的・倫理的語彙です。
イスラム文化圏における重要な概念「**Tawakal（結果を神に委ねる）**」とペアで用いられ、**「人間としてできる限りの最善を尽くし、その上で最終的な結果は神の采配を信じる」** という崇高な努力を意味します。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 4</span>
<span class="id-example-title">Penggunaan 'berikhtiar'</span>
</div>
<div class="id-example-body">

- **Sebagai manusia kita wajib berikhtiar sungguh-sungguh, setelah itu bertawakal kepada Tuhan.**<br>
  （人間として私たちは真摯に人事を尽くさねばならず、その後に神に結果を委ねるのである。）
- **Keluarga pasien telah berikhtiar mencari pengobatan ke berbagai rumah sakit terbaik.**<br>
  （患者の家族は最高の病院をいくつも巡り、人知の及ぶ限りのあらゆる治療の手を尽くした。）

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に最も適切な動詞を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Bank Indonesia terus ( ... ) menjaga stabilitas nilai tukar Rupiah di tengah gejolak pasar global.
2. Dokter mengatakan bahwa kita harus tetap ( ... ) mencari kesembuhan sambil terus berdoa.
3. Mesin fotokopi ini sudah tidak ( ... ) sejak kemarin sore karena korsleting listrik.

**解答・解説:**
1. **berupaya**（中央銀行がマクロ安定のために公的施策を講じる格調高い文脈であるため `berupaya` が最適）。
2. **berikhtiar**（祈り[berdoa]とセットで、病気平癒のために人間の最善を尽くす信仰的・精神的文脈のため `berikhtiar` が最適）。
3. **bekerja**（機械が電気のショートで作動しないため物理的作動を表す `bekerja`）。

</details>

## まとめと使い分けのツボ

1. **職業としての労働、機械や薬の作動は `bekerja`**。
2. **困難克服のための個人の一生懸命な努力、起業は `berusaha`**。
3. **政府声明や公式文書での「施策の遂行・戦略的尽力」は格調高い `berupaya`**。
4. **病気や人生の岐路で「人事を尽くして天命を待つ」崇高な尽力は `berikhtiar`**。
