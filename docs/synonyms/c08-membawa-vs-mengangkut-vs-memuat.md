# C08：membawa vs mengangkut vs memuat（運ぶ・輸送・積載の規模と手段の違い）

物流、交通、日常の買い物、引っ越しなどにおいて、「荷物を運ぶ」「トラックに積む」「内容を掲載する」を表現する動詞が **`membawa`**、**`mengangkut`**、**`memuat`** の3つです。

日本語ではすべて「運ぶ」や「積む」で済ませがちですが、インドネシア語では **「人間が手で持っているのか（小規模携行）」「トラックや船などの輸送機関が大量に運搬しているのか（輸送・移送）」「容器や乗り物が内部に収納・積載しているのか（容量・掲載）」** によって動詞が厳格に分かれます。

---

## 3動詞の比較対照サマリー表 (Tabel Perbandingan)

| 動詞（語根） | 中核的機能 | 運搬の手段と規模 | 日本語の対応 | 代表的なコロケーション |
| :--- | :--- | :--- | :--- | :--- |
| **membawa (bawa)** | **「携行・所持」**<br>身体や手に持って移動する、同伴する | 個人レベル・手荷物・同伴者 | 持っていく・連れていく・運ぶ | *membawa tas*, *membawa payung*, *membawa dampak* |
| **mengangkut (angkut)** | **「大量輸送・搬送」**<br>乗り物や労働力を用いて荷や人を運搬する | 車両、船舶、航空機、組織的大量輸送 | 輸送する・搬送する・運搬する | *truk mengangkut beras*, *kereta mengangkut penumpang* |
| **memuat (muat)** | **「積載・収容・掲載」**<br>内部に荷を収める、記事を載せる | 乗り物の積載量、メディアの掲載 | 積む・収容できる・掲載する | *kapal memuat kontainer*, *koran memuat berita*, *daya muat* |

---

## 1. membawa（手荷物の携行・持参・連行）

`membawa` は最も基本的で守備範囲の広い動詞です。個人が身の回りのものを **「手や鞄に入れて移動する」**、あるいは比喩的に **「結果や影響をもたらす（*membawa dampak*）」** 際に使います。

- **Krisis ekonomi global ini membawa dampak serius bagi industri tekstil.**<br>
  （この世界金融危機は、繊維産業に深刻な影響をもたらした。）

## 2. mengangkut（乗り物による大量輸送・移送）

`mengangkut` の中核義は **「車両、列車、船舶などの輸送機関（alat transportasi）を用いて、大量の物資や大勢の乗客を別の場所へ輸送すること」** です。物流や公共交通の専門用語として多用されます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'mengangkut'</span>
</div>
<div class="id-example-body">

- **Truk kontainer itu mengangkut bahan baku industri dari pelabuhan ke pabrik.**<br>
  （そのコンテナトラックは、港から工場へ工業用原材料を輸送している。）
- **Kereta rel listrik (KRL) Jabodetabek mengangkut lebih dari satu juta penumpang setiap hari.**<br>
  （ジャボデタベックの通勤電車[KRL]は、毎日100万人以上の乗客を輸送している。）
- **Helikopter militer dikerahkan untuk mengangkut bantuan logistik ke daerah terisolasi.**<br>
  （孤立地域へ救援物資を空輸・搬送するため、軍用ヘリコプターが投入された。）

## 3. memuat（積載する・収容力がある・記事を掲載する）

`memuat` の中核義は **「乗り物や容器、あるいは媒体（新聞・雑誌）の内部に、対象物を格納・配置すること（load / accommodate / publish）」** です。

### (1) 「乗り物・船に荷物を積む（積載）」
- **Kapal kargo itu memuat ribuan ton batu bara menuju Cina.**<br>
  （その貨物船は中国へ向けて数千トンの石炭を積載している。）
- **Bus pariwisata ini mampu memuat hingga lima puluh penumpang.**<br>
  （この観光バスは最大50人の乗客を収容[定員積載]できる。）

### (2) 「新聞・メディアに記事を掲載する」
紙面やウェブサイトにニュースを「載せる」場合、標準語では必ず **`memuat`** を使います。
- **Surat kabar nasional itu memuat berita utama tentang pemilihan umum.**<br>
  （その全国紙は総選挙に関するトップニュースを掲載した。）

## 3動詞の連鎖シナリオ（港の物流）

1. **Buruh membawa karung beras di pundaknya.**<br>
   → 作業員が肩の上に米袋を担いで「運ぶ」（個人の身体動作）。
2. **Kapal kargo memuat sepuluh ribu ton beras di dermaga.**<br>
   → 貨物船が埠頭で1万トンの米を「船倉に積み込む・積載する」（積載容量）。
3. **Kapal itu mengangkut beras dari Makassar ke Jakarta.**<br>
   → その船がマカッサルからジャカルタへ米を海上「輸送する」（移動・輸送）。

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に membawa, mengangkut, memuat を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Truk tronton ini tidak boleh melintas di jalan sempit karena ( ... ) muatan berlebih.
2. Setiap kali bepergian ke luar negeri, saya selalu ( ... ) obat-obatan pribadi.
3. Media massa daring dilarang ( ... ) konten yang mengandung unsur ujaran kebencian.

**解答・解説:**
1. **mengangkut**（または積載しているという意味で `memuat` も可能ですが、「過積載の荷を運んでいる」という輸送行為としては `mengangkut muatan berlebih` が標準的です）。
2. **membawa**（個人的な常備薬を手荷物として「携行する・持参する」ため `membawa`）。
3. **memuat**（ウェブメディアが記事・コンテンツを「掲載する・載せる」ため `memuat`）。

</details>

## まとめと使い分けのツボ

1. **手や鞄で身の回りの物を持っていくなら `membawa`**。
2. **トラック、船、飛行機で大量の荷や人を輸送するなら `mengangkut`**（公共交通・物流）。
3. **「船に〜トンの荷を積む」「定員〜人を収容する」積載なら `memuat`**。
4. **新聞やニュースに記事を「掲載する」のも `memuat`**。
