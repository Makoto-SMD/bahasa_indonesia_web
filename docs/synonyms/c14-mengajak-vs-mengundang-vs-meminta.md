# C14：mengajak vs mengundang vs meminta（誘う・正式招待・要請依頼の社会的距離）

他者に対して「一緒に行こうと声をかける」「イベントに招く」「何かをしてくれるよう頼む」という対人コミュニケーションでは、相手との**社会的距離（Jarak Sosial）**や**フォーマリティの度合い**に応じて **`mengajak`**、**`mengundang`**、**`meminta`** を厳格に使い分けます。

友人をご飯に誘うときに *mengundang* を使うと堅苦しすぎ、逆に結婚式や公的カンファレンスに取引先を招くときに *mengajak* を使うと失礼にあたることがあります。3者の明確な境界線を理解しましょう。

---

## 3動詞の社会的距離・形式性比較表 (Tingkat Formalitas & Jarak Sosial)

| 動詞（語根） | 社会的距離・関係性 | 動作の性質 | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **mengajak (ajak)** | **近い（友人・同僚・家族）** | 「一緒に〜しよう」と口頭で誘う、同行を促す | 誘う・声をかける・呼びかける | *mengajak makan siang*, *mengajak jalan-jalan* |
| **mengundang (undang)** | **公的・儀礼的（親戚・顧客・賓客）** | 招待状や公式連絡をもって正式に行事に招く | 招待する・招く・招聘する | *mengundang ke pernikahan*, *surat undangan* |
| **meminta (minta)** | **利害・業務関係（要求・要請）** | 相手に労力、物、情報、許可を求める | 頼む・要請する・求める・乞う | *meminta bantuan*, *meminta izin*, *permintaan* |

---

## 1. mengajak（気軽に「一緒に〜しよう」と誘う・呼びかける）

`mengajak` の中核義は **「相手に同行を促し、一緒に同じ行動をとるよう誘いかける（invite casually / ask along）」** です。口頭でのカジュアルな誘いに最も自然に使われます。

<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'mengajak'</span>
</div>
<div class="id-example-body">

- **Teman kantor mengajak saya makan siang di warung padang dekat sini.**<br>
  （同僚が私を近くのパダン料理屋でのランチに誘ってくれた。）
- **Akhir pekan ini ayah berencana mengajak kami sekeluarga pergi ke kebun binatang.**<br>
  （今週末、父は私たち家族を動物園へ連れて行こうと[誘おうと]計画している。）
- **Pemerintah mengajak seluruh lapisan masyarakat untuk menjaga kebersihan lingkungan.**<br>
  （政府は環境の清潔さを維持するよう全社会層に呼びかけている[促している]。）

## 2. mengundang（招待状を出して公式に「招く・招聘する」）

`mengundang` は、**「結婚式（kondangan）、セミナー、祝賀会、公式晩餐会などに、敬意を込めて正式に客として招く（invite officially）」** 儀礼的・公式な動詞です。名詞 **`undangan`（招待状・招待客）** と直結しています。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'mengundang'</span>
</div>
<div class="id-example-body">

- **Kami bermaksud mengundang Bapak dan Ibu untuk menghadiri resepsi pernikahan putri kami.**<br>
  （私たちの娘の結婚披露宴にご出席いただきたく、皆様をご招待申し上げます。）
- **Universitas mengundang pakar ekonomi dari Jepang sebagai pembicara utama dalam seminar.**<br>
  （大学はセミナーの基調講演者として日本から経済専門家を招聘・招待した。）
- **Presiden mengundang para pimpinan partai politik ke istana negara untuk berdiskusi.**<br>
  （大統領は会談のため、各政党の指導者たちを大統領宮殿に招待した。）

</div>
</div>

## 3. meminta（何かを「求める・頼む・要請する」）

`meminta`（口語では `minta`）は、同行や招待ではなく、**「相手から物、金銭、時間、労力、許可、助けを提供してもらうよう求める（ask for / request）」** 行為です。

<div class="id-example-header">

- **Manajer meminta staf bagian akuntansi untuk segera menyerahkan laporan keuangan.**<br>
  （マネージャーは財務担当スタッフに財務諸表を至急提出するよう求めた[指示・要請した]。）
- **Saya ingin meminta izin tidak masuk kantor besok karena demam tinggi.**<br>
  （高熱があるため、明日オフィスを休む許可をいただきたい[頼みたい]のですが。）
- **Pengemis itu duduk di pinggir jalan meminta belas kasihan pejalan kaki.**<br>
  （その物乞いは道端に座り、通行人の情けを乞うていた。）

## 場面による使い分け比較シナリオ

同僚のブディ（Budi）に対して：
1. **Saya mengajak Budi ngopi di kafe.**<br>
   → 「ブディ、カフェでコーヒーでも飲もうよ」と気軽に誘う（一緒に行く）。
2. **Saya mengundang Budi ke acara ulang tahun anak saya.**<br>
   → 「子どもの誕生日パーティーにぜひ来てください」と正式に招待状を渡して招く（ゲストとして招待）。
3. **Saya meminta Budi membantu menyiapkan materi presentasi.**<br>
   → 「プレゼン資料の作成を手伝ってほしい」と頼む・依頼する（作業の要請）。

## 実戦ミニクイズ (Latihan Soal)

**問題:**
1. Panitia simposium internasional telah ( ... ) menteri luar negeri untuk membuka acara secara resmi.
2. Setiap hari Minggu pagi, kakak selalu ( ... ) adik bersepeda keliling kompleks perumahan.
3. Klien dari luar kota itu ( ... ) tambahan waktu dua hari untuk menyelesaikan pembayaran invoice.

**解答・解説:**
1. **mengundang**（国際シンポジウムの開会を飾る賓客として外相を公式に「招待・招聘した」ため `mengundang`）。
2. **mengajak**（日曜の朝に一緒にサイクリングしようと気軽に「誘う・連れ出す」ため `mengajak`）。
3. **meminta**（請求書の支払期限の2日間の延長という権利・猶予を「要請・要求している」ため `meminta`）。

## まとめと使い分けのツボ

1. **「一緒にランチ行こう」「遊びに行こう」と誘うなら `mengajak`**。
2. **結婚式、セミナー、式典へゲストとして正式に招くなら `mengundang`**（招待状＝*surat undangan*）。
3. **助け、許可、資料提出、時間延長を「頼む・求める」なら `meminta`**。
