# C03：bantu vs tolong（助ける・手伝うの機能差と依頼構文での使い分け）

インドネシア語で「助ける」「手伝う」を表現する語として、誰もが知る **`bantu`** と **`tolong`**。

しかし、「手伝ってください」と言いたいときに *Bantu saya!* なのか *Tolong bantu saya!* なのか、あるいは海で溺れているときに叫ぶのは *Bantu!* なのか *Tolong!* なのか、明確に区別して使えている学習者は多くありません。本記事では、この2語の**品詞的機能（動詞 vs 依頼副詞）**と**ニュアンスの深刻度（日常的支援 vs 緊急救命）**の決定的な違いを解説します。

---

## 比較対照サマリー表 (Tabel Perbandingan)

| 単語 | 基本的文法機能 | ニュアンスと深刻度 | 日本語の対応 | 代表的な使われ方 |
| :--- | :--- | :--- | :--- | :--- |
| **bantu** | **他動詞（membantu）**<br>人の作業を補助・支援する | 日常的な手伝い、作業支援、財政的援助 | 手伝う・援助する・助ける | *membantu pekerjaan*, *bantuan sosial*, *pembantu* |
| **tolong** | **1. 依頼副詞（Please）**<br>**2. 動詞（menolong：救助）** | 丁寧な依頼、または危機的状況からの救出 | 〜してください / 救う・助ける | *Tolong buka pintu*, *menolong korban*, *Tolong!*（助けて！） |

---

## 1. bantu（手伝う・支援する）の本質

`bantu` の本質は 「**誰かの力や作業に寄り添い、負担を軽減する（assist / help）**」 です。生命の危機というよりは、**仕事、家事、経済、学業などの「日常的支援」** に使われます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'bantu'</span>
</div>
<div class="id-example-body">

- **Bolehkah saya membantu Anda membawa koper ini?**<br>
  （このスーツケースをお運びするのを手伝いましょうか？）
- **Pemerintah memberikan bantuan dana kepada para korban bencana.**<br>
  （政府は被災者たちに資金援助を提供した。）
- **Dia selalu membantu ibunya memasak di dapur setiap sore.**<br>
  （彼女は毎夕、台所で母が料理するのを手伝っている。）

</div>
</div>

> [!NOTE]
> 文頭で単体で *Bantu buka pintu.* と言うと、「ドアを開けるのを手伝って」という砕けた指示になり、丁寧な「〜してください」という依頼にはなりません。

---

## 2. tolong（〜してください／命を救う）の本質

`tolong` には、まったく異なる2つの顔があります。

### (1) 丁寧な依頼の機能語（Please / 〜してください）
文頭に置くことで、平叙文や命令文を**丁寧な依頼文（Kalimat Permintaan）**に変える魔法の言葉です。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2A</span>
<span class="id-example-title">Tolong Sebagai Penanda Santun (Please)</span>
</div>
<div class="id-example-body">

- **Tolong kirimkan laporan ini kepada direktur sebelum jam lima.**<br>
  （5時前にこの報告書を社長へ送ってください。）
- **Tolong bicara lebih pelan sedikit, saya belum begitu paham.**<br>
  （もう少しゆっくり話してください、まだよく理解できません。）

</div>
</div>

### (2) 動詞 menolong（危険や困難から救助する・助命する）
動詞接辞を付けた **`menolong`**、あるいは緊急時の叫び声としての **`Tolong!`** は、単なる手伝いではなく 「**危機、災難、溺水、事故などから人を救い出す（rescue / save）**」 という重大な意味を持ちます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2B</span>
<span class="id-example-title">Menolong Sebagai Tindakan Penyelamatan</span>
</div>
<div class="id-example-body">

- **Tolong! Ada pencuri masuk ke rumah tetangga!**<br>
  （助けて！隣の家に泥棒が入った！）
- **Dokter berusaha keras menolong pasien yang kritis itu.**<br>
  （医師はその重篤な患者の命を救おうと全力を尽くした。）
- **Tim SAR berhasil menolong korban yang terjebak tanah longsor.**<br>
  （捜索救助隊は土砂崩れに閉じ込められた被災者を救助することに成功した。）

</div>
</div>

## 決定的な使い分けシナリオ

### 「私を手伝ってください」はどう言う？
1. **Tolong bantu saya.** （最も自然で丁寧な表現：`Tolong` [依頼] ＋ `bantu` [手伝う]）
2. **Bantu saya dong.** （友人同士のカジュアルな表現：「ちょっと手伝ってよ」）
3. **Tolong saya!** （緊急事態：「助けてくれ！（命の危機・救助要請）」に聞こえる）

### 海で溺れたときに叫ぶ言葉は？
- ○ **Tolong! Tolong!** （助けて！＝正解）
- × *Bantu! Bantu!* （不自然。荷物運びを手伝ってほしいように聞こえてしまう）

## 派生語の比較対照

| 語根 | 派生語 | 意味 | 例文 |
| :--- | :--- | :--- | :--- |
| **bantu** | **bantuan** | 援助・支援金・物資 | *bantuan kemanusiaan*（人道支援） |
| | **pembantu** | お手伝いさん・アシスタント | *pembantu rumah tangga (PRT)* |
| | **membantu** | 手助けする（能動態） | *membantu menyelesaikan tugas* |
| **tolong** | **pertolongan** | 救助・救済・助け | *pertolongan pertama (P3K)*（応急手当） |
| | **menolong** | 救い出す・助ける（能動態） | *menolong orang tenggelam* |
| | **penolong** | 救済者・命の恩人 | *Dia adalah penolong hidup saya.* |

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に bantu または tolong を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. ( ... ) ambilkan berkas yang ada di atas meja kerja saya.
2. Kami mengucapkan terima kasih atas segala ( ... ) bapak selama masa sulit ini.
3. Petugas pemadam kebakaran itu mempertaruhkan nyawanya demi ( ... ) anak yang terperangkap api.

**解答・解説:**
1. **Tolong**（文頭で「〜してください」という丁寧な依頼を行うため `Tolong`）。
2. **bantuan**（名詞「ご支援・手助け」を表すため `bantuan`。*pertolongan* は命の恩人のような極めて重い救済に使われる）。
3. **menolong**（火災の火に囲まれた子どもの「命を救助する」ため `menolong`）。

</details>

---

## まとめと使い分けのツボ

1. **人に何かを頼むときの「〜してください」は文頭に `Tolong`**。
2. **日常業務や家事の「手伝い・援助」は `bantu / membantu / bantuan`**。
3. **事故や災害、急病人の「救命・救助」は `tolong / menolong / pertolongan`**。
4. **一番便利な日常フレーズは `Tolong bantu saya.`（手伝ってください）**。
