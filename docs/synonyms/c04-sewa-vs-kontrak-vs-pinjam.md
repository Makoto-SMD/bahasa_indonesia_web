# C04：sewa vs kontrak vs pinjam（借りる・賃貸・契約の対象物と期間の違い）

日本語では本を「借りる」、レンタカーを「借りる」、アパートを「借りる」のすべてに同じ「借りる」を使いますが、インドネシア語では **`pinjam`**、**`sewa`**、**`kontrak`** を厳格に使い分ける必要があります。

最大の違いは 「**金銭を支払うかどうか（無料の貸し借り vs 有料の賃貸）**」、そして有料の場合における 「**期間と対象物の規模（日雇い・月極レンタル vs 年単位の不動産・雇用契約）**」 です。間違った単語を使うと、相手に誤解を与えたりビジネスで失笑を買うことになります。

---

## 3語の比較対照サマリー表 (Tabel Perbandingan)

| 単語 | 金銭の発生 | 主な対象物 | 期間の目安 | 日本語の対応 | 代表例 |
| :--- | :---: | :--- | :--- | :--- | :--- |
| **pinjam** | **無料（無償）** | 筆記具、本、お金、車（友人間） | 一時的・短期 | （無償で）借りる | *pinjam uang*, *pinjam pulpen*, *pinjam buku di perpustakaan* |
| **sewa** | **有料（有償）** | 車、衣装、ホテル、オフィス、機材 | 時間・日・月単位 | レンタルする・賃借する | *sewa mobil*, *sewa kamar*, *uang sewa*（家賃/賃料） |
| **kontrak** | **有料（契約）** | 家・不動産、土地、労働・雇用 | 年単位（1〜数年） | リースする・契約する | *rumah kontrak*, *pegawai kontrak*, *kontrak kerja* |

---

## 1. pinjam（無償で借りる・借金する）

`pinjam` の中核義は 「**対価（お金）を払わずに、後で返す約束で一時的に借りること**」 です。友人同士での物の貸し借りや、図書館での本の貸出などに使います。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'pinjam'</span>
</div>
<div class="id-example-body">

- **Bolehkah saya meminjam pulpen Anda sebentar untuk tanda tangan?**<br>
  （サインするために少しの間あなたのペンをお借りしてもいいですか？）
- **Dia meminjam buku sejarah dari perpustakaan universitas.**<br>
  （彼は大学の図書館から歴史の本を借りた。）
- **Budi meminjam uang dari bank untuk modal usaha.**<br>
  （ブディは事業資金のために銀行からお金を借りた[借金した]。）

</div>
</div>

> [!WARNING]
> レンタカー屋や不動産屋に行って *Saya mau pinjam mobil / rumah.* と言うのは誤りです（「タダで貸してください」という意味になってしまいます）。

---

## 2. sewa（料金を支払ってレンタル・賃借する）

`sewa` の中核義は 「**使用料（uang sewa）を支払って、一定期間物や施設を借りること（rent / lease）**」 です。時間単位、日単位、あるいは月極でのレンタル全般を広く指します。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'sewa'</span>
</div>
<div class="id-example-body">

- **Kami menyewa mobil avanza selama tiga hari untuk liburan di Bali.**<br>
  （私たちはバリ島旅行のため3日間アヴァンザ車をレンタルした。）
- **Berapa biaya sewa apartemen ini per bulan?**<br>
  （このアパートの月々の賃料はいくらですか？）
- **Perusahaan itu menyewa lantai lima belas di gedung perkantoran Sudirman.**<br>
  （その会社はスディルマンのオフィスビルの15階を賃借している。）

</div>
</div>

---

## 3. kontrak（年単位の不動産賃貸契約・雇用契約）

`kontrak` はオランダ語 *contract* / 英語 *contract* 由来の語で、本来は 「**公式な契約書を結ぶこと**」 を意味します。

インドネシアの不動産慣習において、一軒家や土地、アパートを **「年単位**（通常1年〜数年分を一括前払い）」で長期賃貸すること** を特に **`kontrak rumah`（借家契約） と呼びます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'kontrak'</span>
</div>
<div class="id-example-body">

- **Keluarga mereka sudah dua tahun tinggal di rumah kontrakan.**<br>
  （彼らの家族はもう2年間、賃貸の借家[rumah kontrakan]に住んでいる。）
- **Masa kontrak rumah kami akan habis akhir bulan depan, kami harus mencari tempat baru.**<br>
  （借家の契約期間が来月末で切れるので、新しい住まいを探さなければならない。）
- **Dia dipekerjakan sebagai pegawai kontrak selama dua tahun.**<br>
  （彼は2年間の契約社員[pegawai kontrak]として雇用された。）

</div>
</div>

## sewa と kontrak の住居における使い分け

| 住居タイプ | 支払いサイクル | 呼称 |
| :--- | :--- | :--- |
| **コス（Kost：単身者下宿）** | 月払い（Bulanan） | *Sewa kamar kost* / *Kost-kostan* |
| **サービスアパート** | 月払い、または半年払い | *Sewa apartemen* |
| **一軒家（Rumah）** | 通常1〜2年分一括前払い | *Kontrak rumah* / *Rumah kontrakan* |

---

## 「貸す」側の表現はどう言う？

| 語根 | 借りる（Borrow / Rent） | 貸す（Lend / Rent out） |
| :--- | :--- | :--- |
| **pinjam** | **meminjam**（借りる） | **meminjamkan** / **meminjami**（貸す） |
| **sewa** | **menyewa**（借りる） | **menyewakan**（貸し出す・賃貸に出す） |
| **kontrak** | **mengontrak**（契約して借りる） | **mengontrakkan**（契約で貸し出す） |

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に pinjam, sewa, kontrak を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Bolehkah saya ( ... ) payungmu sebentar? Nanti sore saya kembalikan.
2. Turis asing itu ( ... ) sepeda motor seharga seratus ribu rupiah per hari di Bali.
3. Kami baru saja menandatangani ( ... ) rumah untuk jangka waktu tiga tahun.

**解答・解説:**
1. **meminjam**（友人の傘を無料で借りて後で返すため `meminjam`）。
2. **menyewa**（1日あたり10万ルピアの使用料を払ってレンタルするため `menyewa`）。
3. **kontrak**（3年間の長期不動産賃貸契約を結んでいるため `kontrak`）。

</details>

## まとめと使い分けのツボ

1. **無料で友だちや図書館から借りるなら `pinjam`**。
2. **レンタカーや月極アパートなど有料レンタル全般は `sewa`**。
3. **年単位の借家やビジネスの雇用契約は `kontrak`**。
4. **「貸す」にするには接尾辞 `-kan` を付ける**（`meminjamkan`, `menyewakan`）。
