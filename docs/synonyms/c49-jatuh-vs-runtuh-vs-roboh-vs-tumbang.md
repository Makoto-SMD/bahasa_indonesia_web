# C49：jatuh vs runtuh vs roboh vs tumbang（落ちる・崩壊する・倒壊する・大木根こそぎ/打倒の落下倒壊動詞比較）

重力によって下方に崩れ落ちる現象を表す日本語の「落ちる」「転ぶ」「崩壊する」「倒壊する」「（大木が）倒れる」「（政権が）打倒される」。インドネシア語では、単なる落下や転倒なのか、天井や土砂が上からガラガラと崩れ落ちるのか、建造物や壁が地面に倒壊するのか、立派な大木や長寿政権が根こそぎバタリと倒れるのかによって **`jatuh`**、**`runtuh`**、**`roboh`**、**`tumbang`** が厳格に区別されます。

自然災害（地震・台風・土砂崩れ）のニュースから、政治変動、日常の怪我まで、主語に応じた的確な動詞選択をマスターしましょう。

---

## 4動詞の主語適格性・崩壊メカニズム比較表 (Subjek & Mekanisme Runtuh)

| 動詞 | 主語の適格対象 | 崩落・倒壊のメカニズム | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **jatuh** | **【物体・人間・数値・抽象】** | 高所からの落下、つまずき転倒、価格下落 | 落ちる・転ぶ・下落する・恋に落ちる | *jatuh dari tangga*, *harga jatuh*, *jatuh cinta* |
| **runtuh** | **【天井・壁・山・土砂・帝国】** | 重力で粉々になって上から崩れ落ちる | 崩壊する・崩落する・瓦解する | *tanah runtuh*, *gedung runtuh*, *kekaisaran runtuh* |
| **roboh** | **【建造物・家屋・塀・柱・橋】** | 直立していた構造物がへし折れ倒れる | 倒壊する・倒れる・ペシャンコに | *rumah roboh*, *jembatan roboh*, *tembok roboh* |
| **tumbang** | **【大木・電柱・政権・横綱】** | 根元から巨体がドサリと倒れる・打倒 | （大木が）根こそぎ倒れる・政権打倒 | *pohon tumbang*, *rezim tumbang*, *juara tumbang* |

## 1. jatuh（落ちる・落下する・転ぶ・下落する）

最も包括的で身近な「落ちる、転倒する（fall / drop）」です。
- 高所からの落下（*jatuh dari pohon*）
- 歩行中の転倒（*tersandung lalu jatuh*）
- 物価や株価の急落（*harga saham jatuh*）
- 心理的表現：*jatuh cinta*（恋に落ちる）、*jatuh sakit*（病に倒れる）

<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'jatuh'</span>
</div>
<div class="id-example-body">

- **Anak kecil itu menangis karena jatuh dari sepeda saat belajar mengayuh.**<br>
  （その幼子は、自転車の練習中に転んでしまって泣き出した。）
- **Gelas kaca itu jatuh dari meja dan langsung pecah berkeping-keping di lantai.**<br>
  （そのガラスのコップは机から落ちて、床の上で粉々に割れた。）
- **Dia langsung jatuh cinta pada pandangan pertama ketika bertemu gadis itu di perpustakaan.**<br>
  （図書館でその少女に出会った瞬間、彼は一目惚れして恋に落ちた。）

## 2. runtuh（崩壊する・崩落する・瓦解する）

天井、鉱山の坑道、崖、山の斜面などが **「構造を保てなくなり、ガラガラと崩れ落ちる（collapse / cave in / crumble）」** ことを指します。また、国家や帝国、独裁体制の「歴史的瓦解」にも多用されます。

- *plafon runtuh*（天井の崩落）
- *tanah runtuh / longsor*（土砂崩れ・崖崩れ）
- *runtuhnya Kekaisaran Romawi*（ローマ帝国の崩壊・瓦解）

<span class="id-example-badge">Contoh 2</span>

</div>

- **Plafon ruang kelas sekolah dasar itu tiba-tiba runtuh dan melukai beberapa murid.**<br>
  （その小学校の教室の天井が突如として崩落し、数人の児童が負傷した。）
- **Hujan lebat selama tiga hari berturut-turut menyebabkan tebing curam itu runtuh menimbun jalan.**<br>
  （3日連続の豪雨により、急峻な崖が崩れ落ちて道路を埋め尽くした。）

  （この歴史書は、1991年のソビエト連邦崩壊[瓦解]のプロセスを詳細に描き出している。）

## 3. roboh（（家屋・建物・橋が）倒壊する・ペシャンコに倒れる）

直立していた **「家屋、ビル、塀、橋などの人工建造物がへし折れて倒壊する（collapse / fall down / topple [buildings]）」** ことを指します。地震や暴風雨の被災ニュースの定番語です。

- *rumah warga roboh*（民家が倒壊する）
- *jembatan roboh diterjang banjir*（洪水に襲われて橋が崩落倒壊する）
- *tembok pagar roboh*（塀が倒れる）

## 4. tumbang（大木が根こそぎ倒れる・長寿政権が打倒される）

地面に根を張っていた **「大木や電柱が根元からドサリと倒れる（topple / fall down from roots）」** ことを指します。また、長年にわたり君臨した「独裁政権（rezim）の打倒・崩壊」や「無敗のチャンピオンの敗北」の比喩として非常に有名です。

- *pohon tumbang menghalangi jalan*（倒木が道路を塞ぐ）
- *tumbangnya rezim Orde Baru*（スハルト新秩序体制の打倒・崩壊）
- *sang juara bertahan akhirnya tumbang*（王者がついに倒された）

## ニュアンス対比シナリオ：大嵐（Badai）の爪痕

自然災害報道における使い分け：

```text
【高所からの小物の落下】
"Genteng rumah jatuh berserakan di halaman."
（屋根瓦が庭に落ちて散乱した＝jatuh）

【大木の根こそぎの倒木】
"Pohon-pohon besar di pinggir jalan tumbang menutup akses jalan raya."
（道路脇の大木が根こそぎ倒れ、主要幹道へのアクセスを遮断した＝tumbang）

【古い民家の倒壊】
"Sebuah bangunan ruko tua roboh diterjang angin puting beliung."
（竜巻の直撃を受けて、古い雑居ビル[ショップハウス]が倒壊した＝roboh）

【土砂や崖の崩落】
"Tebing bukit runtuh menimbun jalur rel kereta api antarkota."
（丘の崖が崩落して都市間鉄道の線路を埋め尽くした＝runtuh）
```

## まとめと使い分けのツボ

1. **jatuh**: 落下・転倒・物価下落（*jatuh cinta*, *harga jatuh*）。
2. **runtuh**: 天井・崖・土砂の崩落、帝国の歴史的崩壊（*runtuhnya Uni Soviet*）。
3. **roboh**: 家屋・ビル・塀・橋など直立建造物の倒壊（*rumah roboh*）。
4. **tumbang**: 大木の根こそぎの倒木（*pohon tumbang*）、独裁政権の打倒、王者の敗北。
