# C17：bertemu vs menemui vs menemukan vs berjumpa（会う・面会・発見・遭遇の語根 temu の体系）

インドネシア語の最重要語根の一つ **`temu`** からは、**`bertemu`**、**`menemui`**、**`menemukan`**、**`berjumpa`** という極めて日常的でありながら文法的な性格が全く異なる動詞群が派生します。

特に **「人に会う」と言いたいときに、なぜ `bertemu` には前置詞 `dengan` が必要なのか**、**なぜ `menemui` は前置詞なしで直接目的語をとるのか**、そして **`menemukan` はなぜ「会う」ではなく「発見する（見つける）」になるのか** という接辞規則（`ber-`, `meN-...-i`, `meN-...-kan`）の本質を完全に解き明かします。

---

## 4動詞の文法構造・機能比較表 (Sistem Derivasi Temu)

| 動詞 | 文法形態 | 目的語の要否と前置詞 | 動作の意味と性質 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **bertemu** | 自動詞（ber-） | **前置詞 `dengan` が必要** | 双方が合意または偶然に会う（meet） | *bertemu dengan teman*, *pertemuan*（会議） |
| **menemui** | 他動詞（meN-...-i） | **直接目的語をとる（前置詞不要）** | 目的を持って相手の元へ「面会・訪問」しに行く | *menemui direktur*, *menemui dokter* |
| **menemukan** | 他動詞（meN-...-kan） | **直接目的語をとる（前置詞不要）** | 紛失物や新しい真実・解決策を「見つける・発見する」 | *menemukan dompet*, *penemuan*（発明・発見） |
| **berjumpa** | 自動詞（ber-） | **前置詞 `dengan` が必要（文語的）** | 情緒的・文学的に「巡り合う・再会する」 | *sampai berjumpa lagi*, *berjumpa di perantauan* |

---

## 1. bertemu（自動詞：前置詞 dengan を伴って「会う」）

`bertemu` は接頭辞 `ber-` を持つ自動詞です。自動詞であるため、**後ろに「会う相手」を直接置くことは文法的にできず、必ず前置詞 `dengan`（〜と）を挟まなければなりません**。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'bertemu'</span>
</div>
<div class="id-example-body">

- **Kemarin saya bertemu dengan teman lama di sebuah kedai kopi.**<br>
  （昨日、私はあるカフェで旧友と[偶然]会った。）
- **Presiden Indonesia dijadwalkan bertemu dengan Perdana Menteri Jepang pekan depan.**<br>
  （インドネシア大統領は来週、日本の首相と会談する[会う]予定である。）
- **Kami sering bertemu di stasiun setiap pagi.**<br>
  （私たちは毎朝駅でよく顔を合わせる。）

</div>
</div>

> [!WARNING]
> × *Saya kemarin bertemu teman lama.* （日常会話では省略されがちですが、標準文法・検定試験では前置詞 `dengan` の脱落は誤文とみなされます）。正しくは **`bertemu dengan`** です。

---

## 2. menemui（他動詞：前置詞なしで直接「面会・訪問する」）

`menemui` は接尾辞 `-i` を持つ他動詞です。接尾辞 `-i` の「場所・対象へのアプローチ」機能により、**「明確な目的を持って、相手がいる場所へ出向いて直接会う・面談する（visit / see someone）」** という能動的な動作を表します。他動詞なので前置詞は不要です。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'menemui'</span>
</div>
<div class="id-example-body">

- **Saya datang ke kantor ini khusus untuk menemui manajer pemasaran.**<br>
  （私はマーケティングマネージャーに面会するため[会うため]にわざわざこのオフィスに来ました。）
- **Dokter sedang menemui keluarga pasien di ruang konsultasi.**<br>
  （医師は相談室で患者の家族と面談している。）
- **Polisi menemui saksi kunci untuk meminta keterangan terkait kecelakaan itu.**<br>
  （警察はその事故に関する証言を求めるため、重要証人に面会した。）

</div>
</div>

---

## 3. menemukan（他動詞：失くし物や真実を「発見する・見つける」）

`menemukan` は接尾辞 `-kan` を持つ他動詞です。接尾辞 `-kan` の使役・結果化機能により、「会う」という意味ではなく、**「探していた物、失くした物、あるいは未知の科学的真実や解決策を『発見する・見つけ出す（find / discover）』」** という全く別の重要な動詞になります。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'menemukan'</span>
</div>
<div class="id-example-body">

- **Akhirnya saya menemukan kunci rumah yang hilang di bawah sofa.**<br>
  （ついにソファーの下で失くした家の鍵を見つけた。）
- **Tim peneliti berhasil menemukan spesies katak baru di hutan Kalimantan.**<br>
  （研究チームはカリマンタンの熱帯雨林でカエルの新種を発見することに成功した。）
- **Kita harus segera menemukan solusi alternatif untuk mengatasi krisis energi.**<br>
  （私たちはエネルギー危機を克服するための代替解決策を至急見出さねばならない。）

</div>
</div>

---

## 4. berjumpa（文学的・情緒的な「出会う・再会する」）

語根 `jumpa` に `ber-` が付いた自動詞で、`bertemu` と同義ですが、より詩的・情緒的な響きを持ちます。別れの挨拶の定番 **`Sampai berjumpa lagi!`（また会う日まで＝さようなら）** で知られます。

- **Semoga kita dapat berjumpa kembali di lain kesempatan.**<br>
  （また別の機会に私たちが再会できることを願っています。）

## 文法構文の対比まとめ

| 構文パターン | 正誤 | 解説 |
| :--- | :---: | :--- |
| **Saya bertemu dengan dia.** | **◎ 正しい（BAKU）** | 自動詞 `bertemu` ＋ 前置詞 `dengan` ＋ 相手 |
| **Saya bertemu dia.** | **✕ 非標準（口語）** | 前置詞 `dengan` が脱落している |
| **Saya menemui dia.** | **◎ 正しい（BAKU）** | 他動詞 `menemui` ＋ 直接目的語（前置詞不要） |
| **Saya menemui dengan dia.** | **✕ 重大誤用** | 他動詞の直後に前置詞を挟んではならない |
| **Saya menemukan dia.** | **△ 特殊な意味** | 「捜索の末、行方不明の彼を（生き埋め・迷子から）発見した」という意味になる |

## 実戦ミニクイズ (Latihan Soal)

<summary>クイズ：空欄に最も適切な動詞・前置詞の組み合わせを補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Sekretaris menginformasikan bahwa pimpinan tidak dapat ( ... ) tamu tanpa janji temu sebelumnya.
2. Pekan lalu saya tidak sengaja ( ... ) dengan teman kuliah di sebuah toko buku.
3. Arkeolog berhasil ( ... ) fosil manusia purba berusia jutaan tahun di Jawa Tengah.

**解答・解説:**
1. **menemui**（直後に前置詞なしで直接目的語 `tamu`（来客）が来ているため、他動詞 `menemui` が正解）。
2. **bertemu**（直後に前置詞 `dengan` が続いているため、自動詞 `bertemu` が正解）。
3. **menemukan**（大昔の化石を「発見した・見つけ出した」ため他動詞 `menemukan` が正解）。

</details>

## まとめと使い分けのツボ

1. **`bertemu` の後ろには必ず `dengan`（〜と会う）**。
2. **`menemui` の後ろには前置詞なしで直接相手（〜に面会する）**。
3. **`menemukan` は「発見する・見つける」**（人を見つけるのではない）。
4. **「また会いましょう」は `Sampai berjumpa lagi!`**。
