# C26：besar vs agung vs akbar vs raya（物理的巨大・偉大・壮大・偉容の「大きい」比較）

日本語の「大きい」「巨大だ」「偉大だ」に対応するインドネシア語には、日常的な **`besar`** のほかに、宗教や国家の格式を背負った **`agung`**、**`akbar`**、**`raya`** という3つの壮大な語が存在します。

単に建物や身体のサイズが大きいのか、人格や思想が「偉大（最高峰）」なのか、数万人規模のメガイベントや大モスクを称えるのか、あるいは「大通り（jalan raya）」「祝祭日（hari raya）」のように国土全体に広がる偉容なのか、そのスケール感と語源的背景を整理しましょう。

---

## 4語のスケール・格式・語源比較表 (Dimensi Kebesaran & Keagungan)

| 単語 | 語源的背景 | 中核的ニュアンス | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **besar** | オーストロネシア固有 | **物理的サイズ・数量・影響力の大きさ** | 大きい・巨大な・重大な | *rumah besar*, *pengaruh besar*, *orang besar*（大物） |
| **agung** | サンスクリット借用 | **道徳的・精神的な「崇高さ・最高位」** | 偉大な・最高峰の・崇高な | *Mahkamah Agung*（最高裁）, *karya agung* |
| **akbar** | アラビア語借用 | **宗教的・集会的な「壮大・最大規模」** | 壮大な・最大級の・大〜 | *masjid akbar*, *rapat akbar*, *Allahu Akbar* |
| **raya** | 古マレー語固有 | **国土全体・全域に広がる「偉容・大〜」** | 主要な・大〜・祝祭の | *jalan raya*（大通り）, *hari raya*（大祝祭日） |

---

## 1. besar（最も一般的：物理的サイズ・影響力）

`besar`（対義語: *kecil*）は最も基礎的な形容詞です。
1. **物理的な体積や寸法が大きい**: *gedung besar*（大きなビル）
2. **数量や規模が大きい**: *biaya besar*（莫大な費用）
3. **影響力や重要性が高い**: *masalah besar*（重大な問題）

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'besar'</span>
</div>
<div class="id-example-body">

- **Perusahaan multinasional itu memiliki kantor cabang besar di lima benua.**<br>
  （その多国籍企業は5大陸に大きな支社を展開している。）
- **Keberhasilan proyek ini membawa keuntungan besar bagi perekonomian lokal.**<br>
  （このプロジェクトの成功は、地域経済に多大な[大きな]利益をもたらした。）
- **Pembesar（高官・要人）** / **Membesar-besarkan（大げさに言う・誇張する）**

## 2. agung（精神的・制度的な「最高位・崇高・偉大」）

`agung` は、物理的な大きさではなく、**「精神的・倫理的な崇高さ、国家制度における最高峰の権威（supreme / grand / magnificent）」** を表します。

司法の最高機関である「最高裁判所」は、インドネシア語で **`Mahkamah Agung (MA)`** と呼ばれます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'agung'</span>
</div>
<div class="id-example-body">

- **Mahkamah Agung Republik Indonesia bertugas mengadili perkara pada tingkat kasasi.**<br>
  （インドネシア共和国最高裁判所は上告審において事件を審判する責務を負う。）
- **Candi Borobudur diakui sebagai karya agung arsitektur warisan budaya dunia.**<br>
  （ボロブドゥール寺院は世界文化遺産の建築的最高傑作[karya agung＝マスターピース]として認められている。）
- **Tuhan Yang Maha Agung senantiasa melimpahkan berkah-Nya kepada umat manusia.**<br>
  （至高にして偉大なる神[Yang Maha Agung]は、常に人類にその祝福を注いでおられる。）

</div>
</div>

## 3. akbar（アラビア語由来の「最大級・壮大なメガイベント」）

アラビア語 *akbar*（最も偉大、より大きい＝*kabīr* の最上級）に由来する言葉です。イスラム教の祈りの言葉 *Allahu Akbar*（アッラーは偉大なり）で有名ですが、現代インドネシア語では **「数万人規模の大集会、巨大モスク、国家的メガイベント」** の冠詞として多用されます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'akbar'</span>
</div>
<div class="id-example-body">

- **Ratusan ribu warga memadati stadion GBK untuk menghadiri rapat akbar kampanye.**<br>
  （数十万人の市民が選挙運動の大集会[rapat akbar]に参加するためGBKスタジアムを埋め尽くした。）
- **Masjid Akbar Surabaya merupakan salah satu masjid terbesar di Asia Tenggara.**<br>
  （スラバヤ大モスク[Masjid Akbar]は東南アジア最大級のモスクの一つである。）
- **Reuni akbar alumni lintas angkatan akan digelar pada akhir pekan ini.**<br>
  （卒業生全期合同の大同窓会[reuni akbar]が今週末に開催される。）

</div>

## 4. raya（国土・公道・大祝祭の「全域的偉容」）

`raya` は古くからマレー語に定着している固有語で、名詞の後ろに置かれて **「公的な、主要な、全土に開かれた、あるいは最高の大祝祭（grand / main）」** を意味します。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 4</span>
<span class="id-example-title">Penggunaan 'raya'</span>
</div>
<div class="id-example-body">

- **Ambulans melaju kencang di jalan raya utama kota Jakarta.**<br>
  （救急車はジャカルタ市内の主要幹線道路[jalan raya＝公道・大通り]を高速で疾走した。）
- **Seluruh umat Muslim merayakan Hari Raya Idulfitri setelah sebulan penuh berpuasa.**<br>
  （すべてのイスラム教徒は丸1ヶ月の断食を終え、イードの大祝日[Hari Raya]を祝う。）
- **Kebun Raya Bogor（ボゴール植物園）**: インドネシア最古の広大な国家植物園。
- **Pasar Raya（巨大市場・百貨店）** / **Jakarta Raya（大ジャカルタ都市圏）**

</div>

## 決定的な固有名詞・コロケーション対比表

| 表現 | 最適な「大きい」 | なぜその単語か？ |
| :--- | :---: | :--- |
| **最高裁判所** | Mahkamah **Agung** | 国家司法の「最高位・崇高性」 |
| **大通り・幹線道路** | Jalan **Raya** | 公共に開かれた「全域的主要道路」 |
| **大統領選挙の大集会** | Kampanye / Rapat **Akbar** | 数万人規模の「メガ集会」 |
| **イード・レバランの祝日** | Hari **Raya** Idulfitri | 国民的・宗教的な「大祝日」 |
| **世界遺産の傑作** | Karya **Agung** | 芸術・人類遺産の「マスターピース」 |
| **大きな家・大きな車** | Rumah / Mobil **Besar** | 物理的な寸法・サイズ |

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に besar, agung, akbar, raya を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Pengendara sepeda motor dilarang melintas di jalan ( ... ) antarprovinsi tersebut.
2. Putusan pengadilan tingkat kasasi yang berkekuatan hukum tetap dikeluarkan oleh Mahkamah ( ... ).
3. Menjelang pemilihan umum, partai politik menggelar apel ( ... ) yang dihadiri puluhan ribu kader.

**解答・解説:**
1. **raya**（州間幹線道路・主要大通りのため `jalan raya` が正解）。
2. **Agung**（司法の最高裁機関であるため固有名詞として `Mahkamah Agung` が正解）。
3. **akbar**（何万人もの党員が動員されたメガ規模の大集会・総決起大会のため `apel akbar`［または *rapat akbar*］が正解）。

</details>

## まとめと使い分けのツボ

1. **物理的サイズ、金額、影響力は `besar`**。
2. **最高裁、名作マスターピース、崇高な理念は `agung`**（*Mahkamah Agung*）。
3. **大集会、巨大モスク、メガイベントは `akbar`**（*rapat akbar*）。
4. **大通り、大祝祭、大都市圏は名詞の後ろに `raya`**（*jalan raya, hari raya*）。
