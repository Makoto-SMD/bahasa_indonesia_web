# C01：tinggal vs diam（住む・滞在する・黙るの境界線）

インドネシア語を学ぶ日本人が日常会話や自己紹介で最初に出会う類義語ペアが **`tinggal`** と **`diam`** です。

日本語の辞書を引くと、どちらにも「住む」「居る」という訳語が当てられているため、「*Saya tinggal di Jakarta.* と *Saya diam di Jakarta.* は同じなのか？」という疑問が生じます。しかし、インドネシアの現代標準語において、この2語の間には**明確なニュアンスの差、多義性の違い、そして地域方言（マレーシア語やスマトラ方言との差）**が存在します。

---

## 比較対照サマリー表 (Tabel Perbandingan)

| 単語 | 基本的ニュアンス | 主な語義 | 代表的なコロケーション |
| :--- | :--- | :--- | :--- |
| **tinggal** | **「居住する」「留まる」「残る」**<br>生活の拠点を置く標準的表現 | 1. 居住する（住んでいる）<br>2. 残る・留まる（残存）<br>3. 〜するだけでよい（tinggal + V） | *tinggal di apartemen*, *waktu tinggal sedikit*, *tinggal tanda tangan* |
| **diam** | **「静止する」「沈黙する」「じっとする」**<br>動きや音がない状態の維持 | 1. 黙る・口を利かない<br>2. じっとしている・動かない<br>3. 住む（口語・マレー方言的） | *diam saja*, *jangan bergerak diam di tempat*, *pendiam*（無口な人） |

---

## 1. tinggal の本質と使い方

`tinggal` の中核イメージは **「ある場所に生活や痕跡が定着して残ること」** です。

### (1) 「住む・居住する」（最も標準的な用法）
住所や生活拠点、滞在先を述べる場合、ジャカルタをはじめとするインドネシア全土の現代標準語（Bahasa Baku）では常に **`tinggal`** を用います。

### (2) 「残る・残留する」
時間、数量、あるいは人が「その場に残る」ことを表します。
- **Waktu yang tersisa tinggal lima menit.**（残された時間はあと5分だけだ。）
- **Dia tinggal di kantor sampai larut malam.**（彼は深夜までオフィスに残った。）

### (3) 「〜するだけでよい・あとは〜するばかりだ」
助動詞的に動詞の前に置かれ、準備が整って「あとは〜するだけ」という手軽さを表します。
- **Semua dokumen sudah lengkap, tinggal ditandatangani.**（書類はすべて揃いました、あとはサインするだけです。）

## 2. diam の本質と使い方

`diam` の中核イメージは **「音や動きを止めて、静止状態を維持すること」** です。

### (1) 「黙る・沈黙する」
声を出さずに静かにしている状態を表します。

- **Mengapa kamu hanya diam saja sejak rapat dimulai?**<br>
  （なぜ会議が始まってからずっと黙ったままなのですか？）
- **Lebih baik diam daripada berbicara hal yang menyakiti orang lain.**<br>
  （他人を傷つけることを言うくらいなら、黙っているほうがましだ。）

### (2) 「じっとしている・静止する」
身体を動かさずにその場に留まる動作です。
- **Diam di situ! Jangan bergerak!**（そこでじっとしていろ！動くな！）

### (3) 「住む」としての用法と地域差（注意点！）
マレーシア語（Bahasa Melayu）や、インドネシアのスマトラ島、リアウ諸島、カリマンタン島などマレー語の影響が強い地域では、`diam` を「住む（*Saya diam di Medan.*）」という意味で普通に使います。

しかし、**ジャカルタやジャワ島中心の現代標準インドネシア語では、「住む」に `diam` を使うと古風、または方言的・不自然**に聞こえます。標準的な公の場やビジネスでは、「住む」には必ず **`tinggal`** を使います。

## 派生語による決定的な違い

語根に接辞が付いた派生語を比較すると、両者の意味の方向性の違いが一目瞭然になります。

| 語根 | 派生語 | 意味 | 例文 |
| :--- | :--- | :--- | :--- |
| **tinggal** | **tempat tinggal** | 住居・現住所 | *Di mana tempat tinggal Anda?* |
| | **meninggal (dunia)** | 逝去する・亡くなる | *Kakeknya meninggal dunia kemarin.* |
| | **meninggalkan** | 去る・残す・置き去りにする | *Ia meninggalkan pesan penting.* |
| | **ketinggalan** | 取り残される・置き忘れる | *Dompet saya ketinggalan di rumah.* |
| **diam** | **pendiam** | 無口な人・物静かな性格 | *Adik saya seorang pendiam.* |
| | **mendiamkan** | 放置する・黙殺する・冷ます | *Jangan mendiamkan masalah ini.* |
| | **diam-diam** | こっそりと・密かに（副詞） | *Ia diam-diam belajar bahasa Jepang.* |

## 実戦ミニクイズ (Latihan Soal)

**問題:**
1. Anak itu sangat ( ... ), ia jarang sekali berbicara dengan teman sekelasnya.
2. Kami sekeluarga sudah lama ( ... ) di perumahan ini.
3. Rencana ini sudah matang, ( ... ) menunggu persetujuan direktur.

**解答・解説:**
1. **pendiam**（無口な性格。語根は `diam`）。
2. **tinggal**（生活拠点として「住んでいる」ため `tinggal` が標準）。
3. **tinggal**（「〜するだけでよい」という残余条件を表すため `tinggal`）。

## まとめと使い分けのツボ

1. **自己紹介や住所を聞くときは 100% `tinggal` を使う**（*Saya tinggal di Tokyo.*）。
2. **`diam` は「声を出さない（黙る）」または「動かない（じっとする）」が本来の意味**。
3. **派生語 `diam-diam`（こっそり）や `pendiam`（無口）は日常会話の必須単語**。
