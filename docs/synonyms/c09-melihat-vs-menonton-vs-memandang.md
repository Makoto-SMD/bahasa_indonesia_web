# C09：melihat vs menonton vs memandang vs menatap（視線・意識・鑑賞の「見る」徹底比較）

日本語の「見る」には、目に入る（see）、意識して見る（look）、楽しんで鑑賞する（watch）、遠くを眺める（view/gaze）、じっと見つめる（stare）など多くのグラデーションがあります。

インドネシア語でも、**`melihat`**、**`menonton`**、**`memandang`**、**`menatap`** の4動詞が視線の強さや鑑賞の目的に応じて使い分けられます。映画館で何をするのか、夜空の星をどう見るのか、怒って相手をどう睨むのか、それぞれの正確な使い分けを整理しましょう。

---

## 4動詞の視線強度・目的比較表 (Derajat Ketajaman Pandangan)

| 動詞（語根） | 視線の性質と集中度 | 主な対象 | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **melihat (lihat)** | 「**一般的な視覚・目撃**」<br>無意識〜意識的な視覚全般（see / look） | あらゆる人・物・出来事 | 見る・目撃する・会う | *melihat pemandangan*, *melihat kecelakaan* |
| **menonton (tonton)** | 「**娯楽・ショーの鑑賞**」<br>動く映像やパフォーマンスを楽しむ（watch） | 映画、テレビ、試合、劇 | 観る・鑑賞する・観戦する | *menonton film*, *menonton sepak bola di TV* |
| **memandang (pandang)** | 「**広角的な眺望・見渡す**」<br>風景や人物を情緒的・客観的に眺める | 風景、空、水平線、評価 | 眺める・見晴らす・見なす | *memandang laut*, *memandang remeh*（見下す） |
| **menatap (tatap)** | 「**焦点的凝視・直視**」<br>相手の目や一点をじっと見つめる（stare） | 相手の目、顔、写真、一点 | 見つめる・凝視する・直視する | *menatap mata lawan*, *tatap muka*（対面） |

---

## 1. melihat（最も基本の「見る」）

`melihat` は視覚全般を網羅する動詞です。単に「目に映る」「目撃する」「確かめる」など、英語の *see* や *look at* に相当します。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'melihat'</span>
</div>
<div class="id-example-body">

- **Saya melihat dia sedang berjalan sendirian di pusat perbelanjaan.**<br>
  （私は彼がショッピングモールを一人で歩いているのを[偶然]見た。）
- **Coba lihat grafik penjualan ini, bulan ini ada peningkatan signifikan.**<br>
  （この売上グラフを見てごらん、今月は顕著な伸びがある。）
- **Dari lantai tertinggi gedung ini, kita bisa melihat seluruh kota Jakarta.**<br>
  （このビルの最上階から、ジャカルタの街全体を見ることができる。）

</div>
</div>

## 2. menonton（娯楽・パフォーマンスを「観る」）

`menonton` は、映画、演劇、スポーツの試合、YouTube動画、テレビ番組など、「**エンターテインメントや動的な催し物を鑑賞する**」 場合に限定して使われます（英語の *watch a show*）。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'menonton'</span>
</div>
<div class="id-example-body">

- **Malam minggu kemarin kami menonton film laga terbaru di bioskop.**<br>
  （先週の土曜の夜、私たちは映画館で最新のアクション映画を観た。）
- **Ribuan suporter memadati stadion untuk menonton pertandingan final.**<br>
  （決勝戦を観戦するため、何千人ものサポーターがスタジアムを埋め尽くした。）
- **Anak-anak dilarang menonton konten video yang mengandung kekerasan.**<br>
  （子どもたちが暴力描写を含む動画コンテンツを視聴することは禁止されている。）

</div>
</div>

> [!WARNING]
> 「映画を見る」を *melihat film* と言うと、「映画のポスターやチケットが目に入った」ような奇妙なニュアンスになります。作品を鑑賞するときは必ず **`menonton film`** です。

---

## 3. memandang（遠くの景色や人を「眺める」）

`memandang` は、「**視界を広く取って、風景や情景、あるいは人物を感慨深く眺める**」 動作です。また比喩的に「物事をどう捉えるか、どう評価するか（view as）」という意味にも発展します。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'memandang'</span>
</div>
<div class="id-example-body">

- **Sambil minum kopi, kakek duduk di teras memandang matahari terbit.**<br>
  （コーヒーを飲みながら、祖父はテラスに座って日の出を眺めていた。）
- **Jangan memandang enteng kemampuan lawan sebelum bertanding.**<br>
  （試合前に相手の実力を侮って[軽く眺めて]はならない。）
- **Dari sudut pandang sosiologi, fenomena ini sangat menarik.**<br>
  （社会学的な視点[sudut pandang]から見ると、この現象は非常に興味深い。）

</div>
</div>

---

## 4. menatap（視線を固定して「見つめる・凝視する」）

`menatap` は、「**視線を一点、特に相手の目や顔に集中させて、真剣に・じっと見つめる（gaze / stare）**」 動作です。愛、怒り、決意、疑念などの強い感情が伴います。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 4</span>
<span class="id-example-title">Penggunaan 'menatap'</span>
</div>
<div class="id-example-body">

- **Dia menatap tajam mata saya saat menyampaikan kabar duka tersebut.**<br>
  （彼はその悲報を伝える際、私の目を鋭くじっと見つめた。）
- **Ibu menatap foto mendiang ayahnya dengan penuh rasa rindu.**<br>
  （母は深い恋しさを込めて、亡き父の写真をじっと見つめていた。）
- **Kuliah tatap muka (luring) telah kembali diberlakukan secara penuh.**<br>
  （対面授業[tatap muka]が全面再開された。）

</div>
</div>

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に melihat, menonton, memandang, menatap を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Kami berencana pergi ke bioskop malam ini untuk ( ... ) film horor Indonesia.
2. Gadis itu tersipu malu ketika pemuda tampan itu ( ... ) wajahnya lekat-lekat.
3. Dari puncak bukit ini kita bisa ( ... ) hamparan sawah hijau yang membentang luas.
4. Kemarin saya tidak sengaja ( ... ) dompetnya terjatuh di jalan raya.

**解答・解説:**
1. **menonton**（映画館でホラー映画を「鑑賞する」ため `menonton`）。
2. **menatap**（顔を間近でじっと「見つめられた」ため `menatap`）。
3. **memandang**（または `melihat` も可能ですが、広大な田園風景を情緒的に「見晴らす・眺める」文脈では `memandang` が最も美しい）。
4. **melihat**（財布が落ちるのを偶然「目撃した・見かけた」ため `melihat`）。

</details>

---

## まとめと使い分けのツボ

1. **目に入る、日常的な確認は `melihat`**。
2. **映画、ドラマ、サッカー観戦、YouTube視聴は `menonton`**。
3. **景色をゆったり眺める、物事を評価・見なすのは `memandang`**（視点＝*sudut pandang*）。
4. **相手の目をじっと凝視する、対面は `menatap`**（対面＝*tatap muka*）。
