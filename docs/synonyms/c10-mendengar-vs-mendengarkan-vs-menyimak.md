# C10：mendengar vs mendengarkan vs menyimak（聞こえる・聴く・傾聴・精聴の集中度の違い）

日本語の「聞く」と「聴く」の違いと同様に、インドネシア語でも聴覚の意識レベルに応じて **`mendengar`**、**`mendengarkan`**、**`menyimak`** の3動詞を使い分けます。

単に音が耳に入ってきたのか（hear）、音楽や忠告を自発的に聴いているのか（listen）、それとも学術講義やニュースの要点を一言一句逃さず理解・分析しようと傾聴しているのか（comprehend/pay close attention）という**意識の集中度の違い**をマスターしましょう。

---

## 3動詞の聴取集中度ピラミッド (Tingkat Konsentrasi Menyimak)

| 動詞（語根） | 意識の集中度 | 動作の本質（英語） | 日本語の対応 | 代表例 |
| :--- | :---: | :--- | :--- | :--- |
| **mendengar (dengar)** | **★☆☆（受動的）** | 耳に音が入ってくる、噂を耳にする（hear） | 聞こえる・耳にする・聞く | *mendengar suara aneh*, *mendengar kabar* |
| **mendengarkan (dengar)** | **★★☆（自発的）** | 意識を向けて音や人の言葉を聴く（listen to） | 聴く・耳を傾ける・従う | *mendengarkan musik*, *mendengarkan nasihat* |
| **menyimak (simak)** | **★★★（分析的）** | 内容を深く理解・批判・精査しながら集中して聴く（comprehend / examine） | 傾聴する・精聴する・じっくり拝聴する | *menyimak pidato presiden*, *menyimak penjelasan guru* |

---

## 1. mendengar（受動的に「聞こえる・耳にする」）

`mendengar` は、特別な意志を持たなくても 「**自然に耳に音や声が入ってくる状態**」 です。また「噂やニュースを風の便りに耳にする」場合にも使われます。

<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'mendengar'</span>
</div>
<div class="id-example-body">

- **Apakah Anda mendengar suara dentuman keras di luar tadi malam?**<br>
  （昨夜、外で激しい爆発音が聞こえましたか？）
- **Saya baru mendengar kabar bahwa manajer kita akan dipindahtugaskan ke Surabaya.**<br>
  （部長がスラバヤへ異動になるという知らせを今耳にしたばかりです。）
- **Kakek sudah agak kurang mendengar karena faktor usia.**<br>
  （祖父は高齢のため、少し耳が遠くなっている[聞こえが悪くなっている]。）

</div>
</div>

## 2. mendengarkan（意志を持って「耳を傾ける・聴く」）

接尾辞 `-kan` が付いた `mendengarkan` は、対象に注意を向けて 「**自発的に耳を傾ける（listen to）**」 動作です。音楽を聴く、ラジオを聴く、親や医師の忠告に従って耳を傾ける場合に使います。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'mendengarkan'</span>
</div>
<div class="id-example-body">

- **Setiap pagi ia suka mendengarkan musik klasik sambil sarapan.**<br>
  （毎朝、彼は朝食を取りながらクラシック音楽を聴くのが好きだ。）
- **Tolong dengarkan baik-baik apa yang akan saya sampaikan ini.**<br>
  （私が今からお話しすることを、よく聴いてください。）
- **Anak itu tidak pernah mendengarkan nasihat orang tuanya.**<br>
  （あの子は親の忠告に決して耳を傾けない[従わない]。）

</div>
</div>

## 3. menyimak（内容を吟味しながら「傾聴・精聴する」）

`menyimak` は、語根 `simak`（注意深く見守る・吟味する）から派生した高度な動詞です。単に音を拾うだけでなく、「**話の論理、要点、細部を頭の中で咀嚼・分析しながら、一言一句集中して聴く（pay close attention to / scrutinize）**」 という学術的・知的な聴取動作です。

UKBIのリスニング問題の指示文には、必ずこの `menyimak` が使われます（例: *Simaklah rekaman audio berikut ini!*「以下の音声を精聴しなさい」）。

<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'menyimak'</span>

- **Para siswa diminta menyimak pemaparan materi dari narasumber secara saksama.**<br>
  （生徒たちは講師からの講義内容の説明をじっくり傾聴[精聴]するよう求められた。）
- **Setelah menyimak pidato kenegaraan presiden, para analis memberikan tanggapan.**<br>
  （大統領の施政方針演説を傾聴・精査した後、アナリストたちは見解を発表した。）
- **Saya sedang menyimak perdebatan di parlemen melalui siaran langsung.**<br>
  （私は生中継を通じて議会での激しい議論を注視・傾聴している。）

## 3動詞の集中度比較シナリオ（大学の講義室）

1. **Mahasiswa mendengar suara sirine ambulans dari luar jendela kampus.**<br>
   → 窓の外から救急車のサイレンの音が「耳に入ってくる・聞こえる」（自然な聴覚）。
2. **Mahasiswa mendengarkan dosen berbicara di depan kelas.**<br>
   → 教室の前で教授が話す言葉に「耳を傾けて聴いている」（通常の聴講）。
3. **Mahasiswa menyimak argumen rumit tentang teori ekonomi makro untuk dicatat.**<br>
   → ノートを取るためにマクロ経済理論の複雑な論理展開を「一言一句分析しながら傾聴・精聴している」（最高度の集中）。

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に mendengar, mendengarkan, menyimak を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Sebelum menjawab soal ujian UKBI, para peserta wajib ( ... ) audio percakapan dengan cermat.
2. Saat sedang membaca buku di kamar, tiba-tiba saya ( ... ) suara langkah kaki mencurigakan.
3. Hobi saya saat akhir pekan adalah duduk bersantai sambil ( ... ) siaran radio lagu-lagu lawas.

**解答・解説:**
1. **menyimak**（試験問題に答えるため、会話音声を注意深く「精聴・傾聴する」ので `menyimak` が最適）。
2. **mendengar**（読書中にふと足音が「聞こえてきた」受動的聴覚なので `mendengar`）。
3. **mendengarkan**（趣味としてラジオ放送の古い音楽を「聴いて楽しんでいる」ので `mendengarkan`）。

</details>

## まとめと使い分けのツボ

1. **自然に耳に入る、噂を耳にするなら `mendengar`**（hear）。
2. **音楽やラジオを聴く、忠告を聞き入れるなら `mendengarkan`**（listen to）。
3. **授業、試験、大統領演説をメモを取りながら真剣に傾聴・精聴するなら `menyimak`**（UKBI必修動詞）。
