# C31：berbicara vs berkata vs bercakap vs mengobrol（話す・言う・対話・おしゃべりの会話動詞比較）

人間が言葉を発する行為全般を表す日本語の「話す」「言う」「しゃべる」。インドネシア語では、発話の機能（言語能力なのか、発言内容の提示なのか、双方向の会話なのか、気楽な駄弁りなのか）に応じて **`berbicara`**、**`berkata`**、**`bercakap`**、**`mengobrol`** が厳格に使い分けられます。

公式スピーチから、発言の引用（直説法・間接法）、カフェでの友達同士の雑談（ngobrol）に至るまで、会話動詞の正確な使い分けを整理しましょう。

---

## 4動詞の発話機能・会話形態比較表 (Fungsi & Konteks Komunikasi)

| 動詞（語根） | 発話の機能と性質 | 文体・レジスター | 日本語の対応 | 代表例 |
| :--- | :--- | :--- | :--- | :--- |
| **berbicara (bicara)** | **言語能力・公式発言・一方/双方** | 標準・フォーマル | 話す・言語を操る・演説する | *berbicara bahasa Indonesia*, *pembicara* |
| **berkata (kata)** | **具体的な語句・発言内容を口にする** | 直接引用・間接話法で多用 | 言う・述べる・口にする | *berkata jujur*, *berkata bahwa...* |
| **bercakap (cakap)** | **双方向の言葉のキャッチボール** | やや文語的（日常は ngomong） | 対話する・言葉を交わす | *bercakap-cakap*, *percakapan*（会話） |
| **mengobrol (obrol)** | **気楽な世間話・雑談・おしゃべり** | 口語・カジュアル（親しい間柄） | 雑談する・おしゃべりする・駄弁る | *mengobrol santai*, *obrolan ringan* |

---

## 1. berbicara（言語を話す・公式スピーチ・発言する）

`berbicara` は最も標準的で包括的な「話す（speak / talk）」です。
1. **ある言語を操る能力**: *Bisa berbicara bahasa Indonesia?*（インドネシア語が話せますか？）
2. **公式な場での発言・演説**: *pembicara seminar*（セミナーの講演者）

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 1</span>
<span class="id-example-title">Penggunaan 'berbicara'</span>
</div>
<div class="id-example-body">

- **Presiden berbicara di depan forum internasional tentang krisis iklim global.**<br>
  （大統領は地球規模の気候危機について国際フォーラムの前で演説した[話した]。）
- **Mari kita berbicara empat mata untuk menyelesaikan kesalahpahaman ini.**<br>
  （この誤解を解決するため、サシで[二人だけで＝empat mata]腹を割って話しましょう。）
- **Dia terlalu pemalu untuk berbicara di depan umum.**<br>
  （彼は人前で話すには内気すぎる。）

</div>
</div>

## 2. berkata（言葉・発言内容を口にして「言う」）

`berkata` は、語根 `kata`（言葉・単語）から派生した動詞で、「**具体的な内容を言葉にして言う、述べる（say / utter）**」 動作です。直接話法（鍵括弧の前の発言動詞）や間接話法で極めて頻繁に使われます。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 2</span>
<span class="id-example-title">Penggunaan 'berkata'</span>
</div>
<div class="id-example-body">

- **Ayah selalu berpesan agar kita senantiasa berkata jujur dalam situasi apa pun.**<br>
  （いかなる状況でも常に正直なことを言うよう、父はいつも戒めていた。）
- **Ia berkata kepada saya, "Tolong tunggu di sini sebentar."**<br>
  （彼は私に「ここで少し待ってください」と言った。）
- **Bolehkah saya berkata sepatah dua patah kata sebelum acara ditutup?**<br>
  （閉会前にお祝いの言葉を一言二言[sepatah dua patah kata]申し上げてもよろしいですか？）

</div>
</div>

## 3. bercakap（双方向で言葉を交わす「対話・会話」）

`bercakap`（重ね言葉の **`bercakap-cakap`** で多用）は、2人以上の人間が 「**双方向で言葉をキャッチボールする（converse / chat）**」 ことを表します。教科書のタイトル「日常会話（*Percakapan Sehari-hari*）」の基幹単語です。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 3</span>
<span class="id-example-title">Penggunaan 'bercakap'</span>
</div>
<div class="id-example-body">

- **Mereka duduk di teras sambil bercakap-cakap mengenai masa depan anak-anak.**<br>
  （彼らはテラスに座り、子どもたちの未来について言葉を交わして[対話して]いた。）
- **Buku ini memuat latihan percakapan bahasa Indonesia untuk tingkat pemula.**<br>
  （この本は初級者向けのインドネシア語会話[percakapan]練習を収録している。）

</div>
</div>

## 4. mengobrol（気楽な雑談・おしゃべり・世間話）

`mengobrol`（口語では **`ngobrol`**）は、堅苦しいビジネスや議論ではなく、「**カフェや休憩室で、取り留めのない話題をリラックスして楽しむおしゃべり（chit-chat / hanging out）**」 です。親しい友人や同僚との交流を象徴する語です。

<div class="id-example">
<div class="id-example-header">
<span class="id-example-badge">Contoh 4</span>
<span class="id-example-title">Penggunaan 'mengobrol'</span>
</div>
<div class="id-example-body">

- **Kami asyik mengobrol di kedai kopi hingga tidak terasa waktu sudah larut malam.**<br>
  （私たちはカフェでおしゃべりに夢中になり、気づけばもう深夜になっていた。）
- **Daripada melamun sendirian, lebih baik kita mengobrol santai di kantin.**<br>
  （一人でぼんやりしているくらいなら、学食で気楽に雑談でもしようよ。）
- **Obrolan（名詞: おしゃべり・雑談）**: *Obrolan hangat di malam minggu.*（土曜の夜の温かいおしゃべり。）

## 場面別の使い分け対比表

| 場面 | 最適な動詞 | 理由 |
| :--- | :---: | :--- |
| **外国語を操る（言語能力）** | **berbicara** | *Bisa berbicara bahasa Jepang.* |
| 「**正直に言いなさい**」 | **berkata** | 具体的な発話内容（*Berkata jujur.*） |
| **教科書の「会話文」** | **percakapan (cakap)** | 双方向の言葉のやり取り |
| **カフェで友達とダベる** | **mengobrol / ngobrol** | リラックスした無目的の雑談 |
| **セミナーの講師・演説者** | **pembicara (bicara)** | 公の場での発信者 |

## 実戦ミニクイズ (Latihan Soal)

<details class="id-quiz">
<summary>クイズ：空欄に berbicara, berkata, percakapan, mengobrol を補いなさい（クリックで解説を表示）</summary>

**問題:**
1. Sebelum mengambil kesimpulan, hakim meminta kedua belah pihak untuk ( ... ) secara terbuka.
2. Kami menghabiskan waktu sore dengan duduk ( ... ) santai di pinggir danau.
3. Anak yang baik selalu ( ... ) sopan santun kepada orang yang lebih tua.

**解答・解説:**
1. **berbicara**（双方がオープンに「意見を述べる・話し合う」公式審理の場のため `berbicara` が最適）。
2. **mengobrol**（湖のほとりでリラックスして「雑談・おしゃべりして」過ごしたため `mengobrol`［または *bercakap-cakap*］が正解）。
3. **berkata**（年上の人に対して礼儀正しい言葉を「口にする・言う」ため `berkata sopan santun` が正解）。

</details>

## まとめと使い分けのツボ

1. **言語を話す、公式スピーチ、話し合いは `berbicara`**（講演者＝*pembicara*）。
2. **具体的な言葉を口にする、引用は `berkata`**（正直に言う＝*berkata jujur*）。
3. **双方向の対話、会話練習は `bercakap / percakapan`**。
4. **カフェや飲み会での気楽な雑談・おしゃべりは `mengobrol / ngobrol`**。
