本記事は、ジャカルタで働く会社員の典型的な平日の1日を描いた初級者向け読解テキストです。

## 2. インドネシア語本文 (Teks Bacaan)

<div class="id-example" markdown>

Nama saya Budi. Saya tinggal di Jakarta Selatan dan bekerja sebagai staf pemasaran di sebuah perusahaan swasta di pusat kota. Setiap hari kerja, saya biasanya bangun pada pukul lima pagi. Setelah mandi dan sarapan roti isi serta segelas teh hangat, saya bersiap-siap untuk berangkat ke kantor.

Perjalanan dari rumah ke kantor membutuhkan waktu sekitar satu jam. Saya biasanya naik kereta komuter (KRL) dari stasiun terdekat. Suasana di dalam kereta pada pagi hari selalu sangat ramai dan padat oleh para pekerja. Jika kereta terlambat, saya memesan ojek daring lewat aplikasi di ponsel agar tidak terlambat masuk kantor.

Saya mulai bekerja pada pukul delapan pagi. Sebelum memulai tugas, saya dan rekan-rekan kerja menyapa satu sama lain dan minum kopi bersama di dapur kantor. Pada jam makan siang, kami biasanya makan di warung makan dekat kantor. Makanan favorit saya adalah nasi rames dengan ayam goreng dan sambal terasi yang pedas.

Pekerjaan selesai pada pukul lima sore. Terkadang hujan deras tiba-tiba turun di Jakarta pada sore hari, sehingga jalanan menjadi macet. Saya harus sabar menunggu antrean transportasi umum. Meskipun lelah setelah seharian bekerja keras, saya merasa senang bisa pulang ke rumah dan berkumpul kembali bersama keluarga.

</div>

<div class="id-meaning">

</div>

</div>

- **読解ポイント**:
  - `bekerja sebagai ~`: 「〜として働く」。身分や職業を表す前置詞 `sebagai` の基本用例です。

  - `setelah ~`: 「〜の後に」。時間的順序を表す代表的な接続詞です。

## 5. 文法・構文の徹底解説

### ① 乗り物に乗る表現：`naik + 乗り物`
インドネシア語では「電車に乗る」「車に乗る」「バイクに乗る」など、あらゆる交通機関への乗車に動詞 **`naik`**（上がる・登る）を使います。

- `naik kereta`（電車に乗る）
- `naik ojek`（バイクタクシーに乗る）
- `naik bus`（バスに乗る）

### ② 目的と結果の接続詞：`agar` と `sehingga`
文の因果関係をつなぐ頻出接続詞です：
- **`agar` / `supaya`**（〜するために、〜するように）：目的を表します。
  - *Saya memesan ojek daring agar tidak terlambat.*（遅刻しないようにバイクタクシーを頼む）
- **`sehingga`**（その結果〜、そのため〜）：客観的な結果を表します。
  - *Hujan deras turun, sehingga jalanan menjadi macet.*（大雨が降り、そのため道路が渋滞した）

### ③ 最上級を表す接頭辞 `ter-`
形容詞の前に `ter-` をつけると、「最も〜（英語の -est / most）」という最上級の意味になります。
- `dekat`（近い） → **`terdekat`**（最も近い、最寄りの）
- `besar`（大きい） → **`terbesar`**（最大の）
- `baik`（良い） → **`terbaik`**（最高の）

## 7. 背景知識コラム：ジャカルタの通勤と「Ojek Daring」

ジャカルタ首都圏（Jabodetabek）は世界屈指の交通渋滞都市として知られています。多くの通勤者が郊外（ボゴール、デポック、タンゲラン、ブカシ）から都心へ向かうため、朝夕のKRL通勤電車は超満員となります。

また、駅から会社までの「ラストワンマイル」を埋める足として欠かせないのが **ojek daring（オンラインバイクタクシー）** です。大手配車アプリ「Gojek」や「Grab」を使って手軽に呼ぶことができ、車の間を縫って走れるため、渋滞時の強い味方として市民の生活に深く定着しています。
