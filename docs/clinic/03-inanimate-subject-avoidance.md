# 【誤用克服】無生物主語の壁！「この薬を飲めば治る」をインドネシア語の語順で表現する

日本語は人間を主語にして「この薬を飲んだら治りますよ」「この道をまっすぐ行けば駅に着きますよ」と条件節（〜たら/〜れば）で迂回して表現する傾向が強いです。一方、インドネシア語は英語と同様に「無生物（薬・道・ニュース）を主語にして直接述語を置く」方が圧倒的に簡潔で自然です。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**この薬を飲めば頭痛が治るよ。**」
- ❌ **不自然な直訳**: `Kalau kamu minum obat ini, sakit kepala kamu sembuh.`
- ⭕ **自然なネイティブ表現**: `Obat ini menyembuhkan sakit kepala.`
- **病因分析**: 人間を主語にして「Kalau kamu...」と長く回りくどく言うより、「Obat ini（この薬が）menyembuhkan sakit kepala（頭痛を治す）」と無生物主語にする方がネイティブらしく知的です。

### 症例 2: 「**この道を行けば駅に着きます。**」
- ❌ **不自然な直訳**: `Kalau lewat jalan ini, kamu tiba di stasiun.`
- ⭕ **自然なネイティブ表現**: `Jalan ini menuju ke stasiun.`
- **病因分析**: 「Jalan ini menuju ke stasiun（この道が駅に通じている）」と表現するのが最も簡潔です。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「この薬を飲めば風邪が治る」を最も自然かつ簡潔に言うと？**

- 1. Obat ini menyembuhkan flu. (正解)
- 2. Kalau minum obat ini kamu sembuh flu.
- 3. Obat ini kamu minum maka flu sembuh.
- 4. Flu sembuh jika kamu minum obat ini.

**Q2. 「この道を行けば駅に着く」のスマートな表現は？**

- 1. Jalan ini menuju ke stasiun. (正解)
- 2. Kalau kamu jalan di jalan ini sampai stasiun.
- 3. Kamu tiba di stasiun jika jalan ini.
- 4. Jalan ini kamu pakai ke stasiun.

**Q3. 無生物主語構文の大きなメリットは？**

- 1. 「もし〜なら」と仮定節を重ねず、主語と動詞で簡潔・明快に表現できる (正解)
- 2. 必ず受動態にできる
- 3. 主語を省略できる
- 4. 文末詞を増やせる
