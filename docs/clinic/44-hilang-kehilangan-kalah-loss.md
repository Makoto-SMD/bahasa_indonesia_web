# 【誤用克服】「失う」の hilang, kehilangan, kalah（敗北）の他動詞・自動詞混同

日本語の「なくす」「うしなう」「まける」の混同により、財布を無くした時に saya hilang（私自身が行方不明になった）と言ってしまったり、試合で負ける（kalah）と物を紛失する（kehilangan）を取り違えるトラブルを解決します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**「財布を無くしてしまいました」と警察に届ける時。**」
- ❌ **不自然な直訳**: `Saya hilang dompet.`
- ⭕ **自然なネイティブ表現**: `Saya kehilangan dompet. / Dompet saya hilang.`
- **病因分析**: hilang は自動詞で「消える・紛失する」です。主語に人を置いて Saya hilang と言うと「私自身が行方不明になりました・遭難しました」という意味になります。人が主語なら被害構文の kehilangan（〜を失う）、または Dompet saya hilang（財布が紛失した）とします。

### 症例 2: 「**「昨日のサッカーの試合で負けてしまった」と言う時。**」
- ❌ **不自然な直訳**: `Tim kami hilang dalam pertandingan kemarin.`
- ⭕ **自然なネイティブ表現**: `Tim kami kalah dalam pertandingan kemarin.`
- **病因分析**: 勝負や試合に「負ける」のは kalah です。hilang を使うと「試合中にチーム全員が神隠しに遭って行方不明になった」ような意味不明な文になってしまいます。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。
