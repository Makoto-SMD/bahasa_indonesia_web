# 【誤用克服】「できる」の使い分けミス（能力の mampu, 状況の bisa, 許可の dapat）

日本語の「できる」には、①個人の肉体的・経済的能力（mampu / sanggup）、②一般的な状況可能（bisa）、③公的・法的許可（dapat / boleh）の異なる次元があります。何でも bisa で済ませる癖を脱却し、正確なニュアンスを身につけます。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**彼は家を買う経済的余裕がない（買えない）。**」
- ❌ **不自然な直訳**: `Dia tidak bisa beli rumah.`
- ⭕ **自然なネイティブ表現**: `Dia tidak mampu membeli rumah.`
- **病因分析**: お金や体力の限界で「〜できない」場合は mampu を使います。tidak bisa だと「買い方を知らない」「物理的に禁止されている」ようにも聞こえます。

### 症例 2: 「**ここは駐車可能です（法・規則の許可）。**」
- ❌ **不自然な直訳**: `Bisa parkir di sini.`
- ⭕ **自然なネイティブ表現**: `Dapat parkir di sini. / Boleh parkir di sini.`
- **病因分析**: 公的な案内や許可には dapat / boleh が格調高く適合します。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「家を買う金銭的余裕がある」を表す最適な助動詞は？**

- 1. mampu (正解)
- 2. bisa
- 3. boleh
- 4. boleh jadi

**Q2. 「体力・気力的に耐えきれない」を表す言葉は？**

- 1. tidak sanggup (正解)
- 2. tidak bisa
- 3. tidak boleh
- 4. tidak dapat

**Q3. 公式文書で「〜することが可能です」を表す格調高い語は？**

- 1. dapat (正解)
- 2. bisa
- 3. sanggup
- 4. sempat
