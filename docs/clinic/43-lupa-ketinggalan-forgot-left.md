# 【誤用克服】「忘れる」の lupa（記憶の喪失）と ketinggalan（置き忘れ）の過失責任と表現差

日本語の「わすれた」には、約束や知識を頭から失念した（forget）と、物理的な持ち物を特定の場所に置き忘れてきた（leave behind）の両方があります。インドネシア語で「傘を電車に忘れた」を lupa payung di kereta と言うと構文が破綻します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**「電車の中に傘を置き忘れてしまいました」と言う時。**」
- ❌ **不自然な直訳**: `Saya lupa payung di dalam kereta.`
- ⭕ **自然なネイティブ表現**: `Payung saya ketinggalan di dalam kereta.`
- **病因分析**: 物理的な物をどこかに「置き忘れる・置いてきてしまう」時は必ず ketinggalan（受動・自発）を用います。lupa は「記憶から消える（失念する）」なので、物を目的語にして lupa barang di... と言うと極めて不自然です。

### 症例 2: 「**「彼の名前を忘れてしまった」と言う時。**」
- ❌ **不自然な直訳**: `Namanya ketinggalan.`
- ⭕ **自然なネイティブ表現**: `Saya lupa namanya.`
- **病因分析**: 記憶や約束、タスクを「忘れる」時は lupa を用います。人の名前を ketinggalan と言うと「名前だけ物理的にどこかに落としてきた」ような意味不明な文になります。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。

## 4. 理解度チェッククイズ

### 問1: 「レストランに傘を置き忘れてきた」の自然な表現は？

- [x] 1. Payung saya ketinggalan di restoran. (正解)
- [ ] 2. Saya lupa payung di restoran.
- [ ] 3. Payung saya melupakan restoran.
- [ ] 4. Restoran ketinggalan payung saya.

### 問2: 「宿題をするのを忘れた」の自然な表現は？

- [x] 1. Saya lupa mengerjakan PR. (正解)
- [ ] 2. PR saya ketinggalan mengerjakan.
- [ ] 3. Saya ketinggalan PR lupa.
- [ ] 4. PR lupa saya kerjakan.

### 問3: 「忘れ物はありませんか？」とホテル退出時に聞く定番フレーズは？

- [x] 1. Ada barang yang ketinggalan? (正解)
