# 【誤用克服】「開ける・閉める」の buka と tutup、membukakan（開けてあげる）の使役

ドアや窓を「開ける／閉める」基本動詞 buka / tutup ですが、他人のために「開けてあげる（benefactive）」という相手への配慮を表す際は、受益接辞 -kan を伴う membukakan / menutupkan を用いるのが美しいインドネシア語の作法です。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**荷物を抱えた同僚のために「ドアを開けてあげるよ」と言う時。**」
- ❌ **不自然な直訳**: `Saya buka pintu untukmu.`
- ⭕ **自然なネイティブ表現**: `Biar saya bukakan pintunya ya.`
- **病因分析**: 他人のために親切に動作を行う（受益使役）際は、接辞 -kan を使って membukakan pintunya と表現するのが極めて自然でスマートです。buka pintu untukmu は直訳的で硬い響きになります。

### 症例 2: 「**「お店は何時に開きますか／閉まりますか？」と営業時間を尋ねる時。**」
- ❌ **不自然な直訳**: `Jam berapa toko ini membukakan?`
- ⭕ **自然なネイティブ表現**: `Jam berapa tokonya buka / tutup?`
- **病因分析**: 店舗の営業開始・終了という自動詞的・状態的表現には、単純語の buka / tutup を用います。membukakan を使うと「誰のために店を開けてあげるのか」という不自然な文になります。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。

## 4. 理解度チェッククイズ

### 問1: 両手に荷物を持つ人のために「ドアを開けてあげます」と言うスマートな表現は？

- [x] 1. Biar saya bukakan pintunya. (正解)
- [ ] 2. Saya buka pintu kepadamu.
- [ ] 3. Saya membukakan untuk pintu.
- [ ] 4. Pintu dibuka untukmu.

### 問2: 「スーパーは何時に閉まりますか？」の正しい表現は？

- [x] 1. Supermarket tutup jam berapa? (正解)
- [ ] 2. Supermarket menutupkan jam berapa?
- [ ] 3. Supermarket ditutupkan jam berapa?
- [ ] 4. Supermarket kancing jam berapa.

### 問3: 「銀行口座を開設する」の正しい表現は？

- [x] 1. membuka rekening (正解)
- [ ] 2. menutup rekening
