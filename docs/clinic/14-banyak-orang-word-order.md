# 【誤用克服】banyak orang と orang banyak（群衆）の意味差と語順ミス

「たくさんの人」を表現したい時、banyak orang と言うべきか、orang banyak と言うべきか？後置修飾のルール（名詞＋形容詞）を機械的に適用して orang banyak と言ってしまうと、「大衆・群衆・一般庶民」という全く別の意味になります。語順による意味変化を徹底解剖します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**通りにはたくさんの人がいます（多数の個人）。**」
- ❌ **不自然な直訳**: `Ada orang banyak di jalan raya.`
- ⭕ **自然なネイティブ表現**: `Ada banyak orang di jalan raya.`
- **病因分析**: 「たくさんの人」という不特定多数の個人を指す場合は数量詞 banyak を名詞の前に置きます。後ろに置くと「群衆・大衆」という集合名詞的ニュアンスになります。

### 症例 2: 「**大勢の人の前で話すのは緊張します（公衆の面前）。**」
- ❌ **不自然な直訳**: `Gugup berbicara di depan banyak orang.`
- ⭕ **自然なネイティブ表現**: `Gugup berbicara di depan orang banyak.`
- **病因分析**: 「公衆の面前・人前」という定型的な表現では、後置修飾の orang banyak（群衆・大衆）を用いるのが極めて自然です。

## 4. 理解度チェッククイズ

**Q1. 「通りにたくさんの人がいる」の正しい語順は？**

- 1. Ada banyak orang di jalan. (正解)
- 2. Ada orang banyak di jalan.
- 3. Ada banyaknya orang di jalan.
- 4. Ada perorangan banyak di jalan.

**Q2. 「人前で（公衆の面前で）」を表す決まり文句は？**

- 1. di depan orang banyak (正解)
- 2. di depan banyak orang
- 3. di depan terbanyak orang
- 4. di depan orang-orang banyak

**Q3. banyak orang と orang banyak の違いは？**

- 1. banyak orang は「多数の人々」、orang banyak は「群衆・大衆」 (正解)
- 2. 全く同じ意味
- 3. banyak orang はスラング
- 4. orang banyak は誤用
