# 【誤用克服】頻度副詞 selalu, sering, kadang-kadang, jarang の語順と誤用防止

頻度副詞（いつも・しばしば・時々・めったに〜ない）の位置は文の意味や自然さに直結します。特に jarang はそれ自体に「めったに〜ない（否定）」のニュアンスが含まれるため、日本語の「めったに食べない」を tidak jarang makan と直訳すると「しばしば食べる」という二重否定の逆の意味になります。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**「私はドリアンをめったに食べません」と言う時。**」
- ❌ **不自然な直訳**: `Saya tidak jarang makan durian.`
- ⭕ **自然なネイティブ表現**: `Saya jarang makan durian.`
- **病因分析**: jarang は単体で「めったに〜しない（rarely/seldom）」を表す準否定副詞です。tidak jarang と言うと「めったに〜しないわけではない＝頻繁に食べる（quite often）」という肯定強調になってしまいます。

### 症例 2: 「**「彼はいつも朝遅刻してくる」と述語を修飾する時。**」
- ❌ **不自然な直訳**: `Dia datang terlambat selalu.`
- ⭕ **自然なネイティブ表現**: `Dia selalu datang terlambat.`
- **病因分析**: selalu（いつも）や sering（しばしば）などの頻度副詞は、基本的に修飾する動詞・述語の直前に置くのが標準的です。英語のように文末に放り出すと不自然になります。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。

## 4. 理解度チェッククイズ

### 問1: 「彼はめったに遅刻しない」の最も自然な表現は？

- [x] 1. Dia jarang terlambat. (正解)
- [ ] 2. Dia tidak jarang terlambat.
- [ ] 3. Dia selalu tidak terlambat.
- [ ] 4. Dia terlambat jarang.

### 問2: tidak jarang が表す本当の意味は？

- [x] 1. 頻繁にある（めったにないわけではない） (正解)
- [ ] 2. 全くない
- [ ] 3. 時々ある
- [ ] 4. 常にない

### 問3: 「いつも・常に」を表す副詞 selalu の標準的な位置は？

- [x] 1. 動詞・述語の直前 (正解)
- [ ] 2. 文の最後尾
- [ ] 3. 名詞と形容詞の間
- [ ] 4. 前置詞の直後
