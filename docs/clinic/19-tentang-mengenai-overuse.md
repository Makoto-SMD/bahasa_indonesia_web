# 【誤用克服】「〜について」を何でも tentang にしてしまう論文・ビジネス文の矯正

日本語の「〜について（議論する、報告する、考える）」を何でもかんでも前置詞 tentang で直訳する癖は、文章を幼稚で冗長にします。接尾辞「-i」や「-kan」の他動詞を活用することで、前置詞を使わずに直接目的語をとる洗練されたビジネス文体へとリライトします。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**私たちは新しいプロジェクトについて議論した。**」
- ❌ **不自然な直訳**: `Kami berdiskusi tentang proyek baru.`
- ⭕ **自然なネイティブ表現**: `Kami membahas proyek baru.`
- **病因分析**: 「berdiskusi tentang...」も文法的には正しいですが、ビジネスや論文では他動詞 membahas（〜を討議する）を使って直接目的語を取る方が圧倒的に簡潔で知性的です。

### 症例 2: 「**彼はその規則について知っている。**」
- ❌ **不自然な直訳**: `Dia tahu tentang aturan itu.`
- ⭕ **自然なネイティブ表現**: `Dia mengetahui aturan itu.`
- **病因分析**: tahu tentang ではなく、他動詞 mengetahui を使います。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の品詞分類・前置詞の本来の役割に即した構文パターンを確立します。

## 4. 理解度チェッククイズ

**Q1. 「新しいプロジェクトについて議論する」を最も簡潔・知的に言うと？**

- 1. membahas proyek baru (正解)
- 2. berdiskusi tentang proyek baru
- 3. bicara tentang proyek baru
- 4. omong-omong tentang proyek baru

**Q2. 「規則について知っている」を1単語の他動詞で表現すると？**

- 1. mengetahui aturan (正解)
- 2. tahu tentang aturan
- 3. kenal aturan
- 4. paham tentang aturan

**Q3. tentang の乱用を避けて文章を引き締めるための秘訣は？**

- 1. 接尾辞 -kan や -i を伴う他動詞（meN-）に置き換えて直接目的語を取る (正解)
- 2. 前置詞を全部消す
- 3. 受動態にする
- 4. 英語の単語を混ぜる
