# 【誤用克服】日本語の「〜として」を何でも sebagai と直訳する不自然さの解消

日本語の「〜として」は、①身分・資格（医者として働く）、②代表（日本代表として）、③機能（部屋をオフィスとして使う）、④時（最初として）など極めて多機能です。これを何でも sebagai と機械直訳する癖を排し、menjadi や untuk などを使い分ける技術を伝授します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**この部屋を寝室として使っています。**」
- ❌ **不自然な直訳**: `Kamar ini digunakan sebagai kamar tidur.`
- ⭕ **自然なネイティブ表現**: `Kamar ini dijadikan kamar tidur. / Kamar ini untuk kamar tidur.`
- **病因分析**: sebagai は「身分・身分資格（sebagai dokter, sebagai guru）」に最も適合します。物の用途や機能転換には dijadikan（〜にされる）や untuk を使う方が自然です。

### 症例 2: 「**お土産としてこのお菓子を買いました。**」
- ❌ **不自然な直訳**: `Saya membeli kue ini sebagai oleh-oleh.`
- ⭕ **自然なネイティブ表現**: `Saya membeli kue ini untuk oleh-oleh.`
- **病因分析**: 目的・用途なので untuk oleh-oleh が自然です。

## 2. 処方箋とパラダイムシフト

## 4. 理解度チェッククイズ

**Q1. 「医者として働く（身分・職業）」を表す自然な表現は？**

- 1. bekerja sebagai dokter (正解)
- 2. bekerja untuk dokter
- 3. bekerja menjadi dokter
- 4. bekerja dengan dokter

**Q2. 「お土産としてお菓子を買う（用途）」の最も自然な前置詞は？**

- 1. untuk oleh-oleh (正解)
- 2. sebagai oleh-oleh
- 3. dengan oleh-oleh
- 4. menjadi oleh-oleh

**Q3. 部屋をオフィスに転換する時の動詞は？**

- 1. dijadikan kantor (正解)
- 2. disebagaikan kantor
- 3. diuntukkan kantor
- 4. dimenjadikan kantor
