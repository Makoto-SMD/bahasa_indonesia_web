# 【誤用克服】「送る・迎えに行く・持っていく」の移動方向のベクトル錯誤

日本語の「送る」「連れていく」「持ってくる」は方向性（話者基準か相手基準か）によって語彙が厳格に分かれます。メールを「送る（kirim）」と人を空港へ「送る（antar）」の混同や、迎えに行く（jemput）の使い分けを徹底解説します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**友人を車で「空港まで送る」と言う時。**」
- ❌ **不自然な直訳**: `Saya mau kirim teman saya ke bandara.`
- ⭕ **自然なネイティブ表現**: `Saya mau antar teman saya ke bandara.`
- **病因分析**: kirim は荷物・手紙・データを「郵送・送信する」動詞です。生身の人間を車やバイクで目的地まで「送り届ける」のは antar を使います。kirim teman だと友人を小包にして送るような珍妙な表現になります。

### 症例 2: 「**学校へ子供を「迎えに行く」と言う時。**」
- ❌ **不自然な直訳**: `Saya mau ambil anak saya di sekolah.`
- ⭕ **自然なネイティブ表現**: `Saya mau jemput anak saya di sekolah.`
- **病因分析**: 物を取りに行くのは ambil ですが、人間を車などで「出迎える・拾い上げる」のは必ず jemput を用います。ambil anak だと誘拐や物の回収のような不自然さが出ます。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。
