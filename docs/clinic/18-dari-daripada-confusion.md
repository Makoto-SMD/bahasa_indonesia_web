# 【誤用克服】起点 dari と比較 daripada の混同（誤った daripada の使用）

マレー語や古いインドネシア語の用法、あるいは英語の than と from の混同から、「dari」と「daripada」を取り違えるミスが頻発します。「dari」は場所・時間の起点（〜から）および出所、「daripada」は比較（〜よりも）専用です。daripada を起点に使ってしまう誤用を徹底根絶します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**私は日本から来ました。**」
- ❌ **不自然な直訳**: `Saya datang daripada Jepang.`
- ⭕ **自然なネイティブ表現**: `Saya datang dari Jepang.`
- **病因分析**: 場所や起点は 100%「dari」です。daripada は比較以外では使えません。

### 症例 2: 「**健康は富よりも大切です。**」
- ❌ **不自然な直訳**: `Kesehatan lebih penting dari kekayaan.`
- ⭕ **自然なネイティブ表現**: `Kesehatan lebih penting daripada kekayaan.`
- **病因分析**: 比較には正式には daripada を使います（口語では dari に略されることもありますが、公式な文章では daripada が正確です）。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の品詞分類・前置詞の本来の役割に即した構文パターンを確立します。

## 4. 理解度チェッククイズ

**Q1. 「日本から来ました（起点）」の正しい文は？**

- 1. Saya datang dari Jepang. (正解)
- 2. Saya datang daripada Jepang.
- 3. Saya datang kepada Jepang.
- 4. Saya datang di Jepang.

**Q2. 「AはBより大きい（比較）」の正式な接続詞は？**

- 1. A lebih besar daripada B. (正解)
- 2. A lebih besar dari pada B.
- 3. A lebih besar kepada B.
- 4. A lebih besar untuk B.

**Q3. daripada の文法的な唯一の機能は？**

- 1. 2つの物事を比べる（〜よりも） (正解)
- 2. 場所の出発点を表す（〜から）
- 3. 時間の起点を表す（〜から）
- 4. 理由を表す（〜なので）
