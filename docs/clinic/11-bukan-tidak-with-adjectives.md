# 【誤用克服】形容詞や動詞に bukan を使ってしまう誤用パターンの徹底診断

日本語の「〜ではない」という否定の統一感に引っ張られ、形容詞や動詞に bukan を誤用してしまう症例（❌ Ini bukan enak / ❌ Dia bukan tahu）は初中級者の大定番です。bukan が許される唯一の例外（対比構文 bukan A melainkan B）も含めて完全診断します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**この料理は美味しくない。**」
- ❌ **不自然な直訳**: `Makanan ini bukan enak.`
- ⭕ **自然なネイティブ表現**: `Makanan ini tidak enak.`
- **病因分析**: 形容詞 enak の否定は必ず tidak です。bukan を単体で形容詞につけることはできません。

### 症例 2: 「**私はそのことを知らない。**」
- ❌ **不自然な直訳**: `Saya bukan tahu hal itu.`
- ⭕ **自然なネイティブ表現**: `Saya tidak tahu hal itu.`
- **病因分析**: 動詞 tahu の否定は tidak です。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の品詞分類・前置詞の本来の役割に即した構文パターンを確立します。

## 4. 理解度チェッククイズ

**Q1. 「このホテルは高くない」の正しい文は？**

- 1. Hotel ini tidak mahal. (正解)
- 2. Hotel ini bukan mahal.
- 3. Hotel ini jangan mahal.
- 4. Hotel ini belum mahal.

**Q2. 形容詞の直前に bukan が文法的に使える唯一の条件は？**

- 1. 「〜ではなく…だ」という melainkan との対比構文の時 (正解)
- 2. 過去形の時
- 3. 疑問文の時
- 4. 丁寧語の時

**Q3. 「私は知らない」の正しいインドネシア語は？**

- 1. Saya tidak tahu. (正解)
- 2. Saya bukan tahu.
- 3. Saya jangan tahu.
- 4. Saya tanpa tahu.
