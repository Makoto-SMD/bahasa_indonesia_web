# 【誤用克服】「思う・考える」の pikir, kira, sangka, rasa の致命的なニュアンス差

日本語の「〜だと思う」「考える」をすべて pikir で済ませていませんか？インドネシア語では、論理的に思考する（pikir）、不確実な推測・思い込み（kira）、予期していなかった思い違い（sangka）、主観的な感覚・所感（rasa/merasa）が明確に区別されます。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**「明日は雨が降ると思うよ（推測）」と私見を述べる時。**」
- ❌ **不自然な直訳**: `Saya pikir besok akan hujan.`
- ⭕ **自然なネイティブ表現**: `Saya rasa besok akan hujan. / Kayaknya besok hujan.`
- **病因分析**: 客観的な推論や思索には pikir を使いますが、個人的な予感や天気の推測には rasa（感覚）や口語の kayaknya（〜みたい）を使うのが極めて自然です。

### 症例 2: 「**「君が怒っているのかと思った（思い違い・早合点）」と言う時。**」
- ❌ **不自然な直訳**: `Saya pikir kamu marah.`
- ⭕ **自然なネイティブ表現**: `Saya kira / sangka kamu marah tadi.`
- **病因分析**: 実際は違っていた推測や「〜かと勘違いしていた」という過去の思い込みには kira や sangka を用います（Saya kira bukan begitu = そうじゃないと思ってた）。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。
