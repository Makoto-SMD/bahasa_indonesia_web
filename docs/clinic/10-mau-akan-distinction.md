# 【誤用克服】「〜するつもり/〜だろう」の mau と akan の意志と未来の混同矯正

日本語の「〜する」「〜でしょう」に対して、インドネシア語の「mau」は強い主観的意志・欲望（〜したい、〜する気だ）を含み、「akan」は客観的未来・予定（〜する予定だ、〜だろう）を示します。天候や客観的予測に mau を使ってしまう不自然さを矯正します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**明日は雨が降るでしょう（天気予報）。**」
- ❌ **不自然な直訳**: `Besok mau hujan.`
- ⭕ **自然なネイティブ表現**: `Besok akan hujan.`
- **病因分析**: 雨自身に「降りたい」という意志はないため、客観的未来には akan を使います（ただし口語で「雨が降りそうだ」と空模様を見て言う mau hujan は例外的に使われますが、公式予測は akan です）。

### 症例 2: 「**私は来年結婚するつもりです（強い意志）。**」
- ❌ **不自然な直訳**: `Saya akan menikah tahun depan.`
- ⭕ **自然なネイティブ表現**: `Saya mau menikah tahun depan. / Saya berencana menikah.`
- **病因分析**: 本人の意志・決意を強調する場合は mau または berencana を用います。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 客観的な天気予報で「明日は晴れるでしょう」と言う時の助動詞は？**

- 1. akan (正解)
- 2. mau
- 3. ingin
- 4. hendak

**Q2. 相手に「何が飲みたい？」と希望を尋ねる時の助動詞は？**

- 1. mau (正解)
- 2. akan
- 3. boleh
- 4. harus

**Q3. mau と akan の根本的な違いは？**

- 1. mau は主観的意志・欲求、akan は客観的未来・予定 (正解)
- 2. mau は過去、akan は未来
- 3. mau は否定文専用、akan は肯定文専用
- 4. 全く同じで違いはない
