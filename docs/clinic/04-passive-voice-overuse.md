# 【誤用克服】日本語の受身「〜される」の過剰直訳を排し、自然な能動態に直す

日本語では「雨に降られる」「先生に褒められる」「友達に来られる」のように受身表現（特に被害受動）が極めて日常的です。しかしこれをインドネシア語で機械的に受動態に直訳すると、非常に不自然な文になります。自然な能動態 meN- や周囲辞 ke-...-an へのパラダイムシフトを行います。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**私は先生に褒められました。**」
- ❌ **不自然な直訳**: `Saya dipuji oleh guru.`
- ⭕ **自然なネイティブ表現**: `Guru memuji saya. / Saya mendapat pujian dari guru.`
- **病因分析**: 日本語では「私が褒められた」と言いますが、インドネシア語では「Guru memuji saya（先生が私を褒めた）」と能動態で言う方が圧倒的に活き活きとして自然です。

### 症例 2: 「**昨夜、友達に来られて勉強できなかった。**」
- ❌ **不自然な直訳**: `Tadi malam saya didatangi teman sehingga tidak bisa belajar.`
- ⭕ **自然なネイティブ表現**: `Tadi malam teman datang ke rumah sehingga saya tidak bisa belajar.`
- **病因分析**: 「友達に来られる」は単に「Teman datang（友達が来た）」と能動態で言えば足ります。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「先生に褒められた」を最も自然に表現する能動文は？**

- 1. Guru memuji saya. (正解)
- 2. Saya dipuji oleh guru.
- 3. Pujian guru kepada saya.
- 4. Saya ada pujian guru.

**Q2. 日本語の「雨に降られた（被害）」に最も適したインドネシア語は？**

- 1. Saya kehujanan. (正解)
- 2. Saya dihujani.
- 3. Hujan memukul saya.
- 4. Saya tertabrak hujan.

**Q3. 日本語の受身をインドネシア語に移す際の重要な原則は？**

- 1. 動作主を主語にした能動文（meN-）に変換できないかまず検討する (正解)
- 2. 常に di- を使う
- 3. 常に ter- を使う
- 4. 受動態は禁止されている
