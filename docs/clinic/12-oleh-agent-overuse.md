# 【誤用克服】受動態で oleh を常に挿入してしまう「英語直訳・日本語直訳」癖の矯正

英語の受動態「by」や日本語の「〜によって」に引きずられ、受動態 di- の後ろに機械的にすべて「oleh」を挿入してしまう日本人学習者が後を絶ちません。インドネシア語では、動作主が動詞の直後に隣接する場合、oleh は省略するのがはるかに自然で流暢です。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**そのケーキは母が作りました（母によって作られた）。**」
- ❌ **不自然な直訳**: `Kue itu dibuat oleh ibu.`
- ⭕ **自然なネイティブ表現**: `Kue itu dibuat ibu.`
- **病因分析**: 動作主 ibu が動詞 dibuat の直後に密着しているため、oleh は入れない方がすっきりして自然です。

### 症例 2: 「**その車は修理工によって昨日修理された。**」
- ❌ **不自然な直訳**: `Mobil itu diperbaiki kemarin oleh montir.`
- ⭕ **自然なネイティブ表現**: `Mobil itu diperbaiki kemarin oleh montir.`
- **病因分析**: 動詞と動作主の間に kemarin などの副詞が割り込む場合は、oleh が脱落すると意味が崩れるため oleh が必須です。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の品詞分類・前置詞の本来の役割に即した構文パターンを確立します。

## 4. 理解度チェッククイズ

**Q1. 受動態で動作主が動詞の直後に来る場合の oleh の扱いは？**

- 1. 省略するのが最も自然ですっきりしている (正解)
- 2. 絶対に省略してはならない
- 3. 必ず文頭に置く
- 4. 名詞には使えない

**Q2. oleh が必須となる条件は？**

- 1. 動詞と動作主の間に副詞（kemarin, tadi など）が挟まる時 (正解)
- 2. 主語が人間の時
- 3. 動詞が現在形の時
- 4. 受動態の時常に

**Q3. 「その料理は母が作った（作られた）」の最も簡潔で自然な文は？**

- 1. Makanan dimasak ibu. (正解)
- 2. Makanan dimasak oleh karena ibu.
- 3. Makanan memasak oleh ibu.
- 4. Makanan dibuat oleh pada ibu.
