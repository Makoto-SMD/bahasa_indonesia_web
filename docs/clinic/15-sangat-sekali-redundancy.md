# 【誤用克服】sangat ... sekali の二重修飾の違和感と自然な強調表現

「とても」を強調したいあまり、前置強調の sangat と後置強調の sekali を同時に使って【❌ sangat bagus sekali】と重ねてしまう誤用が非常に目立ちます。文法的には許容される場面もありますが、スマートな文章では「どちらか一方」を使うのが洗練された大人のインドネシア語です。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**このホテルはとても綺麗です。**」
- ❌ **不自然な直訳**: `Hotel ini sangat bersih sekali.`
- ⭕ **自然なネイティブ表現**: `Hotel ini sangat bersih. / Hotel ini bersih sekali.`
- **病因分析**: sangat と sekali を両方重ねると「馬から落ちて落馬する」のような二重強調のくどさが出ます。どちらか片方だけに絞るのがエレガントです。

### 症例 2: 「**富士山はとても高い。**」
- ❌ **不自然な直訳**: `Gunung Fuji amat sangat tinggi sekali.`
- ⭕ **自然なネイティブ表現**: `Gunung Fuji sangat tinggi. / Gunung Fuji tinggi sekali.`
- **病因分析**: 強調語を過剰に乱立させる癖を矯正します。

- 1. sangat enak または enak sekali (正解)
- 2. sangat enak sekali
- 3. amat sangat lezat sekali
- 4. paling sangat enak

**Q2. sangat の正しい配置位置は？**

- 1. 形容詞の直前（sangat indah） (正解)
- 2. 形容詞の直後
- 3. 文末
- 4. 主語の直前

**Q3. sekali の正しい配置位置は？**

- 1. 形容詞の直後（indah sekali） (正解)
- 2. 形容詞の直前
- 3. 文頭
- 4. 主語の直後
