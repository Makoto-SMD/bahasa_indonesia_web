# 【誤用克服】「〜しておく（準備・放置）」の直訳ミスを防ぐ（siapkan, biarkan, dulu）

日本語の「〜ておく」には、①事前準備（切符を買っておく）、②状態の放置（そのままにしておく）、③とりあえず・先行動作（先に食べておく）の3つの異なる意味があります。これらをすべて同一の単語で直訳しようとする誤用を是正し、siapkan, biarkan, dulu を使い分けます。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**切符を事前に買っておきます。**」
- ❌ **不自然な直訳**: `Saya membeli tiket menaruh.`
- ⭕ **自然なネイティブ表現**: `Saya membeli tiket terlebih dahulu. / Saya siapkan tiketnya.`
- **病因分析**: 「〜ておく」の「おく」を物理的な「置く（menaruh）」と直訳するのは致命的な誤用です。準備なら menyiapkan、事前に先行するなら terlebih dahulu / dulu を使います。

### 症例 2: 「**ドアを開けたままにしておいてください。**」
- ❌ **不自然な直訳**: `Tolong simpan pintu terbuka.`
- ⭕ **自然なネイティブ表現**: `Biarkan pintunya terbuka.`
- **病因分析**: 状態の放置は biarkan（そのままにさせておく）を用います。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「ドアを開けたままにしておいて（放置）」の自然な表現は？**

- 1. Biarkan pintunya terbuka. (正解)
- 2. Tolong taruh pintu buka.
- 3. Simpan pintu buka.
- 4. Bikin pintu terbuka.

**Q2. 「先に食べておいて（先行）」を表す日常語は？**

- 1. Makan duluan ya. (正解)
- 2. Makan menaruh ya.
- 3. Makan simpan ya.
- 4. Makan buat ya.

**Q3. 「事前に資料を準備しておく」を表す動詞は？**

- 1. menyiapkan dokumen (正解)
- 2. menaruh dokumen
- 3. menyimpan dokumen
- 4. membiarkan dokumen
