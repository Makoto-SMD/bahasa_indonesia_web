# 【誤用克服】「〜しやすい/にくい」の mudah / susah と gampang / sulit のレジスター使い分け

インドネシア語で「簡単・容易」を表す mudah と gampang、「困難・難しい」を表す sulit と susah は、意味は似ていますが文脈とレジスター（改まり度）が異なります。公式ビジネス文書で gampang/susah を多用すると幼く響き、動詞への接続パターンにも注意が必要です。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**ビジネスの契約書や公式報告書で「解決が極めて困難である」と書く時。**」
- ❌ **不自然な直訳**: `Masalah ini susah sekali diselesaikan.`
- ⭕ **自然なネイティブ表現**: `Masalah ini sangat sulit diselesaikan.`
- **病因分析**: 公式文書・学術論文・フォーマルスピーチでは sulit（困難）および mudah（平易）を用います。susah や gampang は日常口語（bahasa percakapan）の響きが強くなります。

### 症例 2: 「**「このペンは書きやすい（使いやすい）」と言う時。**」
- ❌ **不自然な直訳**: `Pulpen ini mudah untuk tulis.`
- ⭕ **自然なネイティブ表現**: `Pulpen ini enak / mudah dipakai untuk menulis.`
- **病因分析**: インドネシア語で「〜しやすい」は mudah dipakai / enak digunakan など動詞の受動的適性を表す形を用います。直訳で mudah untuk menulis とすると構文が崩れます。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。
