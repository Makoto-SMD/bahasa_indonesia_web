# 【誤用克服】「持っている/ある」の混乱（Ada buku vs Punya buku vs Memiliki）

日本語の「ある・いる・持っている」に対応する ada, punya, memiliki の混同は、初中級者の大定番です。「Ada mobil」と「Punya mobil」はどう違うのか？「Saya ada uang」と「Saya punya uang」の微妙な使い分けを整理します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**私は車を持っています。**」
- ❌ **不自然な直訳**: `Saya ada mobil.`
- ⭕ **自然なネイティブ表現**: `Saya punya mobil.`
- **病因分析**: 法的な所有権や自分の所有物であることを述べる場合は punya を使います。「Saya ada mobil」と言うと「（今日使える）車がある・手元にある」という一時的ニュアンスになります。

### 症例 2: 「**机の上にペンがあります。**」
- ❌ **不自然な直訳**: `Punya pulpen di atas meja.`
- ⭕ **自然なネイティブ表現**: `Ada pulpen di atas meja.`
- **病因分析**: 場所における物理的存在には ada を使い、punya は絶対に使えません。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「机の上に本がある」の正しい文は？**

- 1. Ada buku di atas meja. (正解)
- 2. Punya buku di atas meja.
- 3. Memiliki buku di atas meja.
- 4. Adanya buku di atas meja.

**Q2. 「彼は車を所有している」を表す最も適切な語は？**

- 1. Dia punya mobil. (正解)
- 2. Dia ada mobil di jalan.
- 3. Dia tempat mobil.
- 4. Dia menjadi mobil.

**Q3. 公的文書・論文で「権利や資産を保有する」を表す格式高い動詞は？**

- 1. memiliki (正解)
- 2. punya
- 3. ada
- 4. dapat
