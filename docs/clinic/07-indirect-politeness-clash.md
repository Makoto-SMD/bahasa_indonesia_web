# 【誤用克服】「遠慮・遠回しな断り」が招く誤解と、インドネシア流の温かい断り方

日本人の「行けたら行きます」「ちょっと都合が悪くて…」という曖昧・遠回しな断り文句は、インドネシアでは「本当は来るのか？」「失礼な嘘つき」と解釈され、重大な人間関係の摩擦を引き起こします。角を立てずに温かく断るインドネシア流の処方箋を伝授します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**（パーティーに誘われて）行けたら行きます（本当は行かない）。**」
- ❌ **不自然な直訳**: `Mungkin saya pergi kalau bisa.`
- ⭕ **自然なネイティブ表現**: `Maaf sekali, kali ini saya tidak bisa ikut karena ada acara lain.`
- **病因分析**: 「行けたら行く」を直訳すると、相手は「来る」と期待して料理を用意してしまいます。断る時は最初に「Maaf sekali（本当にごめん）」と謝意を示し、行けない理由を添えるのが礼儀です。

### 症例 2: 「**（商談の提案を断る時）検討させていただきます。**」
- ❌ **不自然な直訳**: `Saya akan mempertimbangkannya.`
- ⭕ **自然なネイティブ表現**: `Usulannya sangat bagus, namun untuk saat ini kami belum bisa melanjutkan.`
- **病因分析**: ただ検討すると言うだけでなく、提案を一度褒めてから「現時点では見送る」と明確に伝えます。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. インドネシアで誘いを断る際の鉄則は？**

- 1. 「行けたら行く」と曖昧に濁す
- 2. 最初に感謝とお詫び（Maaf sekali）を述べ、理由を添えて温かく断る (正解)
- 3. 返事をせず無視する
- 4. 怒った顔で断る

**Q2. 「また別の機会に誘ってね」の定番フレーズは？**

- 1. Lain kali ajak saya lagi ya. (正解)
- 2. Jangan ajak saya lagi.
- 3. Mungkin saya mau nanti.
- 4. Tolak ajakan Anda.

**Q3. 「お気持ちだけいただきます」を表す上品な表現は？**

- 1. Terima kasih atas niat baiknya. (正解)
- 2. Saya tidak mau barangnya.
- 3. Ambil saja kembali.
- 4. Jangan kasih saya.
