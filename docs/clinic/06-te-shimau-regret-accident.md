# 【誤用克服】「〜てしまう（後悔・完了）」の直訳ミス（terlanjur, keburu, sampai）

日本語の「〜てしまう」は、①取り返しのつかない後悔（言ってしまった、買っちゃった）、②時間切れ・先を越される（バスが行ってしまった）、③完了（全部食べてしまった）を含みます。これらを terlanjur, keburu, habis で鮮やかに外科手術します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**秘密をつい言ってしまった（取り返しがつかない）。**」
- ❌ **不自然な直訳**: `Saya sudah bicara rahasia.`
- ⭕ **自然なネイティブ表現**: `Saya terlanjur membocorkan rahasianya.`
- **病因分析**: 取り返しのつかない後悔には副詞 terlanjur（後の祭り・時すでに遅し）を使います。

### 症例 2: 「**間に合わなくて電車が行ってしまった。**」
- ❌ **不自然な直訳**: `Kereta pergi tidak sempat.`
- ⭕ **自然なネイティブ表現**: `Keretanya keburu berangkat.`
- **病因分析**: 時間切れで手遅れになる「〜てしまう」は keburu を使います。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「取り返しがつかないことをしてしまった（後悔）」を表す副詞は？**

- 1. terlanjur (正解)
- 2. keburu
- 3. habis
- 4. sudah

**Q2. 「急がないとバスが出ちゃうよ（時間切れ手遅れ）」を表す副詞は？**

- 1. keburu (正解)
- 2. terlanjur
- 3. terlalu
- 4. belum

**Q3. 「全部食べ尽くしてしまった」を表す自然な形は？**

- 1. Habis saya makan. (正解)
- 2. Makan saya selesai.
- 3. Sudah makan habis.
- 4. Saya makan terlanjur.
