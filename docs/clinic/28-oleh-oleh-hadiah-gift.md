# 【誤用克服】「お土産」の oleh-oleh と「プレゼント」の hadiah の混同是正

日本語では旅行土産も誕生日プレゼントも「おみやげ・贈り物」とひとくくりにしがちですが、インドネシア語では明確に分類されます。旅先から買ってくる名産品は oleh-oleh、記念日・祝い事・賞品として贈る物は hadiah または kado を用います。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**友人の誕生日パーティーに「プレゼント」を持参する時。**」
- ❌ **不自然な直訳**: `Saya bawa oleh-oleh untuk ulang tahunmu.`
- ⭕ **自然なネイティブ表現**: `Saya bawa kado / hadiah untuk ulang tahunmu.`
- **病因分析**: 誕生日・結婚祝いなどの慶事のプレゼントには kado（誕生日等の個人的ギフト）や hadiah（一般的な贈り物・賞品）を使います。oleh-oleh は旅行・帰省先からの「旅のお土産」に限定されます。

### 症例 2: 「**バリ島旅行から帰ってきて職場で配るお菓子を渡す時。**」
- ❌ **不自然な直訳**: `Ini hadiah dari Bali untuk teman-teman.`
- ⭕ **自然なネイティブ表現**: `Ini oleh-oleh dari Bali untuk teman-teman.`
- **病因分析**: 旅先の名物菓子などを配る際は必ず oleh-oleh を使います。hadiah と言うと、何か特別な功績や表彰の賞品を授与するかのようなニュアンスになってしまいます。

## 2. 処方箋とパラダイムシフト

母語（日本語）の思考フレームを解体し、インドネシア語の語彙の守備範囲・対人関係のレジスターに即した自然な表現パターンを身体化します。
