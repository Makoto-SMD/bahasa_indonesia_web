# 【誤用克服】「〜てあげる/もらう」を memberi で直訳しない！-kan と受動態の処方箋

日本語の「〜てあげる」「〜てもらう」「〜てくれる」という授受表現を、そのまま memberi（与える）で直訳した【Dia memberi saya pergi】のような壊れた文は日本人学習者の典型的な誤用です。インドネシア語では接尾辞「-kan」の受益構文や「受動態」を使って表現します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**彼は私にコーヒーを淹れてくれた。**」
- ❌ **不自然な直訳**: `Dia memberi membuat saya kopi.`
- ⭕ **自然なネイティブ表現**: `Dia membuatkan saya kopi.`
- **病因分析**: 英語の give me や日本語の「作ってくれる」を直訳せず、動詞 membuat に受益の接尾辞 -kan をつけて membuatkan saya kopi とします。

### 症例 2: 「**私は先生に推薦状を書いてもらった。**」
- ❌ **不自然な直訳**: `Saya menerima guru menulis surat.`
- ⭕ **自然なネイティブ表現**: `Surat rekomendasi saya dituliskan oleh guru.`
- **病因分析**: 「〜してもらう」は受益の受動態（dituliskan）で表現するのが自然です。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「彼は私に本を買ってくれた」の正しいインドネシア語は？**

- 1. Dia membelikan saya buku. (正解)
- 2. Dia memberi saya membeli buku.
- 3. Dia membeli buku memberi saya.
- 4. Dia dapat buku dari saya.

**Q2. 日本語の「〜してもらう」をインドネシア語で表現する最も自然な方法は？**

- 1. 受動態（di- / di-...-kan）を使う (正解)
- 2. memberi を直前に置く
- 3. dapat を動詞の前に置く
- 4. menerima を動詞の前に置く

**Q3. 「ドアを開けてあげてください」は？**

- 1. Tolong bukakan pintunya. (正解)
- 2. Tolong memberi buka pintu.
- 3. Tolong buka memberi pintu.
- 4. Tolong dibukakan memberi.
