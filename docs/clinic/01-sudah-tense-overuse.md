# 【誤用克服】「〜した＝sudah」の呪縛！過去テンスとアスペクト完了の混同を直す

日本語話者が最も頻繁に犯す誤用が「過去の出来事なら何でも sudah をつけてしまう」現象です。インドネシア語には動詞の過去形が存在せず、文脈や時制副詞（kemarin, tadi）で過去を表します。sudah は「すでに完了していること（現在の視点）」を強調する場合にのみ使うという根本原則を体得します。

## 1. 症例カルテ（日本人特有の不自然な発話例）

### 症例 1: 「**昨日、映画を見ました。**」
- ❌ **不自然な直訳**: `Saya kemarin sudah menonton film.`
- ⭕ **自然なネイティブ表現**: `Kemarin saya menonton film.`
- **病因分析**: kemarin（昨日）という過去の時を表す語がある場合、sudah を入れると「すでに観終えていた」という不自然な完了強調になり、ネイティブにはくどく聞こえます。単に動詞をそのまま置くだけで十分です。

### 症例 2: 「**さっき彼と話しました。**」
- ❌ **不自然な直訳**: `Tadi saya sudah berbicara dengan dia.`
- ⭕ **自然なネイティブ表現**: `Tadi saya berbicara dengan dia.`
- **病因分析**: tadi（さっき）が過去を示しているため、sudah は原則不要です。

## 2. 処方箋とパラダイムシフト

日本語の発想（テンス・アスペクトの混同や授受表現の直訳）から脱却し、インドネシア語本来の語彙体系と構文を自然にマッピングするための思考ルールを身につけます。

## 4. 理解度チェッククイズ

**Q1. 「昨日ナシゴレンを食べた」の最も自然な表現は？**

- 1. Kemarin saya makan nasi goreng. (正解)
- 2. Kemarin saya sudah makan nasi goreng.
- 3. Saya sudah kemarin makan nasi goreng.
- 4. Kemarin sudah saya makan nasi goreng.

**Q2. sudah を必ず使うべき状況は？**

- 1. 「すでに完了している/もう済んだ」というアスペクト状態を強調したい時 (正解)
- 2. 過去の出来事には文脈に関係なく常に
- 3. 文末に置く時
- 4. 疑問文の時

**Q3. 「さっき彼に会った」の自然な文は？**

- 1. Tadi saya bertemu dengan dia. (正解)
- 2. Tadi saya sudah bertemu dengan dia.
- 3. Sudah tadi saya bertemu dengan dia.
- 4. Saya sudah tadi bertemu dia.
