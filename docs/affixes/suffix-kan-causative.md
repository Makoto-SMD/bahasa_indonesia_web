# 接尾辞 -kan の使役（〜させる）用法

インドネシア語の接尾辞（Akhiran）の中で最も頻出するのが **`-kan`** です。
この接尾辞の代表的な機能の1つが**「使役（Kausatif：〜させる、〜の状態にする）」**です。

日本語で「きれいだ ➔ きれいにする」「入る ➔ 入れる」「落ちる ➔ 落とす」と言うのと同様に、形容詞や自動詞の末尾に `-kan` をつけ（同時に接頭辞 `meN-` または受動態 `di-` とセットにして）、**状態や動作を引き起こす他動詞**へと変身させます。

---

## 1. 使役の基本メカニズム

```
【形容詞・自動詞】                     【使役他動詞 (meN-...-kan)】
 bersih（きれいだ）     ─────>        membersihkan（きれいにする・清掃する）
 masuk（入る）          ─────>        memasukkan（中に入れる）
```

主語が、目的語に対して「その状態や動作を引き起こす」という強い働きかけの文を作ります。

---

## 2. パターン①：形容詞 ＋ -kan ➔ 「〜の状態にさせる」

形容詞を語根にして、目的語をその形容詞の状態へと変化させます。

| 語根（形容詞） | 意味 | 派生語（meN-...-kan） | 意味（使役） |
| :--- | :--- | :--- | :--- |
| **bersih** | 清潔な・きれいな | **membersihkan** | きれいにする、清掃する |
| **panas** | 熱い・温かい | **memanaskan** | 温める、加熱する |
| **dingin** | 冷たい | **mendinginkan** | 冷やす、冷却する |
| **besar** | 大きい | **membesarkan** | 大きくする、育てる |
| **hidup** | 生きている | **menghidupkan** | （電気や機械を）つける、起動する |
| **mati** | 死んでいる | **mematikan** | （電気や火を）消す、止める |

<div class="id-example" markdown>

<div class="id-sentence">
Tolong panaskan sup ini sebelum dimakan.
</div>
<div class="id-reading">
トロン パナスカン スプ イニ スブルム ディマカン
</div>
<div class="id-meaning">
食べる前にこのスープを温めてください。
</div>

</div>

> [!TIP]
> エアコンやテレビを「つける」ときは `menghidupkan`（生かす ➔ 起動する）、「消す」ときは `mematikan`（殺す ➔ 停止させる）という直感的なメタファーが使われます。

---

## 3. パターン②：自動詞 ＋ -kan ➔ 「〜を行動させる・動かす」

本来は目的語を取らない「自動詞」に `-kan` をつけることで、その動作を目的語に対して強制する「他動詞」へと変化させます。

| 語根（自動詞） | 意味 | 派生語（meN-...-kan） | 意味（使役） |
| :--- | :--- | :--- | :--- |
| **masuk** | 入る | **memasukkan** | （中へ）入れる |
| **keluar** | 出る | **mengeluarkan** | （外へ）出す、取り出す |
| **turun** | 降りる・下がる | **menurunkan** | 降ろす、下げる |
| **naik** | 上がる・乗る | **menaikkan** | 上げる、値上げする |
| **jatuh** | 落ちる | **menjatuhkan** | 落とす、倒す |
| **tidur** | 眠る | **menidurkan** | （子供を）寝かしつける |

<div class="id-example" markdown>

<div class="id-sentence">
Ibu sedang menidurkan adik di kamar tidur.
</div>
<div class="id-reading">
イブ スダン ムニドゥルカン アディッ ディ カマル ティドゥール
</div>
<div class="id-meaning">
母は寝室で妹を寝かしつけているところです。
</div>

</div>

---

## 4. 能動態と受動態のペア構文

使役の `meN-...-kan` は、そのまま `di-...-kan` の受動態と綺麗なペアを作ります。

- 能動態: `Pemerintah **menaikkan** harga bensin.`  
  （政府はガソリンの価格を**引き上げました**。）
- 受動態: `Harga bensin **dinaikkan** oleh pemerintah.`  
  （ガソリンの価格は政府によって**引き上げられました**。）

<div class="id-example" markdown>

<div class="id-sentence">
Sampah plastik harus dimasukkan ke dalam tempat sampah.
</div>
<div class="id-reading">
サンパ プラスティッ ハルス ディマスクカン ク ダラム トゥムパッ サンパ
</div>
<div class="id-meaning">
プラスチックごみはゴミ箱の中に入れられなければなりません。
</div>

</div>
