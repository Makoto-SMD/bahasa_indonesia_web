# 接頭辞 meN- の役割と鼻音化変化の法則（K, T, S, P 脱落ルール）

インドネシア語の動詞の王様が、接頭辞 **`meN-`**（ムン-）です。
主に**「主語が能動的に動作を行う能動態動詞」**を作り出します。

この接頭辞の表記で "N" が大文字で書かれるのには重要な理由があります。
それは、**語根（Kata Dasar）の最初の文字（頭文字）に応じて、鼻音（m, n, ng, ny）がカメレオンのように姿を変えるから**です。

そして、この変化の頂点に君臨するのが、全学習者が必ず暗記すべき**「K, T, S, P 脱落ルール」**です。

---

## 1. meN- の変化完全マスター表

語根の頭文字によって、接頭辞は以下の6つの形に変化します。

| 語根の頭文字 | 変化後の接頭辞 | 頭文字の扱い | 語根の例 | 派生語（meN- + 語根） | 意味 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **母音 (a, i, u, e, o)** | **meng-** | そのまま残る | `ambil`<br>`isi` | **mengambil**<br>**mengisi** | 取る<br>入れる・満たす |
| **g, h, kh** | **meng-** | そのまま残る | `goreng`<br>`hitung` | **menggoreng**<br>**menghitung** | 炒める・揚げる<br>計算する・数える |
| **b, f, v** | **mem-** | そのまま残る | `baca`<br>`bantu` | **membaca**<br>**membantu** | 読む<br>手伝う |
| **d, j, c, z** | **men-** | そのまま残る | `dengar`<br>`cari` | **mendengar**<br>**mencari** | 聞く<br>探す |
| **l, m, n, r, w, y** | **me-** | そのまま残る | `lihat`<br>`masak` | **melihat**<br>**memasak** | 見る<br>料理する |
| **【K】** | **meng-** | **消滅（脱落）！** | `kirim` | **mengirim**（❌ mengkirim） | 送る |
| **【T】** | **men-** | **消滅（脱落）！** | `tulis` | **menulis**（❌ mentulis） | 書く |
| **【S】** | **meny-** | **消滅（脱落）！** | `sapu` | **menyapu**（❌ mensapu） | ほうきで掃く |
| **【P】** | **mem-** | **消滅（脱落）！** | `pakai` | **memakai**（❌ mempakai） | 使う・着る |

---

## 2. 【最重要】K, T, S, P 脱落の黄金ルール

インドネシア語の音韻法則において、無声音である **K, T, S, P** で始まる語根に `meN-` がつくと、**頭文字が鼻音に完全に吸収されて消え去り（脱落同化）**ます。

語呂合わせとして**「カ・タ・サ・パ（K-T-S-P）」**とリズムで覚えましょう！

### 2.1 K ➔ meng- (Kが消える)
- `kirim`（送る） ➔ **`mengirim`**
- `kurang`（減る） ➔ **`mengurangi`**（減らす）
- `kunci`（鍵） ➔ **`mengunci`**（鍵をかける）

### 2.2 T ➔ men- (Tが消える)
- `tulis`（書く） ➔ **`menulis`**
- `tolong`（助ける） ➔ **`menolong`**
- `tarik`（引く） ➔ **`menarik`**（引っ張る・魅力的な）

### 2.3 S ➔ meny- (Sが消える)
- `sapu`（ほうき） ➔ **`menyapu`**
- `sewa`（賃貸） ➔ **`menyewa`**（借りる・レンタルする）
- `siram`（水をかける） ➔ **`menyiram`**（水をやる）

### 2.4 P ➔ mem- (Pが消える)
- `pakai`（使う） ➔ **`memakai`**
- `pinjam`（借りる） ➔ **`meminjam`**
- `potong`（切る） ➔ **`memotong`**

Saya sedang menulis surat dan memakai kacamata.
</div>

## 3. 特殊な例外ルール

### 3.1 1音節の語根 ➔ menge-（ムンゲ-）
語根がたったの1音節（母音1つ）しかない超短い単語には、発音の安定のために **`menge-`** がつきます。

- `cat`（ペンキ・塗料） ➔ **`mengecat`**（ペンキを塗る）
- `bom`（爆弾） ➔ **`mengebom`**（爆撃する）
- `pel`（モップがけ） ➔ **`mengepel`**（床を拭く）
- `cek`（確認する） ➔ **`mengecek`**（チェックする）

### 3.2 外来語起源で子音が2つ続く場合 ➔ 脱落しない！
英語などの外来語で、先頭が `kr-`, `tr-`, `pr-`, `st-` のように子音が重なっている単語は、**K-T-S-P であっても脱落せずそのまま残ります**。

- `kritik` ➔ **`mengkritik`**（批判する ➔ ❌ mengritik とはならない）
- `traktir` ➔ **`mentraktir`**（おごる ➔ ❌ menraktir とはならない）
- `proses` ➔ **`memproses`**（処理する ➔ ❌ memroses とはならない）
- `stabil` ➔ **`menstabilkan`**（安定させる）
