# 接尾辞 -kan の受益（〜のためにする）・対象化構文

接尾辞 **`-kan`** のもうひとつの極めて重要な機能が、「**受益（Benefaktif：〜のために…してあげる・してくれる）**」です。

日本語の「買って**あげる**」「作って**くれる**」「持ってきて**あげる**」のように、**誰かの利益のために動作を行うニュアンス**を、動詞に `-kan` を付与するだけで表現できます。

英語の `buy him a present` や `cook her dinner` と同じ「二重目的語構文」を作り出します。

---

## 1. 受益構文の基本ルールと書き換え

インドネシア語で「誰かのために何かをする」と言う場合、全く同じ意味を表す**2つの構文パターン**が存在します。

```
【パターン A：-kan を使う（二重目的語）】
  主語 ＋ meN-[語根]-kan ＋ [受益者（人）] ＋ [対象物（モノ）]
  ※前置詞 untuk は不要！人の直後にモノを置く。

【パターン B：-kan を使わない（前置詞 untuk）】
  主語 ＋ meN-[語根] ＋ [対象物（モノ）] ＋ untuk ＋ [受益者（人）]
  ※前置詞 untuk（〜のために）を添える。
```

### 対比の具体例：
- パターンA: **`Saya membelikan adik buku cerita.`**
- パターンB: **`Saya membeli buku cerita untuk adik.`**
- 意味: 私は妹（弟）に絵本を買ってあげました。

<div class="id-example" markdown>

<div class="id-sentence">
Ayah membuatkan kami meja belajar yang kokoh.
</div>
<div class="id-reading">
アヤ ムンブアッカン カミ メジャ ブラジャール ヤン ココ
</div>
<div class="id-meaning">

## 2. 日常会話で最頻出の受益動詞一覧

日常のサービス、家庭、オフィスで相手に親切にするときに真っ先に使う動詞群です。

| 語根 | meN-...-kan 派生語 | 受益の意味 | 例文 |
| :--- | :--- | :--- | :--- |
| **beli**（買う） | **membelikan** | 〜に買ってあげる | `membelikan ibu obat`（母に薬を買ってあげる） |
| **buat**（作る） | **membuatkan** | 〜に作ってあげる | `membuatkan kopi`（コーヒーを淹れてあげる） |
| **bawa**（持つ・運ぶ） | **membawakan** | 〜に持ってきてあげる・運んであげる | `membawakan tas`（カバンを持ってあげる） |
| **buka**（開ける） | **membukakan** | 〜のために開けてあげる | `membukakan pintu`（ドアを開けてあげる） |
| **ambil**（取る） | **mengambilkan** | 〜に取ってあげる | `mengambilkan garam`（塩を取ってあげる） |
| **cari**（探す） | **mencarikan** | 〜のために探してあげる | `mencarikan hotel`（ホテルを探してあげる） |
| **cerita**（話・物語） | **menceritakan** | 〜に話して聞かせる | `menceritakan dongeng`（昔話を語って聞かせる） |

<div class="id-example" markdown>

<div class="id-sentence">
Bolehkah saya membawakan koper Anda yang berat itu?
</div>
<div class="id-reading">
ボレカ サヤ ムンバワカン コペル アンダ ヤン ブラッ イトゥ
</div>
<div class="id-meaning">
あなたのその重いスーツケースをお運びしましょうか？
</div>

</div>

## 3. 依頼文（Tolong + 語根-kan）での絶大な効果

命令・依頼をするときに、語根に `-kan` をつけて 【**Tolong ＋ 語根-kan ＋ saya ＋ モノ**】 の形にすると、「**私のために〜してくれませんか？**」という親切で温かみのある実践フレーズになります。

- `Tolong carikan saya taksi.`（私のためにタクシーを呼んで/探してください）
- `Tolong buatkan saya teh manis hangat.`（温かい甘いお茶を淹れてください）
- `Tolong ambilkan dokumen itu.`（その書類を取ってください）

---

## 4. 受益構文の受動態（di-...-kan）

受益構文を受動態にする場合、**「受益者（人）」ではなく「対象物（モノ）」が主語**になります。

- 能動態: `Ibu **membuatkan** adik susu hangat.`
- 受動態: `Susu hangat **dibuatkan** oleh ibu untuk adik.`  
  （温かいミルクが母によって弟のために作られました。）

<div class="id-example" markdown>

<div class="id-sentence">
Secangkir kopi hangat sudah disiapkan untuk tamu penting.
</div>
<div class="id-reading">
スカンキール コピ ハンガッ スダ ディスィアプカン ウントゥッ タム プンティン
</div>
<div class="id-meaning">
温かいコーヒー1杯が大切な来客のために準備されました。
</div>

</div>
