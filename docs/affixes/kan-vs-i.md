# 接尾辞 -kan と -i の徹底比較と使い分け

インドネシア語中級への最大の登竜門にして、検定試験（C級・B級）でも頻繁に狙われるのが「**接尾辞 -kan と -i の違い**」です。

辞書を引くと、同じ語根に `-kan` と `-i` の両方が載っていて「どっちを使えばいいの？」と途方に暮れた経験がある方も多いはずです。

しかし、言語学者も認める「**たった1つの物理的モデル（目的語が動くか、止まっているか）**」を理解すれば、この2つの使い分けは驚くほど明快になります。

---

## 1. 黄金の物理モデル：目的語は「動く」か「止まっている」か！

動詞の直後に置かれる**「目的語（O）」がどのような状態にあるか**に注目してください。

```
【 接尾辞 -kan の世界 】 ➔ 「目的語（O）が移動する！」
  主語 ─── (動作) ───> 【目的語 O】がスーッと動いて別の場所へ移動する
  ※ O は「動かされるモノ（移動物）」！

【 接尾辞 -i の世界 】   ➔ 「目的語（O）は静止して待っている！」
  主語 ─── (動作) ───> 【目的語 O】は動かず、そこに動作が着弾・浸透する
  ※ O は「場所・受容器（ターゲット）」！
```

| 項目 | 接尾辞 -kan | 接尾辞 -i |
| :--- | :--- | :--- |
| **目的語（O）の性質** | **動かされる物体（移動物）** | **その場にある場所・受取人（静止）** |
| **中核のニュアンス** | 使役（動かす）、受益（あげる） | 場所（〜に）、付与（〜を施す） |
| **文型パターン** | `...-kan` ＋ **[動くモノ]** ＋ ke [場所] | `...-i` ＋ **[静止する場所]** ＋ dengan [モノ] |

---

## 2. 決定的な対比ペア4選（これで完全理解！）

### 対比①：masuk（入る）
- **`memasukkan`（-kan）**: 「**（モノを）入れる**」 ➔ 目的語（荷物やお金）が動いて中に入る！
- **`memasuki`（-i）**: 「**（自分が場所へ）入る**」 ➔ 目的語（部屋や建物）は動かず、自分がそこに入る！

<div class="id-example" markdown>

<div class="id-sentence">
Dia memasukkan uang ke dalam dompet, lalu memasuki toko itu.
</div>
<div class="id-reading">
ディア ムマスクカン ウアン ク ダラム ドンペッ ラル ムマスクキ トコ イトゥ
</div>
<div class="id-meaning">
彼はお金を財布に入れ（memasukkan uang）、それからその店に入りました（memasuki toko）。
</div>

</div>

### 対比②：duduk（座る）
- **`mendudukkan`（-kan）**: 「**（人やモノを）座らせる**」 ➔ 赤ちゃんやお年寄りを椅子に座らせる。
- **`menduduki`（-i）**: 「**（自分が椅子に）座る、占領する**」 ➔ 椅子自体は動かず、そこに座る。

- `Ibu mendudukkan adik di kursi.`（母は妹を椅子に座らせた ➔ 妹が動いた）
- `Bapak menduduki kursi empuk itu.`（父はその柔らかい椅子に座った ➔ 椅子は静止）

### 対比③：tanam（植える）
畑に植物の苗を植える場面を想像してください。
- **`menanamkan`（-kan）**: 「**（苗・種を）植える**」 ➔ 動くのは「苗」！
- **`menanami`（-i）**: 「**（畑に）植え付ける**」 ➔ 目的語は動かない「畑（場所）」！

<div class="id-example" markdown>

<div class="id-sentence">
Petani menanami sawah dengan padi.
</div>
<div class="id-reading">
プタニ ムナナミ サワ ドゥンガン パディ
</div>
<div class="id-meaning">
農家は田んぼ（静止場所）に稲を植え付けました。
</div>

</div>

> もし苗を目的語にするなら：`Petani **menanamkan** bibit padi di sawah.` となります。

### 対比④：kirim（送る）
手紙を相手に送る場面です。
- **`mengirimkan`（-kan）**: 「**（手紙・荷物を）送る**」 ➔ 動くのは「手紙（物）」！
- **`mengirimi`（-i）**: 「**（相手の人に）送ってあげる**」 ➔ 目的語は受け取る「人（受取人）」！

- `Saya mengirimkan surat kepada teman.`（私は友人に手紙を送った）
- `Saya mengirimi teman surat.`（私は友人に手紙を送った）

## 3. 要約対比マトリックス

| 語根 | meN-...-kan（目的語が動く！） | meN-...-i（目的語は場所・人！） |
| :--- | :--- | :--- |
| **duduk**（座る） | `mendudukkan anak`（子供を座らせる） | `menduduki kursi`（椅子に座る） |
| **masuk**（入る） | `memasukkan koin`（コインを入れる） | `memasuki ruangan`（部屋に入る） |
| **kirim**（送る） | `mengirimkan paket`（小包を送る） | `mengirimi ibu uang`（母にお金を送る） |
| **jatuh**（落ちる） | `menjatuhkan gelas`（グラスを落とす） | `menjatuhi lantai`（床の上に落ちかかる） |
| **tanam**（植える） | `menanamkan modal`（資本を投下する） | `menanami kebun`（庭に植える） |
