# 接頭辞 ber- と meN- の対比と使い分け

インドネシア語を学ぶ上で、誰もが一度は「同じ語根なのに `ber-` がついたり `meN-` がついたりして混乱する！」という壁にぶつかります。

しかし、この2つの接頭辞の「**動作の向き（ベクトル）**」の違いを一度インストールしてしまえば、初見の単語であってもどちらを使うべきかが直感的に見抜けるようになります。

---

## 1. コア概念の対比：内向きの ber- vs 外向きの meN-

```
【 ber- のベクトル（内向き）】
      主語 ─── (動作・状態) ───> 主語自身に留まる（自動詞）
      ※目的語を取らない！「主語がそうなる / 主語がそれを持っている」

【 meN- のベクトル（外向き）】
      主語 ─── (働きかけ) ───> 外部の対象・目的語へ（他動詞）
      ※目的語が必須！「主語が外部の対象をどうこうする」
```

| 比較項目 | 接頭辞 ber- | 接頭辞 meN- |
| :--- | :--- | :--- |
| **動詞の性質** | **自動詞**（Verba Intransitif） | 主に**他動詞**（Verba Transitif） |
| **目的語（O）** | 取らない（前置詞句が続く） | 必須（直後に目的語を置く） |
| **動作の対象** | 主語自身、または相互 | 外部の対象物・相手 |
| **受動態（di-）** | 変換できない（受動態なし） | **受動態（di-）に変換できる** |

---

## 2. 同一語根での意味激変ペア（最頻出6選）

同じ語根から、`ber-` と `meN-`（または meN-...-kan）によって対照的な意味が生まれる代表例です。

| 語根 | ber- の派生語（自動詞） | 意味 | meN- の派生語（他動詞） | 意味 |
| :--- | :--- | :--- | :--- | :--- |
| **ajar** | **belajar** | 学ぶ・勉強する（主語が学ぶ） | **mengajar** | 〜を教える（相手に教える） |
| **henti** | **berhenti** | 立ち止まる・停止する | **menghentikan** | 〜を停止させる・止める |
| **ubah** | **berubah** | （自然に）変わる・変化する | **mengubah** | 〜を変える・変更する |
| **pindah** | **berpindah** | 引っ越す・移住する | **memindahkan** | 〜を移動させる・移す |
| **tukar** | **bertukar** | （互いに）交換し合う | **menukar** | 〜を別のものと交換する |
| **kumpul** | **berkumpul** | （人々が）集まる | **mengumpulkan** | 〜を集める・収集する |

<div class="id-example" markdown>

<div class="id-sentence">
Bis itu berhenti di depan halte, lalu sopir menghentikan mesinnya.
</div>
<div class="id-reading">
ビス イトゥ ブルヘンティ ディ デパン ハルテ ラル ソピル ムンヘンティカン ムスィンニャ
</div>
<div class="id-meaning">
そのバスはバス停の前で止まり（berhenti）、それから運転手はエンジンを止めました（menghentikan）。
</div>

</div>

> 「バス自身が止まる」のは自動詞 `berhenti`。「運転手がエンジンを止める」のは他動詞 `menghentikan`。この対比がインドネシア語の美しさです。

## 3. 文型パターンの対比

### 3.1 [主語] ＋ ber-[語根] (＋ 前置詞句)
目的語は取れないため、相手や場所を述べる場合は前置詞（`dengan`, `di`, `ke` 等）が必要です。

- `Saya bertemu **dengan** teman lama.`（私は旧友と会いました ➔ ❌ Saya bertemu teman lama）
- `Mereka berbicara **tentang** politik.`（彼らは政治について話している）

### 3.2 [主語] ＋ meN-[語根] ＋ [目的語]
前置詞を挟まず、名詞（目的語）を直接置きます。

- `Saya menemui dosen di kampus.`（私は大学で教授に面会しました）
- `Mereka membicarakan masalah itu.`（彼らはその問題を話し合っている）
