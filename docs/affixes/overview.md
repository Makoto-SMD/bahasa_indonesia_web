# 接辞システム概要と語根（Kata Dasar）の基本概念

インドネシア語を学ぶすべての人が直面する、最もエキサイティングで奥深い領域が**「接辞システム（Sistem Imbuhan）」**です。

インドネシア語は、核となる**「語根（Kata Dasar）」**と呼ばれるシンプルな基本単語に、パーツ（接辞）を前・後ろ・両側にカチャカチャとレゴブロックのように組み合わせることで、**名詞・動詞・形容詞・受動態・使役など無数の新しい単語を論理的に生み出す言語**（膠着語的性質）です。

接辞の仕組みを理解すると、**1つの語根を覚えるだけで10個〜20個の関連単語が一網打尽**にできるようになります。

---

## 1. 語根（Kata Dasar）とは何か？

語根とは、**いかなる接辞もついていない、意味の純粋な「核」となる基本単語**のことです。

インドネシア語の辞書（KBBIなど）の見出し語は、基本的にすべてこの**「語根のアルファベット順」**で並んでいます。したがって、知らない派生語に出会ったときは、接辞を頭の中で剥ぎ取って「語根」を見つけ出さなければ辞書を引くことすらできません。

### 語根ファミリーの例：`ajar`（教え・学び）
1つの語根 `ajar` から、接辞によってこれだけの言葉が整然と生まれます。

```
                     ┌── belajar（学ぶ・勉強する [自動詞]）
                     ├── mengajar（〜を教える [他動詞]）
      ajar           ├── pelajar（学習者・生徒 [名詞]）
 (教え・学び)        ├── pengajar（教える人・教員 [名詞]）
                     ├── pelajaran（教科・授業・レッスン [名詞]）
                     └── pengajaran（教授法・教育活動 [名詞]）
```

## 2. 接辞の4大分類（Imbuhan）

接辞は、語根の「どこにくっつくか」によって4種類に分類されます。

| 種類 | インドネシア語名 | くっつく位置 | 主な接辞 | 例（語根 ➔ 派生語） |
| :--- | :--- | :--- | :--- | :--- |
| **接頭辞** | Awalan (Prefiks) | 語根の**前** | `meN-`, `ber-`, `di-`, `ter-`, `pe-`, `se-` | `tulis` ➔ **`menulis`**（書く） |
| **接尾辞** | Akhiran (Sufiks) | 語根の**後ろ** | `-kan`, `-i`, `-an` | `makan` ➔ **`makanan`**（食べ物） |
| **周囲辞** | Konfiks (Sirkumfiks) | 語根の**前後両方** | `ke-...-an`, `peN-...-an`, `per-...-an` | `sehat` ➔ **`kesehatan`**（健康） |
| **挿入辞** | Sisipan (Infiks) | 語根の**途中** | `-el-`, `-em-`, `-er-`（現代では化石化） | `gigi` ➔ **`gerigi`**（ノコギリの刃） |

---

## 3. 主要な接辞とその役割のクイックマップ

今後の講義で1つずつ徹底解剖していく主要接辞の役割一覧です。

### 3.1 主な接頭辞（Prefiks）
- **`meN-`**: 能動態動詞を作る（主語が何かを行う行為）。
- **`ber-`**: 自動詞・所有・状態を作る（主語自身に関する状態や動作）。
- **`di-`**: 三人称の受動態を作る（〜される）。
- **`ter-`**: 最上級（もっとも〜）、無意図・偶発（うっかり〜してしまう）、完了・自発。
- **`peN-`**: 行為者（〜する人）や道具（〜するもの）を作る。
- **`se-`**: 1つの単位（〜個）、同一性（同じくらい〜）。

### 3.2 主な接尾辞（Sufiks）
- **`-kan`**: 使役（〜させる）、受益（〜のためにする）、他動詞化。
- **`-i`**: 場所・対象への反復動作、〜を与える。
- **`-an`**: 動作の結果（食べ物、書き物）、道具、集合名詞。

### 3.3 主な周囲辞（Konfiks）
- **`ke-...-an`**: 形容詞・名詞から抽象名詞を作る（例: `adil` 公正 ➔ `keadilan` 正義）、過度・被害。
- **`peN-...-an`**: 動作の過程・プロセス・行政手続きを表す名詞。

<div class="id-example" markdown>

<div class="id-sentence">
Pemerintah mengumumkan kebijakan baru untuk meningkatkan keselamatan lalu lintas.
</div>
<div class="id-reading">
プムリンタ ムングムムカン クビジャカン バル ウントゥッ ムニンカッカン クスラマタン ラル リンタス
</div>
<div class="id-meaning">
政府は交通安全を向上させるための新しい政策を発表しました。
</div>

</div>

> 上記の例文には、語根 `perintah`（命令）➔ `pemerintah`（政府）、`umum`（公）➔ `mengumumkan`（発表する）、`bijak`（賢い）➔ `kebijakan`（政策）、`tingkat`（階）➔ `meningkatkan`（向上させる）、`selamat`（無事）➔ `keselamatan`（安全性）と、接辞がぎっしり詰まっています！

## 4. 辞書を引くための「語根特定テクニック」

インドネシア語学習者が辞書を引くときは、以下の順番で逆算して語根を割り出します。

1. **周囲辞や接尾辞を外す**: 末尾の `-kan`, `-i`, `-an` を取り除く。
2. **接頭辞を外す**: 先頭の `me-`, `ber-`, `di-`, `ter-`, `pe-`, `se-` を取り除く。
3. **鼻音化の復元**: 接頭辞が `men-`, `mem-`, `meng-`, `meny-` だった場合、頭文字が `k, t, s, p` のどれかから変化していないか照合する。
