# 接頭辞 pe- / peN- の動作主・道具・性質の形成

接頭辞 **`pe-`** および **`peN-`** は、動詞や名詞、形容詞から「**〜する人（行為者・職業）」「〜するための道具」「〜な性格・傾向を持つ人**」という名詞を作り出します。英語の `-er`（`teach` ➔ `teacher`、`write` ➔ `writer`）に相当する接頭辞です。

最大の朗報は、**`peN-` の音韻変化ルールが `meN-` と 100% 完全一致している**という点です。すでに学んだ「K, T, S, P 脱落」の知識がそのまま使えます！

---

## 1. peN- と meN- の完全な平行性

語根の頭文字による鼻音化（m, n, ng, ny）の変わり方は、`meN-` と瓜二つです。

| 語根 | meN- 動詞 | peN- 名詞 | 意味（行為者・道具） |
| :--- | :--- | :--- | :--- |
| **tulis**（K-T-S-P: T脱落） | `menulis`（書く） | **penulis** | 筆者・作家・ライター |
| **pakai**（K-T-S-P: P脱落） | `memakai`（使う） | **pemakai** | 使用者・ユーザー |
| **sapu**（K-T-S-P: S脱落） | `menyapu`（掃く） | **penyapu** | 清掃員・ほうき |
| **kirim**（K-T-S-P: K脱落） | `mengirim`（送る） | **pengirim** | 送信者・差出人 |
| **baca** | `membaca`（読む） | **pembaca** | 読者 |
| **beli** | `membeli`（買う） | **pembeli** | 買い手・客 |
| **jual** | `menjual`（売る） | **penjual** | 売り手・店員 |
| **ajar** | `mengajar`（教える） | **pengajar** | 教員・講師 |
| **cat**（1音節語根） | `mengecat`（塗る） | **pengecat** | 塗装工 |

<div class="id-reading">

</div>

## 2. pe-（鼻音化なし）と ber- 動詞の連携

`peN-` が「他動詞（meN-）」に対応するのに対し、鼻音化しないシンプルな **`pe-`** は、主に**「自動詞（ber-）」に対応する行為者**を作ります。

| 語根 | ber- 動詞（自動詞） | pe- 名詞（行為者） | 意味 |
| :--- | :--- | :--- | :--- |
| **kerja** | `bekerja`（働く） | **pekerja** | 労働者・ワーカー |
| **renang** | `berenang`（泳ぐ） | **perenang** | 水泳選手 |
| **lari** | `berlari`（走る） | **pelari** | ランナー・走者 |
| **ajar** | `belajar`（学ぶ） | **pelajar** | 学生・生徒 |

> 【**見分けの超重要対比：ajar の場合**】
> - `ajar` ➔ `belajar`（自分が学ぶ）に対応する人は **`pelajar`**（生徒・学習者）
> - `ajar` ➔ `mengajar`（人に教える）に対応する人は **`pengajar`**（先生・教員）

## 3. 「道具・器具」を作る peN-

人間だけでなく、特定の動作を行うための「道具・機械・文房具」の名前も作ります。

- `hapus`（消す） ➔ **`penghapus`**（消しゴム・黒板消し）
- `buka`（開ける） ➔ **`pembuka botol`**（栓抜き / 缶切り）
- `hangat`（温かい） ➔ **`penghangat ruangan`**（ヒーター・暖房器具）
- `dingin`（冷たい） ➔ **`pendingin udara`**（エアコン ＝ AC）

## 4. 人の「癖・性格」を表す pe- / peN-

形容詞や名詞につくと、「**その性質を強く持っている人**」「**〜癖のある人**」という意味になります。

- `malu`（恥ずかしい） ➔ **`pemalu`**（恥ずかしがり屋・人見知りの人）
- `malas`（怠惰な） ➔ **`pemalas`**（怠け者）
- `marah`（怒る） ➔ **`pemarah`**（怒りっぽい人・短気な人）
- `bohong`（嘘） ➔ **`pembohong`**（嘘つき）
- `rokok`（タバコ） ➔ **`perokok`**（喫煙者・タバコを吸う人）
