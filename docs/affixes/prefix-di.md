# 接頭辞 di- による受動構文の完全整理

能動態の接頭辞 `meN-` が「K, T, S, P 脱落」など複雑な音韻変化を伴うのに対し、受動態の接頭辞 **`di-`** は驚くほどシンプルです。

どんな語根であっても、**頭文字に関係なく単に `di-` をペタッとくっつけるだけ**で完成します（例: `beli` ➔ `dibeli`、`tulis` ➔ `ditulis`、`ambil` ➔ `diambil`）。

本講では、この接頭辞 `di-` を使った三人称受動構文の完全なメカニズムと、接尾辞（`-kan`, `-i`）と連携する発展的な受動態まで体系的に整理します。

---

## 1. 能動態（meN-）から受動態（di-）への変換ステップ

受動態を作る手順は、英語の受動態変換と非常によく似ています。

```
能動態:  [動作主 (S)]      ──>  meN-[語根]  ──>  [対象・目的語 (O)]
               │                     │                     │
               ▼                     ▼                     ▼
受動態:  [対象・主語 (S)]   ──>   di-[語根]   ──>  (oleh) [動作主]
```

### 具体例：
- 能動態: `Budi membaca buku ini.`（ブディはこの本を読んでいる）
  1. 目的語 `buku ini` を文頭に持ってくる。
  2. 動詞 `membaca` の `meN-` を **`di-`** に替える ➔ **`dibaca`**。
  3. 元の主語 `Budi` の前に `oleh`（〜によって）を添えて後ろに回す。
- 受動態: **`Buku ini dibaca oleh Budi.`**（この本はブディによって読まれている）

## 2. 前置詞 oleh（〜によって）の省略ルール

動作主を示す前置詞 `oleh` は、いつでも必ず書かなければいけないわけではありません。明確な省略ルールがあります。

### 2.1 oleh を省略できるケース
受動態動詞の**すぐ直後に動作主がぴったり隣接している場合**、`oleh` は省略可能です。

- `Surat ini ditulis oleh sekretaris.` ➔ **`Surat ini ditulis sekretaris.`**（⭕ 省略OK）
- `Kue itu dimakan oleh adik.` ➔ **`Kue itu dimakan adik.`**（⭕ 省略OK）

### 2.2 oleh を絶対に省略できないケース
動詞と動作主の間に、**副詞や時間・場所の語句が挟まる場合**、`oleh` を省略すると誰が動作をしたのか文構造が壊れてしまうため、省略は禁止されます。

- ⭕ `Buku ini ditulis kemarin **oleh** Budi.`
- ❌ `Buku ini ditulis kemarin Budi.`（文法崩壊）

## 3. 複合受動態：di-...-kan と di-...-i

接頭辞 `di-` は、接尾辞 `-kan`（使役・受益）や `-i`（反復・場所付与）とペアを組んで「周囲辞」として頻出します。

| 複合接辞 | 語根 | 派生語（受動態） | 能動態 | 意味（受動） |
| :--- | :--- | :--- | :--- | :--- |
| **di-...-kan** | `buka`（開く） | **dibukakan** | membukakan | 〜のために開けられる |
| | `bersih`（清潔） | **dibersihkan** | membersihkan | 清掃される・きれいにされる |
| | `kirim`（送る） | **dikirimkan** | mengirimkan | 送信される・届けられる |
| **di-...-i** | `teman`（友） | **ditemani** | menemani | 同伴される・付き添われる |
| | `isi`（中身） | **diisi** | mengisi | 満たされる・記入される |
| | `tahu`（知る） | **diketahui** | mengetahui | 知られている |

## 4. 表記の再確認：前置詞 di vs 接頭辞 di-

正書法（EYD）の最も代表的な採点基準です。

- **場所の前置詞**: 単語と単語なので**スペースを空ける**。
  - `di kantor`（オフィスで）
  - `di stasiun`（駅で）
  - `di rumah`（家で）
- **受動態の接頭辞**: 接辞なので**隙間なくくっつける**。
  - `dijual`（売られている）
  - `dibeli`（買われる）
  - `dilarang`（禁止される）
