# 実践対話・トラブル解決：EC通販の返品・返金交渉と開封動画（Tokopedia & Shopee Komplain）

インドネシアの2大オンラインマーケットプレイスTokopediaとShopee。購入した商品が偽物（barang palsu / KW）、サイズや色の違い（salah ukuran / warna）、不良品・初期不良（barang cacat / rusak）、そして購入者保護の生命線である「開封動画（video unboxing）」を武器に返品・返金（retur & refund）を成功させるための実践対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **video unboxing** | 開封動画 | トラブル解決の絶対必須条件 |
| **komplain pesanan / ajukan retur** | 注文への異議申立 / 返品申請 | 取引完了ボタンを押す前に申請 |
| **barang cacat / rusak** | 不良品・キズ物 / 破損品 | 初期不良の申し立て |
| **barang palsu / barang KW** | 偽造品・コピー商品 | KWはジャカルタ俗語 |
| **resi pengembalian barang** | 返品荷物の送り状（着払い伝票） | 出品者宛てへの返送番号 |
| **ongkir retur ditanggung penjual** | 返送送料は出品者が負担する | 不良品時の基本ルール |
| **selesaikan pesanan** | 取引を完了する（受取完了） | 押すと代金が出品者へ渡るため厳禁 |

## 2. リアル実践対話シナリオ（出品者とのチャット交渉 & 仲裁申請）

購入者（Pembeli）が、届いたワイヤレスイヤホンが充電できず偽物だったため、出品者（Penjual / Seller）にチャットで返品を要求し、応じない場合はプラットフォームの仲裁（Pusat Resolusi）へ持ち込みます。

<div class="id-example">
<div class="id-sentence"><strong>Pembeli:</strong> Halo Seller, paket TWS Bluetooth sudah saya terima tadi siang. Namun setelah saya coba cas selama tiga jam, unit sebelah kiri sama sekali tidak menyala dan tidak bisa terhubung ke ponsel. Nomor seri di kotak juga tidak terdaftar di situs resmi (barang palsu/KW). Saya minta retur dan pengembalian dana penuh ya.</div>
<div class="id-translation"><strong>購入者:</strong> こんにちは、出品者様。TWS Bluetoothイヤホンの荷物を先ほど受け取りました。しかし3時間充電してみたものの、左側のユニットが全く起動せずスマートフォンに接続できません。また箱のシリアル番号も公式サイトに登録されていません（偽造品/コピー商品です）。商品の返品と全額返金をお願いいたします。</div>
<div class="id-explanation">cas（充電する＝charge） / unit sebelah kiri tidak menyala（左ユニットがつかない） / nomor seri tidak terdaftar（シリアル番号が未登録） / pengembalian dana penuh（全額返金）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Seller:</strong> Halo Kak, sebelum dikirim barang sudah kami tes dan berfungsi normal. Kalau segel plastik sudah dibuka, toko kami tidak menerima retur barang elektronik. Silakan bawa sendiri ke service center resmi ya.</div>
<div class="id-translation"><strong>出品者:</strong> こんにちは。発送前にお品物は動作確認テストを行っており、正常に作動していました。プラスチックの封印を開封された場合、当店では電化製品の返品はお受けできません。ご自身で正規サービスセンターへお持ち込みください。</div>
<div class="id-explanation">segel plastik sudah dibuka（封印フィルムが開封された） / tidak menerima retur（返品を受け付けない）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pembeli:</strong> Jangan lepas tanggung jawab begitu ya. Saya memiliki rekaman video unboxing lengkap tanpa jeda (tanpa cut/edit) sejak paket masih tersegel rapi oleh kurir, yang membuktikan langsung bahwa produk memang cacat fungsi dari awal. Saya sudah klik tombol 'Ajukan Komplain' di Pusat Resolusi Tokopedia. Jika Seller menolak, biarkan pihak admin Tokopedia yang memutuskan dan menahan dana pembayaran.</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 異議申立の定型文
- **Saya belum menekan tombol 'Selesaikan Pesanan' karena barang yang dikirim tidak sesuai dengan deskripsi produk.**
  （送られてきた商品が商品説明と一致していないため、私はまだ「取引完了」ボタンを押していません。）
- **Tolong kirimkan label pengiriman balik (resi retur) agar saya bisa mengantarkan paket ini ke gerai kurir J&T terdekat.**
  （最寄りのJ&Tクーリエ店舗へこの荷物を持ち込めるよう、返送用送り状（着払いバーコード）を発行してください。）

### 誤配送（サイズ・色違い）
- **Saya memesan sepatu ukuran 42 warna putih, tetapi yang datang ukuran 40 warna hitam.**
  （私はサイズ42の白の靴を注文したのに、届いたのはサイズ40の黒でした。）

## 4. 現地のリアル事情・生活のヒント

> [!IMPORTANT]
> **「Video Unboxing（開封動画）」は現代インドネシアの絶対鉄則**:
> Tokopedia、Shopee、Lazadaなどインドネシアの全ECサイトでは、**「配達伝票（Resi）がはっきり映った未開封状態から、ハサミを入れて中身を取り出し、電源を入れて動作確認するまでを1本のノーカット動画（Video Unboxing tanpa jeda）で撮影すること」**が、クレーム時の公式必須要件（Syarat Wajib Komplain）に指定されています。
> 高額な家電やパソコン、衣類が届いた際は、どんなに面倒でもスマホで開封動画を撮影しながら荷解きをする習慣を徹底しましょう。

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 不良品が届いた際、絶対に押してはいけないアプリのボタンは？</summary>
<strong>正解: Selesaikan Pesanan（Pesanan Diterima / 取引完了）</strong><br>
解説: これを押すと「問題なく受け取った」とみなされ、出品者に売上金が即時振り込まれて返品不可になります。
</details>

<details class="id-quiz">
<summary>Q2. ネット通販で返品クレームを通すための絶対必須素材は？</summary>
<strong>正解: Video unboxing（開封動画）</strong><br>
解説: 配達時の未開封からノーカットで撮影された動画が唯一無二の客観的証拠となります。
</details>
