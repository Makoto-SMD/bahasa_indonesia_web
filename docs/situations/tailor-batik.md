# 実践対話・伝統文化：仕立て屋でのバティック採寸・オーダーメイド（Penjahit & Jahit Batik）

市場や専門店（Pasar Mayestik, Thamrin City, Batik Danar Hadi）で購入した高級バティック生地（kain batik tulis / cap）。街の仕立て屋（Penjahit / Tailor）に持ち込んで、自分の体型にぴったりフィットする長袖フォーマルシャツ（kemeja batik lengan panjang）をオーダーメイドするための採寸・裏地（furing）・柄合わせ（motif sambung）に関する実践対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **penjahit / tukang jahit** | 仕立て屋・洋服仕立て職人 | Mayestikや専門店街に密集 |
| **jahit kemeja / jahit baju** | シャツを仕立てる・縫製する | オーダーメイドの基本動詞 |
| **kain batik (batik tulis / cap)** | バティック生地（手描き / 型押し蝋結染め） | 通常2.5m前後の布地 |
| **lengan panjang / pendek** | 長袖 / 半袖 | フォーマル用は必ず長袖 |
| **lapisan furing (furing katun/sutra)** | 裏地・ライニング（綿/絹） | 着心地と耐久性を高める裏地 |
| **motif sambung (motif simetris)** | 前合わせ・胸ポケットの柄合わせ | 腕利きの仕立て職人の証 |
| **ukur badan / pita ukur** | 身体の採寸 / メジャー（巻尺） | 肩幅、胸囲、袖丈等の計測 |
| **ongkos jahit** | 仕立て工賃（縫製工賃） | 20万〜50万ルピア程度 |

## 2. リアル実践対話シナリオ（仕立て屋での採寸と細部デザインの打ち合わせ）

顧客（Pelanggan）が、購入した手描きバティック布（Kain Batik Tulis）を持参して仕立て職人（Penjahit）と打ち合わせを行います。

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Selamat siang, Pak Penjahit. Saya membawa kain batik sutra tulis halus ini dari Solo. Saya ingin menjahit kemeja batik pria lengan panjang ukuran pas badan (slim fit) untuk menghadiri acara resepsi diplomatik dan pernikahan.</div>
<div class="id-translation"><strong>客:</strong> こんにちは、仕立て職人さん。ソロで購入した上質な手描きシルク・バティック生地を持ってきました。外交レセプションや結婚式に出席するため、体にフィットしたスリムフィットの長袖男性用バティックシャツを仕立てていただきたいのですが。</div>
<div class="id-explanation">kain batik sutra tulis halus（上質な手描きシルクバティック布） / kemeja batik lengan panjang（長袖バティックシャツ） / ukuran pas badan (slim fit)（体にフィットしたスリム仕立て） / resepsi diplomatik（外交レセプション）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Penjahit:</strong> Selamat siang, Pak. Wah, motif batiknya sangat indah dan klasik sekali. Mari berdiri tegak di depan cermin, saya ukur badannya dulu. Lebar bahu 46 cm, lingkar dada 102 cm, panjang lengan 61 cm, dan panjang baju 74 cm. Untuk kerahnya ingin model kerah kemeja standar atau kerah Shanghai (mandarin collar)?</div>
<div class="id-translation"><strong>職人:</strong> こんにちは。おお、バティックの文様が非常に美しく格調高いですね。鏡の前に真っ直ぐお立ちください、まずお身体の採寸をいたします。肩幅46cm、胸囲102cm、裄丈（袖丈）61cm、着丈74cmですね。襟の形は標準的なシャツカラー（レギュラーカラー）とマオカラー（スタンドカラー・上海襟）のどちらがお好みですか？</div>
<div class="id-explanation">lebar bahu（肩幅） / lingkar dada（胸囲） / panjang lengan（袖丈） / kerah kemeja standar（標準襟） / kerah Shanghai（スタンドカラー）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Kerah kemeja standar saja ya. Yang paling penting, tolong bagian depan kancing dan saku dada kiri motif batiknya dibuat menyambung rapi (motif sambung tanpa terputus). Dan tolong pasang lapisan furing katun yang halus dan adem di bagian dalam agar nyaman dipakai di ruangan ber-AC maupun di luar.</div>
<div class="id-translation"><strong>客:</strong> 標準のシャツ襟でお願いします。最も重要な点として、前立てのボタン部分と左胸ポケットのバティック柄が、途切れずに美しく柄合わせ（motif sambung）されるようにお願いします。それと、エアコンの室内でも外でも快適に着られるよう、内側には肌触りが滑らかで涼しい綿の裏地（Furing）を全面に張ってください。</div>
<div class="id-explanation">motif menyambung rapi（柄が綺麗につながっている・柄合わせ） / saku dada kiri（左胸ポケット） / lapisan furing katun yang adem（涼しい綿の裏地ライニング）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Penjahit:</strong> Siap, Pak. Menjaga kesinambungan motif adalah keahlian utama kami. Ongkos jahit termasuk furing katun premium adalah Rp350.000. Waktu pengerjaannya sekitar satu minggu, nanti kalau sudah selesai bisa dicoba fitting terlebih dahulu di toko kami.</div>
<div class="id-translation"><strong>職人:</strong> かしこまりました。柄の連続性を美しく保つ柄合わせは、まさに当店の腕の見せ所です。高級コットン裏地込みの仕立て代は35万ルピアとなります。仕上がり所要期間は約1週間で、完成しましたら当店にてフィッティング（試着）をしてサイズ感を最終確認していただけます。</div>
<div class="id-explanation">menjaga kesinambungan motif（柄の連続性を保つ） / ongkos jahit（仕立て工賃） / dicoba fitting（フィッティング試着をする）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 試着時のサイズ修正（Revisi）
- **Bagian pinggang dan ketiak terasa agak terlalu sempit saat saya mengangkat tangan, bisakah dilebarkan satu sentimeter?**
  （腕を上げた時に腰回りと脇の下が少し窮屈すぎるので、1cmほど幅を出して（広げて）もらえますか？）
- **Lengan kemeja ini sedikit terlalu panjang menutup pergelangan tangan, tolong dipotong dan dinaikkan dua sentimeter.**
  （シャツの袖が少し長すぎて手首を覆ってしまうので、2cmほど丈を詰めて短くしてください。）

### 残り布（Sisa Kain）の返却
- **Tolong sisa potongan kain batiknya dikembalikan kepada saya ya, untuk dibuatkan masker atau syal kecil.**
  （マスクやミニスカーフを作りたいので、カットした残りのバティック布のハギレも一緒に返却してくださいね。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **「Motif Sambung（柄合わせ）」が高級仕立ての決定打**:
> 既成品の安いバティックシャツと、腕利きの仕立て屋による高級オーダーシャツの最大の違いは、**「フロントのボタンを留めた時に、左右の絵柄が1枚の絵画のように完璧につながっているか（motif sambung）」**、および**「胸ポケットがどこにあるか分からないほど背景の柄と完全に同化して縫い合わされているか」**です。
> 仕立てに出す際は、必ず職人に「Tolong motifnya harus nyambung ya（必ず柄合わせしてくださいね）」と念押しするのが通のオーダー作法です。

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. バティックシャツの内側に汗取り・型崩れ防止で張る「裏地」は？</summary>
<strong>正解: Furing（Lapisan furing）</strong><br>
解説: 高級バティックには綿（katun）や絹（sutra）の裏地が必須です。
</details>

<details class="id-quiz">
<summary>Q2. 胸ポケットや前立てのバティック柄を途切れず一体化させる技術を何と言う？</summary>
<strong>正解: Motif sambung / Motif nyambung</strong><br>
解説: 繋ぐ（sambung）柄という意味で、仕立て職人の腕前を測る指標です。
</details>
