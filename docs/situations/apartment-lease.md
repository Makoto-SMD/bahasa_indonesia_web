# 実践対話・トラブル解決：アパート契約更新・家賃交渉・退去立会い（Perpanjang Sewa & Pindah）

契約満了前の更新通知、家賃（biaya sewa）の値上げ交渉、敷金・保証金（uang jaminan / deposit）の全額返還と退去時の点検立会い（serah terima unit）。海外駐在員・留学生必修の不動産実務対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **perpanjang kontrak / perpanjangan sewa** | 契約更新 / 賃貸延長 | 通常2〜3ヶ月前に意思表示 |
| **biaya sewa / uang sewa** | 家賃・賃借料 | 年払い（bayar tahunan）が一般的 |
| **uang deposit / uang jaminan** | 敷金・保証金 | 家賃1〜2ヶ月分が相場 |
| **IPL (Iuran Pengelolaan Lingkungan)** | 管理費・共益費 | 家賃込みか別か確認必須 |
| **serah terima unit / kunci** | 部屋・鍵の引き渡し | 入居時と退去時に書面作成 |
| **kondisi awal** | 入居当初の状態・原状 | 原状回復義務の基準 |
| **pemilik unit (owner) / agen properti** | オーナー（大家） / 不動産仲介業者 | やり取りの相手先 |

## 2. リアル実践対話シナリオ（オーナー・仲介業者との家賃交渉 & 退去点検）

### シーンA: 契約更新にあたって家賃据え置きを交渉する

<div class="id-example">
<div class="id-sentence"><strong>Penyewa:</strong> Selamat sore, Ibu Maria. Mengenai kontrak sewa apartemen saya yang akan berakhir dua bulan lagi, saya sangat berminat untuk memperpanjangnya satu tahun ke depan. Namun, apakah biaya sewanya bisa tetap sama dengan tahun ini?</div>
<div class="id-translation"><strong>借主:</strong> こんにちは、マリアさん。あと2ヶ月で満了するアパートの賃貸契約についてですが、今後1年間の更新を前向きに希望しております。ただ、家賃については今年度と同額に据え置いていただくことは可能でしょうか？</div>
<div class="id-explanation">berakhir dua bulan lagi（あと2ヶ月で満了する） / berminat untuk memperpanjang（更新を希望する） / tetap sama（同額・現状維持）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pemilik:</strong> Halo, Pak Tanaka. Sebenarnya ada kenaikan biaya IPL dari pengelola gedung. Tapi karena Bapak selalu membayar tepat waktu dan merawat unit dengan sangat baik, saya setuju untuk tidak menaikkan harga sewa tahun ini.</div>
<div class="id-translation"><strong>オーナー:</strong> こんにちは、田中さん。実はビル管理会社からの管理費（IPL）の値上げがあったのです。ですが、田中さんは常に期日通りにお支払いいただき、お部屋もとても綺麗に使ってくださっているので、今年度の家賃値上げは見送る（据え置く）ことに同意しますよ。</div>
<div class="id-explanation">kenaikan biaya IPL（管理費の値上げ） / membayar tepat waktu（期日通りに支払う） / merawat unit（部屋を丁寧に手入れする）。</div>
</div>

### シーンB: 退去時の部屋立会い点検と敷金（デポジット）の返還確認

<div class="id-example">
<div class="id-sentence"><strong>Penyewa:</strong> Seluruh perabotan sudah saya bersihkan dan dinding yang pernah dipasang lukisan sudah ditambal rapi sesuai kondisi awal. Ini berita acara serah terima dan kunci unitnya.</div>
<div class="id-translation"><strong>借主:</strong> すべての家具を清掃し、絵画を掛けていた壁の穴も入居当初の状態に合わせて綺麗に補修いたしました。こちらが引き渡し調書（Berita Acara）と部屋の鍵です。</div>
<div class="id-explanation">ditambal rapi（綺麗に穴埋め補修された） / sesuai kondisi awal（原状に合わせて） / berita acara serah terima（引き渡し調書・立会い議事録）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Agen:</strong> Baik, mari kita periksa bersama. Kondisi kulkas, AC, dan mesin cuci semuanya berfungsi normal. Kapan uang deposit sebesar satu bulan sewa akan ditransfer kembali ke rekening Bapak? Paling lambat dalam 14 hari kerja setelah dipotong tagihan listrik terakhir.</div>
<div class="id-translation"><strong>エージェント:</strong> はい、では一緒に点検いたしましょう。冷蔵庫、エアコン、洗濯機の状態はすべて正常に作動していますね。1ヶ月分相当の敷金（デポジット）はいつ口座に返金送金されるかですが、最終の電気代請求を精算（控除）した後、最長でも14営業日以内に返金されます。</div>
<div class="id-explanation">berfungsi normal（正常に機能している） / ditransfer kembali ke rekening（銀行口座へ返金送金される） / dipotong tagihan terakhir（最終請求額を控除したのち）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 敷金返還の督促
- **Sudah lewat tiga minggu sejak saya pindah, mohon konfirmasi kapan sisa uang deposit saya akan dikembalikan.**
  （退去から3週間が過ぎました。敷金の残金がいつ返金されるのかご確認をお願いいたします。）
- **Berikut bukti transfer pembayaran tagihan listrik dan air bulan terakhir yang sudah saya lunasi.**
  （私がすでに完納した最終月の電気・水道代の振込証明書を添付いたします。）

### 修繕責任の切り分け
- **Kerusakan pada kompresor AC ini murni karena faktor usia pakai, bukan akibat kelalaian penyewa.**
  （このエアコンのコンプレッサー故障は純粋に経年劣化によるものであり、賃借人の過失によるものではありません。）

## 4. 現地のリアル事情・生活のヒント

> [!CAUTION]
> **敷金（Deposit）の返金トラブル対策**:
> インドネシアで最も多い不動産トラブルが「退去後にデポジットがなかなか返ってこない」問題です。
> これを防ぐためには、**①入居初日に部屋中の既存の傷・汚れ・エアコンの型番を写真と動画で撮影しておくこと**、**②退去時に「Berita Acara Serah Terima（BAST: 引き渡し調書）」に双方の署名をもらい、返金期日（例: 14日以内）を明記させること**が極めて重要です。

<details class="id-quiz">
<summary>Q1. マンションの「管理費・共益費」を表すインドネシアの定着略語は？</summary>
<strong>正解: IPL（Iuran Pengelolaan Lingkungan）</strong><br>
解説: 家賃に含まれているか（include IPL）、別途支払いか（exclude IPL）を必ず契約前に確認します。
</details>

<details class="id-quiz">
<summary>Q2. 部屋の引き渡し時に作成する公式な「立会い調書・確認書」は？</summary>
<strong>正解: Berita Acara Serah Terima（BAST）</strong><br>
解説: 鍵や設備の引き渡し（serah terima）の事実を証明する公的書類です。
</details>
