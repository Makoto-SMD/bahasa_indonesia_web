# 実践対話・トラブル解決：入国管理局でのKITAS手続き・写真撮影（Kantor Imigrasi & Foto Biometrik）

在留邦人全員が必ず訪れる入国管理局（Kantor Imigrasi）。一次滞在許可証（ITAS / e-KITAS）の更新、指紋採取と生体顔写真撮影（foto biometrik dan rekam sidik jari）、面談での質問対応を滞りなく完了するための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **Kantor Imigrasi (Kanim)** | 入国管理局・入管支署 | Kanim Jakarta Selatan等 |
| **KITAS / ITAS** | 限時滞在許可（証） | 就労、家族帯同、リタイア等 |
| **rekam biometrik** | 生体情報登録 | 顔写真撮影および指紋スキャン |
| **sidik jari** | 指紋 | 両手の指を順番にスキャン |
| **surat rekomendasi sponsor** | スポンサー（会社）の推薦状 | 申請時の基本添付書類 |
| **tanda bukti pendaftaran** | 申請受付票・整理券 | QRコード付きの予約票 |
| **pengambilan paspor** | パスポートの受領・返却 | スタンプ押印後の引き取り |
| **overstay (tinggal lebih masa)** | 不法滞在・オーバーステイ | 1日あたり100万ルピアの罰金 |

## 3. トラブル解決！現場で使える必修フレーズ集

### ドレスコード（服装規定）の遵守
- **Pengunjung kantor imigrasi dilarang memakai celana pendek, kaos oblong tanpa kerah, dan sandal jepit.**
  （入国管理局の来館者は、ショートパンツ、襟なしTシャツ、ビーチサンダルの着用が禁止されています。）
- **Apakah saya harus mengenakan kemeja berkerah untuk pengambilan foto KITAS?**
  （KITASの写真撮影には襟付きのシャツを着ていかなければなりませんか？）

### 代理人によるパスポート受領
- **Apakah paspor asli saya bisa diambilkan oleh staf HRD perusahaan dengan membawa surat kuasa resmi?**
  （正式な委任状（Surat Kuasa）を持参すれば、私のパスポート原本は会社の総務人事部スタッフに代理受領してもらえますか？）

## 4. 現地のリアル事情・生活のヒント

> [!CAUTION]
> **入国管理局の厳格なドレスコードと礼儀**:
> インドネシアの官公庁、特に入国管理局では**服装規定（tata tertib berpakaian）**が厳格に適用されます。ショートパンツやサンダル履きで行くと、入口の警備員に入館を断られます。必ず長ズボン、襟付きシャツ（kemeja / batik）、靴（sepatu）を着用して訪れましょう。
> また、審査官には常に敬意（Pak / Bu）をもって笑顔で挨拶し、質問には簡潔かつ事実のみを回答するのがトラブルを避ける最大のポイントです。

<details class="id-quiz">
<summary>Q1. 入管で採取される「指紋」のインドネシア語は？</summary>
<strong>正解: sidik jari</strong><br>
解説: 手の指紋は sidik jari、足は sidik kaki と言います。
</details>

<details class="id-quiz">
<summary>Q2. 代理人に手続きを委任する際に作成する「委任状」は？</summary>
<strong>正解: Surat Kuasa</strong><br>
解説: 権限（kuasa）を付与する文書＝委任状です。印紙（meterai）を貼付して署名します。
</details>
