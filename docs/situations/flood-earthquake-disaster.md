# 実践対話・防災危機管理：冠水・洪水・地震発生時の緊急避難と安否確認（Banjir & Gempa Bumi）

雨季の豪雨による道路冠水や洪水（banjir / genangan air）、環太平洋火山帯に位置するインドネシア特有の地震（gempa bumi）や津波（tsunami）。社内・家族間の安否確認（konfirmasi keselamatan）、避難場所への移動（evakuasi ke tempat aman）、救助要請（SAR / Basarnas）、インフラ遮断時の状況把握を迅速に行うための実践防災対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **banjir / genangan air** | 洪水（床上浸水等） / 道路冠水・水たまり | 雨季（musim hujan）に多発 |
| **ketinggian air mencapai lutut/pinggang** | 水深が膝 / 腰の高さに達する | 浸水レベルの伝達 |
| **gempa bumi / getaran gempa** | 地震 / 地震の揺れ | マグニチュード・震源（pusat gempa） |
| **evakuasi / jalur evakuasi** | 避難 / 避難経路・非常口 | 非常階段を使って地上へ |
| **titik kumpul darurat (assembly point)** | 緊急避難集合場所 | 広場や指定の安全空地 |
| **konfirmasi keselamatan** | 安否確認 | 全社員・家族の安全確認 |
| **BMKG (Badan Meteorologi, Klimatologi, dan Geofisika)** | 気象気候地球物理庁 | 地震・津波・豪雨警報の公式元 |
| **potensi tsunami** | 津波の可能性 | 沿岸部での避難判断 |

## 2. リアル実践対話シナリオ（地震発生直後の避難誘導 & 豪雨冠水時の安否連絡）

### シーンA: 高層ビルで強い地震が発生した際の避難指示

<div class="id-example">
<div class="id-sentence"><strong>Petugas Keamanan (Satpam):</strong> Perhatian seluruh penghuni gedung! Baru saja terjadi gempa bumi berkekuatan 6,2 magnitudo berpusat di Banten. Harap tetap tenang, jangan panik! Jangan menggunakan lift! Silakan turun menggunakan tangga darurat secara teratur menuju titik kumpul di lapangan parkir luar.</div>
<div class="id-translation"><strong>警備責任者:</strong> ビル内全滞在者の皆様にお知らせします！たった今、バンテン沖を震源とするマグニチュード6.2の地震が発生いたしました。落ち着いて、決してパニックにならないでください！エレベーターは絶対に使用しないでください！非常階段を使って整然と、屋外駐車場の指定緊急集合場所（アセンブリーポイント）へ避難してください。</div>
<div class="id-explanation">gempa berkekuatan 6,2 magnitudo（マグニチュード6.2の地震） / berpusat di Banten（バンテンを震源とする） / jangan menggunakan lift（エレベーター使用禁止） / tangga darurat（非常階段） / titik kumpul（集合場所）。</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 家族・知人への安否確認チャット
- **Keluarga kami di Jakarta semuanya aman dan tidak ada kerusakan berarti di rumah. Bagaimana kondisi kalian di sana?**
  （ジャカルタの私たち家族は全員無事で、自宅にも目立った被害はありません。そちらの状況はいかがですか？）
- **Gempa ini menurut BMKG tidak berpotensi tsunami, jadi warga pesisir pantai tidak perlu panik.**
  （BMKGの発表によると、この地震による津波の心配（可能性）はありませんので、沿岸部の住民はパニックになる必要はありません。）

### 被災・救助要請
- **Tolong kirimkan bantuan perahu karet dan makanan siap saji ke komplek kami karena aliran listrik dan air bersih padam total.**
  （電力と水道が完全に遮断されているため、私たちの住宅区画へ救難ゴムボートと即席食品の支援物資を送ってください。）

## 4. 現地のリアル事情・生活のヒント

> [!IMPORTANT]
> **BMKGアプリと「Info BMKG」の常備**:
> インドネシアの地震情報や津波警報、気象予報は、公式機関である気象気候地球物理庁（BMKG）の公式アプリ「**Info BMKG**」や公式X（旧Twitter: @infoBMKG）が最も迅速かつ正確です。
> 大きな揺れを感じた際は、デマやフェイクニュース（hoaks）に惑わされず、直ちにアプリを開いて震源地（pusat gempa）、深さ（kedalaman）、津波警報の有無（tidak berpotensi tsunami / berpotensi tsunami）を1分以内に確認する習慣を身につけましょう。
