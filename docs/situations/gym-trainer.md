# 実践対話・フィットネス：ジム入会・パーソナルトレーナーとのセッション（Fitness & Personal Trainer）

健康維持や運動不足解消のために通うフィットネスクラブ・スポーツジム（Pusat Kebugaran / Gym）。会員プランの選択（keanggotaan membership）、施設見学、パーソナルトレーナー（Personal Trainer: PT）との目標設定（ダイエット・筋力アップ・姿勢改善）、トレーニング中の負荷やフォームの指示を受けるための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **keanggotaan gym / membership** | ジム会員権・メンバーシップ | 月会費制または年一括 |
| **Personal Trainer (PT)** | 専属パーソナルトレーナー | 個別指導セッション |
| **turun berat badan / bakar lemak** | 体重を減らす・減量 / 脂肪燃焼 | ダイエットの目標 |
| **bentuk otot / membesarkan otot** | 筋肉をつける・ボディメイク | 筋力アップの目標 |
| **alat beban (barbel & dumbbell)** | フリーウェイト器具（バーベル等） | マシントレーニング |
| **pemanasan / pendinginan** | ウォーミングアップ / クールダウン | 怪我予防の前後運動 |
| **tiga set masing-masing sepuluh repetisi** | 10回をそれぞれ3セット | トレーニング回数の指示 |
| **otot pegal / kram otot** | 筋肉痛 / 筋肉の痙攣・つり | トレーニング後の痛み |

## 2. リアル実践対話シナリオ（ジム窓口での入会相談 & トレーナーとの初回指導）

### シーンA: 受付での施設見学と会員プランの確認

<div class="id-example">
<div class="id-sentence"><strong>Calon Member:</strong> Selamat sore, saya tertarik untuk bergabung menjadi anggota gym di sini. Apakah saya boleh melihat-lihat fasilitas mesin dan ruang ganti terlebih dahulu?</div>
<div class="id-translation"><strong>入会希望者:</strong> こんにちは。こちらのジムの会員に入会することに興味があるのですが。まずトレーニングマシン施設や更衣室を見学させていただくことは可能ですか？</div>
<div class="id-explanation">tertarik untuk bergabung（加入することに興味がある） / melihat-lihat fasilitas（施設を見学する） / ruang ganti（更衣室、ロッカー室）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Staf Gym:</strong> Tentu saja, mari saya antarkan berkeliling, Pak. Fasilitas kami mencakup area kardio, free weights, sauna, dan kolam renang. Untuk paket keanggotaan 12 bulan, ada promo gratis biaya pendaftaran dan gratis dua sesi pengenalan bersama Personal Trainer.</div>
<div class="id-translation"><strong>ジムスタッフ:</strong> もちろんです、ご案内して一巡りいたしましょう。当施設の設備には、有酸素運動エリア、フリーウェイト、サウナ、および温水プールが含まれております。12ヶ月の会員プランですと、入会金無料キャンペーンおよびパーソナルトレーナーによる無料導入セッション2回分が付帯しております。</div>
<div class="id-explanation">area kardio（有酸素エリア） / biaya pendaftaran（登録料・入会金） / sesi pengenalan（オリエンテーション・導入セッション）。</div>
</div>

### シーンB: パーソナルトレーナーによるトレーニング指導

<div class="id-example">
<div class="id-sentence"><strong>Trainer:</strong> Halo Pak Tanaka, fokus latihan kita hari ini adalah melatih otot dada dan trisep dengan gerakan bench press. Posisi punggung harus menempel rapat di bangku, dan bahu jangan terlalu naik.</div>
<div class="id-translation"><strong>トレーナー:</strong> こんにちは田中さん。今日の私たちのトレーニングの重点は、ベンチプレスの動作による大胸筋と上腕三頭筋の強化です。背中はベンチにしっかり密着させ、肩がすくんで上がりすぎないようにしてくださいね。</div>
<div class="id-explanation">melatih otot dada（胸の筋肉を鍛える） / bench press（ベンチプレス） / menempel rapat di bangku（ベンチにピタッとくっつく）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Member:</strong> Beban barbel ini terasa agak terlalu berat di pergelangan tangan saya. Apakah bebannya bisa dikurangi lima kilogram dulu agar bentuk gerakan saya tidak salah?</div>
<div class="id-translation"><strong>会員:</strong> このバーベルの負荷重量は、私の手首にとって少し重すぎるように感じられます。フォーム（動作の形）が崩れないよう、まずは重りを5キロ減らしていただけますか？</div>
<div class="id-explanation">beban barbel（バーベルの重量負荷） / pergelangan tangan（手首） / dikurangi lima kilogram（5キロ減らされる） / bentuk gerakan tidak salah（正しいフォームを崩さない）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Trainer:</strong> Pilihan yang sangat tepat, Pak. Lebih baik fokus pada teknik dan postur yang benar daripada memaksakan beban berat. Tarik napas saat menurunkan barbel ke dada, dan hembuskan napas kuat-kuat saat mendorong ke atas. Dorong... satu, dua, tahan... bagus sekali!</div>
<div class="id-translation"><strong>トレーナー:</strong> 非常に賢明なご判断です。無理に重いウェイトを扱うよりも、正しい技術と姿勢に集中する方がずっと効果的です。バーベルを胸へ下ろす時に息を吸い、上へ押し上げる時に息を力強く吐き出してください。押し上げて…1、2、キープ…素晴らしいです！</div>
<div class="id-explanation">memaksakan beban berat（無理に重い負荷をかける） / tarik napas（息を吸う） / hembuskan napas（息を吐く） / mendorong ke atas（上へ押し上げる）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 筋肉痛や体調の申告
- **Kaki saya masih terasa sangat pegal linu sehabis latihan squat kemarin, bisakah hari ini fokus ke tubuh bagian atas saja?**
  （昨日のスクワットのせいで脚がまだ激しい筋肉痛なので、今日は上半身のトレーニングだけに集中できますか？）
- **Tolong sediakan handuk bersih dan kunci loker sebelum saya masuk ke ruang sauna.**
  （サウナ室に入る前に、清潔なタオルとロッカーの鍵を用意してください。）

### 契約の休会・解約
- **Saya harus dinas luar kota selama dua bulan, apakah keanggotaan saya bisa dibekukan (freeze) sementara?**
  （2ヶ月間地方出張に行かなければならないのですが、私の会員資格を一時休会（フリーズ）させることは可能ですか？）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **ジャカルタのメガジム（Fitness First, Celebrity Fitness等）**:
> インドネシアの富裕層・中間層の間では健康意識の高まりからフィットネスブームが定着しており、大型モール内には「Fitness First」や「Celebrity Fitness」などの大手ジムがほぼ全館に出店しています。
> 会費交渉では「今月契約すれば会費初月無料」「入会金（joining fee）免除」といったプロモーションが頻繁に行われているため、入会時には受付カウンターで「Ada promo khusus apa bulan ini?（今月はどんな特別プロモーションがありますか？）」と必ず確認しましょう。

<details class="id-quiz">
<summary>Q1. 激しい運動後の「筋肉痛」を表すインドネシア語は？</summary>
<strong>正解: Otot pegal / Pegal-pegal（Pegal linu）</strong><br>
解説: 体のこりや筋肉痛を pegal と言います。
</details>

<details class="id-quiz">

<strong>正解: Freeze membership（Cuti gym）</strong><br>
解説: 一時凍結（freeze）する手続きを指します。
</details>
