# 実践対話・公的手続き：警察署での無犯罪証明書（SKCK）申請と指紋採取（Surat Catatan Kepolisian）

現地企業への就職、就労ビザ（KITAS/ITAS）取得、第三国ビザの申請、帰国時の手続きなどで要求される警察発行の「無犯罪経歴証明書（SKCK: Surat Keterangan Catatan Kepolisian）」。地方警察本部（Polres / Polda / Mabes Polri）での必要書類提出、指紋採取部門（Unit Sidik Jari）での十指指紋原紙作成、公的手数料（PNBP）の納付と受領をスムーズに行うための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **SKCK (Surat Keterangan Catatan Kepolisian)** | 警察証明書・無犯罪経歴証明書 | かつてのSKKB（良民証明書） |
| **Mabes Polri / Polda / Polres** | 警察庁 / 州警察本部 / 地方警察署 | 外国人はPoldaまたはMabes Polri |
| **rumus sidik jari / rekam sidik jari** | 指紋分類式 / 指紋押捺・採取 | 10本の指をインクで採取 |
| **surat rekomendasi dari sponsor/kantor** | 勤務先スポンサーからの推薦レター | 申請目的を明記した公式文書 |
| **pasfoto 4x6 latar belakang kuning/merah** | 4x6cmの証明写真（黄/赤背景） | 外国人は通常黄色背景 |
| **biaya PNBP (Penerimaan Negara Bukan Pajak)** | 非税収国家歳入公的手数料 | 公式料金 Rp30.000 |
| **masa berlaku SKCK** | 証明書の有効期間 | 発行日から6ヶ月間有効 |

## 3. トラブル解決！現場で使える必修フレーズ集

### 指紋採取時の指示
- **Tempelkan jari secara bergantian dari sisi kiri lalu gulingkan ke kanan di atas bantalan tinta.**
  （インク台の上で、指の左端から右端へ向けて順番にローリング（転がすように）押し当ててください。）
- **Setelah selesai mencap sidik jari, silakan bersihkan tangan dengan sabun dan cairan pembersih di wastafel belakang.**
  （指紋を押捺し終えましたら、奥の洗面台にある石鹸と専用洗浄液で手を綺麗に洗ってください。）

## 4. 現地のリアル事情・生活のヒント

> [!NOTE]
> **写真の背景色ルール（Latar Belakang Kuning）**:
> インドネシアの警察や行政機関における証明写真では、背景色が国籍によって厳格に指定されています。
> 一般のインドネシア国民は偶数年生まれが青（biru）、奇数年生まれが赤（merah）ですが、**外国人（WNA）のSKCK申請写真の背景色は「黄色（kuning）」**と規定されています。写真館（Studio Foto）で撮影する際は、必ず「Foto untuk SKCK WNA latar belakang warna kuning」と指定しましょう。
