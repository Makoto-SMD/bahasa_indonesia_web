# 実践対話・トラブル解決：量り売りランドリー・ドライクリーニング（Laundry Kiloan & Dry Clean）

インドネシア生活に欠かせないキロ単位の格安洗濯屋「ランドリー・キロアン（Laundry Kiloan）」や高級ドライクリーニング（Dry Clean）。衣類の預け入れ、仕上がり日数の確認、紛失（baju hilang）、縮みや色移り（luntur）、破れ（robek）などのトラブルを交渉・解決するための実践対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **laundry kiloan** | キロ単位の格安洗濯サービス | 洗濯・乾燥・アイロン込み |
| **dry clean / cuci kering** | ドライクリーニング | スーツやデリケート衣類向け |
| **cuci komplit / cuci setrika** | フル洗濯（洗濯＋アイロン仕上げ） | 1kgあたり約7,000〜12,000ルピア |
| **setrika saja** | アイロンがけのみ | 洗濯は自宅で済ませた場合 |
| **luntur / terkena luntur** | 色落ちする / 色移りする | 白シャツがピンクに染まる等 |
| **menyusut / mengkerut** | （生地が）縮む | 乾燥機の熱による縮み |
| **robek / rusak** | 破れる / 破損する | 洗濯機での引っ掛かり |
| **ganti rugi / kompensasi** | 損害賠償・補償 | 紛失や破損時の弁償規定 |

## 2. リアル実践対話シナリオ（ランドリー店への預け入れ & 色移りトラブルの抗議）

### シーンA: 衣類の預け入れと仕上がり日時の確認

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Selamat sore, Mbak. Saya mau mencuci pakaian seberat satu keranjang ini. Paketnya cuci komplit ya, sudah termasuk setrika wangi dan lipat rapi kan?</div>
<div class="id-translation"><strong>客:</strong> こんにちは。このカゴ1杯分の衣類を洗濯に出したいのですが。洗濯・アイロンがけ・綺麗にたたむところまで含んだフルセットのパッケージでお願いしますね。</div>
<div class="id-explanation">cuci komplit（全工程フルパッケージ） / setrika wangi（香り付きアイロン仕上げ） / lipat rapi（きれいにたたむ）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kasir:</strong> Baik, mari kita timbang dulu di timbangan digital... totalnya 4,5 kilogram. Untuk paket reguler selesainya dua hari lagi. Jika butuh cepat, ada paket ekspres 24 jam dengan biaya tambahan Rp5.000 per kilo.</div>
<div class="id-translation"><strong>店員:</strong> はい、まずデジタルの秤で重さを量りますね…合計で4.5キログラムです。通常便ですと仕上がりは2日後になります。お急ぎでしたら、1キロあたり5千ルピアの追加料金で24時間の特急（エクスプレス）便もございますよ。</div>
<div class="id-explanation">timbang di timbangan digital（デジタル計量器で量る） / paket reguler（通常便） / paket ekspres 24 jam（24時間特急便）。</div>
</div>

### シーンB: 預けた白シャツへの色移りトラブルに抗議する

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Mbak, tolong periksa kemeja kerja putih saya ini. Waktu saya serahkan warnanya putih bersih, tapi sekarang ada bercak noda merah muda akibat terkena luntur pakaian lain. Bagaimana ini?</div>
<div class="id-translation"><strong>客:</strong> 店員さん、私のこの仕事用の白いシャツを確認してください。お預けした時は真っ白だったのに、今は他の衣類からの色移りによってピンク色のシミ汚れがついてしまっています。これはどういうことですか？</div>
<div class="id-explanation">putih bersih（真っ白な、清潔な白） / bercak noda merah muda（ピンクのシミ） / terkena luntur（色移り被害に遭う）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kasir:</strong> Aduh, mohon maaf sekali atas kelalaian staf pencuci kami, Pak. Kami akan mencoba membersihkan kembali noda luntur ini menggunakan cairan penghilang kelunturan khusus secara gratis. Jika nodanya tetap tidak bisa hilang, kami akan memberikan ganti rugi maksimal sepuluh kali lipat dari ongkos cuci sesuai ketentuan nota.</div>
<div class="id-translation"><strong>店員:</strong> ああ、洗濯担当スタッフの不注意を深くお詫び申し上げます。専用の色移り除去液を使用して、無料でシミ抜きの再洗い（洗い直し）を試みさせていただきます。もしそれでもシミが落ちない場合は、伝票の規定に基づき、洗濯代金の最大10倍の損害賠償（弁償金）をお支払いいたします。</div>
<div class="id-explanation">kelalaian staf pencuci（洗濯スタッフの過失・不注意） / cairan penghilang kelunturan（色移り除去専用液） / ganti rugi sepuluh kali lipat（10倍の損害賠償）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 高級服の注意喚起
- **Tolong dua helai jas dan satu gaun sutra ini jangan dicuci biasa, harus pakai dry clean.**
  （このジャケット2着とシルクのドレス1着は普通に水洗いせず、必ずドライクリーニングでお願いします。）
- **Kancing kemeja desainer ini sangat rapuh, tolong lapisi kain pelindung saat menyetrika.**
  （このブランドシャツのボタンは非常に壊れやすいので、アイロンがけの際は当て布をしてください。）

### 枚数・点数の確認
- **Mari kita hitung jumlah potong pakaian bersama-sama dan catat di nota agar tidak ada yang hilang tertukar.**
  （紛失や取り違えを防ぐため、一緒に衣類の総枚数を数えて伝票にメモしておきましょう。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **Laundry Kiloanの上手な使い分け**:
> インドネシアの「Laundry Kiloan」は安価で香りも良く極めて便利ですが、普段着、タオル、シーツ類に向いています。高級なスーツ、デリケートなウール・シルク製品、大切なドレスシャツは、紛失・縮み・色移り事故を防ぐため、ショッピングモール内などに入っている専門の高級クリーニング店（5aseSec, Jeeves等）を利用するのが安全です。

<details class="id-quiz">
<summary>Q1. 洗濯で他の服の色が移ってしまう「色移り・色落ち」を表す単語は？</summary>
<strong>正解: luntur（terkena luntur）</strong><br>
解説: 色が褪せる、色移りすることを luntur と言います。
</details>

<details class="id-quiz">
<summary>Q2. キロ単位のランドリーで「洗濯＋アイロン仕上げ」のフルセットは何と呼ぶ？</summary>
<strong>正解: cuci komplit / cuci setrika</strong><br>
解説: アイロンのみは「setrika saja」、洗濯乾燥のみは「cuci kering saja」と呼ばれます。
</details>
