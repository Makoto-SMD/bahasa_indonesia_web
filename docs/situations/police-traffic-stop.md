# 実践対話・トラブル解決：交通警察の検問・反則切符の確認（Razia Polisi & Surat Tilang）

道路上での一斉検問（Razia Lalu Lintas）、車検証（STNK）や運転免許証（SIM）の提示、違反切符（Surat Tilang）の交付と罰金納付（e-Tilang）。交通警察（Polantas）に呼び止められた際に、慌てずに適法な権利を確認し、スムーズに対処するための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **razia / operasi lalu lintas** | 一斉取り締まり・検問 | 年末年始や作戦期間に多発 |
| **tilang (bukti pelanggaran)** | 反則切符・交通違反切符 | 行政処分通知 |
| **e-Tilang (tilang elektronik)** | 電子違反切符・ETLE | カメラ自動取り締まりとオンライン納付 |
| **SIM (Surat Izin Mengemudi)** | 運転免許証 | SIM A（普通乗用車）、SIM C（二輪） |
| **STNK (Surat Tanda Nomor Kendaraan)** | 車両登録証（車検証） | 原本を車内に常備する義務 |
| **surat tugas** | 職務執行命令書・検問令状 | 正規の検問かどうかの証明書 |
| **slip biru / slip merah** | 青切符（違反を認め即納付） / 赤切符（裁判所出頭） | 現代はほぼ青切符/e-Tilang |
| **pungli (pungutan liar)** | 不法徴収・裏金・賄賂 | 違法行為なので応じてはならない |

## 2. リアル実践対話シナリオ（検問で警察官に止められた際のやり取り）

車を運転中の外国人ドライバー（Pengemudi）が、検問中の警察官（Petugas Polantas）に停止を命じられ、書類提示を行う場面です。

<div class="id-example">
<div class="id-sentence"><strong>Polisi:</strong> Selamat siang, Pak. Mohon tepi ke pinggir sebentar. Kami sedang mengadakan operasi pemeriksaan rutin kelengkapan surat kendaraan bermotor. Bisa tolong perlihatkan SIM dan STNK aslinya?</div>
<div class="id-translation"><strong>警察官:</strong> こんにちは。少々車を路肩へ寄せてください。現在、自動車の携帯書類完備状況に関する定期一斉検査（検問）を実施しております。運転免許証（SIM）と車検証（STNK）の原本を見せていただけますか？</div>
<div class="id-explanation">pemeriksaan rutin（定期検査） / kelengkapan surat kendaraan（車両書類の完備性） / perlihatkan aslinya（原本を見せる）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pengemudi:</strong> Selamat siang, Pak Polisi. Ini SIM A internasional dan SIM A Indonesia saya yang masih berlaku, serta STNK asli mobil ini. Pajak kendaraannya juga baru saja dibayar bulan lalu.</div>
<div class="id-translation"><strong>ドライバー:</strong> こんにちは、警察官の方。こちらが有効期限内の国際免許証およびインドネシアのSIM A（普通免許）、ならびにこの車のSTNK原本です。自動車税（Pajak Kendaraan）も先月支払ったばかりです。</div>
<div class="id-explanation">masih berlaku（まだ有効である） / pajak kendaraan baru dibayar（自動車税は支払ったばかり）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Polisi:</strong> Baik, dokumennya lengkap dan masih berlaku. Namun tadi Bapak melanggar aturan marka jalan garis lurus tanpa putus saat berpindah lajur di dekat jembatan layang. Untuk itu, kami harus memberikan surat tilang.</div>
<div class="id-translation"><strong>警察官:</strong> はい、書類はすべて揃っており有効ですね。しかし先ほど、高架橋の近くで車線変更した際、破線のない実線（追越・車線変更禁止標示）の道路標示規則に違反されました。そのため、交通違反切符（Tilang）を交付しなければなりません。</div>
<div class="id-explanation">melanggar aturan marka jalan（道路標示規則に違反する） / garis lurus tanpa putus（切れ目のない実線＝車線変更禁止） / berpindah lajur（車線変更する）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pengemudi:</strong> Baik, Pak, saya mengakui kesalahan saya. Tolong berikan kode bayar e-Tilang (slip biru) saja ya, agar saya bisa langsung mentransfer denda tilang secara resmi melalui ATM atau mobile banking BRI.</div>
<div class="id-translation"><strong>ドライバー:</strong> 分かりました。私の不注意（違反）を認めます。銀行（BRI等）のATMやモバイルバンキングを通じて公式に反則金を即座に振り込めるよう、e-Tilangの納付コード（青切符）を発行してください。</div>
<div class="id-explanation">mengakui kesalahan（非・過失を認める） / kode bayar e-Tilang（電子交通反則金納付コード） / slip biru（違反を認めて銀行納付する青切符）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 違法な検問（偽警察・不当な金銭要求）への対処
- **Bolehkah saya melihat plang tanda razia resmi dan surat perintah tugas dari kesatuan Bapak?**
  （公式な検問標識の看板と、部隊からの職務命令書（Surat Tugas）を拝見できますでしょうか？）
- **Saya ingin membayar denda secara resmi melalui bank sesuai prosedur e-Tilang pemerintah.**
  （私は政府のe-Tilang手続きに従い、銀行経由で公式に罰金を支払いたいと思います。）

### 偶数奇数規制（Ganjil-Genap）での確認
- **Apakah ruas jalan ini saat jam sekarang termasuk dalam kawasan pembatasan lalu lintas ganjil-genap?**
  （この道路区間は、今の時間帯は奇数偶数ナンバー規制の対象エリアに含まれていますか？）

## 4. 現地のリアル事情・生活のヒント

> [!IMPORTANT]
> **「現場での現金手渡し（Uang Damai）」の廃止**:
> かつてのインドネシアでは警察官にその場で現金を握らせて見逃してもらう慣習（uang damai / damai di tempat）が横行していましたが、現在は**電子監視カメラ（ETLE: Electronic Traffic Law Enforcement）や「e-Tilang」システムが急速に全国整備**され、現場での現金収賄は贈収賄罪（gratifikasi / suap）として厳罰対象となっています。
> 違反した場合は潔く違反を認め、「Saya minta slip biru e-Tilang ya（e-Tilangの青切符をお願いします）」と告げ、公式なBRIVA口座番号宛てにスマホ決済（ネットバンキング）で納付するのが最も安全・潔白な解決法です。

<strong>正解: STNK（Surat Tanda Nomor Kendaraan）</strong><br>
解説: コピーではなく原本（asli）の車載義務があります。不携帯は取り締まり対象となります。
</details>
