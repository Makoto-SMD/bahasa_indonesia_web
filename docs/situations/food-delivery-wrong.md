# 実践対話・トラブル解決：フードデリバリーの誤配・品不足・返金申請（GoFood & Pesanan Kurang）

日常生活の必須インフラであるGoFoodやGrabFood、ShopeeFood。注文した料理と中身が違う誤配（pesanan tertukar）、メニューの入れ忘れ・品不足（ada makanan yang kurang）、スープのこぼれ・破損（makanan tumpah / rusak）、アプリ内サポート窓口（Pusat Bantuan）への返金クレーム（pengajuan refund）を的確に行うための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **pesanan tertukar / salah menu** | 注文の取り違え / 違うメニューが届いた | 他人の袋と入れ替わった |
| **ada item yang kurang** | 品数が足りない・入れ忘れ | 注文した一部商品が入っていない |
| **makanan tumpah / bungkus rusak** | 料理がこぼれている / 包装が破損 | スープやドリンクの漏れ |
| **pusat bantuan (help center)** | アプリ内ヘルプセンター | 返金申請の公式ルート |
| **foto bukti struk dan makanan** | レシートと料理の証拠写真 | 返金審査の必須素材 |
| **pengembalian dana (refund)** | 返金・ウォレットへの残高戻し | GoPay/OVOに即時返金 |
| **driver pengantar** | 配達ドライバー | 配達中のトラブル連絡相手 |

## 2. リアル実践対話シナリオ（配達員への確認 & アプリサポートへの返金申請）

届いた料理の袋を開けたところ、スープがこぼれて注文したチキンが1品入っていなかった顧客（Pemesan）が、配達ドライバー（Driver）およびサポートセンター（Customer Care）に問い合わせます。

<div class="id-example">
<div class="id-sentence"><strong>Pemesan:</strong> Mas driver, paket makanannya baru saja saya buka di lobi meja resepsionis. Tapi ada satu porsi ayam bakar madu yang kurang (tidak ada di dalam kantong plastik), dan kuah sup buntutnya tumpah membasahi kotak nasi. Apakah tadi pihak resto menyerahkan dua kantong atau cuma satu kantong?</div>
<div class="id-translation"><strong>注文者:</strong> 配達員さん、受付カウンターのテーブルで料理の荷物を開けたばかりなのですが。注文したハニーグリルチキンが1人前足りず（袋の中に入っておらず）、オックステールスープがこぼれてご飯の箱が水浸しになっています。先ほどお店側からは袋を2つ渡されましたか？それとも1つだけでしたか？</div>
<div class="id-explanation">meja resepsionis（受付テーブル） / ada satu porsi yang kurang（1人前足りない） / kuah sup tumpah（スープの汁がこぼれる） / pihak resto menyerahkan（レストラン側が渡す）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Driver:</strong> Waduh, maaf sekali, Kak! Tadi dari pihak resto memang hanya menyerahkan satu kantong plastik yang sudah di-stapler rapat, jadi saya tidak bisa memeriksa isinya. Soal sup tumpah, tadi di jalan saya sempat mengerem mendadak karena ada motor motong jalur. Tolong laporkan langsung ke Pusat Bantuan di aplikasi ya Kak agar dana makanan yang kurang dan rusak bisa diganti rugi.</div>
<div class="id-translation"><strong>配達員:</strong> うわあ、大変申し訳ありません！先ほどお店からはホチキスで固く留められた袋を1つだけ手渡されたため、私の方で中身を確認することができませんでした。スープのこぼれにつきましては、道中でバイクが急に割り込んできて急ブレーキをかけてしまったためです。不足分と破損した料理の代金が返金補償されるよう、アプリのヘルプセンターへ直接通報をお願いできますでしょうか。</div>
<div class="id-explanation">di-stapler rapat（ホチキスでしっかり閉じられた） / tidak bisa periksa isi（中身を確認できない） / motor motong jalur（バイクが車線を割り込む） / dana diganti rugi（代金が補償される）。</div>
</div>

### アプリのチャットサポート（Pusat Bantuan）へのクレーム文面

<div class="id-example">
<div class="id-sentence"><strong>Laporan ke CS:</strong> Halo tim GoFood, saya ingin mengajukan pengembalian dana untuk pesanan nomor GF-98765. Menu 'Ayam Bakar Madu' seharga Rp45.000 tidak disertakan oleh restoran, dan menu 'Sup Buntut' seharga Rp65.000 tumpah total dan tidak layak konsumsi. Bersama ini saya lampirkan foto struk kasir dari dalam kantong serta foto kondisi makanan yang rusak sebagai bukti pendukung. Mohon proses refund ke saldo GoPay saya secepatnya.</div>
<div class="id-translation"><strong>CSへの通報:</strong> GoFoodサポートチームの皆様、注文番号GF-98765に対する返金（リファンド）を申請いたします。4万5千ルピアの「ハニーグリルチキン」がレストランにより同梱されておらず、6万5千ルピアの「オックステールスープ」は全量こぼれて食用に適さない状態でした。袋内のレジレシートの写真および破損した食品の状態の写真を証明資料として添付いたします。至急、私のGoPay残高への返金処理をお願いいたします。</div>
<div class="id-explanation">tidak disertakan oleh restoran（レストランによって同梱されなかった） / tumpah total（全量こぼれた） / tidak layak konsumsi（食用に適さない、食べられない） / lampirkan foto sebagai bukti pendukung（裏付け証拠として写真を添付する）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 辛さ・氷抜きのオーダーミス
- **Saya memesan sambal dipisah dan level pedas sedang, tapi kenapa sambalnya dicampur dan rasanya sangat pedas sekali?**
  （サンバルは別添え、中辛で注文したのに、なぜサンバルが混ぜられていて激辛になっているのですか？）
- **Saya sudah memberi catatan 'tanpa es batu' di aplikasi karena sakit flu, tolong diperhatikan ya.**
  （風邪をひいているためアプリで「氷なし」と備考欄に記載したのですが、気をつけてくださいね。）

### 誤配（別の人の料理が届いた）
- **Makanan yang diantar ini bukan pesanan saya, nama di bon kasir adalah Ibu Dewi bukan nama saya.**
  （配達されたこの料理は私の注文ではありません。レシートの名前は私ではなくデウィ様となっています。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **返金率100%を勝ち取る写真撮影のコツ**:
> GoFoodやGrabFoodでは、AIとカスタマーサポートが写真画像をもとに自動〜半自動で即時返金（Instant Refund）を判定します。
> 品不足やこぼれがあった際は、絶対にすぐ捨てず、**①外袋に貼られたレシート（注文番号と店名が読めること）**、**②届いた料理の全景（何が入っていて何が入っていないか）**、**③こぼれた汁や破損部分のアップ**の3枚を撮影して申請すれば、数分〜数時間で全額が電子マネー残高に返還されます。

<details class="id-quiz">
<summary>Q1. 料理がこぼれたり痛んで「食べられる状態ではない（食用不可）」を表す公的表現は？</summary>
<strong>正解: tidak layak konsumsi / tidak layak makan</strong><br>
解説: サポートへの返金申請で決定打となる表現です。
</details>

<details class="id-quiz">
<summary>Q2. アプリ上で返金（リファンド）を要求する手続きは？</summary>
<strong>正解: pengajuan refund / pengembalian dana</strong><br>
解説: pengembalian（戻すこと）＋ dana（資金＝代金返還）。
</details>
