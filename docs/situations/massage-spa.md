# 実践対話・リラクゼーション：スパ・リフレクソロジーでの施術と強さ指示（Pijat & Refleksi）

バリ島やジャカルタ市内のスパ（Spa）、伝統的マッサージ（Pijat Tradisional）、足裏リフレクソロジー（Pijat Refleksi / Kokuo, Bersih Sehat等）。コースの選択、アロマオイルの香り選び、力加減（痛すぎる・強め・弱め）、重点的にほぐしてほしい部位（肩・腰・ふくらはぎ）の的確な指示を伝えるための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **pijat tradisional / refleksi** | 伝統的全身マッサージ / 足裏リフレ | オイルあり/ドライ |
| **terapis (pemijat)** | セラピスト・マッサージ師 | 施術担当者 |
| **terlalu keras / sakit** | 痛すぎる・強すぎる | 力加減を弱めてもらう |
| **kurang keras / lebih bertenaga** | 弱すぎる・もっと強く | 圧迫力を強めてもらう |
| **sedang saja / pas** | ちょうど良い・普通 | 理想的な強さ |
| **pundak / leher kaku** | 肩 / 首のこり（カチコチ） | デスクワークの疲れ |
| **pinggang pegal / betis kencang** | 腰の重だるさ / ふくらはぎの張り | 立ち仕事や運動後 |
| **minyak aroma (minyak esensial)** | アロマオイル（ラベンダー・レモングラス等） | 香りの選択 |

---

## 2. リアル実践対話シナリオ（受付でのコース選び & 施術中の力加減リクエスト）

### シーンA: 受付でのコース選びと重点部位の指定

<div class="id-example">
<div class="id-sentence"><strong>Resepsionis:</strong> Selamat sore, selamat datang. Mau paket perawatan apa hari ini, Kak? Kami ada pijat refleksi 90 menit dan pijat tradisional Bali full body dua jam.</div>
<div class="id-translation"><strong>受付係:</strong> こんにちは、いらっしゃいませ。本日はどのトリートメントコースをご希望ですか？90分の足裏リフレクソロジーと、2時間のバリ伝統フルボディマッサージがございます。</div>
<div class="id-explanation">paket perawatan（トリートメントパッケージ） / pijat refleksi（リフレクソロジー） / full body dua jam（全身2時間）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Saya mau paket tradisional full body 90 menit dengan minyak aroma lavender ya. Tolong fokuskan lebih banyak waktu di area pundak, leher, dan pinggang bawah karena otot saya terasa sangat kaku dan pegal akibat duduk lama di kantor.</div>
<div class="id-translation"><strong>客:</strong> ラベンダーのアロマオイルを使った、90分の伝統フルボディコースをお願いします。オフィスでの長時間のデスクワークで筋肉がカチコチに凝って重だるいので、肩、首、および腰回りの部位に重点的に時間をかけてほぐしてください。</div>
<div class="id-explanation">minyak aroma lavender（ラベンダー精油） / fokuskan di area pundak dan pinggang（肩と腰の部位に集中させる） / otot kaku dan pegal（筋肉のこりと張り）。</div>
</div>

### シーンB: 施術室での力加減の微調整

<div class="id-example">
<div class="id-sentence"><strong>Terapis:</strong> Permisi ya, Pak. Bagaimana tekanannya sekarang, apakah terlalu keras atau sudah pas?</div>
<div class="id-translation"><strong>セラピスト:</strong> 失礼いたしますね。現在の指圧の強さ（圧力）はいかがでしょうか、強すぎますか？それともちょうど良いでしょうか？</div>
<div class="id-explanation">bagaimana tekanannya（圧力・強さはいかがですか） / terlalu keras（強すぎる・痛い） / sudah pas（ちょうど良い）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Di bagian bahu tekanannya sangat pas dan enak sekali. Tapi di bagian tulang punggung dan betis, tolong agak dikurangi sedikit ya, rasanya agak terlalu sakit/ngilu.</div>
<div class="id-translation"><strong>客:</strong> 肩の部分は圧力がぴったりでとても気持ちいいです。でも背骨のあたりとふくらはぎは、少し力を緩めて弱くしてください。少し痛すぎます。</div>
<div class="id-explanation">sangat pas dan enak（ぴったりで気持ちいい） / agak dikurangi sedikit（少し力を弱める・減らす） / agak terlalu sakit（少し痛すぎる）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Terapis:</strong> Baik, Pak, saya kurangi tekanannya. Kalau nanti terasa sakit lagi, langsung bilang saja ya. Suhu ruangan AC-nya apakah terlalu dingin?</div>
<div class="id-translation"><strong>セラピスト:</strong> かしこまりました、力を緩めますね。もしまた痛みを感じましたら、遠慮なくすぐにおっしゃってくださいね。お部屋のエアコンの温度は寒すぎませんか？</div>
<div class="id-explanation">suhu ruangan AC terlalu dingin（エアコンの室温が寒すぎるか）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 施術中のとっさの合図
- **Aduh sakit! Tolong pelan-pelan sedikit ya.**
  （痛っ！もう少し優しく・力を緩めてください。）
- **Bisa tolong ditekan lebih keras lagi di bagian telapak kaki tengah ini?**
  （この足の裏の真ん中あたりを、もっと強めにグッと押してもらえますか？）
- **Tolong jangan ditekan bagian luka memar di lutut kanan saya.**
  （右膝の打撲（あざ）の部分は押さないでください。）

### 施術後のチップ
- **Pijatannya sangat mantap dan badan saya terasa jauh lebih enteng sekarang. Ini tip buat Mbak.**
  （マッサージの腕前が最高で、体が今すごく軽くなりました。こちらチップです。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **Refleksiチェーンとチップの相場**:
> インドネシアには街角に清潔で健全なリフレクソロジーチェーン（Kokuo Family Massage, Bersih Sehat, Zen Family Spa, Nest等）が多数あり、1時間あたり10万〜20万ルピア（約1,000〜2,000円）という非常にリーズナブルな価格で極上の施術を受けられます。
> 施術終了後、温かい生姜湯（Wedang Jahe）を飲みながら、担当してくれたセラピストに**2万〜5万ルピア（90分〜120分なら5万ルピアが標準）**のチップを渡すのが心地よいマナーです。

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. マッサージ中に「痛い！もう少し弱くして」と頼む最も手軽な表現は？</summary>
<strong>正解: Sakit, tolong pelan-pelan / Kurangi sedikit</strong><br>
解説: 痛い（sakit）＋ ゆっくり・優しく（pelan-pelan）と言えば直ちに力を緩めてくれます。
</details>

<details class="id-quiz">
<summary>Q2. マッサージ後に「体がとても軽くなった」を表す表現は？</summary>
<strong>正解: Badannya terasa enteng / ringan</strong><br>
解説: 重い（berat）の対義語である「enteng / ringan（軽い）」を用います。
</details>
