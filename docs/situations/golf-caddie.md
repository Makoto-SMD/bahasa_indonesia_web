# 実践対話・ゴルフ実務：ゴルフ場チェックイン・キャディへの指示とチップ（Padang Golf & Kedi）

東南アジア駐在員の最大の社交場・リフレッシュであるゴルフ（main golf）。ジャカルタ近郊（ボゴール、カラワン、BSD）の名門コースでの受付（registrasi & tee time）、担当キャディ（Kedi）への番手クラブ要求、グリーンの芝目や傾斜（kemiringan & garis green）の確認、OBや池ポチャ、ホールアウト後のチップ（tip kedi）の渡し方をマスターするための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **padang golf / lapangan golf** | ゴルフ場・カントリークラブ | 18ホールが標準 |
| **kedi (caddy)** | キャディ（専属帯同キャディ） | 1プレーヤーに1人帯同 |
| **tee time / waktu mulai main** | スタート時刻 / ティータイム | 週末の朝は争奪戦 |
| **stik golf / klab golf** | ゴルフクラブ | 番手ごとに指示 |
| **driver / kayu nomor satu (wood 1)** | ドライバー / 1番ウッド | ティーショットで使用 |
| **iron / besi nomor tujuh (iron 7)** | アイアン / 7番アイアン | セカンドショット等 |
| **pemberitahuan arah angin** | 風向き・アゲインスト/フォロー | angin kencang（強風） |
| **kemiringan green / garis putter** | グリーンの傾斜・スライス/フックライン | kanan tinggi（右が高い）等 |
| **tip kedi** | キャディへのチップ | 20万〜30万ルピアが標準相場 |

## 2. リアル実践対話シナリオ（ティーグラウンド & グリーン上でのキャディとのやり取り）

### シーンA: 1番ホールのティーグラウンドで風と距離を確認する

<div class="id-example">
<div class="id-sentence"><strong>Golfer:</strong> Selamat pagi, Mbak Kedi. Nama saya Tanaka. Hari ini tolong bantu saya dengan baik ya. Hole pertama ini berapa meter jaraknya ke bendera dan anginnya bertiup ke arah mana?</div>
<div class="id-translation"><strong>ゴルファー:</strong> おはようございます、キャディさん。私の名前は田中です。今日はよろしくお願いしますね。この1番ホールはピンフラッグまで何ヤード（メートル）ありますか？また風はどちらへ吹いていますか？</div>
<div class="id-explanation">tolong bantu dengan baik（どうぞよろしくお願いします） / jarak ke bendera（ピンまでの距離） / angin bertiup ke arah mana（風はどちら向きに吹いているか）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kedi:</strong> Selamat pagi Pak Tanaka, saya Rani kedi Bapak hari ini. Par 4 ini jaraknya 380 yard ke pin tengah. Anginnya sedikit melawan (headwind). Di sebelah kanan ada bunker pasir dan di sebelah kiri ada kolam air (hazard). Sebaiknya arahkan pukulan lurus ke fairway bagian kiri saja, Pak. Ini driver-nya.</div>
<div class="id-translation"><strong>キャディ:</strong> おはようございます田中さん、本日担当キャディを務めますラニです。このパー4はセンターピンまで380ヤードです。風は少し向かい風（アゲインスト）です。右側にバンカー、左側に池（ハザード）がございます。フェアウェイ左寄りを狙って真っ直ぐ打たれるのが賢明です。こちらがドライバーです。</div>
<div class="id-explanation">pin tengah（センターピン） / angin melawan（向かい風、アゲインスト） / bunker pasir（砂バンカー） / kolam air（池・ウォーターハザード） / arahkan pukulan ke fairway（フェアウェイへ向けて打つ）。</div>
</div>

### シーンB: グリーン上での芝目とパッティングラインの読み

<div class="id-example">
<div class="id-sentence"><strong>Golfer:</strong> Rani, tolong bersihkan bola saya dulu. Dari posisi bola ini ke lubang sekitar empat langkah. Bagaimana garis bacaan green-nya?</div>
<div class="id-translation"><strong>ゴルファー:</strong> ラニさん、まずボールを拭いてマークしてください。このボールの位置からカップまでは約4歩ですね。グリーンのライン（傾斜・芝目）の読みはどうですか？</div>
<div class="id-explanation">bersihkan bola（ボールを拭く・泥を落とす） / garis bacaan green（グリーンのラインの読み）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kedi:</strong> Posisi sebelah kiri lebih tinggi, Pak. Garisnya belok ke kanan (slice) sekitar satu kepalan tangan di sebelah kiri lubang. Laju bolanya agak menurun dan kencang (licin), jadi pukul santai saja ya, Pak. Ini putter-nya.</div>
<div class="id-translation"><strong>キャディ:</strong> 左側が高くなっております。カップの左手拳（こぶし）1つ分を狙うスライスライン（右へ曲がる傾斜）です。下り傾斜で転がりが非常に速い（すべる）ので、優しくソフトにタッチしてくださいね。こちらがパターです。</div>
<div class="id-explanation">sebelah kiri lebih tinggi（左が高い＝フック/スライスの基準） / belok ke kanan（右へ曲がる・スライス） / satu kepalan tangan（握り拳ひとつ分） / laju bola licin/menurun（下り傾斜で速い）。</div>
</div>

### シーンC: ホールアウト後の労いとチップの支払い

<div class="id-example">
<div class="id-sentence"><strong>Golfer:</strong> Terima kasih banyak atas bantuannya sepanjang 18 hole hari ini, Rani. Petunjuk garis green-mu sangat akurat sehingga permainan saya bisa mencapai skor terbaik. Ini tip untukmu ya.</div>
<div class="id-translation"><strong>ゴルファー:</strong> 今日は18ホール全体を通じて素晴らしいサポートを本当にありがとう、ラニさん。君のグリーンのラインの読みが非常に正確だったおかげで、自己ベストスコアを出すことができました。こちらが本日のチップです。</div>
<div class="id-explanation">sepanjang 18 hole（18ホール通じて） / petunjuk garis green sangat akurat（グリーンの読みが極めて正確） / skor terbaik（ベストスコア）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### クラブの番手指定
- **Tolong ambilkan besi (iron) nomor delapan atau sembilan dari bag golf.**
  （ゴルフバッグから8番か9番アイアンを取ってきてください。）
- **Apakah jaraknya cukup jika saya memakai kayu nomor tiga (3-wood)?**
  （3番ウッド（スプーン）を使えば距離は届きますか？）

### OBや池ポチャ時の暫定球
- **Sepertinya bolanya melenceng ke kanan masuk hutan (out of bounds). Saya akan memukul bola sementara (provisional ball) dulu.**
  （ボールが右へスライスして林の中（OBゾーン）に入ったようです。まず暫定球（provisional ball）を打ちます。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **キャディチップ（Tip Kedi）の常識**:
> インドネシアのゴルフ場では、キャディフィーはプレー代に含まれているのが通例ですが、ラウンド終了後の**キャディ個人への現金チップ（Tip Langsung）の支払いが絶対的なマナー（不文律）**となっています。
> 相場はジャカルタ・近郊で**18ホールあたり25万〜30万ルピア（約2,500〜3,000円）**が標準です。バーディー賞（uang birdie）として5万ルピア程度を追加で渡すことも喜ばれる習慣です。

<summary>Q1. グリーン上で「右に曲がる（スライスライン）」をキャディに伝える/聞く表現は？</summary>
<strong>正解: Belok ke kanan / Buang ke kanan</strong><br>
解説: 逆に左へ曲がる（フックライン）は belok ke kiri と言います。

<details class="id-quiz">

<strong>正解: Besi（stik besi nomor 7 等）</strong><br>
解説: 鉄＝besi、ウッド（木）＝kayu と呼ばれます。
</details>
