# 実践対話・文化マナー：町内会（RT / RW）の集会・住民登録・地域交流（Rukun Tetangga & Gotong Royong）

一軒家や住宅地（komplek）に暮らす際の地域コミュニティの基盤である隣組・町内会（RT: Rukun Tetangga、RW: Rukun Warga）。町内会長（Ketua RT）への入居挨拶と身元届（lapor diri）、毎月の町内会費（iuran RT / uang sampah）、独立記念日（17 Agustus）のイベント参加、相互扶助の大掃除（gotong royong）に溶け込むための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **RT (Rukun Tetangga) / RW (Rukun Warga)** | 隣組・班（最小自治組織） / 町内会 | RTは数十世帯、RWは複数のRT |
| **Ketua RT (Pak RT)** | 町内会長・組長 | 地域住民の顔役・行政窓口 |
| **lapor diri warga baru** | 新規住民の転入届・出頭 | 入居後24時間以内の挨拶 |
| **iuran RT (iuran keamanan & kebersihan)** | 町内会費（警備費・ゴミ回収費） | 毎月数万〜数十万ルピア |
| **gotong royong / kerja bakti** | 共同作業・互助奉仕活動・大掃除 | 日曜朝に排水溝掃除など |
| **pos satpam / pos ronda** | 警備所 / 自警団の詰所（夜警詰所） | 夜間の巡回警備の拠点 |
| **peringatan HUT RI (17 Agustus)** | 独立記念日のお祭り（8月17日） | 綱引きやパン喰い競走の祭り |
| **surat pengantar RT** | RT会長の発行する紹介状・証明書 | 行政手続きの第一歩 |

## 2. リアル実践対話シナリオ（新居への入居挨拶 & 町内会長（Pak RT）との面談）

住宅地に一軒家を借りた日本人住人（Warga Baru）が、町内会長（Pak RT）の自宅を訪ねて転入の挨拶を行い、町内ルールを確認します。

<div class="id-example">
<div class="id-sentence"><strong>Warga Baru:</strong> Selamat malam, apakah ini benar rumah Bapak RT? Assalamu'alaikum.</div>
<div class="id-translation"><strong>新住民:</strong> こんばんは、こちらは町内会長様（RT）のお宅でいらっしゃいますでしょうか？アッサラーム・アライクム（平安あれ）。</div>
<div class="id-explanation">rumah Bapak RT（町内会長のお宅） / Assalamu'alaikum（イスラム圏の丁寧な訪問挨拶）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pak RT:</strong> Wa'alaikumsalam. Benar sekali, saya Pak Bambang, Ketua RT 05 di komplek ini. Silakan masuk dan duduk. Ada yang bisa saya bantu, Pak?</div>
<div class="id-translation"><strong>RT会長:</strong> ワ・アライクムッ・サラーム。いかにも、私がこの住宅街のRT05の組長を務めているバンバンです。どうぞお上がりになってお座りください。何かご用件でしょうか？</div>
<div class="id-explanation">Ketua RT 05（第5隣組会長） / silakan masuk dan duduk（どうぞお入りになってお座りください）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Warga Baru:</strong> Terima kasih, Pak RT. Saya Tanaka dari Jepang, baru saja pindah menempati rumah nomor B-12 di jalan Mawar sejak kemarin. Sebagai warga baru, saya ingin melapor diri sekaligus menyerahkan fotokopi paspor dan dokumen kontrak sewa rumah untuk pencatatan warga.</div>
<div class="id-translation"><strong>新住民:</strong> ありがとうございます、会長。私は日本から参りました田中と申します。昨日からマワール通りのB-12番地の住宅に転入してまいりました。新住民として転入の届出（Lapor Diri）をさせていただくとともに、住民台帳への記録のため、パスポートのコピーと賃貸借契約書のコピーを提出したく存じます。</div>
<div class="id-explanation">baru saja pindah menempati rumah（住宅へ引っ越して入居したばかり） / melapor diri sebagai warga baru（新住民として転入届を出す） / pencatatan warga（住民台帳への登録）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pak RT:</strong> Selamat datang di lingkungan kami, Pak Tanaka! Kami sangat senang menyambut warga baru. Di lingkungan RT kita, ada iuran bulanan sebesar Rp150.000 untuk biaya keamanan satpam 24 jam dan pengangkutan sampah. Dan hari Minggu depan ada kegiatan kerja bakti membersihkan selokan air, kalau Pak Tanaka ada waktu luang silakan ikut bergabung santai saja.</div>
<div class="id-translation"><strong>RT会長:</strong> 私たちの地域コミュニティへようこそ、田中さん！新しい住民の方を心より歓迎いたします。当RTでは、24時間の警備員費用およびゴミ回収代金として、毎月15万ルピアの町内会費がございます。また来週の日曜日は側溝の排水路を清掃するボランティア共同作業（Kerja Bakti）がありますので、もしお時間がありましたらどうぞ気楽にご参加くださいね。</div>
<div class="id-explanation">iuran bulanan（毎月の会費） / keamanan satpam（警備員によるセキュリティ） / pengangkutan sampah（ゴミ回収） / kerja bakti membersihkan selokan（側溝清掃の奉仕活動）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 騒音・工事の事前連絡
- **Mohon izin Pak RT, rumah kami akan mengadakan sedikit renovasi genteng selama tiga hari, mungkin akan agak berisik di siang hari.**
  （町内会長、ご容赦をお願いしたいのですが、我が家では3日間屋根瓦の小規模な修繕工事を行う予定でして、日中は多少の騒音が出るかもしれません。）
- **Ini ada sedikit oleh-oleh buah tangan khas Jepang untuk Pak RT dan keluarga.**
  （こちらは町内会長とご家族様への、ささやかな日本の特産お土産（手土産）です。）

### 独立記念日の寄付
- **Panitia 17 Agustus sedang mengumpulkan donasi sukarela untuk memeriahkan lomba anak-anak di lapangan RT.**
  （8月17日独立記念日実行委員会は、広場での子どもたちの競技大会を盛り上げるための任意の寄付金（協賛金）を集めています。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **「Gotong Royong（相互扶助）」の魔法**:
> インドネシア社会を理解する上で最も神聖な概念が「**Gotong Royong（ゴトン・ロヨン＝相互扶助・助け合い）**」です。
> 外国人であっても、地域の清掃活動（Kerja Bakti）や独立記念日のイベントに顔を出し、缶コーヒーやミネラルウォーターを差し入れするだけで、「気さくで地域を尊重してくれる良い隣人（orang baik）」として全住民から深く認知され、治安上の見守りや緊急時の救援など、計り知れない恩恵を受けることができます。
