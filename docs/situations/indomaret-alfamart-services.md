# 実践対話・生活便利術：コンビニ（Indomaret & Alfamart）の多機能サービス活用（Layanan Minimarket）

インドネシア全土の街角に数十メートルおきに並ぶ2大コンビニ「インドマレット（Indomaret）」と「アルファマート（Alfamart）」。単なる食品や日用品の買い物にとどまらず、長距離鉄道（KAI）のチケット発券、公共料金（水道・電気・ネット代）の現金納付、EC荷物の店頭受取・発送、交通系ICカード（Flazz / e-money）のチャージ（top up）をレジ店員（Kasir）と手際よく行うための実践対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **kasir minimarket** | コンビニのレジカウンター | 全サービスの受付場所 |
| **top up saldo e-money / Flazz** | 交通系ICカードへの残高チャージ | 高速道路や通勤電車に必須 |
| **bayar tagihan / bayar kode pembayaran** | 請求書の支払い / 決済コード納付 | Tokopediaや航空券の決済 |
| **cetak tiket kereta api (KAI)** | 鉄道チケットの発券 | 予約コードのレシート印刷 |
| **tarik tunai tanpa kartu** | キャッシュレス無人引き出し | BCA等のコードでレジ出金 |
| **ambil paket barang** | 店頭受取の宅配荷物を受け取る | PINコードを提示 |
| **biaya admin per transaksi** | 1取引あたりの事務手数料 | 通常2,500〜5,000ルピア |
| **struk bukti pembayaran** | 支払証明レシート | トラブル時の保管必須 |

## 3. トラブル解決！現場で使える必修フレーズ集

### おつりの「寄付」の確認
- **Sisa kembalian Rp500-nya mau didonasikan untuk yayasan kemanusiaan, Kak?**
  （おつりの端数500ルピアは、人道支援財団へ寄付に回されますか？）
- **Tidak usah didonasikan, tolong kembalikan uangnya saja ya.**
  （寄付は結構ですので、そのままおつりを返金してください。）

### 荷物の店頭受取（Ambil Paket）
- **Saya mau mengambil paket kiriman belanja daring yang dititipkan di gerai Indomaret ini, nomor resinya JNT-098765 dan nomor OTP saya 4521.**
  （このインドラレット店舗留めで預けられているネット通販の荷物を受け取りたいです。追跡番号はJNT-098765、受取PINコードは4521です。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **「Indomaret Point」と「Alfamart」のレジおつり寄付**:
> インドネシアのコンビニのレジでは、おつりが数十〜数百ルピア（数円程度）の端数になると、店員が必ず「Kembaliannya mau didonasikan?（おつりは寄付しますか？）」と聞いてきます。
> 寄付に同意するとレシートに「Donasi Rp300」と印字されます。気前よく「Boleh, silakan（いいですよ、どうぞ）」と答えるのが現地の庶民感覚ですが、小銭が必要な場合は「Tidak usah, terima kasih（要りません）」と笑顔で断っても全く問題ありません。
