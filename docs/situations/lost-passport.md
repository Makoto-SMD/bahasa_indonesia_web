# 実践対話・トラブル解決：パスポート紛失・盗難・警察届と日本大使館連絡（Paspor Hilang & Laporan Polisi）

海外生活・旅行で最も重大な危機である「パスポートの紛失・盗難（paspor hilang / dicuri）」。現地の警察署（Kantor Polisi）での紛失届（Surat Keterangan Kehilangan）、日本大使館（Kedutaan Besar Jepang）での渡航書または新パスポート申請、入国管理局での再出国スタンプ手続きを冷静に進めるための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **paspor hilang / kecopetan** | パスポートの紛失 / スリ被害 | スリは copet / kecopetan |
| **surat keterangan kehilangan (SKTLK)** | 警察発行の紛失証明書 | 再発行手続きの絶対必須書類 |
| **Kantor Polisi / Polsek / Polres** | 警察署 / 地区警察署 / 地方警察本部 | Polsek（郡署）以上で発行 |
| **Kedutaan Besar Jepang (Kedubes)** | 在インドネシア日本国大使館 | ジャカルタ・サリナ近くに所在 |
| **Surat Perjalanan Laksana Paspor (SPLP)** | 帰国のための渡航書（緊急旅券） | 緊急帰国時に発行 |
| **kronologi kejadian** | 事件・紛失の経緯・時系列 | 警察の調書に記載する事実関係 |
| **fotokopi paspor / pasfoto** | パスポートのコピー / 証明写真 | 白背景・規定サイズ |
| **stempel visa pengganti** | 代替ビザスタンプ | 入国管理で原本番号を引き継ぐ |

## 2. リアル実践対話シナリオ（地区警察署（Polsek）での紛失届作成）

スリ被害に遭いパスポートを紛失した外国人（Korban）が、警察署のSPKT（総合警察サービスセンター）窓口で警察官（Polisi）に紛失届を申請します。

<div class="id-example">
<div class="id-sentence"><strong>Korban:</strong> Selamat sore, Pak Polisi. Saya ingin membuat Surat Keterangan Tanda Lapor Kehilangan (SKTLK). Dompet dan paspor asli Jepang saya hilang tercuri saat berada di kawasan wisata Kota Tua tadi siang.</div>
<div class="id-translation"><strong>被害者:</strong> こんにちは、警察官の方。紛失届証明書（SKTLK）を作成していただきたいのですが。今日の昼に観光地のコタ・トゥアにいた際、私の財布と日本のパスポート原本が盗難に遭って紛失してしまいました。</div>
<div class="id-explanation">surat tanda lapor kehilangan（紛失届証明書） / hilang tercuri（盗まれて紛失した） / kawasan wisata（観光地区）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Polisi:</strong> Baik, mari duduk di sini. Bisa jelaskan kronologi kejadiannya secara rinci? Kapan tepatnya kejadian tersebut, apa saja ciri-ciri barang yang hilang, dan nomor paspornya berapa?</div>
<div class="id-translation"><strong>警察官:</strong> はい、こちらへお座りください。事件の経緯（クロノロジー）を詳しく説明していただけますか？正確にはいつの出来事か、紛失した物品の特徴は何か、そしてパスポート番号は何番ですか？</div>
<div class="id-explanation">kronologi kejadian secara rinci（経緯の詳細な時系列） / ciri-ciri barang（物品の特徴）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Korban:</strong> Kejadiannya sekitar jam 13.30 saat saya sedang mengambil foto di depan Museum Fatahillah. Tas ransel saya dirobek dari belakang. Barang yang hilang adalah satu paspor Jepang nomor TR1234567, uang tunai Rp1,5 juta, dan dua kartu kredit. Ini fotokopi paspor dan KTP saya yang tersimpan di ponsel.</div>
<div class="id-translation"><strong>被害者:</strong> 出来事はファタヒラ広場博物館の前で写真を撮っていた午後1時半頃です。私のリュックサックが後ろから切り裂かれました。紛失物は日本のパスポート（番号TR1234567）1冊、現金150万ルピア、およびクレジットカード2枚です。こちらがスマホに保存してあったパスポートのコピーと身分証です。</div>
<div class="id-explanation">tas ransel dirobek dari belakang（リュックが背後から切り裂かれた） / uang tunai（現金） / fotokopi paspor（パスポートのコピー）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Polisi:</strong> Baik, laporannya sudah saya ketik. Silakan baca kembali isi kronologinya. Jika sudah benar, bubuhkan tanda tangan di bawah materai ini. Ini surat kehilangan aslinya untuk dibawa ke Kedutaan Besar Jepang dan Kantor Imigrasi.</div>
<div class="id-translation"><strong>警察官:</strong> はい、届出内容をタイプ作成しました。経緯の記載内容を読み返して確認してください。相違がなければ、この印紙の下に署名をお願いします。日本大使館および入国管理局へ提出するための紛失届原本がこちらになります。</div>
<div class="id-explanation">bubuhkan tanda tangan（署名を記名する） / surat kehilangan asli（紛失証明書の原本）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 日本大使館への緊急連絡
- **Halo, bagian konsuler Kedutaan Besar Jepang di Jakarta? Saya baru saja kehilangan paspor dan membutuhkan SPLP (Surat Perjalanan Laksana Paspor) darurat untuk pulang ke Tokyo.**
  （もしもし、在ジャカルタ日本大使館の領事部ですか？たった今パスポートを紛失してしまい、東京へ帰国するための緊急渡航書（SPLP）が必要です。）
- **Berapa lembar pasfoto yang harus saya serahkan dan berapa biaya administrasi resminya?**
  （証明写真は何枚提出しなければなりませんか？また公式な手数料はいくらですか？）

### クレジットカードの即時利用停止
- **Tolong segera blokir kartu kredit saya karena nomor kartu dan kode CVV kemungkinan besar sudah diketahui pihak pelaku pencurian.**
  （カード番号やセキュリティコードが窃盗犯に知られた可能性が極めて高いため、至急私のクレジットカードを利用停止にしてください。）

## 4. 現地のリアル事情・生活のヒント

> [!IMPORTANT]
> **パスポート再発行の3大ステップ**:
> ① **地元警察署（Polsek / Polres）**: 即座に駆け込み、紛失証明書（Surat Keterangan Kehilangan）を取得する。
> ② **日本大使館 / 総領事館**: 警察の証明書、戸籍謄本または抄本（コピーでも可の場合あり）、写真を提出して「帰国のための渡航書」または新旅券を申請。
> ③ **入国管理局（Ditjen Imigrasi）**: 新旅券または渡航書に、当初の入国スタンプ・滞在許可を引き継ぐ代替スタンプ（Endorsement / Stempel Pengganti）を押印してもらう（※これを怠ると空港の出国審査で出国できません）。
