# 実践対話・トラブル解決：交通事故・接触事故・当て逃げ時の現場対応（Kecelakaan Lalu Lintas）

バイクの割り込みによる接触事故（tabrakan / senggolan）、物損事故、当て逃げ（tabrak lari）。外国人が最もパニックになりやすい交通事故現場において、感情的にならず冷静に事実確認を行い、相手方・警察（Polisi）・保険会社と示談や事故証明取得を進めるための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **kecelakaan lalu lintas (lakalantas)** | 交通事故 | 公式行政略語 lakalantas |
| **tabrakan / tertabrak** | 衝突事故 / ぶつけられる | 激しい衝突 |
| **senggolan / bersenggolan** | かすり傷・軽い接触 | バイクとミラーの接触など |
| **tabrak lari** | 当て逃げ・ひき逃げ | 現場から逃走する重罪 |
| **ganti rugi / uang damai** | 損害賠償・示談金 | 民事・示談での解決金 |
| **penyelesaian secara kekeluargaan** | 話し合い（和解・家族的）による示談 | 警察沙汰にしない現地慣習 |
| **laporan kepolisian (surat laporan polisi)** | 警察の事故証明書・届出書 | 車両保険の保険金請求に必須 |
| **rekaman kamera dasbor (dashcam)** | ドライブレコーダーの映像 | 客観的証拠として決定打 |

## 2. リアル実践対話シナリオ（接触事故の現場での相手方 & 警察との対話）

赤信号で停車中、後方からバイクに追突されたドライバー（Pengemudi）が、バイクの運転手（Pengendara Motor）および駆けつけた交通警察官（Polisi）と話し合う場面です。

<div class="id-example">
<div class="id-sentence"><strong>Pengemudi:</strong> Mas, tolong pinggirkan kendaraannya ke tempat yang aman dulu agar tidak menimbulkan kemacetan. Kenapa Mas menabrak bagian belakang mobil saya yang sedang berhenti di lampu merah?</div>
<div class="id-translation"><strong>ドライバー:</strong> あなた、渋滞を引き起こさないよう、まずは車両を安全な路肩へ寄せてください。こちらは赤信号で停車していたのに、なぜ私の車の後部に追突したのですか？</div>
<div class="id-explanation">pinggirkan kendaraan（車両を端に寄せる） / menimbulkan kemacetan（渋滞を引き起こす） / menabrak bagian belakang（後部に衝突する）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pengendara Motor:</strong> Maaf sekali, Pak. Tadi rem motor saya licin karena hujan, jadi tidak sempat mengerem mendadak. Bumper belakang mobil Bapak penyok dan lampu belakangnya pecah. Bagaimana kalau kita selesaikan secara damai saja?</div>
<div class="id-translation"><strong>バイク運転手:</strong> 大変申し訳ありません。雨でバイクのブレーキが滑ってしまい、急ブレーキが間に合いませんでした。車のリアバンパーがへこみ、テールランプが割れてしまいましたね。話し合い（示談）で穏便に解決できませんでしょうか？</div>
<div class="id-explanation">rem licin（ブレーキが滑る） / mengerem mendadak（急ブレーキをかける） / bumper penyok（バンパーが凹む） / lampu pecah（ランプが割れる） / selesaikan secara damai（示談で解決する）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Polisi:</strong> Selamat siang, ada apa ini? Apakah ada korban luka? Jika hanya kerugian materiil, silakan periksa dokumen SIM dan STNK masing-masing. Apakah ingin diselesaikan secara kekeluargaan atau dibuatkan laporan resmi lakalantas?</div>
<div class="id-translation"><strong>警察官:</strong> こんにちは、何がありましたか？お怪我をされた方はいらっしゃいますか？もし物損（物質的損害）だけであれば、各自の運転免許証（SIM）と車両登録証（STNK）を確認し合ってください。示談（当事者間の話し合い）で解決しますか？それとも正式な事故証明書を作成しますか？</div>
<div class="id-explanation">korban luka（負傷者） / kerugian materiil（物損） / SIM dan STNK（免許証と車検証） / diselesaikan secara kekeluargaan（示談で友好的に解決する）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pengemudi:</strong> Kami ingin klaim asuransi komprehensif, Pak Polisi. Jadi kami membutuhkan surat laporan resmi kepolisian agar biaya perbaikan di bengkel resmi ditanggung oleh pihak asuransi.</div>
<div class="id-translation"><strong>ドライバー:</strong> 警察官の方、当方は車両総合保険の保険金請求（クラム）を行いたいと考えております。そのため、正規ディーラー工場での修理費用が保険会社から補償されるよう、警察の正式な事故届出書（事故証明）の発行をお願いいたします。</div>
<div class="id-explanation">klaim asuransi komprehensif（車両総合保険の請求） / surat laporan kepolisian（警察届出書） / ditanggung asuransi（保険でカバーされる）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 証拠の保全（写真・動画・ドラレコ）
- **Tolong jangan ubah posisi kendaraan sebelum saya mengambil foto dari berbagai sudut sebagai bukti.**
  （証拠として様々なアングルから写真を撮り終えるまで、車両の位置を動かさないでください。）
- **Kejadian tabrakan ini terekam jelas di kamera dasbor (dashcam) depan dan belakang mobil saya.**
  （この衝突の瞬間は、私の車の前後のドライブレコーダーに鮮明に記録されています。）

### 当て逃げされた場合の通報
- **Mobil saya diserempet oleh mobil sedan hitam yang langsung melarikan diri ke arah tol dalam kota.**
  （私の車は黒のセダンに擦られ、その車はそのまま都市高速方面へ当て逃げ（逃走）しました。）
- **Saya berhasil mencatat nomor plat kendaraannya, yaitu B 9999 ABC.**
  （相手車両のナンバープレート番号「B 9999 ABC」を控えメモすることに成功しました。）

## 4. 現地のリアル事情・生活のヒント

> [!CAUTION]
> **「群衆（Massa）」が集まる前に警察・路肩へ**:
> インドネシアではバイク対自動車の事故において、たとえバイク側に重大な過失（信号無視や逆走）があっても、周囲の群衆（massa）が「車に乗っている裕福な側＝悪者」と感情的に決めつけて騒ぎ立てるリスク（amuk massa）があります。
> 事故が起きたら、車外で相手と大声で口論せず、**静かに窓を開けて「Mari kita ke pos polisi terdekat（最寄りの交番へ行きましょう）」と提案し、安全な公的場所へ移動するのが身を守るための最優先原則**です。

<details class="id-quiz">
<summary>Q1. 「当て逃げ・ひき逃げ」を意味するインドネシア語の成句は？</summary>
<strong>正解: tabrak lari</strong><br>
解説: 衝突する（tabrak）＋ 逃げる（lari）の組み合わせです。
</details>

<details class="id-quiz">
<summary>Q2. 保険会社に車両修理費を請求する際に警察から取り寄せる書類は？</summary>
<strong>正解: Surat Laporan Polisi（Laporan Kepolisian）</strong><br>
解説: 保険会社（asuransi）に提出する必須の公式事故証明書です。
</details>
