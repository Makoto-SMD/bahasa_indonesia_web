# 実践対話・トラブル解決：空港での乗り継ぎ・ロストバゲージ申告（Transit Bandara & Bagasi Hilang）

スカルノ・ハッタ国際空港（CGK）やングラ・ライ空港（DPS）での国際線から国内線へのターミナル間移動（transit antar-terminal）、預け荷物がターンテーブルに出てこないロストバゲージ（bagasi hilang / tertinggal）、航空会社の手荷物紛失窓口（Baggage Claim / Lost & Found）での手続きと追跡を完遂するための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **transit pesawat / penerbangan lanjutan** | 乗り継ぎ / 乗り継ぎ便 | 同一航空券か別切りか |
| **pindah terminal / kalayang (Skytrain)** | ターミナル移動 / 空港連絡モノレール | T3からT1/T2への移動 |

## 2. リアル実践対話シナリオ（Lost & Found窓口での手荷物捜索申告）

国際線から国内線に乗り継いだ乗客（Penumpang）が、預け荷物が届いていないことに気づき、航空会社のバゲッジサービス窓口（Petugas Lost & Found）で申告します。

<div class="id-sentence"><strong>Penumpang:</strong> Selamat malam, Mbak. Saya penumpang Garuda Indonesia GA-875 dari Haneda transit ke Bali. <div class="id-translation"><strong>乗客:</strong> こんばんは。羽田発バリ行きのガルーダ便GA-875で乗り継いできた乗客です。他の乗客は全員スーツケースを受け取り終えましたが、私のサムソナイト製の黒い大型スーツケース1個が、5番カルーセル（ターンテーブル）に未だに出てきません。</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### ターミナル間移動の確認
- **Di mana saya bisa naik Skytrain (Kalayang) untuk pindah dari Terminal 3 Internasional ke Terminal 2 Domestik?**
  （ターミナル3国際線からターミナル2国内線へ移動するためのスカイトレイン（連絡モノレール）はどこで乗れますか？）
- **Apakah waktu transit dua jam ini cukup untuk melewati imigrasi dan mengambil bagasi?**
  （2時間の乗り継ぎ時間は、入国審査を通過して手荷物を受け取るのに十分ですか？）

### 破損・壊れたスーツケースの弁償申告
- **Koper saya keluar dalam kondisi rodanya patah satu dan ada retakan besar di bagian samping.**
  （私のスーツケースはキャスター（車輪）が1個折れ、側面に大きなヒビ割れが入った状態で出てきました。）
- **Saya ingin mengajukan klaim ganti rugi atas kerusakan fisik bagasi ini.**
  （この手荷物の物理的破損に対する損害賠償クレームを申請したいのですが。）

## 4. 現地のリアル事情・生活のヒント

> [!IMPORTANT]
> **ジャカルタT3乗り継ぎの「預け荷物スルー」確認**:
> 日本からジャカルタ経由でスラバヤ、バリ、ジョグジャカルタ等へ国内線乗り継ぎをする際、**「荷物が最終目的地までスルーで運ばれるか（bagasi di-thru）」、それとも「ジャカルタで一度ピックアップして税関審査を通す必要があるか」**は航空会社（ガルーダ等）や発券条件によって異なります。
> 日本出発時のチェックインカウンターで必ず「Apakah bagasi langsung ke Denpasar?（荷物はデンパサール直行ですか？）」と確認し、預かりタグの3文字コード（DPS等）を自分の目で照合しましょう。
