# 実践対話・トラブル解決：停電・ブレーカー落ち・電気トークン購入（Listrik Padam & Token PLN）

突然の真っ暗闇（mati lampu）、家電を同時使用した際のブレーカー落ち（anjlok / jeglek）、そして前払い式メーターの警告音（token habis）。インドネシアの電力事情（PLN）を乗り切るための必須対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **mati lampu / listrik padam** | 停電する / 電気が消える | mati lampuは最も身近な口語 |
| **jeglek / anjlok** | ブレーカーが落ちる | 容量オーバーでスイッチが飛ぶ擬音語 |
| **sekring / MCB** | ヒューズ / ブレーカー盤 | 配電盤の安全ブレーカー |
| **token listrik / pulsa listrik** | プリペイド電気トークン | 20桁の番号を購入して入力する |
| **meteran listrik / kWh meter** | 電気メーター | デジタルメーターで残量を管理 |
| **tambah daya** | 電気契約容量の増設 | 1300VA, 2200VAなどへの容量アップ |
| **PLN (Perusahaan Listrik Negara)** | 国営電力会社 | インドネシアの電力供給元 |

## 2. リアル実践対話シナリオ（コンビニでのトークン購入 & 管理人との対話）

### シーンA: コンビニ（Indomaret / Alfamart）で電気トークンを購入する

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Selamat sore, Mbak. Mau beli token listrik PLN prabayar.</div>
<div class="id-translation"><strong>客:</strong> こんにちは。前払い式のPLN電気トークンを買いたいのですが。</div>
<div class="id-explanation">token listrik PLN prabayar（プリペイド電気トークン）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kasir:</strong> Boleh sebutkan nomor meteran atau ID pelanggannya, Kak? Dan mau isi nominal yang berapa?</div>
<div class="id-translation"><strong>レジ係:</strong> メーター番号または顧客IDを教えていただけますか？また、いくらの金額をチャージされますか？</div>
<div class="id-explanation">nomor meteran（メーター番号） / ID pelanggan（顧客ID） / nominal（額面）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Pelanggan:</strong> Nomornya 3201-9876-5432 atas nama Budi. Mau isi yang dua ratus ribu rupiah ya.</div>
<div class="id-translation"><strong>客:</strong> 番号は3201-9876-5432、名義はBudiです。20万ルピア分をお願いします。</div>
<div class="id-explanation">atas nama（〜名義で）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Kasir:</strong> Baik, totalnya Rp202.500 termasuk biaya admin. Ini struknya ya, Kak. Dua puluh digit nomor stroom ada di bagian bawah cetakan.</div>
<div class="id-translation"><strong>レジ係:</strong> かしこまりました、手数料込みで合計20万2,500ルピアです。こちらがレシートです。印刷の下部に20桁のトークン番号が記載されています。</div>
<div class="id-explanation">biaya admin（事務手数料） / dua puluh digit nomor stroom（20桁の電力入力コード）。</div>
</div>

### シーンB: 家でブレーカーが頻繁に落ちるトラブルを管理人に相談する

<div class="id-example">
<div class="id-sentence"><strong>Penghuni:</strong> Pak, kenapa ya listrik di rumah sering jeglek setiap kali saya menyalakan oven bersamaan dengan AC dan pemanas air?</div>
<div class="id-translation"><strong>住人:</strong> 管理人さん、エアコンと給湯器を使っている時にオーブンをつけるたびに、なぜ頻繁にブレーカーが落ちてしまうのでしょうか？</div>
<div class="id-explanation">sering jeglek（頻繁にブレーカーが飛ぶ） / menyalakan oven bersamaan（同時にオーブンをつける） / pemanas air（給湯器・湯沸かし器）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Petugas:</strong> Itu karena daya listrik rumah ini hanya 1300 VA, jadi kelebihan beban, Pak. Solusinya harus mengajukan permohonan tambah daya ke PLN menjadi 2200 VA atau 3500 VA.</div>
<div class="id-translation"><strong>管理人:</strong> それはこの家の契約電力が1300VAしかないため、負荷超過（容量オーバー）になっているからです。解決策としては、PLNに契約容量を2200VAまたは3500VAへ増設する申請を出す必要があります。</div>
<div class="id-explanation">daya listrik（電力容量） / kelebihan beban（過負荷・容量オーバー） / permohonan tambah daya（容量増設申請）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 停電時の状況確認
- **Apakah di sekitar sini sedang ada pemadaman listrik bergilir dari PLN?**
  （この周辺一帯で、PLNによる輪番停電が行われているのですか？）
- **Mati lampu ini hanya di rumah saya saja atau satu komplek perumahan?**
  （この停電は私の家だけですか？それとも住宅地（コンプレックス）一帯ですか？）
- **Genset darurat gedung sudah menyala, tapi lift belum bisa digunakan.**
  （ビルの非常用自家発電機は回っていますが、エレベーターはまだ使えません。）

### メーターの警告アラーム
- **Meteran listriknya berbunyi 'tit tit' terus karena sisa kWh-nya sudah di bawah batas minimum.**
  （残りの電力量（kWh）が最低基準を下回っているため、電気メーターがずっと「ピッピッ」とアラームを鳴らしています。）
- **Bagaimana cara mematikan suara alarm meteran listrik ini?**
  （この電気メーターのアラーム音を一時的に消音するにはどうすればいいですか？）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **PLN Mobileアプリの活用**:
> 現在のインドネシアでは、スマートフォンの公式アプリ「**PLN Mobile**」を使うのが最も便利です。コンビニに行かなくても、アプリから直接クレジットカードやQRIS、Gopay/OVOでトークンを購入でき、停電の通報（pengaduan gangguan）や容量増設（tambah daya）の申し込みも数タップで完了します。

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 家電を使いすぎて「ブレーカーが落ちた！」と叫ぶときの日常語は？</summary>
<strong>正解: Listriknya jeglek! / Listriknya anjlok!</strong><br>
解説: ジャワ語起源のオノマトペ的表現「jeglek」または「anjlok」が全国的に定着しています。
</details>

<details class="id-quiz">
<summary>Q2. 「前払い式の電気トークン」のインドネシア語は？</summary>
<strong>正解: token listrik / pulsa listrik</strong><br>
解説: 携帯電話のチャージ（pulsa）と同じ感覚で「pulsa listrik」とも呼ばれます。
</details>
