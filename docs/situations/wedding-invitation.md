# 実践対話・文化マナー：インドネシア人の結婚披露宴参列・祝辞（Kondangan Pernikahan）

同僚、部下、ビジネスパートナーからの結婚式招待（undangan pernikahan）。インドネシア独自の参列文化「コンダンガン（kondangan）」、服装（バティック正装）、ご祝儀（amplop sumbangan）の相場と入れ方、受付での記帳、新郎新婦や両親への祝辞（ucapan selamat）、ビュッフェ（prasmanan）での立ち居振る舞いを完璧にこなすための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **kondangan / menghadiri pernikahan** | 結婚披露宴に参列すること | ジャワ語起源の全国的慣習語 |
| **undangan pernikahan** | 結婚式の招待状 | 近年はデジタル招待状（Web）が主流 |
| **baju batik lengan panjang** | 長袖の高級バティックシャツ | 男性の最高格の公式礼装 |
| **kebaya** | クバヤ | 女性の伝統的正装ドレス |
| **amplop sumbangan / uang angpao** | ご祝儀の封筒 / お祝い金 | 箱に投入する（無記名または名前記入） |
| **kotak sumbangan** | ご祝儀投入箱 | 受付に設置された鍵付き箱 |
| **pelaminan** | 新郎新婦の高砂・玉座ステージ | 記念撮影と挨拶の壇上 |
| **prasmanan (makan prasmanan)** | 立食・着席ビュッフェ料理 | 参列者へのもてなしのごちそう |

---

## 2. リアル実践対話シナリオ（受付での記帳 & 高砂ステージでの新郎新婦への祝辞）

同僚の結婚式に参列した日本人駐在員（Tamu Undangan）が、受付で記帳し、高砂壇上（Pelaminan）で新郎新婦（Mempelai）にお祝いを伝えます。

<div class="id-example">
<div class="id-sentence"><strong>Penerima Tamu:</strong> Selamat malam, Bapak. Selamat datang di pernikahan Rian dan Dita. Silakan mengisi buku tamu dan memindai kode QR buku kehadiran di sini.</div>
<div class="id-translation"><strong>受付係:</strong> こんばんは。リアンとディタの結婚式へようこそお越しくださいました。こちらで芳名帳へのご記帳、およびQRコードによるご出席登録をお願いいたします。</div>
<div class="id-explanation">mengisi buku tamu（芳名帳に記帳する） / memindai kode QR（QRコードをスキャンする）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Tamu:</strong> Terima kasih, Mbak. Ini amplopnya saya masukkan ke dalam kotak sumbangan ini ya. Apakah suvenir pernikahannya diambil sekarang?</div>
<div class="id-translation"><strong>参列者:</strong> ありがとうございます。こちらのご祝儀袋はこのお祝い箱に入れてよろしいですね。引き出物（記念ギフト）は今受け取る形でしょうか？</div>
<div class="id-explanation">kotak sumbangan（ご祝儀投入箱） / suvenir pernikahan（結婚式の引き出物・プチギフト）。</div>
</div>

### 高砂（Pelaminan）での新郎新婦・ご両親への挨拶

<div class="id-example">
<div class="id-sentence"><strong>Tamu:</strong> Halo Rian, selamat ya! Selamat menempuh hidup baru. Kalian berdua terlihat sangat serasi dan berbahagia sekali malam ini.</div>
<div class="id-translation"><strong>参列者:</strong> やあリアン、本当におめでとう！新しい人生の門出を心よりお祝いします。今夜のお二人は本当に息がぴったりで、最高にお幸せそうですね。</div>
<div class="id-explanation">selamat menempuh hidup baru（ご結婚・新しい人生の門出おめでとう＝最定番の祝辞） / sangat serasi（非常にお似合いの、息が合っている）。</div>
</div>

<div class="id-example">

<div class="id-translation"><strong>新郎:</strong> 田中さん、ご多忙の折にもかかわらず、私たちの晴れの日に足をお運びいただき本当にありがとうございます。あちらのビュッフェ料理や特設屋台（Gubukan）のお食事をどうぞ心ゆくまでお楽しみくださいね！</div>
<div class="id-explanation">menyempatkan hadir（都合をつけて参列してくださる） / hari bahagia（晴れの日・記念の日） / makanan gubukan（結婚式会場内の特設ブース屋台料理＝サテ、ローストビーフ、アイス等）。</div>
</div>

<div class="id-translation"><strong>参列者:</strong> お二人の結婚生活が常に安らぎと愛情と神の恵みに満ち、おじいさん・おばあさんになるまで末永く続きますように。</div>
<div class="id-explanation">sakinah, mawaddah, warahmah（イスラム文化圏における家庭円満・愛の最高の祝福句） / langgeng hingga kakek-nenek（白頭偕老・おじいちゃんおばあちゃんになるまで末永く）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### お祝いメッセージの書き方（祝儀袋・メッセージカード）
- **Selamat berbahagia untuk kedua mempelai, semoga cinta dan kebahagiaan selalu menyertai keluarga baru kalian.**
  （新郎新婦のお二人へ心からのお祝いを申し上げます。愛と幸福が新しいご家庭に常に寄り添いますように。）
- **Mohon maaf saya datang agak terlambat karena lalu lintas jalan raya sangat padat.**
  （道路の渋滞が非常に激しかったため、到着が少し遅れてしまい申し訳ありません。）

### 記念撮影の合図
- **Bolehkah kita berfoto bersama sebentar di atas pelaminan sebagai kenang-kenangan?**
  （記念の思い出として、高砂壇上でご一緒に少しお写真を撮ってもよろしいですか？）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **Kondanganのマナーとご祝儀相場**:
> - **服装**: 男性は長袖のバティック（Batik lengan panjang）と革靴を着用すれば、大統領が出席する披露宴でも通用する最高格式の正装となります。スーツ（jas）は親族や媒酌人以外は少数派です。
> - **ご祝儀（Amplop）の相場**: ホテルの格式や関係性によりますが、同僚・部下であれば**30万〜50万ルピア**、親しい友人や取引先、高級五つ星ホテルの場合は**50万〜100万ルピア**程度を新札で無地の白い封筒に入れ、自分の名前を小さく裏に書いて受付の鍵付き箱（kotak sumbangan）へ投入します。
> - **時間**: 招待状に「19:00〜21:00」とある場合、日本の披露宴と異なり「その時間内のいつ入って、いつ退出してもよい（自由出入り）」形式が基本です。

<summary>Q1. インドネシアで結婚式を祝う定番の決まり文句「ご結婚おめでとう」は？</summary>

解説: 半袖ではなく「長袖（lengan panjang）」がフォーマルな正装とみなされます。
</details>
