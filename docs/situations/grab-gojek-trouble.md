# 実践対話・トラブル解決：配車アプリ（Grab / Gojek）のトラブル・位置連絡（Kendala Ojol & Taksi Online）

インドネシア生活の移動を支える配車アプリGrabとGojek（バイクタクシー＝Ojol、自動車＝GrabCar / GoCar）。待ち合わせ場所のピン留めズレ、ドライバーが逆走・動かないトラブル（driver tidak jalan）、勝手なキャンセル要求（minta di-cancel）、料金二重請求（double charge）をアプリ内のチャットや電話で解決するための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **ojol (ojek online)** | オンラインバイクタクシー | GrabBike, GoRide |
| **titik jemput (pick-up point)** | 乗車地点・ピックアップ場所 | アプリのピン位置 |
| **titik antar (drop-off point)** | 降車地点・目的地 | ピンの正確な設定が重要 |
| **driver tidak bergerak / diam saja** | 運転手が動かない / 止まったまま | キャンセルさせようとする手口 |
| **minta dicancel** | キャンセルしてくれと頼む | 乗客側キャンセルを強要 |
| **tarif tol / parkir** | 高速道路代 / 駐車場代 | 実費は乗客の現金/電子マネー負担 |
| **salah rute / putar balik** | ルート間違い / Uターンする | 道に迷ったときの指示 |
| **OVO / GoPay / tunai** | アプリ内電子決済 / 現金決済 | キャッシュレスが推奨 |

## 3. トラブル解決！現場で使える必修フレーズ集

### ドライバーが動かない・キャンセルを要求してきた場合
- **Pak, mohon maaf saya tidak bisa membatalkan pesanan ini dari sisi saya karena performa akun saya akan turun. Kalau Bapak berhalangan menjemput, silakan Bapak sendiri yang membatalkan dari aplikasi driver.**
  （運転手さん、当方のアカウント評価が下がるため、乗客側からこの注文をキャンセルすることはできません。もしお迎えに来られないご都合があるのなら、運転手様ご自身でドライバーアプリ側からキャンセルしてください。）
- **Kenapa posisi mobil Bapak di peta malah semakin menjauh dari titik jemput?**
  （なぜ地図上のあなたのお車の位置が、ピックアップ地点から逆にどんどん離れていっているのですか？）

### 高速道路の利用指示と支払い
- **Lewat jalan tol saja ya Pak biar lebih cepat dan tidak terjebak macet. Nanti tarif tolnya masukkan saja ke tagihan aplikasi.**
  （より早く渋滞に巻き込まれないよう、高速道路を通ってください。高速代金はアプリの請求に合算（入力）してください。）

## 4. 現地のリアル事情・生活のヒント

> [!WARNING]
> **「乗客にキャンセルさせる」悪質手口への自衛策**:
> 渋滞や遠方を嫌う一部のドライバーが、車をわざと動かさずチャットで「Minta tolong cancel ya Kak（キャンセルしてくれ）」と要求してくることがあります。
> 乗客側が「乗客都合キャンセル」を選択すると、キャンセルペナルティ料金を請求されたり、アカウントの信頼スコアが低下します。**動かない場合は「Tolong Bapak yang cancel ya（あなたがキャンセルしてください）」と返し、それでも動かない場合は「Driver tidak bergerak（ドライバーが動かない）」を理由に選択してキャンセル**するか、サポート窓口（Pusat Bantuan）に通報しましょう。
