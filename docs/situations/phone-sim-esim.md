# 実践対話・通信手続き：プリペイドSIM・eSIM購入とスマホIMEI税関登録（Beli SIM Card & Daftar IMEI）

日本から持ち込んだスマートフォンをインドネシアで使うための最重要関門。主要キャリア（Telkomsel, Indosat, XL）でのプリペイドSIM / eSIM購入とプラン設定、空港税関（Bea Cukai）での**端末識別番号（IMEI）登録**と課税手続き、通信電波が開通しないトラブルへの対処法をマスターするための実践対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **kartu perdana / eSIM** | 新規SIMカード（スターターパック） / デジタルeSIM | 空港や公式ショップで購入 |
| **kuota internet / paket data** | データ通信容量 / データパッケージ | 20GB, 50GBなど |
| **registrasi nomor prabayar** | プリペイド回線の開通登録 | パスポート情報と紐付け |
| **pendaftaran IMEI (Bea Cukai)** | IMEI番号の税関登録 | 登録しないと現地SIMで電波不通 |
| **nomor IMEI (15 digit)** | 15桁の国際端末識別番号 | *#06# で確認 |
| **pajak masuk / bea masuk** | 輸入関税・付加価値税 | 端末価格500ドル超過分に課税 |
| **jaringan sinyal tidak muncul / no service** | 圏外・電波が立たない | IMEI未登録が原因 |
| **GraPARI (Telkomsel) / Gerai Indosat** | 各キャリアの公式直営フラッグシップ店 | 最も安全確実な登録窓口 |

## 4. 現地のリアル事情・生活のヒント

> [!CAUTION]
> **到着空港の税関（Bea Cukai）ブースで登録するのが鉄則**:
> 海外から持ち込んだスマホのIMEI登録は、ジャカルタやバリ島の**到着空港の手荷物受取所を出た直後の税関ブース（Pos Bea Cukai）で済ませるのが最もスムーズかつ経済的**です（税関エリア内なら500米ドル相当までの免税枠が適用されるため）。
> 空港を出てから市内の税関支署で後日申請すると、免税枠が適用されず全額課税（本体価格の約40%近い税金）となり、予約や移動にも膨大な手間がかかります。
