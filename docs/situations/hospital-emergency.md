# 実践対話・トラブル解決：救急病院・ER・デング熱疑いでの受診（UGD & Demam Berdarah）

夜間の突然の高熱、激しい悪寒、熱帯病（デング熱やチフス）が疑われる緊急事態。救急救命室（UGD / IGD: Unit Gawat Darurat）での受付、海外旅行保険（asuransi）のキャッシュレス手続き、血液検査（cek darah）、入院手続き（rawat inap）をスムーズに行うための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **UGD / IGD (Unit / Instalasi Gawat Darurat)** | 救急外来 / 救急救命室 | 24時間オープンの緊急受付 |
| **demam tinggi mendadak** | 突然の高熱 | 39度〜40度の急激な発熱 |
| **DBD (Demam Berdarah Dengue)** | デング出血熱 | 蚊が媒介する熱帯病の代表 |
| **cek darah lengkap (hematologi)** | 完全血算検査 | 血小板数（trombosit）を確認 |
| **trombosit turun** | 血小板の減少 | デング熱判定の決定打 |
| **infus (cairan infus)** | 点滴（点滴液） | 脱水防止・血小板維持 |
| **rawat inap / rawat jalan** | 入院 / 通院（外来） | 医師の診断による判断 |
| **asuransi cashless (tanpa tunai)** | キャッシュレス海外旅行保険 | 提携カード提示で自己負担ゼロ |

---

## 2. リアル実践対話シナリオ（救急外来での受付 & 医師の診察）

発熱と悪寒に苦しむ患者（Pasien）の配偶者（Pendamping）が、救急受付スタッフ（Petugas UGD）および救急当直医（Dokter Jaga）と話します。

<div class="id-example">
<div class="id-sentence"><strong>Pendamping:</strong> Selamat malam, Suster. Suami saya demam tinggi mendadak mencapai 39,5 derajat sejak kemarin sore. Tubuhnya menggigil parah, sendi-sendinya nyeri, dan mual muntah. Ini kartu asuransi internasional kami.</div>
<div class="id-translation"><strong>付き添い:</strong> こんばんは、看護師さん。夫が昨日の夕方から突然39.5度の高熱を出しています。ひどい悪寒で体が震え、関節の激痛と吐き気・嘔吐があります。こちらが私たちの海外旅行保険カードです。</div>
<div class="id-explanation">demam tinggi mendadak（急激な高熱） / menggigil parah（ひどく震える、悪寒） / sendi-sendinya nyeri（関節が痛む） / kartu asuransi internasional（国際保険証券カード）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Suster:</strong> Baik, Bu. Silakan pasien langsung berbaring di tempat tidur observasi nomor 3. Dokter jaga akan segera memeriksa tanda-tanda vital. Untuk asuransi, pihak rumah sakit kami sudah bekerja sama secara cashless, jadi kami yang akan menghubungi call center asuransi.</div>
<div class="id-translation"><strong>看護師:</strong> はい。患者様は直ちに3番の観察ベッドに横になってください。当直医がすぐにバイタルサインの診察を行います。保険に関しては当院とキャッシュレス提携がございますので、病院側から保険コールセンターへ連絡いたします。</div>
<div class="id-explanation">tempat tidur observasi（観察ベッド） / tanda-tanda vital（バイタルサイン: 血圧・脈拍等） / bekerja sama secara cashless（キャッシュレス提携している）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Dokter:</strong> Selamat malam. Setelah melihat gejala nyeri di belakang bola mata dan bintik-bintik merah di lengan, saya curiga ini mengarah ke Demam Berdarah Dengue (DBD). Kita harus segera ambil sampel darah untuk cek kadar trombosit dan hematokrit, lalu pasang infus cairan.</div>
<div class="id-translation"><strong>医師:</strong> こんばんは。眼球の奥の痛みや腕の点状出血（赤い斑点）といった症状から見ますと、デング熱（DBD）の疑いが強いです。至急採血を行い、血小板数（trombosit）とヘマトクリット値を検査した上で、直ちに点滴を装着しましょう。</div>
<div class="id-explanation">nyeri di belakang bola mata（眼球の奥の痛み＝デング熱特有の症状） / bintik merah（赤い発疹・点状出血） / curiga mengarah ke DBD（デング熱を疑う） / ambil sampel darah（採血する） / pasang infus（点滴をつなぐ）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Dokter:</strong> Hasil laboratorium menunjukkan trombosit Bapak turun drastis ke angka 70.000 (normal di atas 150.000). Pasien harus segera menjalani rawat inap di ruang perawatan agar bisa dipantau secara ketat selama 24 jam.</div>
<div class="id-translation"><strong>医師:</strong> 検査結果が出ました。血小板数が7万まで急激に低下しています（正常値は15万以上）。24時間体制で厳重な経過観察を行うため、直ちに入院治療（Rawat Inap）病棟へ移っていただく必要があります。</div>
<div class="id-explanation">trombosit turun drastis（血小板の急激な低下） / menjalani rawat inap（入院治療を受ける） / dipantau secara ketat（厳重に監視・モニタリングされる）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 症状の具体的伝達
- **Saya merasa pusing berputar, tidak nafsu makan, dan perut bagian kanan terasa nyeri sekali.**
  （めまいがして目が回り、食欲が一切なく、右腹部が激しく痛みます。）
- **Apakah pasien memiliki riwayat alergi terhadap obat antibiotik tertentu?**
  （患者様は特定の抗生物質に対するアレルギー歴をお持ちですか？）
- **Tidak ada riwayat alergi obat apa pun.**
  （薬のアレルギー歴は一切ありません。）

### 保証書（Guarantee Letter: GL）の確認
- **Apakah pihak asuransi sudah menerbitkan surat jaminan (Guarantee Letter) untuk biaya rawat inap ini?**
  （保険会社側から、今回の入院費用に対する支払い保証書（GL）は発行されましたか？）

## 4. 現地のリアル事情・生活のヒント

> [!IMPORTANT]
> **デング熱（DBD）の受診タイミング**:
> デング熱は発熱後3日目〜5日目の「熱が下がり始めた時期（fase kritis）」に血小板が急激に減少し、ショック症状に陥る危険があります。38度以上の熱が2日以上続き、関節痛や眼球痛がある場合は、市販薬（アスピリン系は出血を促すため禁忌）で我慢せず、直ちにSOSインターナショナル、シロアム（Siloam）、ポンドックインダ（RS Pondok Indah）などの大手私立総合病院のUGDへ駆け込んで採血（cek darah lengkap）を行ってください。

<strong>正解: trombosit（血小板数）</strong><br>
解説: 正常値15万〜45万に対し、10万以下に激減すると即座に入院措置が取られます。
</details>
