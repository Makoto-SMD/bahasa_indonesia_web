# 実践対話・トラブル解決：お手伝いさん・ドライバーへの日常業務指示・注意喚起（Instruksi Harian & Teguran）

雇用開始後の日々のコミュニケーション。「今日はお迎えの時間を変更して」「アイロンの温度に気をつけて」「施錠を徹底して」など、相手の尊厳を守りつつ（menjaga perasaan）、業務指示を明確に伝え、ミスがあった際に穏やかに改善を促す（menegur dengan sopan）ための対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **jemput / antar** | 迎えに行く / 送る | ドライバーへの最頻出指示語 |
| **kunci pintu / gembok pagar** | ドアを施錠する / 門に南京錠をかける | 防犯上の基本動作 |
| **setrika pakaian** | アイロンをかける | 温度設定の注意が必要 |
| **hati-hati / pelan-pelan** | 気をつけて / ゆっくり・安全に | 乱暴な運転をいさめる表現 |
| **jangan lupa** | 忘れないでね | リマインドの定番表現 |
| **tolong diperhatikan** | 注意・留意してください | 丁寧な注意喚起の言葉 |
| **simpan bon / struk bensin** | 領収書・ガソリンのレシートを保管する | 経費精算の基本 |

## 2. リアル実践対話シナリオ（日常の指示出し & 丁寧な注意）

### シーンA: ドライバーへのお迎え時間変更と安全運転の指示

<div class="id-example">
<div class="id-sentence"><strong>Majikan:</strong> Pak Joko, nanti sore jadwal saya ada perubahan. Tolong jemput anak saya di sekolah jam 14.30 dulu, baru setelah itu jemput saya di kantor jam 18.00. Karena hari ini hujan dan jalanan licin, tolong mengemudi dengan hati-hati dan jangan mengebut ya.</div>
<div class="id-translation"><strong>雇用主:</strong> ジョコさん、今日の夕方はスケジュールに変更があります。まず午後2時半に子どもの学校へお迎えに行ってもらい、そのあと午後6時に私のオフィスへ迎えに来てください。今日は雨で道路が滑りやすいので、くれぐれも安全運転で、スピードは出さないようお願いしますね。</div>
<div class="id-explanation">ada perubahan jadwal（予定に変更がある） / jalanan licin（道が滑りやすい） / jangan mengebut（スピードを出さない、暴走しない）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Sopir:</strong> Siap, Pak. Saya catat jamnya. Nanti sebelum berangkat dari sekolah anak, saya akan kabari lewat pesan WhatsApp. Mobil juga sudah saya cuci dan bensin sudah terisi penuh.</div>
<div class="id-translation"><strong>運転手:</strong> 了解いたしました。時間をメモしました。子どもの学校を出発する前に、WhatsAppメッセージでご連絡いたします。車も洗車を済ませ、ガソリンも満タンにしてあります。</div>
<div class="id-explanation">siap, Pak（了解しました、かしこまりました） / bensin sudah terisi penuh（ガソリン満タン）。</div>
</div>

### シーンB: お手伝いさん（ART）へ施錠の徹底と丁寧な注意喚起

<div class="id-example">
<div class="id-sentence"><strong>Ibu (Majikan):</strong> Mbak Siti, tolong ke sini sebentar ya. Tadi siang waktu saya pulang, pintu pagar depan dan pintu balkon atas terlihat tidak terkunci. Di daerah sini keamanan harus sangat dijaga. Tolong ke depannya selalu pastikan semua pintu terkunci rapat saat Mbak sedang di dalam maupun saat keluar rumah ya.</div>
<div class="id-translation"><strong>奥様:</strong> シティさん、ちょっとこちらに来てくださいね。先ほど昼に私が帰宅した際、表の門扉と2階のバルコニーのドアの鍵がかかっていませんでした。この地域では防犯対策を徹底しなければなりません。今後は家にいる時も外出する時も、すべてのドアがしっかり施錠されているか必ず確認してくださいね。</div>
<div class="id-explanation">tidak terkunci（施錠されていない） / keamanan harus dijaga（安全・防犯を守らなければならない） / terkunci rapat（しっかり施錠されている）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>ART:</strong> Aduh, mohon maaf sekali, Ibu. Tadi sehabis menjemur pakaian di atas, saya lupa mengunci kembali pintunya. Saya berjanji akan lebih teliti dan tidak akan mengulangi kelalaian ini lagi.</div>
<div class="id-translation"><strong>お手伝いさん:</strong> ああ、本当に申し訳ございません、奥様。先ほど屋上で洗濯物を干した後、鍵をかけ直すのをうっかり忘れてしまいました。今後はもっと注意を払い、二度とこのような不注意を繰り返さないようお約束いたします。</div>
<div class="id-explanation">habis menjemur pakaian（洗濯物を干し終わったあと） / lebih teliti（もっと注意深く、綿密に） / tidak mengulangi kelalaian（不注意を繰り返さない）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### アイロンがけ・洗濯の指示
- **Bahan kemeja sutra dan wol ini sangat halus, tolong setrika pakai suhu rendah atau gunakan setrika uap.**
  （このシルクやウールのシャツの生地は非常に繊細なので、低温でアイロンをかけるかスチームアイロンを使ってください。）
- **Pakaian warna putih tolong dipisahkan dari pakaian berwarna gelap saat mencuci agar tidak terkena luntur.**
  （色移りを防ぐため、洗濯の際は白い衣類と濃い色の衣類を分けて洗ってください。）

### 経費・領収書の提出
- **Tolong kumpulkan bon pembelian belanjaan dapur dan karcis parkir setiap akhir pekan untuk diganti uangnya.**
  （お金を精算するため、毎週末にキッチンの買い物レシートや駐車場の利用券をまとめて提出してください。）

## 4. 現地のリアル事情・生活のヒント

> [!TIP]
> **感情を害さない叱責（Teguran Halus）の極意**:
> インドネシア文化では、人前で大声で叱責すること（memarahi di depan orang）は相手の面子（gengsi）を完全に潰し、突然の辞職（kabur）を招く最大のタブーです。
> ミスを指摘する際は、必ず**一対一の個室で、まずは日頃の労働への感謝を述べてから、「Tolong lain kali lebih diperhatikan ya（次回からはもう少し気を配ってね）」と穏やかに伝える**のが、長く信頼関係を維持する秘訣です。

## 5. 理解度チェッククイズ

<details class="id-quiz">
<summary>Q1. 「（他人に）車で送ってもらう」と「迎えに来てもらう」の基本動詞は？</summary>
<strong>正解: 送る＝antar、迎える＝jemput</strong><br>
解説: ドライバーに「Antar saya ke kantor（会社へ送って）」「Jemput jam 5（5時に迎えて）」と使います。
</details>

<details class="id-quiz">
<summary>Q2. ドアや門が「しっかり施錠されている」を表す表現は？</summary>
<strong>正解: terkunci rapat</strong><br>
解説: 隙間なく密閉・施錠されていることを形容詞 rapat で表します。
</details>
