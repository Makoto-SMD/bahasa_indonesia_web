# 実践対話・トラブル解決：送金不着・ATMカード吸い込み・限度額変更（Kendala Transfer & Kartu Tertelan）

ATM機によるカードの吸い込み事故（kartu tertelan）、オンライン送金したのに相手に届かない送金不着（transfer belum masuk / pending）、高額決済時の送金限度額引き上げ（naikkan limit transfer）。銀行コールセンターや支店窓口での緊急トラブル対応対話ドリルです。

---

## 1. 現場の重要語彙・用語集

| インドネシア語 | 日本語 | ニュアンス・実務メモ |
| :--- | :--- | :--- |
| **kartu tertelan di mesin ATM** | ATM機にカードが吸い込まれる | 停電や放置、暗証番号間違い |
| **blokir kartu / pemblokiran rekening** | カード利用停止・ブロック / 口座凍結 | 不正利用防止の緊急処置 |
| **transfer belum masuk / tertunda (pending)** | 送金が未着・反映されない / 保留中 | 銀行間ネットワーク遅延 |
| **bukti transfer / mutasi rekening** | 振込明細書（スクショ） / 入出金履歴 | 調査時の必須証拠 |
| **naikkan limit transfer harian** | 1日の送金限度額を引き上げる | 家賃や学費の大型振込時 |
| **Halo BCA (1500888) / Call Center** | 24時間公式コールセンター | 直ちに通報すべき緊急窓口 |
| **salah transfer / salah nomor rekening** | 誤送金 / 口座番号の間違い | 返金手続きが必要 |

## 2. リアル実践対話シナリオ（ATMでカードが吸い込まれた際の緊急通報）

ショッピングモールのATMでカードを吸い込まれた顧客（Nasabah）が、銀行の緊急コールセンター（Petugas Call Center）へ直ちに通報してカードをブロックします。

<div class="id-example">
<div class="id-sentence"><strong>Nasabah:</strong> Selamat sore, Halo BCA. Tolong bantu saya, kartu debit saya baru saja tertelan di mesin ATM dalam mal Grand Indonesia. Mesinnya tiba-tiba restart sendiri dan kartu tidak keluar. Saya ingin segera memblokir kartu tersebut untuk keamanan.</div>
<div class="id-translation"><strong>顧客:</strong> こんにちは、Halo BCAですか。助けてください、グランドインドネシア・モール内のATM機に私のデビットカードがたった今吸い込まれてしまいました。機械が突然勝手に再起動し、カードが出てこないのです。安全のため、直ちにそのカードをブロック（利用停止）したいのですが。</div>
<div class="id-explanation">kartu baru saja tertelan（カードが吸い込まれたばかり） / mesin restart sendiri（機械が勝手に再起動する） / memblokir kartu（カードをブロックする）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Petugas:</strong> Selamat sore, Bapak. Tetap tenang, kami bantu proses pemblokiran sekarang juga. Mohon verifikasi data keamanan: boleh sebutkan nomor rekening, nama ibu kandung, dan perkiraan saldo terakhir Bapak?</div>
<div class="id-translation"><strong>オペレーター:</strong> こんにちは。落ち着いてください、今すぐ利用停止処理をお手伝いいたします。セキュリティ上の本人確認をさせていただきます。口座番号、実母の旧姓（お名前）、および直近の口座残高の概算を教えていただけますでしょうか？</div>
<div class="id-explanation">proses pemblokiran sekarang juga（今すぐ停止処理する） / nama ibu kandung（実母の名前＝本人確認の定番質問） / perkiraan saldo terakhir（直近の残高概算）。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Nasabah:</strong> Nomor rekening saya 876-001-2345, nama ibu kandung Hanako, dan saldo terakhir sekitar 45 juta rupiah.</div>
<div class="id-translation"><strong>顧客:</strong> 口座番号は876-001-2345、母の名前はHanako、直近の残高は約4,500万ルピアです。</div>
<div class="id-explanation">インドネシアの本人確認質問に的確に回答します。</div>
</div>

<div class="id-example">
<div class="id-sentence"><strong>Petugas:</strong> Data sesuai, Pak. Kartu debit Bapak dengan nomor akhir 5678 sudah resmi terblokir permanen per detik ini. Dana di dalam rekening tetap aman. Untuk penggantian kartu fisik baru, Bapak cukup datang ke kantor cabang BCA terdekat atau cetak mandiri lewat mesin CS Digital dengan membawa e-KTP/paspor asli.</div>
<div class="id-translation"><strong>オペレーター:</strong> データが一致いたしました。末尾5678のデビットカードは、ただ今の秒数をもって正式に恒久停止（ブロック）されました。口座内の資金は安全に保持されております。新しい物理カードの再発行については、最寄りのBCA支店窓口へお越しいただくか、パスポート原本をご持参の上「CSデジタル無人機」にて即時セルフ印刷発行が可能です。</div>
<div class="id-explanation">terblokir permanen per detik ini（ただ今この瞬間をもって恒久ブロックされた） / mesin CS Digital（CSデジタル無人自動発行機）。</div>
</div>

## 3. トラブル解決！現場で使える必修フレーズ集

### 送金不着（Pending）の調査依頼
- **Saya sudah mentransfer uang sewa sebesar Rp120 juta via BI-FAST sejak pagi, tapi pihak pemilik rumah bilang saldo belum masuk.**
  （朝からBI-FAST経由で家賃1億2,000万ルピアを送金したのですが、大家さん側はまだ入金が反映されていないと言っています。）
- **Ini nomor referensi transaksi (RRN) dan bukti mutasi rekening pendebetan berhasil.**
  （こちらが取引照会番号（RRN）および出金成功の明細履歴です。）

### 一時的な送金限度額の引き上げ
- **Saya perlu menaikkan limit transfer harian di aplikasi mobile banking menjadi Rp200 juta untuk keperluan pembayaran DP rumah.**
  （住宅頭金（DP）の支払いの必要上、アプリでの1日の送金限度額を2億ルピアまで引き上げたいのですが。）

## 4. 現地のリアル事情・生活のヒント

> [!CAUTION]
> **ATM吸い込み時の「偽ステッカー・偽電話番号」詐欺**:
> ATMのカード挿入口付近に「カードが吸い込まれた場合の緊急連絡先」として、偽の電話番号が書かれたステッカーが勝手に貼られている犯罪が報告されています。
> カードが吸い込まれた際は、ATMに貼られた怪しいシール番号には絶対に電話せず、**必ず自分のスマホで公式番号（BCAなら1500888、Mandiriなら14000）を検索して直接ダイヤル**してください。また、いかなる場合も暗証番号（PIN）を口頭で伝えてはいけません。
