### [IMP-001] プロジェクト初期立ち上げとポート競合防止
- **発生状況 / 課題**:
  - 日本語学習ナレッジベース（ポート8000）と同時並行で稼働させる必要がある。
  - ルビ拡張の読み込みエラーやPowerShellスクリプトの実行ポリシー制限をあらかじめ防ぐ必要がある。
- **根本原因**:
  - デフォルトポート（8000）の重複による起動失敗リスク。
  - Python仮想環境のPYTHONPATH未解決。
- **再発防止策・改善内容**:
  1. `run_server.ps1` および `run_server.bat` のデフォルト引数を `-a localhost:8001` に固定。
  2. `.venv/Lib/site-packages/local_project.pth` を作成し、プロジェクトルートのモジュールを常にロード可能にした。
  3. `format.ps1` をASCIIベースの安全なスクリプト構造にし、`-ExecutionPolicy Bypass` で安定動作する手順を確立。
- **反映先**:
  - `run_server.ps1`, `run_server.bat`, `AGENTS.md`, `pdca/GUIDELINES.md`

### [IMP-002] インドネシア語記事におけるルビ（カタカナ読み等）の完全撤廃
- **発生状況 / 課題**:
  - 執筆記事内のインドネシア語文章に `{単語|カタカナ}` 構文でルビを振っていたが、読みにくく不自然であるため不要との改善提案（ユーザーFB）を受領。
- **根本原因**:
  - 日本語学習サイト向けに構築された初期テンプレート・ルビ機能がそのまま引き継がれていたこと。インドネシア語はアルファベット表記であり、文章全体にカタカナのルビを振る必要性がそもそもない。
- **再発防止策・改善内容**:
  1. **全既存記事（13記事・374箇所）のルビを完全削除**: アルファベット本来のすっきりした文章に一括置換。
  2. **組織規約・ガイドラインの改定**:
     - `AGENTS.md`: ルビ構文規約を削除し、ルビ付与を禁止・不要と明記。
     - `pdca/GUIDELINES.md`: 「2.1 ルビの廃止方針」としてルビ不要ルールを明記。
     - `.agents/skills/autonomous-editorial/SKILL.md`: Writer/Reviewerの工程からルビ要件を排除。
     - `.agents/agents/writer.md`, `reviewer.md`: 執筆時・校正時のチェック項目からルビを排除し、混入防止を義務付け。
  3. **今後のタスク指示書**: ルビ付与指示は一切行わない。
- **反映先**:
  - `AGENTS.md`, `pdca/GUIDELINES.md`, `.agents/skills/autonomous-editorial/SKILL.md`, `.agents/agents/writer.md`, `.agents/agents/reviewer.md`, `docs/` 配下全記事

### [IMP-003] 長文読解（Reading Comprehension）コンテンツの構造化標準
- **発生状況 / 課題**:
  - 単語集や短文フレーズの学習だけでは、段落構成を持ったまとまった文章の読解力や文脈把握力が身につきにくいという学習課題。
  - 初級〜上級のレベル差や、日常生活から政治・経済・歴史哲学まで幅広い題材を体系的に学習できる長文コンテンツが求められた。
- **根本原因**:
  - 従来のナレッジベースは文法解説・語根辞書・短文パターンが中心であり、長文パッセージと包括的な解説が一体となった教材が不足していたこと。
- **再発防止策・改善内容**:
  1. **6部構成の長文読解テンプレートを標準化**:
     - ① 読解テキスト概要（難易度・語数・読了目安時間・テーマ）
     - ② インドネシア語本文（長文テキスト）
     - ③ 段落ごとの対訳と読解ポイント（対照形式）
     - ④ 重要語彙・キーフレーズ10選（品詞・語根・派生語分析）
     - ⑤ 文法・構文の徹底解説（接辞・接続詞・構文の深掘り）
     - ⑥ 読解力チェッククイズ（各3問、解答・解説付きアドモニション）
     - ⑦ 背景知識・文化コラム（社会・歴史・文化の深層理解）
  2. **段階的難易度と多彩な題材の設計**:
     - 初級（日常・バリ観光）→ 初中級（コーヒー文化・レバラン帰省）→ 中級（交通革命・熱帯雨林保護・QRISデジタル経済）→ 中上級（ボロブドゥールとバティック・ビジネス異文化協働）→ 上級（新首都IKN計画）の10記事を整備。
- **反映先**:
  - `docs/reading/`, `task/TASK-R01-R10_reading_comprehension.md`, `task/REVIEW-R01-R10_reading_comprehension.md`, `task/PROGRESS.md`, `zensical.toml`

### [IMP-004] ナビゲーション階層整理・総合サイトマップ新設・トップページ全面改訂
- **発生状況 / 課題**:
  - 全500記事の拡充に伴い、上部ナビゲーションタブが18個もフラットに並んで画面外に見切れる問題が発生。
  - トップページの主要セクションカードにリンクが設定されておらず、クリックしても該当ページに飛べない問題。
  - 全体にどのようなコンテンツがあるのか（500記事の全貌）が学習者に伝わらない問題。
- **根本原因**:
  - 初期設計時のフラットなタブ構成（8項目）のまま記事を追加し続けたため、タブ項目が18個に膨張しUIが破綻していた。
  - 初期ホームページのカードが静的な説明リストにとどまり、リンクや記事数、全体ロードマップとの連携が不足していた。
- **再発防止策・改善内容**:
  1. **ナビゲーションの7大トップタブへの階層整理 (`zensical.toml`)**:
     - `ホーム・案内` / `文字・文法・語根` / `語彙・類義語` / `会話・実践ドリル` / `ビジネス・実務` / `読解・時事・検定` / `地理・文化探訪` の7つに集約。
     - 上部タブの見切れを完全解消し、左サイドバーで各サブセクションが展開される階層構造を確立。
  2. **総合サイトマップの新設 (`docs/sitemap.md`)**:
     - 全18ジャンル・500記事の完全目録を作成。
     - 「目的別・レベル別おすすめ学習ルート（入門・旅行・ビジネス・検定・中上級時事）」を完備。
     - 各見出しに明示的アンカー（`#sec-01`〜`#sec-18`）を配置し、リンク切れ警告を完全撲滅。
  3. **トップページの全面改訂 (`docs/index.md`)**:
     - すべてのカードを直接クリック可能なリンク付きカードに刷新。
     - 「総合サイトマップ（500記事一覧）」への目立つバナーボタンを配置。
     - 最新の6段階ロードマップと、ルビ廃止規約に適合したすっきりした例文・対話例を掲載。
- **反映先**:
  - `zensical.toml`, `docs/index.md`, `docs/sitemap.md`, `pdca/NOTES.md`

### [IMP-005] 読者本位UIへの刷新、語根派生語テーブル化、太字約物バグ解消、長文読解順序最適化
- **発生状況 / 課題**:
  1. トップページに「全500記事の圧倒的網羅性」「自律運用の仕組み」など制作側都合の表現や、ランダムに動作しない「今日の実践フレーズ」等があり、読者体験に不要との指摘。
  2. 語根別派生語マスター図鑑（50記事）の Mermaid ダイアグラムが自動縮小され、文字が小さすぎて読めない。
  3. `**「年齢の上下...」**` 等の強調記法で、全角約物の外側に `**` がある場合に太字（`<strong>`）に変換されずアスタリスクが露出する。
  4. 時事ニュース等の長文読解記事で、長文と日本語訳が交互に並んでおり読解リズムが阻害される。
- **根本原因**:
  1. 制作側の開発成果や内部運用（AI自律運用等）をそのままトップページに反映してしまっていたこと。
  2. Mermaid（`graph TD`）は横幅が広がるとSVGが極端に縮小されるため、多ノード・長文のダイアグラムには不向きであること。
  3. Python-Markdown等のパーサーが全角約物（読点や鉤括弧）に隣接した半角アスタリスクを強調境界として認識しない仕様制約。
  4. 短文例文のフォーマット（`.id-example`）をそのまま長文記事に流用したため、パラグラフごとに対訳が挟まってしまっていたこと。
- **再発防止策・改善内容**:
  1. **トップページの読者本位化 (`docs/index.md`)**:
     - 制作都合の煽り（記事数固定表示・自律運用説明・ランダム性のない対話枠）を全削除し、体系的学習ロードマップとカテゴリ案内に特化。
  2. **派生語マスター図鑑全50記事のテーブル化 (`docs/derivations/`)**:
     - 視認性・モバイル対応に優れた Markdown テーブル（派生語、品詞・分類、意味・ニュアンス）に全面刷新。
  3. **日本語約物と太字ルールの確立 & 全202ファイル一括修正**:
     - `「**強調内容**」` のように括弧の内側に `**` を配置するルールを確立し、`pdca/GUIDELINES.md` に明記。
     - 全 `docs/` 配下（202ファイル）の壊れた太字記法を一括置換・修正し、`<strong>` レンダリングを確認。
  4. **長文読解全60記事のセクション順序再構成 (`docs/news-reading/`, `docs/reading/`)**:
     - ① インドネシア語長文本文（全文通読） → ② 重要語彙とコロケーション（読解中に確認） → ③ 日本語訳（読了後の答え合わせ） → ④ 構文・背景・クイズ の順序に全記事を再編。
- **反映先**:
  - `docs/index.md`, `docs/derivations/`（50記事）, `docs/news-reading/`（50記事）, `docs/reading/`（10記事）, `docs/vocabulary/family-relations.md` ほか全202ファイル, `pdca/GUIDELINES.md`
