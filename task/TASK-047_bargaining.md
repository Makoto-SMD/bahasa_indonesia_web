## 2. 記事のねらい・ゴール
バリ島の芸術市場（Pasar Seni Sukawati/Ubud）やジョグジャカルタのマリオボロ通り、ジャカルタのタナアバン市場など、インドネシアのローカル市場で欠かせない「値段交渉（Tawar-menawar）」。
ただ安く買うだけでなく、現地の人と笑顔で駆け引きを楽しみ、お互いに気持ちよく取引するための黄金ステップとキラーフレーズを伝授する。

## 3. 必須構成項目
1. **値段交渉（Tawar-menawar）の心得と基本スタンス**
   - 敵対的な値切りではなく「笑顔の交流・言葉のキャッチボール」
   - 定価がある場所（Harga Pas / モール・スーパー）では値切らないマナー
2. **値段交渉の6段階ステップ**
   - ① 尋ねる：`Berapa harganya, Mas?`（いくらですか？）
   - ② 高いと伝える：`Wah, kemahalan! / Mahal banget!`（うわ、高すぎる！）
   - ③ 値引き可能か聞く：`Bisa kurang gak? / Boleh tawar?`（まけてくれませんか？）
   - ④ 希望額を言う：`Kalau lima puluh ribu boleh?`（5万ルピアならどうですか？）
   - ⑤ まとめ買い提案：`Kalau beli dua / tiga, dapat berapa?`（2個/3個買うならいくらになりますか？）
   - ⑥ 立ち去り（Walk away）：`Terima kasih, saya jalan-jalan dulu ya.`（ありがとう、ちょっと他も見てきます） $\rightarrow$ 店主「Bolehlah!」
3. **通（ツウ）に聞こえるキラーフレーズ**
   - `Harga pasnya berapa?`（ズバリ底値はいくら？）
   - `Kasih harga lokal / harga teman dong!`（ローカル価格/友達価格にしてよ！）
   - `Harga nett-nya berapa?`（正味いくら？）
   - `Pasnya berapa, Bang?`
4. **交渉のルールとタブー**
   - 朝一番の最初の客（Penglaris）：朝イチは商売の縁起担ぎのため値切りに応じてもらいやすい反面、冷やかしは嫌がられる
   - 合意したら必ず購入すること（価格合意後のキャンセルは重大なマナー違反）
