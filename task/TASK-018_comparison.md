# 執筆指示書: TASK-018 比較表現（lebih, paling, sama ... dengan, se-）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/comparison.md`
- **目的**: インドネシア語の比較構文（優劣比較・最上級・同等比較）を体系的に解説する。
- **要件**:
  1. 比較級（`lebih + 形容詞 + daripada`＝〜より…だ）。
  2. 最上級の2大表現（`paling + 形容詞` vs 接頭辞 `ter- + 形容詞`）。
  3. 同等比較の2大表現（`sama + 形容詞 + dengan` vs 接頭辞 `se- + 形容詞`）。
  4. 劣等比較（`kurang + 形容詞 + daripada`＝〜ほど…ではない）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
