# 執筆指示書: TASK-012 指示詞（ini / itu）と指示代名詞の使い方

- **担当**: Writer
- **対象ファイル**: `docs/grammar/demonstratives.md`
- **目的**: インドネシア語の基本指示語「ini（これ・この）」と「itu（あれ・それ・あの・その）」、および場所の指示詞（sini, situ, sana）を完全マスターさせる。
- **要件**:
  1. 代名詞としての用法（文頭に置く「これは〜です」＝ `Ini buku.`）。
  2. 連体詞（指示形容詞）としての用法（名詞の後ろに置く「この本」＝ `buku ini`）。
  3. 冠詞（英語の the）としての `itu` の機能（すでに話題に出た特定の名詞を指す働き）。
  4. 場所の指示詞：`sini`（ここ）、`situ`（そこ）、`sana`（あそこ）と前置詞（di / ke / dari）との合体（di sini, ke sana 等）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
