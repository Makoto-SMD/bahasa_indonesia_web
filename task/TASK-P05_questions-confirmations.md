## 記事仕様
- **ファイル名**: `docs/patterns/questions-confirmations.md`
- **タイトル**: 【万能文章型⑤】疑問・確認・頻出質問のパターン構文（Sudah...belum / Berapa / Kapan / Kenapa）
- **想定読者**: 質問力を鍛え、相手から的確な情報を引き出すための質問テンプレートを自在に使いこなしたい学習者
- **記事の構成案**:
  1. 型1：`Sudah + [動詞] + [目的語] + belum?`（もう〜しましたか？まだですか？【完了確認の超頻出型】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集（食事、支払い、到着、確認）
     - 代入完成例文
  2. 型2：`Berapa + [名詞 / 単位] + untuk + [対象]?`（〜にはどれくらいの〜がかかりますか？【価格・時間・数量】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  3. 型3：`Kapan + [主語 / イベント] + dimulai / tiba?`（いつ〜は始まりますか／到着しますか？【日時の質問】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  4. 型4：`Kenapa + [主語] + tidak + [動詞 / 状態]?`（なぜ〜は〜しない／〜ではないのですか？【理由の質問】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  5. 穴埋めパターンドリル（穴あき問題と展開式解答）
