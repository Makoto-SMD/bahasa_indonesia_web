# 執筆指示書: TASK-010 否定詞の使い分け（tidak vs bukan の絶対原則）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/negation-tidak-bukan.md`
- **目的**: インドネシア語学習者が必ず直面する最大級の関門「tidak と bukan の完全な使い分け法則」を体系的に解き明かす。
- **要件**:
  1. 根本原理の対比表:
     - `tidak`: 動詞（〜しない）・形容詞（〜でない）を否定。
     - `bukan`: 名詞（〜ではない）・代名詞（私ではない）を否定。
  2. 例外・強調用法（`bukan karena... melainkan...`、疑問の念押し `... bukan?` など）。
  3. 日本人が間違えやすい典型トラップ（例: 「美味しくない」は tidak enak、「日本酒ではない」は bukan sake）。
  4. 口語表現（`nggak` / `gak`）との関係。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
