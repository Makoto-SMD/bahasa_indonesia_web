## 記事仕様
- **ファイル名**: `docs/patterns/opinions-comparisons.md`
- **タイトル**: 【万能文章型④】意見・感想・比較・評価のパターン構文（Menurut saya / Lebih...daripada / Terlalu）
- **想定読者**: 自分の主観、料理やサービスの感想、2つのものの比較、過剰な状態を「型＋穴埋め」で伝えたい学習者
- **記事の構成案**:
  1. 型1：`Menurut saya, [主語] + sangat + [形容詞].`（私の考えでは〜はとても〜です【私見の提示】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集（ホテル、企画、料理、都市、交通）
     - 具体的な代入例文
  2. 型2：`Saya lebih suka + [A] + daripada + [B].`（BよりもAの方が好きです【好みの比較】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  3. 型3：`[主語] + terlalu + [形容詞] + untuk + [対象 / 目的].`（〜にとって〜は〜すぎる【過剰・課題の指摘】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  4. 型4：`Dibandingkan dengan [A], [B] jauh lebih [形容詞].`（Aと比較して、Bの方がはるかに〜です【優劣・客観比較】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  5. 穴埋めパターンドリル（穴あき問題と展開式解答）
