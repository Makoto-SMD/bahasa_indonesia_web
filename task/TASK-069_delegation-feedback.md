# 執筆指示書: TASK-069 社員・スタッフへの指示・依頼・フィードバック

## 担当役職
- 企画・指示: 編集長 (Director)
- 執筆: 執筆担当 (Writer)
- 校正: 校正担当 (Reviewer)
- 検証: ビルド・検証 (Engineer)
- 監修: 上司 (BOSS)

## 記事仕様
- **ファイル名**: `docs/business/delegation-feedback.md`
- **タイトル**: 現地スタッフへの指示・業務依頼・フィードバックの伝え方
- **想定読者**: インドネシア現地法人のマネージャー・駐在員としてローカルスタッフをマネジメントする日本人リーダー
- **記事の構成案**:
  1. インドネシア人スタッフとの信頼関係構築の基本原則（人前で怒らない、笑顔と敬意、Bapak/Ibu/Mas/Mbakの使い分け）
  2. 業務指示・依頼のフレーズ（Tolong bantu..., Mohon dikerjakan..., Tenggat waktunya...）
  3. 優先順位と目的の共有（Prioritas utama, Tujuannya adalah...）
  4. 進捗確認とフォローアップ（Bagaimana perkembangannya?, Ada kendala?）
  5. ポジティブフィードバックと褒め言葉（Kerja bagus!, Luar biasa!）
  6. 改善指導・注意の伝え方（サンドイッチ話法、個別の場で話す、次はどうするか）
  7. 実践マネジメント対話とクイズ
