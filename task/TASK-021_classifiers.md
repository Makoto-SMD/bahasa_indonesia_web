# 執筆指示書: TASK-021 助数詞（Kata Penggolong）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/classifiers.md`
- **目的**: 日本語の「〜人」「〜匹」「〜本」「〜枚」に対応するインドネシア語の助数詞（orang, ekor, buah, lembar, batang 等）と数詞の結合ルールを解説する。
- **要件**:
  1. 助数詞の基本構文: 【数詞 ＋ 助数詞 ＋ 名詞】（例: `dua orang guru`）。
  2. 数字の「1（satu）」と助数詞が結合した接頭辞 `se-` の法則（`seorang`, `seekor`, `sebuah`, `selembar` 等）。
  3. 主要助数詞一覧マップ（人間: orang、動物: ekor、一般物・無生物: buah、紙・薄い物: lembar、細長い物: batang、粒・小さな丸い物: butir、本・書籍: jilid 等）。
  4. 日常会話での助数詞の省略傾向（口語では `dua bir` や `tiga nasi goreng` のように助数詞なしで数えることが多い実態）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
