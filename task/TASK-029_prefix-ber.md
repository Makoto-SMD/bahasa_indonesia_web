# 執筆指示書: TASK-029 接頭辞 ber- の自動詞・所有・状態表現完全マップ

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-ber.md`
- **目的**: インドネシア語の最も重要な自動詞接頭辞「ber-」の多彩な意味（所有、着用、動作・行動、相互動作、状態、数）と音韻変化（ber-, be-, bel-）を完全解説する。
- **要件**:
  1. `ber-` の音変化ルール:
     - 原則: `ber-`（berjalan, berbicara）
     - 語根頭文字が `r` の場合: `be-`（renang ➔ berenang, bukan ber-renang）
     - 第一音節が `-er-` を含む場合: `be-`（kerja ➔ bekerja, cermin ➔ becermin）
     - 特殊例外: `ajar` ➔ `belajar`
  2. 意味機能の6大マップ:
     - ① 所有（〜を持っている）: punya と同義（beruang＝金がある、beristri＝妻がいる）
     - ② 着用（〜を身につけている）: pakai と同義（berbaju merah＝赤い服を着ている）
     - ③ 行動・動作（〜をする）: berjalan（歩く）、berolahraga（運動する）
     - ④ 相互動作（互いに〜する）: bersalaman（握手し合う）
     - ⑤ 集合・グループ（〜人組で）: berdua（2人で）
  3. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
