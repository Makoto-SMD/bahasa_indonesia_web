# 執筆指示書: TASK-002 eの2種類の発音（シュワー /ə/ と エ /e/）

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/letter-e.md`
- **目的**: インドネシア語のアルファベット「E」が持つ2つの異なる音（曖昧母音シュワー /ə/ と はっきりした母音 /e/・/ɛ/）を日本人が直感的にマスターできるように解説する。
- **要件**:
  1. シュワー（e pepet: /ə/）とタリング（e taling: /e/）の口の形・発音原理の図解的説明。
  2. 辞書での表記（e と é / è）について解説。
  3. 単語の意味が変わるミニマルペア（対比例: apel /ə/ と apel /e/, perang と pirang など）の表。
  4. 頻出単語の例文カード（`.id-example`）を複数掲載（`selamat`, `teman`, `kantor`, `merdeka`, `sore` 等）。
  5. 日常対話（`.dialogue-box`）を収録。
