# 執筆指示書: TASK-013 疑問詞（5W1H）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/question-words.md`
- **目的**: インドネシア語の基本疑問詞（Apa, Siapa, Di mana, Ke mana, Dari mana, Kapan, Mengapa/Kenapa, Bagaimana, Berapa）の体系的な用法と語順を解説する。
- **要件**:
  1. 疑問詞一覧表（疑問詞、意味、文頭・文末での配置特徴）。
  2. 疑問詞を文頭に置く強調用法と接辞 `-kah` の役割。
  3. 疑問詞を平叙文の語順のまま置く自然な口語用法（`Nama Anda siapa?` 等）。
  4. 数量・価格・時間を尋ねる `Berapa` の多用途性。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
