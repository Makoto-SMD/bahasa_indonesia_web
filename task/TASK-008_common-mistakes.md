# 執筆指示書: TASK-008 日本人が間違えやすい発音・聞き取りの罠まとめ

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/common-mistakes.md`
- **目的**: 第1セクション「文字と発音」の総決算として、日本人学習者が100%つまずく典型的な発音の罠・聞き取りの落とし穴を総まとめし、実践的な克服法を提供する。
- **要件**:
  1. 罠①: 語末の母音化の癖（`tidak` を「ティダック」、`malam` を「マラム」と母音を付け足す罠）。
  2. 罠②: 「C」の英語化の罠（`cokelat` をコケラット、`cinta` をシンタと読むミス）。
  3. 罠③: シュワー /ə/ の平坦化（`selamat pagi` を日本語の「セラマット パギ」と言うミス）。
  4. 罠④: 単語で意味が変わる危険な発音違いペア（`kelapa` 椰子の実 vs `kepala` 頭、`pohon` 木 vs `mohon` お願いする など）。
  5. 罠⑤: `R` と `L` の取り違え。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
