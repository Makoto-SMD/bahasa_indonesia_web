# 執筆指示書: TASK-028 接頭辞 di- による受動構文の完全整理

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-di.md`
- **目的**: 三人称受動態を形成する接頭辞 `di-` の文法機能、能動態（meN-）との相互変換、前置詞 oleh の有無、接尾辞（-kan, -i）と合体した受動態（di-...-kan, di-...-i）の体系を解説する。
- **要件**:
  1. `di-` の基本原理（鼻音化のような複雑な音変化がなく、語根の前にそのまま di- をつけるだけという簡潔さ）。
  2. 能動態（meN-）から受動態（di-）への完全変換ステップ（主語と目的語の入れ替え、meN- を di- に置換）。
  3. 前置詞 `oleh`（〜によって）の省略ルール（動詞の直後なら省略可、副詞などが挟まる場合は省略不可）。
  4. 複合受動態: `di-...-kan`（使役・受益の受動）および `di-...-i`（反復・場所の受動）の入門。
  5. 前置詞の `di`（分かち書き: di pasar）と接頭辞の `di-`（接合書き: dipasar ではなく dijual）の再確認。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
