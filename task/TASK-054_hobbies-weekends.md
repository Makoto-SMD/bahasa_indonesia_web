## 2. 記事のねらい・ゴール
同僚や現地の友人との距離を一気に縮める最高のトピックである「趣味（Hobi）」と「週末の過ごし方（Akhir Pekan）」。
インドネシアの国民的スポーツであるバドミントン（bulu tangkis）や、日曜朝の大イベント「カーフリーデー（Car Free Day / CFD）」、カフェ巡り（ngopi）、モール散策（cuci mata / jalan-jalan）など、現地のリアルな週末カルチャーを織り交ぜながら、休日の予定を語り・誘い合う会話力を養う。

## 3. 必須構成項目
1. **趣味を尋ねる・答える基本構文**
   - `Apa hobi Anda?`（あなたの趣味は何ですか？）
   - `Hobi saya bermain bulu tangkis dan membaca komik.`（私の趣味はバドミントンと漫画を読むことです）
   - `Kalau ada waktu luang, saya suka ngopi di kafe.`（自由時間があれば、カフェでコーヒーを飲むのが好きです）
2. **人気の趣味ボキャブラリー集**
   - スポーツ：`bulu tangkis`（バドミントン）, `futsal`（フットサル）, `lari / jogging`（ランニング）, `berenang`（水泳）
   - 娯楽・カルチャー：`nonton film di bioskop`（映画館で映画を見る）, `main game online`（オンラインゲーム）, `masak`（料理）
   - レジャー：`jalan-jalan ke mall`（モール巡り）, `cuci mata`（ウインドウショッピング・目の保養）, `mendaki gunung`（登山）
3. **週末の過ごし方（Akhir Pekan）と日常の質問**
   - `Biasanya kalau akhir pekan kamu ngapain aja?`（普段の週末は何をしてるの？）
   - `Cuma santai di kos / rumah sambil rebahan.`（部屋でゴロゴロしながらのんびりしてるよ）
   - `Ikut Car Free Day (CFD) di Sudirman.`（スディルマン通りのカーフリーデーに参加する）
4. **休日に誘う・計画を立てる会話フレーズ**
   - `Hari Sabtu besok kamu ada acara gak?`（今週の土曜日、何か予定ある？）
   - `Mau ikut ngopi bareng anak-anak kantor gak?`（会社の同僚たちとお茶しに行かない？）
   - `Gimana kalau kita pergi bareng ke Bogor naik KRL?`（電車で一緒にボゴールへ遊びに行かない？）
   - `Boleh juga! Jam berapa kumpulnya?`（いいね！ 何時集合？）
5. **実践ロールプレイダイアログ（週末のバドミントンとCFDに誘う会話）**
