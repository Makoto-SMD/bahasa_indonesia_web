# 執筆指示書: TASK-037 接尾辞 -kan と -i の徹底比較

- **担当**: Writer
- **対象ファイル**: `docs/affixes/kan-vs-i.md`
- **目的**: インドネシア語学習者が最も頭を抱える「-kan と -i の違い」を、目的語が「動く（移動する）」か「静止している（場所・受容器）」かという明確な物理モデルで徹底的に解き明かす。
- **要件**:
  1. 黄金の物理モデル:
     - `-kan`: 目的語（O）が「移動する・動かされる」（使役・移動）。
     - `-i`: 目的語（O）が「その場に静止している・動作の目的地」（場所・着弾点）。
  2. 決定的な対比ペア4選:
     - `mendudukkan`（座らせる: 人を椅子に座らせる） vs `menduduki`（座る: 椅子に自分が座る）
     - `memasukkan`（入れる: 荷物を部屋に入れる） vs `memasuki`（入る: 自分が部屋に入る）
     - `mengirimi`（人に送る: 相手に手紙を送る） vs `mengirimkan`（物を送る: 手紙を相手に送る）
     - `menanami`（畑に植える: 畑に野菜を植える） vs `menanamkan`（苗を植える: 苗を畑に植える）
  3. 文法公式の対比: 【動詞-kan ＋ 移動物 ＋ ke 場所】 vs 【動詞-i ＋ 静止場所 ＋ dengan 移動物】。
  4. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
