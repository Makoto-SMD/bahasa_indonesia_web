## 記事仕様
- **ファイル名**: `docs/patterns/location-movement.md`
- **タイトル**: 【万能文章型②】場所・存在・移動・交通のパターン構文（Ada / Di mana / Naik / Antar）
- **想定読者**: 道案内、配車、移動、物の有無・場所確認を「型＋穴埋め」で自在に表現したい学習者
- **記事の構成案**:
  1. 型1：`Apakah ada + [名詞] + di + [場所]?`（〜に〜はありますか？【存在・有無】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集（ホテル、モール、カフェ、オフィス）
     - 具体的な代入例文
  2. 型2：`[名詞] + ada di mana? / Di mana + [施設]?`（〜はどこにありますか？【位置の質問】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  3. 型3：`Saya mau ke + [目的地] + naik + [交通手段].`（〜へ〜に乗って行きたい【移動方法】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  4. 型4：`Tolong antar saya ke + [目的地] + lewat + [経由地].`（〜経由で〜まで連れて行ってください【配車・タクシー】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  5. 穴埋めパターンドリル（穴あき問題と展開式解答）
