## 記事仕様
- **ファイル名**: `docs/patterns/reasons-conditions-time.md`
- **タイトル**: 【万能文章型③】理由・条件・時系列のパターン構文（Karena / Kalau / Sebelum / Sesudah）
- **想定読者**: 単文から一歩進んで、「〜だから…」「もし〜なら…」「〜する前に…」「〜した後に…」といった論理的で複文的な表現を穴埋め式で作りたい学習者
- **記事の構成案**:
  1. 型1：`[主文・結果] + karena + [理由・原因].`（〜なので〜です【理由の説明】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集（遅刻、体調、キャンセル、購入理由）
     - 代入完成例文
  2. 型2：`Kalau + [条件・仮定], + [主文・提案・指示].`（もし〜なら、〜してください【条件とアドバイス】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  3. 型3：`Sebelum + [行動A], tolong + [行動B].`（〜する前に、〜してください【事前準備】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  4. 型4：`Setelah / Sesudah + [行動A], saya akan + [行動B].`（〜した後に、〜します【事後対応・時系列】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  5. 穴埋めパターンドリル（穴あき問題と展開式解答）
