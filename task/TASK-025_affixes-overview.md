# 執筆指示書: TASK-025 接辞システム概要と語根（Kata Dasar）の基本概念

- **担当**: Writer
- **対象ファイル**: `docs/affixes/overview.md`
- **目的**: インドネシア語の心臓部である「接辞システム（Sistem Imbuhan）」の全容と、基本単位である「語根（Kata Dasar）」から派生語が無限に広がるメカニズムを解説する。
- **要件**:
  1. 語根（Kata Dasar）の概念（辞書の見出し語はすべて語根であること、語根自体の品詞と意味）。
  2. 接辞の4大分類（接頭辞 awalan/prefiks, 接尾辞 akhiran/sufiks, 周囲辞 konfiks, 挿入辞 infiks）。
  3. 1つの語根から派生する具体例（例: `ajar` [教える] ➔ `belajar`, `mengajar`, `pelajar`, `pelajaran`, `pengajar` 等のファミリー展開）。
  4. 辞書（KBBI等）を引くための語根特定テクニック。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
