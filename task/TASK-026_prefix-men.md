# 執筆指示書: TASK-026 接頭辞 meN- の鼻音化変化法則（K, T, S, P 脱落）

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-men.md`
- **目的**: 能動態動詞を作る最も重要な接頭辞「meN-」の全変化パターンと、語根頭文字の K, T, S, P が鼻音と同化して消滅する黄金ルールを完璧に体系化する。
- **要件**:
  1. `meN-` の "N"（大文字）の意味（後ろに来る語根の頭文字によって me-, mem-, men-, meng-, meny-, menge- に化けること）。
  2. 語根頭文字ごとの変化完全分類表:
     - 母音 (a, i, u, e, o) 及び g, h ➔ `meng-`
     - b, f ➔ `mem-`
     - d, j, c ➔ `men-`
     - l, m, n, r, w, y ➔ `me-`
  3. 【最重要黄金ルール】K, T, S, P の脱落と鼻音同化:
     - K ➔ `meng-` (kirim ➔ mengirim)
     - T ➔ `men-` (tulis ➔ menulis)
     - S ➔ `meny-` (sapu ➔ menyapu)
     - P ➔ `mem-` (pakai ➔ memakai)
  4. 1音節の語根（cat, bom, pel 等）➔ `menge-` の特殊ルール。
  5. 外来語の例外（頭文字が子音連続の場合: kritik ➔ mengkritik、traktir ➔ mentraktir 等）。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
