## 記事仕様
- **ファイル名**: `docs/business/contracts-terms.md`
- **タイトル**: 契約書・覚書（MOU）・合意条項のビジネス用語と法務表現
- **想定読者**: インドネシアの企業と契約書（Perjanjian Kerjasama / Kontrak）や覚書（Nota Kesepahaman / MOU）を締結・確認する日本人ビジネスパーソン
- **記事の構成案**:
  1. 契約書の基本文書名と種類（Surat Perjanjian, Kontrak, MOU / Nota Kesepahaman, NDA / Perjanjian Kerahasiaan）
  2. 契約書の前文と当事者表記（Pihak Pertama, Pihak Kedua, Pasal）
  3. 頻出の契約条項（Pasal-Pasal Penting: 権利と義務、有効期間、解除事由、違約金、不可抗力 Force Majeure、紛争解決）
  4. 契約交渉・修正依頼の会話表現（Klausul ini perlu direvisi..., Mohon tambahkan pasal...）
  5. 署名・調印と収入印紙（Meterai）のルール
  6. 理解度クイズ
