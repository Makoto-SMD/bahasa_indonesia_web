# 執筆指示書: TASK-024 受動態の基礎（三人称受動態 di- と 一人称・二人称受動態）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/passive-voice.md`
- **目的**: インドネシア語文法最大の関門である「受動態構文（Pasif）」の2大ルール（三人称の接頭辞 di- 構文 vs 一人称・二人称の語幹受動構文）を日本人向けに徹底的に整理する。
- **要件**:
  1. 能動態（SVO）から受動態への変換メカニズム。
  2. 三人称受動態: 【主語（被動作主） ＋ di-動詞 (＋ oleh 動作主)】（例: `Buku itu dibaca (oleh) dia.`）。
  3. 【最重要関門】一人称・二人称受動態（語幹受動態）:
     - ❌ `Buku itu dibaca oleh saya.` は文法的に不自然！
     - ⭕ **【主語 ＋ 人称代名詞 ＋ 語根動詞】**: `Buku itu saya baca.`（その本は私が読みました）。
  4. なぜインドネシア語で受動態が多用されるのか（話題の焦点化・客観的トーン・丁寧さ）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
