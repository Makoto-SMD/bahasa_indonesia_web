# 執筆指示書: TASK-019 等位接続詞（dan, atau, tetapi, melainkan）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/coordinating-conjunctions.md`
- **目的**: 語と語、節と節を対等に結ぶ等位接続詞（並列、選択、逆接、対比）の用法と文法ルールを解説する。
- **要件**:
  1. `dan`（並列: 〜と、そして）と口語の `sama`。
  2. `atau`（選択: または、それとも）と疑問文での二者択一。
  3. `tetapi` / `tapi`（逆接: しかし）の用法。
  4. 【最重要検定頻出】`tetapi` vs `melainkan` の使い分け（tidak A, tetapi B vs bukan A, melainkan B の相関ルール）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
