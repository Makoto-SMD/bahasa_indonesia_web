## 2. 記事のねらい・ゴール
バリ島のリゾートヴィラから大都市のビジネスホテルまで、滞在を快適にするための必須フレーズを網羅する。
フロントでのチェックイン・チェックアウト、デポジットの支払い、部屋の要望（禁煙・高層階・ダブルベッド）、そしてエアコン故障や水回りトラブル、荷物の一時預かりまで、あらゆるシチュエーションをスムーズに解決できる実践力を養成する。

## 3. 必須構成項目
1. **チェックイン（Check-in）の手続き**
   - `Saya mau check-in. Saya sudah pesan kamar atas nama Tanaka.`（チェックインをお願いします。タナカの名前で部屋を予約しています）
   - `Boleh pinjam paspor Anda untuk difotokopi?`（コピー用にパスポートをお借りできますか？）
   - `Uang jaminan / deposit`（デポジット・保証金）
   - `Sarapan pagi dimulai jam berapa dan di mana?`（朝食は何時からどこで食べられますか？）
   - `Password Wi-Fi-nya apa?`（Wi-Fiのパスワードは何ですか？）
2. **部屋・アメニティのリクエスト**
   - `Kamar bebas rokok`（禁煙ルーム） vs `Kamar merokok`（喫煙ルーム）
   - `Tempat tidur ukuran king / double / twin`（キング/ダブル/ツインベッド）
   - `Kamar di lantai atas dengan pemandangan bagus`（眺めの良い高層階の部屋）
   - `Minta handuk tambahan / sikat gigi`（追加のタオル/歯ブラシをください）
3. **部屋のトラブル・故障の申告（フロントへの電話連絡）**
   - `AC di kamar saya rusak / tidak dingin.`（私の部屋のエアコンが壊れている/冷えません）
   - `Air panasnya tidak keluar.`（お湯が出ません）
   - `Kran airnya bocor.`（蛇口から水漏れしています）
   - `Kunci kartu kamar saya tidak berfungsi.`（部屋のカードキーが作動しません）
   - `Bisa tolong kirim teknisi untuk memperbaikinya?`（修理のために技術スタッフを送っていただけますか？）
4. **チェックアウト（Check-out）と荷物預かり**
   - `Boleh minta late check-out sampai jam 2 siang?`（午後2時までレイトチェックアウトできますか？）
   - `Saya mau check-out sekarang. Ini kunci kamarnya.`（今チェックアウトしたいです。これがルームキーです）
   - `Bolehkah saya menitipkan koper di sini sampai sore?`（夕方までここにスーツケースを預けてもいいですか？）
5. **実践ロールプレイダイアログ（ホテルのフロントでのチェックインと要望）**
