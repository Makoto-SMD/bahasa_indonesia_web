## 2. 記事のねらい・ゴール
周囲辞 `peN-...-an` と `per-...-an` は、ビジネス文書、ニュース、学術論文、公的スピーチの主役となる最重要名詞化接辞である。
日本人学習者が最も混同しやすい「動作プロセス（peN-...-an）」「制度・事象・結果（per-...-an）」の違いを、対応する動詞（meN- vs ber-）との連動性から論理的に解き明かす。
この記事により、接辞セクション全16記事の集大成として確固たる名詞化の体系的理解を確立する。

## 3. 必須構成項目
1. **周囲辞 `peN-...-an` と `per-...-an` の全体像**
   - どちらも「名詞」を作る周囲辞
   - `meN-` 動詞と対をなす `peN-...-an`（動詞の動作プロセス・行為の実行）
   - `ber-` 動詞や名詞と対をなす `per-...-an`（事象・制度・場所・結果・関係）
2. **`peN-...-an` の法則と鼻音化音変化**
   - 接頭辞 `peN-` と同様の鼻音化変化（K, T, S, P の脱落）
   - `tulis` $\rightarrow$ `penulisan`（執筆プロセス）
   - `kembang` $\rightarrow$ `pengembangan`（開発・発展させること）
   - `bayar` $\rightarrow$ `pembayaran`（支払い手続き・決済）
   - `didik` $\rightarrow$ `pendidikan`（教育・教育活動）
3. **`per-...-an` の法則と r の脱落変化**
   - `per-` が語根と結合。語根頭や第1音節に `er` があると `pe-...-an` に変化（kerja $\rightarrow$ pekerjaan, ajar $\rightarrow$ pelajaran）
   - `temu`（会う）$\rightarrow$ `pertemuan`（会合・ミーティング）
   - `beda`（異なる）$\rightarrow$ `perbedaan`（違い・相違点）
   - `syarat`（条件）$\rightarrow$ `persyaratan`（要件・条件項目）
   - `janji`（約束する）$\rightarrow$ `perjanjian`（契約・協定）
4. **同一語根による徹底対比（ニュアンスの決定的な違い）**
   - **ajar（教える/学ぶ）**：
     - `pengajaran`（教えるプロセス・教授法・教育行為）
     - `pelajaran`（教科・学科・学習・教訓）
   - **ubah（変える/変わる）**：
     - `pengubahan`（修正作業・変更プロセス）
     - `perubahan`（変化そのもの・変容した状態）
   - **kembang（発展する/させる）**：
     - `pengembangan`（開発・育成・開拓プロセス）
     - `perkembangan`（自然な成長・発達・推移）
   - **kirim / bangun との関連語**：
     - `pengiriman`（発送業務） vs `kiriman`（送られた荷物）
     - `pembangunan`（建設事業・開発） vs `bangunan`（建物そのもの）
5. **接辞システム完全マスターのまとめフローチャート**
   - 語根 $\rightarrow$ meN-（能動）/ di-（受動）/ ber-（自己状態）/ ter-（無意図・最上級）/ -kan（使役・受益）/ -i（対象・反復）/ -an（結果）/ ke-...-an（抽象名詞・被害）/ peN-...-an（プロセス）/ per-...-an（事象）
6. **注意点**
   - ルビ構文（`{単語|読み}`）は一切使用しないこと。
