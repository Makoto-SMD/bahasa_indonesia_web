# 執筆指示書: TASK-017 助動詞（bisa, boleh, harus, mau, ingin）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/auxiliary-verbs.md`
- **目的**: 動詞の前に置くだけで可能・許可・義務・意志・希望を表現できる主要助動詞のニュアンスの違いと使い分けを完全解説する。
- **要件**:
  1. 可能・能力（`bisa`＝できる、`dapat`＝可能である、フォーマル） vs 許可（`boleh`＝〜してもよい）。
  2. 否定形のニュアンス対比: `tidak bisa`（できない） vs `tidak boleh`（してはいけない＝禁止）。
  3. 義務・必然（`harus`＝〜しなければならない、`perlu` / `usah`＝〜する必要がある）。`tidak usah`（〜する必要はない）の最頻出用法。
  4. 意志・希望（`mau`＝〜したい・〜するつもり、口語で万能） vs `ingin` / `hendak`（願望・〜したい、やや改まった丁寧表現）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
