# 執筆指示書: TASK-014 時制副詞（sudah, belum, sedang, akan, pernah）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/tense-aspect.md`
- **目的**: インドネシア語には動詞の活用（過去形・未来形など）がなく、「時制・アスペクト副詞を動詞の前に置くだけ」で過去・現在・未来を自在に操れるシステムを解説する。
- **要件**:
  1. 動詞の語形変化がないことの解説（英語との比較: eat-ate-eaten ではなく常に makan）。
  2. 5大時制副詞の徹底整理:
     - `sudah` (完了: もう〜した)
     - `belum` (未完了: まだ〜していない) ※tidak sudah とは言わない超重要ルール
     - `sedang` / `lagi` (進行: 〜している最中)
     - `akan` / `mau` (未来・意志: 〜する予定・〜するつもり)
     - `pernah` (経験: かつて〜したことがある) / `belum pernah` (一度も〜したことがない)
  3. 時を表す語句（kemarin, besok, tadi, nanti など）との連携。
  4. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
