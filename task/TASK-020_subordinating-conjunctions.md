# 執筆指示書: TASK-020 従属接続詞（理由・条件・結果・目的・譲歩）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/subordinating-conjunctions.md`
- **目的**: 複文（主節と従属節）を形成する主要な従属接続詞（karena, kalau/jika, sehingga, supaya/agar, meskipun）の用法をマスターさせる。
- **要件**:
  1. 理由・原因: `karena` / `sebab`（〜なので、〜だから）。
  2. 条件・仮定: `kalau`（会話）/ `jika` / `bila` / `apabila`（フォーマル）（もし〜なら）。
  3. 結果・帰結: `sehingga` / `sampai`（その結果〜、〜するほどに）。
  4. 目的: `supaya` / `agar`（〜するために、〜するように）。
  5. 譲歩: `meskipun` / `walaupun`（〜にもかかわらず、〜だけれども）。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
