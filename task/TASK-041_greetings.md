# 執筆指示書: TASK-041 基本の挨拶と自己紹介（初対面・お礼・別れ）

## 1. 基本情報
- 記事番号: 041
- ファイルパス: `docs/conversation/greetings.md`
- 担当: Writer (執筆担当)
- 監修: Director (編集長)

## 2. 記事のねらい・ゴール
日常会話セクション（041〜060）の幕開けとなる最重要記事。
インドネシア人と心を通わせる第一歩である「時間帯ごとの挨拶」「自己紹介」「調子の尋ね方」「感謝・謝罪」「別れの挨拶」を網羅する。
特に「Selamat tinggal（残る人へ） vs Selamat jalan（行く人へ）」の違いや、「Permisi（失礼します） vs Maaf（すみません）」の使い分けなど、文化的な礼儀作法・ニュアンスも丁寧に伝授する。

## 3. 必須構成項目
1. **時間帯ごとの基本挨拶（Selamat ...）**
   - `Selamat pagi`（おはようございます / 日の出〜10:30頃）
   - `Selamat siang`（こんにちは / 10:30〜15:00頃）
   - `Selamat sore`（こんにちは・夕方の挨拶 / 15:00〜18:30頃）
   - `Selamat malam`（こんばんは / 18:30以降）
   - 親しい間柄での短縮形：`Pagi!`, `Siang!`, `Sore!`, `Malam!` / `Halo!`, `Hai!`
2. **近況を尋ねる・答える会話**
   - `Apa kabar?`（お元気ですか？）
   - `Kabar baik.`（元気です）
   - `Baik-baik saja.`（変わりなく元気です）
   - `Kurang sehat.` / `Biasa saja.`
3. **初対面の自己紹介フレーズ**
   - `Perkenalkan, nama saya ...`（初めまして、私の名前は〜です）
   - `Saya orang Jepang.` / `Saya berasal dari Tokyo, Jepang.`（日本人です / 日本の東京出身です）
   - `Senang bertemu dengan Anda.`（お会いできて嬉しいです）
   - 職業・身分の紹介（Saya bekerja di ..., Saya mahasiswa ...）
4. **感謝（お礼）と返答**
   - `Terima kasih.` / `Terima kasih banyak.`（ありがとうございます / 大変ありがとうございます）
   - `Makasih.`（親しい間柄でのカジュアルなお礼）
   - `Sama-sama.`（どういたしまして / 最も一般的）
   - `Kembali.`（どういたしまして / 改まった場面・サービス業）
5. **謝罪と配慮（Maaf vs Permisi）**
   - `Maaf`（ごめんなさい・申し訳ありません：過失や迷惑に対する謝罪）
   - `Permisi`（失礼します・ちょっと通してください：声掛けや通り抜け）
   - `Tidak apa-apa.` / `Gak apa-apa.`（大丈夫です・気にしないで）
6. **別れの挨拶（Selamat tinggal vs Selamat jalan）**
   - `Selamat jalan`（見送る側 $\rightarrow$ 去る側へ：「道中ご無事で・行ってらっしゃい」）
   - `Selamat tinggal`（去る側 $\rightarrow$ 残る側へ：「お元気で・さようなら」）
   - 最も日常的で使いやすいフレーズ：
     - `Sampai jumpa!`（また会いましょう！）
     - `Sampai nanti!`（また後で！）
     - `Sampai besok!`（また明日！）
     - `Hati-hati ya!`（気をつけてね！）
7. **実践ロールプレイ会話ボックス（.dialogue-box）**
   - 初対面での自己紹介ミニ会話を掲載。
