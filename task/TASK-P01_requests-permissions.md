## 記事仕様
- **ファイル名**: `docs/patterns/requests-permissions.md`
- **タイトル**: 【万能文章型①】依頼・許可・希望のパターン構文（Tolong / Boleh / Mau / Minta）
- **想定読者**: 1つの「型（テンプレート）」を覚えて、穴埋め単語を入れ替えることで日常・旅行・ビジネスのあらゆるシチュエーションに対応したい学習者
- **記事の構成案**:
  1. 型1：`Tolong + [動詞] + [目的語] + (ya)`（〜してください・〜をお願いします）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集（生活、移動、オフィス、レストラン）
     - 具体的な代入例文（4〜5パターン）
  2. 型2：`Boleh saya + [動詞] + [目的語]?`（〜してもよろしいですか？【許可】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  3. 型3：`Saya mau + [動詞 / 名詞] + (yang [形容詞])`（〜が欲しい／〜なものがいい【希望】）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  4. 型4：`Minta tolong untuk + [動詞] / Minta + [名詞]`（〜をください・〜を頼む）
     - 穴あきテンプレートと解説
     - 入れ替えパーツ集と代入例文
  5. 穴埋めパターンドリル（穴あき問題と展開式解答）
