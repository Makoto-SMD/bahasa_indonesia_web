## 2. 記事のねらい・ゴール
海外滞在時に命や安全に直結する医療サバイバル表現を網羅する。
身体の各部位の痛み（sakit kepala, sakit perut）、熱帯特有の「バリ腹（Bali Belly / Diare）」やデング熱（DBD）、インドネシア独自の民間健康概念「Masuk Angin（体に風が入る）」の解説から、薬局（Apotek）での薬の買い方・用法用量の聞き方、病院（Rumah Sakit）での海外旅行保険手続きまでを完全伝授する。

## 3. 必須構成項目
1. **体調不良・痛みの基本構文（sakit ...）**
   - `Saya merasa tidak enak badan.`（体がだるい・体調が悪い）
   - 部位別の痛み：`sakit kepala / pusing`（頭痛・めまい）, `sakit perut`（腹痛）, `sakit tenggorokan`（喉の痛み）, `sakit gigi`（歯痛）
2. **熱帯で遭遇しやすい症状と病名**
   - `demam / badan panas`（発熱）
   - `diare / mencret`（下痢・バリ腹）
   - `mual dan muntah`（吐き気と嘔吐）
   - `batuk dan pilek`（咳と鼻水）
   - `Demam Berdarah Dengue (DBD)`（デング熱）
   - 【文化解説】`Masuk angin`（体に風が入る風邪・冷え症状。万能ハーブ薬 Tolak Angin や コインで背中を擦る Kerokan の紹介）
3. **薬局（Apotek）での薬の購入**
   - 街の薬局（Kimia Farma, Century, Guardian）
   - `Ada obat untuk diare / penurun panas?`（下痢止め/解熱剤はありますか？）
   - 用法・用量の聞き方：
     - `Diminum berapa kali sehari?`（1日何回飲みますか？）
     - `Sehari tiga kali, dua tablet setelah makan.`（1日3回、食後に2錠）
     - `Sebelum makan`（食前）, `Sebelum tidur`（就寝前）
4. **病院（Rumah Sakit）での受診と保険手続き**
   - `Di mana Rumah Sakit yang ada dokter berbahasa Inggris / Jepang?`（英語/日本語を話す医師がいる病院はどこですか？）
   - `Unit Gawat Darurat (UGD / IGD)`（救急外来・緊急治療室）
   - `Saya mau klaim asuransi perjalanan.`（旅行保険を請求したいです）
   - `Tolong buatkan surat keterangan medis dan kuitansi.`（医療診断書と領収書を作成してください）
5. **実践ロールプレイダイアログ（薬局での症状相談と薬の購入）**
