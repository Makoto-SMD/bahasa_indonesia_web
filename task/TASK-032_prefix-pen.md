# 執筆指示書: TASK-032 接頭辞 pe- / peN- の動作主・道具・性質の形成

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-pen.md`
- **目的**: 動作を行う「人（動作主）」や「道具・器具」、人の「性質・性向」を表す名詞を形成する接頭辞 `pe-` および `peN-` の法則を解説する。
- **要件**:
  1. `peN-` と `meN-` の完全な平行性（meN- と同じ鼻音化ルールで pem-, pen-, peng-, peny-, penge- に変化し、K-T-S-P も同様に脱落する）。
     - tulis ➔ penulis (筆者・作家)
     - curi ➔ pencuri (泥棒)
     - sapu ➔ penyapu (清掃道具・人)
     - pakai ➔ pemakai (使用者)
  2. 接頭辞 `pe-`（鼻音化しないタイプ）と `ber-` 動詞の対応関係:
     - kerja ➔ pekerja (労働者)
     - renang ➔ perenang (水泳選手)
     - ajar ➔ pelajar (学生・生徒)
  3. 「道具・器具」を作る peN-（penghapus: 消しゴム、pembuka botol: 栓抜き）。
  4. 人の「癖・性格」を表す pe- / peN-（pemalu: 恥ずかしがり屋、pemalas: 怠け者、perokok: 喫煙者）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
