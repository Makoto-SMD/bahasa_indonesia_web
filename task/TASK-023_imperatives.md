# 執筆指示書: TASK-023 命令文・禁止文・依頼文（tolong, silakan, coba, jangan）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/imperatives.md`
- **目的**: 相手に行動を促す・控えてもらうための命令・依頼・勧誘・禁止表現（tolong, silakan, coba, mari/ayo, jangan）の丁寧度と文法規則を解説する。
- **要件**:
  1. 命令文の語根化ルール（接頭辞 meN- が脱落して語根 Kata Dasar の形になる基本規則：例: menulis -> Tulis!）。接尾辞 `-lah` による語調の緩和。
  2. 丁寧な依頼: `tolong`（〜してください、助けて） vs `mohon`（非常に改まった公的依頼）。
  3. 許可・促し: `silakan`（どうぞ〜してください）。
  4. 試み・気軽な促し: `coba`（〜してみて）。
  5. 禁止: `jangan`（〜するな、〜しないでください） vs 丁寧な禁止（`tolong jangan...`, `dilarang...`）。
  6. 勧誘: `mari`（丁寧） vs `ayo` / `yuk`（カジュアル）（〜しましょう）。
  7. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
