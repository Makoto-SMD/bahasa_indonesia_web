# 執筆指示書: TASK-036 接尾辞 -i の反復・場所・対象付与

- **担当**: Writer
- **対象ファイル**: `docs/affixes/suffix-i.md`
- **目的**: 接尾辞 `-i` が持つ3大機能（場所・方向の付与「〜に…する」、対象への付与・浸透「〜を施す」、反復・執拗な動作「何度も〜する」）を解説する。
- **要件**:
  1. 場所・目的地への動作（前置詞 di/ke の内包: masuk ➔ memasuki [〜に入る], duduk ➔ menduduki [〜に座る・占領する], datang ➔ mendatangi [〜を訪れる]）。
  2. 対象への付与（〜を与える・備え付ける: obat ➔ mengobati [治療する], garam ➔ menggarami [塩を振る], cat ➔ mengecati [ペンキを塗る]）。
  3. 反復・継続動作（何度も〜する: pukul ➔ memukuli [何度も殴りつける], cium ➔ menciumi [何度もキスする]）。
  4. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
