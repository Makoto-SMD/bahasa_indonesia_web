## 2. 記事のねらい・ゴール
インドネシアでの生活や長期滞在、ビジネスで避けて通れないのが銀行取引と電子マネー。
民間最大手BCAや国営Mandiriでの口座開設（Buka rekening）、ATMでの現金引き出し（Tarik tunai）・預け入れ（Setor tunai）、多発する「カード吸い込み（Kartu tertelan）」トラブル対応、そしてインドネシア全土で普及率100%を誇るQR統一決済「QRIS（クリス）」のスマートな使いこなしまでを網羅する。

## 3. 必須構成項目
1. **主要銀行とATMの基本操作用語**
   - 4大銀行（BCA, Mandiri, BNI, BRI）
   - ATM画面の重要単語：`Tarik Tunai`（出金）, `Setor Tunai`（入金）, `Transfer`（振込・送金）, `Informasi Saldo`（残高照会）
   - 券種指定：`Pecahan Rp 50.000` / `Pecahan Rp 100.000`
2. **銀行窓口（Teller / Customer Service）での会話**
   - `Saya mau buka rekening tabungan baru.`（新しい普通預金口座を開設したいです）
   - 必要書類の確認（Paspor, KITAS, NPWP）
   - `Saya mau transfer uang ke rekening bank lain.`（他行口座へ送金をしたいです）
   - `Nomor rekening tujuan`（振込先口座番号）, `Nama pemilik rekening`（口座名義人）
3. **【トラブル対応】ATMにカードが吸い込まれたとき**
   - `Kartu ATM saya tertelan di mesin ini.`（私のATMカードがこの機械に吸い込まれました）
   - `Tolong blokir kartu ATM saya segera.`（今すぐ私のATMカードを利用停止・ブロックしてください）
   - `PIN saya terblokir karena salah tiga kali.`（暗証番号を3回間違えてロックされました）
4. **国家統一QR決済「QRIS（クリス）」の仕組みと実務会話**
   - QRIS（Quick Response Code Indonesian Standard）とは？
   - GoPay, OVO, Dana, モバイルバンキングアプリで共通スキャンできる革命的システム
   - 店舗でのやり取り：
     - `Bisa bayar pakai QRIS?`（QRISで払えますか？）
     - `Silakan di-scan barcode QRIS-nya.`（QRISのバーコードをスキャンしてください）
     - `Sudah berhasil, ini bukti transfernya.`（決済成功しました、これが完了画面です）
