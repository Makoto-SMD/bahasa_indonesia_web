# 執筆指示書: TASK-005 音節の区切り方と連音（リエゾン・音の脱落）

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/syllables-linking.md`
- **目的**: 単語を正しく音節分解（pemenggalan kata）する基本法則と、会話における連音（リエゾン）や音の脱落現象を解説する。
- **要件**:
  1. 母音と子音の配置パターン（V-CV, VC-CV, V-CCV など）による音節区切り。
  2. 接頭辞・接尾辞を含む派生語の音節区切り（語根と接辞の境界）。
  3. 会話で起きる連音現象（子音終わり＋母音始まりのスムーズな接続：例: `makan nasi` / `tidak ada`）。
  4. 口語での音の脱落（`sudah` -> `dah`, `tidak` -> `nggak` / `gak`, `sudah ada` -> `udah ada`）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
