## 2. 記事のねらい・ゴール
周囲辞（Konfiks）とは語根の前後に同時に付く接辞である。中でも `ke-...-an` はインドネシア語の表現力を飛躍させる最重要接辞。
「名詞化（美しさ・健康）」、「被害受動（雨に降られる・置き忘れる）」、「過度（大きすぎる・甘すぎる）」という一見全く異なる3大用法を持つ。
本記事では、この多義性を明快に整理し、語根の品詞と文脈から意図を即座に見抜く思考フレームを学習者に授ける。

## 3. 必須構成項目
1. **周囲辞（Konfiks）の基本と `ke-...-an` の構造**
   - 語根の前と後ろを挟むサンドイッチ構造：`ke-` ＋ 語根 ＋ `-an`
   - 音変化はなく、語根にそのまま付く
   - 品詞と文脈によって「名詞」「動詞（受動・被害）」「形容詞（過度）」の3つの顔を持つ
2. **用法①：抽象名詞化（形容詞/名詞/動詞 ＋ ke-...-an）**
   - 性質・状態・概念を名詞化するフォーマルな機能
   - `indah`（美しい）$\rightarrow$ `keindahan`（美しさ）
   - `sehat`（健康な）$\rightarrow$ `kesehatan`（健康）
   - `bersih`（清潔な）$\rightarrow$ `kebersihan`（清潔さ・美化）
   - `mampu`（能力がある）$\rightarrow$ `kemampuan`（能力）
   - `sulit`（難しい）$\rightarrow$ `kesulitan`（困難・苦難）
   - `ada`（ある）$\rightarrow$ `keadaan`（状態・状況）
   - `raja`（王）$\rightarrow$ `kerajaan`（王国）
3. **用法②：被害受動・無意図な被災（Adversative Passive）**
   - 主語が望まない事態に巻き込まれ、「〜に遭う」「〜されて困る」という感情・状態を表す
   - `hujan`（雨）$\rightarrow$ `kehujanan`（雨に降られる）
   - `panas`（暑い）$\rightarrow$ `kepanasan`（暑さにやられる・のぼせる）
   - `dingin`（寒い）$\rightarrow$ `kedinginan`（寒さに震える・凍える）
   - `tinggal`（残る）$\rightarrow$ `ketinggalan`（乗り遅れる・置き忘れる・時代遅れの）
   - `curi / maling`（盗む/泥棒）$\rightarrow$ `kemalingan`（泥棒に入られる）
   - `hilang`（消える）$\rightarrow$ `kehilangan`（失う・なくす）
   - `tahu`（知る）$\rightarrow$ `ketahuan`（ばれる・発覚する）
4. **用法③：過度・〜すぎる（形容詞 ＋ ke-...-an）**
   - 口語（Informal）で特に多用される「terlalu 〜（〜すぎる）」の短縮的表現
   - `besar`（大きい）$\rightarrow$ `kebesaran`（大きすぎる ※名詞の「偉大さ」との文脈区別も解説）
   - `kecil`（小さい）$\rightarrow$ `kekecilan`（小さすぎる）
   - `manis`（甘い）$\rightarrow$ `kemanisan`（甘すぎる）
   - `asin`（しょっぱい）$\rightarrow$ `keasinan`（しょっぱすぎる）
   - `mahal`（高い）$\rightarrow$ `kemahalan`（高すぎる）
5. **文脈による見分け方（名詞 vs 過度）**
   - 文頭や主語位置にあれば名詞、述語（述部）にあれば「〜すぎる」
6. **重要注意点**
   - ルビ構文（`{単語|読み}`）は一切使用しないこと。
