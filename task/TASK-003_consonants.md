# 執筆指示書: TASK-003 日本人が要注意の子音 (c, r, ng, ny, sy, kh)

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/consonants.md`
- **目的**: 日本人にとって聞き取りや発音が特に難しい子音（c, r, ng, ny, sy, kh, 語尾のk/h）の調音メカニズムと実践コツを詳しく解説する。
- **要件**:
  1. 「C」（常に「チャ行」）の解説と代表単語。
  2. 「R」（巻き舌・歯茎ふるえ音）と「L」の明確な違い。
  3. 鼻音「ng」（軟口蓋鼻音）と「ny」（硬口蓋鼻音）の出し方のコツ。
  4. 外来子音「sy」と「kh」（アラビア語起源など）。
  5. 語尾の子音の特殊ルール（語尾の「k」は喉の閉鎖音「ッ」、「h」は息の抜け音）。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
