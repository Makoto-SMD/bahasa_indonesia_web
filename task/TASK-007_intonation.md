# 執筆指示書: TASK-007 イントネーションと文末の抑揚（平叙文・疑問文・命令文）

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/intonation.md`
- **目的**: インドネシア語の自然な抑揚（イントネーション）、文の種類（平叙文、Yes/No疑問文、疑問詞疑問文、命令・依頼文）による文末ピッチ変化の法則を解説する。
- **要件**:
  1. 平叙文のイントネーション（下降調 ↘）。
  2. Yes/No 疑問文のイントネーション（文末上昇調 ↗、または語順そのままで尻上がりにする口語パターン）。
  3. 疑問詞（Apa, Siapa 等）疑問文のイントネーション（疑問詞部分が強調され、文末はやや下降 ↘）。
  4. 命令文・感嘆文のイントネーション（急激な下降 ↘）。
  5. 文末助詞（ya, kan, dong, kok）とイントネーションの相互作用。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
