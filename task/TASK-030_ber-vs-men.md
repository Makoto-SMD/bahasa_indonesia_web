# 執筆指示書: TASK-030 接頭辞 ber- と meN- の対比と使い分け

- **担当**: Writer
- **対象ファイル**: `docs/affixes/ber-vs-men.md`
- **目的**: 同じ語根に対して `ber-` がついた場合と `meN-` がついた場合で意味や文型がどのように劇的に変化するかを徹底比較する。
- **要件**:
  1. 根本原理の対比: `ber-`（内向き・主語自身の状態・自動詞） vs `meN-`（外向き・対象への働きかけ・他動詞）。
  2. 同一語根での意味激変ペア一覧（超頻出対比）:
     - `ajar` ➔ `belajar`（学ぶ） vs `mengajar`（〜を教える）
     - `henti` ➔ `berhenti`（止まる） vs `menghentikan`（〜を止める）
     - `ubah` ➔ `berubah`（変わる） vs `mengubah`（〜を変える）
     - `tukar` ➔ `bertukar`（互いに交換する） vs `menukar`（〜を取り替える）
     - `pindah` ➔ `berpindah`（引っ越す） vs `memindahkan`（〜を移動させる）
     - `temu` ➔ `bertemu`（会う） vs `menemukan`（〜を発見する）
  3. 文法パターンの対比: 【主語 ＋ ber-動詞】 vs 【主語 ＋ meN-動詞 ＋ 目的語】。
  4. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
