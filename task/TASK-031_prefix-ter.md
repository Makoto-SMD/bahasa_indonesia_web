# 執筆指示書: TASK-031 接頭辞 ter- の5大機能

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-ter.md`
- **目的**: 1つの接頭辞でありながら最上級から「うっかり無意図」まで多彩な顔を持つ接頭辞 `ter-` の5大機能を体系的に整理する。
- **要件**:
  1. `ter-` の音変化ルール（基本形 ter-、r頭文字や-er-音節で te- に変化: te-rasa, te-rima 等）。
  2. 5大機能の徹底解説:
     - ① 最上級（Superlatif）: 形容詞について「最も〜」（terbaik, terbesar, tertinggi）
     - ② 無意図・偶発・アクシデント（Ketidaksengajaan）: 「うっかり〜してしまう、不意に〜された」（terjatuh, tertidur, tertinggal）
     - ③ 完了・結果状態（Keadaan/Selesai）: 「すでに〜されている状態」（terbuka, tertutup, tertulis）
     - ④ 自発・潜在（Spontanitas）: 「自然と〜と思われる・感じられる」（terasa, teringat, terbayang）
     - ⑤ 可能・能力（Kesanggupan）: 否定文で「〜できない」（tidak terangkat, tidak terbeli）
  3. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
