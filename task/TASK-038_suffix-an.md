# 執筆指示書: TASK-038 接尾辞 -an の名詞化（結果・道具・集合・頻度）

## 1. 基本情報
- 記事番号: 038
- ファイルパス: `docs/affixes/suffix-an.md`
- 担当: Writer (執筆担当)
- 監修: Director (編集長)

## 2. 記事のねらい・ゴール
接尾辞 `-an` はインドネシア語で最も高頻度に登場する名詞化接尾辞である。動詞から「結果」「対象」「道具」を作り、名詞から「集合」「定期性・単位」を作る。
本記事では、丸暗記ではなく語根と接尾辞 `-an` の意味関係を体系化し、日常会話から新聞記事まで瞬時に単語の意味を推測・理解できる力を養う。

## 3. 必須構成項目
1. **接尾辞 `-an` の全体像とルール**
   - 語根にそのまま `-an` を後置する極めてシンプルな構造
   - 主な品詞変化：動詞 → 名詞（結果・対象・道具）、名詞 → 名詞（集合・単位・定期性）、形容詞 → 名詞/形容詞（模倣・性質）
2. **用法①：動作の結果・対象（動詞語根 ＋ -an）**
   - `makan`（食べる）→ `makanan`（食べ物・料理）
   - `minum`（飲む）→ `minuman`（飲み物）
   - `tulis`（書く）→ `tulisan`（筆跡・文章・書かれたもの）
   - `baca`（読む）→ `bacaan`（読書物・読み物）
   - `pikir`（考える）→ `pikiran`（考え・思考・思想）
3. **用法②：道具・器具・手段（動詞語根 ＋ -an）**
   - `timbang`（量る）→ `timbangan`（はかり・体重計）
   - `gantung`（吊るす）→ `gantungan`（ハンガー・吊り具）
   - `pegang`（握る）→ `pegangan`（取っ手・手すり・心の拠り所）
   - `tutup`（閉める）→ `tutupan` / `penutup`（フタ・覆い）
4. **用法③：定期性・期間・頻度・単位（時間名詞/単位 ＋ -an）**
   - `hari`（日）→ `harian`（日刊・毎日の・日給）
   - `minggu`（週）→ `mingguan`（週刊・毎週の・週給）
   - `bulan`（月）→ `bulanan`（月刊・月払いの・月給）
   - `tahun`（年）→ `tahunan`（年次の・年間の）
   - `kilo`（キロ）→ `kiloan`（量り売り・キロ単位の。ランドリー等で頻出）
   - `ratus` → `ratusan`（数百の）, `ribu` → `ribuan`（数千の）
5. **用法④：集合・類似・模倣（名詞/形容詞重複 ＋ -an）**
   - `sayur-sayuran`（野菜類全般）
   - `buah-buahan`（果物類全般）
   - `obat-obatan`（薬品類・医薬品）
   - `orang-orangan`（かかし・人形）
   - `mobil-mobilan`（ミニカー・おもちゃの車）
6. **注意点・口語での特徴**
   - 口語では仕事・用事を表す `pekerjaan` の代わりに `kerjaan` を日常的によく使う
   - ルビ構文（`{単語|読み}`）は一切使用しないこと。
