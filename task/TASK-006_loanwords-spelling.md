# 執筆指示書: TASK-006 外来語の綴りと発音ルール（英語・オランダ語・アラビア語起源）

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/loanwords-spelling.md`
- **目的**: インドネシア語に大量に含まれるオランダ語・英語・アラビア語・ポルトガル語・中国語からの借用語の表記ルールと発音規則を解説する。
- **要件**:
  1. 英語・オランダ語由来の文字変換ルール（-tion -> -si, c -> k/s, ph -> f, x -> ks, y -> i など）。
  2. オランダ語起源の身近な日常語（kantor, handuk, kamar, gratis, bensin, knalpot など）。
  3. アラビア語・ポルトガル語起源の身近な単語（waktu, kabar, selamat, sabun, keju, sepatu, mentega など）。
  4. 現代英語の直接借用と発音のインドネシア化（download -> unduh / download, online -> daring / online など）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
