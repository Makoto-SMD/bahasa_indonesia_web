# 執筆指示書: TASK-015 基本前置詞（di, ke, dari）の場所表現

- **担当**: Writer
- **対象ファイル**: `docs/grammar/prepositions-location.md`
- **目的**: インドネシア語の空間・場所移動を表す3大基本前置詞（di: 〜で/に、ke: 〜へ、dari: 〜から）の法則と、複合場所表現（di atas, di bawah, di dalam, di luar 等）を完全攻略させる。
- **要件**:
  1. 3大空間前置詞の基本役割（静止・所在の `di`、到達・方向の `ke`、起点・出所の `dari`）。
  2. 接頭辞の `di-`（受動態）と前置詞の `di`（空白を空けて書く）の表記規則の違い（超重要！）。
  3. 位置名詞（atas, bawah, dalam, luar, depan, belakang, samping, antara）と組み合わせた複合前置詞。
  4. 人を目的地・起点とする場合の注意（ke ではなく kepada、dari ではなく dari pada/dari）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
