# 執筆指示書: TASK-009 基本語順（SVO）と後置修飾の絶対原則

- **担当**: Writer
- **対象ファイル**: `docs/grammar/word-order.md`
- **目的**: インドネシア語文法の最重要基盤である「SVO語順（主語・動詞・目的語）」と「名詞＋修飾語（後置修飾 / DMの法則）」を日本人に直感的に叩き込む。
- **要件**:
  1. 英語との語順比較（SVO型言語であること、be動詞に相当する語が基本不要であること）。
  2. 後置修飾の絶対原則（DMの法則: Diterangkan＝修飾される語 ＋ Menerangkan＝修飾する語）。日本語の「赤い車」が「車・赤い（mobil merah）」になる理由。
  3. 名詞＋形容詞、名詞＋名詞（所有格）、名詞＋指示詞の連結順序（例: `buku merah saya ini` ＝ この私の赤い本）。
  4. 例文カード（`.id-example`）を複数掲載。
  5. 実践対話（`.dialogue-box`）。
