## 2. 記事のねらい・ゴール
インドネシア旅行や現地生活のハイライトである外食。
高級レストランから庶民派食堂（Warung）、おしゃれなカフェまで、スムーズに注文して食事を楽しむための必須表現を網羅する。
特にインドネシア特有の「お茶にはデフォルトで砂糖が大量に入っている（es teh manis問題）」や「辛さ調整（jangan pedas, sambal dipisah）」、「店員の呼び方（Mas/Mbak）」、「持ち帰り（bungkus）」など、現地のリアルな飲食習慣に直結する知恵を完全伝授する。

## 3. 必須構成項目
1. **入店と店員への呼びかけ**
   - 店員の呼び方：男性には `Mas!`（マス）、女性には `Mbak!`（ムバッ）
   - 人数と座席：`Untuk berapa orang?`（何名様ですか？） $\rightarrow$ `Untuk dua orang.`（2人です）
   - `Bebas rokok`（禁煙席・ノン喫煙エリア） vs `Bisa merokok`（喫煙席）
2. **メニューの確認と注文フレーズ**
   - `Boleh minta menunya?`（メニューをいただけますか？）
   - `Apa menu yang paling rekomendasi di sini?`（ここの一番おすすめのメニューは何ですか？）
   - `Saya mau pesan ini satu, dan ini satu.`（これを1つ、そしてこれを1つお願いします。）
3. **辛さとお茶（砂糖）のカスタマイズ（超重要！）**
   - 辛さ調整：
     - `Jangan pedas ya.`（辛くしないでくださいね）
     - `Pedasnya sedang saja.`（辛さは中くらいで）
     - `Sambal dipisah, tolong.`（サンバル［チリソース］は別皿にしてください）
   - ドリンク注文の落とし穴：
     - `Es teh manis`（デフォルトの激甘アイスティー）
     - `Es teh tawar`（無糖のアイスティー ※必須単語！）
     - `Tanpa gula`（砂糖なしで）
     - `Air mineral dingin / biasa`（冷たい/常温のミネラルウォーター）
4. **店内飲食（Makan di sini） vs 持ち帰り（Bungkus）**
   - `Makan di sini atau bungkus?`（店内でお召し上がりですか、それともお持ち帰りですか？）
   - `Bungkus ya, Mas.`（持ち帰りでお願いします、お兄さん）
   - `Bisa tolong bungkus sisanya?`（残りを持ち帰り用に包んでくれますか？）
5. **味の感想を伝えるボキャブラリー**
   - `enak`（美味しい）, `enak sekali / mantap!`（すごく美味しい！最高！）
   - `pedas`（辛い）, `manis`（甘い）, `asin`（しょっぱい）, `asam`（酸っぱい）, `gurih`（旨味がある・香ばしい）
6. **お会計（Minta bon）のフレーズ**
   - `Mas, minta bon / tagihan tolong.`（お兄さん、伝票・お会計をお願いします。）
   - `Bisa bayar pakai QRIS?`（QRISで払えますか？）
   - `Bisa bayar pisah?`（別々にお会計できますか？）
7. **実践ロールプレイダイアログ（カフェでの注文とリクエスト）**
