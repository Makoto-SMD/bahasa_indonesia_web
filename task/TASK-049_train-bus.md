## 2. 記事のねらい・ゴール
近年のインドネシア（特にジャカルタ首都圏）の公共交通は劇的な進化を遂げている。
日本の中古車両が活躍する近郊電車「KRL」、日本の技術で建設された地下鉄「MRT」、自動運転の「LRT」、そして東南アジア初の高速鉄道「Whoosh（ウーシュ）」、BRT「TransJakarta」。
これら公共交通機関を乗りこなすための電子カード（E-money/KMT）のチャージ、ホーム番線確認、女性専用車両ルール、乗り換え、高速鉄道の予約・チェックイン会話を完全網羅する。

## 3. 必須構成項目
1. **公共交通機関の種類と特徴**
   - `KRL Commuter Line`（首都圏電車：日本の中古車両）
   - `MRT Jakarta`（地下鉄）
   - `LRT Jabodebek`（高架軽量鉄道）
   - `Kereta Cepat Whoosh`（ジャカルタ〜バンドン高速鉄道）
   - `TransJakarta`（専用レーンを走るBRTバス）
2. **切符・電子マネーカード（E-money）の購入とチャージ**
   - 電子マネーカードの重要性（Flazz, e-money, TapCash, Brizzi, KMT）
   - `Bisa tolong isi saldo kartu ini Rp 50.000?`（このカードに5万ルピア分チャージしてくれますか？）
   - `Berapa tarif sampai Stasiun Bogor?`（ボゴール駅までの運賃はいくらですか？）
   - `Tap-in` / `Tap-out`（改札機へのタッチ）
3. **駅構内・ホームでの案内確認フレーズ**
   - `Kereta ke arah Manggarai ada di peron berapa?`（マンガライ方面への電車は何番線ホームですか？）
   - `Apakah kereta ini langsung atau harus transit?`（この電車は直通ですか、それとも乗り換えが必要ですか？）
   - `Jadwal keberangkatan berikutnya jam berapa?`（次の出発時刻は何時ですか？）
4. **【超重要】車内ルールとマナー**
   - `Gerbong khusus wanita`（女性専用車両：先頭・最後尾車両。男性が乗ると厳重に注意される！）
   - `Kursi prioritas`（高齢者・妊婦・子連れ優先席）
5. **高速鉄道Whoosh・長距離特急列車（KAI）の利用**
   - `Kereta Api Jarak Jauh (KAI)`（長距離特急列車）
   - 座席クラス：`Eksekutif`（最上位エグゼクティブ）, `Bisnis`, `Ekonomi Premium`
   - `Tunjukkan boarding pass dan kartu identitas.`（搭乗券と身分証を提示してください）
6. **実践ロールプレイダイアログ（駅の窓口でのチャージとホーム確認）**
