# 執筆指示書: TASK-011 人称代名詞と親称・敬称システム

- **担当**: Writer
- **対象ファイル**: `docs/grammar/pronouns.md`
- **目的**: インドネシア語の最も文化的で豊かな領域である「人称代名詞（一人称・二人称・三人称）」と「親称・親族名称（Bapak, Ibu, Mas, Mbak等）」を体系化して解説する。
- **要件**:
  1. 一人称（saya: 丁寧・フォーマル vs aku: 親しい友人・恋人）、二人称（Anda: 改まった敬称 vs kamu: 親しい相手）。
  2. 【超重要】一人称複数（kami: 聞き手を含まない「私たち」 vs kita: 聞き手を含む「私たち」）の絶対的区別。
  3. 二人称代名詞の代わりに使われる親称（Bapak/Pak, Ibu/Bu, Mas, Mbak, Kak, Bang, Om, Tante）。
  4. 三人称（dia: 単数、beliau: 尊敬、mereka: 複数）。性別（彼・彼女）による区別がないことの解説。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
