# 執筆指示書: TASK-056 緊急事態（事故・盗難・紛失・警察）のサバイバルフレーズ

## 1. 基本情報
- 記事番号: 056
- ファイルパス: `docs/conversation/emergencies.md`
- 担当: Writer (執筆担当)
- 監修: Director (編集長)

## 2. 記事のねらい・ゴール
スリ、盗難、パスポート紛失、交通事故、火災などの緊急時に、周囲に助けを求め、警察（Polisi）や病院に正確に通報するためのサバイバル表現を網羅する。
特にパスポート再発行や保険金請求に不可欠な警察の紛失届証明書（Surat Laporan Kehilangan）の取得手続きや、現地の緊急電話番号（110, 118, 112）まで、非常事態を乗り切るための防犯知識を完全伝授する。

## 3. 必須構成項目
1. **緊急時に大声で助けを呼ぶ叫び声**
   - `Tolong!`（助けて！・Help!）
   - `Ada copet / maling!`（スリだ！ / 泥棒だ！）
   - `Kebakaran!`（火事だ！）
   - `Tolong panggilkan polisi / ambulans sekarang!`（今すぐ警察/救急車を呼んでください！）
   - インドネシアの主要緊急電話番号（警察: 110, 救急車: 118/119, 消防: 113, 総合緊急通報: 112）
2. **盗難（Kemalingan / Dicopet）と紛失（Kehilangan）の届出**
   - 警察署（Kantor Polisi / Polsek）へ行く
   - `Dompet dan paspor saya hilang di stasiun.`（駅で財布とパスポートをなくしました）
   - `Tas saya dijambret saat jalan kaki di trotoar.`（歩道を歩いているときにカバンをひったくられました）
   - 最重要書類：`Surat Tanda Penerimaan Laporan Kehilangan`（警察の紛失届受領証明書）の発行依頼
3. **交通事故（Kecelakaan Lalu Lintas）の現場対応**
   - `Terjadi kecelakaan antara motor dan mobil.`（バイクと車の事故が発生しました）
   - `Ada orang yang terluka dan berdarah.`（負傷して出血している人がいます）
   - `Tolong jangan dipindahkan, tunggu ambulans datang.`（動かさないでください、救急車が来るのを待ちましょう）
4. **日本大使館・領事館への連絡**
   - `Kedutaan Besar Jepang (Embassy of Japan)`
   - `Saya perlu menghubungi Kedutaan Besar Jepang untuk penerbitan paspor baru.`（新しいパスポート発給のために日本大使館に連絡する必要があります）
5. **実践ロールプレイダイアログ（警察署で盗難・紛失証明書を作成してもらう会話）**
