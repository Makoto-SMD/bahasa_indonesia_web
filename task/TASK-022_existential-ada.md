# 執筆指示書: TASK-022 存在表現（ada の多機能性）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/existential-ada.md`
- **目的**: インドネシア語で最も便利で多機能な動詞「ada」の3大用法（存在「〜がある/いる」、所有「〜を持っている」、在席・所在）と否定形（tidak ada / gak ada）を解説する。
- **要件**:
  1. 存在用法: 英語の `There is / There are`、日本語の「〜がある/いる」（有生・無生の区別なく ada 一つでOK）。
  2. 所有用法: 【主語 ＋ ada ＋ 目的物】で英語の `have`（持っている）を表す用法（例: `Saya ada uang.`）。
  3. 所在・在席用法: 【主語 ＋ ada ＋ 場所】（例: `Bos ada di kantor?`）。
  4. 否定形: `tidak ada`（ない・いない）、口語の `gak ada`。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
