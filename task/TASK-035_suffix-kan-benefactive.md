# 執筆指示書: TASK-035 接尾辞 -kan の受益用法と対象化構文

- **担当**: Writer
- **対象ファイル**: `docs/affixes/suffix-kan-benefactive.md`
- **目的**: 接尾辞 `-kan` の第2の重要機能である「受益（Benefaktif：〜のために…してあげる/くれる）」構文（二重目的語構文）を解説する。
- **要件**:
  1. 受益用法（Benefaktif）の定義: 英語の `give / buy someone something`（SVOO構文）に相当。
  2. 構文の2つの書き換えパターン:
     - パターンA（-kan あり）: 【動詞-kan ＋ 受益者 ＋ 物】（例: `Saya membelikan ibu baju baru.`）
     - パターンB（-kan なし）: 【動詞 ＋ 物 ＋ untuk 受益者】（例: `Saya membeli baju baru untuk ibu.`）
  3. 日常生活で最も使う受益動詞（membelikan [買ってあげる], membawakan [持ってきてあげる], membuatkan [作ってあげる], membukakan [開けてあげる], menceritakan [話して聞かせる]）。
  4. 依頼文での強力な活用: `Tolong carikan saya taksi!`（タクシーを探してください）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
