# 執筆指示書: TASK-004 二重母音（ai, au, oi）とアクセントの法則

- **担当**: Writer
- **対象ファイル**: `docs/pronunciation/diphthongs-accent.md`
- **目的**: インドネシア語の二重母音（diftong: ai, au, oi）と連続母音（vokal rangkap）の違い、および語のアクセント（強勢）が置かれる法則を解説する。
- **要件**:
  1. 二重母音（ai, au, oi）の定義と滑らかな発音の要領。
  2. 二重母音と連続母音の違い（例: `santai` [ai] vs `air` [a-ir]）。
  3. アクセント（ストレス）の黄金原則: **「原則として後ろから2番目の音節（penultimate syllable）を強く、やや長めに読む」**。
  4. 例外（後ろから2番目の音節が曖昧母音 /ə/ の場合、最後の音節に強勢が移動する）。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。
