# 執筆指示書: TASK-016 抽象前置詞（pada, untuk, dengan, tentang, tanpa, kepada）

- **担当**: Writer
- **対象ファイル**: `docs/grammar/prepositions-abstract.md`
- **目的**: 物理的な場所・移動以外の抽象的な関係（時・対象・目的・手段・随伴・話題・除外）を表す主要前置詞を整理する。
- **要件**:
  1. `pada` の2大機能（時「〜に」: pada jam..., 人・抽象物「〜において・〜へ」: pada saya）。
  2. `untuk`（〜のために、〜にとって）と目的・用途の表現。
  3. `dengan` の3大用法（手段「〜で・〜を使って」、同伴「〜と一緒に」、様態「〜をもって」）。口語の `sama` との関連。
  4. `tentang`（〜について・〜に関して）と `tanpa`（〜なしで・〜することなく）。
  5. `kepada`（人に対する方向・宛先）と `pada` の使い分け。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
