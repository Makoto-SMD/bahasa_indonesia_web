# 執筆指示書: TASK-064 社内ミーティング・意見表明・賛成・反対のスマートな表現

## 担当役職
- 企画・指示: 編集長 (Director)
- 執筆: 執筆担当 (Writer)
- 校正: 校正担当 (Reviewer)
- 検証: ビルド・検証 (Engineer)
- 監修: 上司 (BOSS)

## 記事仕様
- **ファイル名**: `docs/business/meetings-opinions.md`
- **タイトル**: 社内ミーティング・意見表明・賛成・反対のスマートな表現
- **想定読者**: インドネシア人スタッフとの定例会議やプロジェクトミーティングで発言・進行を行う日本人ビジネスパーソン
- **記事の構成案**:
  1. 会議の開始・司会進行フレーズ（出席確認、議題の提示、発言の促し）
  2. 自分の意見を述べる表現（Saya rasa..., Menurut saya..., Berdasarkan data...）
  3. 賛成・合意を示すスマートなフレーズ（Saya setuju..., Sepakat...）
  4. 角を立てずに反対・懸念・代案を伝えるテクニック（Ada pertimbangan lain..., Bagaimana kalau...）
  5. 質問・確認・割り込みのフレーズ（Boleh saya potong sebentar?, Maksudnya...）
  6. 会議の締めくくり・決定事項の確認（Kesimpulannya..., Action items）
  7. 実践対話とクイズ

## チェック項目
- ❌ **ルビ（`{単語|カタカナ}`）は絶対に使用しない。**
- インドネシア人の会議文化（和を重んじる Musyawarah mufakat、ストレートな批判を避ける配慮）をコラムで言及。
- `.id-example` や `.dialogue-box` などのUIコンポーネントを活用。
