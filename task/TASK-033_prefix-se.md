# 執筆指示書: TASK-033 接頭辞 se- の多機能性

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-se.md`
- **目的**: 単語の頭につく極小の接頭辞 `se-` が生み出す「1つの単位（satu）」「同一・同等（sama）」「全体（seluruh）」「〜するとすぐに（setelah/begitu）」の4大機能を解説する。
- **要件**:
  1. ① 「1つ」を表す `se-`（satu の短縮形態素: seorang, sebuah, sehari, serumah 等）。
  2. ② 「同一・同等（同じくらい〜）」を表す `se-`（sama の意味: sekelas, sekantor, setinggi, seenak 等）。
  3. ③ 「全体・〜じゅう」を表す `se-`（seluruh の意味: se-Indonesia, sedunia, sekeluarga, sekota 等）。
  4. ④ 「〜するとすぐに・〜した途端に」を表す時間副詞的 `se-`（setibanya, sesampainya 等）。
  5. 固有名詞や大文字の前でのハイフン連結ルール（se-Indonesia, se-Jawa）。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
