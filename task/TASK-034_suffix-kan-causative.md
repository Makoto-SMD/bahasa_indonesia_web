# 執筆指示書: TASK-034 接尾辞 -kan の使役用法

- **担当**: Writer
- **対象ファイル**: `docs/affixes/suffix-kan-causative.md`
- **目的**: 動詞の末尾について「〜させる（使役 / Kausatif）」という意味を付与する接尾辞 `-kan` の文法機能と構文を徹底解説する。
- **要件**:
  1. 使役接尾辞 `-kan` のコア機能（英語の make / cause someone to do something）。
  2. 形容詞 ＋ -kan ➔ 「〜の状態にさせる」（bersih ➔ membersihkan [清掃する＝きれいにする]、panas ➔ memanaskan [温める]、besar ➔ membesarkan [大きくする]）。
  3. 自動詞 ＋ -kan ➔ 「〜を行動させる・動かす」（masuk ➔ memasukkan [中に入れる]、keluar ➔ mengeluarkan [外に出す]、jatuh ➔ menjatuhkan [落とす]）。
  4. 能動態（meN-...-kan）と受動態（di-...-kan）のペア構文。
  5. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
