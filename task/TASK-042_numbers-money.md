## 2. 記事のねらい・ゴール
インドネシアに滞在・旅行する日本人が最も苦戦するのが「ルピア（Rupiah）の桁数の多さ」である。
ゼロが多いため「1万ルピア」「10万ルピア」「100万ルピア」が瞬時にパッと出てこない。
本記事では、基本の数字（0〜99）から大きな桁数（ribu, juta, miliar）、ピリオドとカンマの表記ルール、日常生活での省略スラング（50k、ceban等）、両替や会計で必須のフレーズまでを完全網羅する。

## 3. 必須構成項目
1. **基本の数字（0〜10）**
   - nol, satu, dua, tiga, empat, lima, enam, tujuh, delapan, sembilan, sepuluh
2. **2桁の数字（11〜99）**
   - 10番台の `-belas`（sebelas, dua belas, tiga belas...）
   - 10の位の `-puluh`（dua puluh, tiga puluh...）
   - 「se-」の規則（satu-belas ではなく sebelas、satu-puluh ではなく sepuluh）
3. **大きな桁数と3桁区切り（ribu, juta, miliar）**
   - 日本語の「万」とインドネシア語の「千（ribu）/ 百万（juta）」の対比表
   - `seratus`（100）, `seribu`（1,000）
   - `sepuluh ribu`（10,000 ＝ 1万）
   - `seratus ribu`（100,000 ＝ 10万）
   - `satu juta`（1,000,000 ＝ 100万）
   - `sepuluh juta`（10,000,000 ＝ 1,000万）
   - `seratus juta`（100,000,000 ＝ 1億）
   - `satu miliar`（1,000,000,000 ＝ 10億）
   - `satu triliun`（1,000,000,000,000 ＝ 1兆）
4. **インドネシアの表記ルール：ピリオドとカンマの逆転**
   - インドネシアでは「ピリオドが3桁区切り」「カンマが小数点」
   - 例: `Rp 50.000,00`（5万ルピア）
5. **日常会話での金額短縮・スラング**
   - `50k`（k = kilo = ribu）
   - 千の単位を省略する口語（Lima puluh = 50 ribuのこと）
   - 中華系インドネシア語起源の数詞（ceban = 1万, goceng = 5千, goban = 5万）の紹介
6. **買い物・会計・両替で使える実践フレーズ**
   - `Berapa harganya?`（いくらですか？）
   - `Totalnya berapa?`（合計でいくらですか？）
   - `Bisa pakai uang pas?`（お釣りが出ないようちょうど出せますか？）
   - `Ini kembaliannya.`（こちらお釣りです。）
   - `Bisa bayar pakai QRIS / tunai?`（QRIS/現金で払えますか？）
   - `Saya mau tukar uang Yen ke Rupiah.`（円をルピアに両替したいです。）
   - `Berapa kurs hari ini?`（今日のレートはいくらですか？）
