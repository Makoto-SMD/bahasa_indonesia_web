# 執筆指示書: TASK-027 接頭辞 meN- の自動詞と他動詞の使い分け

- **担当**: Writer
- **対象ファイル**: `docs/affixes/prefix-men-transitivity.md`
- **目的**: 接頭辞 `meN-` が作り出す「他動詞（目的語を必要とする動詞）」と「自動詞（目的語を取らない動詞）」の違い、および口語で meN- が脱落する会話ルールの実態を解説する。
- **要件**:
  1. 他動詞 meN-（目的語 O が必須: membaca buku, membeli mobil 等）。
  2. 自動詞 meN-（目的語不要・状態や自然現象・進行・音: menangis, menyanyi, merokok, mendarat, menguning 等）。
  3. 名詞から作られる meN- 動詞（rokok ➔ merokok、darat ➔ mendarat）。
  4. 形容詞から作られる meN- 動詞（kuning ➔ menguning [黄色くなる]、luas ➔ meluas [広がる]）。
  5. 会話・口語における meN- の脱落現象（口語では `Saya beli kopi.` のように meN- が省略される実態と、省略してはいけないケース）。
  6. 例文カード（`.id-example`）と対話ボックス（`.dialogue-box`）。※ルビ構文は使用禁止。
